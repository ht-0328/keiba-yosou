# 03 単勝のルール

**単勝は、単勝 10.0〜19.9倍の馬を1点だけ買う券種である。** 払戻率が全券種で最も高く、1着だけを当てるので無駄な買い目が出ない。1着の確信がある本命馬がいるときも、連勝式に逃げずに単勝1点で勝負する。1倍台の馬は買わない。

## 券種の特徴

| 項目 | 内容 |
|---|---|
| 当てるもの | 1着の1頭 |
| 払戻率 | 80%（複勝と並んで最も高い） |
| 向いている狙い | 単勝 10.0〜19.9倍の馬の1点勝負。1着の確信がある本命馬の1点勝負 |
| 1レースの点数 | 1点（勝ち馬を絞れないときは、オッズに応じて複数に配分） |
| 強み | 多くの人が複系に流れるため、穴馬の単勝は実力より高いオッズで残りやすい |

## ルール

| ID | いつ（条件） | どうする（行動） | なぜ | 判定に使う情報 | 検証 |
|---|---|---|---|---|---|
| TAN-01 | 常に | 単勝 10倍以上 50倍未満の馬だけを買う。10.0〜19.9倍を優先する | 10.0〜19.9倍は単勝の回収率が最も高い帯（STAT-06）。1.0〜4.9倍は過剰人気で、50倍以上は回収率が落ちる | 締め切り前の単勝オッズ | 未 |
| TAN-02 | 常に | 1レースの点数は1点。多くても 2〜3点 | 点数を増やすと合成オッズが下がり、単勝の強みが消える | 買い目の数 | 未 |
| TAN-03 | 候補を選ぶとき | 勝ち切るか大敗するかの両極端な馬（逃げ馬、条件が一変した馬）を選ぶ | 単勝は2着以下に価値がない。安定して 2〜3着に来る馬より、勝ち切る型が向く | 脚質、前走との条件の違い | 未 |
| TAN-04 | 候補を選ぶとき | 前走 6着以下の馬を候補に入れる | 前走の着順が悪いと、力より人気を落とす | 前走着順 | 未 |
| TAN-05 | 候補を選ぶとき | 前走 2着の馬は買わない | 過剰人気になりやすく、単勝の回収率が最も低い（STAT-13） | 前走着順 | 未 |
| TAN-06 | 候補を選ぶとき | 3〜4歳の逃げ・先行馬を優先する。6歳以上の馬と追い込み馬は避ける | 高齢馬と追い込み馬は着を落としやすく、1着を取り切れない（STAT-22） | 年齢、脚質 | 未 |
| TAN-07 | 候補を選ぶとき | 上級条件で芝⇔ダートを替えてきた穴馬は候補に入れる | 芝ダ替わりの穴馬は激走する割合が高い（STAT-21） | 前走と今走の芝ダ、クラス | 未 |
| TAN-08 | 単勝 1.0〜2.9倍の圧倒的人気馬がいるとき | その馬が、前走の展開や騎手の人気で過剰人気になっていないか確かめる。勝算が薄ければ、その馬を消して 10.0〜19.9倍の馬の単勝を買う | 1番人気が勝つのは約 3割（STAT-01）。圧倒的人気馬が飛ぶレースでは、中穴の単勝の期待値が上がる | 単勝オッズ、前走の展開、騎手 | 未 |
| TAN-09 | 1着になる確信のある本命馬がいるとき | 連勝式に逃げず、その馬の単勝1点で勝負する | 1点なら無駄な買い目が無く、期待値が最も高い | 本命馬の勝算 | 未 |
| TAN-10 | メインレース（11R）を買うとき | 直前の 10R の 1〜3着の馬番を見て、隣り合う2つに挟まれた番号（9番と11番なら 10番）の単勝（複勝も）を買う | 仕組みの説明は無い。年間の集計で単勝回収率が 200% を超えたという結果だけ（STAT-17） | 10R の 1〜3着の馬番 | 未 |
| TAN-11 | 常に | 単勝 1倍台の馬は買わない。買うなら 2.0倍以上 | 1倍台の勝率は約 50% 以上あるが（STAT-07）、1回外れたときの損に見合わない。1.5倍で2連勝しても、3回目で外れるとマイナスになる | 単勝オッズ | 未 |
| TAN-12 | 勝ち馬を1頭に絞れないとき | 無理に1点にせず、候補それぞれにオッズに応じた金額を配分して買う | どれが勝っても同じ回収率になる。3.0倍に 5,000円、5.0倍に 3,000円、7.5倍に 2,000円 の計 10,000円なら、どれが勝っても 15,000円（回収率 150%） | 候補の単勝オッズ | 未 |
| TAN-13 | 上位人気の馬を買う前に | 次に当たる馬は買わない。①3勝クラス以上のダートで上位人気になった牝馬 ②夏競馬でトップハンデを背負う馬 ③重賞で1番人気になった経験が無いのに、重賞初挑戦で1番人気になった馬 ④不利な枠（芝の内が有利なコースの大外枠、ダートで砂を被りやすい内枠）に入った馬 | ①パワー不足 ②斤量の負担 ③実績に見合わない人気 ④枠の不利 | クラス・芝ダ・性別、開催時期・斤量、過去の重賞での人気、枠順とコース | 未 |

TAN-01 と TAN-09、TAN-02 と ALL-07・TAN-12 は食い違う（[01 の「ルール同士の食い違い」](01-overview.md#ルール同士の食い違い)）。

## 買い目の例

架空のレース（馬番・オッズはこの例のために作った値）。

> 16頭立て。候補は2頭。
>
> - 7番: 4歳、逃げ、前走 8着、単勝 18.0倍
> - 12番: 3歳、先行、前走 2着、単勝 6.5倍
>
> 判定:
>
> - 7番は TAN-01（10.0〜19.9倍）・TAN-04（前走 6着以下）・TAN-06（4歳の逃げ馬）に合う → 買う
> - 12番は TAN-01（10倍未満）と TAN-05（前走 2着）に反する → 買わない
>
> 買い目: 単勝 7番 の1点（TAN-02）
>
> 勝ち馬を 7番と 9番（単勝 12.0倍）に絞れないなら、TAN-12 で 7番に 4,000円、9番に 6,000円 のように配分する（どちらが勝っても約 72,000円）。
