# 12 ルールの根拠になっている統計

**この文書の目的:** ルールの「なぜ」に使われている統計の主張を1か所に集め、このリポジトリのデータ（jvdata-store の DuckDB）で確かめる対象にする。「主張されている値」の列は出どころの主張のままで、確かめた結論は「検証」の列に書く。

**状態:** 24本を元DB の全期間（2011年1月〜）と直近5年で確かめた。**当たっている 13本・ずれている 10本・確かめられない 1本。** 数値・数え方・作り直すコマンドは Git の対象外の `reports/馬券の買い方/統計の検証/README.md` にある。人気・オッズは確定のもので数えた（買う時点のオッズではない。[13-issues.md](13-issues.md) の課題5）。

- 検証は元DB で行い、結果（JV-Data から集計した実値）は Git の対象外の `reports/馬券の買い方/統計の検証/` に置いた。この文書には実値を書かず、「検証」の列に結論（当たっている／ずれている／確かめられない）と結果の場所だけを書く。
- 主張の値が「数字なし」のものは、傾向として述べられているだけである。検証では、その傾向があるかどうかを見る。
- 確かめた結果、主張と違ったときは、その統計を使っているルールの「今の扱い」を見直す（[01-overview.md](01-overview.md#ルール同士の食い違い)）。ルールと買い目の型そのものは個別には検証しないと決めたので（[13-issues.md](13-issues.md) の課題1）、ずれていた統計を根拠にするルールも表からは外さない。

## 検証で決めたこと

- **期間と対象**: 元DB の全期間（2011年1月〜）の中央競馬の全レース。資料の時点に近い直近5年（2021年〜）も並べ、年ごとの表も添えた。統計が競馬場やクラスを決めているもの（STAT-10・11・16・21 など）は、その条件で絞った。
- **人気の時点**: 確定人気・確定オッズで見た。締め切り前のオッズは過去1年ぶんしかなく、単複・馬連だけなので使わなかった（[13-issues.md](13-issues.md) の課題5）。
- **回収率の数え方**: 100円ずつ買ったとして、払戻の合計 ÷ 買った金額の合計。払戻は確定の払戻。
- **道具**: 出走（1頭）単位は `tools/成績集計/perf.py`、レース単位（3着以内の人気の組・人気の和・人気で決める買い目の回収率・ハサミ目・馬単÷馬連）は `tools/決着の型/outcome.py`。
- **中穴・大穴の線**: ルールの単勝オッズの線と、穴馬の予想モデルの人気順位の線の対応づけは [02-glossary.md](02-glossary.md#馬を分ける言葉オッズと人気順位の線) に書いた。統計の検証は、主張に書かれた線（人気順位かオッズ）でそのまま数えた。
