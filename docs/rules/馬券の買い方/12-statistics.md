# 12 ルールの根拠になっている統計

**この文書の目的:** ルールの「なぜ」に使われている統計の主張を1か所に集め、このリポジトリのデータ（jvdata-store の DuckDB）で確かめる対象にする。**値はすべて出どころの主張であり、まだ確かめていない。**

- 検証は元DB で行い、結果（JV-Data から集計した実値）は Git の対象外の `reports/` に置く。この文書には実値を書かず、「検証」の列を「済（結果へのリンク）」に変えるだけにする。
- 主張の値が「数字なし」のものは、傾向として述べられているだけである。検証では、その傾向があるかどうかを見る。
- 確かめた結果、主張と違ったときは、その統計を使っているルールの「今の扱い」を見直す（[01-overview.md](01-overview.md#ルール同士の食い違い)）。

## 検証のときに決めること

- **期間と対象**: 何年分の、どのレース（中央競馬の全レースか、クラスや競馬場で絞るか）で確かめるか。
- **人気の時点**: 確定人気で見るか、締め切り前のオッズで見るか。ルールは買う時点のオッズで判断するので、締め切り前のオッズで見るのが本来である。
- **回収率の数え方**: 100円ずつ買ったとして、払戻の合計 ÷ 買った金額の合計。
- **中穴・大穴の線**: ルールの単勝オッズの線と、穴馬の予想モデルの人気順位の線の対応づけ（[02-glossary.md](02-glossary.md#馬を分ける言葉オッズと人気順位の線)）。
