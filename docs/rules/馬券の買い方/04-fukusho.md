# 04 複勝のルール

**複勝は、上位人気が飛んだときにオッズが跳ねる 3〜7番人気の馬を、1点で買う券種である。** 1・2番人気の低いオッズと、10番人気以下は買わない。単勝で勝負したい本命馬の取りこぼしを防ぐ使い方もある。当たった払戻を次のレースに回すコロガシはしない。

## 券種の特徴

| 項目 | 内容 |
|---|---|
| 当てるもの | 3着以内の1頭（出走 7頭以下は2着以内） |
| 払戻率 | 80%（単勝と並んで最も高い） |
| 向いている狙い | 上位人気が飛んだときの 3〜7番人気。本命馬の取りこぼし防止 |
| 1レースの点数 | 1点 |
| 強み | 的中率が全券種で最も高い（18頭立てで約 16%。STAT-19）。上位人気が飛ぶと、オッズが幅の上限に張り付く |

## ルール

| ID | いつ（条件） | どうする（行動） | なぜ | 判定に使う情報 | 検証 |
|---|---|---|---|---|---|
| FUK-01 | 常に | 3〜7番人気の馬を買う。1・2番人気（複勝 1.1〜1.2倍）は買わない | 低オッズは危険に見合わない。上位人気が飛ぶと、3〜7番人気の複勝オッズは大きく跳ねる | 人気順位、複勝オッズ | 未 |
| FUK-02 | 候補を選ぶとき | 複勝オッズの下限が 2.0〜4.0倍の馬を優先し、1.4倍以下の馬は買わない | 低配当は当たっても元が取りにくい | 複勝オッズの下限 | 未 |
| FUK-03 | 単勝で買いたい本命馬がいるとき | あえて複勝1点で買う | 展開の不利で 2・3着に落ちても当たり、取りこぼしを防げる | 本命馬 | 未 |
| FUK-04 | レースを選ぶとき | 少頭数（8頭立てなど）のレースを選ぶ。または、3着以内に来ない馬を先に外して（削除式）、実質の候補を絞る | 候補が少ないほど、複勝の的中率が上がる | 出走頭数、各馬の消す材料 | 未 |
| FUK-05 | 下級条件のダートで、気性に難のある1番人気が内枠に入ったとき | 1番人気が飛ぶ前提で、3〜7番人気の複勝を買う | 内枠で揉まれると、気性に難のある馬は力を出せない | クラス、芝ダ、1番人気の枠と気性 | 未 |
| FUK-06 | 重賞・G1 を買うとき | 複勝率の高いトップ騎手（例: ルメール、川田将雅）が乗る上位人気馬に絞って一定額を買い、月単位で目標の利益を狙う（投資型） | 情報の多いレースでは、複勝率の高い騎手 × 上位人気馬が安定して当たる | レースの格、騎手、人気順位 | 未 |
| FUK-07 | 常に | 1点勝負にし、コロガシ（払戻を次のレースに全額回す）はしない | 買うたびに控除率 20% が引かれ、回すほど効率が落ちる | 買い方 | 未 |
| FUK-08 | フルゲート・極端な悪馬場・開幕週の高速馬場・ハンデ戦など、荒れやすい条件のとき | 穴馬の複勝を買う | 複勝オッズの幅は、同時に3着以内に入る他の2頭の人気で決まる。人気馬が飛ぶと配当が幅の上限に張り付く | 出走頭数、馬場状態、開催週、ハンデ戦か | 未 |
| FUK-09 | 候補を選ぶとき | 10番人気以下は買わない | 10番人気以下の複勝率は 8% 以下に落ちる（STAT-05） | 人気順位 | 未 |

- 鉄板の軸馬の選び方（展開・血統・調教・過去の実績の4つ）は ALL-10 を使う。
- 騎手の例は、このルール集を書いた時点のものである。検証のときはデータから騎手ごとの複勝率を出し直し、結果は Git の対象外の `reports/` に置く。
- FUK-08 と ALL-09（悪馬場・ハンデ戦は見送る）は食い違う（[01 の「ルール同士の食い違い」](01-overview.md#ルール同士の食い違い)）。

## 買い目の例

架空のレース（馬番・オッズはこの例のために作った値）。

> 12頭立て。1番人気の 4番（複勝 1.1〜1.2倍）は買わない（FUK-01）。
>
> - 8番: 5番人気、複勝 2.4〜3.8倍
> - 3番: 9番人気、複勝 6.0〜9.5倍
> - 11番: 11番人気、複勝 9.0〜15.0倍
>
> 判定:
>
> - 8番は FUK-01（3〜7番人気）と FUK-02（下限 2.0〜4.0倍）に合う → 買う
> - 3番は FUK-01（8番人気以下）に反する → 買わない
> - 11番は FUK-09（10番人気以下）に反する → 買わない
>
> 買い目: 複勝 8番 の1点。4番が飛べば、払戻は上限の 3.8倍に近づく（FUK-08 の考え方）。
