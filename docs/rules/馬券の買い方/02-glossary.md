# 02 この文書で使う言葉の意味

**この文書の目的:** ルール集に出てくる言葉のうち、分かりにくいものの意味をまとめる。馬をオッズや人気順位で分ける線（穴馬・中穴・大穴）もここで決める。

## 馬券と買い方の用語

| 用語 | 意味 | このルール集では |
|---|---|---|
| 払戻率 | 馬券の売上のうち、的中者に払い戻される割合。残りが控除率（主催者の取り分） | 単勝・複勝 80%、馬連・ワイド 77.5%、馬単・3連複 75%、3連単 72.5%、WIN5 70% |
| 回収率 | 使った金額に対する、戻ってきた金額の割合 | 100% を超えればプラス |
| 期待値 | 1つの買い目の「当たる確率 × 配当」。100円買って平均いくら戻るか | 期待値の低い買い目を削るのが、全ルールの土台 |
| 合成オッズ | 複数の買い目のどれが当たっても同じだけ戻ると見たときの、まとめてのオッズ。1 ÷（各買い目の 1/オッズ の合計） | 10倍・20倍・20倍の3点なら 1 ÷ (0.1 + 0.05 + 0.05) = 5.0倍。低配当目を削ると上がる |
| オッズに応じた資金配分 | 複数の候補に、どれが当たっても同じ回収率になるよう、オッズの逆数に比例して金額を配ること | 単勝で勝ち馬を絞れないとき（TAN-12） |
| トリガミ | 当たったのに、払戻が買った総額を下回ること | 低配当目を削る理由（SRF-04・SRT-05） |
| 捨て馬券 | 買った時点で当たらないと分かる買い目。単勝の2点買い、同じ軸からの多点流しなど | 無くす（ALL-07） |
| 単系・複系 | 単系は1着を当てないと当たらない券種（単勝・馬単・3連単）。複系は1着を当てなくても当たる券種（複勝・ワイド・馬連・3連複） | 多くの人は複系に流れるため、単系の穴馬のオッズが高く残りやすい |
| 複勝オッズの幅と下限 | 複勝オッズは「2.0〜2.5倍」のように幅で示される。同時に3着以内に入った他の2頭の人気で払戻の原資を分け合うため、人気馬が飛ぶと上限に、人気馬が来ると下限に近づく。低いほうの値が下限 | 下限は FUK-02 の線。上限に張り付く狙いは FUK-08 |
| コロガシ | 当たった払戻を、そのまま次のレースに全額使うこと | しない（FUK-07、WIN-01） |
| 軸（軸馬） | 流しの中心に置く馬。来ないと当たらない | 本命（◎） |
| 対抗・押さえ・連下・紐 | 本命に次ぐ評価の馬が対抗。的中の幅を広げるために足す馬が押さえ。3着の列に置く馬が連下。流しの相手が紐（ひも） | 買い目の型の列の説明に使う |
| 流し | 軸馬と、相手の馬それぞれとの組み合わせを買う買い方 | 軸1頭 − 相手4頭 なら 4点 |
| 全流し（総流し） | 軸馬から、残りの全頭へ流すこと | WID-08、SRT-P07 |
| 2頭軸流し | 3連複で軸を2頭にし、3頭目を相手へ流すこと。ワイドでは、軸2頭それぞれから同じ相手へ流すこと | SRF-P12、WID-12 |
| フォーメーション | 1着・2着・3着（列）ごとに候補を決め、列をまたぐ組み合わせを買う買い方 | 3連複・3連単の基本の買い方 |
| 型の表記「1-2-4」 | フォーメーションで、1列目に1頭、2列目に2頭、3列目に4頭を置くこと。3列目には2列目の馬を含めて数える（含めない型は、その旨を書く） | 買い目の型の名前（SRF-P01 など） |
| ボックス | 選んだ馬の全組み合わせを買う買い方 | 馬単・3連単では使わない（ALL-04）。ワイド3頭・3連複 4〜6頭・馬連4頭は型として残す |
| マルチ | 馬単・3連単で、選んだ組み合わせの着順の並び替えを全部買う買い方。3連単は 6倍の点数になる | 使わない（ALL-04） |
| 1着固定・2着固定 | 馬単・3連単で、1着（または2着）の候補を1頭に決めること | 馬単は大穴・確信のある馬を1着固定、2着の多い1番人気を2着固定（UMT-09）。3連単は本命を1着固定 |
| 裏表（表裏・折り返し） | 馬単・3連単で、1着と2着を入れ替えた買い目も買うこと | 馬単の裏表は買わず、馬連にする（UMT-08）。3連単の表裏は SRT-P03 |
| 低配当目のカット | 予想配当が決めた線に満たない買い目を買わないこと | 3連複は 100倍未満、3連単は 200倍未満を削る |
| 人気の和 | 1〜3着の馬の人気順位を足した値。1番人気・5番人気・6番人気なら 12 | 3連単の削り方（SRT-06）と型（SRT-P10） |
| 均等買い | 全買い目を同じ金額で買うこと | 爆発力を重視するとき |
| 合成オッズに合わせた資金配分 | どの買い目が当たっても戻る額が同じくらいになるよう、オッズの低い目に多く賭けること | 回収額をならしたいとき。SRF-P10 |
| 重ね買い（セット買い） | 同じ馬・同じ組み合わせを、2つ以上の券種で同時に買うこと | [11-kasanegai.md](11-kasanegai.md) |
| 削除式 | 3着以内に来ない馬を先に外して、候補を絞るやり方 | FUK-04 |
| 投資型 | 的中率の高い買い目に一定額を買い続け、月単位で利益を出す買い方 | FUK-06 |
| ハサミ目 | 直前のレースの 1〜3着の馬番のうち、隣り合う2つに挟まれた番号 | TAN-10 |
| 万馬券 | 100円が1万円以上になる配当（100倍以上） | 3連複の狙いの下限 |
| 多重的中 | 1レースで2つ以上の買い目が同時に当たること | ワイド・重ね買いで起きる |
| WIN5 | 指定された5レースの1着馬をすべて当てる券種。払戻率 70%、最高払戻 6億円 | [10-win5.md](10-win5.md) |
| セット（WIN5） | 5レースそれぞれの候補の組み合わせ1つ分。候補の頭数の積が点数 | 48点を1セット（WIN-02） |
| キャリーオーバー | WIN5 で的中者がいなかったとき、払戻の原資が次回に持ち越されること | 狙う（WIN-03） |

## 馬を分ける言葉（オッズと人気順位の線）

**ルールの中にオッズや人気順位の線が書いてあるときは、その線に従う。** 書いていないときは、下の目安を使う。

| 用語 | 意味 | この文書の目安 |
|---|---|---|
| 人気馬（上位人気） | 支持を集めている上位の馬 | 1〜5番人気。ルールによっては「1〜3番人気」「単勝 20倍未満」 |
| 危険な人気馬 | 人気に見合う力が無く、4着以下になりそうな人気馬 | 予想モデル「人気馬が4着以下になるかを予想」の出力で決める。単勝を買ってはいけない型は TAN-13 |
| 圧倒的人気馬 | 支持が1頭に集中している 1番人気 | 単勝 1.0〜2.9倍（TAN-08）。SRT-P07 は 1.1〜1.5倍 |
| 鉄板馬 | まず馬券を外さないと見られている圧倒的人気馬 | 単勝 1倍台（WID-08） |
| 穴馬 | 人気薄の馬 | 単勝 10倍以上。人気順位で書くルールでは 6番人気以下か 4番人気以下 |
| 中穴 | 穴馬のうち、来てもおかしくない程度の馬 | 単勝 10倍以上 30倍未満。人気順位で書くルールでは 3〜9番人気か 4〜9番人気 |
| 大穴 | 穴馬のうち、人気の薄い馬 | 単勝 30倍以上 |
| 超大穴 | ほとんど支持のない馬 | 単勝 100倍以上 |

予想モデル「穴馬が3着以内に入るかを予想」の中穴・大穴は、人気順位で分けている（出走頭数 13頭以下は 4〜6番人気と 7番人気以下、14頭以上は 6〜9番人気と 10番人気以下）。この文書の線とは違うので、対応づけは検証のときに決める。

## 馬と条件の言葉

| 用語 | 意味 | このルール集では |
|---|---|---|
| ピンかパー | 1着か大敗かの両極端になりやすい馬 | 単勝向き（TAN-03） |
| 脚質 | レースでの位置取りの型。逃げ・先行・差し・追い込み | 逃げ・先行は単勝向き、追い込みは不向き（TAN-06） |
| 展開（ペース） | レースの流れ。逃げ馬が複数いればハイペースで差し馬が有利、逃げ馬が1頭（単騎逃げ）ならスローペースで前の馬が残りやすい | 軸馬の4つの観点の1つ（ALL-10）。逃げ馬のいないレースは見送る（ALL-09） |
| 自力のある馬 | 展開に頼らず、自分の力で1着になれる馬 | ワイドを 1〜2点に絞るときの軸（WID-10） |
| 前走着順 | 直前のレースの着順 | 6着以下は狙い目、2着は過剰人気（TAN-04・TAN-05・ALL-05） |
| 条件一変 | 前走から乗り替わり・斤量・コース・芝ダ・距離などが大きく変わること | 大穴が激走する理由（UMT-03） |
| トラックチェンジ | 芝からダート、ダートから芝への替わり | 上級条件での穴馬の狙い（TAN-07） |
| 上級条件・下級条件 | 上のクラスと下のクラス | 目安として、上級は 3勝クラス・オープン、下級は未勝利・1勝クラス |
| 混戦 | 抜けた馬がおらず、1番人気の単勝が 4.0倍以上つくレース | 見送る（ALL-09） |
| ハンデ戦 | 馬ごとに斤量を変えて力をそろえるレース。最も重い斤量がトップハンデ | 見送る（ALL-09）。夏競馬のトップハンデは危険な人気馬（TAN-13）。ただし FUK-08 と食い違う |
| 極端な悪馬場 | 不良馬場など、データが通用しにくい馬場 | 見送る（ALL-09）。ただし FUK-08 と食い違う |
| 開幕週の高速馬場 | 開催の最初の週で、芝が荒れておらず時計が速い状態 | 穴馬の複勝の狙い（FUK-08） |
| フルゲート | 出走頭数が上限（多くは 16〜18頭）のレース | 穴馬の複勝の狙い（FUK-08） |
| 夏競馬 | 6〜9月ごろの開催。馬の体調の変化が大きい | 見送る（ALL-09） |
| 新馬戦 | 初めて走る馬だけのレース。過去のデータが無い | 見送る（ALL-09） |
| 洋芝 | 北海道などで使う寒さに強い芝。力の要る馬場 | 欧州系の血統が合う（ALL-10） |
| 内枠で揉まれる | 内側の枠から出て、他馬に囲まれて走りにくくなること | 気性に難のある1番人気が飛ぶ理由（FUK-05）。ダートの内枠は砂を被る不利（TAN-13） |
| 穴騎手 | 人気薄（6〜9番人気）の馬に乗ったときの複勝率が高い騎手 | ワイドの相手（WID-09） |
| 共倒れ | 上位人気の馬がそろって馬券外になること | 馬単の狙い目のレース（UMT-01） |
| 一騎打ち | 実力上位が2頭に絞れるレース | 3連単の型（SRT-P09） |
| 1番人気が飛ぶ | 1番人気の馬が馬券に絡まない（4着以下になる）こと | 馬連・ワイド・3連複でレースを選ぶ条件 |
