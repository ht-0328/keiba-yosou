# 07 ワイドのルール

**ワイドは、軸と相手の片方を上位人気、もう片方を穴馬にして、少点数で流す券種である。** 基本は 2〜4番人気を軸に穴馬3頭程度へ 3〜4点。逆に、4番人気以下の穴馬を軸に 1〜3番人気の3頭へ流す3点も、1〜3番人気のどれかが3着以内に入る割合が約 93% あるので的中率が高い。3着以内の2頭を当てればよく、複系で唯一、1レースで2つ以上の買い目が同時に当たる。

## 券種の特徴

| 項目 | 内容 |
|---|---|
| 当てるもの | 3着以内の2頭（順不同） |
| 払戻率 | 77.5% |
| 向いている狙い | 上位馬から穴馬へ、または穴馬から 1〜3番人気へ、低リスクで |
| 1レースの点数 | 1〜5点 |
| 強み | 1番人気を外しても、1番人気が1着に来たときに当たる目が残る。穴馬2頭が3着以内なら多重的中 |

## ルール

| ID | いつ（条件） | どうする（行動） | なぜ | 判定に使う情報 | 検証 |
|---|---|---|---|---|---|
| WID-01 | 軸を決めるとき | 2〜4番人気の実力上位馬を軸にする | 軸を堅実な馬にしたほうが的中しやすく、配当は相手の穴馬で作れる | 人気順位 | 未 |
| WID-02 | 相手を選ぶとき | 穴馬3頭程度へ流す（3〜4点） | 点数を絞って合成オッズを保ちつつ、穴馬2頭の多重的中を狙える | 穴馬の候補 | 未 |
| WID-03 | 買い目を決めるとき | 危険な1番人気は買い目から外す | 1番人気が1着に来ても、2・3着に選んだ2頭が入れば当たる。外す損が小さい | 1番人気の危うさ | 未 |
| WID-04 | 相手を選ぶとき | 相手の穴馬は、2頭同時に3着以内に入る組み合わせを意識して選ぶ | 穴馬同士のワイドが2つ当たると、払戻が一気に大きくなる | 穴馬の候補 | 未 |
| WID-05 | 単勝 10倍以下が3頭以下、かつ 30倍以下が5頭以下のレースのとき | 1番人気と2番人気のワイド1点を買う | この条件では上位2頭がそろって3着以内に入りやすい（的中率 約 66%。STAT-12） | 単勝オッズの分布 | 未 |
| WID-06 | 本命・相手・穴の3頭が決まったとき | 3頭ボックス（3点）を買う | 3頭とも3着以内なら3点すべて当たり（トリプル的中）、馬連・馬単より大きい払戻になる | 3頭の候補 | 未 |
| WID-07 | 軸を決めるとき | 3番人気を軸に、5〜9番人気の5頭へ流す（5点） | 3番人気は複勝率が約 40% と高く（STAT-04）、5〜9番人気は中穴で配当が出る | 人気順位 | 未 |
| WID-08 | 単勝 1倍台の鉄板馬がいるとき | その馬の複勝の代わりに、鉄板馬から相手を絞ったワイド流し（または全流し）を買う | 複勝 1.1倍より合成オッズが上がる | 鉄板馬、相手の候補 | 未 |
| WID-09 | 相手を選ぶとき | 6〜9番人気で複勝率の高い騎手（穴騎手）が乗る馬と、上位人気馬の組み合わせを買う | 穴騎手は、人気薄でも3着以内に持ってくる | 騎手、人気順位 | 未 |
| WID-10 | 買い目を決めるとき | ボックスと保険の買い目をやめ、1着になれる自力のある馬を軸に 1〜2点に絞る。当たったときの回収率が 500% 以上になる組み合わせだけ買う | 点数を絞るほど、1点あたりの期待値が上がる | 軸馬の力、ワイドオッズ | 未 |
| WID-11 | 軸を穴馬にするとき | 4番人気以下の穴馬1頭を軸にし、相手は 1〜3番人気の3頭（3点） | 1〜3番人気のどれかが3着以内に入る割合は約 93%（STAT-02）。軸の穴馬が来れば、高い確率で当たる | 人気順位、穴馬の候補 | 未 |
| WID-12 | 1・2番人気が信頼できるとき | 1・2番人気の2頭を軸にし、それぞれから中穴・大穴へ流す（2頭軸） | 1・2番人気がそろって4着以下になるのは約 15%（STAT-03）。片方が来れば、相手しだいで万馬券になる | 人気順位、穴馬の候補 | 未 |

- 穴騎手の例（このルール集を書いた時点のもの）: 三浦皇成、丹内祐次、松岡正海、団野大成、西村淳也、横山和生。検証のときはデータから騎手ごとの複勝率を出し直し、結果は Git の対象外の `reports/` に置く。
- WID-06 と WID-10、WID-05 と ALL-02 は食い違う（[01 の「ルール同士の食い違い」](01-overview.md#ルール同士の食い違い)）。

## 買い目の例

架空のレース（馬番・オッズはこの例のために作った値）。

> 16頭立て。1番人気の 2番は前走で人気を裏切っており、外す（WID-03）。
>
> - 軸: 4番（3番人気、単勝 6.0倍。WID-01）
> - 相手: 9番（単勝 15.0倍）、11番（単勝 22.0倍）、15番（単勝 40.0倍）（WID-02）
>
> 買い目: ワイド 4−9、4−11、4−15 の3点。
>
> - 結果が 2番・4番・11番 の順なら、4−11 が当たる（1番人気が1着でも当たる）
> - 結果が 9番・4番・11番 の順なら、4−9 と 4−11 の2つが当たる（多重的中）
>
> 同じレースを WID-11 で組むなら、穴馬の 11番（6番人気）を軸に、1〜3番人気の 2・5・4番へ流す: ワイド 11−2、11−5、11−4 の3点。
