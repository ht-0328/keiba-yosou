# 06 判断の手順（フローチャート）

**この文書で示すこと:** 条件によって分かれる判断の手順。

**結論: この予想だけの判断は3つある。「一律で、どの組を買うか」（`FlatPlan.tickets()`）、「甲・丙で、どの組をいくらで買うか」（`ObiStakePlan.tickets()`）、「乙で、どの組をいくらで買うか」（`FormationPlan.tickets()`）である。** レース選び（`ObiDayPicker`）は、点数が線以上かどうかの1つの判断だけなので、図にしない（予想が見た確率が無いレースは、荒れ具合の確率だけを点数にする）。 学習データに入れる行の選び方（`WildRaceRows.keep()`）は、払戻が線以上かどうかの1つの判断だけなので、図にしない（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)）。

図の読み方（凡例）は [手本の 06 の「図の読み方」](../近走と適性から3着以内を予想/06-flowchart.md) を参照。

## 図1. 一律の買い目（`FlatPlan.tickets()`）

```mermaid
flowchart TD
    A[全頭で3連単の組を作る<br>18頭なら 4,896通り] --> B{その組のオッズがあり、1,000倍以上か}
    B -- いいえ --> X[買わない]
    B -- はい --> C[候補にする]
    C --> D[組の確率を Harville の式で出す<br>1着は荒れる前提の1着の確率<br>2着・3着は今の予想と荒れる前提の予想の3着以内の確率の平均の重み]
    D --> E[候補を組の確率の高い順に並べる<br>同じ確率なら馬番の小さい組を先に]
    E --> F{上から 1万円 ÷ 1点の金額 点以内か<br>100円なら 100点}
    F -- はい --> G[1点の金額で買う]
    F -- いいえ --> X
```

## 図2. 甲・丙の買い目（`ObiStakePlan.tickets()`）

```mermaid
flowchart TD
    A[3着以内の確率の上位8頭で組を作る<br>甲は3連単の並び 336通り・丙は3連複 56通り] --> B{その組のオッズがあるか}
    B -- 無い --> X[買わない]
    B -- ある --> C[帯に要る金額 = 100万円 ÷ オッズ<br>100円単位で切り上げ]
    C --> D{帯に要る金額が 1,000円以下か}
    D -- 超える --> X
    D -- 以下 --> E[候補にする]
    E --> F[候補を 当たる確率 ÷ 金額 の高い順に並べる]
    F --> G{これまでの金額 + この組の金額が 1万円以下か}
    G -- 超える --> H[この組は飛ばして次の組へ]
    G -- 以下 --> I[買う]
```

## 図3. 乙の買い目（`FormationPlan.tickets()`）

```mermaid
flowchart TD
    A[1着の欄: 1着の確率の上位3頭<br>2着の欄: 3着以内の確率の上位5頭<br>3着の欄: 3着以内の確率の上位8頭] --> B{3頭が別の馬で、オッズがあるか}
    B -- いいえ --> X[買わない]
    B -- はい --> C[組の確率（Harville の式）の高い順に並べる]
    C --> D{上位10点か}
    D -- はい --> E[300円]
    D -- いいえ --> F[100円]
    E --> G{オッズ × 金額が 1万円以上か}
    F --> G
    G -- 下回る --> X
    G -- 以上 --> H[買う]
```
