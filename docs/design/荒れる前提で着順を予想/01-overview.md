# 01 荒れる前提で着順を予想する: 概要

**近走と適性の材料から、「このレースが荒れるとしたら、どの馬が来るか」として、出走馬ごとに3着以内に入る確率と1着になる確率を出す予想である。**
荒れたレースとは、3連単の払戻（100円あたり）が 10万円以上（= 1,000倍以上）のレースで、この予想は**荒れたレースの行だけで学ぶ**。荒れたレースの3連単を当てる（最初は帯 = 1つの的中で払戻 100万円以上を狙う）ために、利用者の依頼で作った。

- 作り方: 機械学習の二値分類。LightGBM と CatBoost の2つのモデルで予測確率を出し、平均する（手本と同じ）。材料・列・期間は手本の予想（[近走と適性から3着以内を予想](../近走と適性から3着以内を予想/01-overview.md)）と同じで、学ぶ行だけが違う。
- 予測する時点: 木曜・前日・当日の3つ（[07-prediction-timing.md](07-prediction-timing.md)）。
- 使い方: 道具「帯狙い」（`tools/帯狙い/obi.py`）が、開催日ごとに「荒れる」と決めて買うレースを全部選び（荒れ具合の予想の3連単が 1,000倍以上になる確率が線以上のレース。1日何レースでも）、この予想と今の予想で、1レース 1万円の3連単の買い目（1,000倍以上の組を組の確率の高い順に一律の金額で）を出す。
- データの元: JRA-VAN Data Lab. の中央競馬のデータ（jvdata-store が DuckDB に貯めたもの）。
- 用語の意味: [02-glossary.md](02-glossary.md) を参照。
- 状態: **プログラムは `src/yosou/upset_premise/` と `tools/帯狙い/` にある。** 学習済みのモデルは Git の対象外の `reports/荒れる前提で着順を予想/models/` に置く。研究「百万馬券を当てる」の確かめで、荒れる前提の予想は使うことにした。買い目は、一律の買い方が 1,000倍以上で決まったレースを甲・乙・丙より当てたので既定にしたが、**順位の付け方を 2021〜2026年の結果を見て選んだので、まだ見ていない期間での確かめが無く、参考として出すだけで、実際のお金では買わない**（[15-decisions.md の 4・5](15-decisions.md#4-買い方)）。

## 3つの段

| 段 | 何を決めるか | 何を使うか |
|---|---|---|
| 1. レース選び | 開催日ごとに、どのレースを「荒れる」と決めて買うか（線以上のレースを全部。1日何レースでも） | 荒れ具合の予想の3連単が 1,000倍以上になる確率（大荒れ＋超荒れ）（[15-decisions.md の 1](15-decisions.md#1-レース選びに何を使うか)） |
| 2. 荒れる前提の予想 | 選んだレースで、荒れるとしたらどの馬が1着・3着以内に来るか | **この予想**（荒れたレースだけで学んだ3着以内と1着のモデル） |
| 3. 買い目 | 2. の確率（と今の予想の3着以内の確率）から、1万円でどの組をいくら買うか | この予想の買い方（一律・甲・乙・丙。既定は一律。[04-classes.md](04-classes.md#2-この予想だけのクラス)） |

## 1頭の例

架空の1頭を、当日に予測する場合。材料は手本の [「1頭の例」](../近走と適性から3着以内を予想/01-overview.md#1頭の例) と同じ架空の馬で、人気だけを変えた。

> - **レース**: 2025年5月、東京・芝1600m・良、オープン、**16頭立て**
> - **人気**: **11番人気**（単勝 45倍）
> - **前走**: 12着（着差 1.8秒）
> - **近走・適性・調教・血統**: 手本の「1頭の例」と同じ
>
> → 手本の予想（全部のレースで学んだもの）: 3着以内に入る確率 **0.04**
> → この予想（荒れたレースだけで学んだもの）: 3着以内に入る確率 **0.13**

荒れたレースでは、前走で大敗した人気薄もいつもよりずっと来る（研究「百万馬券を当てる」の docs/03）。この予想は、それを学んだぶん、人気薄の確率を手本より高く出す。逆に、1番人気の確率は手本より低くなる。
