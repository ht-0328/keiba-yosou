# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想には出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語は、手本と同じものをそのまま使う。この予想で増えるのは、帯・荒れたレースと、レース選び・買い目の用語である。

- 機械学習の用語は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。増える用語も、減る用語も無い。
- 競馬とこの設計の用語（ID 列・評価用の列・ウォームアップ期間・レース内順位・事実表など）は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。レース単位の表の用語は [荒れ具合の予想の 02](../レースの荒れ具合を4段階で予想/02-glossary.md) を参照。下の表は、それに足すものである。

## この予想で増える用語

| 用語 | 意味 | この設計では |
|---|---|---|
| 帯 | 1つの的中で受け取る払戻が 100万円以上になること（100万円の札束に付く帯から）。倍率ではなく受け取る金額で数える | レースについて言うときは、3連単の払戻（100円あたり）が 100万円以上のレース。レース選びの当たり具合は、選んだレースに帯がどれだけ集まったかで測る（[16-evaluation.md](16-evaluation.md#2-評価指標)） |
| 荒れたレース | 3連単の払戻（100円あたり）が 10万円以上のレース | 荒れる前提のモデルは、この行だけで学ぶ（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |
| 荒れる前提 | 「このレースは荒れる」と最初から決めて、荒れたときに来る馬を当てること。荒れるかどうかは問わない | 3着以内と1着のモデルの学び方（[01-overview.md](01-overview.md)） |
| レース選び | 開催日ごとに、「荒れる」と決めて買うレースを選ぶこと（線以上のレースを全部。1日何レースでも） | 点数が線以上のレース（[15-decisions.md の 1](15-decisions.md#1-レース選びに何を使うか)） |
| 点数 | レースを選ぶ値。荒れ具合の予想の3連単が 1,000倍以上になる確率と、予想が見た 1,000倍以上になる確率の平均 | `RaceSelectionScore`（[15-decisions.md の 1](15-decisions.md#1-レース選びに何を使うか)） |
| 予想が見た 1,000倍以上になる確率 | 今の予想の全頭の1着の確率から Harville の式で全部の3連単の組の確率を出し、オッズが 1,000倍以上の組の確率を合計したもの。「予想から見て、このレースが 1,000倍以上で決まる確率」 | `BigPayoutChance`（[15-decisions.md の 8](15-decisions.md#8-予想が見た-1000倍以上になる確率)） |
| 1,000倍以上になる確率 | 3連単の払戻（100円あたり）が 10万円以上（= オッズ 1,000倍以上）で決まる確率。荒れ具合の予想の3連単の大荒れ（10万円以上）と超荒れ（50万円以上）の確率の合計 | レース選びの点数 |
| 一律 | 1,000倍以上の3連単の組を、組の確率の高い順に、1点の金額を一律にして予算に収まる点数だけ買う買い方 | 既定の買い方（[15-decisions.md の 4](15-decisions.md#4-買い方)） |
| 2着・3着の重み | Harville の式で2着・3着を決めるときの、馬ごとの重み。一律では、今の予想と荒れる前提の予想の3着以内の確率の平均 | 組の確率（[15-decisions.md の 6](15-decisions.md#6-組の確率の2着3着の重み)） |
| 今の予想 | 全部のレースで学んだ手本の予想（近走と適性から3着以内を予想）の本番のモデル | 2着・3着の重みに使う。道具「帯狙い」が同じレースを今の予想でも予想する |
| 帯の集まり方 | 選んだレースの帯の割合 ÷ 全レースの帯の割合。2 なら、全レースより2倍帯が出やすいレースを選べている | レース選びの当たり具合（[16-evaluation.md](16-evaluation.md#2-評価指標)） |
| 帯の倍率 | 100万円 ÷ 1点の掛け金。この倍率以上の組が当たると帯になる | 甲・丙の買い方で、組ごとの掛け金を決める（[15-decisions.md の 4](15-decisions.md#4-買い方)） |
| Harville の式 | 1着の確率から、3連単の組（1着・2着・3着の順）の確率を作る式。1着の馬を除いた残りで2着を、さらに残りで3着を、同じ比で決める。2着・3着の比に、1着の確率でなく別の重みを使うこともできる | 買い目の組の確率（[04-classes.md](04-classes.md#2-この予想だけのクラス)） |
| 帯狙いの財布 | 帯を狙う買い目にだけ使うお金。勝負用・ポリシー用・単勝と馬単用の財布とは分けて数える | [15-decisions.md の 5](15-decisions.md#5-お金の扱い) |
