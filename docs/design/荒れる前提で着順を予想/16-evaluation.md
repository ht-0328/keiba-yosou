# 16 当たり具合の測り方

**この文書で決めること:** 学習に使っていないデータで、この予想の当たり具合をどう測るか。何と比べれば「当たっている」と言えるか。

**結論:**

| 決めること | 結論 |
|---|---|
| 1. 期間の分け方 | `train` は手本と同じ（学習・検証・テストの既定）。確かめは、2021〜2026年の11の半年の区切り（それぞれ前の期間だけで学ぶ）で行い、まだ見ていなかった 2021〜2022年と参考の 2023〜2026年に分けても並べる |
| 2. 評価指標 | 段ごとに分ける。レース選びは同じレース数を選んだときに実際に 1,000倍以上だった割合（と帯の集まり方）、荒れる前提の予想は上位の馬が1〜3着に来た割合と人気薄の割合、買い目は 1,000倍以上で決まったレースのうち当てた割合と回収率 |
| 3. 半年ずつずらした確かめ | 研究「百万馬券を当てる」で行った。基準と結果は研究の docs/01 の 8・docs/04・docs/06 |
| 4. 本番のモデルの学習 | `train` の出力の検証データの当たり具合と行数を見る |

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 期間の分け方

- `train` の期間の分け方と、テストデータを `train` で使わない決まりは手本と同じ（[手本の 16 の「1. 期間の分け方」](../近走と適性から3着以内を予想/16-evaluation.md#1-期間の分け方)）。
- 最初の確かめ（研究の docs/04）は、まだ一度も数えていない 2021〜2022年を使い、2023〜2026年は参考にとどめた。レース選びの精度と一律の買い方の確かめ（研究の docs/06）は、2021〜2026年の全部で数え、2021〜2022年と 2023〜2026年のどちらでも同じ向きの結果になるかを見た。

## 2. 評価指標

| 段 | 指標 | 比べる相手 |
|---|---|---|
| レース選び | 点数の高い順に同じレース数（1開催日あたり 8・5・2.5・1レース）を選んだとき、実際に 3連単が 1,000倍以上で決まった割合。点数の並べ方の良さ（AUC）。帯を狙う見方では、帯の集まり方（選んだレースの帯の割合 ÷ 全レースの帯の割合）と 90% の幅 | 荒れ具合の予想の3連単の超荒れの確率（最初の決め方）と、大荒れ＋超荒れの確率（今の決め方） |
| 荒れる前提の予想 | 荒れたレース・帯のレース・選んだレースで、上位5頭のうち3着以内に来た頭数、1〜3着が全部上位8頭に入った割合、勝ち馬が1着の上位3頭に入った割合。上位に人気薄がいる割合 | 今の予想（同じ区切りで学び直した手本の当日のモデル） |
| 買い目 | 選んだレースで1レース 1万円を買ったときの、1,000倍以上で決まったレースのうち当てた割合、回収率と 90% の幅、いちばん大きい当たりを除いた回収率、いちばん深い落ち込み、最大の連敗。帯を狙う見方では帯の回数 | 同じレースを、元の Harville の式・今の予想だけで同じ買い方にしたもの |

荒れる前提の予想は、荒れなかったレースでは外れる前提なので、買い目の指標は荒れなかったレースの外れも含めて数える（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 6）。全券種の買い目の回収率は、手本と同じく道具「印の成績」で出す（研究の docs/04 の 4）。

## 3. 半年ずつずらした確かめ

研究「百万馬券を当てる」の `walk.py`（11の区切りで学ぶ）と `backtest.py`（races・horses・bets・select・flat）で行った。採用の基準は結果を見る前に決めた（研究の docs/01 の 8・docs/06 の 1）。

| 段 | 結果（研究の docs/04・docs/06） |
|---|---|
| レース選び | 「帯になる確率」のモデル・「1,000倍以上になる確率」の専用モデル・馬の予想から作る材料を足したモデルは、どれも荒れ具合の予想と同じだったので採らない。荒れ具合の予想の大荒れ＋超荒れの確率が、超荒れだけの確率より同じレース数で当てたので、それを使う |
| 荒れる前提の予想 | 荒れたレースで今の予想を上回り、人気薄も選べた。使う |
| 買い目 | 一律（2着・3着の重みに今の予想を混ぜる）が、1,000倍以上で決まったレースのうち当てた割合が元の式・甲・乙・丙より高く、両方の期間で回収率が 100% を超えた。既定にする。順位の付け方を 2021〜2026年の結果を見て選んだので、まだ見ていない期間での確かめが無く、参考として出す |

動かし方（リポジトリ直下で。数値は Git の対象外の `reports/百万馬券を当てる/` に出る）は、研究の README の「動かし方」を参照。

## 4. 本番のモデルの学習

`uv run python -m yosou.upset_premise train` の出力に、時点ごとの検証データ（荒れたレースだけ）での当たり具合（手本と同じ表）と、学習・検証の行数が出る。行数が手本より少ないこと、検証データの当たり具合が極端に悪くないことを見る。
