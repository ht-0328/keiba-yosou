# 16 当たり具合の測り方

**この文書で決めること:** 学習に使っていないデータで、この予想の当たり具合をどう測るか。何と比べれば「当たっている」と言えるか。

**結論:**

| 決めること | 結論 |
|---|---|
| 1. 期間の分け方 | `train` は手本と同じ（学習・検証・テストの既定）。確かめは、まだ見ていない 2021〜2022年の4つの半年の区切りで行い、2023〜2026年の7つは参考として並べる |
| 2. 評価指標 | 段ごとに分ける。レース選びは帯の集まり方、荒れる前提の予想は上位の馬が1〜3着に来た割合と人気薄の割合、買い目は回収率・帯の回数・いちばん大きい当たりを除いた回収率 |
| 3. 半年ずつずらした確かめ | 研究「百万馬券を当てる」で行った。基準と結果は研究の docs/01 の 8 と docs/04 |
| 4. 本番のモデルの学習 | `train` の出力の検証データの当たり具合と行数を見る |

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 期間の分け方

- `train` の期間の分け方と、テストデータを `train` で使わない決まりは手本と同じ（[手本の 16 の「1. 期間の分け方」](../近走と適性から3着以内を予想/16-evaluation.md#1-期間の分け方)）。
- 確かめ（研究）は、まだ一度も数えていない 2021〜2022年を使った。2023〜2026年の数字は、ほかの研究で何度も見ているので、参考にとどめた。

## 2. 評価指標

| 段 | 指標 | 比べる相手 |
|---|---|---|
| レース選び | 帯の集まり方（選んだレースの帯の割合 ÷ 全レースの帯の割合）と、開催日のブートストラップの 90% の幅。帯の拾い方 | 荒れ具合の予想（今は、これをそのまま使う） |
| 荒れる前提の予想 | 荒れたレース・帯のレース・選んだレースで、上位5頭のうち3着以内に来た頭数、1〜3着が全部上位8頭に入った割合、勝ち馬が1着の上位3頭に入った割合。上位に人気薄がいる割合 | 今の予想（同じ区切りで学び直した手本の当日のモデル） |
| 買い目 | 選んだレースで1レース 1万円を買ったときの回収率と 90% の幅、帯の回数、いちばん大きい当たりを除いた回収率、いちばん深い落ち込み、最大の連敗 | 同じレースを今の予想で同じ買い方にしたもの |

荒れる前提の予想は、荒れなかったレースでは外れる前提なので、買い目の指標は荒れなかったレースの外れも含めて数える（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 6）。全券種の買い目の回収率は、手本と同じく道具「印の成績」で出す（研究の docs/04 の 4）。

## 3. 半年ずつずらした確かめ

研究「百万馬券を当てる」の `walk.py`（11の区切りで学ぶ）と `backtest.py`（races・horses・bets）で行った。採用の基準は結果を見る前に決めた（研究の docs/01 の 8）。

| 段 | 結果（研究の docs/04） |
|---|---|
| レース選び | 新しいモデルは比べる目安と同じだったので採らず、荒れ具合の予想を使う |
| 荒れる前提の予想 | 荒れたレースで今の予想を上回り、人気薄も選べた。使う |
| 買い目 | 甲・乙・丙のどれも基準に届かなかった。買い目は参考として出す |

動かし方（リポジトリ直下で。数値は Git の対象外の `reports/百万馬券を当てる/` に出る）は、研究の README の「動かし方」を参照。

## 4. 本番のモデルの学習

`uv run python -m yosou.upset_premise train` の出力に、時点ごとの検証データ（荒れたレースだけ）での当たり具合（手本と同じ表）と、学習・検証の行数が出る。行数が手本より少ないこと、検証データの当たり具合が極端に悪くないことを見る。
