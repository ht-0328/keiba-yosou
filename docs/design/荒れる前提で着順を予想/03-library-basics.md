**この文書の目的:** 設計を読む前に、LightGBM と CatBoost（と、表を扱う pandas）で何ができるかを知っておく。

**この文書で示すこと: 使う道具は手本の予想とまったく同じである。そのため、道具の説明は書かず、[手本の 03](../近走と適性から3着以内を予想/03-library-basics.md) を参照する。この予想で違う点は無い。**

同じ説明を2つのフォルダに写すと、片方だけ直したときに食い違う。そのため、この文書は入口だけを持つ。

## この予想で違う点

**無し。** 荒れる前提の2つのモデル（3着以内・1着）は、手本と同じ二値分類で、`fit()` と `predict_proba()` の2列目（「3着以内に入る確率」「1着になる確率」）を使う。違うのは、荒れたレースの行だけで学んだことだけである。新しいライブラリは使わず、手本で使っていない機能も使わない。

レース選びは、荒れ具合の予想の学習済みモデル（多クラス分類）をそのまま使う。使い方は [荒れ具合の予想の 03](../レースの荒れ具合を4段階で予想/03-library-basics.md) を参照。
