# 09 特徴量

**この文書で決めること:** 荒れる前提の3着以内・1着の予測の手がかり（特徴量）に、何を使うか。

**結論: 新しい特徴量は作らない。手本の時点ごとの今の本番の列を、そのまま使う。** レース選びは、荒れ具合の予想の 49個の特徴量で学んだ学習済みモデルを使う（[荒れ具合の 09](../レースの荒れ具合を4段階で予想/09-features.md)）。

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 表の見方

一覧は手本の 09 にある。この文書には、どれを使うかと、その理由だけを書く。

## 荒れる前提の3着以内・1着

| 時点 | 3着以内 | 1着 |
|---|---|---|
| 木曜 | 馬の力の材料 ＋ 展開の予想（P）＋ 能力スコア（T） | 同じ |
| 前日 | 馬の力の材料 ＋ 展開スコア（S） | 馬の力の材料 |
| 当日 | 今の材料（券種の支持を含む） | 今の材料 ＋ 勝ち切る材料（Q） |

一覧は [手本の 09](../近走と適性から3着以内を予想/09-features.md) を参照。

**理由。** 研究「百万馬券を当てる」の事例（docs/03）では、荒れたレースで来る人気薄の型は「近走・力・人気の差が縮まる」ことだった。違うのは材料ではなく、材料の効き方である。そのため、同じ材料のまま、学ぶ行だけを荒れたレースにして、効き方を学び直させる。

## 使わない特徴量

- **3連単の払戻・荒れたかどうか。** そのレースの結果なので、特徴量にしない（[11-leak-prevention.md](11-leak-prevention.md#決まり)）。学ぶ行を選ぶのにだけ使う。
- **レース選びの確率（3連単の超荒れの確率）。** 入れない。荒れる前提のモデルは「荒れるとしたら」を学ぶので、荒れやすさの手がかりは要らない。レース選びと馬の予想を別のモデルに分けたのはこのためである。
