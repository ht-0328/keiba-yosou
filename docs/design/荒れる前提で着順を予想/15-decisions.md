# 15 決めたこと

**この文書の目的:** 設計の中で決めたことを、ここに集める。利用者は「帯を当てたい」「このレースは最初から荒れるとして、既存の予想方法ではなく別の方法で予想する」「まずレース選びから」「1レース 1万円で」と指定し、そのあと「1,000倍以上のレースと判断したら1日何レースでも参加する」「1,000倍以上の組を一律の金額で買う」「まず選ぶ精度を、次に選んだレースでの的中率を上げる」「的中率を保ちつつ選ぶ精度と回収率を上げる」と指定した。方法は任された。1レースの予算・券種・一律の金額は利用者の指定で、ほかは研究「百万馬券を当てる」の確かめ（`research/百万馬券を当てる/docs/04-検証の結果.md`・`docs/06-1000倍以上のレースを狙う.md`）で決めた。あとで見直せるように、選ばなかった選び方も残す。

## 1. レース選びに何を使うか

| 選び方 | 変わること |
|---|---|
| **点数 = 荒れ具合の予想の3連単が 1,000倍以上になる確率（大荒れ＋超荒れ）と、予想が見た 1,000倍以上になる確率の平均 が線以上のレースを全部（決めたこと）** | 新しいモデルを持たない。荒れ具合の予想と今の予想の学習済みモデルをそのまま使う。同じレース数を選んだとき、実際に 1,000倍以上だった割合が大荒れ＋超荒れだけより高く、選んだレースでの的中率は同じで、回収率もほぼ同じ。1日に何レースでも買い、線に届く日が無ければ買わない。その日の全レースを今の予想で予想するので、今週の予想の保存した結果を読む |
| 荒れ具合の予想の大荒れ＋超荒れの確率だけ | 予想が見た確率を平均する前の決め方。同じ線（0.40）なら選ぶレースは多く（2〜3レース/日）、精度は数ポイント低いが、1開催日に 2〜3レース選ぶときは回収率が平均より高い。今の予想を全レースに出さないので速い。道具の `--score 大荒れ＋超荒れ` で選べるように残す |
| 荒れ具合の予想の3連単の超荒れ（50万円以上）の確率で、開催日ごとに1レース | 最初の決め方。超荒れだけの確率は、同じレース数を選んだとき、大荒れ＋超荒れより 1,000倍以上のレースを当てる割合が低かった。1日1レースに絞ると、荒れる日に2レース目以降を買えない |
| 3連単・3連複・馬連のオッズ板から作る材料（市場が見た 1,000倍以上になる確率・1番人気の組のオッズ・エントロピー など）を荒れ具合の予想の材料に足す | 同じレース数を選んだときの割合は数ポイント上がるが、選んだレースでの的中率と回収率が下がる。市場が「荒れそう」と見るレースは 1,000倍以上の組が多く、100点では覆えないため |
| 市場が見た確率より自分の予想が荒れると見るレース（点数 − 市場の見立て） | 回収率は上がるが、実際に 1,000倍以上だった割合が下がる |
| 「一律の買い目が当たるか」を直接当てるモデル | 学べるレースが 2021年からしか無く、大荒れ＋超荒れを上回らなかった |
| 「3連単が 1,000倍以上になるか」だけを当てる専用の二値分類のモデル（荒れ具合の予想と同じレース単位の材料） | 同じレース数を選んだときの割合も AUC も、大荒れ＋超荒れと同じだった（材料が同じなので、目的変数を変えても上がらない） |
| 上の専用モデルの材料に、馬の予想（今の予想・荒れる前提の予想）から作るレース単位の材料（1番人気の確率、人気薄の確率の合計 など）を足したモデル | 2022〜2026年の区切りで、大荒れ＋超荒れと同じだった。材料が足りる期間が短い（馬の予想の予測が要る）割に、上がらない |
| 新しく作る「帯になる確率」のモデル（3連単 100万円以上を当てさせる二値分類） | まだ見ていない年で、選んだレースの帯の数が超荒れの確率と同じだった |
| 条件のルール「多頭数（16頭以上）で人気が割れている」 | 確かめの期間で超荒れの確率を下回った |

- 線は利用者が決めるものとし、既定は 0.40（[7](#7-線と1点の金額)）。線を下げるほど買うレースは増え、実際に 1,000倍以上で決まる割合は下がる（研究の docs/06 の 2）。
- レース選びの精度は、どの方法でも数ポイントしか上がらない。市場（オッズ板）そのものでも同じ程度で、残りは運の部分が大きい（研究の docs/06 の 2）。
- 専用モデルの作り方と確かめは研究の `walk.py big`・`backtest.py select` に、点数の確かめは `backtest.py select`・`flat --score` に残した。

## 2. 荒れる前提のモデルの学び方

| 選び方 | 変わること |
|---|---|
| **手本と同じ材料・列・期間で、学ぶ行を荒れたレースだけにする（決めたこと）** | 手本の学習のコマンドに、予想の名前と `WildRaceRows` を渡すだけで作れる。材料の作り方を2か所に持たない |
| 荒れたレースで来た人気薄の型（脚質・前走の大敗・条件替わりなど）を新しい特徴量にする | 研究の事例では、型は「材料の効き方が変わる」ことで、新しい材料は要らなかった |
| 帯のレース（100万円以上）だけで学ぶ | 1年に百レースほどしか無く、馬ごとのモデルには少なすぎる |

研究の確かめは、研究「既存モデルの改善」の表（2017年から）で行った。本番の学習は手本と同じ既定の期間（当日は 2021年8月から）なので、学ぶ行はさらに少なくなる。

## 3. 予測する時点

手本と同じ3つの時点で出せるようにした（ほかの予想と同じ既定）。レース選びは単勝オッズの割れ方、買い目は組ごとのオッズを使うので、買い目は当日の予測で組む（[07](07-prediction-timing.md#買うかどうかを当日の予測で決める理由)）。

## 4. 買い方

| 買い方 | 中身 | 確かめの結果（研究の docs/04 の 3・docs/06 の 3） |
|---|---|---|
| **一律（3連単。既定）** | 全頭の組のうちオッズが 1,000倍以上の組を、組の確率の高い順に、1点の金額（既定 100円）を一律にして予算に収まる点数（100円なら 100点）だけ買う | 1,000倍以上で決まったレースのうち当てた割合が甲・乙・丙より高く、2021〜2022年・2023〜2026年のどちらでも回収率が 100% を超えた。100円では、回収率の 90% の幅の下の端が 100% を下回る。300円・500円では 2021〜2026年の全体で下の端も 100% を超えたが、2023〜2026年だけでは下回る。順位の付け方は 2021〜2026年の結果を見て選んだので、まだ見ていない期間での確かめにはなっていない |
| 甲 全部帯（3連単） | 当たれば必ず帯になる組だけを、帯に要る金額（100万円 ÷ オッズ、100〜1,000円）で、当たる確率 ÷ 金額の高い順に1万円まで | 帯は2年で1回。基準に届かない |
| 乙 本線厚め（3連単） | 1着3頭 → 2着5頭 → 3着8頭（最大 72点）。組の確率の上位10点を 300円、残りを 100円。トリガミは買わない | 当たりは多いが、帯は無かった。基準に届かない |
| 丙 全部帯（3連複） | 甲を3連複にしたもの | 買える組がほとんど無い。基準に届かない |

- 一律を既定にしたのは、利用者の「1,000倍以上の組を一律の金額で買う」という指定に合い、選んだレースでの的中率がいちばん高かったからである。
- 「1万倍以上の組だけを狙う」は、6年で数回しか当たらず、現実的でないので採らない（利用者の判断）。

## 5. お金の扱い

| 選び方 | 変わること |
|---|---|
| **実際のお金では買わない。道具「帯狙い」は買い目を参考として出す（決めたこと）** | 財布（`reports/回顧/財布.json`）にも、回顧の表1「買い目の記録」にも書かない。今週の予想の計画（`day_planner.py`）も変えない |
| 勝負用の財布で買う | 基準（回収率と 90% の幅の下の端が 100% 超え）は、一律の 300円・500円が 2021〜2026年の全体では満たす。しかし順位の付け方を 2021〜2026年の結果を見て選んだので、まだ見ていない期間での確かめが無い。確かめてから決める |

線 0.40・1点 100円だと、1年におよそ 250レース・250万円を使う。線を下げるほど増える。買い方が基準を満たしたら、帯狙いの財布を設計書「買うレースと買い目を決める」の 08 に足す。

## 6. 組の確率の2着・3着の重み

Harville の式は、1着の馬を除いた残りで2着を、さらに残りで3着を、1着の確率と同じ比で決める。一律の買い方では、2着・3着の比に1着の確率でなく別の重みを使う（`trifecta_probability` の `place`）。

| 選び方 | 変わること |
|---|---|
| **1着は荒れる前提の1着の確率、2着・3着は今の予想と荒れる前提の予想の3着以内の確率の平均（決めたこと）** | 100円・300円・500円のどの金額でも、1,000倍以上で決まったレースのうち当てた割合が元の式より高く（1.3〜1.5倍）、2021〜2022年・2023〜2026年のどちらでも回収率が 100% を超えた。同じレースを今の予想でも予想する手間が増える |
| 元の Harville の式（2着・3着も荒れる前提の1着の確率の比） | 最初の決め方。荒れる前提の1着の確率は人気薄に寄るので、2着・3着まで人気薄で固めた組に寄り、当たる割合が低い |
| 2着・3着を今の予想の3着以内の確率だけにする | 300円・500円では上と同じくらい当て、回収率は上より高い。100円では上より当てる割合が低い。1つの式にそろえるため採らない |
| 1着も今の予想と平均する・今の予想だけにする | 100円では上と同じくらい当てるが、300円・500円で下がる。荒れる前提の予想を使うという利用者の指定にも合わない |
| 2着・3着を荒れる前提の3着以内の確率だけにする | 元の式とほぼ同じで、上がらない |

- 荒れたレース（1,000倍以上）は「人気薄が勝って、2着・3着に人気馬や中位の馬が入る」形が多い。1着を荒れる前提の予想で、2着・3着を今の予想も混ぜた重みで決めると、この形に合う。

## 7. 線と1点の金額

| 項目 | 既定 | 替え方 |
|---|---|---|
| 線（点数がこの値以上なら買う） | 0.40 | 道具の `--line`。研究の `backtest.py flat --line` で、線ごとの成績を数えられる |
| 1点の金額 | 100円（100点） | 道具の `--stake`（100・300・500）。金額を上げると点数が減り、当てる割合は下がるが、当たり1回の払戻と回収率は上がる |

- 線 0.40 は、1開催日に 1〜2レースを選び、選んだレースの半分が実際に 1,000倍以上で決まる線である（研究の docs/06 の 2）。利用者の「そういうレースと判断した場合は参加する」に合わせ、線を超えたレースは何レースでも買う。
- 1点の金額は利用者が決めるものとし、既定は的中の回数がいちばん多い 100円にした。

## 8. 予想が見た 1,000倍以上になる確率

今の予想（全部のレースで学んだ手本の予想）の全頭の1着の確率から、Harville の式で全部の3連単の組の確率を出し、締め切り前の3連単のオッズが 1,000倍以上の組の確率を合計する（`BigPayoutChance`）。「予想から見て、このレースが 1,000倍以上で決まる確率」になる。

| 選び方 | 変わること |
|---|---|
| **今の予想の1着の確率で Harville の式（決めたこと）** | 荒れ具合の予想（レース単位の材料）とは別の材料（馬ごとの近走・適性）から作るので、平均すると精度が上がる。新しい学習は要らない |
| 2着・3着に今の予想の3着以内の確率の重みを使う | 同じ程度の精度。一律の買い方の組の確率とは別物なので、式は単純なほうにそろえた |
| 荒れる前提の予想の1着の確率で出す | 荒れる前提の予想は人気薄の確率を高く出すので、どのレースでも高い値になり、レースを選び分けられない |

- 組ごとのオッズが無い時点（木曜・前日のオッズ発売前）と、今の予想を出せないレースでは、この確率は無く、点数は荒れ具合の確率だけになる。
- 平均が効くのは線を上げて選ぶ数を絞ったときで、1開催日に 2〜3レース以上選ぶと、大荒れ＋超荒れだけのほうが回収率は高い（研究の docs/06 の 2）。既定の線 0.40 は、平均で 1〜2レース/日になる。
