# 11 リークを防ぐ決まり

**この文書で決めること:** 学習では当たるのに本番では当たらないモデル（リーク）にならないよう、特徴量と目的変数を作るときに守る決まり。

**結論: 特徴量は、予測する時点（木曜・前日・当日。[07-prediction-timing.md](07-prediction-timing.md)）で分かることだけから作る。手本の決まり 1〜4 をそのまま守り、この予想では、今回の序盤の結果・過去のレースの記録・前半タイムの基準・相手の数え方・温度についての決まり（6〜10）を足す。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 決まり

1〜4 は手本と同じで、[手本の 11 の「決まり」](../近走と適性から3着以内を予想/11-leak-prevention.md#決まり) を参照する（そのレースの結果を使わない、過去走から作る特徴量は開催日より前のものだけから計算する、マスタの累計の成績を使わない、学習データと予測用データを同じプログラムで作る）。手本の 5（確定オッズ）は、この予想ではオッズを使わないので当てはまらない。この予想では、6〜10 を足す。

**6. 今回のレースの序盤の結果は、目的変数と評価用の列にだけ使う。**

- 事実表に足す列のうち、今回のレースの値である 1〜4コーナーの順位（`corner1`〜`corner4`）、最初のコーナーの番号と周回数、先頭の馬番（`first_corner_leader_no`）、前3ハロン（`first3f`）は、特徴量にしない。手本の決まり 1 の列（脚質 `style` など）と同じ扱いである。
- 特徴量に使うのは、過去走の同じ列（前走の値・近5走の値）だけである。
- 最初のコーナーの番号（M）は、そのレース自身の記録ではなく、同じコースの過去のレースの記録から決める。そのレース自身の記録は、レースが終わるまで無いためである。

**7. 過去のレースの記録（`race_history`）は、開催日の前日までの行だけを見る。**

- `race_history` には、予測するレースと、同じ日のほかのレースも入っている（学習のときは、同じ日のレースの結果もすでに DB にある）。コースの形（M）・全体の先頭率・前半タイムの基準は、同じ日の先に終わったレースも数えない。予測のときは、同じ日のレースの結果はまだ無いためである。
- 手本の「騎手の近1年の3着以内の割合」と同じく、共通の `AsOfLookup`（前日まで）の1か所で守る。

**8. 前半タイムの基準は、前日までの3年のレースだけから作る。そのレース自身の前半タイムは、基準にも特徴量にも入れない。**

- 学習データの全期間から1つの基準を作ると、昔のレースの基準に、その後のレースが混ざる（[10-target.md の 5.](10-target.md#5-前半タイムの基準の作り方)）。
- `PaceRecordSource` が返す表には、そのレース自身の前半タイム（目的変数の元）と基準が並んでいる。特徴量（Q）を作る `PaceBaselineFeatures` は、基準の列（平均・標準偏差・件数）だけを読む。

**9. 相手（L・P）は、予測の時点で出走する馬から作る。学習データは、確定した出走馬から作る。**

- 予測では、前日・当日は速報の取消を反映したあとの馬、木曜は出走馬名表の馬で作る（[07-prediction-timing.md の「取消が出たときの扱い」](07-prediction-timing.md#取消が出たときの扱い)）。
- 学習データでは、実際に走った馬で作る。木曜・前日の時点の出走予定の馬は、元DB に残っていない（出馬表は新しい版で上書きされる）ので作れない。**これはリークではないが、学習と予測で相手の数え方が少し違う。** 取消の多いレースほど、木曜・前日の予測は、学習のときより条件が違う。
- 今後の予測のたびに、その時点の予測用データを残す（`PredictionArchiveRepository`。[15-decisions.md の 12](15-decisions.md#12-予測の記録を残すか)）。残った記録で、「その時点の材料で予測したら、どれだけ当たったか」を後から確かめられる。

**10. 木の数（早期終了）・先頭の確率の温度・当たり具合の確かめは、別のデータで行う。テストデータは、直す判断に使わない。**

- 早期終了は検証データの前半、温度は検証データの後半で決める（[16-evaluation.md の 1.](16-evaluation.md#1-期間の分け方)）。同じデータで両方を決めると、確率が実際より当たって見える。
- テストデータ（既定は 2026年1月から）は、候補を1つに決めたあとに1回だけ確かめる。テストの結果を見て特徴量や線引きを直さない。
