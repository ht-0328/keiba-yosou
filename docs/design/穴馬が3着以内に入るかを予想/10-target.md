# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。

**結論: 目的変数は「その穴馬が3着以内なら 1、それ以外は 0」。競走中止・失格は 0 にする。手本と同じく、「1着なら 1」の列も学習データに置いておく（使うのは 3着以内だけ）。**（[15-decisions.md](15-decisions.md#7-1着の列も学習データに置くか)）

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 作り方

学習データの1行は、1レースの穴馬1頭である（[08-training-data.md](08-training-data.md#1-学習データの形)）。その1頭の結果から、次のように目的変数を決める。

| その穴馬の結果 | 答え（目的変数: 3着以内） | 1着の列 | 意味 |
|---|---|---|---|
| 確定着順が 1着 | 1 | 1 | 馬券になった |
| 確定着順が 2着・3着 | 1 | 0 | 馬券になった |
| 確定着順が 4着以下 | 0 | 0 | 馬券にならなかった |
| 競走中止・失格 | 0 | 0 | 走ったが、馬券にならなかった |
| 出走取消・発走除外・競走除外 | ― | ― | サンプルにしない（走っていない。[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |

- 着順は**確定着順**を使う。降着があれば、降着後の着順になる。
- 同着は、どちらも同じ着順として扱う（3着同着なら、2頭とも 1）。
- **7頭以下のレースでも、3着以内かどうかで決める。** 複勝は 7頭以下だと2着までしか付かないが、目的変数は頭数で変えない。頭数で意味が変わる目的変数だと、モデルが学ぶ「1」の意味がレースによってずれるためである（危険な人気馬の予想と同じ決まり）。
- **中穴・大穴で目的変数を変えない。** どちらも「3着以内なら 1」である。区分は出力を絞るためのもので、当てるものは同じである。
- 「1着なら 1」の列は、モデルには渡さない。あとで穴馬の単勝用のモデルを作るときに、学習データを作り直さずに済むように置いておく。

`predict_proba()` の2列目が、目的変数が 1 になる確率、つまり「3着以内に入る確率」になる（[03-library-basics.md](03-library-basics.md#この予想で違う点)）。

## 理由

**「3着以内なら 1」にする理由（危険な人気馬の予想のように裏返さない理由）。**

- 当てたいのは「来るかどうか」である。1 を「来た」にしておくと、予測確率がそのまま「来やすさ」の大きさになり、確率の高い順に並べるだけで、狙う穴馬の順になる。
- 手本の予想と同じ向きなので、手本の目的変数を付ける部品（`Top3TargetBuilder`）をそのまま使える（[04-classes.md](04-classes.md#1-共通の部品とこの予想だけの部品の分け方)）。

**中止・失格を 0 にする理由。** 出走して馬券にならなかった点は、4着以下と同じだからである。馬券を買った人から見れば、区別する意味が無い。

**1着の列も置く理由。** 穴馬は単勝の配当が大きく、あとで単勝用のモデルを作りたくなる可能性が高い。列を1つ置いておくだけで、そのときに学習データを作り直さずに済む。

## 1 と 0 の数の偏り

1レースの穴馬は、16頭立てなら 11頭である。そのうち3着以内に入れるのは最大3頭で、人気馬が3着以内を占めるレースも多い。そのため、**1（3着以内）は 0 よりも大幅に少ない。** 中穴より大穴のほうが、さらに少ない（率は書かない。数え上げは [08-training-data.md](08-training-data.md#5-行数の数え上げ) を参照）。

この偏りは、**直さずにそのまま学習する。**

- 偏りを直す設定（片側のサンプルを重く扱う設定）を使うと、予測確率が実際の確率からずれる。
- この予想では、予測確率を確率として使う（オッズと比べる、線引きを決める）。そのため、確率の大きさがずれる設定は使わない。
- 手本の予想（全頭で 3着以内なら 1）より偏りは大きく、危険な人気馬の予想（1 がやや多い）とは逆向きである。偏りが大きくても、二値分類のモデルは、少ない側の確率を小さい値として出すだけで、学習はできる。

LightGBM と CatBoost の、偏りを直す設定の名前は、[12-lightgbm.md](12-lightgbm.md#2-ハイパーパラメータの初期値)・[13-catboost.md](13-catboost.md#2-ハイパーパラメータの初期値) を参照。
