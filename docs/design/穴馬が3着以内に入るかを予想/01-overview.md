# 01 穴馬が3着以内に入るかを予想する: 概要

**近走の内容と適性と人気から、穴馬1頭ずつについて「3着以内に入る確率」を出す予想である。**
穴馬とは、出走頭数が 13頭以下なら確定単勝人気の 4番人気以下、14頭以上なら 6番人気以下の馬である（14頭以上を多頭数とする）。危険な人気馬の予想で決めた「人気馬」の範囲の、ちょうど裏返しである。
適性とは、そのコース・距離・馬場に向いているかどうかで、同じ条件での過去の成績・持ち時計・血統から見る。
**人気順位は特徴量に入れるが、単勝オッズと JRA-VAN のマイニング予想は使わない。**

- 作り方: 機械学習の二値分類。LightGBM と CatBoost の2つのモデルで予測確率を出し、平均する（アンサンブル）。
- 予測する時点: 木曜（出走馬名表）・前日（出馬表）・当日（馬体重の発表のあと）の3つのどれでも出せる。時点ごとに、その時点で分かる特徴量だけで学習した別のモデルを使う（[07-prediction-timing.md](07-prediction-timing.md)）。
- 人気の渡し方: 予測のときは、利用者が `--pops` で全頭の人気を渡す（木曜は 馬名:人気、前日・当日は 馬番:人気）。前日・当日は、元DB に締め切り前のオッズがあれば、そこから作る（[07-prediction-timing.md](07-prediction-timing.md#予測のときの人気の与え方)）。
- データの元: JRA-VAN Data Lab. の中央競馬のデータ（jvdata-store が DuckDB に貯めたもの）。
- 用語の意味: [02-glossary.md](02-glossary.md) を参照。
- 状態: 決めることは決まった（[15-decisions.md](15-decisions.md)）。プログラムは `src/yosou/longshots_in_top3/` に作った（人気に関する部品と 3着以内の目的変数の部品は `src/yosou/shared/` に移した。[04-classes.md](04-classes.md#1-共通の部品とこの予想だけの部品の分け方)）。実データでの学習はこれから。2026-09-24 に、既存モデルの修正計画に沿って直した（オッズから作った基準の補正・中穴と大穴で別のモデル・複勝の期待値。[15-decisions.md の 12](15-decisions.md#12-既存モデルの修正計画での直し)）。

**1レースで、複数の穴馬を挙げられる。** 穴馬1頭ずつに別々の確率を出すので、1レースの出力は「穴馬ごとの、3着以内に入る確率」の表（高い順）になる。穴馬は出走馬の大半（16頭立てなら 6〜16番人気の 11頭）なので、「1レースで挙げるのは1頭まで」のような決まりは設けない（[15-decisions.md](15-decisions.md#11-買いと判定する線引きを設計書に入れるか)）。

**中穴・大穴は、出力を絞るときにだけ使う区分である。** 既定では穴馬すべてを出す。`predict` に `--zone 中穴` か `--zone 大穴` を付けると、その区分の穴馬だけを出す。区分は出走頭数と人気順位から決め（線引きは [08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)）、モデルには渡さない。モデルは1つで、区分ごとに分けない（[15-decisions.md](15-decisions.md#3-区分ごとに別のモデルにするか)）。

手本とした予想（[手本の 01](../近走と適性から3着以内を予想/01-overview.md)）は、出走する全頭について「3着以内に入る確率」を出す。危険な人気馬の予想（[人気馬の 01](../人気馬が4着以下になるかを予想/01-overview.md)）は、対象を人気馬に絞って「4着以下になる確率」を出す。この予想は、対象を穴馬（人気馬の裏返し）に絞り、当てる側は手本と同じ「3着以内」にしたものである。

## 1頭の例

架空の1頭を当日に予測する場合で、モデルに何を渡して何が返ってくるかを示す。材料のうち、この予想で足した人気の分だけを書いた。近走・適性・調教・血統は、手本の [「1頭の例」](../近走と適性から3着以内を予想/01-overview.md#1頭の例) と同じ架空の馬とする。

> - **レース**: 2025年5月、東京・芝1600m・良、オープン、**16頭立て**
> - **人気**: **8番人気**（16頭立てなので、穴馬は 6番人気以下。この馬は対象になる。区分は中穴）
> - **前走**: 3着、5番人気（人気より2つ良い着順）
> - **近5走**: 平均人気 4.6、そのうち人気より悪い着順だったのは 2回
> - **近走・適性・調教・血統**: 手本の「1頭の例」と同じ
>
> → モデルの予測確率: **3着以内に入る確率 0.22**

この 0.22 は「8番人気だが、5回に1回ほどの見込みで馬券になる」という意味である。同じレースのほかの穴馬にも、それぞれの確率が出る。

## 使うデータ

75個の特徴量を、10 のまとまりに分けて使う（当日の場合。木曜・前日は一部を使わない。[07-prediction-timing.md](07-prediction-timing.md#時点ごとに使う特徴量) を参照）。75個の一覧は [09-features.md](09-features.md) を参照。

- **A〜I の9つのまとまり（71個）は、手本と同じである。** 何が分かるかの見取り図は [手本の 01 の「使うデータ」](../近走と適性から3着以内を予想/01-overview.md#使うデータ) を参照。
- **J（4個）は、危険な人気馬の予想と同じである。** この予想では、それをそのまま使う。

| まとまり | 何が分かるか | 特徴量の例 |
|---|---|---|
| J. 人気と人気の履歴 | 今回どれだけ人気か。これまで人気より走ってきたか | 人気順位、前走の人気と着順の差、近5走の平均人気 |

使わないデータとその理由は、[09-features.md](09-features.md#使わない特徴量) と [11-leak-prevention.md](11-leak-prevention.md) を参照。
