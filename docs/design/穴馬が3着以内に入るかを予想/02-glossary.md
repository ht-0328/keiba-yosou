# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想と危険な人気馬の予想に出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語（二値分類・特徴量・目的変数・リークなど）は、手本と同じものをそのまま使う。人気に関する用語（人気馬・少頭数・多頭数・確定単勝人気・締め切り前の人気・時系列オッズ・馬券外）は、危険な人気馬の予想と同じものをそのまま使う。この予想で増えるのは、穴馬とその区分に関する用語だけである。

- 機械学習の用語は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。増える用語も、減る用語も無い。
- 競馬とこの設計の用語（ID 列・評価用の列・ウォームアップ期間・レース内順位・事実表・出走別着度数）は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。
- 人気に関する用語は [人気馬の 02 の「この予想で増える用語」](../人気馬が4着以下になるかを予想/02-glossary.md#この予想で増える用語) を参照。下の表は、それに足すものである。

## この予想で増える用語

| 用語 | 意味 | この設計では |
|---|---|---|
| 穴馬 | 単勝人気が下位の馬。何番人気からを指すかに、決まった定義は無い | 学習データの行にする馬。範囲は出走頭数で変え、人気馬の範囲の裏返しにする（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |
| 中穴・大穴 | 穴馬のうち、人気が比較的上の馬（中穴）と、下の馬（大穴）。一般には、中穴は 4〜9番人気あたり、大穴は二桁人気や単勝 50倍以上を指すことが多いが、決まった定義は無い | 出力を絞るときの区分。線引きは出走頭数で変える（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)）。モデルには渡さない（[15-decisions.md](15-decisions.md#5-穴馬の区分を特徴量に入れるか)） |
| 穴馬の区分 | その穴馬が中穴か大穴か | `predict` の `--zone` で指定する値。出力の表にも列として出す（[07-prediction-timing.md](07-prediction-timing.md#予測のときの人気の与え方)） |
| 馬券内 | 3着以内に入ること（複勝の対象になること）。「馬券外」の反対 | 目的変数が 1 になる側。着順で決め、頭数では変えない（[10-target.md](10-target.md#作り方)） |
| 見立ての人気 | 発売の前に、利用者が「何番人気になりそうか」を自分で決めた人気 | 木曜の予測で使う。`--pops 馬名:人気` で渡す（[07-prediction-timing.md](07-prediction-timing.md#予測のときの人気の与え方)） |
| 道具の穴馬 | keiba-yosou の道具（`tools/傾向スコア/`）が使う穴馬の範囲。6番人気以下で、頭数によらない | この設計とは範囲が違う。道具で穴馬の事例を数えるときは、`--pop` と `--field` で、この設計の範囲にそろえる |
