# 11 リークを防ぐ決まり

**この文書で決めること:** 学習では当たるのに本番では当たらないモデル（リーク）にならないよう、特徴量を作るときと、行を選ぶときに守る決まり。

**結論: 特徴量は、予測する時点（木曜・前日・当日。[07-prediction-timing.md](07-prediction-timing.md)）で分かることだけから作る。人気と出走頭数の扱い（決まり 5・6）は危険な人気馬の予想と同じで、この予想では、穴馬の区分と、木曜の見立ての人気についての決まり（7・8）を足す。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 決まり

1〜4 は手本と同じで、[手本の 11 の「決まり」](../近走と適性から3着以内を予想/11-leak-prevention.md#決まり) を参照する（そのレースの結果を使わない、過去走と調教は開催日より前のものだけから計算する、マスタの累計の成績を使わない、学習データと予測用データを同じプログラムで作る）。

5・6 は危険な人気馬の予想と同じで、[人気馬の 11 の「決まり」](../人気馬が4着以下になるかを予想/11-leak-prevention.md#決まり) を参照する（人気は、学習では確定単勝人気、予測ではその時点で分かる人気を使い、行を選んだ値と特徴量「人気順位」の値を同じにする。出走頭数は、その時点で分かる頭数を使う）。この予想では、7 と 8 を足す。

**7. 穴馬の区分は、行を選んだ人気と頭数から決め、出力の列にだけ使う。**

- 区分（中穴・大穴）は、特徴量にしない（[09-features.md](09-features.md#使わない特徴量)）。出力の表の列と、区分ごとの当たり具合を見るのにだけ使う。
- 区分を決める人気と頭数は、穴馬かどうかを決めた値と同じにする。「穴馬の行なのに区分が無い」「6番人気なのに大穴」のような食い違いを作らないためである。
- 予測のあとに取消が出て頭数が変わると、穴馬の範囲（13頭以下か 14頭以上か）も区分も変わることがある。そのときは、予測を出し直す（決まり 6 と同じ）。木曜の頭数は出走馬名表の頭数なので、前日までに変わることが多い。

**8. 木曜の人気は利用者の見立てで、学習の確定単勝人気とはずれるものとして扱う。**

- 木曜は前売りが無いので、利用者が「何番人気になりそうか」を見立てて `--pops 馬名:人気` で渡す（[07-prediction-timing.md](07-prediction-timing.md#予測のときの人気の与え方)）。
- モデルは、確定単勝人気で選んだ穴馬で学習している。木曜の予測は「N 番人気になりそうな馬」に、「確定で N 番人気だった馬」の確率を当てはめるので、見立てが外れた分だけ確率もずれる。前日・当日に、見た人気や締め切り前のオッズで出し直して、ずれを小さくする。
- 見立ての人気を元DB に書き込まない。元DB は読むだけである（keiba-yosou の決まり）。見立ては `--pops` の引数として、その予測にだけ使う。
