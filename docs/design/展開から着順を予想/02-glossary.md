# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想に出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語（特徴量・目的変数・リーク・過学習・早期終了など）と、競馬とこの設計の用語（ID 列・評価用の列・ウォームアップ期間・事実表など）は、手本と同じものをそのまま使う。この予想で増えるのは、レースの中で確率をそろえること・回帰・分位点・スタッキング・過去のレースでの確かめ方に関する用語と、位置取り・ペース・末脚・着順・馬券に関する用語である。

- 機械学習の用語は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。
- 多クラス分類・クラス・累積確率・集約・マクロ F1 は [荒れ具合の 02](../レースの荒れ具合を4段階で予想/02-glossary.md#この予想で増える用語機械学習) を参照。
- 競馬とこの設計の用語は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。

## この予想で増える用語（機械学習）

| 用語 | 意味 | この設計では |
|---|---|---|
| 回帰 | 当てたい値が、クラスではなく数（秒・円など）の問題 | 前半タイムの基準との差（秒）を当てる（予想③） |
| 分位点 | 値を小さい順に並べたとき、下から何割の位置にある値か。50% の分位点は真ん中の値（中央値） | 前半タイムの 10%・50%・90% の分位点 |
| 分位点回帰 | 平均ではなく、分位点を当てるように学習する回帰。10% の分位点を当てるモデルは「これより速くなるのは 10% だけ」という値を出す | LightGBM は `objective="quantile"`、CatBoost は `MultiQuantile`（[03-library-basics.md](03-library-basics.md#3-前半タイムの分位点回帰)） |
| 予測区間 | 実際の値が、決めた割合で入ると見込む幅 | 10% の分位点から 90% の分位点までの幅（80% の予測区間） |
| 包含率 | 実際の値が予測区間に入った割合。80% の予測区間なら 80% に近いほど良い | [16-evaluation.md](16-evaluation.md#2-評価指標) |
| MAE（平均絶対誤差） | 予測した値と実際の値の差の絶対値の平均 | 前半タイムの秒数の当たり具合 |
| raw スコア（ロジット） | 二値分類のモデルが、確率に直す前に出す値。確率 p とは `log(p / (1 − p))` で行き来できる | 先頭の確率をレースの中でそろえる材料（[03-library-basics.md](03-library-basics.md#2-先頭の確率をレースの中で合計-1-にそろえる)） |
| ソフトマックス | いくつかの値を、合計 1 の確率に直す計算。`exp(値) ÷ exp(値) の合計` | 1レースの各馬の raw スコアを、合計 1 の先頭の確率に直す |
| 温度 | ソフトマックスの前に raw スコアを割る数。1 より大きいと確率がならされ、小さいととがる | 検証データの後半で決める（[10-target.md](10-target.md#2-先頭の馬の目的変数)） |
| 校正 | モデルが出した確率を、実際の割合に合うように直すこと | 温度を決めること |
| レースごとのログ損失 | 各レースで、実際に先頭になった馬に付けた確率 p の `−log(p)` を、レースで平均した値。小さいほど良い | 予想①のいちばん大事な指標（[16-evaluation.md](16-evaluation.md#2-評価指標)） |
| 平滑化 | 走った数が少ない馬の割合を、全体の割合に寄せること。1走して1回先頭だった馬を「先頭率 100%」と見ないため | 先頭率・先団率（[09-features.md](09-features.md#k-序盤の位置取りの履歴15個)） |
| 回帰（二乗誤差） | 予測した値と実際の値の差の2乗の平均を小さくするように学習する回帰。平均に近い値を出す。LightGBM は `objective="regression"`、CatBoost は `loss_function="RMSE"` | 4コーナーの位置（④）と上がりの速さ（⑤）を当てる（[03-library-basics.md](03-library-basics.md#4-4コーナーの位置と上がりの速さの回帰)） |
| スタッキング | あるモデルの予測の値を、別のモデルの特徴量に入れて使うこと。前のモデルを「前の組」、それを使うモデルを「後の組」と書く | 前半（①〜③）の予測を後半（④〜⑥）と着順（⑦）に、後半の予測を着順に入れる（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 11） |
| 学習に使っていない予測 | そのサンプルを学習に使っていないモデルが出した予測。スタッキングで後の組の学習データに入れる前の組の予測は、これでなければならない。学習に使ったサンプルへの予測は、実際より当たって見えるため | 前の年までで学習したモデルで、その年を予測した値（[16-evaluation.md](16-evaluation.md#7-年ごとの的中率と回収率)） |
| ウォークフォワード検証 | 時期を少しずつ先へずらしながら、「その時期より前のデータだけで学習し、その時期を予測する」をくり返す確かめ方。本番と同じく、未来のデータを使わずに予測したときの当たり具合が分かる | 1年ずつずらし、その年の前の年までで学習し直して、その年を予測する（[16-evaluation.md](16-evaluation.md#7-年ごとの的中率と回収率)） |
| Harville の式 | 1着の確率だけから、2着・3着の確率を出す式。「1着の馬を除いた残りの馬の中で、1着の確率の割合で2着が決まる」と考える。例えば 1着の確率が A 0.5・B 0.3・C 0.2 なら、A が1着のとき B が2着の確率は 0.3 ÷（0.3 + 0.2）= 0.6 | 着順の予想（⑦）の、2着・3着と買い目ごとの確率（[10-target.md](10-target.md#10-着順の目的変数と確率の出し方)） |
| ならしの指数 | Harville の式で 2着・3着を割り当てるとき、1着の確率を何乗してから使うか（λ）。1 なら Harville の式のまま。1 より小さいと、2着・3着の確率が人気のない馬にも配られる。Harville の式のままだと、強い馬の 2着・3着の確率が高く出すぎることが知られているため | 0.50〜1.00 の 0.05 刻みから、検証データで決める（[15-decisions.md の 19](15-decisions.md#19-2着3着の割り当てのならし)） |

## この予想で増える用語（競馬とこの設計）

| 用語 | 意味 | この設計では |
|---|---|---|
| 最初のコーナー | そのレースで、通過順位が記録された最初のコーナー。JV-Data の「コーナー通過順位」（`ra__コーナー通過順位`）の最初の行 | 先頭と位置を見る地点（[10-target.md](10-target.md#1-最初のコーナーの決め方)） |
| 通過順位の文字列 | コーナーごとの馬番の並び。例 `(*8,7)10(3,9)` は「8番と7番が並んで先頭で、そのうち前は8番、その後ろに10番、…」。`( )` は集団、`*` は集団の中の先頭、`-` は小差、`=` は大差 | 先頭の馬を決める元（[10-target.md](10-target.md#2-先頭の馬の目的変数)） |
| 先頭の馬 | 最初のコーナーで先頭だった馬。通過順位の文字列で1頭に決まるときだけ正解にする | 予想①の目的変数 |
| 序盤の位置 | 最初のコーナーでの順位を、0（先頭）〜 1（最後方）に直した値。`(順位 − 1) ÷ (出走頭数 − 1)` | 予想②の目的変数の元と、K の特徴量の元 |
| 先団・中団・後方 | 序盤の位置を3つに分けたもの。先団は 3分の1 まで、中団は 3分の2 まで、後方はそれより後ろ。この設計だけの区分で、JRA-VAN の脚質（逃げ・先行・差し・追込）とは別もの | 予想②のクラス（0・1・2） |
| 先頭率・先団率 | 過去の走のうち、最初のコーナーで先頭（先団）だった割合。平滑化してある | K・L の特徴量 |
| 前半タイム | JV-Data の前3ハロン。スタートから 600m のタイム。ただし距離が 200m で割り切れないレースは「余りの距離 + 400m」（1500m なら 500m、1150m なら 550m） | 予想③の元（[10-target.md](10-target.md#4-前半のペースの目的変数)） |
| 測る区間 | 前半タイムが何 m のタイムか（500・550・600m） | 距離から決まる |
| 前半タイムの基準 | 開催日の前日までの3年の、同じ競馬場・コース・距離・クラスのレースの前半タイムの平均。そのレースが「普段と比べて速いか遅いか」を測る物差し | [10-target.md](10-target.md#5-前半タイムの基準の作り方) |
| 基準との差 | 前半タイム − 前半タイムの基準（秒）。マイナスなら普段より速い | 予想③の回帰の目的変数 |
| ハイ・平均・スロー | 基準との差を、基準のばらつき（標準偏差）で割って3つに分けたもの | 予想③の多クラスの目的変数（0 = スロー、1 = 平均、2 = ハイ） |
| コーナーを5回以上通るレース | 1周半以上するレース（例: 中山の芝2500m）。JV-Data はコーナーを4つまでしか記録しないので、最初に通ったコーナーが記録から抜ける | 先頭と位置の正解を作らない（[10-target.md](10-target.md#1-最初のコーナーの決め方)） |
| 直線コース | コーナーの無いコース（新潟の芝1000m） | 先頭と位置の正解を作らない。前半ペースは作る |
| 後半タイム | JV-Data の後3ハロン（`ra` の「後3ハロン」）。ゴールまでの最後の 600m を、その時点の先頭の馬が通ったタイム | 予想⑥の元（[10-target.md](10-target.md#9-後半のペースの目的変数)） |
| 後半タイムの基準 | 前半タイムの基準と同じ作り方で、後半タイムの平均と標準偏差を出したもの | 予想⑥の目的変数と、U の特徴量（[10-target.md](10-target.md#9-後半のペースの目的変数)） |
| 上がり3ハロン | 1頭ごとの、最後の 600m のタイム（`se` の「後3ハロンタイム」）。後半タイム（レースの値）とは違い、その馬自身が走ったタイム | 予想⑤の元 |
| 上がりの速さ | 上がり3ハロンのレース内順位を、0（いちばん速い）〜 1（いちばん遅い）に直した値。`(上がりの順位 − 1) ÷ (上がりのある頭数 − 1)` | 予想⑤の目的変数と、N の特徴量（[10-target.md](10-target.md#8-上がりの速さの目的変数)） |
| 4コーナーの位置 | 4コーナーでの順位を、0（先頭）〜 1（最後方）に直した値。`(順位 − 1) ÷ (出走頭数 − 1)`。序盤の位置と同じ物差し | 予想④の目的変数と、N の特徴量（[10-target.md](10-target.md#7-4コーナーの位置の目的変数)） |
| 着順の位置 | 確定着順を、同じく 0（1着）〜 1（最下位）に直した値 | N の特徴量（4コーナーからゴールまでの位置の変化） |
| 券種 | 馬券の種類。この設計で扱うのは、単勝（1着を当てる）・複勝（3着以内を当てる。7頭立て以下は2着以内）・ワイド（2頭がどちらも3着以内）・馬連（1・2着の2頭。順番は問わない）・馬単（1着・2着を順番どおり）・3連複（1〜3着の3頭。順番は問わない）・3連単（1〜3着を順番どおり）の7つ。枠連と WIN5 は扱わない | [16-evaluation.md](16-evaluation.md#8-券種ごとの買い方) |
| 買い目・点数 | 1つの組み合わせを1点と数える。例えば「馬連 7-3・7-12」は 2点 | 1点100円で数える |
| 印 | 予想の結論を、馬に付ける記号で表したもの。◎（本命）・○（対抗）・▲（単穴）・△（連下）・☆（穴）・注（注意） | 付け方は [16-evaluation.md の 8.](16-evaluation.md#8-券種ごとの買い方) |
| 確定オッズ | 締め切ったあとに決まったオッズ。払戻の額はこのオッズで決まる。複勝とワイドは「最低〜最高」の幅で発表される | 期待値で買うときに使う。実際に買う時点（締め切り前）のオッズとは少し違う |
| 期待値 | 買い目が当たる確率 × オッズ。1.0 より大きければ、その確率が正しいかぎり、たくさん買うと払戻が賭け金を上回る見込み | 期待値で買うときの線（[16-evaluation.md の 8.](16-evaluation.md#8-券種ごとの買い方)） |
| 的中率 | 買ったレースのうち、1点でも当たったレースの割合 | 券種ごと・年ごとに出す（[16-evaluation.md の 7.](16-evaluation.md#7-年ごとの的中率と回収率)） |
| 回収率 | 払戻の合計 ÷ 賭け金の合計。100% を超えれば、賭けた額より多く戻った | 券種ごと・年ごとに出す |
