# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想には出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語（二値分類・特徴量・目的変数・リークなど）は、手本と同じものをそのまま使う。この予想で増えるのは、人気に関する競馬の用語だけである。

- 機械学習の用語は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。増える用語も、減る用語も無い。
- 競馬とこの設計の用語（ID 列・評価用の列・ウォームアップ期間・レース内順位・事実表・出走別着度数）は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。下の表は、それに足すものである。

## この予想で増える用語

| 用語 | 意味 | この設計では |
|---|---|---|
| 人気馬 | 単勝人気が上位の馬。何番人気までを指すかに、決まった定義は無い | 学習データの行にする馬。範囲は出走頭数で変える（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |
| 少頭数・多頭数 | 出走頭数が少ないレース・多いレース。JRA の公式な定義は無い | 何頭から多頭数とするかは [15-decisions.md](15-decisions.md#1-多頭数を何頭からにするか) を参照 |
| 確定単勝人気 | 発売の締め切り後に確定した単勝オッズの、小さい順の順位。JV-Data の `se`（馬毎レース情報）にある | 学習データで人気馬を選ぶ値であり、特徴量「人気順位」の値（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 5） |
| 締め切り前の人気 | 発走前の、まだ動く単勝オッズの順位 | 予測のときに使う人気。利用者が渡すか、元DB のオッズから作る（[07-prediction-timing.md](07-prediction-timing.md#予測のときの人気の与え方)） |
| 時系列オッズ | 発走前の単勝オッズを、時刻ごとに記録した JV-Data（速報系のデータ `0B41`） | 当日の人気を元DB から作るときに使う。今の元DB には入っていない（[09-features.md](09-features.md#使うデータの期間)） |
| 馬券外 | 3着以内に入らないこと（複勝の対象から外れること） | 目的変数が 1 になる側。着順で決め、頭数では変えない（[10-target.md](10-target.md#作り方)） |
| 危険な人気馬 | 人気のわりに走らず、馬券にならなかった馬 | 4着以下になる確率が高いと予測された人気馬（[01-overview.md](01-overview.md)） |
