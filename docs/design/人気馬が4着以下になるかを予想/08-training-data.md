# 08 学習データ

**この文書で決めること:** 学習データの1行を何にするか。どのレース・どの馬・どの期間の行を入れるか。

**結論: 1サンプル = 1レースの人気馬1頭。中央競馬の芝・ダートの出走のうち、確定単勝人気が上位（13頭以下なら 1〜3番、14頭以上なら 1〜5番）の馬だけを行にする。期間は手本と同じ既定（2021年8月から、ウォームアップは 2020年）で、約 7.2 万行になる。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 学習データの形

架空の1レース（16頭立て）の一部を例にすると、学習データは次の形になる。

| レースID | 馬番 | 人気順位 | 出走頭数 | 斤量 | 前走の着順 | 近5走の平均人気 | …（特徴量はあと 60個以上） | 目的変数: 4着以下 |
|---|---|---|---|---|---|---|---|---|
| 架空レースA | 5 | 1 | 16 | 57.0 | 1 | 2.2 | … | 0 |
| 架空レースA | 14 | 2 | 16 | 55.0 | 3 | 4.6 | … | 1 |
| 架空レースA | 9 | 4 | 16 | 56.0 | （欠損値） | （欠損値） | … | 1 |

- この 16頭立てのレースから学習データに入るのは、1〜5番人気の5行だけである。6番人気以降の 11頭は行にしない（下の「3. どのサンプルを入れるか」）。
- 3着以内に入れるのは3頭までなので、この5行のうち、目的変数が 1 になる行は**少なくとも2つ**になる。
- 9番の馬は元DB に過去走が無いので、前走と近5走の特徴量は欠損値になる。学習データでは、欠損値を 0 で埋めず、欠損値のまま持つ。モデルに渡すときの欠損値の扱いは、[12-lightgbm.md](12-lightgbm.md#1-学習データの渡し方)・[13-catboost.md](13-catboost.md#1-学習データの渡し方) を参照。

## 2. 列の種類

学習データの列は4種類ある。モデルに渡すのは**特徴量と目的変数だけ**である。

| 種類 | 列 | モデルに渡すか |
|---|---|---|
| ID 列 | レースID、馬ID、開催日 | 渡さない |
| 特徴量 | 75個。[09-features.md](09-features.md) を参照 | `fit` の `X` として渡す |
| 目的変数 | 4着以下（1/0）。[10-target.md](10-target.md) を参照 | `fit` の `y` として渡す |
| 評価用の列 | 確定着順、確定の単勝オッズ、確定の単勝人気、単勝の払戻、複勝の払戻 | 渡さない |

- 確定の単勝人気は、評価用の列であると同時に、行を選ぶ条件であり、特徴量「人気順位」の元でもある。手本の予想と違って人気を特徴量に使う理由は [09-features.md](09-features.md#使わない特徴量) を参照。
- 2つの時点（前日・当日）のモデルは、同じ学習データから、その時点で使う特徴量の列だけを渡して学習する（[07-prediction-timing.md](07-prediction-timing.md#時点ごとに使う特徴量)）。
- ID 列と年を特徴量にしない理由は、[手本の 08 の「2. 列の種類」](../近走と適性から3着以内を予想/08-training-data.md#2-列の種類) と同じである。
- 予測用データは、この学習データから目的変数と評価用の列を除いた形になる。

## 3. どのサンプルを入れるか

| 決まり | 内容 | 理由 |
|---|---|---|
| 対象のレース | 中央競馬の平地（芝とダート）。障害は入れない | 障害は走り方が違い、レースの数も少ない |
| **対象の馬** | **出走した馬のうち、人気馬だけ。13頭以下のレースは確定単勝人気 1〜3番、14頭以上のレースは 1〜5番** | 当てたいのは人気馬が飛ぶかどうかである。6番人気以降の行を入れても、当てる対象にならない（[15-decisions.md](15-decisions.md#9-学習データの行を人気馬だけにするか)） |
| 取消・除外 | 出走取消・発走除外・競走除外はサンプルにしない | 走っていない馬には目的変数が無い |
| 期間 | 「学習データの始まり」から。既定は 2021年8月1日 | 下の「4. 期間の指定」 |
| 新馬戦 | 入れる | 過去走の特徴量は欠損値になるが、血統・騎手・調教師で予測できる。新馬戦でも人気は付く |

**人気馬の範囲は、出走頭数で変える。** 13頭以下（少頭数）は 1〜3番人気、14頭以上（多頭数）は 1〜5番人気である。どの頭数でも、人気馬が出走馬の 2〜4割に収まるようにした。14頭を境にした理由と、選ばなかった線引きは [15-decisions.md](15-decisions.md#1-多頭数を何頭からにするか) を参照。

**レース内順位は、そのレースの全出走馬から計算する。** まとまり G の特徴量（近5走の平均着差のレース内順位など）は、6番人気以降の馬も含めた全出走馬の中での順位である。人気馬だけで順位を付けると、同じ「3位」でも 16頭中の3位か5頭中の3位かで意味が変わる。そのため、行を人気馬に絞るのは、特徴量を作ったあとにする（[06-flowchart.md](06-flowchart.md#図1-学習データに入れる行の選び方)）。

**ウォームアップ期間。** 手本と同じ決まりで、学習データの始まりより前の出走も読み、サンプルにはせず、あとのサンプルの過去走の特徴量を計算するためだけに使う。ウォームアップ期間の出走は、人気馬かどうかによらず全部読む。近5走の平均人気（まとまり J）も、この期間の出走から数える。

## 4. 期間の指定

**期間の区切り方（4つの日と `train` の引数、既定の値、既定を 2021年8月からにした理由）は、手本とまったく同じである。** [手本の 08 の「4. 期間の指定」](../近走と適性から3着以内を予想/08-training-data.md#4-期間の指定) と [「既定を 2021年8月からにした理由」](../近走と適性から3着以内を予想/08-training-data.md#既定を-2021年8月からにした理由) を参照。

```powershell
uv run python -m yosou.favorites_out_of_top3 train --warmup-from 2020-01-01 --train-from 2021-08-01
```

（既定と同じ期間で学習するコマンド。`--warmup-from` は省略できる）

## 5. 行数の数え上げ

既定の期間（2021年8月から、中央の芝・ダート）で、学習データは**約 7.2 万行**になる（2026-09-22 時点の元DB で 72,396 行）。内訳は次のとおり。

| 人気馬の区分 | 行数 |
|---|---|
| 13頭以下のレースの 1〜3番人気 | 19,776 |
| 14頭以上のレースの 1〜5番人気 | 52,620 |
| 合わせて | 72,396 |

- 手本の予想は、同じ期間の全出走を使って約 23.6 万行である。人気馬だけに絞るので、行数はその3割ほどになる。
- 行数が減ると、LightGBM で「出走の少ないカテゴリの値をまとめる」設定を見直す必要がある（[12-lightgbm.md](12-lightgbm.md#2-ハイパーパラメータの初期値)）。
- この中を、学習データ・検証データ・テストデータに時期で分ける。分け方は次の設計書で決める。
