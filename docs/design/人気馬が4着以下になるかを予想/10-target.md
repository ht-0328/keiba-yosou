# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。

**結論: 目的変数は1つだけで、「その人気馬が4着以下なら 1、3着以内なら 0」。競走中止・失格も 1 にする。**（利用者が 2026-09-22 に決めた。[15-decisions.md](15-decisions.md#2-目的変数何を危険だったとするか)）

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 作り方

学習データの1行は、1レースの人気馬1頭である（[08-training-data.md](08-training-data.md#1-学習データの形)）。その1頭の結果から、次のように目的変数を決める。

| その人気馬の結果 | 答え（目的変数） | 意味 |
|---|---|---|
| 確定着順が 1着・2着・3着 | 0 | 馬券になった（危険ではなかった） |
| 確定着順が 4着以下 | 1 | 馬券にならなかった（危険だった） |
| 競走中止・失格 | 1 | 走ったが、馬券にならなかった |
| 出走取消・発走除外・競走除外 | ― | サンプルにしない（走っていない。[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |

- 着順は**確定着順**を使う。降着があれば、降着後の着順になる。
- 同着は、どちらも同じ着順として扱う（3着同着なら、2頭とも 0）。
- **7頭以下のレースでも、3着以内かどうかで決める。** 複勝は 7頭以下だと2着までしか付かないが、目的変数は頭数で変えない。頭数で意味が変わる目的変数だと、モデルが学ぶ「1」の意味がレースによってずれるためである。
- 目的変数は1つだけ置く。手本の予想のように「1着なら 1」の列は置かない。この予想で当てたいのは、人気馬が馬券圏内から外れるかどうかだけである。

`predict_proba()` の2列目が、目的変数が 1 になる確率、つまり「4着以下になる確率」になる（[03-library-basics.md](03-library-basics.md#この予想で違う点)）。

## 理由

**「4着以下なら 1」にする理由（「3着以内なら 1」の裏返しにしない理由）。**

- 当てたいのは「危険かどうか」である。1 を「危険だった」にしておくと、予測確率がそのまま「危険さ」の大きさになり、確率の高い順に並べるだけで、危ない人気馬の順になる。
- 「3着以内なら 1」にすると、危ない順に並べるのに 1 から引く手間が要り、確率の読み違いが起きやすい。

**中止・失格を 1 にする理由。** 出走して馬券にならなかった点は、4着以下と同じだからである。馬券を買った人から見れば、区別する意味が無い。

## 1 と 0 の数の偏り

1レースに人気馬は 3頭か 5頭で、そのうち3着以内に入れるのは最大3頭である。そのため、**1（4着以下）のほうが 0 よりやや多くなる。** 1番人気でも 4着以下になることは珍しくなく、5番人気では 4着以下のほうが多い。

この偏りは、**直さずにそのまま学習する。**

- 偏りを直す設定（片側のサンプルを重く扱う設定）を使うと、予測確率が実際の確率からずれる。
- この予想では、予測確率を確率として使う（オッズと比べる、線引きを決める）。そのため、確率の大きさがずれる設定は使わない。
- 手本の予想（3着以内なら 1）は、1 が 0 より大幅に少なかった。この予想は、手本より偏りが小さい。

LightGBM と CatBoost の、偏りを直す設定の名前は、[12-lightgbm.md](12-lightgbm.md#2-ハイパーパラメータの初期値)・[13-catboost.md](13-catboost.md#2-ハイパーパラメータの初期値) を参照。
