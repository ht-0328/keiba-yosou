# 03 LightGBM と CatBoost（と pandas）の使い方

**この文書の目的:** 設計を読む前に、LightGBM と CatBoost（と、表を扱う pandas）で何ができるかを知っておく。

**この文書で示すこと: 使う道具は手本の予想とまったく同じである。そのため、道具の説明は書かず、[手本の 03](../近走と適性から3着以内を予想/03-library-basics.md) を参照する。この予想で違う点は無い。**

同じ説明を2つのフォルダに写すと、片方だけ直したときに食い違う。そのため、この文書は入口だけを持つ。

## この予想で違う点

**無し。** 新しいライブラリは使わず、手本で使っていない機能も使わない。

`predict_proba()` の2列目が何の確率かだけが変わる。手本では「3着以内に入る確率」、この予想では「4着以下になる確率」である（[10-target.md](10-target.md#作り方)）。どちらも目的変数が 1 になる確率で、モデルの使い方は変わらない。
