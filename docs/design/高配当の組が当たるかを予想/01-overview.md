# 01 高配当の組が当たるかを予想する: 概要

**5つの券種（ワイド・馬連・馬単・3連複・3連単）のオッズと、馬ごとの予想（近走と適性から3着以内を予想・1着の予想・人気馬が4着以下になるかを予想）から、馬券の組ごとに「その組が当たる確率」を出す予想である。** 出した確率で、高配当の組が当たるかを見る。
組とは、1枚の馬券が当たりになる馬の組み合わせである（ワイド 5-12、3連単 5→12→3 など）。
高配当の組とは、オッズが券種ごとの「高配当の線」以上の組である（3連複なら 100倍以上、いわゆる万馬券。券種ごとの線は [10-target.md](10-target.md#オッズの帯)）。
この予想は、**市場の確率（その券種のオッズから見た組の確率）を出発点にして、そこからの上げ下げだけを学ぶ**。上げ下げの手がかりは、馬ごとの予想が市場より高く見ている馬と、券種どうしのオッズのずれである。
利用者の依頼「高配当の的中に特化した予想を作ってほしい。回収率は 100% を超えること」で作った。

- 作り方: 機械学習の二値分類。学習データの1行は「1レース × 1券種 × 1つの組」で、目的変数は「その組が当たったら 1」。券種ごとに、LightGBM と CatBoost の2つのモデルで確率を出し、平均する。
- 予測する時点: 当日だけ（締め切り前の5券種のオッズがそろう、発走の約10分前）。木曜・前日は出さない（[07-prediction-timing.md](07-prediction-timing.md)）。
- 使い方: オッズが高配当の線以上・上限未満で、期待値（確率 × オッズ）が 1.05 以上の組を、買い目「ワイド（高配当）」のように券種ごとに出す。今週の予想の当日の予想・発走前の通知・その日の結果に出す。財布と買うレースの計画には入れない（[買うレースと買い目を決める の 08 の 2](../買うレースと買い目を決める/08-bankroll-and-review.md#高配当の買い目)）。
- データの元: JRA-VAN Data Lab. の中央競馬のデータ（jvdata-store が DuckDB に貯めたもの）と、このリポジトリのほかの予想が出した馬ごとの予想。
- 用語の意味: [02-glossary.md](02-glossary.md) を参照。
- 状態: 決めることは全部決まった（[15-decisions.md](15-decisions.md)）。本番で出す券種はワイド・馬連・馬単・3連複の4つ、1レース・1券種の上限は確率の高い順に 10点（正式なパッケージでの数え直し [16-evaluation.md の 6](16-evaluation.md#6-確かめた結果) で決めた）。プログラムは `src/yosou/high_payout_combos/`、道具は `tools/高配当の買い目/`。

**手本の予想（[近走と適性から3着以内を予想](../近走と適性から3着以内を予想/01-overview.md)）との違いは5つである。**
①学習データの1行が「1頭」ではなく「1つの組」である。
②特徴量を近走や適性から作らず、オッズと、ほかの予想が出した確率・印から作る。近走や適性は、馬ごとの予想を通して間接に使う。
③出発点（基準）が単勝オッズではなく、その券種のオッズから見た組の確率である。
④外れの組が当たりの組よりずっと多いので、外れの組を間引いて学ぶ（[08-training-data.md](08-training-data.md#4-外れの組の間引きと行の重み)）。
⑤予測は当日だけで、モデルは時点ごとではなく券種ごとに分ける。

## 1つの組の例

架空の1つの組を当日に予測する場合で、モデルに何を渡して何が返ってくるかを示す。値はすべて架空である。

> - **レース**: 16頭立て。1番人気は単勝 3.2倍で、危険な人気馬（消）と判定されている
> - **組**: ワイド 5-12。ワイドの最低オッズは **24.0倍**（高配当の線 10倍以上・上限 300倍未満なので、買える帯にある）
> - **市場の確率（出発点）**: 1 ÷ 24.0 = 0.042。このレースのワイドの全部の組で合計すると 3.9 なので、合計が 3 になるようにそろえて **0.032**
> - **ほかの券種の市場**: 3連単のオッズから足し合わせた「5番と12番がどちらも3着以内」の確率は 0.035。馬連 5-12 の市場の確率は 0.011
> - **5番の馬**: 3番人気（単勝 6.0倍）。3着以内の確率 0.40、複勝オッズから見た3着以内率 0.38（差 +0.02）。印は ○
> - **12番の馬**: 9番人気（単勝 28.0倍）。3着以内の確率 0.21、複勝オッズから見た3着以内率 0.14（差 **+0.07**。6番人気以下で、複勝オッズより来ると見る馬）。印は ☆
> - **組のまとめ**: 馬ごとの予想から Harville の式で出した「どちらも3着以内」の確率は 0.050（市場の確率より高い）。組に危険な人気馬はいない
>
> → モデルの予測確率: **この組が当たる確率 0.047**（市場の確率 0.032 から上げた）。期待値 = 0.047 × 24.0 = **1.13**。期待値の線 1.05 以上なので、買い目に入る

市場の確率 0.032 にオッズ 24.0 を掛けると 0.77 で、何も手がかりが無ければ、どの組を買っても払戻率（ワイドは 77.5%）ほどしか戻らない。この予想は、市場の確率より当たると見た組だけを選ぶ。

## 使うデータ

特徴量は6つのまとまり（A〜F）に分ける。数は券種で違い、2頭の券種（ワイド・馬連・馬単）は 80個ほど、3頭の券種（3連複・3連単）は 100個ほどである。一覧は [09-features.md](09-features.md) を参照。

| まとまり | 何が分かるか | 特徴量の例 |
|---|---|---|
| A. その券種の市場 | その券種を買う人たちと、3連単を買う人たちが、この組をどう見ているか | オッズの対数、市場の確率の対数、3連単から足し合わせた確率の対数、その差 |
| B. ほかの券種の市場 | 同じ馬どうしの組を、ほかの券種の人たちはどう見ているか | ワイドの組に対する、馬連・馬単の同じ2頭の市場の確率 |
| C. Harville の式で出した確率 | 馬ごとの1着の確率（予想と、単勝の市場）から組み立てると、この組はどれだけ来るか | 予想の Harville の確率、単勝の市場の Harville の確率、その券種の市場との差 |
| D. 組の位置ごとの馬の材料 | 組の1頭ずつが、市場よりどれだけ来ると予想されているか | 3着以内の確率、複勝オッズから見た3着以内率との差、人気、印、危険な人気馬か |
| E. 組のまとめ | 組の全部の馬を合わせると、どんな組か | 人気の和、複勝オッズより来ると見る穴馬の数、危険な人気馬の数 |
| F. レースの材料 | どんなレースか（その組だけでなく、レース全体の形） | 頭数、1番人気のオッズ、1番人気が危険な人気馬か、対象の組の数 |

使わないデータとその理由は、[09-features.md](09-features.md#使わない特徴量) と [11-leak-prevention.md](11-leak-prevention.md) を参照。
