# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想には出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語は、手本と同じものをそのまま使う。この予想で増えるのは、組・オッズの帯・市場の確率・出発点と、外れの組の間引き・評価の用語である。

- 機械学習の用語（二値分類・特徴量・目的変数・リーク・早期終了など）は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。
- 競馬とこの設計の用語（ID 列・評価用の列・確定オッズ・締め切り前のオッズ・オッズから見た勝率・単勝の期待値など）は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。
- 印（◎○▲△☆注消）と危険な人気馬の決め方は [買うレースと買い目を決める の 07 の 3](../買うレースと買い目を決める/07-expected-value.md#3-危険な人気馬の判定) と [07 の 5](../買うレースと買い目を決める/07-expected-value.md#5-印の付け方) を参照。下の表は、それに足すものである。

## この予想で増える用語

| 用語 | 意味 | この設計では |
|---|---|---|
| 組 | 1枚の馬券が当たりになる馬の組み合わせ。順不同の券種（ワイド・馬連・3連複）は馬番の小さい順、着順を区別する券種（馬単・3連単）は着順の並びで書く | 学習データの1行（[08-training-data.md](08-training-data.md#1-学習データの形)） |
| 組の位置 | 組の中の何頭目か。着順を区別する券種は着順（1着・2着・3着）、順不同の券種は単勝人気の小さい順に並べた順 | 馬ごとの材料を列にするときの並び（[09-features.md](09-features.md#d-組の位置ごとの馬の材料)） |
| オッズの板 | 1つの券種の、全部の組のオッズの一覧。列はレースID・組番・オッズ | 5券種ぶんを使う。学習は確定オッズ、予測は締め切り前のオッズ（[07-prediction-timing.md](07-prediction-timing.md#予測のときのオッズの与え方)） |
| ワイドの最低オッズ | ワイドのオッズは「最低〜最高」の幅で発表される。その低いほう | ワイドのオッズは、すべて最低オッズで数える |
| オッズの帯 | 券種ごとの3つの線（学ぶ下限・高配当の線・上限）で区切ったオッズの範囲 | [10-target.md](10-target.md#オッズの帯) |
| 学ぶ下限 | このオッズ以上の組を、学習データと予測の対象にする線 | 値は [10-target.md](10-target.md#オッズの帯) の表 |
| 高配当の線 | このオッズ以上の組を「高配当の組」と呼び、買い目の候補にする線 | 値は同じ表。3連複なら 100倍（万馬券） |
| 上限 | このオッズ以上の組は、学習データにも買い目にも入れない線 | 値は同じ表 |
| 対象の組 | オッズが学ぶ下限以上・上限未満の組 | 学習データと予測の行（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |
| 市場の確率 | その券種のオッズから見た、組が当たる確率。1 ÷ オッズ を、同じレースのその券種の全部の組で合計が 1（ワイドは、当たりの組が3つあるので 3）になるようにそろえた値 | 24.0倍のワイドで、レースの合計が 3.9 なら 0.032。出発点と、特徴量のまとまり A |
| 3連単から足し合わせた確率 | 3連単の市場の確率を、その組が当たりになる並びの全部で足した値。「5番と12番がどちらも3着以内」なら、5番と12番を含む3連単の組の市場の確率を全部足す | 特徴量のまとまり A |
| Harville の式 | 馬ごとの1着の確率から、組の確率を作る式。1着の馬を除いた残りで2着を、さらに残りで3着を、同じ比で決める | 特徴量のまとまり C（[09-features.md](09-features.md#c-harville-の式で出した確率)） |
| 複勝オッズから見た3着以内率 | 複勝の最低と最高の真ん中のオッズの逆数を、同じレースの中で合計が 3（7頭以下は 2）になるようにそろえた値 | 馬ごとの材料。3着以内の確率との差を見る |
| 出発点（基準） | モデルが学び始める位置。市場の確率をロジットにした値。モデルは、ここからの上げ下げだけを学ぶ | [10-target.md](10-target.md#出発点基準) |
| ロジット | 確率 p を log(p ÷ (1 − p)) にした値。確率 0.032 なら −3.41 | 出発点の形 |
| 期待値 | モデルの確率 × オッズ。1 で元返し。1.13 なら、100円あたり平均 113円戻る見込み | 買い目を選ぶ値 |
| 期待値の線 | 期待値がこの値以上の組を買う線 | 全券種で同じ値（[15-decisions.md の 10](15-decisions.md#10-期待値の線)） |
| 馬ごとの表 | 1頭1行の表。馬ごとの予想（3着以内の確率・1着の確率）と、市場の見立て・人気・印・危険な人気馬の判定を持つ | 特徴量のまとまり C〜F の元（[08-training-data.md](08-training-data.md#5-馬ごとの予想の出どころ)） |
| 学習に使っていない期間の予測 | 予想のモデルが、自分の学習に使っていないレースに出した予測。過去のレースを区切りごとに「前の期間だけで学んで次の期間を予測する」形で作る | 馬ごとの表の、過去のレースの分（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 1） |
| 外れの組の間引き | 外れの組の一部だけを、くじで選んで学習データに残すこと | [08-training-data.md](08-training-data.md#4-外れの組の間引きと行の重み) |
| 行の重み | 学習のときに、行ごとに「どれだけ重く見るか」を表す数。重み 10 の行は、同じ行が 10個あるのと同じように誤差に数えられる | 間引いた外れの組に、残した割合の逆数を付ける |
| 対数損失（ログ損失） | 確率が正解からどれだけ外れたかを測る値。小さいほど良い | 市場の確率と比べる（[16-evaluation.md](16-evaluation.md#2-評価指標)） |
| 探す期間・確かめる期間 | 買い目の決まり（線や材料）を選ぶのに結果を見てよい年と、選んだあとに同じ決まりで数えるだけの年 | 年の分け方は [16-evaluation.md の 1](16-evaluation.md#1-期間の分け方) |
| ブートストラップの 90% の幅 | 開催日を単位に、くじで選び直した開催日の集まりで回収率を何度も数え、その 90% が入る範囲。回収率が偶然でどれだけ動くかを表す | 採用の基準（[16-evaluation.md](16-evaluation.md#5-採用の基準)） |
| 落ち込み | 買い続けたときに、それまでの最高の収支から、いちばん下がった額 | 運用の目安（[16-evaluation.md](16-evaluation.md#2-評価指標)） |
