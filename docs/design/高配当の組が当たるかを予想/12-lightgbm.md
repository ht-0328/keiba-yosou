# 12 LightGBM で学習・予測するための設計

**この文書で決めること:** 07〜10 で決めた学習データ（特徴量と目的変数）は、LightGBM と CatBoost に共通である。この文書では、それを LightGBM で学習・予測するために、LightGBM だけに必要な次の3つを決める。**節の番号と題名は、手本の 12 とそろえてある。**

| 決めること | 結論 |
|---|---|
| 1. 学習データの渡し方 | 特徴量は全部を数値のまま渡す。市場の確率のロジットを `init_score`、行の重みを `sample_weight` として渡す |
| 2. ハイパーパラメータの初期値 | 目的関数は二値分類（`binary`）。木の数は早期終了で決める。手本より、少ない当たりの組に合わせすぎない向きの値にする |
| 3. 学習・予測・保存の手順 | 券種ごとに1つずつ、計5つのモデルを学習する。学習したらモデルを保存し、予測のときはその券種のものを読み込む（4.〜6.） |

- 用語の意味は [02-glossary.md](02-glossary.md) を参照。
- 学習データ・特徴量・目的変数は CatBoost と共通で、[08-training-data.md](08-training-data.md)・[09-features.md](09-features.md)・[10-target.md](10-target.md) を参照。この文書には、LightGBM だけに関わることを書く。
- CatBoost の設計は [13-catboost.md](13-catboost.md) を参照。
- LightGBM の使い方の基本は [03-library-basics.md](03-library-basics.md) を参照。
- 図の読み方は、フローチャートは [手本の 06](../近走と適性から3着以内を予想/06-flowchart.md#図の読み方)、シーケンス図は [手本の 05](../近走と適性から3着以内を予想/05-sequence.md#図の読み方) の「図の読み方」を参照。

## 1. 学習データの渡し方

学習と予測は、共有の `LightGbmModel`（`src/yosou/shared/ml_model/`）が行う。この予想は、学習データ（`TrainingData`）に出発点と重みを入れて渡すだけである。

| 列 | 渡し方 | 理由 |
|---|---|---|
| 数値特徴量（全部） | そのまま渡す。欠損値も NaN のまま | LightGBM は、欠損値を分かれ道のどちら側に送るかを学習で決める。ほかの券種の板に無い組（まとまり B）が欠損値になる |
| カテゴリ特徴量 | 無い | [09-features.md](09-features.md#カテゴリ特徴量の渡し方) |
| 出発点（市場の確率のロジット） | 学習データは `fit(init_score=出発点)`、検証データは `fit(eval_init_score=[出発点])` | 市場の確率からの上げ下げだけを学ばせる（[10-target.md](10-target.md#出発点基準)） |
| 行の重み | 学習データは `fit(sample_weight=重み)`、検証データは `fit(eval_sample_weight=[重み])` | 間引いた外れの組を、元の数のぶん重く見る。検証データにも渡すのは、早期終了が見る当たり具合を、間引く前と同じ割合の対数損失にするため（[08-training-data.md](08-training-data.md#4-外れの組の間引きと行の重み)） |
| ID 列・評価用の列 | 渡さない | [08-training-data.md](08-training-data.md#2-列の種類) |

## 2. ハイパーパラメータの初期値

`lightgbm.LGBMClassifier` の引数名で書く。ここの値は設定ファイルの初期値で、プログラムを書き換えずに設定ファイルで変えられる（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)）。5券種とも同じ値で学ぶ。

| 引数 | 初期値 | 意味 | 理由 |
|---|---|---|---|
| `objective` | `binary` | 目的関数。二値分類 | 組が当たる確率を返すようにする |
| `learning_rate` | 0.03 | 学習率 | 手本（0.05）より小さくする。出発点からの上げ下げは小さいので、少しずつ学ぶ |
| `n_estimators` | 3000 | 木の数の上限 | 実際の数は早期終了で決まる |
| 早期終了 | 100 回 | 検証データの当たり具合が、木を 100 本足しても良くならなければ止める | 木を増やしすぎて過学習するのを防ぐ |
| `num_leaves` | 31 | 1本の木の葉の数 | 既定値のまま |
| `min_child_samples` | 300 | 1枚の葉に入るサンプルの最小数 | 手本（100）より大きくする。当たりの組は少なく、1レースに似た組が何百もあるので、少数の当たりに合わせた分かれ道を作らせない |
| `colsample_bytree` | 0.5 | 木を1本作るごとに、特徴量の半分を選んで使う | 市場の確率どうしのように、よく似た特徴量が多い。1つの特徴量だけに頼らせない |
| `subsample` / `subsample_freq` | 0.7 / 1 | 木を1本作るごとに、サンプルの 7割を選んで使う | 過学習を抑える |
| `reg_lambda` | 20 | 葉の値を大きくしすぎないように抑える強さ | 既定値（0）より強くする。市場の確率からの上げ下げを、少ない例で大きく動かさない |
| `max_bin` | 127 | 数値特徴量を区切る数の上限 | 既定値（255）の半分にする。行が多い（3連単は学習データだけで数百万行）ので、速さとメモリを優先する |
| `random_state` | 0 | 乱数の種 | 同じ学習データから同じモデルができるようにする |
| `n_jobs` | 3 | 使うスレッドの数 | 結果ではなく、速さと PC の空きのための設定 |

- 値は、下調べで使ったものである。調整のやり方は手本と同じで、設定ファイルを変えて学習し、検証の期間を変えて比べる（[手本の 16 の「5. ハイパーパラメータの調整のやり方」](../近走と適性から3着以内を予想/16-evaluation.md#5-ハイパーパラメータの調整のやり方)）。
- 1 と 0 の数の偏りを直す設定（`is_unbalance`・`class_weight`）は使わない（[10-target.md](10-target.md#1-と-0-の数の偏り)）。

## 3. カテゴリ特徴量の値の変え方（フローチャート）

カテゴリ特徴量が無いので、この手順は働かない。共有の `LightGbmEncoder` は、数値の列をそのまま通す。設定の `min_category_count`（出走の少ないカテゴリの値を「その他」にまとめる線）は、共有の設定の形に合わせて初期値のファイルに書くが、この予想では何も変えない。

## 4. 学習のやりとり（シーケンス図）

券種ごとの学習の流れは [05-sequence.md の図2](05-sequence.md#図2-学習) を参照。`LightGbmModel` の中のやりとり（エンコーダー → `LGBMClassifier.fit()`）は [手本の 12 の「4.」](../近走と適性から3着以内を予想/12-lightgbm.md#4-学習のやりとりシーケンス図) と同じで、違うのは `fit()` に出発点と重みを渡すことだけである（上の 1）。5つの券種ごとに1回ずつ、計5回この流れを行う。

## 5. 予測のやりとり（シーケンス図）

1レースの予測の流れは [05-sequence.md の図4](05-sequence.md#図4-1レースの予測と買い目) を参照。`LightGbmModel` は、木の出した値（上げ下げ）に、予測用データの出発点（その組の市場の確率のロジット）を足して、確率に戻す。出発点を使って学んだモデルに、出発点の無いデータを渡すと、誤りにして止まる（共有の `BaselineCheck`）。

## 6. 保存

| モデル | 置き場所 |
|---|---|
| 券種ごとの LightGBM | `reports/高配当の組が当たるかを予想/models/<券種の英名>/race_day/lightgbm.joblib`（券種の英名は `wide`・`quinella`・`exacta`・`trio`・`trifecta`） |

- 読み書きは `TicketModelRepository` が行う。1つの券種のフォルダの中は、共有の `ModelRepository` と同じ形（時点のフォルダ `race_day` の下に、モデルごとのファイルと設定）である。この予想の時点は当日の1つだけなので、フォルダも `race_day` の1つだけになる。
- ファイルの形は手本と同じ（[手本の 12 の「6. 保存」](../近走と適性から3着以内を予想/12-lightgbm.md#6-保存)）。出発点を使って学んだかも一緒に保存する。
- 使った設定は、同じフォルダの `settings.json` に一緒に保存する（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)）。
- 置き場所は Git の対象外。モデルは JV-Data から作ったもので、公開しないため。
