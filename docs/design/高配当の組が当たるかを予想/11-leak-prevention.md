# 11 リークを防ぐ決まり

**この文書で決めること:** 学習では当たるのに本番では当たらないモデル（リーク）にならないよう、特徴量を作るときと、確かめるときに守る決まり。

**結論: 特徴量は、発走前に分かるもの（オッズ・馬ごとの予想・印）だけから作る。馬ごとの予想は、学習に使っていない期間の予測だけを使う。払戻と着順は、目的変数と評価にだけ使う。確かめは確定オッズで行い、本番は締め切り前のオッズになることを前提にする。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。この予想は、近走や調教の特徴量を自分では作らない。それらを作るときの決まり（開催日より前のものだけから計算する、マスタの累計を使わない）は、馬ごとの予想の側が守る（[手本の 11 の「決まり」](../近走と適性から3着以内を予想/11-leak-prevention.md#決まり)）。

## 決まり

**1. 馬ごとの予想は、学習に使っていない期間の予測だけを使う。**

過去のレースの馬ごとの確率は、そのレースを学習に使っていないモデルが出したもの（前の期間だけで学んで次の期間を予測したもの）にする。学習に使ったレースの予測は、結果を知ったうえでの予測なので、実際より当たって見える。それを特徴量にすると、この予想は「馬ごとの予想はよく当たる」と学び、本番で外れる。印・危険な人気馬の判定・期待値も、その予測から、本番と同じ決め方で付け直す（[08-training-data.md](08-training-data.md#5-馬ごとの予想の出どころ)）。

**2. そのレースの結果は特徴量にしない。**

払戻・着順・当たった組は、目的変数（当たったか）と評価（払戻）にだけ使う。組の表では、目的変数と評価用の列を、特徴量とは別の種類の列として持つ（[08-training-data.md](08-training-data.md#2-列の種類)）。

**3. 確定オッズは、結果ではなく「締め切り時点の市場の見方」なので、特徴量と出発点に使ってよい。ただし、本番では締め切り前のオッズになる。**

- 学習と年ごとの確かめは確定オッズ、本番の予測は締め切り前（発走の約10分前）のオッズで、値がずれる。ほかの買い方の検証と同じ前提である（[買うレースと買い目を決める の 08 の 4](../買うレースと買い目を決める/08-bankroll-and-review.md#4-実際に買い始める前の確かめフォワードテストはしない)）。
- ワイド・馬単・3連複・3連単は、締め切り前のオッズの過去の分がさかのぼって取れない。そのため、確定オッズで確かめ、ずれの大きさは、締め切り前のオッズの記録がある期間と、買い目の記録で見る（[16-evaluation.md](16-evaluation.md#7-気をつけること)）。
- 過去のレースの馬ごとの表（単勝・複勝のオッズ、単勝人気、印、危険な人気馬の判定、期待値）も、確定オッズで作る。本番では、当日の予想が締め切り前のオッズで作る。単勝人気は、どちらも「そのときの単勝オッズの小さい順」である。

**4. 学習データと予測用データは、同じクラスで作る。**

特徴量を作るクラスは、オッズの板と馬ごとの表を引数で受け取り、板の出どころ（確定か締め切り前か）を知らない。組の表づくり（学習）と1レースの予測（本番）が、同じクラスを呼ぶ（[04-classes.md](04-classes.md)）。

**5. 年ごとの確かめでは、テストの年より前の年だけで学ぶ。**

テストの年の2年前までで学習し、直前の年で早期終了し、テストの年を予測する。テストの年の行は、学習にも早期終了にも使わない（[16-evaluation.md](16-evaluation.md#4-年ごとの確かめ)）。

**6. 期待値の線は全券種で同じにし、結果を見て券種ごとに選ばない。成績は、探す期間と確かめる期間に分けて並べ、片方だけで良い決まりを採らない。**

結果を見て券種ごとに線を選ぶと、探した期間に合わせすぎて、次の年に同じ成績にならない（[15-decisions.md の 10](15-decisions.md#10-期待値の線)）。採用の基準は [16-evaluation.md](16-evaluation.md#5-採用の基準) を参照。
