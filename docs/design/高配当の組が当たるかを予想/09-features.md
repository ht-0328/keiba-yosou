# 09 特徴量

**この文書で決めること:** 組が当たる確率の手がかり（特徴量）に、何を使うか。使うデータの期間。使わない特徴量。

**結論: 特徴量は6つのまとまり（A〜F）で、どれも数値である。市場（その券種・3連単・ほかの券種・単勝）から見た組の確率と、馬ごとの予想から見た組の確率、組の1頭ずつの材料、組のまとめ、レースの材料を使う。数は券種で違い、ワイド 80個・馬連 81個・馬単 81個・3連複 99個・3連単 102個である。近走・適性・調教・血統の特徴量は作らず、馬ごとの予想を通して使う。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。特徴量の一覧は、コードでは券種ごとの `CATALOGS`（`src/yosou/high_payout_combos/feature/feature_catalog.py`）にある。

## 表の見方

- 「特徴量」は列の名前である。組の位置ごとに作るもの（まとまり D）は、名前の後ろに位置（0 始まり）を付ける（`p30`・`p31`・`p32`）。
- 「例」は、[01-overview.md の「1つの組の例」](01-overview.md#1つの組の例) と同じ架空の組（16頭立てのワイド 5-12、最低オッズ 24.0倍）の値である。
- log は自然対数。確率の対数を取るときは、0 にならないように小さい値（1e-9。Harville の式で出した確率は 1e-12）を下限にする。
- 「どこから」の「馬ごとの表」は [08-training-data.md の 5](08-training-data.md#5-馬ごとの予想の出どころ)、「板」はオッズの板である。
- 型は、どれも数値特徴量である。板に無くて作れない値は欠損値のまま持つ。

## A. その券種の市場

その券種を買う人たちと、3連単を買う人たちが、この組をどう見ているか。作るクラスは `OwnMarketFeatures`。

| 特徴量 | 意味 | 例 | どこから |
|---|---|---|---|
| `log_odds` | オッズの対数 | log(24.0) = 3.18 | その券種の板 |
| `log_q` | 市場の確率 q の対数。q = 1 ÷ オッズ を、レースのその券種の全部の組で合計 1（ワイドは 3）にそろえた値 | log(0.032) = −3.44 | その券種の板（共有の `ComboBlendFeatures`） |
| `log_t` | 3連単から足し合わせた確率 t の対数。3連単の市場の確率を、その組が当たりになる並びの全部で足した値 | log(0.035) = −3.35 | 3連単の板（共有の `TrifectaSources`・`PoolFolding`） |
| `d_t` | `log_t` − `log_q`。3連単の人たちが、その券種の人たちより、この組を高く見ているか | +0.09 | 上の2つ |

## B. ほかの券種の市場

その組に含まれる2頭・3頭の組を、ほかの券種の市場がどう見ているか。値は、ほかの券種での市場の確率 q の対数である。ほかの券種の板に、その組が無ければ欠損値にする。券種ごとに作る列が違う。作るクラスは `CrossMarketFeatures`。

| 券種 | 特徴量 | 意味 | 例（ワイド 5-12） |
|---|---|---|---|
| ワイド a-b | `x_exa` | 馬単 a→b と b→a の市場の確率の和の対数 | log(0.011) = −4.51 |
| | `x_quin`・`d_quin` | 馬連 a-b の市場の確率の対数と、`log_q` との差 | −4.51、−1.07 |
| 馬連 a-b | `x_exa`・`d_exa` | 馬単の両方の並びの市場の確率の和の対数と、`log_q` との差 | ― |
| | `x_wide`・`d_wide` | ワイド a-b の市場の確率の対数と、`log_q` との差 | ― |
| 馬単 a→b | `x_quin`・`d_quin` | 馬連 a-b の市場の確率の対数と、`log_q` との差 | ― |
| | `x_wide` | ワイド a-b の市場の確率の対数 | ― |
| | `x_rev` | 逆の並び（馬単 b→a）の市場の確率の対数 | ― |
| 3連複 a-b-c | `x_wide` | ワイド ab・ac・bc の市場の確率の対数の和 | ― |
| | `x_quin` | 馬連 ab・ac・bc の市場の確率の対数の和 | ― |
| 3連単 a→b→c | `x_trio`・`d_trio` | 3連複 a-b-c の市場の確率の対数と、`log_q` との差 | ― |
| | `x_exa` | 馬単 a→b の市場の確率の対数 | ― |
| | `x_quin` | 馬連 a-b の市場の確率の対数 | ― |
| | `x_wide` | ワイド ab・ac・bc の市場の確率の対数の和 | ― |

このまとまりを作るのに板が要る券種は、ワイドは馬単・馬連、馬連は馬単・ワイド、馬単は馬連・ワイド、3連複はワイド・馬連、3連単は3連複・馬単・馬連・ワイドである。板が足りないときの扱いは [06-flowchart.md](06-flowchart.md#図2-板が足りない券種の扱い) を参照。

## C. Harville の式で出した確率

馬ごとの1着の確率をレースで合計 1 にそろえ、Harville の式で組の確率を組み立てる。馬単 a→b は「a が1着の確率 × 残りの馬の中で b が1着の確率」、3連単はさらに3着を掛ける。馬連・3連複は全部の並びの和、ワイド a-b は「a と b がどちらも3着以内」で、3頭目を全部の馬で足した3連複の確率の和である。レースの中で合計をそろえ直さない。作るクラスは `HarvilleFeatures`（式そのものは `HarvilleProbability`・`WidePairProbability`）。

| 特徴量 | 意味 | 例 | どこから |
|---|---|---|---|
| `log_hv` | 馬ごとの予想の1着の確率から出した組の確率の対数 | log(0.050) = −3.00 | 馬ごとの表 |
| `d_hv` | `log_hv` − `log_q`。予想が、その券種の市場より、この組を高く見ているか | +0.45 | A・C |
| `log_hw` | 単勝の市場（オッズから見た勝率）から、同じ式で出した組の確率の対数 | log(0.036) = −3.32 | 馬ごとの表 |
| `d_hw` | `log_hw` − `log_q`。単勝の人たちの見方に直すと、その券種の市場より高いか | +0.12 | A・C |

## D. 組の位置ごとの馬の材料

組の1頭ずつに、次の 20個を作る。2頭の券種は 40個、3頭の券種は 60個になる。作るクラスは `PositionHorseFeatures`（馬ごとの材料そのものは `HorseMaterials`）。

**組の中の並び。** 着順を区別する券種（馬単・3連単）は、組の並び（1着 → 2着 → 3着）のままにする。順不同の券種（ワイド・馬連・3連複）は、単勝人気の小さい順に並べ替える（同じ人気なら、組番の並び）。順不同の券種を馬番の順のままにすると、同じ位置に人気馬も人気薄も入り、位置ごとの列が意味を持たなくなるためである。並べ替えは `ComboMembers` が行う。

例は、位置 0 が 5番の馬（3番人気）、位置 1 が 12番の馬（9番人気）である。

| 特徴量 | 意味 | 例（位置 0、位置 1） | どこから |
|---|---|---|---|
| `pw` | 1着になる確率（1着の予想） | 0.15、0.03 | 馬ごとの表 |
| `p3` | 3着以内に入る確率（近走と適性から3着以内を予想） | 0.40、0.21 | 馬ごとの表 |
| `mw` | オッズから見た勝率（単勝の市場の見立て） | 0.13、0.028 | 馬ごとの表 |
| `m3` | オッズから見た3着以内率（単勝の市場の見立て） | 0.37、0.12 | 馬ごとの表 |
| `pm` | 複勝オッズから見た3着以内率 | 0.38、0.14 | 馬ごとの表の複勝オッズ（`PlaceMarketRate`） |
| `e3` | `p3` − `pm`。複勝オッズより来ると見る度合い | +0.02、+0.07 | 上の2つ |
| `r3` | log(`p3` ÷ `m3`)。3着以内の予想と市場の比 | 0.08、0.56 | 上の列 |
| `rw` | log(`pw` ÷ `mw`)。1着の予想と市場の比 | 0.14、0.07 | 上の列 |
| `rpm` | log(`p3` ÷ `pm`)。3着以内の予想と複勝の市場の比 | 0.05、0.41 | 上の列 |
| `lwo` | 単勝オッズの対数（1倍未満は 1倍として） | 1.79、3.33 | 馬ごとの表 |
| `lpo` | 複勝の最低と最高の真ん中のオッズの対数（1倍未満は 1倍として） | 0.79、1.79 | 馬ごとの表 |
| `pop` | 単勝人気 | 3、9 | 馬ごとの表 |
| `rk` | 3着以内の確率のレース内順位 | 2、7 | 馬ごとの表 |
| `dg` | 危険な人気馬（消）なら 1、ほかは 0 | 0、0 | 馬ごとの表 |
| `ds` | 危険度（人気馬の予想の4着以下の確率 − 市場から見た4着以下の確率）。値の無い馬は 0 | 0.01、0 | 馬ごとの表 |
| `psup` | 3連単の支持。3連単の板から見た勝率（その馬が1着の3連単の組の市場の確率の合計）÷ `mw` | 1.05、0.90 | 3連単の板（`TrifectaPoolWin`）と馬ごとの表 |
| `mk` | 印の番号。◎ 0・○ 1・▲ 2・△ 3・☆ 4・注 5・無印 6・消 7 | 1（○）、4（☆） | 馬ごとの表 |
| `updown` | 上げ下げ。3着以内の確率のロジット − 市場の見立てのロジット | 0.13、0.67 | 馬ごとの表 |
| `wv` | 単勝の期待値（1着になる確率 × 単勝オッズ） | 0.90、0.84 | 馬ごとの表 |
| `pv` | 複勝の期待値 | 0.92、1.20 | 馬ごとの表 |

印の番号は、番号の大小に「◎ に近いほど小さい、消がいちばん大きい」という並びの意味があるので、数値特徴量として渡す。

## E. 組のまとめ

組の馬（2頭か3頭）の材料の、和・最小・最大・数。作るクラスは `ComboSummaryFeatures`。

| 特徴量 | 意味 | 例 |
|---|---|---|
| `s_e3`・`min_e3`・`max_e3` | 組の馬の `e3` の和・最小・最大 | 0.09、0.02、0.07 |
| `s_r3`・`s_rw`・`s_rpm` | 組の馬の `r3`・`rw`・`rpm` の和 | 0.64、0.21、0.46 |
| `s_pop`・`max_pop`・`min_pop` | 組の馬の単勝人気の和・最大・最小 | 12、9、3 |
| `n_ls_in` | 組の馬のうち、6番人気以下で `e3` が 0.05 以上の馬（複勝オッズより来ると見る穴馬）の数 | 1（12番の馬） |
| `n_dg_in` | 組の馬のうち、危険な人気馬の数 | 0 |
| `s_lp3` | 組の馬の log(`p3`) の和 | −2.48 |
| `s_lpm` | 組の馬の log(`pm`) の和 | −2.93 |
| `log_ratio` | 予想と市場の比の対数の和。着順を区別する券種は、1頭目の `rw` ＋ 2頭目以降の `r3`。順不同の券種は `s_r3` と同じ | 0.64 |

「6番人気以下で `e3` が 0.05 以上」の線は、`longshot_rule.py` の1か所に置く。6番人気以下の複勝の買い方と同じ線である（[買うレースと買い目を決める の 08 の 2](../買うレースと買い目を決める/08-bankroll-and-review.md#採用している券種当日の予想の6番人気以下の複勝)）。

## F. レースの材料

レースの全部の組に同じ値が入る（`fav_out_dg` を除く）。作るクラスは `RaceFeatures`（レースごとの値は `RaceMaterials`）と `RegionFeatures`。

| 特徴量 | 意味 | 例 | どこから |
|---|---|---|---|
| `field` | 頭数（馬ごとの表の、そのレースの行数） | 16 | 馬ごとの表 |
| `fav_odds` | 1番人気の単勝オッズ（単勝オッズの最小） | 3.2 | 馬ごとの表 |
| `ent` | 人気の割れ方。−Σ `mw` × log(`mw`)。大きいほど、勝率が多くの馬に散っている | 2.35 | 馬ごとの表 |
| `n_dg` | 危険な人気馬の数 | 1 | 馬ごとの表 |
| `max_wv` | 単勝の期待値の最大 | 1.12 | 馬ごとの表 |
| `s3` | オッズから見た勝率の、上位3頭の和 | 0.52 | 馬ごとの表 |
| `n_ls` | 6番人気以下で `e3` が 0.05 以上の馬の数 | 2 | 馬ごとの表 |
| `fav_dg`・`fav_e3`・`fav_rw` | 1番人気の馬の `dg`・`e3`・`rw` | 1、−0.06、−0.15 | 馬ごとの表 |
| `exp_high` | ◎ の単勝の期待値が 1.0 以上なら 1、ほかは 0 | 1 | 馬ごとの表 |
| `reg_q` | その券種の組のうち、オッズが学ぶ下限以上の組（上限は見ない）の市場の確率の合計 | 2.1 | その券種の板 |
| `reg_n` | その券種の組のうち、オッズが学ぶ下限以上の組の数 | 108 | その券種の板 |
| `reg_hv` | 対象の組（学ぶ下限以上・上限未満）の、予想の Harville の確率の合計 | 2.2 | C |
| `fav_out_dg` | 1番人気が危険な人気馬で、組に1番人気を含まなければ 1 | 1 | D・F |

## カテゴリ特徴量の渡し方

カテゴリ特徴量は無い。全部を数値特徴量として渡す（[12-lightgbm.md](12-lightgbm.md#1-学習データの渡し方)・[13-catboost.md](13-catboost.md#1-学習データの渡し方)）。

## 使わない特徴量

| 使わないもの | 理由 |
|---|---|
| 払戻・着順などの、そのレースの結果 | リークになる。目的変数と評価にだけ使う（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 2） |
| LightGBM と CatBoost の2つの馬ごとの予想の確率の差、2つがそろって高く見ているか | 入れても当たり具合が変わらず、本番の印を付けた表から取りにくい（[15-decisions.md の 9](15-decisions.md#9-外した材料)） |
| レースの種類（芝かダートか・クラス・ハンデ戦か） | 同じ理由（[15-decisions.md の 9](15-decisions.md#9-外した材料)） |
| 近走・適性・調教・血統・騎手などの特徴量そのもの | 馬ごとの予想がすでに使っている。この予想は、その結果（確率と印）を受け取る |
