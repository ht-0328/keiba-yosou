# 07 いつ予測するか

**この文書で決めること:** 予測をいつ行うか。その時点でどの特徴量を使うか。予測のとき、オッズをどこから取るか。

**結論: 予測は当日だけに出す。締め切り前の5券種のオッズの板がそろったあと（買い目を決める発走の約10分前）である。木曜・前日は出さない。モデルは時点ごとに分けず、券種ごとに1組（LightGBM と CatBoost）だけを持つ。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 時点ごとに分かること

時点の区切り（木曜・前日・当日）と、それぞれで分かることは [手本の 07 の「時点ごとに分かること」](../近走と適性から3着以内を予想/07-prediction-timing.md#時点ごとに分かること) を参照。この予想に要るものが、いつ分かるかは次のとおり。

| 要るもの | 木曜 | 前日 | 当日（発走の約10分前） |
|---|---|---|---|
| 馬ごとの予想（3着以内の確率・1着の確率） | ある | ある | ある（当日の予想） |
| 単勝・複勝のオッズ、人気、印、危険な人気馬の判定 | 無い | 前日のオッズで出せる | ある |
| ワイド・馬連・馬単・3連複・3連単のオッズの板 | 無い | そろわない | **ある** |

## 時点ごとに使う特徴量

| 時点 | 使う特徴量 |
|---|---|
| 木曜・前日 | 予測を出さない |
| 当日 | まとまり A〜F の全部（[09-features.md](09-features.md)）。当日の予想の、印を付けた1レースの表（馬ごとの表）と、締め切り前の5券種のオッズの板から作る |

## 予測のときのオッズの与え方

| 場面 | オッズの板 | 馬ごとの表 |
|---|---|---|
| 学習・年ごとの確かめ | 確定オッズ（`FinalOddsRepository`） | 過去のレースの、学習に使っていない期間の予測に、本番と同じ決め方で印・危険な人気馬・期待値を付けたもの（[08-training-data.md](08-training-data.md#5-馬ごとの予想の出どころ)） |
| 本番の予測 | 締め切り前のいちばん新しい断面（`AnnouncedTicketOddsRepository`。jvdata-store が速報のオッズとして取ったもの） | 今週の予想の当日の予想が作る、印を付けた1レースの表 |

- **学習は確定オッズ、予測は締め切り前のオッズで、値がずれる。** 対象の組を選ぶ帯、出発点、期待値のどれも、予測では締め切り前のオッズで決まる。ずれの扱いは [11-leak-prevention.md](11-leak-prevention.md#決まり) の 3 と [16-evaluation.md](16-evaluation.md#7-気をつけること) を参照。
- オッズの板は、予測の入口（`HighPayoutPredictor.predict()`）に引数で渡す。板の出どころ（確定か締め切り前か）は、特徴量を作るクラスからは見えない。学習と予測で同じクラスが特徴量を作る（[04-classes.md](04-classes.md)）。
- 板が足りない券種（締め切り前の3連単の板がまだ無い、など）は、誤りにせず、その券種と、その板が要る特徴量を持つ券種の予測を出さない（[06-flowchart.md](06-flowchart.md#図2-板が足りない券種の扱い)）。

## 当日だけにする理由

- **5券種のオッズの板が要る。** この予想の出発点は、その券種のオッズから見た組の確率で、特徴量の多くも券種どうしのオッズのずれである。ワイド・馬単・3連複・3連単のオッズは、木曜には無く、前日にもそろわない。
- **買うかどうかがオッズで決まる。** 高配当の線以上か、期待値（確率 × オッズ）が線以上かは、買うときのオッズが無いと決められない。
- **馬券を買う時点が発走の約10分前である。** 買い目を決める時刻より前の予測を出しても、使う場面が無い。

## 時点ごとにモデルを分けない理由

手本は、時点ごとに分かる特徴量が違うので、時点ごとに別のモデルを学ぶ。この予想は当日にしか出さないので、分ける時点が無い。代わりに、**券種ごとに別のモデルを学ぶ**。券種で、組の頭数・着順を区別するか・特徴量の列・当たりやすさがどれも違うためである（[12-lightgbm.md](12-lightgbm.md)）。
