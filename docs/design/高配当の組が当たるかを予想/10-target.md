# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。どのオッズの組を対象にするか（オッズの帯）。何を出発点にして学ぶか。

**結論: 目的変数は「その組が当たったら 1、外れたら 0」。対象は、オッズが券種ごとの学ぶ下限以上・上限未満の組で、買うのは高配当の線以上の組だけである。出発点は、その券種のオッズから見た組の確率（市場の確率）のロジットで、モデルはそこからの上げ下げだけを学ぶ。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 作り方

| 目的変数の値 | その組が |
|---|---|
| 1 | 当たった（その券種の払戻に、その組がある） |
| 0 | 外れた（払戻に無い） |

- 払戻は元DB の払戻の表から読む（`PayoutRepository`）。評価用の列の「100円あたりの払戻」は、同じ組が複数行あれば合計し、外れの組は 0 にする。
- **同着。** 同着で当たりの組が増えたレースは、払戻のある組を全部 1 にする。
- **ワイド。** ワイドは1レースに当たりの組が3つある（1〜3着の3頭から2頭を選ぶ組）。3つとも 1 にする。
- **出走取消・競走除外。** 取消の馬を含む組は、確定オッズの板に無いので行にならない。
- 「高配当だったか」は目的変数にしない。当たったかどうかだけを当てさせ、高配当かどうかは、対象の組と買う組をオッズで選ぶことで扱う（下の「オッズの帯」）。

## オッズの帯

券種ごとに、オッズ（ワイドは最低オッズ）で3つの線を引く。

| 券種 | 学ぶ下限 | 高配当の線 | 上限 |
|---|---|---|---|
| ワイド | 3倍 | 10倍 | 300倍 |
| 馬連 | 8倍 | 30倍 | 1,000倍 |
| 馬単 | 15倍 | 60倍 | 3,000倍 |
| 3連複 | 20倍 | 100倍 | 3,000倍 |
| 3連単 | 100倍 | 500倍 | 10,000倍 |

| 線 | 何に使うか | 決め方 |
|---|---|---|
| 学ぶ下限 | このオッズ以上・上限未満の組を、学習データと予測の対象にする | 高配当の線より下まで学ぶと、当たりの例が約2倍に増える（[15-decisions.md の 5](15-decisions.md#5-学ぶ範囲をどこまで広げるか)） |
| 高配当の線 | このオッズ以上・上限未満の組だけを、買い目の候補にする | 3連複の万馬券（100倍以上）が出るのは約3レースに1回である。ほかの券種も「約3レースに1回出る」倍率にそろえた。ワイドだけは、利用者の感覚に合わせて少し低い 10倍にした（[15-decisions.md の 1](15-decisions.md#1-高配当の線をどこに引くか)） |
| 上限 | このオッズ以上の組は、学習データにも買い目にも入れない | それより上は、当たりの例が極端に少なく、市場のオッズどおりに買っても回収率が極端に低い帯で、確率を見積もれない |

線は、1つの帯を表す不変の値（`PayoutBand`）と、5券種の既定の帯（`DEFAULT_BANDS`）としてコードの1か所に置く（[04-classes.md](04-classes.md#2-この予想だけのクラス)）。

## 出発点（基準）

**モデルは、市場の確率 q を出発点にして、そこからの上げ下げだけを学ぶ。**

- 出発点 = logit(q) = log(q ÷ (1 − q))。q は 1e-9 以上・0.999 以下に収めてから計算する。
- モデルの確率 = 出発点に、特徴量から学んだ上げ下げを足して、確率に戻した値。
- 例（架空）: q = 0.032 なら出発点は −3.41。上げ下げが +0.40 なら −3.01 で、確率は 0.047 になる。

| 理由 | 説明 |
|---|---|
| オッズは、組が当たる確率のいちばん強い手がかりである | 市場の確率から始めれば、モデルは「市場がどこで間違えるか」だけを学べばよい |
| 出発点を置かないと、確率を大きく見積もりすぎる | 出発点を置かない作りでは、期待値の高い組を選んでも回収率が上がらなかった（[15-decisions.md の 2](15-decisions.md#2-出発点を何にするか)） |
| 手本の予想と同じ考え方である | 手本は、単勝オッズから見た確率を出発点にして学ぶ（[買うレースと買い目を決める の 07 の 1](../買うレースと買い目を決める/07-expected-value.md#1-確率の作り方)）。この予想は、単勝の代わりにその券種のオッズを使う |

出発点の渡し方は [12-lightgbm.md](12-lightgbm.md#1-学習データの渡し方)・[13-catboost.md](13-catboost.md#1-学習データの渡し方) を参照。

## 理由

- **「当たったか」を当てさせる理由。** 買い目は、期待値（確率 × オッズ）で選ぶ。オッズは買うときに分かるので、モデルが出すのは確率だけでよい。確率が正しければ、どのオッズの組にも同じ決まり（期待値の線）を当てられる。
- **「高配当の組が当たったか」を別の目的変数にしない理由。** 高配当の線以上の当たりだけを 1 にすると、線のすぐ下の当たりの組（線以上の組とよく似た組）を外れとして学んでしまう。対象の組を学ぶ下限まで広げ、同じ目的変数で学ぶほうが、当たりの例が増える。
- **券種ごとに別のモデルにする理由。** [07-prediction-timing.md](07-prediction-timing.md#時点ごとにモデルを分けない理由) を参照。

## 1 と 0 の数の偏り

対象の組のうち、当たりは1レースに1つ（ワイドは最大3つ）だけで、外れは数十〜数千ある。偏りは手本よりずっと大きい。

- 偏りを直す設定（LightGBM の `is_unbalance`・`class_weight`、CatBoost の `auto_class_weights`）は使わない。使うと、確率が実際より高く出て、期待値に使えなくなる。
- 外れの組を間引くときは、残した外れの組に割合の逆数の重みを付けて、間引く前と同じ割合に戻す（[08-training-data.md](08-training-data.md#4-外れの組の間引きと行の重み)）。偏りを直すための重みではない。
- 出発点が市場の確率なので、モデルは「どの組もめったに当たらない」ことを最初から知っている。偏りが大きくても、学ぶのは市場との差だけである。
