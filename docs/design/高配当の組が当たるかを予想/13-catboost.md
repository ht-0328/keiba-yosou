# 13 CatBoost で学習・予測するための設計

**この文書で決めること:** 07〜10 で決めた学習データ（特徴量と目的変数）は、LightGBM と CatBoost に共通である。この文書では、それを CatBoost で学習・予測するために、CatBoost だけに必要な次の3つを決める。**節の番号と題名は、手本の 13 とそろえてある。**

| 決めること | 結論 |
|---|---|
| 1. 学習データの渡し方 | 特徴量は全部を数値のまま渡す。`cat_features` は使わない。市場の確率のロジットを `Pool` の `baseline`、行の重みを `Pool` の `weight` として渡す |
| 2. ハイパーパラメータの初期値 | 目的関数は二値分類（`Logloss`）。木の数は早期終了で決める。手本より、少ない当たりの組に合わせすぎない向きの値にする |
| 3. 学習・予測・保存の手順 | 券種ごとに1つずつ、計5つのモデルを学習する。学習したらモデルを保存し、予測のときはその券種のものを読み込む（4.〜6.） |

- 用語の意味は [02-glossary.md](02-glossary.md) を参照。
- 学習データ・特徴量・目的変数は LightGBM と共通で、[08-training-data.md](08-training-data.md)・[09-features.md](09-features.md)・[10-target.md](10-target.md) を参照。この文書には、CatBoost だけに関わることを書く。
- LightGBM の設計は [12-lightgbm.md](12-lightgbm.md) を参照。
- CatBoost の使い方の基本は [03-library-basics.md](03-library-basics.md) を参照。

## 1. 学習データの渡し方

学習と予測は、共有の `CatBoostModel`（`src/yosou/shared/ml_model/`）が行う。

| 列 | 渡し方 | 理由 |
|---|---|---|
| 数値特徴量（全部） | そのまま渡す。欠損値も NaN のまま | CatBoost は、数値の欠損値を「どの値よりも小さい値」として扱う |
| カテゴリ特徴量 | 無い。`cat_features` は空 | [09-features.md](09-features.md#カテゴリ特徴量の渡し方) |
| 出発点（市場の確率のロジット） | 学習データと検証データの `Pool(baseline=出発点)` | 市場の確率からの上げ下げだけを学ばせる（[10-target.md](10-target.md#出発点基準)） |
| 行の重み | 学習データと検証データの `Pool(weight=重み)` | [12-lightgbm.md の 1](12-lightgbm.md#1-学習データの渡し方) と同じ理由 |
| ID 列・評価用の列 | 渡さない | [08-training-data.md](08-training-data.md#2-列の種類) |

## 2. ハイパーパラメータの初期値

`catboost.CatBoostClassifier` の引数名で書く。ここの値は設定ファイルの初期値で、プログラムを書き換えずに設定ファイルで変えられる（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)）。5券種とも同じ値で学ぶ。

| 引数 | 初期値 | 意味 | 理由 |
|---|---|---|---|
| `loss_function` | `Logloss` | 目的関数。二値分類 | 組が当たる確率を返すようにする |
| `learning_rate` | 0.05 | 学習率 | 手本と同じ |
| `iterations` | 3000 | 木の数の上限 | 実際の数は早期終了で決まる |
| `early_stopping_rounds` | 100 | 検証データの当たり具合が、木を 100 本足しても良くならなければ止める | 木を増やしすぎて過学習するのを防ぐ |
| `depth` | 6 | 木の深さ | 既定値のまま |
| `l2_leaf_reg` | 10 | 葉の値を大きくしすぎないように抑える強さ | 手本（3）より強くする。市場の確率からの上げ下げを、少ない例で大きく動かさない |
| `rsm` | 0.5 | 分かれ道を作るごとに、特徴量の半分を選んで使う | よく似た特徴量が多いので、1つの特徴量だけに頼らせない |
| `border_count` | 128 | 数値特徴量を区切る数 | 行が多いので、速さとメモリを優先する |
| `bootstrap_type` / `subsample` | `Bernoulli` / 0.7 | 木を1本作るごとに、サンプルの 7割を選んで使う | 過学習を抑える。`Bernoulli` は、サンプルを1つずつ同じ割合のくじで選ぶ選び方 |
| `random_seed` | 0 | 乱数の種 | 同じ学習データから同じモデルができるようにする |
| `thread_count` | 3 | 使うスレッドの数 | 結果ではなく、速さと PC の空きのための設定 |

- 値は、下調べで使ったものである。調整のやり方は [12-lightgbm.md の 2](12-lightgbm.md#2-ハイパーパラメータの初期値) と同じ。
- 1 と 0 の数の偏りを直す設定（`auto_class_weights`）は使わない（[10-target.md](10-target.md#1-と-0-の数の偏り)）。

## 3. カテゴリ特徴量の値の変え方（フローチャート）

カテゴリ特徴量が無いので、この手順は働かない。共有の `CatBoostEncoder` は、数値の列をそのまま通す。
