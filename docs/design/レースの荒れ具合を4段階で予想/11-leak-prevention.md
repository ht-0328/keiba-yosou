# 11 リークを防ぐ決まり

**この文書で決めること:** 学習では当たるのに本番では当たらないモデル（リーク）にならないよう、特徴量を作るときと、レースを選ぶときに守る決まり。

**結論: 特徴量は、予測する時点（木曜・前日・当日。[07-prediction-timing.md](07-prediction-timing.md)）で分かることだけから作る。手本の決まり 1〜5 をそのまま守り、この予想では、払戻と結果の列・過去の荒れ率・全頭のオッズ・1番人気・出走頭数についての決まり（6〜10）を足す。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 決まり

1〜5 は手本と同じで、[手本の 11 の「決まり」](../近走と適性から3着以内を予想/11-leak-prevention.md#決まり) を参照する（そのレースの結果を使わない、過去走から作る特徴量は開催日より前のものだけから計算する、マスタの累計の成績を使わない、学習データと予測用データを同じプログラムで作る、確定オッズは特徴量に使ってよいが予測では締め切り前のオッズになる）。この予想では、6〜10 を足す。

**6. 払戻と、払戻から分かることは、目的変数と評価用の列にだけ使う。**

- 4券種の払戻、払戻の人気順、勝ち馬の人気、1〜3着の人気の和、1番人気の確定着順は、そのレースの結果である。特徴量にはしない（[08-training-data.md](08-training-data.md#2-列の種類)）。
- 「利用者の規則に当てはまるか」は、オッズだけから決まる値なので結果ではないが、特徴量にせず評価の基準に使う（[15-decisions.md](15-decisions.md#9-利用者の規則を特徴量に入れるか)）。

**7. 過去の同条件の荒れ率（E）は、開催日の前日までのレースだけから数える。**

- 同じ日の先に終わったレースも数えない。学習データでは、同じ日のレースの払戻がすでに DB にあるが、予測のときは無いためである。
- 数える窓は前日までの 365日で、共通の `AsOfLookup`（`days_before=1`）で守る（決まり 2 と同じ仕組み。[04-classes.md](04-classes.md#2-共通の部品に足すもの変えるもの)）。
- 荒れ具合の線引きは目的変数と同じ `UpsetLevelRule` で決める。線引きを変えたら、E も一緒に変わる。

**8. 前日・当日の予測では、全頭の単勝オッズが要る。1頭でも無ければ止める。**

- まとまり B（10倍未満の頭数、市場勝率の合計など）は全頭のオッズから作る。欠けた馬がいると、値が学習データとは違う意味になる。
- 学習は確定オッズ、予測は締め切り前のオッズか利用者が渡したオッズで、値が少しずれる（決まり 5）。当日の締め切り直前に出し直すと、ずれは小さくなる。

**9. 1番人気は、その時点の単勝オッズが最小の馬とし、確定人気は使わない。**

- 学習では確定オッズの最小、予測では締め切り前のオッズか渡されたオッズの最小で決める。学習と予測で「そのときのオッズの最小」という同じ作り方になる。
- まとまり D の値（1番人気の前走の着順、近5走の平均着順など）は、その馬の前走までの値である（決まり 2）。今回のレースの確定着順・確定人気は使わない。

**10. 出走頭数は、学習では確定の出走頭数、予測ではその時点で取消・除外になっていない頭数を使う。**

- 木曜の頭数は出走馬名表の頭数で、前日までに変わることが多い。頭数が変わると、オッズの形も荒れ具合の見込みも変わるので、前日・当日に出し直す。
- 発売の無い券種（少頭数）は、学習では目的変数が欠損値になり、その券種のモデルの学習から外れる（[10-target.md](10-target.md#作り方)）。予測では、頭数が少なくても4券種の確率を出す（発売が無ければ、利用者がその券種を見なければよい）。
