# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想に出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語（特徴量・目的変数・リーク・過学習・早期終了など）と、競馬とこの設計の用語（ID 列・評価用の列・確定オッズ・締め切り前のオッズ・オッズから見た勝率・ウォームアップ期間・事実表）は、手本と同じものをそのまま使う。この予想で増えるのは、多クラス分類に関する用語と、荒れ具合・券種・払戻・レース単位の特徴量に関する用語である。

- 機械学習の用語は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。「二値分類」「予測確率」「目的関数」の3つは、この予想では多クラス分類のものに置き換わる（下の表）。
- 競馬とこの設計の用語は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。

## この予想で増える用語（機械学習）

| 用語 | 意味 | この設計では |
|---|---|---|
| 多クラス分類 | 当てたい値が3通り以上ある問題。二値分類（1 か 0）の代わりに使う | 固い・中荒れ・大荒れ・超荒れの4通り。クラスの番号は 0〜3 |
| クラス | 多クラス分類で当てたい値の1つ | 「大荒れ」はクラス 2 |
| 予測確率（多クラス） | `model.predict_proba(X)` が返す、クラスごとの確率の並び。合計は 1 | 1レースにつき4つ（[03-library-basics.md](03-library-basics.md#この予想で違う点)） |
| いちばん高いクラス | 4つの確率のうち、いちばん大きいクラス | 出力の表の列（[01-overview.md](01-overview.md#1レースの例)） |
| 累積確率 | 順序のあるクラスで、「あるクラス以上」の確率を足し合わせた値 | 中荒れ以上の確率 = 中荒れ + 大荒れ + 超荒れ |
| 目的関数（多クラス） | 多クラス分類用の目的関数 | LightGBM は `multiclass`、CatBoost は `MultiClass`（[12-lightgbm.md](12-lightgbm.md#2-ハイパーパラメータの初期値)・[13-catboost.md](13-catboost.md#2-ハイパーパラメータの初期値)） |
| マクロ F1 | クラスごとの F1（当てた割合と拾えた割合の調和平均）を、クラスの数で平均した値。少ないクラスも同じ重みで見る | 評価指標の1つ（[16-evaluation.md](16-evaluation.md#2-評価指標)） |
| 混同行列 | 予測したクラス × 実際のクラス の件数の表 | 4 × 4 の表 |
| 集約 | 何行かの値を、1つの値にまとめること（平均・最大・数えるなど） | 出走馬1頭ごとの特徴量を、レースに1つの値にする（[04-classes.md](04-classes.md#1-レース単位の学習データを作る仕組み)） |

## この予想で増える用語（競馬とこの設計）

| 用語 | 意味 | この設計では |
|---|---|---|
| 荒れ具合 | そのレースの払戻がどれだけ高かったかを4段階（固い・中荒れ・大荒れ・超荒れ）に分けたもの。券種ごとに決める | 目的変数。線引きは [10-target.md](10-target.md#券種ごとの線引き) |
| 券種 | 馬券の種類 | 単勝・馬連・3連複・3連単の4つ。`--bet` で指定する |
| 払戻 | 100円の馬券が当たったときに戻ってくる金額（円）。JV-Data の払戻（`hr`）に券種ごとに入る | 荒れ具合を決める値。同着で複数あるときは最大のもの |
| 払戻の人気順 | その払戻の組み合わせ（馬番・組番）が、オッズの上で何番人気だったか。JV-Data の払戻に入る | 結果なので特徴量にしない。評価用の列 |
| 不成立・特払・返還 | 不成立は、その券種が成立しなかったこと。特払は、的中が無く一律に払い戻したこと。返還は、出走取消などで一部の馬券を返したこと。どれも JV-Data の払戻のフラグ | 不成立と特払は、その券種の目的変数を欠損値にする。返還は普通に扱う（[10-target.md](10-target.md#作り方)） |
| 発売の無い券種 | 出走頭数が少なく、その券種が発売されなかったこと | 目的変数を欠損値にする |
| オッズの形 | 締め切り前の単勝オッズから見た、強い馬が抜けているか、有力馬が何頭いるか | まとまり B（[09-features.md](09-features.md#b-オッズの形10個)） |
| 市場勝率 | 手本の「オッズから見た勝率」と同じ。1 ÷ 単勝オッズ を、同じレースの馬で合計 1 にそろえた値 | B の集中度の材料 |
| 1番人気 | その時点の単勝オッズがいちばん小さい馬。学習では確定オッズ、予測では締め切り前のオッズか渡されたオッズで決める | まとまり D の対象（[09-features.md](09-features.md#d-1番人気の危うさ10個)） |
| 過去の荒れ率 | 開催日の前日までの 365日で、同じ条件のレースのうち中荒れ以上だったレースの割合。券種ごと | まとまり E（[09-features.md](09-features.md#e-過去の同条件の荒れ率8個)） |
| 利用者の規則 | 「1番人気が 4.0倍以上で、2〜5番人気の最大オッズが 10倍未満なら荒れる」という利用者の見立て | 特徴量にはせず、評価の基準に使う（[16-evaluation.md](16-evaluation.md#3-比べる基準)） |
| レース単位の特徴量 | 1レースに1つの値を持つ特徴量。1頭ごとの特徴量を集約して作る | この予想の特徴量はすべてこれ |
