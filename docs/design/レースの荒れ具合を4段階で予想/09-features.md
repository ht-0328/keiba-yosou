# 09 特徴量

**この文書で決めること:** 予測の手がかり（特徴量）に、何を使うか。

**結論: レースの前に分かる、レース単位の 49個の特徴量を、5つのまとまり（A〜E）に分けて使う。手本の1頭ごとの特徴量は、そのままでは使わず、レース単位に集約して使う。オッズの形（B）と1番人気の危うさ（D）は前日と当日に使う。マイニング予想・調教・血統は使わない。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 表の見方

- 例の値は、すべて同じ架空の1レースのもの。[01-overview.md](01-overview.md#1レースの例) のレース（2025年5月、東京・芝1600m・良のオープン、16頭立て）である。各表の「例」の列を縦に読むと、1サンプルになる。
- 「型」は、数値特徴量かカテゴリ特徴量かを示す。
- 「どこから」は、1頭ごとの特徴量（[手本の 09](../近走と適性から3着以内を予想/09-features.md) の A〜J）を集約して作るものは「手本の〇（特徴量の名前）を集約」と書き、事実表や JV-Data の表から新しく作るものはその名前を書いた。
- **集約のしかたは、まとまりごとに決める。** A は「レースの1頭目の値をそのまま」、B・C は「全出走馬の値の最大・数・割合・ばらつき」、D は「1番人気の1頭の値」、E は「過去のレースの割合」である。集約するクラスは [04-classes.md](04-classes.md#3-この予想だけのクラスの一覧) を参照。
- 過去走から作る特徴量は、開催日より前のレースだけから計算する。[11-leak-prevention.md](11-leak-prevention.md) を参照。
- 49個は、当日に予測するときの数である。木曜と前日は、その時点で分からない特徴量を使わない（[07-prediction-timing.md の「時点ごとに使う特徴量」](07-prediction-timing.md#時点ごとに使う特徴量)）。

## A. レースの条件（11個）

手本の A（9個）に、特別戦かどうかとハンデ戦かどうかを足したもの。レースの1頭目の値をそのまま使う（同じレースの馬は、みな同じ値だからである）。

| 特徴量 | 意味 | 例 | 型 | どこから |
|---|---|---|---|---|
| 競馬場 | | 東京 | カテゴリ | 手本の A（競馬場） |
| 芝ダ | 芝かダートか | 芝 | カテゴリ | 手本の A（芝ダ） |
| コース | 回りと内外 | 芝・左 | カテゴリ | 手本の A（コース） |
| 距離 | メートル | 1600 | 数値 | 手本の A（距離） |
| 馬場状態 | 良・稍重・重・不良。前日から | 良 | カテゴリ | 手本の A（馬場状態） |
| クラス | 新馬〜G1 を低い順に並べた番号 | オープン | 数値 | 手本の A（クラス） |
| 出走頭数 | 3連単の組み合わせの数を決める。少頭数は固くなりやすい | 16 | 数値 | 手本の A（出走頭数） |
| 開催月 | 季節を表す | 5 | 数値 | 手本の A（開催月） |
| 牡馬と牝馬が一緒に走るか | 牝馬限定戦かどうかの目安 | はい | カテゴリ | 手本の A（牡馬と牝馬が一緒に走るか） |
| 特別戦か | 競走名の付いたレースか。平場より実績のそろった馬が集まる | はい | カテゴリ | 新しく作る（事実表の `race_name` が空でないか） |
| ハンデ戦か | 負担重量をハンデで決めるレースか。実力をならすので荒れやすい | いいえ | カテゴリ | 新しく作る（`ra` の重量種別コード。事実表に無いので、出走の行を読む SQL に列を足す） |

## B. オッズの形（10個）

締め切り前の単勝オッズから、強い馬が抜けているか、有力馬が何頭いるかを表す。学習では確定オッズ、予測では締め切り前のオッズか、利用者が渡したオッズを使う（[07-prediction-timing.md](07-prediction-timing.md#予測のときのオッズの与え方)）。**前日と当日に使う。** 木曜は前売りが無い。

| 特徴量 | 意味 | 例 | 型 | どこから |
|---|---|---|---|---|
| 1番人気のオッズ | 単勝オッズの最小 | 3.4 | 数値 | 手本の J（単勝オッズ）を集約（最小） |
| 2番人気のオッズ | 小さい順の 2番目 | 6.8 | 数値 | 同上（2番目） |
| 3番人気のオッズ | 小さい順の 3番目 | 7.5 | 数値 | 同上（3番目） |
| 5番人気のオッズ | 小さい順の 5番目。5頭に満たなければ欠損値 | 12.0 | 数値 | 同上（5番目） |
| 1番人気と2番人気のオッズの比 | 2番人気のオッズ ÷ 1番人気のオッズ。大きいほど本命が抜けている | 2.0 | 数値 | 上の2つから |
| 2〜5番人気の最大オッズ | 上位の有力馬がどこまで割れているか。利用者の規則の右辺 | 12.0 | 数値 | 手本の J（単勝オッズ）を集約 |
| 単勝10倍未満の頭数 | 有力馬の数 | 4 | 数値 | 同上（数える） |
| 市場勝率の上位3頭の合計 | 市場の見方が上位に集中しているか | 0.55 | 数値 | 手本の J（オッズから見た勝率）を集約（上位3頭の合計） |
| 市場勝率のエントロピー | 市場の見方がどれだけ割れているか。0（1頭に集中）〜1（全頭が同じ）。頭数の影響を除くため、頭数の対数で割る | 0.78 | 数値 | 同上 |
| 最低人気のオッズ | 単勝オッズの最大。下位がどれだけ見放されているか | 180.0 | 数値 | 手本の J（単勝オッズ）を集約（最大） |

- **利用者のイメージ①（1番人気 4.0倍以上で 2〜5番人気が 10倍未満）は、「1番人気のオッズ」と「2〜5番人気の最大オッズ」で表せる。** 決定木は、この2列に線を引いて同じ規則を作れる。規則そのものを 1/0 の特徴量にはしない（[15-decisions.md](15-decisions.md#9-利用者の規則を特徴量に入れるか)）。
- 事例を数えたところ、1番人気のオッズが上がるほど 3連単の中荒れ以上の割合は単調に上がった（2倍未満で 4割、4〜5倍台で 9割弱）。1番人気のオッズは、この予想でいちばん強い手がかりになる見込みである。
- 前日・当日の予測では、**全頭のオッズが要る。** 1頭でも無いと、頭数や順位の値がずれる。オッズの無い馬が1頭でもいれば、止めて `--odds` で全頭ぶん渡すよう案内する（[07-prediction-timing.md](07-prediction-timing.md#予測のときのオッズの与え方)）。

## C. 出走馬の実績のばらつき（10個）

出走馬1頭ごとの近走・前走・騎手の特徴量を、全出走馬で集約する。メンバーの粒がそろっているか、好調馬が多いかを表す。**木曜から使える**（持ち時計の1個だけ前日から）。

| 特徴量 | 意味 | 例 | 型 | どこから |
|---|---|---|---|---|
| 近5走の平均着差の1位と2位の差 | 実績で抜けた馬がいるか（秒） | 0.3 | 数値 | 手本の E（近5走の平均着差）を集約（小さい順の 1位と 2位の差） |
| 近5走の平均着順の標準偏差 | メンバーの粒のばらつき | 2.1 | 数値 | 手本の E（近5走の平均着順）を集約（標準偏差） |
| 近5走の平均着順の中央値 | メンバー全体の実績の水準 | 5.5 | 数値 | 同上（中央値） |
| 前走3着以内だった馬の割合 | 好調馬の多さ | 0.38 | 数値 | 手本の D（前走の着順）を集約（3以下の割合） |
| 前走が無い馬の割合 | 新馬・初出走の多さ。新馬戦なら 1 | 0.06 | 数値 | 手本の E（近5走の数）を集約（0 の割合） |
| 昇級馬の数 | 前走より上のクラスで走る馬の数 | 2 | 数値 | 手本の D（クラスの変更）を集約（昇級の数） |
| 乗り替わりの馬の数 | 前走と騎手が違う馬の数 | 5 | 数値 | 手本の C（乗り替わり）を集約（乗り替わりの数） |
| 騎手の近1年の3着以内の割合の最大 | 上位騎手がいるか | 0.31 | 数値 | 手本の C（騎手の近1年の3着以内の割合）を集約（最大） |
| 逃げそうな馬の数 | ペースの目安。多いとペースが速くなり、差しが決まって荒れやすい | 2 | 数値 | 手本の G（逃げそうな馬の数）。もともとレースに1つの値 |
| 持ち時計の順位が付く馬の割合 | 同じコース・距離での経験がある馬の割合。前日から | 0.75 | 数値 | 手本の F（持ち時計のレース内順位（コース単位））を集約（欠損値でない割合） |

## D. 1番人気の危うさ（10個）

1番人気（その時点の単勝オッズが最小の馬）の1頭ごとの特徴量を、そのまま取り出す。1番人気が飛びそうかを表す。**前日と当日に使う**（1番人気はオッズで決まるため。馬体重の増減は当日だけ）。

| 特徴量 | 意味 | 例 | 型 | どこから |
|---|---|---|---|---|
| 1番人気の前走の着順 | 前走で負けていれば危うい | 1 | 数値 | 手本の D（前走の着順）の、1番人気の値 |
| 1番人気の前走の人気 | 前走も人気だったか | 1 | 数値 | 手本の D（前走の人気）の、1番人気の値 |
| 1番人気の前走の人気と着順の差 | 前走の着順 − 前走の人気。プラスなら前走は人気より走らなかった | 0 | 数値 | [人気馬の J](../人気馬が4着以下になるかを予想/09-features.md#j-人気と人気の履歴4個) の「前走の人気と着順の差」の、1番人気の値 |
| 1番人気の近5走の平均着順 | 安定して走っているか | 2.4 | 数値 | 手本の E（近5走の平均着順）の、1番人気の値 |
| 1番人気の近5走で人気より悪い着順だった回数 | 人気を裏切ってきた回数 | 1 | 数値 | 人気馬の J の「近5走で人気より悪い着順だった回数」の、1番人気の値 |
| 1番人気の通算の出走数 | キャリアの浅さ。少ないほど実績が薄い | 9 | 数値 | 手本の E（通算の出走数）の、1番人気の値 |
| 1番人気の乗り替わり | 継続・乗り替わり・前走なし | 継続 | カテゴリ | 手本の C（乗り替わり）の、1番人気の値 |
| 1番人気の距離の変更 | 延長・短縮・同じ・前走なし | 同じ | カテゴリ | 手本の D（距離の変更）の、1番人気の値 |
| 1番人気のクラスの変更 | 昇級・降級・同級・前走なし。昇級初戦の1番人気は危うい | 同級 | カテゴリ | 手本の D（クラスの変更）の、1番人気の値 |
| 1番人気の馬体重の増減 | kg。当日から | −6 | 数値 | 手本の B（馬体重の増減）の、1番人気の値 |

- **利用者のイメージ②（1〜2倍台の1番人気が飛ぶ）は、B の「1番人気のオッズ」と、この D の組み合わせで表せる。** 事例を数えたところ、3倍未満の1番人気が飛ぶと 3連単の超荒れが 13%、3着以内なら 1% 弱だった（[10-target.md](10-target.md#理由)）。超荒れを当てるには、1番人気が飛ぶかどうかを当てることがいちばん効く。
- 1番人気の前走の人気と着順は、前走の値なのでリークにならない。今回の確定人気・確定着順は使わない（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 9）。
- 木曜はオッズが無く、1番人気を決められないので、D は使わない。

## E. 過去の同条件の荒れ率（8個）

同じ条件のレースが、開催日の前日までの 365日でどれだけ荒れてきたかを、券種ごとに数える。**木曜から使える。**

| 特徴量 | 意味 | 例 | 型 | どこから |
|---|---|---|---|---|
| 同じ競馬場・芝ダ・距離帯の近1年の中荒れ以上の割合（単勝） | そのコースは単勝が荒れやすいか | 0.45 | 数値 | 新しく作る（`hr` の払戻に [10-target.md](10-target.md#券種ごとの線引き) の線引きで荒れ具合を付け、条件ごとに数える） |
| 同上（馬連） | | 0.66 | 数値 | 同上 |
| 同上（3連複） | | 0.60 | 数値 | 同上 |
| 同上（3連単） | | 0.58 | 数値 | 同上 |
| 同じクラスの近1年の中荒れ以上の割合（単勝） | そのクラスは単勝が荒れやすいか | 0.42 | 数値 | 同上 |
| 同上（馬連） | | 0.62 | 数値 | 同上 |
| 同上（3連複） | | 0.57 | 数値 | 同上 |
| 同上（3連単） | | 0.54 | 数値 | 同上 |

- 距離帯の区切りは、手本の F（出走別着度数）と同じにする。
- 4券種ぶんを全部の券種のモデルに渡す。学習データは券種によらず1つなので、券種ごとに列を変えない（[15-decisions.md](15-decisions.md#8-過去の荒れ率の鍵と券種の数)）。
- 数えるのは前日までのレースだけである。同じ日の先に終わったレースは数えない（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 7）。
- 線引きを変えれば、E の値も一緒に変わる（同じ `UpsetLevelRule` で決めるため）。
- 鍵を「出走頭数の帯」「競走名」に増やす案は [15-decisions.md](15-decisions.md#8-過去の荒れ率の鍵と券種の数) を参照。

## カテゴリ特徴量の渡し方

カテゴリ特徴量は 10個（競馬場、芝ダ、コース、馬場状態、牡馬と牝馬が一緒に走るか、特別戦か、ハンデ戦か、1番人気の乗り替わり・距離の変更・クラスの変更）で、どれも値の種類が少ない。騎手・調教師・父のような、値の種類が多いカテゴリ特徴量は無い。モデルに渡す形はモデルごとに違う。[12-lightgbm.md](12-lightgbm.md#1-学習データの渡し方)・[13-catboost.md](13-catboost.md#1-学習データの渡し方) を参照。

## 使うデータの期間

**方針は手本と同じで、元DB に今入っている期間を、特徴量を外す理由にしない。** JRA-VAN が提供している期間を見て、学習データの期間（[08-training-data.md](08-training-data.md#4-期間の指定)。既定は 2017年1月から、ウォームアップの 2016年を含む）にそろうものは使う。

| データ | 表 | JRA-VAN の提供開始 | この設計での扱い |
|---|---|---|---|
| レース成績 | `ra`・`se` | 1986年 | 使う（A・C・D の元と、確定オッズ） |
| 払戻 | `hr` | 1986年。ただし券種ごとに発売が始まった時期が違い、3連複は 2002年6月、3連単は 2004年8月から | 使う（目的変数と E） |
| 出走別着度数 | `ck` | 2004年 | 使う（D の通算の出走数） |
| 確定の単勝オッズ | `se` | 1986年（レース成績と同じ） | 使う（B・D の学習） |
| 締め切り前の単勝オッズ（時系列オッズ） | `o1` | 過去1年ぶんだけ取れる | 予測に使う（B・D）。学習には使わない |
| 坂路・ウッドチップ調教 | `hc`・`wc` | 2003年・2021年7月27日 | 使わない（下の「使わない特徴量」） |
| タイム型・対戦型マイニング予想 | `dm`・`tm` | 2001年9月・2010年4月 | 使わない |

- 提供開始は、JV-Data仕様書「セットアップデータ」による（隣のリポジトリ jvdata-store の `docs/03-dataspecs.md` にまとめてある）。
- 2026-09-23 時点の DB には、中央の確定成績・払戻・出走別着度数が 2016年1月から入っている（`tools/DBの状態/db_info.py` で確かめられる）。それより前に延ばす案は [15-decisions.md](15-decisions.md#5-学習データの期間の既定) を参照。

## 使わない特徴量

そのレースの結果（払戻、払戻の人気順、着順、1〜3着の人気）は、リークになるので候補にもしない。[11-leak-prevention.md](11-leak-prevention.md) を参照。

| 特徴量 | 使わない理由 |
|---|---|
| 1頭ごとの特徴量そのもの（斤量、前走の着順など、手本の A〜J の各列） | 学習データの1行が1レースなので、1頭の値は列にならない。レース単位に集約した値（B・C・D）だけを使う |
| 調教（手本の I） | レース単位に集約しても意味が薄い（全馬の調教タイムの平均に、荒れとの関係は考えにくい）。2021年7月より前は記録が無く、期間を延ばす妨げになる |
| 血統（手本の H） | 父などの名前はレース単位に集約できない。産駒の3着以内の割合の平均も、荒れとの関係は考えにくい |
| 馬体重（1番人気以外） | 全馬の馬体重の集約に意味が無い。1番人気の増減だけを D で使う |
| JRA-VAN のデータマイニング予想 | JRA-VAN が出した予想なので、特徴量に入れると、モデルがそれをまねるだけになりやすい（手本と同じ理由） |
| 確定人気（`popularity`） | 1番人気は、オッズの小さい順から決める。予測のときは締め切り前のオッズから決めるので、学習と予測で同じ作り方になる（手本と同じ理由） |
| 利用者の規則に当てはまるか | B の2列で表せる。評価の基準に使う（[15-decisions.md](15-decisions.md#9-利用者の規則を特徴量に入れるか)） |
| ほかの予想（危険な人気馬・穴馬）の予測確率 | 学習データが重なるので、その予想が学習に使ったレースでは実際より当たり、リークになる（[15-decisions.md](15-decisions.md#13-ほかの予想の確率を特徴量にするか)） |
