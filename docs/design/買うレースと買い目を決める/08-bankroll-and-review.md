# 08 モジュール6: 資金の配分と、回顧データの蓄積

この文書で決めること: 勝負レースとノルマ参加のレースで、1レースの予算をどう変えるか。勝負レースの中で、買い目ごとに何円買うか。検証の済んでいない券種をどう確かめるか。レースのあとに何を記録し、次の予想にどう活かすか。実際に買い始める前に、何を確かめるか。

結論:

- **資金は「勝負用の財布」「ポリシー用の財布」「単勝・馬単用の財布」「組の期待値用の財布」「穴馬の複勝用の財布」に分ける。** ノルマ参加（購入ポリシーで買うレース）は、競馬を楽しむための参加費（エンタメ税）と割り切り、ポリシー用の財布から出す。ポリシー用の財布が少しずつ減るのは想定内とする。利用者の決定。
- **勝負レースの予算は、勝負用の財布の残高の 5%。** 残高が減れば掛け金も減り、資金が尽きにくい。利用者の決定。ポリシー用の財布は、ノルマ参加（重賞）が残高の 3%、ノルマ参加（日）が残高の 1.5%。勝負用 10万円・ポリシー用 3万円なら、5,000円・900円・400円になる。
- **勝負レースの中は、複勝の買い方（◎の期待値 1.00 以上・16頭以上のレースで、期待値 1.1 以上・複勝 5倍以下の馬）に合う馬を最大3点、1点 = 勝負用の残高の 5% ÷ 3 の均等で買う。** 期待値の大きさで掛け金を変えるのは、実際に買い始めてから、買い目の記録で 100% 超えを確かめてからにする。
- **複勝以外の券種（単勝・枠連・馬連・ワイド・馬単・3連複・3連単）は、過去のデータで先に検証した。** 利用者の決定。研究「複勝以外の回収率100超」と研究「レースの種類ごとの買い方」で、結果を見る前に決めた基準で確かめ、**当日の予想で、単勝（期待値）と◎の期待値 1.00 以上のレースの ◎ の馬単を単勝・馬単用の財布で、組の期待値（市場とモデルを重みで合わせた組の確率 × オッズ。[07 の 2](07-expected-value.md#実際に買う組の期待値の買い目の組の確率市場とモデルを重みで合わせる)）で選ぶ枠連・馬連・馬単・ワイド・3連複・3連単を組の期待値用の財布で買う。** 買い方は券種ごとに、向いたレースの中身で絞る（この文書の 2）。1点の額は財布の残高の券種ごとの割合で、100円に届かない券種は買わない。前日の予想では買わない。
- **当日の予想では、6番人気以下で、3着以内の確率が複勝オッズから見た3着以内率より 0.05 以上高い馬の複勝を、全レースで全部買う（穴馬の複勝用の財布）。** 人気馬は「来ない馬」を見つけ（消）、6番人気以下は「来そうな馬」を見つける、という利用者の考え方による。複勝を買うので、比べる相手を複勝オッズにした（この文書の 2）。
- **3連複は、3連複の荒れ具合の予想で形を決めた買い目も出す。** 固いは買わない、中荒れは 穴−強い人気馬−中穴まで（9番人気まで）、大荒れは 穴−中穴まで−中穴まで、超荒れは 穴−強い人気馬−消を除いた全頭。どれも危険な人気馬（消）は入れない。荒れ具合の予想は直せなかったので、固いと言い切れないレースは中荒れとして扱う。利用者の考え方による（この文書の 2）。
- **WIN5 は、楽しむための参加費として、ポリシー用の財布から買う。** 予想「近走と適性からWIN5の買い目を決める」の判断用の買い目（50点）の日の期待値が線以上の日に、フォーメーションを1枚買う。1回の金額は段階の予算で、本命の確率の積が線以上の多く買う日は 1万円（100点）、ほかの少なく買う日は 3,000円（30点）（[WIN5 の設計書 15 の 13](../近走と適性からWIN5の買い目を決める/15-decisions.md#13-1回の予算段階の予算)）。過去の確かめで採用の基準に届いていないので、勝負用の財布では買わない（この文書の 2）。
- **回顧データは、Python が自動で作って自動で保存する。** 「買い目の記録」「レースの回顧」「馬の回顧ノート」の3つの表を、Git の対象外の `reports/回顧/` に置く。不利は、JV-Data から自動で分かるもの（出遅れ・展開・バイアス）だけを記録し、人が手で記録するものは扱わない。NotebookLM には上げない。利用者の決定。
- **実際のお金で買い始める前のフォワードテスト（締め切り10分前のオッズでの「買ったつもり」の記録）は、しない。** 発走の直前に予想用のデータを取って予想する仕組みは作れないと利用者が判断した。検証は確定オッズまでとする（この文書の 4）。

## 1. 予算の分け方

**要件の問い「勝負レースと、ポリシーで参加する重賞とで、予算の式をどう変えるか」への答え:**

**資金を5つの財布に分け、参加の種類ごとに、どの財布から出すかと額の式を変える。** 勝負用とポリシー用に分けるのは利用者の決定。単勝・馬単用は単勝・馬単を、組の期待値用は組の期待値の買い目を、穴馬の複勝用は6番人気以下の複勝を買うと決めたときに足した（この文書の 2）。

| 財布 | 何のための資金か | 求めること |
|---|---|---|
| 勝負用の財布 | 期待値で回収率 100% 超えを狙う勝負レースの資金 | 回収率 100% を超えること |
| ポリシー用の財布 | 購入ポリシー（重賞は必ず買う・毎日1レース）を守って、競馬を楽しむための参加費（エンタメ税）。WIN5 もここから買う | 減り方が見込みどおりであること。減るのは想定内 |
| 単勝・馬単用の財布 | 当日の予想の単勝（期待値）と、◎の期待値 1.00 以上のレースの ◎ の馬単の資金 | 回収率 100% を超えること |
| 組の期待値用の財布 | 当日の予想で、組の期待値で選ぶ枠連・馬連・馬単・ワイド・3連複・3連単の資金 | 回収率 100% を超えること |
| 穴馬の複勝用の財布 | 当日の予想で、6番人気以下の複勝オッズより来ると見る馬の複勝の資金 | 回収率 100% を超えること |

```text
勝負用の財布:   勝負レースの予算 = 勝負用の財布の残高 × 5%
                1単位（1点の額） = 勝負レースの予算 ÷ 3
ポリシー用の財布: ノルマ参加（重賞）の予算 = ポリシー用の財布の残高 × 3%
                ノルマ参加（日）の予算   = ポリシー用の財布の残高 × 1.5%
単勝・馬単用の財布: 単勝の1点 = 単勝・馬単用の財布の残高 × 0.37%
                  馬単の1点 = 単勝・馬単用の財布の残高 × 0.012%
組の期待値用の財布: 1点 = 組の期待値用の財布の残高 × 券種ごとの割合
                  （枠連 0.035%・馬連 0.11%・馬単 0.12%・ワイド 0.023%・3連複 0.0072%・3連単 0.0099%）
穴馬の複勝用の財布: 1点 = 穴馬の複勝用の財布の残高 × 0.13%
どれも 100円未満は切り捨て。勝負用・ポリシー用は最低 100円。単勝・馬単用・組の期待値用・穴馬の複勝用の1点が 100円に届かなければ、その券種は買わない
```

| 参加の種類 | 出す財布 | 勝負用 10万円・ポリシー用 3万円なら | 買う券種と点数 |
|---|---|---|---|
| 勝負レース（重賞も同じ） | 勝負用 | 5,000円（1点 1,600円） | 複勝。複勝の買い方に合う馬を最大3点（この文書の 2） |
| ノルマ参加（重賞） | ポリシー用 | 900円 | 複勝を、期待値の高い順に最大2点（[03 の 4](03-race-screening.md#4-堅い重賞での買い方)） |
| ノルマ参加（日） | ポリシー用 | 400円 | 同じ選び方で1点 |
| ポリシー（WIN5） | ポリシー用 | 1回 3,000円か 1万円（段階の予算。残高の割合ではなく、決まった予算） | WIN5 のフォーメーション1枚（多く買う日 100点・少なく買う日 30点）。判断用の買い目（50点）の日の期待値が線 1.25 以上の日だけ（この文書の 2） |
| 勝負（単勝・馬単） | 単勝・馬単用 | 10万円なら単勝 300円（馬単は 12円で 100円に届かないので買わない）。100万円なら単勝 3,700円・馬単 100円 | 当日の予想の単勝（期待値）1点と、◎の期待値 1.00 以上のレースの馬単 ◎→○▲☆（2〜3点）（この文書の 2） |
| 勝負（組の期待値） | 組の期待値用 | 50万円なら馬単 600円・馬連 500円・枠連 100円・ワイド 100円 | 当日の予想で、組の期待値で選ぶ枠連・馬連・馬単・ワイド・3連複・3連単（この文書の 2） |
| 勝負（穴馬の複勝） | 穴馬の複勝用 | 10万円なら複勝 100円 | 当日の予想で、6番人気以下で複勝オッズより来ると見る馬の複勝を全部（この文書の 2） |

- **1点を「予算 ÷ 3」にする理由:** 5% を1点にまとめて載せると、ふつうの複勝の期待値と払戻倍率では、ケリー基準のほぼ満額に当たり、資金の上下がとても大きくなる。3点に分ける額にしておけば、1点は残高の 1.7% ほどで、1レースで使うのは最大 5% になる。
- **払戻は、買った財布に戻す。** 財布どうしで補わない。
- 残高・投資・払戻・回収率は、財布ごとに別に数える（表1「買い目の記録」の「参加の種類」で分けられる）。
- 残高に対する割合で額を決めるので、財布が減っても空にはならない（額は小さくなっていく）。
- 毎月の初めに、その時点の残高で額を計算し直す。
- 5つの財布に最初に入れる額は、実際に買い始めるときに利用者が決める。10万円・3万円・10万円・50万円・10万円は例である（組の期待値用の 50万円では馬単だけを買う。ほかの券種が買える額はこの文書の 2）。

### 作ったもの

財布と予算は `tools/今週の予想/wallet.py`（`Wallet`）。初めの額は `reports/回顧/財布.json`（無ければ上の例の 10万円・3万円・10万円・50万円・10万円で作る。足したあとの財布の無い前のファイルには、その例の額で書き足す。実際に買い始めるときに利用者が書き換える）。
残高は、初めの額 − 表1「買い目の記録」の金額（記録だけの行は除く）＋ 精算した払戻 で数え、**毎月の初めの残高**で予算と1点の額を決める（同じ月の中では変わらない）。
勝負レースの1点は予算 ÷ 3、期待値 1.40 以上は 2単位（ケリー基準の4分の1とレースの予算を超えない）。上限（1日 20%・複勝プールの売上の見込みの 0.5%・初めの 70% を下回ったら止める）も
`tools/今週の予想/day_planner.py` が計画で守る（売上の見込みは速報オッズの複勝票数合計）。

### 購入ポリシーを守る費用の見積もり

ノルマ参加の見込みの損は、（1 − 期待値）× 予算 である。例（架空）: 期待値 0.85 の買い目に 900円なら、1レースあたり 135円の損が見込まれる。

JRA の平地の重賞は年に 130レースほどある。そのうち半分がノルマ参加になり、期待値が平均 0.85 だとすると、年に 65 × 135円 ≒ 8,800円。ノルマ参加（日）が年に 20日あれば、20 × 400円 × 0.15 = 1,200円。**ポリシー用の財布が 3万円なら、1年でおよそ 1万円減り、2万円ほどになる見込みである。** これは競馬を楽しむための参加費として、想定内とする（利用者の決定）。見込みよりはっきり速く減っていれば、ノルマ参加の買い方の見積もりが外れているので、見直す。

### 上限

| 上限 | 値（初めの値） | 理由 |
|---|---|---|
| 1日に使う額（勝負用の財布） | 勝負用の財布の残高の 20%（勝負レース4つ分） | G1 の日に重賞の勝負レースが重なっても、1日で資金を大きく減らさない |
| 複勝1点の額 | その複勝プールの売上の見込みの 0.5% | 複勝のプールは小さく、自分の投票でオッズが下がる（研究「回収率100超」の 04 の 6-2） |
| 勝負用の財布が初めの 70% を下回ったとき | 勝負レースを買うのを止めて、線と買い方を見直す | 見積もりが外れている疑いがある。ポリシー用の財布は減るのが想定内なので、この上限は置かない |
| 単勝・馬単用の財布が初めの 70% を下回ったとき | 単勝・馬単を買うのを止めて、見直す | 勝負用と同じ。1点の額は、過去のいちばん深い落ち込みが財布の 15% に収まる割合にしてあるので、70% を割るのは過去に無かった負け方である |
| 組の期待値用の財布が初めの 70% を下回ったとき | 組の期待値の買い目を買うのを止めて、見直す | 単勝・馬単用と同じ考え方 |
| 穴馬の複勝用の財布が初めの 70% を下回ったとき | 6番人気以下の複勝を買うのを止めて、見直す | 単勝・馬単用と同じ考え方 |

## 2. 勝負レースの中の掛け金

### 採用している券種（複勝）

**◎の期待値 1.00 以上で 16頭以上のレースで、複勝の期待値が 1.1 以上・複勝の最低オッズが 5倍以下の馬を、期待値の高い順に最大3点**、**1点1単位の均等**で買う。
勝負レースは、この買い方に合う馬の見込みの利益 E（Σ（期待値 − 1））で選ぶ（[03 の 2](03-race-screening.md)）。☆ を買い目の相手に入れる線（期待値 1.25。07 の 5）は別で、変えていない。

- **この買い方にした理由:** 研究「レースの種類ごとの買い方」の docs/04（手順6）で、2016〜2018年だけで選んだ買い方を 2019〜2026年で一度だけ確かめ、回収率 100% 超え（90% の幅の下の端も 100% 超え）で、
  的中率も前の買い方（期待値 1.25 以上を全レースで3点まで）より大きく上がった。期待値の線を下げ、複勝オッズの低い馬に絞ったので、当たりやすい。

**均等にする理由:** 研究「回収率100超」で、期待値の大きさで掛け金を変える（ケリー基準）と見かけの回収率は上がるが、それは掛け金の配分を結果に合わせただけで、当たる力が上がったわけではないと分かっている（[research/回収率100超 の 04 の 5](../../../research/回収率100超/docs/04-買い方.md)）。まず均等で 100% を超えることを確かめる。

実際に買い始めてから、買い目の記録（この文書の 3 の表1）で 100% を超え続けたら、次の段階に進める。

| 期待値 | 1点の額 |
|---|---|
| 1.40 未満 | 1単位 |
| 1.40 以上 | 2単位（ただし、ケリー基準の4分の1を超えない。1レースの予算 5% も超えない） |

```text
ケリー基準の4分の1 = 勝負用の財布の残高 × （p × b − 1）÷（b − 1）÷ 4
  p = 補正後の3着以内の確率、b = 見込みの払戻倍率
```

### 採用している券種（当日の単勝・馬単）

**当日の予想では、単勝（期待値）を買い、◎の期待値 1.00 以上（◎ の単勝の期待値が 1.00 以上。[07 の 5](07-expected-value.md#5-印の付け方)）のレースは、馬単 ◎→○・▲・☆ も買う。** 複勝の勝負レースの選び方（E の大きい順に1日3つまで）とは別に選び、同じレースで両方を買うこともある。参加の種類は「勝負（単勝・馬単）」で、単勝・馬単用の財布から出す。

| 項目 | 中身 |
|---|---|
| 単勝（期待値） | 1番人気の単勝オッズが 2.3倍以上のレースで、単勝の期待値（1着の確率 × 単勝オッズ）が 1.0 以上・単勝 5倍以下の馬を、期待値の高い順に1点。◎ でなくてもよい。過去の数え上げでは1開催日に平均 2.0 レース |
| 馬単 | ◎の期待値 1.00 以上のレースで、馬単 ◎→○・▲・☆（ふつう2点。期待値が 1.25 以上の ☆ がいれば3点。表示だけの ☆ は入れない）。1開催日に平均 10 レースほど |
| 1点の額 | 単勝は単勝・馬単用の財布の残高（月初）の 0.37%、馬単は 0.012%。100円未満は切り捨て、100円に届かない券種は買わない。トリガミとオッズの無い組は買わない |
| 例 | 財布が 10万円なら単勝 300円だけ。100万円なら単勝 3,700円・馬単 100円 |
| 前日の予想 | 買わない（確かめたのは当日の予想だけ） |
| 1日の上限 | 置かない |
| 止めるとき | 単勝・馬単用の財布が初めの 70% を下回ったら止める（この文書の 1 の上限） |

- **単勝（期待値）にした理由:** 研究「レースの種類ごとの買い方」の docs/04（手順6）で、2016〜2018年だけで選んだ買い方を 2019〜2026年で確かめ、回収率 100% 超え（90% の幅の下の端も 100% 超え）で、的中率が前の買い方（◎の期待値 1.00 以上の ◎ の単勝）の倍ほどになった。1番人気が抜けていないレースで、単勝 5倍以下の、期待値の高い馬を買う。前の ◎ の単勝より回収率は少し下がる。
- **馬単（◎→○▲☆）を残した理由:** 研究「複勝以外の回収率100超」の手順4（[docs/03](../../../research/複勝以外の回収率100超/docs/03-印の買い目の確かめ.md)）で、まだ一度も数えていない 2021〜2022年で基準を満たした。組の期待値の馬単（この文書の下の表）とは別の買い目である。

| 荒れ具合 | 予想「レースの荒れ具合を4段階で予想」の3連複の4つの確率から決める（`TrioUpsetJudge`）。超荒れ（払戻 50,000円以上）はどのレースでも確率がいちばん高いクラスにならないので、超荒れの確率が 0.18 以上なら超荒れ。そうでなければ確率がいちばん高いクラスだが、固いは固いの確率が 0.50 以上のときだけで、届かなければ中荒れとして扱う（固いと言い切れないレースは中荒れの形で買う）。オッズを使う予想なので、前日・当日の予想だけ |
| 穴 | 6番人気以下の複勝の馬（この文書の上の「6番人気以下の複勝」と同じ馬）。いなければ穴の入る形は組まない |
| 人気馬 | 5番人気までで危険な人気馬（消）でない馬 |
| 強い人気馬 | 人気馬のうち、3着以内の確率 − 複勝オッズから見た3着以内率が線（−0.05。超荒れは 0）以上の馬 |
| 中穴まで | 9番人気までで消でない馬。大荒れでは、そのうち 3着以内の確率 − 複勝オッズから見た3着以内率が −0.05 以上の馬 |
| 組 | 1頭目ごとに組み、3頭が違う組だけ。同じ組は1点にまとめる |

- **この形にした理由:** 利用者の考え方「どういう荒れ具合かで買い方を決める」「的中率を上げて、高配当も取って、回収率 100% を超える」による。固いは買わず、中荒れは相手を中穴まで広げ、大荒れは2頭目も中穴まで広げ（中荒れと同じ形では荒れ方に合わない）、超荒れで高配当を取る。
- **荒れ具合の予想の限界:** 荒れ具合の予想は4段階の半分ほどしか当てられず、全頭の予想から作った材料（穴の数・消の数・人気馬の強さ・モデルと市場のずれ など）を足して学び直しても見分ける力は上がらなかった（研究「危険な人気馬を見極める」。研究「百万馬券を当てる」で試した材料でも同じ）。そこで予想を直すのではなく、固いと言い切れないレースを中荒れとして扱う線（0.50）を置き、荒れ具合ごとの形を両方の期間で選んだ。
- **確かめたこと:** 研究「危険な人気馬を見極める」で、研究「既存モデルの改善」の7つの区切りのテスト期間と、まだ見ていなかった 2021年前半〜2022年前半（荒れ具合の予想も学び直した）で数えた。3つの形を合わせた全体の回収率は両方の期間で 100% を超え、買ったレースの的中率は6〜7レースに1回ほどである。固いは、人気順の5頭のボックスでも予想の上位4頭のボックスでも 100% に届かなかった。中荒れ・大荒れは相手を中穴（9番人気）まで広げると人気馬までより的中率も回収率も上がり、大荒れにオッズの下限（100倍以上など）を付けると回収率も的中率も下がった。超荒れの形は両方の期間で、年ごとにもどの年も 100% を超えた。数値は Git の対象外の `reports/危険な人気馬を見極める/`。
- **気をつけること:** 固いのレース（全レースの半分ほど）では3連複を買わないので、3連複が出るのは半分ほどのレースである。全体の 100% 超えは中荒れと超荒れの形が支えている。超荒れのレースは全レースの 5% ほどで、確かめたレースの数が少ない。超荒れの線 0.18 と固いの線 0.50 は、2023〜2026年と 2021〜2022年の両方の結果を見て決めた。検証は確定オッズである。

| 展開が向かなかった | 結果のペースと位置で出した展開スコアが −0.01 以下で、4着以下（[05 の 2](05-race-development.md#2-展開スコア有利不利の判定)） |
| バイアスと逆だった | 結果の位置で出したバイアスの補正が −0.02 以下で、4着以下（[06 の 1](06-realtime-adjustment.md#1-トラックバイアスの検知)） |

進路の妨害・外を回された・折り合いを欠いた、のような不利は、JV-Data に無く、レースの映像を人が見ないと分からない。手で記録する作業は仕組みに入れないので、**扱わない。**

### 作ったもの

3つの表は `src/yosou/review/` が作り、道具「回顧」（`tools/回顧/review.py`）と道具「今週の予想」（予想の前に自動で呼ぶ）が書く。人が手で書く列は無い。

| 表 | 作り方 |
|---|---|
| 表1 買い目の記録 | 今週の予想が計画（[03](03-race-screening.md#作ったもの)）を決めたときに、複勝の買い目を書く（`tools/今週の予想/bet_recorder.py`）。レースが終わると、事実表の複勝・単勝の払戻から払戻を書き足して精算する（`BetSettler`）。オッズの時刻は予想を作った時刻 |
| 表2 レースの回顧 | 結果のペース（展開スコアと同じ区分）・終わった日のバイアスの傾き（内・前。その日のほかの全部のレースと前の日のレースから）・馬場状態。予想のペースは、展開スコアを足した時点の予想が残したハイ・スローの確率（結果の JSON の `pace`） |
| 表3 馬の回顧ノート | 不利のあった馬だけ。下の条件で自動で判定し、程度は線をどれだけ超えたかで 小・中・大（出遅れは 0.1 刻み、展開とバイアスは 0.01 刻み）。さかのぼって書くときは、表 G と過去の傾きの表をレースの年ごとに「その年より前のレース」で作る（学習データの材料と同じ決まり） |

不利の判定で、設計書の「予想の序盤の位置」は**その馬の近5走の序盤の位置の平均**（展開スコアの脚質の決め方と同じ元）にした。展開の予想②を使うと、過去の全レースにさかのぼって付けるのに
展開のモデルを全レースで動かす必要があり、終わったレースの回顧を毎週書き足すのにも1レース1分かかるためである。「展開が向かなかった」は、その走の最初のコーナーの位置で決めた結果の脚質と結果のペースで
表 G を引いた値、「バイアスと逆」は終わった日の使う傾きからいつもの傾きを引いた分を馬番の位置と4コーナーの位置に掛けた値（[06 の 1](06-realtime-adjustment.md#1-トラックバイアスの検知)）で判定する。

### 置き場所

- 3つの表は、keiba-yosou が書き込める DuckDB のファイル `reports/回顧/review.duckdb` に、Python が自動で保存する（`ReviewStore`。同じ鍵の行は置き換える）。jvdata-store の DB は読むだけにしているので、別のファイルにする。
- **Git の対象外の `reports/回顧/` に置く。** 馬名・オッズ・払戻が入るので、公開リポジトリに載せない。
- **NotebookLM には上げない。** 人が後から NotebookLM で分析しないので、上げる手間は要らない。Python が自分で読み書きするだけにする（利用者の決定）。

### 自分の記録からの学び直し（毎月、自動）

1. 買い目の記録から、券種 × オッズの帯ごとの「実際に当たった割合 ÷ 予想の平均」を数え、較正を直す（[07 の 1](07-expected-value.md#1-確率の作り方) の手順 5）。
2. 財布ごとの成績（勝負用の回収率、ポリシー用の減り方）を数える。
3. 半年ごとに、複勝の買う線（1.1）と勝負レースの上限（1日3つ）を見直す。見直しには、その前の期間の記録だけを使う。

## 4. 実際に買い始める前の確かめ（フォワードテストはしない）

**フォワードテスト（これから行われるレースで、締め切り10分前のオッズを使って1か月ほど「買ったつもり」の記録をとり、それでも回収率が 100% を超えるかを確かめること）は、しない。** 利用者が「発走の直前に予想用のデータを取って予想する仕組みは作れない。当日にしか確かめられない」と判断した。そのための道具（keiba-yosou の `tools/フォワードテスト/` と、jvdata-store の発走前のオッズの取り直し）も消した。

これまでの検証（研究「回収率100超」など）は、どれも確定オッズを使っている。実際に買うときに見られるのは締め切り前のオッズで、確定までにオッズは動く。**確定オッズでの回収率は、上限の見積もりでしかない。** 過去の時系列オッズ（単複・馬連）で確かめた範囲では、この差は大きかった（研究「回収率100超」の [04 の 6-1](../../../research/回収率100超/docs/04-買い方.md)。発走の10分前のオッズでは 100% を大きく割り、1分前なら確定オッズとほぼ同じ）。

そこで、実際に買い始める前の確かめは、次のとおりとする。

1. **検証は確定オッズまで。** 採用の基準（回収率 100% 超え、開催日を単位にしたブートストラップの 90% の幅の下の端も 100% 超え）は、確定オッズで満たすことを求める。結果には、締め切り前のオッズでは下がりうることを書き添える。
2. **買い始めたあとは、買い目の記録（この文書の 3 の表1）で確かめる。** 買ったときのオッズと払戻が自動で残るので、実際のオッズでの回収率はここで分かる。線（1.25）は、記録を見てすぐには動かさず、半年ごとの見直し（この文書の 3）で、その前の期間の記録だけを使って決め直す。
