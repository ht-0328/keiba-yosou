# 08 モジュール6: 資金の配分と、回顧データの蓄積

この文書で決めること: 勝負レースとノルマ参加のレースで、1レースの予算をどう変えるか。勝負レースの中で、買い目ごとに何円買うか。検証の済んでいない券種をどう確かめるか。レースのあとに何を記録し、次の予想にどう活かすか。実際に買い始める前に、何を確かめるか。

結論:

- **資金は「勝負用の財布」「ポリシー用の財布」「単勝・馬単用の財布」「組の期待値用の財布」に分ける。** ノルマ参加（購入ポリシーで買うレース）は、競馬を楽しむための参加費（エンタメ税）と割り切り、ポリシー用の財布から出す。ポリシー用の財布が少しずつ減るのは想定内とする。利用者の決定。
- **勝負レースの予算は、勝負用の財布の残高の 5%。** 残高が減れば掛け金も減り、資金が尽きにくい。利用者の決定。ポリシー用の財布は、ノルマ参加（重賞）が残高の 3%、ノルマ参加（日）が残高の 1.5%。勝負用 10万円・ポリシー用 3万円なら、5,000円・900円・400円になる。
- **勝負レースの中は、期待値 1.25 以上の複勝を最大3点、1点 = 勝負用の残高の 5% ÷ 3 の均等で買う。** 期待値の大きさで掛け金を変えるのは、実際に買い始めてから、買い目の記録で 100% 超えを確かめてからにする。
- **複勝以外の券種（単勝・ワイド・馬連・馬単・3連複・3連単）は、過去のデータで先に検証した。** 利用者の決定。全券種のオッズから確率を作る買い方は、どの券種も採用の基準を満たさなかった。**印のルールの買い目を、まだ見ていない年（2021〜2022年）で確かめ直したところ、当日の予想で期待度「高」のレースの ◎ の単勝と馬単（◎→○▲☆）が基準を満たしたので、複勝と別に買う。** 1点の額は単勝・馬単用の財布の残高の割合で決める（単勝 0.1%・馬単 0.03%。100円に届かない券種は買わない）。**さらに、組ごとの期待値（市場とモデルを重みで合わせた組の確率 × オッズ。[07 の 2](07-expected-value.md#実際に買う組の期待値の買い目の組の確率市場とモデルを重みで合わせる)）で組を選ぶ形にし、まだ見ていない年で確かめて、当日の予想の馬単・ワイド・3連複・3連単を買う。** 1点の額は組の期待値用の財布の残高の券種ごとの割合。馬連と、前日の予想は買わない（この文書の 2）。
- **回顧データは、Python が自動で作って自動で保存する。** 「買い目の記録」「レースの回顧」「馬の回顧ノート」の3つの表を、Git の対象外の `reports/回顧/` に置く。不利は、JV-Data から自動で分かるもの（出遅れ・展開・バイアス）だけを記録し、人が手で記録するものは扱わない。NotebookLM には上げない。利用者の決定。
- **実際のお金で買い始める前のフォワードテスト（締め切り10分前のオッズでの「買ったつもり」の記録）は、しない。** 発走の直前に予想用のデータを取って予想する仕組みは作れないと利用者が判断した。検証は確定オッズまでとする（この文書の 4）。

## 1. 予算の分け方

**要件の問い「勝負レースと、ポリシーで参加する重賞とで、予算の式をどう変えるか」への答え:**

**資金を4つの財布に分け、参加の種類ごとに、どの財布から出すかと額の式を変える。** 勝負用とポリシー用に分けるのは利用者の決定。単勝・馬単用は単勝・馬単を、組の期待値用は組の期待値の買い目を買うと決めたときに足した（この文書の 2）。

| 財布 | 何のための資金か | 求めること |
|---|---|---|
| 勝負用の財布 | 期待値で回収率 100% 超えを狙う勝負レースの資金 | 回収率 100% を超えること |
| ポリシー用の財布 | 購入ポリシー（重賞は必ず買う・毎日1レース）を守って、競馬を楽しむための参加費（エンタメ税） | 減り方が見込みどおりであること。減るのは想定内 |
| 単勝・馬単用の財布 | 当日の予想で期待度「高」のレースの ◎ の単勝と馬単の資金 | 回収率 100% を超えること |
| 組の期待値用の財布 | 当日の予想で、組の期待値で選ぶ馬単・ワイド・3連複・3連単の資金 | 回収率 100% を超えること |

```text
勝負用の財布:   勝負レースの予算 = 勝負用の財布の残高 × 5%
                1単位（1点の額） = 勝負レースの予算 ÷ 3
ポリシー用の財布: ノルマ参加（重賞）の予算 = ポリシー用の財布の残高 × 3%
                ノルマ参加（日）の予算   = ポリシー用の財布の残高 × 1.5%
単勝・馬単用の財布: 単勝の1点 = 単勝・馬単用の財布の残高 × 0.1%
                  馬単の1点 = 単勝・馬単用の財布の残高 × 0.03%
組の期待値用の財布: 1点 = 組の期待値用の財布の残高 × 券種ごとの割合
                  （馬単 0.04%・ワイド 0.016%・3連複 0.003%・3連単 0.0007%）
どれも 100円未満は切り捨て。勝負用・ポリシー用は最低 100円。単勝・馬単用と組の期待値用の1点が 100円に届かなければ、その券種は買わない
```

| 参加の種類 | 出す財布 | 勝負用 10万円・ポリシー用 3万円なら | 買う券種と点数 |
|---|---|---|---|
| 勝負レース（重賞も同じ） | 勝負用 | 5,000円（1点 1,600円） | 複勝。期待値 1.25 以上の馬を最大3点（この文書の 2） |
| ノルマ参加（重賞） | ポリシー用 | 900円 | 複勝を、期待値の高い順に最大2点（[03 の 4](03-race-screening.md#4-堅い重賞での買い方)） |
| ノルマ参加（日） | ポリシー用 | 400円 | 同じ選び方で1点 |
| 勝負（単勝・馬単） | 単勝・馬単用 | 10万円なら単勝 100円（馬単は 30円で 100円に届かないので買わない）。40万円なら単勝 400円・馬単 100円 | 当日の予想で期待度「高」のレースの ◎ の単勝1点と、馬単 ◎→○▲☆（2〜3点）（この文書の 2） |
| 勝負（組の期待値） | 組の期待値用 | 50万円なら馬単 200円だけ。100万円なら馬単 400円・ワイド 100円 | 当日の予想で、組の期待値で選ぶ馬単・ワイド・3連複・3連単（この文書の 2） |

- **1点を「予算 ÷ 3」にする理由:** 5% を1点にまとめて載せると、ふつうの複勝の期待値と払戻倍率では、ケリー基準のほぼ満額に当たり、資金の上下がとても大きくなる。3点に分ける額にしておけば、1点は残高の 1.7% ほどで、1レースで使うのは最大 5% になる。
- **払戻は、買った財布に戻す。** 財布どうしで補わない。
- 残高・投資・払戻・回収率は、財布ごとに別に数える（表1「買い目の記録」の「参加の種類」で分けられる）。
- 残高に対する割合で額を決めるので、財布が減っても空にはならない（額は小さくなっていく）。
- 毎月の初めに、その時点の残高で額を計算し直す。
- 4つの財布に最初に入れる額は、実際に買い始めるときに利用者が決める。10万円・3万円・10万円・50万円は例である（組の期待値用の 50万円では馬単だけを買う。ほかの券種が買える額はこの文書の 2）。

### 作ったもの

財布と予算は `tools/今週の予想/wallet.py`（`Wallet`）。初めの額は `reports/回顧/財布.json`（無ければ上の例の 10万円・3万円・10万円・50万円で作る。足したあとの財布の無い前のファイルには、その例の額で書き足す。実際に買い始めるときに利用者が書き換える）。
残高は、初めの額 − 表1「買い目の記録」の金額（記録だけの行は除く）＋ 精算した払戻 で数え、**毎月の初めの残高**で予算と1点の額を決める（同じ月の中では変わらない）。
勝負レースの1点は予算 ÷ 3、期待値 1.40 以上は 2単位（ケリー基準の4分の1とレースの予算を超えない）。上限（1日 20%・複勝プールの売上の見込みの 0.5%・初めの 70% を下回ったら止める）も
`tools/今週の予想/day_planner.py` が計画で守る（売上の見込みは速報オッズの複勝票数合計）。

### 購入ポリシーを守る費用の見積もり

ノルマ参加の見込みの損は、（1 − 期待値）× 予算 である。例（架空）: 期待値 0.85 の買い目に 900円なら、1レースあたり 135円の損が見込まれる。

JRA の平地の重賞は年に 130レースほどある。そのうち半分がノルマ参加になり、期待値が平均 0.85 だとすると、年に 65 × 135円 ≒ 8,800円。ノルマ参加（日）が年に 20日あれば、20 × 400円 × 0.15 = 1,200円。**ポリシー用の財布が 3万円なら、1年でおよそ 1万円減り、2万円ほどになる見込みである。** これは競馬を楽しむための参加費として、想定内とする（利用者の決定）。見込みよりはっきり速く減っていれば、ノルマ参加の買い方の見積もりが外れているので、見直す。

### 上限

| 上限 | 値（初めの値） | 理由 |
|---|---|---|
| 1日に使う額（勝負用の財布） | 勝負用の財布の残高の 20%（勝負レース4つ分） | G1 の日に重賞の勝負レースが重なっても、1日で資金を大きく減らさない |
| 複勝1点の額 | その複勝プールの売上の見込みの 0.5% | 複勝のプールは小さく、自分の投票でオッズが下がる（研究「回収率100超」の 04 の 6-2） |
| 勝負用の財布が初めの 70% を下回ったとき | 勝負レースを買うのを止めて、線と買い方を見直す | 見積もりが外れている疑いがある。ポリシー用の財布は減るのが想定内なので、この上限は置かない |
| 単勝・馬単用の財布が初めの 70% を下回ったとき | 単勝・馬単を買うのを止めて、見直す | 勝負用と同じ。1点の額は、過去のいちばん深い落ち込みが財布の 15% に収まる割合にしてあるので、70% を割るのは過去に無かった負け方である |
| 組の期待値用の財布が初めの 70% を下回ったとき | 組の期待値の買い目を買うのを止めて、見直す | 単勝・馬単用と同じ考え方 |

## 2. 勝負レースの中の掛け金

### 採用している券種（複勝）

期待値 1.25 以上の馬を、期待値の高い順に最大3点、**1点1単位の均等**で買う。

**均等にする理由:** 研究「回収率100超」で、期待値の大きさで掛け金を変える（ケリー基準）と見かけの回収率は上がるが、それは掛け金の配分を結果に合わせただけで、当たる力が上がったわけではないと分かっている（[research/回収率100超 の 04 の 5](../../../research/回収率100超/docs/04-買い方.md)）。まず均等で 100% を超えることを確かめる。

実際に買い始めてから、買い目の記録（この文書の 3 の表1）で 100% を超え続けたら、次の段階に進める。

| 期待値 | 1点の額 |
|---|---|
| 1.25 以上 1.40 未満 | 1単位 |
| 1.40 以上 | 2単位（ただし、ケリー基準の4分の1を超えない。1レースの予算 5% も超えない） |

```text
ケリー基準の4分の1 = 勝負用の財布の残高 × （p × b − 1）÷（b − 1）÷ 4
  p = 補正後の3着以内の確率、b = 見込みの払戻倍率
```

### 採用している券種（当日の期待度「高」のレースの単勝・馬単）

**当日の予想で、レースの期待度が「高」（◎ の単勝の期待値が 1.00 以上。[07 の 5](07-expected-value.md#5-印の付け方)）のレースは全部、◎ の単勝1点と、馬単 ◎→○・▲・☆ を買う。** 複勝の勝負レースの選び方（E の大きい順に1日3つまで）とは別に選び、同じレースで両方を買うこともある。参加の種類は「勝負（単勝・馬単）」で、単勝・馬単用の財布から出す。

| 項目 | 中身 |
|---|---|
| 買うレース | 当日の予想で期待度「高」のレース全部。過去の数え上げでは、1開催日に平均 10 レースほど（多い日は 20 レースを超える） |
| 買い目 | 単勝 ◎（1点）と、馬単 ◎→○・▲・☆（ふつう2点。期待値が 1.25 以上の ☆ がいれば3点。表示だけの ☆ は入れない）。トリガミとオッズの無い組は買わない |
| 1点の額 | 単勝は単勝・馬単用の財布の残高（月初）の 0.1%、馬単は 0.03%。100円未満は切り捨て、100円に届かない券種は買わない |
| 例 | 財布が 10万円なら単勝 100円だけ（1日 1,000円ほど）。40万円なら単勝 400円・馬単 100円（1レース 600〜700円、1日 6,000円ほど） |
| 前日の予想 | 買わない（前日の予想は、まだ見ていない年で基準を満たさなかった） |
| 1日の上限 | 置かない。1点の額が残高の 0.1%・0.03% と小さく、多い日でも1日の投資は財布の数% に収まる |
| 止めるとき | 単勝・馬単用の財布が初めの 70% を下回ったら止める（この文書の 1 の上限） |

- **採用した理由:** 研究「複勝以外の回収率100超」の手順4（[docs/03](../../../research/複勝以外の回収率100超/docs/03-印の買い目の確かめ.md)）で、印のルールの買い目を、印の決め方も買い目の決まりも変えずに、まだ一度も数えていない 2021〜2022年で数えた。結果を見る前に決めた2つの基準（その2年で回収率 100% 超え、2021〜2026年の全体で 90% の幅の下の端も 100% 超え。複勝と同じ強さ）を、前日・当日の20の候補のうち、当日の期待度「高」の単勝と馬単だけが満たした。単勝はどの年も 100% を超えている。数値は Git の対象外の `reports/複勝以外の回収率100超/`（`印の成績-前の年/`・`印の成績-2021から/`・`運用の目安.md`）。
- **1点の額の決め方:** 2021〜2026年の買い目で数えた、いちばん深い落ち込みが、財布の 15%（止まりの線 70% までの半分）に収まる割合にした。馬単は当たりが少なく連敗が長いので、単勝より割合を小さくした。財布が小さいうちは馬単を買わないのはそのためである。
- **財布を分けた理由:** 馬単の振れは、複勝の勝負レースより大きい。勝負用の財布に混ぜると、馬単の連敗だけで勝負用の止まりの線（初めの 70%）を割り、複勝の勝負レースまで止まってしまう。
- **気をつけること:** 検証は確定オッズである。実際に買うのは締め切り前のオッズで、期待度「高」の判定も締め切り前のオッズの単勝の期待値で決まるので、成績は検証より悪く出るおそれがある。買い目の記録（この文書の 3 の表1）の「勝負（単勝・馬単）」の成績を、勝負用と同じく見ていく。
- **作ったもの:** `tools/今週の予想/day_planner.py`（計画の 4. の段）、`wallet.py`（単勝・馬単用の財布と `point_yen`）、`bet_recorder.py`（表1に書く）、`src/yosou/review/bet_settler.py`（馬単の払戻を払戻の明細から入れる。組の馬に取消・除外がいれば返還）。

### 採用している券種（当日の予想の組の期待値の買い目）

**当日の予想では、組の期待値（[07 の 2](07-expected-value.md#実際に買う組の期待値の買い目の組の確率市場とモデルを重みで合わせる)。市場とモデルを重みで合わせた組の確率 × 締め切り前のオッズ）で組を選んで、馬単・ワイド・3連複・3連単を買う。** 印は対象の決まりにだけ使う。複勝の勝負レースや、期待度「高」の ◎ の単勝・馬単とは別に選び、同じレースで重なることもある（同じ馬単の組を ◎ の馬単と両方で買うこともある）。参加の種類は「勝負（組の期待値）」で、組の期待値用の財布から出す。

| 券種 | 対象 | 買うレースの条件 | 線（組の期待値） | オッズの上限 | 1レースの点数 | 重み | 過去の数え上げ（1開催日あたり） |
|---|---|---|---|---|---|---|---|
| 馬単 | 全レース | 15頭以下 | 1.1 以上 | 30倍以下 | 全部（平均 1.2点） | 2023〜2026年で推定したもの | 2.6 レース |
| ワイド | 当日の期待度「高」のレース | 1番人気の単勝オッズが 2.9倍以上 | 1.0 以上 | 300倍以下（最低オッズ） | 期待値の高い順に3点まで（平均 2.8点） | いちばん新しい1年で推定したもの | 4.0 レース |
| 3連複 | ◎ を含む組 | なし | 1.2 以上 | 1,000倍以下 | 期待値の高い順に3点まで（平均 2.1点） | 同上 | 13 レース |
| 3連単 | 全レース | ◎ の単勝の期待値が 0.99 以下（期待度「低」のレースだけになる） | 1.3 以上 | 3,000倍以下 | 全部（平均 9.4点。多いレースは 100点を超える） | 同上 | 13 レース |

買うレースの条件は、券種ごとに向いたレースの中身で絞るもの（研究「レースの種類ごとの買い方」の [docs/03](../../../research/レースの種類ごとの買い方/docs/03-券種ごとに向くレース.md)）。
条件は 2016〜2018年だけで決め、2019〜2026年で、絞らないときより回収率が高く、幅の下の端も 100% を超えた。中身は当日の締め切り前の単勝オッズと印から出す（`tools/今週の予想/combo_race_traits.py`）。
条件を足したので、1開催日に買うレースは、馬単・3連単で4割ほど、ワイドで半分ほど減る。的中率はほぼ変わらない（3連単は少し下がる）。

| 項目 | 中身 |
|---|---|
| 1点の額 | 組の期待値用の財布の残高（月初）× 券種ごとの割合。馬単 0.04%・ワイド 0.023%・3連複 0.0027%・3連単 0.001%。100円未満は切り捨て、100円に届かない券種は買わない |
| 100円に届く財布の額 | 馬単 25万円・ワイド 約43.5万円・3連複 約370万円・3連単 1,000万円 |
| 例 | 財布が 50万円なら馬単 200円・ワイド 100円。100万円なら馬単 400円・ワイド 200円。1,000万円なら4券種とも買う |

| 止めるとき | 組の期待値用の財布が初めの 70% を下回ったら止める（この文書の 1 の上限） |

- **採用した理由:** 研究「複勝以外の回収率100超」で、決まりと重みを結果を見る前に決め、まだ一度も数えていない年で確かめて、基準（その年で回収率 100% 超え、全体で 90% の幅の下の端も 100% 超え）を満たした。馬単は手順5（[docs/04](../../../research/複勝以外の回収率100超/docs/04-組の期待値で選ぶ買い方.md)。2019〜2020年）と手順6（[docs/05](../../../research/複勝以外の回収率100超/docs/05-直前1年の重みと2015年から.md)。2016〜2018年）の両方で満たした。ワイド・3連複・3連単は、重みを直前1年で推定し直す形にして、手順6 で満たした。数値は Git の対象外の `reports/複勝以外の回収率100超/組の期待値/`。
- **馬連は買わない:** 手順5 では 2019〜2020年で基準を満たしたが、手順6 で新しく見た 2016〜2018年では、どちらの重みでも 100% に届かなかった。道具「印の成績」に比べるための行として出す。
- **1点の額の決め方:** 4つの券種の振れ（1点 100円でのいちばん深い落ち込み）がそろう比で配り、4つをまとめて 2016〜2026年の買い目（買うレースの条件で絞ったもの）で数えた、いちばん深い落ち込みが財布の 15% に収まる割合を切り下げた（単勝・馬単と同じ決め方）。3連複・3連単は当たるレースが 2% 前後で、連敗の落ち込みがとても深いので、割合がとても小さい。
- **重みの置き場所と作り直し:** 重みはモデルの置き場所の `combo_blend.json`（券種ごと）。ワイド・3連複・3連単は、いちばん新しい1年のテスト期間（今の本番のモデルの区切りの予測）で推定し直す（`research/複勝以外の回収率100超/combo_value.py rolling --latest-only --save-models`）。モデルを学び直したときも、この手順で作り直す。
- **財布を分けた理由:** 1日に買うレースが多く、連敗も長い。ほかの財布に混ぜると、この振れだけで止まりの線を割ってしまう。
- **気をつけること:** 検証は確定オッズである。実際に買うのは締め切り前のオッズで、組の期待値もそのオッズで出すので、成績は検証より悪く出るおそれがある。3連複・3連単は年ごとの振れが大きく、全体では 100% を超えたが、100% を割る年が何度もあった。買い目の記録（この文書の 3 の表1）の「勝負（組の期待値）」の成績を見ていく。
- **作ったもの:** `src/yosou/shared/combo_value/`（組の確率の部品）、`tools/今週の予想/combo_value_picker.py`・`combo_value_rule.py`（買い目を選ぶ。決まりは `ticket_rules.py` の `COMBO_VALUE_RULES`）、`race_condition.py`・`combo_race_traits.py`（買うレースの条件とレースの中身）、`forecast_tickets.py`（当日の予想で締め切り前のオッズの板から選ぶ）、`day_planner.py`（計画の 5. の段）、`wallet.py`（組の期待値用の財布）。精算は `src/yosou/review/bet_settler.py`（組の券種は払戻の明細から入れる）。道具「印の成績」の表7・表8 にも「（組の期待値）」の行で出す（今の重みで過去を数えた参考の行。採否の判定は研究の docs/04・05）。

手順:

1. **買い目ごとの確率を出す部品を足す。** 1着の確率は、3連単のプールから見た1着の確率を、モデルの3着以内の確率との食い違いで直して作る。2着・3着と買い目の確率は、Harville の式に Stern の補正を入れて出し、券種 × オッズの帯ごとの実績で較正する。

| バイアスと逆だった | 結果の位置で出したバイアスの補正が −0.02 以下で、4着以下（[06 の 1](06-realtime-adjustment.md#1-トラックバイアスの検知)） |

進路の妨害・外を回された・折り合いを欠いた、のような不利は、JV-Data に無く、レースの映像を人が見ないと分からない。手で記録する作業は仕組みに入れないので、**扱わない。**

### 作ったもの

3つの表は `src/yosou/review/` が作り、道具「回顧」（`tools/回顧/review.py`）と道具「今週の予想」（予想の前に自動で呼ぶ）が書く。人が手で書く列は無い。

| 表 | 作り方 |
|---|---|
| 表1 買い目の記録 | 今週の予想が計画（[03](03-race-screening.md#作ったもの)）を決めたときに、複勝の買い目を書く（`tools/今週の予想/bet_recorder.py`）。レースが終わると、事実表の複勝・単勝の払戻から払戻を書き足して精算する（`BetSettler`）。オッズの時刻は予想を作った時刻 |
| 表2 レースの回顧 | 結果のペース（展開スコアと同じ区分）・終わった日のバイアスの傾き（内・前。その日のほかの全部のレースと前の日のレースから）・馬場状態。予想のペースは、展開スコアを足した時点の予想が残したハイ・スローの確率（結果の JSON の `pace`） |
| 表3 馬の回顧ノート | 不利のあった馬だけ。下の条件で自動で判定し、程度は線をどれだけ超えたかで 小・中・大（出遅れは 0.1 刻み、展開とバイアスは 0.01 刻み）。さかのぼって書くときは、表 G と過去の傾きの表をレースの年ごとに「その年より前のレース」で作る（学習データの材料と同じ決まり） |

不利の判定で、設計書の「予想の序盤の位置」は**その馬の近5走の序盤の位置の平均**（展開スコアの脚質の決め方と同じ元）にした。展開の予想②を使うと、過去の全レースにさかのぼって付けるのに
展開のモデルを全レースで動かす必要があり、終わったレースの回顧を毎週書き足すのにも1レース1分かかるためである。「展開が向かなかった」は、その走の最初のコーナーの位置で決めた結果の脚質と結果のペースで
表 G を引いた値、「バイアスと逆」は終わった日の使う傾きからいつもの傾きを引いた分を馬番の位置と4コーナーの位置に掛けた値（[06 の 1](06-realtime-adjustment.md#1-トラックバイアスの検知)）で判定する。

### 置き場所

- 3つの表は、keiba-yosou が書き込める DuckDB のファイル `reports/回顧/review.duckdb` に、Python が自動で保存する（`ReviewStore`。同じ鍵の行は置き換える）。jvdata-store の DB は読むだけにしているので、別のファイルにする。
- **Git の対象外の `reports/回顧/` に置く。** 馬名・オッズ・払戻が入るので、公開リポジトリに載せない。
- **NotebookLM には上げない。** 人が後から NotebookLM で分析しないので、上げる手間は要らない。Python が自分で読み書きするだけにする（利用者の決定）。

### 自分の記録からの学び直し（毎月、自動）

1. 買い目の記録から、券種 × オッズの帯ごとの「実際に当たった割合 ÷ 予想の平均」を数え、較正を直す（[07 の 1](07-expected-value.md#1-確率の作り方) の手順 5）。
2. 財布ごとの成績（勝負用の回収率、ポリシー用の減り方）を数える。
3. 半年ごとに、買う線（1.25）と勝負レースの上限（1日3つ）を見直す。見直しには、その前の期間の記録だけを使う。

## 4. 実際に買い始める前の確かめ（フォワードテストはしない）

**フォワードテスト（これから行われるレースで、締め切り10分前のオッズを使って1か月ほど「買ったつもり」の記録をとり、それでも回収率が 100% を超えるかを確かめること）は、しない。** 利用者が「発走の直前に予想用のデータを取って予想する仕組みは作れない。当日にしか確かめられない」と判断した。そのための道具（keiba-yosou の `tools/フォワードテスト/` と、jvdata-store の発走前のオッズの取り直し）も消した。

これまでの検証（研究「回収率100超」など）は、どれも確定オッズを使っている。実際に買うときに見られるのは締め切り前のオッズで、確定までにオッズは動く。**確定オッズでの回収率は、上限の見積もりでしかない。** 過去の時系列オッズ（単複・馬連）で確かめた範囲では、この差は大きかった（研究「回収率100超」の [04 の 6-1](../../../research/回収率100超/docs/04-買い方.md)。発走の10分前のオッズでは 100% を大きく割り、1分前なら確定オッズとほぼ同じ）。

そこで、実際に買い始める前の確かめは、次のとおりとする。

1. **検証は確定オッズまで。** 採用の基準（回収率 100% 超え、開催日を単位にしたブートストラップの 90% の幅の下の端も 100% 超え）は、確定オッズで満たすことを求める。結果には、締め切り前のオッズでは下がりうることを書き添える。
2. **買い始めたあとは、買い目の記録（この文書の 3 の表1）で確かめる。** 買ったときのオッズと払戻が自動で残るので、実際のオッズでの回収率はここで分かる。線（1.25）は、記録を見てすぐには動かさず、半年ごとの見直し（この文書の 3）で、その前の期間の記録だけを使って決め直す。
