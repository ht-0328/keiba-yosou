# 04 モジュール2: 能力スコアの式

この文書で決めること: 出走馬の能力と適性を、どんな式で1つの点数（能力スコア）にするか。スピード指数・上がり3F・コース適性（左右・距離・芝ダ）・斤量をどう扱うか。

結論:

- **能力スコアは、既存の能力指数をそのまま使い、今回の斤量の分だけ直す。** 能力指数は、スピード指数（馬場差・斤量・ペースを補正した走ごとの速さ）を、新しさと今回の条件への近さで重み付けして平均したもので、**適性はこの重みの中にすでに入っている。**
- **上がり3F は能力スコアに足さない。** スピード指数は走破タイム全体から作るので、上がりの速さもすでに含んでいる。足すと二重に数える。上がり3F は展開（[05](05-race-development.md)）の末脚の材料に使う。
- **左右回りは別に足さない。** 研究で、競馬場・馬場などの細かい重みはほとんど効かなかったため。
- **能力スコアと、ほかの材料（展開・当日の情報・市場）との比重は、手で決めずにモデルに学ばせる。** 市場の確率を出発点にして補正する形（[07 の 1](07-expected-value.md#1-確率の作り方)）で、どれだけ効かせるかをデータから決める。

## 1. 能力スコアの式

### 走ごとのスピード指数（既存）

`tools/共通/ability/speed_figure.py` の式をそのまま使う。

```text
速さ（%）   = コースの基準 + 馬場差 − 100 × log(走破タイム) + 0.05 ×（斤量 − 55kg）− ペース補正
スピード指数 = 80 + 10 × 速さ
```

| 項 | 意味 | 決めた研究 |
|---|---|---|
| コースの基準 | 競馬場・芝ダ・距離ごとの、1勝クラスの古馬のふつうのタイム | 研究「能力指数の作り方」 |
| 馬場差 | その日・その競馬場・その芝ダで、タイムがどれだけ速かったか遅かったか | 同上（いちばん効く補正） |
| 斤量 | 1kg 重いと 0.05% 遅くなる、として 55kg にそろえる | 同上（よく言われる「1kg = 1馬身」より、ずっと小さい） |
| ペース補正 | 脚質 × ペースで得・損した分を引く（スローで逃げた走は下げる） | 同上と研究「展開の理論の検証」 |
| 大敗の切り上げ | レースでいちばん高い指数から 30点より下は、30点下にそろえる | 同上 |

80点が1勝クラスの古馬のふつうの走で、10点が 1% の速さの差（1600m でおよそ 1秒）に当たる。

### 能力指数（既存）

```text
能力指数 A = Σ（重み_j × スピード指数_j）÷ Σ 重み_j        … j は近8走（2年以内）
重み_j   = 0.7^(j走前 − 1) × 距離の近さ × 競馬場の近さ × 馬場の近さ
距離の近さ   = exp(−|今回の距離 − その走の距離| ÷ 800m)      … 800m 違えば 0.37倍
競馬場の近さ = 同じ競馬場なら 1、違えば 0.9
馬場の近さ   = 芝ダが違えば 0.4倍、馬場の組（良・稍重 か 重・不良）が違えば 0.8倍
```

**要件の「コース適性（左右・距離・芝/ダート）」は、この重みで入っている。** 例えば、1600m で速く 2400m で遅い馬が 1600m に出るなら、1600m に近い走が重くなり、能力指数は高く出る。左右回りは、同じ競馬場なら同じ回りなので、競馬場の近さに含まれる。

### 今回の斤量の直し（新しく足す）

スピード指数は 55kg にそろえてあるので、今回の斤量の分だけ引く。

```text
能力スコア A今回 = A − 0.5 ×（今回の斤量 − 55kg）
```

0.5 は、1kg あたり 0.05% × 1% あたり 10点 から出る。例（架空）: 能力指数 83.0 の馬が 58kg を背負うなら、83.0 − 1.5 = 81.5。

### レース内の比べ方（新しく足す）

同じ能力スコアでも、相手が強ければ勝てない。レースの中での位置を次の2つで表す。

```text
能力の偏差 z = （A今回 − レースの A今回 の平均）÷ レースの A今回 の標準偏差
能力の差 d = A今回 − レース内で2番目に高い A今回       … 1位の馬は2位との差、それ以外は負の値
```

例（架空）: 16頭の平均 78.0、標準偏差 3.0 で、A今回 = 84.0 なら z = 2.0。2番目が 82.5 なら d = 1.5。

### 能力スコアが出ない馬

| 馬 | 扱い |
|---|---|
| 過去の走が無い（新馬） | 欠損値。勝負レースにしない（[03 の 2](03-race-screening.md#勝負レースから外すレース)） |
| 初めての条件（初ダートなど） | 条件の近さの重みで、ほかの条件の走から出る。ただし当てにくい。血統（父の産駒のその条件の成績）で補う方法は、研究では未検討 |
| 障害レース | 出さない |

## 2. 上がり3Fと適性の扱い

| 要件の材料 | 扱い | 理由 |
|---|---|---|
| スピード指数 | 能力スコアの元 | |
| 上がり3F | 能力スコアには足さない。展開の「末脚」の材料と、補正の特徴量にする | スピード指数に含まれていて、足すと二重に数える。上がりが効くのは「どの展開で伸びるか」の方 |
| 距離・芝ダ・競馬場の適性 | 能力スコアの重みで入れる。距離・コース・馬場の適性の値（既存の列）も、補正の特徴量にする | 研究で「今回の条件に近い走ほど重く」がいちばん良かった |
| 左右回り | 別に足さない | 競馬場の近さに含まれる。細かい重みはほとんど効かなかった |
| 斤量 | 過去の走は 55kg にそろえ、今回の分だけ引く | 研究で決めた 1kg あたり 0.05% |

**分かっている限界:** 研究「能力指数の作り方」では、**適性の効きは小さく、馬の能力の大部分は基礎の速さで決まる**と分かっている。適性がはっきり効くのは、芝ダ替わりや大きな距離変更のときだけである（[research/能力指数の作り方 の 02](../../../research/能力指数の作り方/docs/02-結果の読み方.md)）。

## 3. 比重をどう決めるか

**要件は「どんな比重で1つのスコアに統合するか」を問うているが、この提案では比重を手で決めない。** 能力スコア・展開スコア・当日の補正を、市場の確率を補正するモデルの特徴量として渡し、どれをどれだけ効かせるかを学習で決める。

```text
logit(補正後の3着以内の確率) = logit(市場の3着以内の確率) + f(能力スコア, 能力の偏差, 能力の差, 適性, 上がり, 展開スコア, 当日の補正, …)
```

f は LightGBM と CatBoost の平均で、既存の全頭の予想と同じ作り（オッズから作った確率を出発点として渡す）である。式の全体は [07 の 1](07-expected-value.md#1-確率の作り方) を参照。

**手で決めない理由:**

- 手で「能力 50%・適性 30%・展開 20%」と決めても、その比が良いかを確かめる方法は、結局データで比べることになる。
- 能力の差の効き方は、クラス・頭数・距離で変わる。1つの比重では表せない。
- 市場（オッズ）は、能力をすでにかなり織り込んでいる。**大事なのは能力の高さではなく、市場が見落としている能力の差**で、それは市場の確率を出発点にした補正でしか測れない。

### 既存の何が悪かったか、どう直すか

研究「既存モデルの改善」で、能力指数を全頭の予想に足す実験をしたところ、良くなったのは 7区切り中3つだけで、採用しなかった（[research/既存モデルの改善 の 5](../../../research/既存モデルの改善/docs/02-結果の読み方.md)）。ただし、**そのとき足したのは、同じ条件の標準タイムと比べただけの簡単な版**（`research/既存モデルの改善/analysis/experiments/speed_figure_features.py`）で、馬場差・斤量・ペースの補正も、新しさと条件の近さの重みも入っていなかった。

研究「能力指数の作り方」で決めた作り方（この文書の 1）は、そのあとで作ったもので、**まだ予想に足して確かめていない。** Phase 3 で、同じ確かめ方（7区切りのうち5つ以上でログ損失が良くなるか）でやり直す。良くならなければ、能力スコアは補正に入れず、木曜の候補の絞り込みと、人が読む説明にだけ使う。

## 4. 能力スコアの使いどころ

| 使いどころ | 使い方 |
|---|---|
| 木曜の候補の絞り込み | オッズがまだ無いので、能力の偏差で人気になりそうな馬を見て、不安のある人気馬を探す（[03 の 2](03-race-screening.md#木曜の候補の絞り込み)） |
| 補正の特徴量 | 上の 3 の f に渡す |
| 人が読む説明 | 出馬表に、能力スコアとレース内の順位を並べる。既存の道具 `tools/能力指数/ability.py` がすでに出している |
