# 10 地方の推奨買目（1着・2着・3着を分けて市場に合わせる）

**この文書で決めること:** 地方競馬の発走前の通知（`tools/発走前の通知/notify.py --local`）に出す「推奨買目」を、どの券種を・どの線で・どのレースで・いくらで出すか。
組の確率の作り方と、年ごとの未見の評価は研究「地方の万馬券」の [docs/05](../../../research/地方の万馬券/docs/05-1着2着3着を分けて市場に合わせる.md) で決めたので、ここでは本番の決まりだけを書く。

- 状態: **決定（作った）。** 道具「地方の推奨買目」（`tools/地方の推奨買目/`）と、発走前の通知の地方で使っている。
- 利用者の要望: 「買い目は推奨買目として出す」「単勝と複勝しか出てこないから他の券種も出す」「参考買目はいらない」。推奨するのは検証で回収率 100% を超えた買い方だけにし、確かめていない買い目は出さない。

## 1. 何を出すか

| 項目 | 決まり |
|---|---|
| 推奨買目 | (a) 道具「地方の推奨買目」が選ぶ 単勝・複勝・枠連・ワイド・馬単・3連単 と、(b) 全頭の予想の ◎ の単勝（単勝の期待値 1.00 以上）と複勝（複勝の期待値 1.25 以上）。同じ券種・同じ組は1度だけ数える |
| 出さないもの | 参考の買い目。馬連・3連複（単体で 100% に届かない年があるので推奨しない） |
| 金額 | 1点 100円。点数の上限は付けない（上限を付けて期待値の高い順に残すと、高く出すぎた組に偏って下がる。docs/05） |
| 時点 | 当日の時点（発走 10分前の速報を取り込んだあと）だけ。前日の時点（馬体重が届く前）は出さない |
| 頭数 | 券種ごとに線を置く。単勝・枠連・ワイドは頭数を問わず出す。複勝・馬単・3連単は 8頭以上のレースだけ出す（頭数の少ないレースを入れると 100% を割る年がある）。線に届かない券種はその旨を添える |

## 2. (a) の決め方

| 券種 | 買う条件（組のオッズの帯・期待値の線） | 頭数 |
|---|---|---|
| 単勝 | 30倍以下・期待値 1.00 以上 | 問わない |
| 複勝 | 20倍以下・期待値 1.00 以上 | 8頭以上 |
| 枠連 | 全部・期待値 1.00 以上 | 問わない |
| ワイド | 50倍以下・期待値 1.00 以上 | 問わない |
| 馬単 | 50倍以下・期待値 1.05 以上 | 8頭以上 |
| 3連単 | 10〜200倍・期待値 1.05 以上 | 8頭以上 |

- **組の確率。** 1着・2着・3着を分けた条件つきロジット（`position_model.py`）。材料は、全頭の予想のモデルごとの 1着・3着以内の確率（LightGBM と CatBoost を分ける）、単勝の支持率、3連単・馬単・3連複の票から見た割合、複勝オッズの逆数。3連単の全部の組の確率 P(a) P(b | a) P(c | a, b) を足し合わせて、単勝・複勝・枠連・ワイド・馬単の組の確率にする（`ticket_probabilities.py`）。
- **期待値。** 組の確率 × その券種の最新のオッズ（複勝・ワイドは幅の真ん中）。発走 10分前のオッズ ≒ 確定オッズ を前提にする（[01 の 4](01-overview.md#まず知っておいてほしいこと何が問題か)）。
- **材料の取り方。** 全頭の予想は地方の予想モデルの `predict`（当日の時点。モデルごとの 1着の確率の列つき）、オッズは速報 0B30（全賭式）を取り込んだ元DB の最新の発表（`repository/announced_*`）、枠連に使う枠番は出走馬の表 `se`。

## 3. 係数

- 2024-01-01 以降の 11頭以上の確定レースの**全部**で当てはめる（評価は年の入れ替えだが、本番は全部の年）。全頭の予想は backtest の当日の予測（`reports/地方競馬の近走と適性から3着以内を予想/predictions-2024検証`。2023年前半までで学んだモデルの未見の予測）、オッズは確定オッズ。
- 置き場所は `reports/地方の推奨買目/係数.json`（Git 対象外。表は同じ場所の `係数.md`）。`tools/地方の推奨買目/fit.py` で作る。無ければ発走前の通知は地方を始めない。
- **当てはめ直すとき。** 全頭の予想のモデルを学び直したとき（予想の鋭さが変わる）。新しい年の確定レースがたまったとき。
- **前提の注意。** 本番の全頭の予想は最近まで学んだモデルで、係数は 2023年前半までのモデルの未見の予測で当てはめたもの。本番の予測のほうがわずかに鋭い見込みなので、係数は予想を控えめに見る側（過信しない方向）に寄る。

## 4. 通知での見せ方

- 文: 「推奨買目（1点 100円・合計 N点 N円）:」のあとに券種ごとに1行（例 `ワイド 7-10・8-12`）。11頭未満などの理由は最後に添える。1点も無ければ「推奨買目: なし（理由）」。
- 表の画像（[発走前の通知](../../../tools/README.md)）: 表の下の「推奨買目」の札のあとに同じ行と合計。長い行は「・」の区切りで折り返す。

## 5. 確かめたこと

- 年ごとの未見の評価（各年を残りの年で当てはめる）で、2 の 6券種は 2024〜2026年とも回収率 100% を超え、全券種をまとめても毎年超える。数値は `reports/地方の万馬券/全券種の買い方.md`（Git 対象外）。
- 頭数の線は、同じ評価を対象の頭数を変えて（11頭以上・10頭以上・8頭以上・5頭以上）流して決めた（`positions.py --min-heads`。数値は `reports/地方の万馬券/全券種の買い方-<N>頭以上.md`）。単勝・枠連・ワイドは 5頭以上（ほぼ全部のレース）でも 3年とも超える。複勝・馬単・3連単は頭数を問わないと 100% を割る年があり、8頭以上なら 3年とも超える。
- 本番の流れ（速報の取り込み → predict → 推奨買目 → 文と画像の投稿）は、終わったレースを `notify.py --local --rid` で通して確かめた。
