# 06 モジュール4: 当日の補正（トラックバイアス・馬体重・パドック）

この文書で決めること: 当日にしか分からない情報（馬場の偏り・馬体重・パドック）を、どう検知して数にし、確率の補正に入れるか。

結論:

- **トラックバイアスは、当日の先に終わったレースで「市場の見立てより来た馬が、内か外か・前か後ろか」を数えて検知する。** 前に試したやり方（上位馬の位置の平均）は効かなかったので、市場の見立てを差し引き、件数の少ない日は過去の傾向に寄せる形に作り直す。
- **馬体重は、増減の帯 × 前走からの間隔 × 馬齢ごとに「市場の見立てより来たか」の表で補正する。** 市場は発表された馬体重を見てオッズを動かすので、「大幅減なら割り引く」と決め打ちすると、市場がすでに割り引いた分を二重に引いてしまう。
- **パドックの気配は使わない。** JV-Data に無く、使うには人が手で記録する必要がある。利用者は「基本買うだけ」なので、手で記録する作業は仕組みに入れない（利用者の決定、2026-09-27）。
- 出走取消・騎手の変更・馬場状態の変更（速報 `0B14`）があれば、そのレースの予想を出し直す。

## 1. トラックバイアスの検知

### 前に試したやり方と、効かなかった理由

研究「既存モデルの改善」で、当日の先に終わったレースの3着以内の馬の「4コーナーの位置の平均」と「馬番の位置の平均」を特徴量に足したところ、良くなったのは 7区切り中2つだけで、採用しなかった（`research/既存モデルの改善/analysis/experiments/track_bias_features.py`）。効かなかった理由として、次の4つが考えられる（まだ確かめていない）。

| 理由 | 何が起きるか | 作り直しでの直し方 |
|---|---|---|
| 市場の見立てを差し引いていない | 強い人気馬がたまたま前や内にいただけでも、「前・内が有利」と数えてしまう | 市場から見た3着以内の確率との差（残差）で数える |
| 3着以内の馬だけを見ている | 前に行った馬が多いレースでは、上位の馬も前になる。負けた馬の位置を見ていない | 全部の馬の位置と残差の関係（傾き）で数える |
| 件数の揺れを抑えていない | 1〜2レースの結果だけで、極端な値が出る | 過去の同じ条件の傾向に寄せる（縮小推定） |
| 芝の内回りと外回りを分けていない | 同じ日に内回りと外回りがあると、違う馬場の傾向が混ざる | 競馬場 × 芝ダ × 内外回り（トラックコード）で分ける |

### 作り直したやり方

当日の、同じ競馬場 × 芝ダ × 内外回りで先に終わったレースの、全部の馬を使う。

```text
残差 e = 3着以内なら 1、そうでなければ 0 − 市場から見た3着以内の確率（確定オッズから）
内らしさ u = 0.5 −（馬番 − 1）÷（頭数 − 1）          … 最内 +0.5、大外 −0.5
前らしさ v = 0.5 − 4コーナーの位置                      … 先頭 +0.5、最後方 −0.5

当日の内の傾き b内 = Σ(e × u) ÷ Σ(u × u)            … 正なら内が有利
当日の前の傾き b前 = Σ(e × v) ÷ Σ(v × v)            … 正なら前が有利
```

件数の少ないうちは、過去の傾向に寄せる。

```text
使う傾き = （n × 当日の傾き + k × 過去の傾き）÷（n + k）
  n = 当日の先に終わったレースの数（前日の同じ競馬場のレースは 0.5 レースと数える）
  k = 4（初めの値。検証で決める）
  過去の傾き = 同じ競馬場 × 芝ダ × 内外回り × 開催の何日目 × 馬場状態の、過去の傾きの平均
```

開催の何日目を入れるのは、開幕週は内の芝が良く、開催の後半ほど内が荒れる、という違いを過去の傾きに持たせるためである。馬場状態がレースの途中で変わったら（雨など）、変わる前のレースは 0.5 レースと数える。

### 馬ごとの補正

```text
バイアスの補正 B = （使う内の傾き − いつもの内の傾き）× 内らしさ u + （使う前の傾き − いつもの前の傾き）× 予想の前らしさ
  予想の前らしさ = 0.5 − 展開予想の「④ 4コーナーの位置」の予想
  いつもの傾き   = 同じ競馬場 × 芝ダ × 内外回りの、全期間の傾きの平均
```

展開予想の ④ は [05-race-development.md](05-race-development.md) を参照。

**いつもの傾きを引く理由。** 前の傾きは、どの馬場でもどの日でも正（平均 +0.2 ほど）である。前に行けた馬は市場の見立てより来る、という恒常的な分で、
これはその日のバイアスではない（展開の予想と馬の力の材料がもう持っている）。引かずに B にすると、後ろから行く馬がどの日も「バイアス逆」になり、
過去の全出走で判定すると出走の2割が「バイアス逆・大」になった。引くと、B はその日と開催の進み具合で「いつもとどれだけ違うか」だけになる。
使う傾きそのものも特徴量として渡す（モデルが恒常的な分を別に使えるように）。

B の単位は、3着以内の確率のポイントである。B は補正の特徴量として f に渡し（[07 の 1](07-expected-value.md#1-確率の作り方)）、出馬表には「バイアス向き（B ≥ +0.02）」「バイアス逆（B ≤ −0.02）」と表示する。

例（架空）: 中山・芝・内回りで、当日3レースが終わった。当日の内の傾き +0.12、過去の内の傾き +0.04 なら、使う傾きは (3 × 0.12 + 4 × 0.04) ÷ 7 = +0.074。いつもの内の傾きが 0 なら、16頭立ての2番の馬は、内らしさ 0.5 − 1/15 = 0.43 なので、内の分の補正は +0.032。

### 作ったもの

`src/yosou/track_bias/`（傾き・過去の傾きの表・当日の傾き・使う傾き・補正・判定）と道具 `tools/トラックバイアス/track_bias.py`（1レースの出走馬ごとの B と判定、当日の傾きの本数・過去の傾き・使う傾き）。
レースごとの傾きと過去の傾きの表は 2011年からの全出走から作り、`reports/トラックバイアス/cache/` にとっておく（元DB が更新されたら作り直す。1分ほど）。
その日の終わったレース（速報の成績）は事実表に入るので、当日の先に終わったレースの傾きは元DB から読める。

| 決めたこと | 内容 |
|---|---|
| 時点 | 前日は、前の日（開催日の前日）の同じ馬場のレースだけを 0.5 本ずつ数える（その日のレースはまだ走っていない）。当日は、その日の先に終わったレース（馬場状態が対象と違えば 0.5）と前の日のレース。木曜は馬番が無いので作らない |
| 過去の傾きの寄せ方 | マス（同じ馬場 × 開催の何日目 × 馬場状態）の平均を、同じ馬場の全体の平均に 30 本ぶんの重みで寄せる。知らない馬場は 0 |
| 特徴量（まとまり U。5個） | 使う内の傾き・使う前の傾き（レースの値）、内の分・前の分・B（馬の値）。学習データには、レースの年ごとに「その年より前のレースだけで作った過去の傾きの表」と、そのレースより前に終わったレースの傾きで付ける（リークを防ぐ）。予測では、保存した展開のモデルの④と、元DB の傾きで付ける |
| 採否 | 研究「既存モデルの改善」の入口⑭（`material_check.py --material トラックバイアス`）で、前日・当日 × 3着以内・1着を7つの区切りで確かめた。前日の3着以内は確率の誤差の基準を満たしたが、印の成績で実際に買う複勝の回収率が大きく下がったので、**補正の材料としてはどのモデルにも足さない**（結果は [全頭の予想の設計書 15 の 19](../近走と適性から3着以内を予想/15-decisions.md#19-トラックバイアスの補正を足すか)）。道具の判定と危険な人気馬の理由「バイアス逆」に使う |

### 使うデータ

| データ | 元 |
|---|---|
| 当日の先に終わったレースの着順・4コーナーの通過順位 | 速報レース情報 `0B15`（当日は成績が入る） |
| 先に終わったレースの確定オッズ | 速報オッズ `0B30` の最後の断面、または確定後のレース成績 |
| 馬場状態の変更 | 速報開催情報 `0B14` |
| 過去の傾き | 過去のレース成績（`se` の通過順位と確定オッズ） |

**過去のデータだけで確かめられる。** 締め切り前のオッズを待たずに、Phase 3 のはじめに、7区切りで採用の基準（ログ損失が5つ以上で良くなる）を確かめる。

## 2. 馬体重の補正

**要件の問い「馬体重の大幅な増減を、どうペナルティ・ボーナスに変えるか」への答え: 過去の同じ条件の馬が、市場の見立てよりどれだけ来たかを表にして、その値を補正にする。**

```text
W(増減の帯, 間隔の帯, 馬齢の組) = そのマスの馬の、実際の3着以内率 − 市場から見た3着以内率の平均
```

| 分け方 | 帯 |
|---|---|
| 増減 | −10kg 以下 / −9〜−4kg / −3〜+3kg / +4〜+9kg / +10kg 以上 |
| 前走からの間隔 | 中3週以内 / 4〜9週 / 10週以上（休み明け） |
| 馬齢 | 2〜3歳 / 4歳以上 |

- 休み明けと若い馬を分けるのは、休み明けの増加や3歳の増加は、太め残りではなく回復や成長のことが多いからである。
- 件数の少ないマスは、同じ増減の帯の全体の値に寄せる。
- **決め打ちの減点にしない理由:** 馬体重は発走のおよそ1時間前に発表され、オッズはそれを見てから動く。確定オッズは発表後の値なので、「−12kg は割り引く」を市場はすでにある程度している。表を市場との差で作れば、市場が割り引き足りない分だけが残る。

例（架空）: 3歳、中2週、−12kg のマスが W = −0.03 なら、市場の見立てより3着以内の確率を 3ポイント下げる方向に補正する。

### 作ったもの

`src/yosou/weight_table/`（帯・表 W・割引・判定）と道具 `tools/馬体重の表/weight_table.py`（表 W と、1レースの出走馬ごとの体重の割引と判定）。表 W は 2011年からの全出走から作り、
`reports/馬体重の表/cache/` にとっておく。件数の少ないマスは同じ増減の帯の全体の値に 300 件ぶんの重みで寄せる。間隔の帯は、中3週以内 = 前走から 28日以内、4〜9週 = 29〜70日、10週以上 = 71日以上。
作った表では、どのマスも市場との差が ±0.02 の中に収まった（市場は発表された馬体重をほぼ織り込んでいる）。
特徴量（まとまり V。1個。体重の割引）は当日だけで、学習データにはレースの年ごとに「その年より前のレースだけで作った表 W」で付ける。採否は入口⑭（`material_check.py --material 馬体重の表`）で確かめる
（結果は [全頭の予想の設計書 15 の 20](../近走と適性から3着以内を予想/15-decisions.md#20-馬体重の表の割引を足すか)）。

**既存との関係:** 既存の全頭の予想は、当日の時点で馬体重と増減を特徴量にすでに入れている（速報の馬体重の反映は `src/yosou/shared/dataset/announced_weight_applier.py`）。つまり補正の f はすでに馬体重を使っている。W の表は、f に足す特徴量というより、**出馬表に「体重の割引」を人が読める形で出すため**と、f の効き方を確かめるために作る。

## 3. パドックの気配

**パドックの気配は、この仕組みでは使わない。** 利用者の決定（2026-09-27）。

- JV-Data にパドックの情報は無い。使うには、人がパドックを見て手で記録する必要がある。
- 利用者は「基本買うだけ」で、手で記録する作業は仕組みに入れない。
- 当日の馬の状態は、自動で取れる馬体重（この文書の 2）と、市場のオッズの動き（パドックを見た人の判断がオッズに入る）で見る。
