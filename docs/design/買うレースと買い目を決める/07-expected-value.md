# 07 モジュール5: 期待値の算出と、危険な人気馬・美味しい穴馬

この文書で決めること: 馬ごと・買い目ごとの当たる確率をどう作るか。期待値をどう計算し、どこに線を引くか。危険な人気馬と美味しい穴馬をどう判定するか。印をどう付けるか。

結論:

- **確率は、全券種のオッズから作った市場の確率を出発点にし、能力・展開・当日の補正を足して作る。** 実際には、**既存の全頭の予想（`src/yosou/form_aptitude_top3/`）の出発点を、単勝だけから作った基準から全券種から作った基準に直し、補正の特徴量を足す**形で作る。新しい予想を横に作らない。
- **期待値は、当たる確率 × 払戻の倍率。** 複勝は、発表の最低オッズに帯ごとの倍率を掛けて払戻を見積もる。
- **買う線は、複勝が 1.25（研究で決めた値。2026-09-28 に 1.20 から改めた。理由は研究の [04 の 4](../../../research/回収率100超/docs/04-買い方.md)）。** ほかの券種は、過去のデータで先に検証したが、どれも採用の基準を満たさなかったので、今は買わない（2026-09-27）。
- **危険な人気馬は、既存の人気馬の予想の「危険度」が人気帯の線以上の馬とする。** 展開不利・バイアス逆・体重の割引などは、判定の条件ではなく「理由」として表示する。**危険な人気馬がいることを、勝負レースを選ぶ理由にはしない。** 期待値の高い馬を買った結果として、危険な人気馬が買い目に入っていない、という順序にする（利用者の決定、2026-09-27）。
- **美味しい穴馬は、穴馬のうち複勝の期待値が 1.25 以上の馬とする。** 大穴でも単勝ではなく複勝で買う。

## 1. 確率の作り方

次の5つの手順を、この順に行う（分かれ道の無い一続きの手順なので、図にしない）。

| 手順 | 中身 | 使う既存のもの |
|---|---|---|
| 1. 市場の確率 q | 各券種のオッズの逆数を、レースで合計 1 にそろえ、その馬の入った買い目を足して、馬ごとの確率を取り出す。3連単は1・2・3着を別々に取り出す。単勝は、オッズの歪みを log(確率) の折れ線で直す | 研究「回収率100超」（`research/回収率100超/analysis/repository/pool_marginal_repository.py` ほか） |
| 2. 補正 f | logit(p) = logit(q) + f(材料)。f は LightGBM と CatBoost の平均で、q を出発点として渡して学習する | 全頭の予想の作り（基準を `init_score`・`baseline` として渡す） |
| 3. そろえ直す | レースの中で、3着以内の確率の合計を 3（5〜7頭立ては 2）にする。全馬のロジットに同じ値を足して合わせる | 研究「回収率100超」 |
| 4. 並びの確率 | 1着の確率から、Harville の式に Stern の補正を入れて、2着・3着と、馬連・ワイド・3連複などの買い目の確率を出す | 同上（`stern_probabilities.py`） |
| 5. 較正 | 券種 × オッズの帯ごとに、過去の「実際に当たった割合 ÷ 予想の平均」を掛けて直す | 研究「既存モデルの改善」（`ProbabilityCalibrator`） |

### 補正 f に渡す材料

| 材料 | 文書 | 今の扱い |
|---|---|---|
| 券種どうしの食い違い（単勝から見た確率と、3連単から見た確率の比など） | この文書 | 研究で 7区切りすべてで効いた。入れる |
| 全頭の予想の今の特徴量（近走・適性・騎手・血統・調教など） | [全頭の予想 の 09](../近走と適性から3着以内を予想/09-features.md) | 入っている |
| 能力スコア・能力の偏差・能力の差 | [04](04-ability-aptitude.md) | 確かめてから入れる |
| 展開スコア・ペースの確率・展開予想の位置と着順の確率 | [05](05-race-development.md) | 確かめてから入れる |
| トラックバイアスの補正・馬体重の表 | [06](06-realtime-adjustment.md) | 確かめてから入れる |

**材料は1つずつ足して確かめ、効いたものだけ残す。** 確かめ方は研究「既存モデルの改善」と同じで、7つの区切りのうち5つ以上で、足す前よりテスト期間のログ損失が小さくなれば残す。

### 時点ごとの違い

| 時点 | 出発点 q | 期待値 |
|---|---|---|
| 木曜 | オッズが無いので、既存の全頭の予想（木曜）の確率をそのまま使う | 出さない |
| 前日 | 前日発売のオッズ（取れる券種すべて） | 出す（仮の値。前日のオッズは当日に大きく動く） |
| 当日 | 締め切り前の全券種のオッズ（速報 `0B30`。予想を出す直前に取り込んだ断面） | 出す（買うのはこの値で決める） |

### 既存の全頭の予想で直すところ

既存の全頭の予想は、単勝オッズから作った3着以内の基準を出発点にしている（2026-09-24 の修正）。研究「回収率100超」で、**単勝オッズと3連複などのオッズが食い違うとき、正しいのは売上の大きい券種の方だった**と分かっている。そこで、出発点を全券種から作った基準に替え、券種どうしの食い違いを特徴量に足す。研究「既存モデルの改善」でも、券種ごとのオッズを足す実験だけが、7区切りすべてではっきり良くなった。締め切り前の全券種のオッズが取れるようになったので（jvdata-store の `0B30`）、この直しを本番に入れられる。

## 2. 期待値の式

| 券種 | 期待値 |
|---|---|
| 単勝 | P(1着) × 単勝オッズ |
| 複勝 | P(3着以内) × 見込みの払戻倍率 |
| ワイド | P(2頭とも3着以内) × 見込みの払戻倍率 |
| 馬連・馬単・3連複・3連単 | P(その組み合わせ) × オッズ |

```text
複勝・ワイドの見込みの払戻倍率 = 発表の最低オッズ × 帯ごとの倍率
  帯ごとの倍率 = 過去の、同じ最低オッズの帯での「実際の払戻 ÷ 最低オッズ」の平均
```

複勝とワイドは、発表のオッズが「最低〜最高」の幅でしか出ないので、最低オッズをそのまま使うと期待値を低く見積もりすぎる（研究で 2割ぶん直った。`src/yosou/shared/place_value/place_price_estimator.py`）。

### 買う線

| 券種 | 線 | 状態 |
|---|---|---|
| 複勝 | 1.25 | 研究「回収率100超」で決めた（前半の年だけで決まりどおりに選び、後半の年で確かめた）。確定オッズでの検証で、締め切り前のオッズでは下がりうる。締め切り前のオッズで確かめる仕組み（フォワードテスト）は作らないと決めた（2026-10-01。[08 の 4](08-bankroll-and-review.md#4-実際に買い始める前の確かめフォワードテストはしない)） |
| ワイド・単勝・馬連・馬単・3連複・3連単 | 無し（買わない） | 過去のデータで先に検証したが、どの券種も採用の基準を満たさなかった（2026-09-27。[08 の 2](08-bankroll-and-review.md#複勝以外の券種の検証過去のデータで先に確かめる)）。今は買わない |

**線を 1.00 にしない理由:** 確率にも払戻の見積もりにも誤差があり、締め切りのあとにもオッズは動く。その分の余裕として 0.20 を取っている。

例（架空）: 9番人気の馬の、補正後の3着以内の確率が 0.24。複勝の最低オッズが 4.8倍で、その帯の倍率が 1.12 なら、見込みの払戻倍率は 5.4倍、期待値は 0.24 × 5.4 = 1.29。線の 1.25 以上なので買う。

## 3. 危険な人気馬の判定

**要件の問い「危険な人気馬をあぶり出す具体的な閾値や条件は？」への答え: 次の2つを両方満たす馬を「危険な人気馬」とする。**

1. **人気馬である。** 13頭以下は1〜3番人気、14頭以上は1〜5番人気（既存の予想と同じ範囲）。
2. **危険度が、人気帯の線以上である。**

```text
危険度 = 予想の4着以下の確率 − 市場から見た4着以下の確率
線     = 人気帯（1番人気・2〜3番人気・4〜5番人気）ごとに、検証期間で決める
```

危険度と線は、既存の人気馬の予想（`src/yosou/favorites_out_of_top3/`、判定は `danger/danger_judge.py`）がすでに出している。線は、検証期間で「危険とした馬が、同じ人気帯の全体より実際に4着以下になりやすい」ように決める。研究「既存モデルの改善」では、直したあとの予想で、7区切りすべてで危険とした1番人気が全体より負けやすかった。

要件の例の形（「オッズは〇〇倍以下だが、〇〇が下位〇%」）で書くと、例えば次のようになる（数は架空）。

> 単勝 3.0倍以下の1番人気で、予想の4着以下の確率が、市場の見立てより 8ポイント以上高い。

### 理由の表示

危険と判定した馬には、なぜ危険かを並べて表示する。これらは判定の条件ではなく、人が読むための理由である（どれも補正 f の材料として、すでに危険度に入っている）。

| 理由 | 条件（初めの値） | 文書 |
|---|---|---|
| 券種どうしの食い違い | 単勝から見た3着以内の確率より、3連単から見た確率が低い | この文書の 1 |
| 展開不利 | 展開スコア D ≤ −0.02 | [05 の 2](05-race-development.md#2-展開スコア有利不利の判定) |
| バイアス逆 | バイアスの補正 B ≤ −0.02 | [06 の 1](06-realtime-adjustment.md#1-トラックバイアスの検知) |
| 体重の割引 | 馬体重の表 W ≤ −0.02 | [06 の 2](06-realtime-adjustment.md#2-馬体重の補正) |
| 能力で見劣る | 能力スコアがレース内で3位以下 | [04 の 1](04-ability-aptitude.md#1-能力スコアの式) |

### 危険な人気馬の使い方

| 使い方 | する・しない | 理由 |
|---|---|---|
| その馬を買い目に入れない（消） | する | 補正後の確率が下がるので、その馬を含む買い目は期待値が下がり、自然に外れる。消は表示のため |
| 危険な人気馬がいるレースを、勝負レースに選ぶ理由にする | **しない** | 研究「既存モデルの改善」で、1番人気を消したレースは、消さなかったレースより大きく負けた。消した馬が負ける割合は、ほかの馬で儲けを出せるほどには高くなかった |

**順序は「1番人気が危険だから買う」のではなく、「期待値の高い穴馬を見つけて買ったら、結果的に1番人気は買っていなかった」である。** 利用者の決定（2026-09-27。[09 の 3](09-decisions.md#3-危険な人気馬とレースの選び方)）。

- レースは見込みの利益で選ぶ（[03 の 2](03-race-screening.md#2-レースの点数)）。危険な人気馬がいるかどうかは、レースを選ぶ条件に入れない。
- 買い目は期待値で選ぶ。危険な1番人気は補正後の確率が下がっているので、その馬を含む買い目は期待値が線に届かず、結果として買い目に入らない。
- 「消」の印は、この結果を人が読めるように示すためのものである。消を先に決めて、そこから買い目を組み立てることはしない。

## 4. 美味しい穴馬の判定

**要件の問い「美味しい穴馬を見つける、オッズと独自スコアの比較の式は？」への答え: 次の2つを両方満たす馬を「美味しい穴馬」とする。**

1. **穴馬である。** 人気馬の範囲より下の人気。
2. **複勝の期待値が 1.25 以上である**（この文書の 2 の式）。

期待値 1.25 以上は、「補正後の確率が、市場の確率の 1.6倍ほど以上」と同じ意味になる。市場の確率どおりなら複勝の期待値はおよそ 0.8（控除率 20% の分）なので、1.25 に届くには、市場より 1.6倍ほど来ると見る必要があるからである。つまり、**オッズと独自の見立ての比較は、期待値の中に入っている。**

- **単勝では買わない。** 研究「回収率100超」で、大穴の単勝は回収率が控除率の水準を大きく下回り、大穴の複勝は 100% を超えた。穴は「勝つのを当てる」のではなく「3着に来るのを当てる」。
- **較正を必ず通す。** 研究「馬券の買い方の検証」で、既存の穴馬の予想の確率は、値として大きすぎたと分かっている。較正を通さずに期待値を出すと、穴馬を買いすぎる。
- 複数いるときは、期待値の高い順に並べる。

## 5. 印の付け方

利用者の考え方「馬を選んで印を付け、印にルールを付けて買う」に合わせ、次の印を付ける。印ごとの買い方は [08 の 2](08-bankroll-and-review.md#2-勝負レースの中の掛け金) を参照。

| 印 | 決め方 | 役割 |
|---|---|---|
| 消 | 危険な人気馬（この文書の 3） | 表示。期待値が下がっているので、結果として買い目に入らない |
| ◎ | 消を除いて、補正後の3着以内の確率が1位 | 軸（安心な馬）。ワイド・3連複の軸 |
| ○ | 同じく2位 | 相手 |
| ▲ | 同じく3位 | 相手 |
| △ | 同じく4〜5位 | 相手（3連複の3列目） |
| ☆ | 穴馬のうち、複勝の期待値が1位。1.25 以上のときだけ付ける | 美味しい穴馬。複勝で買う |
| 注 | 印の無い馬のうち、上げ下げ（logit(p) − logit(q)。市場より来ると見る度合い）が最も大きい馬 | 表示だけ。ワイドの相手の候補 |

既存の予想では、◎ の決め方が違う（展開予想は「1着の確率が1位」、研究「既存モデルの改善」は「単勝の期待値が1位」）。この提案では、**利用者の考え方「安心な馬は3連複の軸にする」に合わせて、3着以内の確率の1位を ◎ にする。**
