## 1. 土日以外の開催日の扱い

**決定: 月曜なども、土日と同じく最低1レース（ノルマ）を買う。** 開催日ごとに1レースを満たす。

関連: [03 の 3](03-race-screening.md#3-購入ポリシーを満たすレースの選び方)

## 2. 障害の重賞の扱い

**決定: 必ず買う重賞に入れない。** 必ず買うのは平地の G1・G2・G3 だけ。障害は能力指数も予想も無く、期待値が出せないため。

関連: [03 の 3](03-race-screening.md#3-購入ポリシーを満たすレースの選び方)、[02 の「重賞」](02-glossary.md#競馬とこの提案の用語)

## 3. 危険な人気馬とレースの選び方

**決定: 理由にしない。** 利用者の言葉で、「1番人気が危険だから買う」のではなく、「期待値の高い穴馬を見つけて買ったら、結果的に1番人気は買っていなかった」という順序にする。

- レースは見込みの利益で選び、危険な人気馬がいるかどうかは条件に入れない。
- 危険な人気馬は補正後の確率が下がっているので、その馬を含む買い目は期待値が線に届かず、結果として買い目に入らない。「消」の印は、その結果を示す表示である。
- 背景: 研究「既存モデルの改善」で、1番人気を消したレースは、消さなかったレースより大きく負けた。

関連: [07 の 3](07-expected-value.md#3-危険な人気馬の判定)

## 4. 検証の済んでいない券種の扱い

**決定: 早く検証する。** これからのレースの記録がたまるのを待たずに、研究「回収率100超」を広げて、過去のデータ（2019〜2026年）で券種ごとに確かめる。採用の基準を満たした券種だけ、複勝と一緒に買う券種にする。満たさなかった券種は買わない。

**検証の結果: 全券種のオッズから確率を作る買い方では、単勝・ワイド・馬連・馬単・3連複・3連単のどれも、採用の基準を満たさなかった。印のルールの買い目を、まだ見ていない年（2021〜2022年）で確かめ直すと、当日の予想で◎の期待値 1.00 以上のレースの ◎ の単勝と馬単（◎→○▲☆）だけが基準を満たした。買うのは、複勝と、その単勝・馬単である**（単勝・馬単は単勝・馬単用の財布から。[08 の 2「採用している券種（当日の単勝・馬単）」](08-bankroll-and-review.md#採用している券種当日の単勝馬単)）。**そのあと、利用者の「単勝・馬単・複勝以外の券種もちゃんと買える予想にして」「当たって儲かる予想なら何でもいい。任せる」を受けて、組ごとの期待値（市場とモデルを重みで合わせた組の確率 × オッズ）で組を選ぶ形を確かめ直し、当日の予想の馬連・馬単が、まだ見ていない 2019〜2020年で基準を満たした。続けて利用者の「全券種 100% を超える予想ができるまでやって」を受けて、ワイド・3連複・3連単の組の確率の重みを直前1年で推定し直す形にし、学習データを 2012年からに広げて新しく作った「まだ見ていない年」2016〜2018年で確かめたところ、ワイド・3連複・3連単が基準を満たした。同じ 2016〜2018年で、馬単は満たしたが馬連は届かなかったので、馬連は買うのをやめた。買うのは、当日の予想の組の期待値の馬単・ワイド・3連複・3連単である**（組の期待値用の財布から。[08 の 2「採用している券種（当日の予想の組の期待値の買い目）」](08-bankroll-and-review.md#採用している券種当日の予想の組の期待値の買い目)）。 堅い重賞のノルマ参加も、ワイドをやめて複勝だけにした（[03 の 4](03-race-screening.md#4-堅い重賞での買い方)）。

関連: [08 の 2「複勝以外の券種の検証」](08-bankroll-and-review.md#複勝以外の券種の検証過去のデータで先に確かめる)

## 5. 勝負用の財布の掛け金

**決定: 勝負レースの予算は、勝負用の財布の残高の 5%。** 残高が減れば掛け金も減り、破産しにくい。

- 5% は1レースの予算として扱い、最大3点の複勝に均等に分ける（1点は残高の 5% ÷ 3 ≒ 1.7%）。5% を1点にまとめると、ケリー基準のほぼ満額に当たり、資金の上下がとても大きくなるため。
- 2つの財布に最初に入れる額は、実際に買い始めるときに決める。

関連: [08 の 1](08-bankroll-and-review.md#1-予算の分け方)

## 6. 購入ポリシーを守る費用

**決定: 競馬を楽しむための「エンタメ税（参加費）」として受け入れる。** 勝負レース用の資金と、ポリシーで楽しむ用の資金を別の財布に分け、ポリシー用の資金が少しずつ減るのは想定内とする。

- ノルマ参加（重賞・日）は、ポリシー用の財布から出す。額は残高に対する割合で決めるので、財布が減っても購入ポリシーは続けられる。
- 払戻は買った財布に戻し、勝負用の財布からポリシー用の財布を補わない。
- 成績は財布ごとに数える。勝負用には回収率 100% 超えを求め、ポリシー用には減り方が見込みどおりかだけを見る。

関連: [08 の 1](08-bankroll-and-review.md#1-予算の分け方)

## 7. 勝負レースの1日の上限

平地の重賞以外で、1日に何レースまで勝負レースにするか。

**決定（おすすめどおり3レース）: 平地の重賞以外の勝負レースは、1日3レースまで。** 平地の重賞は、この上限の外で扱う
（[03 の 3](03-race-screening.md#3-購入ポリシーを満たすレースの選び方) の ① のとおり、期待値のある重賞は全部勝負レースにする）。

| 選び方 | 意味 |
|---|---|
| **① 3レース（決定）** | ルール集の「1日1〜3レースに絞る」と同じ。買うレースが増えるほど、期待値の見積もりの誤差で線を越えただけのレースが混ざる。締め切り前のオッズの記録がたまったら、検証で決め直す |
| ② 上限なし | 見込みの利益があるレースを全部買う。1日に使う額の上限（勝負用の残高の 20%）で止まる |

関連: [03 の 3](03-race-screening.md#3-購入ポリシーを満たすレースの選び方)

## 8. パドックの気配

**決定: 使わない。** JV-Data に無く、使うには人が手で記録する必要がある。利用者は「基本買うだけ」なので、手で記録する作業は仕組みに入れない。同じ理由で、回顧の不利も、JV-Data から自動で分かるものだけにした。

関連: [06 の 3](06-realtime-adjustment.md#3-パドックの気配)、[08 の 3](08-bankroll-and-review.md#3-回顧データの形)

## 9. 回顧データの置き場所

**決定: NotebookLM には上げない。** 人が後から NotebookLM で分析しないので、上げる手間は要らない。Python が自分で読み書きしやすいように、Git の対象外のローカルのフォルダ（`reports/回顧/`）に自動で保存する。

関連: [08 の 3](08-bankroll-and-review.md#3-回顧データの形)

## 10. 締め切り前のオッズでの確かめ

**決定: フォワードテストはしない。** 締め切り10分前のオッズで1か月ほどペーパーテスト（買ったつもりの記録）を回してから買い始める案もあったが、発走の直前に予想用のデータ（締め切り前の全券種のオッズ）を取って予想する仕組みは作れず、当日にしか確かめられないと利用者が判断した。そのための道具（keiba-yosou の `tools/フォワードテスト/` と、jvdata-store の発走前のオッズの取り直し）も消した。

- 検証は確定オッズまでとする。確定オッズでの回収率は上限の見積もりで、締め切り前のオッズでは下がりうることを、結果に書き添える（研究「回収率100超」の 04 の 6-1 に、過去の時系列オッズ（単複・馬連）での確かめがある）。
- 買う判断に使うオッズは、当日の予想を出す直前に jvdata-store の `jvstore realtime` で取り込んだ断面になる。
- 実際のオッズでの回収率は、買い始めたあとの買い目の記録で確かめる。

関連: [08 の 4](08-bankroll-and-review.md#4-実際に買い始める前の確かめフォワードテストはしない)

## 11. ◎ の決め方と期待度

◎ を3着以内の確率の1位で選ぶと、◎ の単勝回収率が 1番人気全体と変わらない（道具「印の成績」）。利用者から「◎ の単勝回収率を 100% 超えにする予想モデルにしてほしい」と頼まれ、◎ の付け方を聞いた。

**決定: 全レースで ◎ を付けるが、レースごとに期待度を付ける。期待度の高いレースで、まずは 100% 超えを目指す。**

期待度（高・低）をレースに添えて見せる形は、[16](#16-レースに添える目安を的中率と配当率にする) で的中率と配当率に替えた。◎ の単勝の期待値が 1.00 以上かどうかは、買い方の決まりの条件「◎の期待値 1.00 以上のレース」として残っている。

| 選び方 | 意味 |
|---|---|
| 届かないレースは ◎ なし | 単勝の期待値が線に届いたレースだけ ◎ を付ける。100% 超えを狙いやすいが、◎ の無いレースができる |
| **全レースに ◎ を付け、期待度を添える（決定）** | ◎ は単勝の期待値の1位で、いつも1頭いる。期待度（高・低）で、単勝を買うレースを選ぶ |
| ◎ は今のまま、別の印を足す | ◎ は3着以内の確率の1位のまま、単勝で買う馬に別の印を付ける |

このために、全頭の予想に「1着になる確率」を出すモデルを足した（[全頭の予想 の 15 の 14](../近走と適性から3着以内を予想/15-decisions.md#14-1着のモデルを足して--を単勝の期待値で選ぶ)）。印の決め方は [07 の 5](07-expected-value.md#5-印の付け方)、単勝の買い方は [08 の 2](08-bankroll-and-review.md#2-勝負レースの中の掛け金)、期待度の決め方と採用の基準・確かめた結果は [全頭の予想 の 16 の 6.](../近走と適性から3着以内を予想/16-evaluation.md#6--の単勝回収率の確かめの期待値の線)。

**期待度の線を固定にした決定。** はじめは「高」の線を区切りごとに検証期間で決める形で確かめたが、線が区切りごとに大きくばらつき、3つの区切りでは線が決まらなかった。
利用者の決定で、◎ と期待度は本番に入れ、線は 1.00 の固定（高・低の2段階）にした。◎の期待値 1.00 以上の ◎ の単勝回収率は 100% を超えたが 90% の幅が 100% をまたぎ、採用の基準を満たさなかったので、単勝は買わない（確かめ中）。

**◎ の候補を単勝 30倍以下に限る決定。** 本番で動かすと、3着以内の確率が最下位の大穴が期待値 1 をわずかに超えて ◎ になるレースがあった。候補の絞り方（オッズの上限・1着の確率の上位N頭）を過去のデータで比べ、
どれも採用の基準には届かないことを確かめたうえで、利用者が「単勝 30倍以下に限る」を選んだ（大穴の ◎ がほとんど無くなり、ばらつきが小さくなる。30倍以下の馬がいなければ1着の確率が1位）。理由は [07 の 5](07-expected-value.md#5-印の付け方)。

## 12. 3連複・3連単の軸と買い目

利用者の依頼: 「3連複・3連単の買い方を、◎ の1頭軸から印に流す形にする。3連単は ◎ 1頭軸のマルチで組み、期待値の高い買い目だけを買う。◎ 軸と軸馬の両パターンで出す」。買い方の中身（流す相手・組の期待値の出し方・線・1点の額）は利用者が任せた。

**決定: 前からの3連複（◎ 軸 − ○▲☆ − ○▲△☆）と、道具が出していた3連単（◎→○▲☆→○▲△☆）は、その券種の買い目として必ず出す（利用者の決定。3連単も設計書の買い目の表に入れた）。そのうえで、3連複は軸の1頭から ○▲△☆ への流し（最大 15点）、3連単は軸の1頭から ○▲△☆ へのマルチ（最大 90点）のうち組の期待値が 1.0 以上の買い目を足す。軸は「◎軸」と「軸馬」（◎○▲ のうち3着以内の確率が1位）の2パターンを道具「印の成績」で出して比べる。合計は「元の買い目だけ」と、それに ◎軸・軸馬の買い目を足したものの3つ。**

| 決めること | 決めたこと | 理由 |
|---|---|---|
| 流す相手 | ○▲△☆（注は入れない） | 注は表示だけの印で、買い目の相手には使わない（[07 の 5](07-expected-value.md#5-印の付け方)） |
| 組の期待値 | 市場が見た組の確率（払戻率 ÷ オッズ）× 3頭の「モデル ÷ 市場」の比の積（[07 の 2](07-expected-value.md#組み合わせの券種の確率馬連馬単ワイド3連複3連単)） | 1着の確率から Harville の式で組の確率を作ると、人気薄の組を見積もりすぎて勝てなかった（研究「回収率100超」の 05）。その研究が「次に試す」とした作り |
| 線 | 1.0 で固定 | 検証期間で線を決めると、数が足りずに区切りごとにばらつく（11 と同じ）。線を動かしたときの成績は、道具の表9 に参考として出す |
| 1点の額 | 3連複 0.3単位・3連単 0.1単位（据え置き） | 実際に買う券種が決まるまで変えない |
| 3連複の期待値 | 流しは全点を買う。期待値で絞った場合は道具で一緒に出す | 利用者の依頼は「3連複は流し、3連単は期待値で絞る」 |

**結果（道具「印の成績」。前日・当日のモデル、確定オッズ）:** 組の期待値で絞ると、絞らない全点より回収率は上がる（前日・当日、◎軸・軸馬のどれでも）。ただし、どの買い方も採用の基準（90% の幅の下の端が 100% 超え）には届かず、◎軸と軸馬のどちらが良いかは前日と当日で逆になる。線を上げると当たりが減って振れが大きくなるだけ（表9）。前からの3連複・3連単の行は前と同じ値で、道具の作り替えで値が変わっていないことの確かめになる。今は買わない。

買い目の決まりは [08 の 2](08-bankroll-and-review.md#2-勝負レースの中の掛け金)、結果の読み方は [全頭の予想 の 16 の 6.](../近走と適性から3着以内を予想/16-evaluation.md#6--の単勝回収率の確かめの期待値の線)。数値は Git の対象外の `reports/印の成績/`。

## 13. ☆ を毎レース付けるか

利用者の指摘: 「☆マークの印が予想に出てきてない」。☆ は「穴馬のうち複勝の期待値が1位で、1.25 以上のときだけ」付けていたので、直近の予想ではオッズのある 74 レース中 11 レースにしか付かなかった。利用者は ☆ を毎レース付けることを選んだ。

**決定: ☆ は、印の付いていない穴馬（人気馬の範囲より下の人気）のうち複勝の期待値が1位の馬に、毎レース付ける。ただし買い目の相手（ワイド・馬連・馬単・3連複・3連単）に入れる ☆ は、今までどおり複勝の期待値が 1.25 以上のものだけにし、線に届かない ☆ は表示だけにする。** 印を付ける順は、線以上の ☆ → 注 → （線以上の ☆ がいないレースだけ）残りの穴馬に表示だけの ☆。こうすると 注 の選び方と全券種の買い目が、表示だけの ☆ を足す前と同じになる（[07 の 5](07-expected-value.md#5-印の付け方)）。

**買い目の相手にも毎回入れる案を退けた理由（道具「印の成績」。2023〜2026年のテスト期間 12,466 レース、確定オッズ）:** 実際に買う単勝・複勝は変わらず、当日・◎の期待値 1.00 以上の馬単（◎→○▲☆）は 116.1% → 118.8% と少し上がった（ただし 90% の幅の下の端が 101.9% → 98.6% と 100% を割った）。一方、☆ を相手に入れる参考の券種は、点数が増えて多くが下がった。◎の期待値 1.00 以上で、ワイドは当日 109.0% → 95.7%・前日 109.8% → 88.1%、元の3連複は当日 97.9% → 88.8%・前日 100.6% → 88.8%、元の3連単は当日 119.7% → 102.4%・前日 104.2% → 91.5%、合計（元の買い目だけ）は当日 108.0% → 100.1%・前日 107.4% → 96.2%。毎回付ける ☆ の馬は単勝回収率 98.6%・複勝回収率 90.9%（当日）で、同じ人気の馬全体（70.4%・68.7%）より高いが、線以上の ☆（単勝 298.5%・複勝 167.8%）には遠く、相手に入れると買い目を薄めた。

数値は Git の対象外の `reports/印の成績/☆を毎回/`（元 = 線以上のときだけ ☆、新 = ☆ を毎回相手にも入れた形）。

## 14. 組の期待値の買い方を、レースの種類ごとに変えるか

利用者の依頼: 「的中率と回収率と勝負数を上げてほしい」「全部同じ方法で予想してるならレースの種類ごとに予想方法を変えるとかしてほしい。そのためのモデルを分けたりしていい」「やれることは全部やって」。

**決定: 組の確率の重み・買う決まり（線・上限・点数）・馬の予想モデルは、芝ダ・クラス・頭数・ハンデ戦の種類ごとに変えない。そのうえで、券種ごとに向いたレースの中身で買うレースを絞る（ワイドは1番人気の単勝オッズが 2.9倍以上。ほかの券種の今の絞り方は 15）。**

研究「レースの種類ごとの買い方」で、芝ダ・クラス・頭数・ハンデ戦ごとに次を試し、各年について「その年より前だけで選び、その年で数える」形（ウォークフォワード）で 2018〜2026年を数えた。
採用の基準（回収率と幅の下の端が 100% 超え、回収率・勝負したレース・的中率がどれも今の買い方以上、前半・後半とも回収率が今の買い方以上、100% 超えの年が5年以上）は、結果を見る前に決めた。

| 試したこと | 結果 |
|---|---|
| 組の確率の重みに種類ごとの差を足す | 学習に使っていない区切りでは、差を足すほど当たり具合が悪くなった |
| 組の確率の材料を足す（人気薄の曲がり・穴馬の比・◎ を含むか） | 当たり具合はほぼ変わらない |
| 買う決まりを芝ダ × クラスの種類ごとに選ぶ | 年ごとに選ばれる決まりが入れ替わり、回収率はどの券種でも今の買い方に届かない |
| 上のクラス・ハンデ戦の馬の予想モデルを分ける／重量種別を足す | 分けると誤差が大きくなり、足しても変わらない |

どの券種でも、勝負したレースか的中率を上げる案はあったが、そのとき回収率が下がった。3つを同時に上げる案は無かった。
また、今の買い方の決まりを選んだのと同じ選び方で年ごとに選び直すと、馬単以外は回収率が 100% 前後まで下がった。今の買い方の成績には、決まりを後から選んだぶんの甘さが入っている。

続けて、利用者の「券種ごとに適したレースがあるんじゃない？とにかく全券種100%超えるように頑張って」を受けて、券種ごとに向いたレースの中身（1番人気の強さ・危険な人気馬・頭数・◎ の単勝の期待値 など）で絞る案を確かめた。
2016〜2018年だけで券種ごとの絞り方の仮説を立て、2019〜2026年で確かめたところ、馬単・ワイド・3連単で、絞らないときより回収率が高く、幅の下の端も 100% を超えた（基準は結果を見る前に決めた）。
3連複は絞ったほうが良い年が半分にとどまり、馬連は絞ると下がった。決まりと絞り方を年ごとに選び直す案は、どの券種も基準を満たさなかった。
絞り方は回収率の高いレースを選ぶもので、的中率はほぼ変わらない（3連単は少し下がる）。1開催日に買うレースは、馬単・3連単で4割ほど、ワイドで半分ほど減る。

研究の手順と結果は `research/レースの種類ごとの買い方/docs/`（絞り方は docs/03）、数値は Git の対象外の `reports/レースの種類ごとの買い方/`。

## 15. 全券種で回収率 100% を超え、的中率も上がる買い方にするか

利用者の依頼: 「全券種の回収率が100%を超えて、的中率も上がる方法を見つかるまでやって。全券種だから、後単勝、複勝、枠連もだよ」「満たせるまで、いろんな方法試してください。やり方は任せます」「券種ごとにレース変えるのもありなんじゃないの」。

**決定: 次の買い方にする（08 の 2）。ワイドは基準を満たす買い方が見つからなかったので、14 の絞り方のまま変えない。**

| 券種 | 買い方 |
|---|---|
| 単勝（期待値） | 1番人気の単勝オッズが 2.3倍以上のレースで、単勝の期待値 1.0 以上・単勝 5倍以下の馬を1点（◎ の単勝の代わり） |
| 複勝 | ◎の期待値 1.00 以上・16頭以上のレースで、複勝の期待値 1.1 以上・複勝の最低オッズ 5倍以下の馬を3点まで |
| 枠連 | ◎の期待値 1.00 以上で、市場の勝率の上位3頭の和が 0.6231 未満のレースで、組の期待値 1.1 以上・300倍以下の枠の組を全部（新しく買う） |
| 馬連 | ◎の期待値 1.00 以上のレースの ◎ を含む組・組の期待値 1.1 以上・30倍以下・3点まで・1番人気が 1.9倍未満（新しく買う） |
| 馬単 | 2モデル一致で市場の勝率の上位3頭の和が 0.6752 以上のレースで、組の期待値 1.0 以上・30倍以下の組を1点 |
| 3連複 | ◎ を含む組・組の期待値 1.2 以上・1,000倍以下・5点まで・危険な人気馬がいないレース |
| 3連単 | ◎の期待値 1.00 以上で15頭以上のレースの、◎ が1着の組・組の期待値 1.0 以上・300倍以下を全部 |

研究「レースの種類ごとの買い方」の docs/04（手順6）で、券種ごとに、決まり（対象・線・上限・点数）と買うレースの絞り方（レースの中身の帯）の組み合わせから、
2016年〜前の年だけで「的中率が前の買い方の 1.1倍以上・回収率 110% 以上」の中から回収率の 90% の幅の下の端がいちばん高いものを選び、2019〜2026年で確かめた。
基準（回収率と幅の下の端が 100% 超え、的中率が前の買い方より高い、100% 超えの年が8年のうち5年以上）は、それぞれの確かめの前に文書にした。

- 満たさなかった券種は作り方を変えて確かめ直した（8回）。1回目に複勝・枠連・3連単、2回目に単勝、3回目に馬連、6回目に馬単・3連複が満たした。回を重ねて満たした券種ほど、たまたま満たした見込みが高い。
- 枠連は、枠連の値段と馬連の値段のずれに重みが付く（枠連の市場の重みがマイナス）。馬連の組の確率のもとを枠の組に足し合わせて組の確率を作る（07 の 2）。
- 的中率は上がるが、回収率は前の買い方より下がる券種が多い（単勝・複勝など）。前の買い方の数字は、決まりを後から選んだぶん甘く出ている。
- ワイドは、的中率を上げる方向では、どの作り方でも回収率の幅の下の端が 100% を割った。

研究の手順と結果は `research/レースの種類ごとの買い方/docs/04-全券種で回収率と的中率.md`、数値は Git の対象外の `reports/レースの種類ごとの買い方/`

## 16. レースに添える目安を的中率と配当率にする

11 で、レースごとに期待度（高・低。◎ の単勝の期待値が 1.00 以上なら高）を添えて見せていた。利用者から「全レースを買う前提で、何をもって期待度を付けているのか分からないので、的中率と配当率の2つを出し、S・A・B・C にして」と頼まれた。

**決定: レースに添える目安は、的中率（◎ が3着以内に来る確率）と配当率（配当が中荒れ以上になる確率。荒れ具合の予想の4券種の平均）の2つにし、どちらも 0〜100% の値と等級（S 75% 以上・A 50% 以上・B 25% 以上・C 25% 未満）で出す。期待度（高・低）は表示しない。**

| 決めること | 決めた内容 |
|---|---|
| 的中率 | ◎ の3着以内の確率をそのまま使う。全頭の予想の確率は帯ごとに実際の割合と合っているので、新しいモデルは作らない |
| 配当率 | 荒れ具合の予想の「中荒れ以上の確率」の平均（03 の 1 の波乱度 U と同じ値）。配当の大きさを券種1つで見ないため、4券種の平均にする。学習済みモデルが無い・オッズがそろわないレースは「なし」 |
| 等級の線 | 利用者の指定（S = 100〜75・A = 75〜50・B = 50〜25・C = 25〜0）。下の線を含む |
| 買い方の決まり | 変えない。「◎の期待値 1.00 以上」と呼んでいた条件は、中身をそのまま「◎の期待値 1.00 以上のレース」と書く（買い目と金額は同じ） |
| 確かめ | 道具「印の成績」の表13 で、的中率の等級ごとの ◎ の実際の複勝率が等級の線の中に収まるかを、モデルを直すたびに見る。配当率は、荒れ具合の予想の学習の記録（中荒れ以上の確率のしきい値ごとの、実際に中荒れ以上だった割合）で読み方を確かめた |

中身は [03 の 5](03-race-screening.md#5-レースごとの目安的中率と配当率)。。
