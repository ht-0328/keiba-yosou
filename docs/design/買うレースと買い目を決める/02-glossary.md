# 02 用語の意味

この提案に出てくる言葉のうち、分かりにくいものの意味をまとめた。競馬と統計・機械学習で普通に使う用語は、そのまま使う。
既存の予想の用語（特徴量・目的変数・リークなど）は [近走と適性から3着以内を予想 の 02](../近走と適性から3着以内を予想/02-glossary.md) を参照。

## お金と確率の用語

| 用語 | 意味 | この提案では（架空の例） |
|---|---|---|
| 期待値 | 馬券1円あたり、平均でいくら戻るか。当たる確率 × 払戻の倍率 | 3着以内の確率 0.30、複勝 4.5倍なら 1.35 |
| 回収率 | 払戻の合計 ÷ 買った金額の合計 | 10万円買って 11万円戻れば 110% |
| 控除率 | 売上のうち、払い戻されずに引かれる割合。券種で違う | 複勝は 20%、3連単は 27.5% |
| 市場の確率 | オッズから逆算した、馬券を買う人たち全体が見ている確率 | 単勝 5.0倍の馬の勝率はおよそ 0.16（控除率の分をそろえたあと） |
| 券種のプール | 1つの券種の売上の全体。大きいほど多くの人の見立てが集まる | 3連単のプールは、単勝のプールよりずっと大きい |
| 補正（上げ下げ） | 市場の確率を、能力・展開・当日の情報で上げたり下げたりすること。ロジットの足し算で行う | 市場 0.20 → 補正後 0.24 |
| ロジット | 確率 p を log(p ÷ (1 − p)) に直した値。足し算で上げ下げしても、確率が 0〜1 からはみ出さない | p = 0.5 なら 0 |
| 較正 | 予想の確率を、実際に当たった割合に合わせて直すこと | 予想 0.10 の買い目が実際には 0.07 しか当たらないなら、0.7倍に直す |
| Harville の式 | 1頭ずつの勝率から、2着・3着まで含めた並びの確率を出す式 | 勝率 0.4 と 0.2 の馬が 1・2着に来る確率 |
| Stern の補正 | Harville の式が2着・3着の確率をずらす癖を直す補正 | 研究「回収率100超」で使った |
| 確定オッズ | 発売の締め切りのあとに決まる最終のオッズ | 過去の検証は、これを使った |
| 締め切り前のオッズ | 発売中に発表されるオッズ。実際に買うときに見られるのはこちら | jvdata-store の速報 `0B30`（全券種）。買う判断には締め切り10分前の断面を使う |
| 見込みの利益 | 買う買い目について、(期待値 − 1) × 掛け金 を足した値 | 期待値 1.30 の買い目に 1,000円なら 300円 |
| トリガミ | 当たっても、そのレースに使った金額より少なくしか戻らないこと | 1,000円使って、当たりが 800円 |
| ケリー基準 | 期待値と確率から、資金の何割を賭けると資金が最も速く増えるかを出す式 | この提案では上限の目安にだけ使う |
| ドローダウン | 資金の山から谷までの下がり幅 | 12万円から 9万円まで下がれば 3万円 |
| ウォークフォワード | 過去で学んで、その次の期間で確かめる、を期間をずらしながらくり返す検証 | 2019〜2022年で学んで 2023年で確かめる |
| 縮小推定 | 件数の少ない集計値を、全体の平均の方へ引き寄せて、揺れを小さくすること | 当日2レースだけの傾向を、過去の同じコースの傾向に半分寄せる |

## 競馬とこの提案の用語

| 用語 | 意味 | この提案では（架空の例） |
|---|---|---|
| 人気馬・穴馬 | 13頭以下は 1〜3番人気、14頭以上は 1〜5番人気が人気馬。それより下が穴馬。既存の予想と同じ | 16頭立ての7番人気は穴馬 |
| 重賞 | グレードが G1・G2・G3 のレース。JV-Data のレース詳細（`ra`）のグレードコードが A・B・C | 必ず買うのは平地の重賞だけ。障害の重賞（F・G・H）は入れない |
| 荒れ具合 | 払戻の額で分けた4段階（固い・中荒れ・大荒れ・超荒れ）。券種ごとに線がある | 線は [荒れ具合の予想 の 10](../レースの荒れ具合を4段階で予想/10-target.md) にだけ書いてある |
| 中荒れ以上の確率 | 荒れ具合の予想が出す、固い以外の3段階の確率の合計 | 3連複が中荒れ以上になる確率 0.45 |
| 勝負レース | 期待値の線を超える買い目があり、見送りの条件に当たらないので、自分から選んで買うレース | 1日に3つまで |
| ノルマ参加 | 期待値の線を超える買い目は無いが、購入ポリシーを守るために買うレース。重賞と、勝負レースの無い日の1レース | ポリシー用の財布から出す |
| 勝負用の財布 | 勝負レースに使う資金。回収率 100% 超えを狙う | 勝負レースの予算 = 残高の 5% |
| ポリシー用の財布 | ノルマ参加に使う資金。競馬を楽しむための参加費（エンタメ税）と割り切り、減るのは想定内とする | ノルマ参加（重賞）は残高の 3% |
| ペーパーテスト | 実際には買わずに、買ったつもりで買い目と金額を記録し、あとで確定の払戻で精算すること | この提案の「記録だけ」 |
| フォワードテスト | これから行われるレースで、本番と同じ手順・同じ時刻のオッズを使ってペーパーテストをし、過去のデータでの検証どおりの成績になるかを確かめること | しないと決めた（2026-10-01。[09 の 10](09-decisions.md#10-締め切り前のオッズでの確かめ)） |
| 能力スコア | 過去の走のスピード指数を、新しさと今回の条件への近さで重み付けした平均。既存の「能力指数」 | 82.5 点（80 が1勝クラスの古馬のふつうの走） |
| 先頭率の合計 | 出走馬全員の、近5走で最初のコーナーを先頭で回った割合を足した値。逃げたい馬がどれだけいるか | 先頭率 0.6 と 0.4 の2頭と、0 の 14頭なら 1.0 |
| 展開スコア | その馬の脚質とペースの組み合わせが、過去に市場の見立てよりどれだけ走ったか | +0.02（3着以内の確率が市場より 2ポイント高い） |
| トラックバイアス | その日の馬場で、内の馬・外の馬、前の馬・後ろの馬のどちらが得をしているかの偏り | 「内の前が残る」日 |
| 危険度 | 人気馬の4着以下の確率 − 市場から見た4着以下の確率。既存の人気馬の予想が出す | 0.42 − 0.33 = 0.09 |
| 回顧ノート | レースのあとに、馬ごとの不利や見直しの要否を記録した表 | 「出遅れ・大・次走で見直す」 |
