# 05 モジュール3: ペースの予測と展開スコア

この文書で決めること: 枠順と脚質から、レースのペース（ハイ・平均・スロー）をどう予測するか。どの位置（脚質 × 枠）の馬が展開で有利・不利になるかを、どう判定するか。

結論:

- **展開の予測は、既存の展開予想（`src/yosou/race_development/`）をそのまま使う。** 前半（先頭の馬・序盤の位置・前半のペース）・後半（4コーナーの位置・上がりの速さ・後半のペース）・着順の7つを予想するもので、枠や相手の脚質も特徴量に入っている。
- **「逃げ馬が何頭ならハイペース」という頭数の線は決めない。** 研究で、逃げたい馬が多いレースでもハイになるのは半分ほどで、逃げたい馬がいなくてもハイになるレースがあると分かっている。ペースは線で決めず、確率（ハイ 0.45・平均 0.38・スロー 0.17 のように）で扱う。
- **有利・不利は「脚質 × ペース × 競馬場」ごとに、過去に市場の見立てよりどれだけ3着以内に来たかの表で決める。** この表とペースの確率・位置の確率から、馬ごとの「展開スコア」を出す。市場との差で数えるので、そのまま期待値の元になる。
- **研究で確かめた理論に合わせる:** 前にいる馬はペースに関係なく有利で、ペースはその大きさを変えるだけ。スローなら逃げの得が大きく、ハイなら逃げの得が消える。「ハイなら差しが有利」は言い過ぎ。

## 1. ペースの予測

### 使う予想

既存の展開予想の「③ 前半のペース」が、レースごとにハイ・平均・スローの確率と、前半タイムの秒数を出す（[展開から着順を予想 の 01](../展開から着順を予想/01-overview.md)）。ペースは、前半タイムを、同じ競馬場・コース・距離・馬場状態の基準と比べた z で分けている。

主な材料は次のとおりで、どれもすでに特徴量に入っている。

| 材料 | 意味 | なぜ効くか |
|---|---|---|
| 先頭率の合計 | 出走馬全員の、近5走で最初のコーナーを先頭で回った割合の合計 | 逃げたい馬の数の数え方として、研究でいちばん当たった |
| 先団率が高い馬の数 | 最初のコーナーで前にいることが多い馬の数 | 先頭を取れなくても、前を争う馬が多いと速くなる |
| 先頭率の1位と2位の差 | 先頭を争う馬がいるか | 差が小さいと、2頭が競り合いやすい |
| 枠と、内の馬の脚質 | 逃げたい馬の内に、先行する馬がいるか | 外枠の逃げ馬は、先頭を取るまでに脚を使う |
| コース | 競馬場・芝ダ・距離 | 最初のコーナーまでの距離で、先頭争いの長さが変わる |

### 要件の問い「逃げ馬が何頭いればハイペースか」への答え

**頭数の線では決めない。** 研究「展開の理論の検証」で、次のことが分かっている（[research/展開の理論の検証 の 02](../../../research/展開の理論の検証/docs/02-結果の読み方.md)）。

- 逃げたい馬が多いほどハイが増え、スローが減る。**向きは正しい。**
- ただし、逃げたい馬が多いレースでもハイになるのは半分ほどで、逃げたい馬がいなくてもハイになるレースがある。**外れが多い。**

「2頭以上ならハイ」と決めて買うと、半分のレースで展開を読み違える。そこで、ペースは確率のまま次の展開スコアに渡し、読み違えの分を確率で薄める。

人が出馬表を読むときの目安としては、次の見方を添える（買う判断には使わない）。逃げたい馬は、先頭率 0.4 以上の馬とする。

| 逃げたい馬 | 読み方 |
|---|---|
| 0頭 | スローに寄りやすい。ただし押し出されて誰かが逃げ、ハイになることもある |
| 1頭 | 単騎で逃げやすく、スローから平均に寄りやすい |
| 2頭以上 | ハイに寄りやすい。ただし片方が控えれば平均以下になる |

## 2. 展開スコア（有利・不利の判定）

### 表: 脚質 × ペース × 競馬場ごとの、市場との差

過去のレースから、次の値を数えた表 G を作る。

```text
G(脚質 s, ペース p, 競馬場と芝ダ c) = そのマスの馬の、実際の3着以内率 − 市場から見た3着以内率の平均
```

- 脚質は、レース前に分かる脚質（近走の先頭率と位置）で分ける。結果の脚質で分けると、「その日に前に行けた馬はもともと調子が良かった」分が混ざって大きく出すぎる（研究で確かめた）。
- 逃げ・先行・差し・追込の4つを別々に数える。逃げと先行では、ペースの影響がまるで違うからである。
- ペースは、結果のペース（前半タイムの z）で分ける。
- 件数の少ないマスは、同じ脚質 × ペースの全競馬場の値に寄せる（縮小推定）。
- **市場との差で数えるので、「強い馬がたまたま前にいた」分は差し引かれている。** 研究では、市場との差で見ても効き目が残り、1〜3番人気でむしろ大きかった。

表 G の例（架空。東京・芝）:

| 脚質 | ハイ | 平均 | スロー |
|---|---|---|---|
| 逃げ | +0.01 | +0.06 | +0.10 |
| 先行 | +0.02 | +0.03 | +0.04 |
| 差し | 0.00 | −0.02 | −0.03 |
| 追込 | −0.01 | −0.04 | −0.06 |

研究の結論どおり、どのペースでも前が後ろより有利で、スローほどその差が大きい。ハイでは、逃げの得が消え、差しが市場並み（0）に戻る。実際の値は Phase 3 で数えて、Git の対象外の `reports/` に置く。

### 馬ごとの展開スコア

```text
展開スコア D = Σ_ペース P(ペース) × Σ_脚質 P(その馬がその脚質の位置を取る) × G(脚質, ペース, 競馬場と芝ダ)
```

- P(ペース) は、1 の「③ 前半のペース」の確率。
- P(脚質の位置) は、既存の展開予想の ① と ② から作る。逃げ = ① 先頭になる確率、先行 = ② 先団の確率 − 逃げ、差し = ② 中団の確率、追込 = ② 後方の確率。
- D の単位は、3着以内の確率のポイント（+0.02 は、市場の見立てより 2ポイント来やすい）。

例（架空）: 東京・芝、ペースはハイ 0.45・平均 0.38・スロー 0.17。ある馬は、逃げ 0.31・先行 0.41・差し 0.21・追込 0.07。

| 脚質 | その脚質のときの G の、ペースの確率での平均 | × 位置の確率 | = |
|---|---|---|---|
| 逃げ | 0.45×0.01 + 0.38×0.06 + 0.17×0.10 = 0.044 | × 0.31 | +0.014 |
| 先行 | 0.45×0.02 + 0.38×0.03 + 0.17×0.04 = 0.027 | × 0.41 | +0.011 |
| 差し | 0.45×0.00 + 0.38×(−0.02) + 0.17×(−0.03) = −0.013 | × 0.21 | −0.003 |
| 追込 | 0.45×(−0.01) + 0.38×(−0.04) + 0.17×(−0.06) = −0.030 | × 0.07 | −0.002 |
| 合計 D | | | **+0.020** |

### 有利・不利の判定

| 判定 | 条件（初めの値） |
|---|---|
| 展開有利 | D ≥ +0.02 |
| 展開不利 | D ≤ −0.02 |
| どちらでもない | それ以外 |

線の ±0.02 は初めの値である。Phase 3 で、判定した馬の実際の3着以内率と市場から見た3着以内率の差が、線を動かしたときにどう変わるかを数えて決め直す。

## 3. 展開の予測の使いどころ

| 使いどころ | 使うもの |
|---|---|
| 補正の特徴量（[07 の 1](07-expected-value.md#1-確率の作り方)） | 展開スコア D、ペースの確率、4コーナーの位置・上がりの速さの予想、着順の予想の確率 |
| 危険な人気馬の理由（[07 の 3](07-expected-value.md#3-危険な人気馬の判定)） | 人気馬で「展開不利」 |
| 当日のトラックバイアスとの組み合わせ（[06 の 1](06-realtime-adjustment.md#1-トラックバイアスの検知)） | 予想の位置（前か後ろか）とバイアスの向き |
| 回顧の「展開が向かなかった」の自動の候補（[08 の 3](08-bankroll-and-review.md#3-回顧データの形)） | 結果のペースと位置で出した D が、不利の線以下の馬 |

### 既存の展開予想で直すところ

既存の展開予想は、着順（⑦）の確率から印と買い目を出しているが、**オッズを特徴量に使わないので、⑦の確率は市場との差を直接は表していない。** そのため、この提案では ⑦ の確率をそのまま期待値に使わず、市場の確率を出発点にした補正（[07](07-expected-value.md)）の特徴量の1つにする。展開予想の中の ①〜⑥ の予想と、⑦ の作り方は変えない。
