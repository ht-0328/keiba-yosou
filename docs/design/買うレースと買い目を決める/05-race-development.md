# 05 モジュール3: ペースの予測と展開スコア

この文書で決めること: 枠順と脚質から、レースのペース（ハイ・平均・スロー）をどう予測するか。どの位置（脚質 × 枠）の馬が展開で有利・不利になるかを、どう判定するか。

結論:

- **展開の予測は、既存の展開予想（`src/yosou/race_development/`）をそのまま使う。** 前半（先頭の馬・序盤の位置・前半のペース）・後半（4コーナーの位置・上がりの速さ・後半のペース）・着順の7つを予想するもので、枠や相手の脚質も特徴量に入っている。
- **「逃げ馬が何頭ならハイペース」という頭数の線は決めない。** 研究で、逃げたい馬が多いレースでもハイになるのは半分ほどで、逃げたい馬がいなくてもハイになるレースがあると分かっている。ペースは線で決めず、確率（ハイ 0.45・平均 0.38・スロー 0.17 のように）で扱う。
- **有利・不利は「脚質 × ペース × 競馬場と芝ダ」ごとに、過去に市場の見立てよりどれだけ3着以内に来たかの表で決める。** この表とペースの確率・位置の確率から、馬ごとの「展開スコア」を出す。市場との差で数えるので、そのまま期待値の元になる。
- **研究で確かめた理論に合わせる:** 前にいる馬はペースに関係なく有利で、ペースはその大きさを変えるだけ。スローなら逃げの得が大きく、ハイなら逃げの得が消える。「ハイなら差しが有利」は言い過ぎ。
- **展開スコアは `src/yosou/development_score/` と道具 `tools/展開スコア/` として作った。** 線は過去のレースで確かめて ±0.01 に決めた（[4.](#4-作ったもの)・[5.](#5-確かめた結果)）。展開スコアは単独で買う根拠にはならず、補正の材料と、危険な人気馬の理由として使う。補正の材料としては、7つの区切りで採用の基準を満たし、印の成績でも悪くなっていなかった前日の3着以内のモデルにだけ足した。

## 1. ペースの予測

### 使う予想

既存の展開予想の「③ 前半のペース」が、レースごとにハイ・平均・スローの確率と、前半タイムの秒数を出す（[展開から着順を予想 の 01](../展開から着順を予想/01-overview.md)）。ペースは、前半タイム（前3ハロン）を、同じ競馬場・コース・距離・クラスの前日までの3年の基準と比べた z で分けている（[展開から着順を予想 の 10 の 4.・5.](../展開から着順を予想/10-target.md#4-前半のペースの目的変数)）。

主な材料は次のとおりで、どれもすでに特徴量に入っている。

| 材料 | 意味 | なぜ効くか |
|---|---|---|
| 先頭率の合計 | 出走馬全員の、近5走で最初のコーナーを先頭で回った割合の合計 | 逃げたい馬の数の数え方として、研究でいちばん当たった |
| 先団率が高い馬の数 | 最初のコーナーで前にいることが多い馬の数 | 先頭を取れなくても、前を争う馬が多いと速くなる |
| 先頭率の1位と2位の差 | 先頭を争う馬がいるか | 差が小さいと、2頭が競り合いやすい |
| 枠と、内の馬の脚質 | 逃げたい馬の内に、先行する馬がいるか | 外枠の逃げ馬は、先頭を取るまでに脚を使う |
| コース | 競馬場・芝ダ・距離 | 最初のコーナーまでの距離で、先頭争いの長さが変わる |

### 要件の問い「逃げ馬が何頭いればハイペースか」への答え

**頭数の線では決めない。** 研究「展開の理論の検証」で、次のことが分かっている（[research/展開の理論の検証 の 02](../../../research/展開の理論の検証/docs/02-結果の読み方.md)）。

- 逃げたい馬が多いほどハイが増え、スローが減る。**向きは正しい。**
- ただし、逃げたい馬が多いレースでもハイになるのは半分ほどで、逃げたい馬がいなくてもハイになるレースがある。**外れが多い。**

「2頭以上ならハイ」と決めて買うと、半分のレースで展開を読み違える。そこで、ペースは確率のまま次の展開スコアに渡し、読み違えの分を確率で薄める。

人が出馬表を読むときの目安としては、次の見方を添える（買う判断には使わない）。逃げたい馬は、先頭率 0.4 以上の馬とする。

| 逃げたい馬 | 読み方 |
|---|---|
| 0頭 | スローに寄りやすい。ただし押し出されて誰かが逃げ、ハイになることもある |
| 1頭 | 単騎で逃げやすく、スローから平均に寄りやすい |
| 2頭以上 | ハイに寄りやすい。ただし片方が控えれば平均以下になる |

## 2. 展開スコア（有利・不利の判定）

### 表 G: 脚質 × ペース × 競馬場と芝ダ ごとの、市場との差

過去のレースから、次の値を数えた表 G を作る。

```text
G(脚質 s, ペース p, 競馬場と芝ダ c) = そのマスの馬の、実際の3着以内率 − 市場から見た3着以内率の平均
```

- 脚質は、レース前に分かる脚質で分ける。近5走の先頭率（最初のコーナーを先頭で回った割合）が 0.4 以上なら「逃げ」、それ以外は近5走の序盤の位置（最初のコーナーの順位を頭数で 0〜1 にしたもの）の平均で、3分の1までなら「先行」、3分の2までなら「差し」、それより後ろなら「追込」。結果の脚質で分けると、「その日に前に行けた馬はもともと調子が良かった」分が混ざって大きく出すぎる（研究で確かめた）。過去走の無い馬は数えない。
- 逃げ・先行・差し・追込の4つを別々に数える。逃げと先行では、ペースの影響がまるで違うからである。
- ペースは、結果のペース（前半タイムの z）で分ける。区分の決め方（基準と ±0.5 の線）は ③ の目的変数と同じにする。③ の確率と掛け合わせるので、同じ物差しでないと意味が合わない。
- 市場から見た3着以内率は、単勝オッズから見た勝率を Harville の式で3着以内に広げたもの（全頭の予想の出発点と同じ物差し。[07 の 1](07-expected-value.md#1-確率の作り方)）。
- 件数の少ないマスは、同じ脚質 × ペースの全競馬場の値に寄せる（縮小推定。縮めた差 = (件数 × そのマスの差 + 重み × 全競馬場の差) ÷ (件数 + 重み)。重みは 500 で、件数が 500 のマスはそのマスの値と全競馬場の値を半分ずつ混ぜる。初期値）。材料に無い競馬場は全競馬場の値を使う。
- **市場との差で数えるので、「強い馬がたまたま前にいた」分は差し引かれている。** 研究では、市場との差で見ても効き目が残り、1〜3番人気でむしろ大きかった。
- 表 G は 2011年からの全出走から作る。学習データや過去の確かめに付けるときは、レースの年ごとに「その年の1月1日より前のレースだけ」で作り直す（リークを防ぐ）。

表 G の例（架空。東京・芝。実際の値はこの例より小さく、道具 `tools/展開スコア/development_score.py --table` で見る）:

| 脚質 | ハイ | 平均 | スロー |
|---|---|---|---|
| 逃げ | +0.01 | +0.06 | +0.10 |
| 先行 | +0.02 | +0.03 | +0.04 |
| 差し | 0.00 | −0.02 | −0.03 |
| 追込 | −0.01 | −0.04 | −0.06 |

研究の結論どおり、どのペースでも前が後ろより有利で、スローほどその差が大きい。ハイでは、逃げの得が消え、差しが市場並み（0）に戻る。実際の値は Git の対象外の `reports/展開スコア/cache/` に置く。

### 馬ごとの展開スコア

```text
展開スコア D = Σ_ペース P(ペース) × Σ_脚質 P(その馬がその脚質の位置を取る) × G(脚質, ペース, 競馬場と芝ダ)
```

- P(ペース) は、1 の「③ 前半のペース」の確率。平均の確率は 1 − スロー − ハイ。
- P(脚質の位置) は、既存の展開予想の ① と ② から作る。逃げ = ① 先頭になる確率、先行 = ② 先団の確率 − 逃げ（先団は前から3分の1までで先頭を含むため。負なら 0）、差し = ② 中団の確率、追込 = ② 後方の確率。4つの合計が 1 になるようにそろえる。
- D の単位は、3着以内の確率のポイント（+0.02 は、市場の見立てより 2ポイント来やすい）。脚質ごとの内訳（その脚質の確率 × ペースで平均した G）も一緒に出す。

例（架空）: 東京・芝、ペースはハイ 0.45・平均 0.38・スロー 0.17。ある馬は、逃げ 0.31・先行 0.41・差し 0.21・追込 0.07。

| 脚質 | その脚質のときの G の、ペースの確率での平均 | × 位置の確率 | = |
|---|---|---|---|
| 逃げ | 0.45×0.01 + 0.38×0.06 + 0.17×0.10 = 0.044 | × 0.31 | +0.014 |
| 先行 | 0.45×0.02 + 0.38×0.03 + 0.17×0.04 = 0.027 | × 0.41 | +0.011 |
| 差し | 0.45×0.00 + 0.38×(−0.02) + 0.17×(−0.03) = −0.013 | × 0.21 | −0.003 |
| 追込 | 0.45×(−0.01) + 0.38×(−0.04) + 0.17×(−0.06) = −0.030 | × 0.07 | −0.002 |
| 合計 D | | | **+0.020** |

### 有利・不利の判定

| 判定 | 条件 |
|---|---|
| 展開有利 | D ≥ +0.01 |
| 展開不利 | D ≤ −0.01 |
| どちらでもない | それ以外 |

線の ±0.01 は、道具 `tools/展開スコア/line_check.py` で決めた（[5.](#5-確かめた結果)）。実際の D は例より小さく（表 G の値がどのマスも小さいうえ、脚質とペースの確率で平均されるため）、±0.02 では判定される馬がごく少ない。

## 3. 展開の予測の使いどころ

| 使いどころ | 使うもの |
|---|---|
| 補正の特徴量（[07 の 1](07-expected-value.md#1-確率の作り方)） | 展開スコア D とその脚質ごとの内訳（まとまり S）、ペースの確率、4コーナーの位置・上がりの速さの予想（まとまり P） |
| 危険な人気馬の理由（[07 の 3](07-expected-value.md#3-危険な人気馬の判定)） | 人気馬で「展開不利」 |
| 当日のトラックバイアスとの組み合わせ（[06 の 1](06-realtime-adjustment.md#1-トラックバイアスの検知)） | 予想の位置（前か後ろか）とバイアスの向き |
| 回顧の「展開が向かなかった」の自動の候補（[08 の 3](08-bankroll-and-review.md#3-回顧データの形)） | 結果のペースと位置で出した D が、不利の線以下の馬 |

### 既存の展開予想で直すところ

既存の展開予想は、着順（⑦）の確率から印と買い目を出しているが、**オッズを特徴量に使わないので、⑦の確率は市場との差を直接は表していない。** そのため、この提案では ⑦ の確率をそのまま期待値に使わず、市場の確率を出発点にした補正（[07](07-expected-value.md)）の特徴量の1つにする。展開予想の中の ①〜⑥ の予想と、⑦ の作り方は変えない。

## 4. 作ったもの

計算は予想のパッケージ `src/yosou/development_score/`（1クラス1ファイル。一覧は `__init__.py`。元DB とファイルを読み書きするリポジトリは `repository/`）、入口は道具 `tools/展開スコア/`。

| 場所 | 何をするか |
|---|---|
| `DevelopmentRunRepository` | 表 G の材料になる、2011年からの中央・平地の全出走（最初のコーナーの順位・前3ハロン・単勝オッズ・着順）を事実表から読む（1 SQL） |
| `PreRaceStyle`・`ResultPace`・`AdvantageRuns` | 出走ごとのレース前の脚質、レースごとの結果のペース（③ と同じ基準と線）、市場から見た3着以内率と3着以内をそろえる |
| `AdvantageTableBuilder`・`AdvantageTable`・`AdvantageTableRepository`・`AdvantageTableStore` | 表 G を作る（縮小推定）・引く・pickle のファイルに書く/読む（`repository/`）・`reports/展開スコア/cache/` にとっておく（元DB が更新されたら作り直す。`rebuild` で強制的に作り直す） |
| `StyleProbabilities`・`DevelopmentScore`・`AdvantageJudge` | ①②③ の予測から脚質とペースの確率を出し、D と脚質ごとの内訳を出し、線で判定する |
| `RaceScoreWorkflow`・`RaceScore` | これから走る1レースを、保存した展開のモデル（`DevelopmentPaceWorkflow`）で予測して D と判定を出す（結果の入れ物が `RaceScore`） |
| `YearlyScorer`・`ScoreHistory` | 過去の出走に、年ごとの確かめの予測とその年より前だけで作った表 G から D を付ける（線の確かめと研究用） |
| `DEVELOPMENT_SCORE_FEATURES` | D と内訳を予想の特徴量にするときの一覧（まとまり S。5個） |
| `tools/展開スコア/development_score.py` | 1レース（または1日）の出走馬ごとの D と判定、各馬の位置とペースの確率を出す。`--table` で表 G を見る。時点は今週の予想と同じ決め方で自動で選ぶ |
| `tools/展開スコア/line_check.py`（部品は `line_tally.py`） | 線を過去のレースで確かめる。結果は `reports/展開スコア/線の確かめ.md` |
| 研究「既存モデルの改善」の `development_score_check.py`（入口⑬） | S を全頭の3着以内の予想に足して、時点ごとに7つの区切りで今の本番と比べる |

展開のモデルが無ければ道具は止まり、`uv run python -m yosou.race_development train` を案内する。

## 5. 確かめた結果

### 線の確かめ（`line_check.py`）

展開の予想の年ごとの確かめの予測がある年（2016年〜）の全出走に、その年より前だけで学習した展開のモデルの予測と、その年より前のレースだけで作った表 G から D を付け、線を動かしたときの「実際の3着以内率 − 市場から見た3着以内率」（差）と複勝の回収率を、木曜・前日・当日の3つの時点で数えた。数値は Git の対象外の `reports/展開スコア/線の確かめ.md`。

| 分かったこと | 決めたこと |
|---|---|
| D と差の向きは合う。D の 10分位で見ると、いちばん低い分位は市場の見立てより来ず、いちばん高い分位は市場の見立てより来る。どの時点でも同じ | 展開スコアは補正の材料として意味がある |
| ±0.02 では、判定される馬がごく少なく（有利側はとくに少ない）、年ごとの差の向きがそろわない | ±0.02 は使わない |
| ±0.01 では、有利側・不利側とも、どの時点でも全ての年で差の向きが合う。±0.015 でも向きはほぼ合うが、判定される馬が少ない | **線は ±0.01** |
| 展開有利の馬は人気薄が多く、市場の見立てより来てはいるが、複勝の回収率は 100% に届かない。効き目が出るのは 4番人気以下で、1〜3番人気の展開有利はむしろ市場の見立てより来ない | 展開有利だけで買わない（補正の材料にする）。モデルは人気との組み合わせを学べる |
| 展開不利の馬のうち 1〜3番人気は、市場の見立てより大きく来ない。どの時点でも同じ | 危険な人気馬の理由（[07 の 3](07-expected-value.md#3-危険な人気馬の判定)）に使う |

### 補正の材料としての確かめ（研究「既存モデルの改善」入口⑬）

[07 の 1](07-expected-value.md#1-確率の作り方) の決まり（材料は1つずつ足して確かめ、7つの区切りのうち5つ以上でログ損失が小さくなれば残す）で、S の 5個を今の本番と同じ材料に足して、木曜・前日・当日 × 3着以内・1着のモデルで比べた。前日の3着以内のモデルと当日の1着のモデルが基準を満たした。前日の3着以内に足し、道具「印の成績」で、今の決まりで実際に買う複勝の回収率が上がり（90% の幅の下の端が 100% を超えた）、◎ と全券種の合計は悪くなっていないことを確かめた。当日の1着は、印の成績で期待度「高」の ◎ の単勝回収率が下がったので足していない。結果と採否は [全頭の予想 の 15 の 17](../近走と適性から3着以内を予想/15-decisions.md#17-展開スコアを足すか)、数値は Git の対象外の `reports/印の成績/展開スコア/`。
