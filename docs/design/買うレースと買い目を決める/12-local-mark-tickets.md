# 12 地方の印の買い目（印で組む買い目を、見込みの回収率で買うか決める）

**この文書で決めること:** 地方競馬の発走前の通知（`tools/発走前の通知/notify.py --local`）に、中央と同じ「印の買い目」を、どの券種で・どの組の確率で・いくらで・どのレースで出すか。
どの券種を採るかは研究「地方の印の買い目」（[docs/01](../../../research/地方の印の買い目/docs/01-印の買い目の買い方.md)）で決めたので、ここでは本番の決まりだけを書く。

- 状態: **決定（作った）。** 道具「地方の推奨買目」（`mark_recommender.py`）と、発走前の通知の地方で使っている。
- 利用者の要望: 「中央競馬は推奨買目と印で買えるようになっているが、地方競馬も同じようにしてほしい」。
- 中央の印の買い目（[08 の 2「採用している券種（当日の予想の全レースの印の買い目）」](08-bankroll-and-review.md#採用している券種当日の予想の全レースの印の買い目)）と同じ形にする。ただし券種と組の確率は地方のデータで選び直した（中央の券種と確率をそのまま持ち込まない）。

## 1. 何を出すか

| 項目 | 決まり |
|---|---|
| 券種と組 | 単勝 ◎・馬単 ◎→○▲☆・3連単 ◎→○▲☆→○▲△☆（印は [07 の 5](07-expected-value.md#5-印の付け方)。地方には危険な人気馬の判定が無いので 消 は付かない）。印の付いた馬がいない位置のある券種（☆ がいないなど）は、その印を飛ばして組む |
| 出さない券種 | 馬連 ◎−○▲☆・馬単の裏 ○▲☆→◎・ワイド ◎−☆注・3連複 ◎−○▲☆−○▲△☆。地方では、どの形で買っても 100% を割る年がある（下の 3） |
| 期待値 | 組の確率 × 最新のオッズ。組の確率は推奨買目と同じ 1着・2着・3着を分けた条件つきロジット（[10 の 2](10-local-recommended-tickets.md#2-a-の決め方)。係数も同じ `reports/地方の推奨買目/係数.json`） |
| 金額 | 中央と同じ（`MarkReturn`）。トリガミの組を外し、どの組が当たっても払った額の 1.1倍以上が戻るように、1レース 5,000円を購入額の割合（オッズに反比例）で配って 100円単位に丸める。1.1倍に届かなければ期待値の低い組から外す |
| 買うか見送るか | 見込みの回収率（割合で重みを付けた期待値の和）が 100% 以上なら「買う」、未満なら「見送り」と、その値を出す |
| 時点 | 当日の時点（発走 10分前の速報を取り込んだあと）だけ。前日の時点（馬体重が届く前）は出さない |
| 頭数 | 5頭以上。4頭以下は理由を添えて「なし」 |
| 推奨買目との関係 | 推奨買目（[10](10-local-recommended-tickets.md)）とは別に出し、同じ組が重なることもある。推奨買目はそのまま出す |

## 2. 通知での見せ方

- 文: 推奨買目のあとに「印の買い目: 買う（見込みの回収率 112%）。合計 5,000円で、どれが当たっても 6,000円以上戻る」のような見出しの1行と、券種ごとに1行（例 `- 馬単（2点 計 1,500円）: 7→4 900円・7→8 600円`。値は架空）。中央の通知と同じ書き方。
- 出せないとき（3連単のオッズがまだ無い、オッズか予想の確率が欠けた馬がいる、◎ が無い、4頭以下）は「印の買い目: なし（理由）」。
- 表の画像: 買い目の欄の推奨買目の下に、同じ見出しと行を添える。

## 3. 確かめたこと

研究「地方の印の買い目」で、道具「印の成績」を地方の全頭の予想（2023年前半までで学んだ当日の予測）で動かしたときの印の組に、組の確率を付けて数えた。
対象は 2024年1月からの 5頭以上の確定レースで、確定オッズを使った。組の確率は、各年について、その年を除いた年で当てはめた係数で出した（入れ替え）。
前の年だけで当てはめた係数でも確かめた。採用の基準は、各年の回収率が 100% を超え、各年の最高の1点を除いても 100% 以上であること。

- 印どおりに全部買うと、どの券種もどの年も 100% に届かない（単勝だけ 100% 前後）。
- レースごとに見込みの回収率で買うか決めると、単勝・馬単・ワイドは券種単体でも基準を満たした。馬連・馬単の裏・3連複・3連単は単体では割る年がある。
- 中央と同じ組（単勝・馬連・馬単・馬単の裏・3連単）は 100% をわずかに割る年がある。全部の券種をまとめても割る。
- **単勝・馬単・3連単の組は、3年とも基準を満たした。** 見込みの線（1.0・1.1・1.2）と頭数（5・8・11頭以上）を動かしても、9通りすべてで基準を満たした。前の年だけで当てはめた係数でも 2025・2026年とも基準を満たした。
- ワイドを足した組（単勝・ワイド・馬単・3連単）も基準を満たしたが、ワイド単体は前の年だけの評価で最高の1点を除くと 100% を割る年があり（大きな当たり頼み）、中央の印の買い目にも無い券種なので入れない。
- 数値は `reports/地方の印の買い目/印の買い目の成績.md`・`印の買い目の成績-前の年.md`（Git 対象外）。
- 本番の流れ（保存済みの当日の予想 → 推奨買目と同じ組の確率 → 印の買い目 → 文と表の画像）は、終わった地方のレースで通して確かめた（1レース数秒）。
