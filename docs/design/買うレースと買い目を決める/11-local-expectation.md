# 11 地方の期待度（レースに添える1つだけの目安）

**この文書で決めること:** 地方競馬の発走前の通知（`tools/発走前の通知/notify.py --local`）に添える「期待度」を、何から作り、どの線で S・A・B・C にし、どこに出すか。買い目はこの目安で変えない。

- 状態: **決定（作った）。** 発走前の通知の地方の文と表の画像で使っている。
- 利用者の要望: 「地方競馬の予想で自信度を出してほしい」「地方はいったん1つの指標で、期待度の高いものにしてほしい」「あくまで期待度を出すだけで、買い目は変えない」。
  そのうえで「期待度は、そもそも推奨買目の期待度にしたほうがいいのでは」（期待度と、実際に買う買い目がつながっていない、という指摘）と、「期待度が S 多すぎ」。
- 中央も同じ名前の「期待度」の1つだけを出す（[03 の 5](03-race-screening.md#5-レースごとの目安期待度)）が、作り方は違う。中央は ◎ の確率と期待値、地方は直前の買い目（[13](13-local-late-tickets.md)）の2つのモデルの値から作る。

## 1. 何を出すか

| 項目 | 決まり |
|---|---|
| 期待度 | そのレースの「直前の買い目の線への近さ」を点数にし、S・A・B・C にしたもの。線は下の値を含む: **S 1 以上・A 0.85 以上・B 0.5 以上・C それ未満** |
| 線への近さ | 馬ごとに、買う馬らしさ ÷ その線（0.4）と 戻りの見込み ÷ その線（0.95）の小さいほうを取り、レースでいちばん大きい値（`LateRule.closeness`）。例: 買う馬らしさ 0.38・戻りの見込み 1.02 の馬がいちばん近ければ min(0.95, 1.07) = 0.95 で A |
| 意味 | 直前の買い目の「2つがそろって線以上」に、そのレースのいちばん近い馬がどこまで届いているか。1 以上なら、そのレースに直前の買い目の買う馬がいる（S ＝ 直前の買い目が出るレース）。線にいちばん近い馬の単勝の回収率は S がいちばん高く、C がいちばん低い（下の 3） |
| 材料 | 買い目を決める時刻（締め切りの約10分前）より前に分かることだけ（[13 の 2](13-local-late-tickets.md#2-材料全部買い目を決める時刻より前に分かること)）。確定オッズは使わない |
| 出す時点 | **当日の時点だけ**（直前の買い目と同じ）。馬体重が届く前の前日の時点は「期待度 なし（…当日の時点で出す）」と書く。2つのモデルの値を出せないレース（時系列オッズが取れない・オッズと予想のそろった馬が 5頭未満・モデルが無い）は「期待度 なし（見込みを出せない: 理由）」 |
| 出す場所 | 通知の文の見出しの次の行（例 `期待度 A（点数 0.91）`。点数は小数2桁）と、表の画像の見出しの札（例 `期待度 A`。発走時刻の左。S は ◎ の帯と同じ金色） |
| 買い目との関係 | 推奨買目・印の買い目・直前の買い目は、期待度で変えない。期待度は読む人の目安で、買うレースや点数の条件には使わない（直前の買い目の線は 13 の決まりで、期待度の S の線と同じ値になる） |

## 2. なぜ直前の買い目の線への近さか

| 試したこと | 分かったこと |
|---|---|
| ◎ の1着の確率 ＋ 3 ×（◎ の単勝の期待値 − 1）（◎ の点数。研究「地方の期待度」の [docs/01](../../../research/地方の期待度/docs/01-点数と線の決め方.md)） | ◎ の単勝・複勝の成績は等級の順に並ぶが、実際に買う買い目の目安になっていない |
| 推奨買目の期待の儲け（1点ごとの（期待値 − 1）の合計。研究の [docs/02](../../../research/地方の期待度/docs/02-推奨買目の見込みで付ける期待度.md)） | 確定オッズで作り直した推奨買目では等級の順に成績が並ぶ。通知の時刻のオッズでは見込みが膨らんで大半のレースが S になり、点数の高いレースほど実際の回収率が低い（研究の [docs/03](../../../research/地方の期待度/docs/03-通知の時刻での確かめ.md)） |
| 直前の買い目の線への近さ | 通知の時刻のオッズで学び、同じ時刻のオッズで確かめた値。線にいちばん近い馬の単勝の回収率は S がいちばん高く、C がいちばん低い（下の 3） |

- 地方は、通知のとき（締め切りの約10分前）のオッズと確定のオッズが大きく違う。そのときのオッズに予想の確率を掛けた期待値は、あとで下がるオッズの組ほど高く出るので、期待値から作る点数は通知の目安にならない。
- 線は、S を直前の買い目の線（1）にそろえた。B の線（0.5）は、それ未満のレースの回収率がはっきり低くなるところ。A の線（0.85）は、線まであと少しのレースを分ける区切りで、A と B の回収率に差は無い（下の 3）。

## 3. 確かめたこと

数値は Git 対象外の `reports/地方の直前の買い目/check.md` の2つめの表（`uv run python tools/地方の直前の買い目/check.py`）。
学習用の表（買い目を決める時刻の断面のオッズと予想）で、3か月ごとにそれより前のレースだけで2つのモデルを学び直して値を付け、全レースを期待度で分けて、
線にいちばん近い馬の単勝を 100円買ったときの成績を確定の払戻で数えた。

- **回収率。** 全体では C → B → A → S の順に上がる。S だけが 100% を超える。A と B はどちらも 100% を割ってほぼ同じ、C はそれよりはっきり低い。
- **年ごと。** S はどの年もいちばん高い。ただし 100% を超えたのは 3つの年のうち 2つで、最初の半年は 100% を少し割った。C はどの年もいちばん低い（最初の半年は B とほぼ同じ）。A と B は年によって入れ替わる。
- **的中率。** 等級の順には並ばない。C は線に近い馬が人気馬になりやすく、的中率はいちばん高いが回収率はいちばん低い。期待度は「当たりやすさ」でなく「買って見合うか」の目安である。
- **割合。** S が全レースの 1割弱、A が 2割ほど、B が 3割ほど、C が 4割ほど。S は学ぶレースが増えるほど減り、直近の年は 20レースに1つほど。

割り引いて見るところ:

- A と B の回収率に差は無いので、読み分けるのは「S か」「C か」である。A と B の線（0.85・0.5）は全部の期間を見て置いた。S の線は直前の買い目の線で、これも全部の期間を見て選んである（[13 の 5](13-local-late-tickets.md#5-確かめ方)）。表の数字は、本当の値より高く出ている。
- 確かめたのは、線にいちばん近い馬の単勝だけである。推奨買目・印の買い目の成績が等級の順に並ぶかは確かめていない（この2つは確定オッズで確かめた買い方で、通知の時刻での成績は別に数える）。
- 過去の確かめの「買い目を決める時刻」は、取り直した時系列オッズの断面で再現したものである。実際の通知での S の成績は、直前の買い目の `results.py` で数える。
