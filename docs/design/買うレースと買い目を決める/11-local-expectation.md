# 11 地方の期待度（レースに添える1つだけの目安）

**この文書で決めること:** 地方競馬の発走前の通知（`tools/発走前の通知/notify.py --local`）に添える「期待度」を、何から作り、どの線で S・A・B・C にし、どこに出すか。買い目はこの目安で変えない。

- 状態: **決定（作った）。** 発走前の通知の地方の文と表の画像で使っている。
- 利用者の要望: 「地方競馬の予想で自信度を出してほしい」「地方はいったん1つの指標で、期待度の高いものにしてほしい」「あくまで期待度を出すだけで、買い目は変えない」。
  そのうえで「期待度は、そもそも推奨買目の期待度にしたほうがいいのでは」（期待度と、実際に買う推奨買目がつながっていない、という指摘）。
- 中央も同じ名前の「期待度」の1つだけを出す（[03 の 5](03-race-screening.md#5-レースごとの目安期待度)）が、作り方は違う。中央は ◎ の確率と期待値、地方はそのレースの推奨買目から作る。

## 1. 何を出すか

| 項目 | 決まり |
|---|---|
| 期待度 | そのレースの推奨買目（[10](10-local-recommended-tickets.md) の8券種）の1点ごとの（期待値 − 1）の合計を点数にし、S・A・B・C にしたもの。線は下の値を含む: **S 3.2 以上・A 1.4 以上・B 0.5 以上・C それ未満** |
| 意味 | 推奨買目を1点 100円で買ったときに見込める儲けを、100円単位で数えたもの（期待の儲け）。買い目の割の良さと点数の多さの両方が入る。高いほど、そのレースの推奨買目の的中率と儲けが大きい（下の 3） |
| 数える買い目 | 道具「地方の推奨買目」が出した推奨買目だけ。全頭の予想から足す ◎ の単勝・複勝（`LocalBetRule`）は数えない（期待値の見立てが別のモデルなので） |
| 出す時点 | **当日の時点だけ**（推奨買目と同じ）。馬体重が届く前の前日の時点は「期待度 なし（…当日の時点で出す）」と書く。推奨買目が1点も無いときは「期待度 なし（推奨買目が無い: 理由）」 |
| 出す場所 | 通知の文の見出しの次の行（例 `期待度 A（点数 2.10）`。点数は小数2桁）と、表の画像の見出しの札（例 `期待度 A`。発走時刻の左。S は ◎ の帯と同じ金色） |
| 買い目との関係 | 推奨買目と ◎ の単勝・複勝の買い方は、期待度で変えない。期待度は読む人の目安で、買うレースや点数の条件には使わない |

## 2. なぜ推奨買目の期待の儲けか

| 試したこと | 分かったこと |
|---|---|
| ◎ の1着の確率 ＋ 3 ×（◎ の単勝の期待値 − 1）（◎ の点数。研究の [docs/01](../../../research/地方の期待度/docs/01-点数と線の決め方.md)） | ◎ の単勝・複勝の成績は等級の順に並ぶが、推奨買目の回収率と1日の儲けは並ばない（S が最もよいとは限らず、C も 100% を超える年がある）。実際に買うものの目安になっていない |
| 推奨買目の見込みの回収率（期待値の平均） | 実際の回収率が等級の順に並ばない。見込みがいちばん高い S が、A・B より低い年がある（見込みの高い組ほど、期待値が高めに出やすい） |
| 推奨買目の期待の儲け（（期待値 − 1）の合計） | 的中率と1日の儲けが、確かめた年のどれでも等級の順に上がる。回収率も S が最も高い（下の 3） |

- 線は、2024年の点数の分位（上から 20%・30%・30%・20%）を取り、0.1 刻みに丸めて固定した。2025・2026年で確かめた。
- 進め方と結果は研究「地方の期待度」の [docs/02](../../../research/地方の期待度/docs/02-推奨買目の見込みで付ける期待度.md)。

## 3. 確かめたこと

数値は Git 対象外の `reports/地方の期待度/推奨買目の見込みの期待度[-前の年].md`。過去のレースの推奨買目は、本番と同じ決まり（`RECOMMENDED_PLANS`）で作り直した。
組の確率は本番と同じ 1着・2着・3着の条件つきロジットを、各年を残りの年で（と、前の年だけで）当てはめたもの。オッズと払戻は確定の値。

- **的中率と1日の儲け。** 2025・2026年とも、入れ替えでも前の年だけでも、C → B → A → S の順に上がる。
- **回収率。** S がどの年も最も高い。C は入れ替えでは 3年とも最も低く 100% を割るが、前の年だけで当てはめた 2025年は 100% を超えた（C は1レース 4点ほどで、年ごとの振れが大きい）。A と B はほぼ同じで、年によって入れ替わる。
- **割合。** S が全レースの 2割ほど、A と B が 3割ずつ、C が 2割ほど。推奨買目の点数は S ほど多く、C は1レース 4点ほど。
- **本番の予想モデルと本番の係数。** 2026年の本番の予想モデルの予測に本番の係数を当てて作り直しても、割合と向き（S の回収率が最も高く、C は 100% を割る）は同じ。
- **◎ の点数との比べ。** 同じ推奨買目を ◎ の点数で分けると、どの等級も回収率が近く、S の回収率が最も高い年は無い。1日の儲けも等級の順に並ばない。
