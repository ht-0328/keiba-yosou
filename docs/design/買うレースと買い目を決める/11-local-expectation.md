# 11 地方の期待度（レースに添える1つだけの目安）

**この文書で決めること:** 地方競馬の発走前の通知（`tools/発走前の通知/notify.py --local`）に添える「期待度」を、何から作り、どの線で S・A・B・C にし、どこに出すか。買い目はこの目安で変えない。

- 状態: **決定（作った）。** 発走前の通知の地方の文と表の画像、道具「印の成績」の表13（`--scene 地方`）で使っている。
- 利用者の要望: 「地方競馬の予想で自信度を出してほしい」「中央は配当率と的中率を分けているが、地方はいったん1つの指標で、期待度の高いものにしてほしい」「あくまで期待度を出すだけで、買い目は変えない」。
- 中央も同じ名前の「期待度」の1つだけを出す（[03 の 5](03-race-screening.md#5-レースごとの目安期待度)）が、式と線は違う。線は地方の未見の予測で決めた（中央の線をそのまま使わない）。

## 1. 何を出すか

| 項目 | 決まり |
|---|---|
| 期待度 | ◎ の1着になる確率 ＋ 3 ×（◎ の単勝の期待値 − 1）の点数を、S・A・B・C にしたもの。線は下の値を含む: **S 0.45 以上・A 0.15 以上・B −0.10 以上・C それ未満** |
| 意味 | 高いほど、◎ の単勝・複勝をべた買いしたときの的中率（勝率・複勝率）と回収率が高い。「当たりやすさ」（1着の確率）と「市場より得か」（単勝の期待値）を足したもので、地方では期待値の重みを 3 にする（下の 2） |
| ◎ | 通知の印と同じ（[07 の 5](07-expected-value.md#5-印の付け方)。単勝 30倍以下の馬の中で単勝の期待値が1位）。地方には危険な人気馬の判定が無い |
| 出す時点 | **当日の時点だけ**（推奨買目と同じ）。馬体重が届く前の前日の時点は「期待度 なし（…当日の時点で出す）」と書く。前日の時点の予想は、◎ の単勝回収率がどの式でも等級の順に上がらず、当日の線を当てると 7割ほどが C になるので目安にならない（下の 3）。◎ の期待値が無いときも「なし」 |
| 出す場所 | 通知の文の見出しの次の行（例 `期待度 A（点数 0.21）`。点数は小数2桁）と、表の画像の見出しの札（例 `期待度 A`。発走時刻の左。S は ◎ の帯と同じ金色）。道具「印の成績」の表13 は `--scene 地方` のとき地方の期待度（式と線が中央と違う）ごとにする |
| 買い目との関係 | 推奨買目（[10](10-local-recommended-tickets.md)）と ◎ の単勝・複勝の買い方は、期待度で変えない。期待度は読む人の目安で、買うレースや点数の条件には使わない |

## 2. なぜ1つの目安で、なぜ期待値の重みが 3 か

| 試したこと | 分かったこと |
|---|---|
| 中央の期待度の式（1着の確率 ＋ 単勝の期待値 − 1）を、中央の線のまま・地方の分位の線で当てる | 勝率・複勝率は等級の順に上がるが、単勝回収率は S が A・B より低い。地方は 1番人気が買われすぎで、確率の高い ◎ の単勝は回収率が低いため |
| 1着の確率だけ | 同じ（勝率は上がるが回収率は上がらない） |
| 単勝の期待値だけ | 回収率は上がるが、勝率が逆（S の勝率がいちばん低い） |
| 1着の確率 ＋ w ×（単勝の期待値 − 1）で w を 0.5・1・2・2.5・3・4・5 | w が 3 までは勝率も複勝率も回収率も等級の順に上がる。4 以上で S の勝率が A を下回る。3 は、勝率の順を保てる中で回収率の差（S − C）がいちばん大きい |
| 3着以内の確率と複勝の期待値で作る、確率と期待値の積 | どれも重み 3 より悪い（回収率が順に上がらない） |

- 線は、2024年の当日の未見の予測で点数の分位（上から 20%・30%・30%・20%）を取り、0.05 刻みに丸めて固定した。2025・2026年で確かめた（下の 3）。
- 候補の一覧は結果を見る前に決めた（研究「地方の期待度」の [docs/01](../../../research/地方の期待度/docs/01-点数と線の決め方.md)）。

## 3. 確かめたこと

数値は Git 対象外の `reports/地方の期待度/期待度の候補-当日.md`・`期待度の候補-前日.md`。◎ の行は、地方の予想モデルの backtest の未見の予測（2023年前半までで学んだモデルの 2024年以降の予測。`predictions-2024検証`）に、印の成績と同じ決め方で印を付けたもの。オッズ・払戻は確定の値。

- **当日の時点。** 2025・2026年とも、◎ の勝率・複勝率・複勝回収率は C → B → A → S の順に上がる。単勝回収率は 2025年は順に上がり、2026年は B と A が入れ替わる（S はどの年も最も高い）。S は全レースの 2割ほどで、◎ の単勝回収率が 3年とも 100% を超える。C は 2割ほどで、どの年も 100% を割る。
- **推奨買目との関係。** 研究「地方の万馬券」段5 の買い目（8券種・11頭以上）の的中レース率も、どの年も期待度の順に上がる（回収率は S がおおむね最も高いが、順には並ばない年がある）。
- **前日の時点。** 前日の時点の未見の予測では、どの式でも ◎ の単勝回収率が等級の順に上がらない（勝率・複勝率・複勝回収率は上がる）。前日の ◎ は全体の単勝回収率が 100% を割り、期待値 1.00 以上のレースが少ない（[地方の予想 の 16](../地方競馬の近走と適性から3着以内を予想/16-evaluation.md#印の成績上の-6)）。当日の線を当てると 7割ほどが C で、S はごくわずかしか無い。そのため期待度は当日の時点だけ出す。
- **頭数ごと。** 7頭以下・8〜10頭・11頭以上のどれでも、S の ◎ の単勝回収率は 100% を超え、C は割る。
