# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。

**結論: 手本とまったく同じ。「3着以内なら 1、それ以外は 0」を当てさせ、「1着なら 1」の列も学習データに置いておく。共通の `Top3TargetBuilder`（列は `TOP3`・`WIN`）をそのまま使う。**

- 作り方（1 になるとき・0 になるとき、確定着順を使う、同着はどちらも同じ着順、競走中止と失格は 0、取消・除外はサンプルにしない）は [手本の 10 の「作り方」](../近走と適性から3着以内を予想/10-target.md#作り方) を参照。
- 3着以内を最初に使う理由と、1着の列も置いておく理由は [手本の 10 の「理由」](../近走と適性から3着以内を予想/10-target.md#理由) を参照。
- 用語の意味は [02-glossary.md](02-glossary.md) を参照。

## この予想で違う点

**目的変数そのものに違いは無い。** 違うのは、目的変数を付ける対象の行が「重賞の出走だけ」になることだけで、それは行の選び方（[08-training-data.md の 3](08-training-data.md#3-どのサンプルを入れるか)）の話である。

## 1 と 0 の数の偏り

**手本と同じく、偏りは直さずにそのまま学習する。** 1 が少なく 0 が多い（16頭立てなら 3 対 13）のは重賞でも同じで、偏りを直す設定を使うと予測確率が実際の確率からずれる。理由は [手本の 10 の「1 と 0 の数の偏り」](../近走と適性から3着以内を予想/10-target.md#1-と-0-の数の偏り) を参照。

重賞は多頭数（フルゲート近く）が多いので、1 の割合は手本の学習データよりわずかに低いが、扱いは変わらない。
