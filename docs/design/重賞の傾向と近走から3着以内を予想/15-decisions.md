## 1. 予想の対象

| 選び方 | 変わること |
|---|---|
| **平地の重賞（G1・G2・G3）の出走全部（決定）** | 1年に約 125レース・約 1,900行。G1〜G3 で傾向の数え方は同じなので、まとめて1つのモデルで学ぶ |
| G1 だけ | 「格の高いレースだけ」に絞れるが、1年に約 400行しかなく、学習データが足りない |
| 重賞にオープン特別も足す | 行数は増えるが、オープン特別は施行条件が変わりやすく、「同じレースの過去の開催」の傾向が薄まる |
| 障害の重賞（グレードコード F・G・H）も入れる | 障害は走り方が違い、平地の傾向と混ざる。どの予想でも障害は入れない決まりに反する |

関連する資料: [08-training-data.md の 3](08-training-data.md#3-どのサンプルを入れるか)、[06-flowchart.md の図1](06-flowchart.md#図1-学習データに入れる行の選び方)。

## 2. レースの同定のしかた

| 選び方 | 変わること |
|---|---|
| **特別競走番号（決定）** | 競走名が変わっても、同じレースとして過去の開催をたどれる。2011年以降の中央の重賞 137番号で、同じ名前が別の番号へ移った例が 0件であることを確かめた |
| 競走名 | 名前が変わった番号が 22件あり、そこで過去の開催が途切れる |
| 競馬場×距離×月 | 施行条件の変更（距離や時期の変更）で、別のレースを同じレースとして混ぜてしまう |

関連する資料: [09-features.md の「レースの同定」](09-features.md#レースの同定)。SQL は `tools/共通/stakes.py`（実装済み）。

## 3. まとまり K に入れる切り口

| 選び方 | 変わること |
|---|---|
| **持続する切り口だけを入れる（決定）** | 前半（2011〜2018年）と後半（2019〜2026年）の期間でずれの相関がある切り口（前に行く馬（脚質判定が逃げ・先行）0.49、内枠 0.30、上位人気 0.27）と、狙いの中心である1番人気（0.16。縮めを強めにする）、属性の切り口（休み明け・関西馬・好走経験者）から 10個を作る |
| 前に行く馬を「最初のコーナー3番手以内」で数える | コーナーを5回以上通るコース（中山2500mなど）では最初のコーナーの順位が記録から取れず、重賞の約 6% でこの切り口が空になる。持続性の相関も 0.36〜0.37 と、脚質判定（0.49）より弱い |
| 荒れ度・二桁人気の好走も入れる | 相関 0.16・0.13 で持続しない。過去のまぐれをモデルが信じてしまう。分析ページには注意書き付きで載せる |
| 傾向を特徴量にせず、分析ページ（`tools/重賞攻略/`）だけにする | モデルは重賞をふつうのレースと同じに扱うことになり、この予想を手本と分ける意味が無くなる |

関連する資料: [09-features.md の「切り口を選んだ根拠」](09-features.md#切り口を選んだ根拠持続性の検証)、[09-features.md の K](09-features.md#k-重賞の傾向10個)。

## 4. ずれの縮め方

| 選び方 | 変わること |
|---|---|
| **縮小推定 n/(n+k)。k は切り口ごと（決定）** | 過去の開催が少ないレースのずれが 0 に縮み、まぐれを信じすぎない。k の表は [09-features.md の「縮めたずれの定義」](09-features.md#縮めたずれの定義) |
| 縮めない生のずれ | 新しい重賞や、当てはまる馬の少ない切り口で、数頭のまぐれがそのまま特徴量になる |
| ベイズ推定でより精密に縮める | 縮小推定と大きくは変わらないわりに、作りと説明が難しくなる |

関連する資料: [09-features.md の「縮めたずれの定義」](09-features.md#縮めたずれの定義)。

## 8. 当たり具合の確かめ方

| 選び方 | 変わること |
|---|---|
| **手本の 16 に準拠し、`evaluate` コマンドを足す（決定）** | 指標・1番人気の基準・「オッズだけで学習したモデル」との比べ方の考え方は手本と同じ。`evaluate` で、学習に使っていない期間（検証・テスト）の重賞について、複勝を期待値で買ったときの回収率（帯別）と、本命と1番人気の比べ方を出す |
| ウォークフォワード（7つの区切り）で確かめる | 研究「既存モデルの改善」の仕組み（`research/既存モデルの改善/`）に重賞版を足した（2026-09-30）。下の「ウォークフォワードの重賞版の結果」 |

### ウォークフォワードの重賞版の結果（2026-09-30）

**区切りは1年ずつの7つにした（テストは 2020年〜2026年）。** 重賞は半年に約 60レースしかなく、半年の区切りではログ損失や回収率が数レースの結果で大きく揺れるため。
7つにしたのは、ほかの予想と同じ採用の基準（7つのうち5つ以上）をそのまま使うため。学習は 2012年1月から検証の前の年まで（いちばん短い区切りでも7年）、
検証はテストの直前の1年、時点は木曜・前日・当日の3つ全部、ハイパーパラメータは初期値のまま。比べたのは、今の既定（85個・オッズから作った基準＋補正）、既定から重賞の傾向（K）を外したもの、オッズだけ。
進め方と結果の読み方は `research/既存モデルの改善/docs/01-進め方.md` の 5 と `02-結果の読み方.md` の 6、数値は `reports/既存モデルの改善/compare/stakes_tendency_top3.md`。

**今の既定を採用するか: 採用しない（採用の基準を満たさない）。木曜・前日・当日のどの時点でも同じ判断である。** 採用の基準は研究「既存モデルの改善」の全頭と同じで、ログ損失がオッズだけより小さい区切りが 7つのうち 5つ以上あり、7つを合わせても小さいこと。

| 見たこと | 結果 |
|---|---|
| 既定がオッズだけよりログ損失が小さい区切り | 7つのうち 4つ（基準は 5つ以上） |
| 7つを合わせたログ損失 | 既定がわずかに小さいが、差はごく小さい |
| 重賞の傾向（K）を外したとき | 既定とほとんど変わらない |
| 複勝を期待値で買ったときの回収率（区切りごと） | 既定は、検証期間で買う線が決まった区切りが 1つだけで、判断できるほど買えなかった。オッズだけは 3つで線が決まり、合計は 100% に届かなかった |

表は当日の結果。時点を替えても判断は変わらない。

| 時点 | 比べた相手 | 結果 |
|---|---|---|
| 当日 | 当日のオッズだけのモデル | 上の表のとおり。基準に届かない |
| 前日 | 前日のオッズだけのモデル | 当日とほぼ同じ（小さい区切りは 7つのうち 4つ）。前日も当日も確定オッズで検証しているため、実際の前日のオッズではここより悪くなる側にぶれる |
| 木曜 | 当日のオッズだけのモデル（オッズが無い時点なので、締め切りの市場の見立てと比べる） | 7つすべてで誤差が大きい。人気の無い馬の確率を高く見積もり、複勝を期待値で買うと7つすべてで回収率が 100% を下回った |

- 予想のコードとモデルは残す（動くし、`evaluate` で確かめられる）。ただし、オッズだけで学んだモデルより良いとは言えないので、買い方の判断で上の扱いをしない。
- **残っている課題（直すとき）:** ① 重賞の傾向（K）の作り方（何を数えるか・縮め方）を見直す。今の K は、オッズから作った基準に上乗せできる情報をほとんど持っていない。
  ② 学習データを増やす（2011年より前の重賞で特別競走番号の同定を確かめて、期間を延ばす。5 の選び方）。③ 複勝の買う線を重賞の数に合わせて決める
  （今の研究の線の選び方は、検証期間に 100点以上買えることを求めるので、重賞の1年では線がほとんど決まらない）。直したら、同じウォークフォワード
  （`uv run python research/既存モデルの改善/walk_forward.py --model stakes_tendency_top3` と `compare.py --only stakes_tendency_top3`）で確かめ直す。

関連する資料: [16-evaluation.md](16-evaluation.md)。

## 9. 新しい一般の予想の材料で作り直し、採用か引退かを決める（2026-10-02）

8 の結果のあと、手本（近走と適性から3着以内を予想）の材料が大きく変わった（[手本の 15 の 11](../近走と適性から3着以内を予想/15-decisions.md#11-研究一番人気を疑うの直し方を移す)。木曜は馬の力の材料 M だけ、前日は M に単勝オッズの材料 J とオッズから作った基準、当日は今の材料 A〜L に券種ごとの支持 N と M を足したもの）。
利用者は 2026-10-02 に、**この予想を手本の新しい材料の上に作り直し、それでも手本に勝てなければ専用モデルは引退させる**と決めた。

**採用と引退の基準は、結果を見る前に次のとおり決めた。** 結果を見てから基準を動かさない。

| 項目 | 決めたこと |
|---|---|
| 区切り | 8 と同じ、1年ずつの7つ（テストは 2020年〜2026年。学習は 2012年1月から検証の前の年まで） |
| 時点 | 木曜・前日・当日の3つ。時点ごとに別々に採否を決める |
| 比べる相手 | (a) オッズだけで学んだモデル（木曜はオッズが無いので、当日のオッズだけのモデル）。(b) 手本の新しい予想を、重賞のレースだけに使ったとき（全レースで学び、同じ区切りの重賞の行だけで測る） |
| 採用の基準 | その時点の専用モデルの確率の誤差（テスト期間のログ損失）が、(a) より小さい区切りが 7つのうち 5つ以上あり、7つを合わせても小さい。**かつ** (b) より小さい区切りが 5つ以上あり、7つを合わせても小さい。両方を満たした時点だけ、専用モデルを採用する |
| 引退 | どの時点も基準を満たさなければ、専用モデルは引退する。重賞も手本の予想で予想し、当日の予想の道具の重賞の表は手本の当日の予測を出す形にする。コードと `train`・`predict` は確かめ直し用に残す |
| ほかに見るもの | ◎（確率1位）の3着以内率を1番人気と比べた表、重賞の傾向（K）を外したときとの差。採否の判断には使わず、理由の説明に使う |

- 作り直した専用モデルの材料: 木曜は M に K（枠を使う1個を除く9個）、前日は M・J・K（10個）とオッズから作った基準、当日は手本の当日と同じ A〜L・N・M に K を足したもの（当日に券種のオッズが無いレースのための N を外したモデルも持つ）。学習データは重賞だけ・2012年から。
- (b) を基準に入れる理由: 専用モデルの存在理由は「重賞を、手本より良く当てる」ことにある。オッズだけに勝っても、手本に勝てなければ、重賞も手本で予想すればよい。
- 確かめ方は研究「既存モデルの改善」の `research/既存モデルの改善/stakes_rebuild.py`（表を作る → 区切りごとに学習する）と `compare.py --only stakes_tendency_top3`。数値は `reports/既存モデルの改善/compare/stakes_tendency_top3.md`。
- 結果と判断は、確かめたあとにここに書き足す。

関連する資料: [16-evaluation.md の 3](16-evaluation.md#3-比べる基準)、[07-prediction-timing.md](07-prediction-timing.md)、[09-features.md](09-features.md)。
