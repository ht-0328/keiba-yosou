# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想（近走と適性から3着以内を予想）に出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語（二値分類・特徴量・目的変数・リークなど）と、競馬とこの設計の用語（ID 列・評価用の列・ウォームアップ期間・事実表・出走別着度数など）は、手本と同じものをそのまま使う。この予想で増えるのは、重賞とレースごとの傾向に関する用語だけである。

- 機械学習の用語は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。この予想で増える機械学習・統計の用語は無い。
- 競馬とこの設計の用語は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。

## この予想で増える用語

| 用語 | 意味 | この設計では |
|---|---|---|
| 重賞 | G1・G2・G3 の格付けが付いたレース。JV-Data ではレース詳細（`ra`）のグレードコード（A = G1、B = G2、C = G3）で見分ける | 予想の対象。障害の重賞（グレードコード F・G・H）は含めない（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |
| 特別競走番号 | JV-Data のレース詳細にある、特別競走ごとの番号。競走名が年によって変わっても（冠スポンサーの変更など）、番号は変わらない | 「同じ重賞」を見分ける鍵（[09-features.md の「レースの同定」](09-features.md#レースの同定)） |
| 過去の開催 | 同じ特別競走番号のレースのうち、そのレースの開催日より前に確定成績があるもの。1回の開催 = 1レース | 傾向はここから数える。例の馬のレースは、過去の開催が 14回ぶんある（[01-overview.md の「1頭の例」](01-overview.md#1頭の例)） |
| レースごとの傾向 | そのレースの過去の開催で、ある条件の馬（例: 前走が同じレースだった馬、単勝 10〜20倍だった馬）がどれだけ走ったか。出走数・複勝率（3着以内の割合）・単勝回収率・複勝回収率で表す。重賞全体やコースの平均（基準）とは比べない | まとまり K の元（[09-features.md の K](09-features.md#k-重賞の傾向51個)） |
| 切り口 | 「自分と同じ条件」の決め方。前走のレース・前走の着順・前走の人気・枠・単勝オッズ・人気・脚質・間隔・所属・好走経験・年齢・性別の 12個 | K は切り口ごとに4つの成績を持つ（[09-features.md の K](09-features.md#k-重賞の傾向51個)）。コードでは `TendencyCut` |
| 帯 | 切り口ごとに、値を「同じ条件」とみなすまとまりにしたもの。枠なら 内（1〜3）・中（4〜5）・外（6〜8）、単勝オッズなら 3倍未満〜50倍以上の6つ、など | 過去の開催の馬と予測する馬を同じ決まりで分ける（コードでは `ConditionBands`）。帯が決まらない（木曜の枠など）と、その切り口の K は欠損値 |
| 前走のレースの鍵 | 前走がどのレースだったかを見分ける値。前走が重賞なら特別競走番号、ほかの特別競走なら競走名、平場ならクラス名、中央の前走が無ければ「前走なし」 | 切り口「前走のレース」の帯。`tools/共通/stakes.py` の `prev_key` |
| 前に行く馬 | 脚質判定（JV-Data の今回レース脚質判定）が逃げ・先行だった馬 | 切り口「脚質」の帯「前」。過去の開催は確定した脚質判定で分け、自分（走る前）は推定脚質で分ける。後ろは差し・追込、どちらでもなければ不明 |
| 休み明け | 前走から 63日以上（中9週以上）あいた出走 | 切り口「間隔」の帯 |
| 好走経験 | 同じ重賞（同じ特別競走番号）で、過去に 3着以内に入ったことがあるか | 切り口「好走経験」の帯（あり・なし）。事実表の「同じ競走名のレースでの3着内の数」で見る |
| 持続性 | ある期間に測ったレースごとの傾向が、あとの期間でも同じ向きに出るか。前半と後半の期間で測った値の相関係数で見る | レース単位の2個（1番人気・1〜3番人気の複勝率）を残した根拠（[09-features.md の「切り口を選んだ理由」](09-features.md#切り口を選んだ理由)） |
| 攻略ポイント | 分析ツール `tools/重賞攻略/` が重賞ごとに書く、傾向と成績のページ。Git の対象外の `reports/重賞攻略/` にできる | 重賞の見分け方（特別競走番号の対応表。`tools/共通/stakes.py`）はモデルと同じ（[01-overview.md の「関連する道具」](01-overview.md#関連する道具分析ツール重賞攻略)） |
