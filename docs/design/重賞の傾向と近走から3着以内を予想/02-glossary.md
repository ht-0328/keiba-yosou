# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想（近走と適性から3着以内を予想）に出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語（二値分類・特徴量・目的変数・リークなど）と、競馬とこの設計の用語（ID 列・評価用の列・ウォームアップ期間・事実表・出走別着度数など）は、手本と同じものをそのまま使う。この予想で増えるのは、重賞とレースごとの傾向に関する用語だけである。

- 機械学習の用語は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。この予想で増える機械学習・統計の用語は、下の表の「縮小推定」だけである。
- 競馬とこの設計の用語は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。

## この予想で増える用語

| 用語 | 意味 | この設計では |
|---|---|---|
| 重賞 | G1・G2・G3 の格付けが付いたレース。JV-Data ではレース詳細（`ra`）のグレードコード（A = G1、B = G2、C = G3）で見分ける | 予想の対象。障害の重賞（グレードコード F・G・H）は含めない（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |
| 特別競走番号 | JV-Data のレース詳細にある、特別競走ごとの番号。競走名が年によって変わっても（冠スポンサーの変更など）、番号は変わらない | 「同じ重賞」を見分ける鍵（[09-features.md の「レースの同定」](09-features.md#レースの同定)） |
| 過去の開催 | 同じ特別競走番号のレースのうち、そのレースの開催日より前に確定成績があるもの。1回の開催 = 1レース | 傾向はここから数える。例の馬のレースは、過去の開催が 14回ぶんある（[01-overview.md の「1頭の例」](01-overview.md#1頭の例)） |
| レースごとの傾向・ずれ | そのレースの過去の開催で、ある切り口の馬（例: 1〜3番人気）の複勝率（前・内枠は超過複勝率）が、基準とどれだけ違うか。プラスなら、そのレースではふつうより走る | まとまり K の元（[09-features.md の K](09-features.md#k-重賞の傾向10個)） |
| 縮小推定（shrinkage） | 数えた元の数 n が少ないときに、推定した値を n/(n+k) 倍して 0（情報なし）に近づける、統計の考え方。まぐれを信じすぎないためのもの | ずれを「縮めたずれ」にする（[09-features.md の「縮めたずれの定義」](09-features.md#縮めたずれの定義)）。k は切り口ごとに決める |
| 基準 | ずれを測るときの比べ先。人気・休み明け・関西馬・好走経験は「同じグレードの重賞全体」の複勝率、前に行く馬・内枠は「同じ競馬場・コース・距離の全クラスのレース」の超過複勝率 | どちらも、そのレースの開催日より前だけから数える（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 6） |
| 超過複勝率 | 3着以内率から、頭数から見た期待（3 ÷ 頭数 の平均）を引いた値。複勝率は頭数が少ないほど高く出るので、頭数の違いをならして比べるためのもの | 前に行く馬・内枠のずれで使う（[09-features.md の「縮めたずれの定義」](09-features.md#縮めたずれの定義)） |
| 前に行く馬 | 脚質判定（JV-Data の今回レース脚質判定）が逃げ・先行だった馬 | K の切り口。過去の開催は確定した脚質判定で数え、自分が当てはまるか（走る前）は推定脚質（逃げ・先行）で見る（[09-features.md の K](09-features.md#k-重賞の傾向10個)） |
| 内枠 | 枠番 1〜3 の馬 | K の切り口。自分の枠の内寄りの度合いは max(0, 5−枠番)/4 で見る |
| 休み明け | 前走から 63日以上（中9週以上）あいた出走 | K の切り口 |
| 関西馬 | 栗東所属の馬 | K の切り口 |
| 好走経験者 | 同じ重賞（同じ特別競走番号）で、過去に 3着以内に入ったことがある馬 | K の切り口。自分が当てはまるかは、事実表の「同じ競走名のレースでの3着内の数」で見る |
| 持続性 | ある期間に測ったレースごとのずれが、あとの期間でも同じ向きに出るか。前半と後半の期間で測ったずれの相関係数で見る | K に入れる切り口を選んだ根拠（[09-features.md の「切り口を選んだ根拠（持続性の検証）」](09-features.md#切り口を選んだ根拠持続性の検証)） |
| 攻略ポイント | 分析ツール `tools/重賞攻略/` が重賞ごとに書く、傾向のずれと成績のページ。Git の対象外の `reports/重賞攻略/` にできる | モデルと同じ数え上げ（`tools/共通/stakes.py`）を使う（[01-overview.md の「関連する道具」](01-overview.md#関連する道具分析ツール重賞攻略)） |
