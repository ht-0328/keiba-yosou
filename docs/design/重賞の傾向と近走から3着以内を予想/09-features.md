# 09 特徴量

**この文書で決めること:** 予測の手がかり（特徴量）に、何を使うか。

**結論: 手本（近走と適性から3着以内を予想）の新しい材料をそのまま使い、この予想では K（重賞の傾向。10個）を足す。木曜・前日は馬の力の材料（M）と対戦レーティング（O）（前日は市場の評価 J も）に K、当日は今の材料（A〜J・L）と券種ごとの支持（N）と M に K を足した 295個である（2026-10-02 に作り直した。[15-decisions.md の 9](15-decisions.md#9-新しい一般の予想の材料で作り直し採用か引退かを決める2026-10-02)）。K は、そのレースより前の開催だけから数えた「縮めたずれ」である。マイニング予想は使わない。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 表の見方

- 例の値は、すべて同じ架空の1頭のもの。[01-overview.md の「1頭の例」](01-overview.md#1頭の例) の馬（2025年11月、東京・芝1800m・良の G3、16頭立て、4歳の牡馬、4枠7番、栗東所属、推定脚質は差し、去年の同じレースで3着）である。
- 「型」は、数値特徴量かカテゴリ特徴量かを示す。K の 10個は、すべて数値特徴量である。
- 「どこから」は、`stakes_tendency` の表（`StakesTendencyRepository` が読む。[04-classes.md の 2](04-classes.md#2-shared-に足す変えるもの)）の列の名前と、出走の行（事実表）の列の名前で書いた。
- 時点ごとの数（木曜 208・前日 220・当日 295）は [07-prediction-timing.md の「時点ごとに使う特徴量」](07-prediction-timing.md#時点ごとに使う特徴量) を参照。

## A〜J・L・M・N・O は手本と同じ

- **木曜・前日の材料**は、手本の M（馬の力の材料の 202個）・O（対戦レーティングの 7個。2026-10-02 に手本に足された）と J（市場の評価の 4個。前日から）をそのまま使う（[手本の 09 の M](../近走と適性から3着以内を予想/09-features.md)。一覧はこの予想の `ABILITY_CATALOG`）。
- **当日の材料**は、手本の当日と同じ A〜I（71個）・J（4個）・L（騎手・調教師・血統の市場に対する成績の 4個）・N（券種ごとのオッズから見た支持の 6個）・M のうち名前の重ならない 200個の 285個をそのまま使う（一覧はこの予想の `RACE_DAY_CATALOG`）。
- どの時点も、最後に K の10個を足す。手本の材料が変わったら、この予想の一覧も同じ形で変わる（一覧は手本と同じ共通の部品から作っている）。
- 2026-10-01 までの作り（A〜J の 75個と K の 85個）は、7つの区切りで採用の基準を満たさなかった（[15-decisions.md の 8](15-decisions.md#8-当たり具合の確かめ方)）。

重賞では A の「クラス」がほぼ一定（G1〜G3）になるが、外さない。グレードの違い（G1 か G3 か）を表す列として、そのまま働くためである。

## レースの同定

**「同じ重賞」は、競走名ではなく特別競走番号で見分ける。** 競走名は年によって変わる（冠スポンサーの変更など）が、特別競走番号は変わらない。

2011年以降の中央の重賞137番号で確かめた（2026-09-29）。

- 同じ名前が別の番号へ移った例: **0件**。
- 名前が変わった番号: 22件（名前で同定すると、この22レースで過去の開催が途切れる）。

同定と傾向の数え上げの SQL は `tools/共通/stakes.py` にあり（実装済み）、分析ツール（`tools/重賞攻略/`）と予想モデルが共通で使う。

## K. 重賞の傾向（10個）

そのレース（同じ特別競走番号）の過去の開催から数えた、有利不利のずれ。**そのレースの開催日より前の開催・基準だけから数える**（リークなし。[11-leak-prevention.md](11-leak-prevention.md#決まり) の 6）。10個とも、`StakesTendencyFeatures`（[04-classes.md の 4](04-classes.md#4-この予想だけのクラスの一覧)）が `stakes_tendency` の表と出走の行を `race_id` で突き合わせて作る。

| 特徴量 | 意味 | 例 | 型 | どこから |
|---|---|---|---|---|
| 重賞の過去開催の数 | DB にある、そのレースのそれより前の開催の数 | 14 | 数値 | `editions` |
| 上位人気の信頼度のずれ | 過去開催の1〜3番人気の複勝率の、縮めたずれ（同じグレードの基準比） | +0.04 | 数値 | `fav123_n`・`fav123_hits`・`base_fav123` から新しく作る |
| 1番人気の信頼度のずれ | 同じく、1番人気だけ | +0.02 | 数値 | `fav1_n`・`fav1_hits`・`base_fav1` から新しく作る |
| 前に行く馬のずれ | 過去開催で脚質判定が逃げ・先行だった馬の超過複勝率の、縮めたずれ（同じコースの基準比） | −0.05 | 数値 | `front_n`・`front_hits`・`front_exp`・`base_front_excess` から新しく作る |
| 前に行く馬のずれ×前に行くか | 上の値 ×（推定脚質が逃げ・先行なら 1、でなければ 0） | 0.00 | 数値 | 上の値と、出走の行の `style_before` |
| 内枠のずれ | 過去開催で枠1〜3だった馬の超過複勝率の、縮めたずれ（同じコースの基準比） | +0.01 | 数値 | `inner_n`・`inner_hits`・`inner_exp`・`base_inner_excess` から新しく作る |
| 内枠のずれ×枠の内寄り | 上の値 × max(0, 5−枠番)/4（枠1で 1、枠4で 0.25、枠5以上で 0） | +0.003 | 数値 | 上の値と、出走の行の `frame_no` |
| 休み明けのずれ×休み明けか | 過去開催で中9週以上（前走から63日以上）だった馬の複勝率の、縮めたずれ（同じグレードの基準比）×（自分が中9週以上なら 1） | 0.00 | 数値 | `rest_n`・`rest_hits`・`base_rest` と、出走の行の `interval_days` |
| 関西馬のずれ×関西馬か | 過去開催の栗東所属の複勝率の、縮めたずれ（同じグレードの基準比）×（自分が栗東なら 1） | +0.03 | 数値 | `west_n`・`west_hits`・`base_west` と、出走の行の `affiliation` |
| 好走経験者のずれ×好走経験があるか | 過去開催で「同じレースで3着以内の経験あり」だった馬の複勝率の、縮めたずれ（同じグレードの基準比）×（自分に経験があれば 1） | +0.06 | 数値 | `repeat_n`・`repeat_hits`・`base_repeat` と、出走の行の `same_race_places_before` |

- **「前に行く馬」は、脚質判定（JV-Data の今回レース脚質判定）が逃げ・先行だった馬で数える。** 最初のコーナーの順位で数えないのは、①コーナーを5回以上通るコース（中山2500mなど）では最初のコーナーの順位が記録から取れず、重賞の約 6% でこの切り口が空になる（脚質判定なら全レースで取れる）、②レースごとの傾向の持続性が、脚質判定のほうが強かった（相関 0.49 対 0.36〜0.37。下の「切り口を選んだ根拠」）、の2つの理由による。過去の開催は確定した脚質判定で数え、自分が当てはまるか（×前に行くか）は、走る前に分かる推定脚質で見る。
- **レース単位の列と、自分に掛けた列の使い分け。** 人気の信頼度2つは、レース全体の性格（このレースの人気は信じてよいか）としてそのまま入れる。自分が人気かどうかは、J の人気順位と組み合わせてモデルが学ぶ。前に行く馬・内枠は、レースの性格（前が止まるレースか、内が有利なコースか）としても、自分が当てはまるか（×前に行くか・×枠の内寄り）としても意味を持つので、両方入れる。休み明け・関西馬・好走経験は、当てはまらない馬には関係が無いので、自分に掛けた列だけを入れる。
- **新設の重賞**（過去の開催が 0）は、ずれが全部 0 になる。ずれは「基準との差」なので、情報が無ければ差も無い（欠損値にはしない）。
- 分かる時点は、「内枠のずれ×枠の内寄り」だけ前日から、ほかの9個は木曜からである（[07-prediction-timing.md の「時点ごとに使う特徴量」](07-prediction-timing.md#時点ごとに使う特徴量)）。

### 縮めたずれの定義

過去の開催が少ないレースでは、複勝率のずれの多くがまぐれである。そこで、切り口ごとに次の式で 0 に縮める（縮小推定。[02-glossary.md](02-glossary.md)）。

```text
縮めたずれ = n / (n + k) × (そのレースの過去の複勝率 − 基準の複勝率)
```

- `n` は、その切り口の過去の出走数（`*_n`）。`n = 0` のときは 0 にする。
- `k` は、切り口ごとに決めた定数（下の表）。過去の出走数が k と同じなら、ずれは半分に縮む。

> 架空の例: 過去の開催の1〜3番人気がのべ 40頭で、複勝率が 0.62。基準（同じ G3 全体のその日までの1〜3番人気）が 0.55 なら、生のずれは +0.07。k = 24 なので 40 ÷ (40 + 24) = 0.625 を掛けて、縮めたずれは +0.04 になる。

| 切り口 | k | 基準 |
|---|---|---|
| 上位人気（1〜3番人気） | 24 | 同じグレードの重賞全体の複勝率（その日より前） |
| 1番人気 | 8 | 同じグレードの重賞全体の複勝率（その日より前） |
| 前に行く馬 | 30 | 同じ競馬場・コース・距離の全クラスのレースの超過複勝率（その日より前） |
| 内枠 | 30 | 同じ競馬場・コース・距離の全クラスのレースの超過複勝率（その日より前） |
| 休み明け | 20 | 同じグレードの重賞全体の複勝率（その日より前） |
| 関西馬 | 40 | 同じグレードの重賞全体の複勝率（その日より前） |
| 好走経験者 | 12 | 同じグレードの重賞全体の複勝率（その日より前） |

**前に行く馬・内枠は、複勝率の代わりに「超過複勝率」（3着以内率 − 3÷頭数 の平均）で同じ式を使う。** 複勝率は頭数が少ないレースほど高く出る（3着以内の枠は頭数によらず3つ）。重賞はフルゲート近くが多いので、生の複勝率のまま全クラスの基準と比べると、一律に不利に見えてしまう。そこで、自分の側は (`front_hits` − `front_exp`) ÷ `front_n`、基準の側は `base_front_excess`（内枠も同様に `inner_*`・`base_inner_excess`）で比べる。`*_exp` は「3 ÷ 頭数」を足し合わせた期待の数である。

- 人気・休み明け・関西馬・好走経験の基準を「同じグレードの重賞全体」にするのは、これらがレースの格で変わる（G1 とG3 では人気の信頼度も休み明けの割合も違う）ためである。前に行く馬・内枠の基準を「同じ競馬場・コース・距離の全クラス」にするのは、これらがコースの形で決まる（クラスにはあまり依らない）ためで、全クラスで数えるほうが基準の行数を確保できる。
- k は、1開催あたりの出走数が多い切り口ほど大きい（上位人気は1開催に3頭、関西馬は数頭いるが、1番人気は1頭しかいない）。「何開催ぶんの情報でずれを半分にするか」がおおよそそろうように決めた。

## 切り口を選んだ根拠（持続性の検証）

**過去のずれが将来も続く（持続する）切り口だけを、特徴量にする。** 持続しないずれを入れると、モデルは過去のまぐれを信じてしまう。

2011〜2018年で計ったレースごとのずれと、2019〜2026年で計ったずれの相関係数で確かめた（2026-09-29。レース単位。詳しい数は Git の対象外の `reports/重賞攻略/` 側にある）。

| 切り口 | 前半と後半のずれの相関 | 特徴量にするか |
|---|---|---|
| 前に行く馬（脚質判定が逃げ・先行） | 0.49 | する |
| 前に行く馬（最初のコーナー3番手以内で数えた場合） | 0.36〜0.37 | **しない**（脚質判定のほうを採用。K の節の説明） |
| 内枠 | 0.30 | する |
| 上位人気（1〜3番人気）の信頼度 | 0.27 | する |
| 1番人気単独の信頼度 | 0.16 | する（下の説明） |
| 荒れ度（勝ち馬の平均人気） | 0.16 | **しない** |
| 二桁人気の好走 | 0.13 | **しない** |

- 1番人気単独は相関が低め（0.16）だが、持続する「上位人気の信頼度」（0.27）の内側の切り口であり、この予想の狙い（1番人気を疑う）の中心なので、縮めを強めにして（1開催に1頭しかいないので、開催数の少ないレースではほぼ 0 になる）残す。
- 荒れ度と二桁人気の好走は、持続しないので特徴量にしない。分析ツールのページには、「過去にこうだった」という事実として、持続しないという注意書き付きで載せる（[01-overview.md の「関連する道具」](01-overview.md#関連する道具分析ツール重賞攻略)）。
- 休み明け・関西馬・好走経験は、切り口が馬の側の属性で、上と同じレース単位の測り方ができない（当てはまる馬が毎年変わる）。属性のずれとして数えて縮めを強めにし、効き目は学習と検証で確かめる。

## 使うデータの期間

**方針: DB に今入っている期間を、特徴量を外す理由にしない**（手本と同じ。[手本の 09 の「使うデータの期間」](../近走と適性から3着以内を予想/09-features.md#使うデータの期間)）。A〜J の元データの提供開始は手本の表のとおりである。この予想で足すのは次の1行だけである。

| データ | 表 | JRA-VAN の提供開始 | この設計での扱い |
|---|---|---|---|
| 傾向の数え上げの元（重賞の確定成績と、基準にする全クラスの確定成績） | `ra`・`se` | 1986年 | **2011年以降の開催から数える。** レースの同定（特別競走番号）を確かめたのが 2011年以降のため。それより前へ延ばすときは、番号の付け替えが無いかを確かめてから |

- 学習データの期間の既定（2012年1月から。ウォームアップ 2011年）は [08-training-data.md の 4](08-training-data.md#4-期間の指定) を参照。DB には 2011年からの中央の確定成績が要る。足りなければ jvdata-store で取得する。

## 使わない特徴量

そのレースの結果（着順・タイムなど）は、リークになるので候補にもしない（[11-leak-prevention.md](11-leak-prevention.md)）。JRA-VAN のマイニング予想と確定人気を使わない理由は、[手本の 09 の「使わない特徴量」](../近走と適性から3着以内を予想/09-features.md#使わない特徴量) と同じである。この予想では、次を足す。

| 特徴量 | 使わない理由 |
|---|---|
| 荒れ度のずれ（そのレースの勝ち馬の平均人気など） | 前半と後半の期間で相関 0.16 と持続しない（上の「切り口を選んだ根拠」）。「荒れやすいレース」という過去の印象は、将来の荒れを当てない |
| 二桁人気の好走のずれ | 相関 0.13 と持続しない。同上 |
