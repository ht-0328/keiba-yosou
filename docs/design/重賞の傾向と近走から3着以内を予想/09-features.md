# 09 特徴量

**この文書で決めること:** 予測の手がかり（特徴量）に、何を使うか。

**結論: 手本（近走と適性から3着以内を予想）の材料をそのまま使い、この予想では K（重賞の傾向。51個）を足す。木曜・前日は馬の力の材料（M）と対戦レーティング（O）（前日は市場の評価 J も）に K、当日は今の材料（A〜J・L）と券種ごとの支持（N）と M に K を足した 336個である。K は、そのレースより前の開催だけから数えた「その重賞の過去の開催で、自分と同じ条件だった馬の成績」そのもので、重賞全体やコースの平均（基準）とは比べない（2026-10-15 に作り直した。[15-decisions.md の 10](15-decisions.md#10-k-をその重賞の過去の開催で自分と同じ条件だった馬の成績に作り直し採用か引退かを決める2026-10-15)）。マイニング予想は使わない。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 表の見方

- 例の値は、すべて同じ架空の1頭のもの。[01-overview.md の「1頭の例」](01-overview.md#1頭の例) の馬（2025年11月、東京・芝1800m・良の G3、16頭立て、4歳の牡馬、4枠7番、栗東所属、推定脚質は差し、去年の同じレースで3着）である。
- K の 51個は、すべて数値特徴量である。
- 「どこから」は、`stakes_tendency` の表（過去の開催の出走馬。`StakesTendencyRepository` が読む。[04-classes.md の 2](04-classes.md#2-shared-に足す変えるもの)）の列の名前と、出走の行（事実表）の列の名前で書いた。
- 時点ごとの数（木曜 238・前日 261・当日 336）は [07-prediction-timing.md の「時点ごとに使う特徴量」](07-prediction-timing.md#時点ごとに使う特徴量) を参照。

## A〜J・L・M・N・O は手本と同じ

- **木曜・前日の材料**は、手本の M（馬の力の材料の 202個）・O（対戦レーティングの 7個。2026-10-02 に手本に足された）と J（市場の評価の 4個。前日から）をそのまま使う（[手本の 09 の M](../近走と適性から3着以内を予想/09-features.md)。一覧はこの予想の `ABILITY_CATALOG`）。
- **当日の材料**は、手本の当日と同じ A〜I（71個）・J（4個）・L（騎手・調教師・血統の市場に対する成績の 4個）・N（券種ごとのオッズから見た支持の 6個）・M のうち名前の重ならない 200個の 285個をそのまま使う（一覧はこの予想の `RACE_DAY_CATALOG`）。
- どの時点も、最後に K の51個を足す。手本の材料が変わったら、この予想の一覧も同じ形で変わる（一覧は手本と同じ共通の部品から作っている）。
- 2026-10-01 までの作り（A〜J の 75個と K の 85個）は、7つの区切りで採用の基準を満たさなかった（[15-decisions.md の 8](15-decisions.md#8-当たり具合の確かめ方)）。

重賞では A の「クラス」がほぼ一定（G1〜G3）になるが、外さない。グレードの違い（G1 か G3 か）を表す列として、そのまま働くためである。

## レースの同定

**「同じ重賞」は、競走名ではなく特別競走番号で見分ける。** 競走名は年によって変わる（冠スポンサーの変更など）が、特別競走番号は変わらない。

2011年以降の中央の重賞137番号で確かめた（2026-09-29）。

- 同じ名前が別の番号へ移った例: **0件**。
- 名前が変わった番号: 22件（名前で同定すると、この22レースで過去の開催が途切れる）。

同定と傾向の数え上げの SQL は `tools/共通/stakes.py` にあり（実装済み）、分析ツール（`tools/重賞攻略/`）と予想モデルが共通で使う。

## K. 重賞の傾向（51個）

そのレース（同じ特別競走番号）の過去の開催で、**自分と同じ条件だった馬がどれだけ走ったか**。**そのレースの開催日より前の開催だけから数える**（リークなし。[11-leak-prevention.md](11-leak-prevention.md#決まり) の 6）。重賞全体やコースの平均（基準）との差にはしない。そのレースの数字そのものを特徴量にし、どれだけ信じてよいかはモデルが「出走数」から学ぶ（縮小推定はしない）。51個とも数値特徴量で、`StakesTendencyFeatures`（[04-classes.md の 4](04-classes.md#4-この予想だけのクラスの一覧)）が、`stakes_tendency` の表（過去の開催の出走馬）と出走の行を、対象のレースで突き合わせて作る。

### レース単位の3個

| 特徴量 | 意味 | 例 | どこから |
|---|---|---|---|
| 重賞の過去開催の数 | DB にある、そのレースのそれより前の開催の数。重賞なら過去が無くても 0 | 14 | `stakes_tendency` の開催の数 |
| 過去開催の1番人気の複勝率 | 過去の開催の1番人気（確定単勝人気）が3着以内に入った割合 | 0.57 | `popularity` = 1 の行の `finish` |
| 過去開催の1〜3番人気の複勝率 | 同じく 1〜3番人気 | 0.52 | `popularity` ≤ 3 の行の `finish` |

### 切り口ごとの 12 × 4 = 48個

切り口（自分と同じ条件の決め方）は12個。切り口ごとに、過去の開催で自分と同じ帯だった馬の **出走数・複勝率・単勝回収率・複勝回収率** の4つを作る。特徴量の名前は「過去開催の〈切り口〉の〈成績〉」（例: 過去開催の前走のレースが同じ馬の複勝率）。

| 切り口 | 帯（同じ条件とみなすまとまり） | 自分の帯の決め方（出走の行） | 過去の開催の馬の帯の決め方 | 分かる時点 | 例（例の馬） |
|---|---|---|---|---|---|
| 前走のレースが同じ馬 | 前走のレースの鍵（重賞なら特別競走番号、ほかの特別競走なら競走名、平場ならクラス名、中央の前走が無ければ「前走なし」） | 対象の馬の行の `prev_key` | `prev_key` | 木曜 | 出走数 31・複勝率 0.35・複勝回収率 1.12 |
| 前走の着順が同じ帯の馬 | 1着 / 2〜3着 / 4〜9着 / 10着以下 / 前走なし | `prev_finish` | `prev_finish` | 木曜 | 複勝率 0.17 |
| 前走の人気が同じ帯の馬 | 1番人気 / 2〜3番人気 / 4〜9番人気 / 10番人気以下 / 前走なし | `prev_popularity` | `prev_popularity` | 木曜 | 複勝率 0.28 |
| 枠が同じ帯の馬 | 内（1〜3枠）/ 中（4〜5枠）/ 外（6枠から） | `frame_no` | `frame_no` | 前日 | 複勝率 0.21 |
| 単勝オッズが同じ帯の馬 | 3倍未満 / 3〜6倍 / 6〜10倍 / 10〜20倍 / 20〜50倍 / 50倍以上 | `win_odds`（予測では締め切り前のオッズ） | `win_odds`（確定オッズ） | 前日 | 複勝率 0.27・単勝回収率 0.95 |
| 人気が同じ帯の馬 | 1番人気 / 2〜3番人気 / 4〜5番人気 / 6〜9番人気 / 10番人気以下 | 単勝オッズの低い順（同じレースの中。同じオッズは同じ順位） | `popularity`（確定単勝人気） | 前日 | 複勝率 0.25 |
| 脚質が同じ馬 | 前（逃げ・先行）/ 後ろ（差し・追込）/ 不明 | `style_before`（推定脚質） | `style`（確定した脚質判定） | 木曜 | 複勝率 0.18 |
| 間隔が同じ帯の馬 | 休み明け（中9週以上）/ 休み明けでない / 前走なし | `interval_days` | `interval_days` | 木曜 | 複勝率 0.20 |
| 所属が同じ馬 | 栗東 / 美浦 / その他 | `affiliation` | `affiliation` | 木曜 | 複勝率 0.22 |
| 好走経験の有無が同じ馬 | あり / なし（同じレースで3着以内の経験） | `same_race_places_before` | `same_race_places_before` | 木曜 | 出走数 9・複勝率 0.44 |
| 年齢が同じ馬 | 2歳 / 3歳 / 4歳 / 5歳 / 6歳以上 | `age` | `age` | 木曜 | 複勝率 0.26 |
| 性別が同じ馬 | 牝 / 牡・セン | `sex` | `sex` | 木曜 | 複勝率 0.19 |

- **帯の境は `ConditionBands` の1か所に書き、過去の開催の馬と予測する馬を同じ決まりで分ける。** 帯が決まらない値（木曜の枠番・オッズ）は欠損値になり、その切り口の4つの成績も欠損値になる。脚質の「不明」は帯の1つとして数える。
- **出走数を特徴量に入れるのは、縮小推定の代わりである。** 過去の開催が少ないレースや、当てはまる馬の少ない帯（好走経験ありなど）では成績がまぐれに揺れる。どれだけ信じるかは、出走数と成績の組み合わせからモデルが学ぶ。
- **過去にその帯の馬がいなければ欠損値**（0 にしない）。「成績が無い」と「複勝率 0」は違う。新設の重賞（過去の開催が 0）は、過去開催の数が 0 で、ほかは全部欠損値になる。
- 成績の意味: 複勝率 = 3着以内の数 ÷ 出走数、単勝回収率 = 単勝の払戻（100円あたり）の合計 ÷ (100 × 出走数)、複勝回収率も同じ。払戻は過去の開催の確定払戻で、外れは 0。
- 前走のレースの鍵は、その馬のそのレースより前の最後の中央の出走から引く（`tools/共通/stakes.py` の `edition_runners_sql`）。地方・海外からの参戦や初出走は「前走なし」の帯になる。
- レース単位の「1番人気の複勝率」は、自分が1番人気でない馬にも入る（このレースの人気が信じてよいかという、レースの性格）。自分の人気の帯の成績は、切り口「人気が同じ帯の馬」が持つ。

## 切り口を選んだ理由

**利用者の指定（2026-10-15）による。** 重賞全体やコースの平均を基準にした「ずれ」には意味が無く、その重賞そのものの傾向（例: その G1 では前走がどのレースだった馬が走るか、外枠は有利か、単勝が何倍以上なら回収率が 100% を超えるか）で予想する（[15-decisions.md の 10](15-decisions.md#10-k-をその重賞の過去の開催で自分と同じ条件だった馬の成績に作り直し採用か引退かを決める2026-10-15)）。

- 前走のレース・枠・単勝オッズは、利用者が挙げた例をそのまま切り口にした。前走の着順・前走の人気・人気は、その隣にある同じ種類の条件で、道具「全頭評価」の傾向の文（前走のレース・前走の人気）ともそろう。
- 脚質・間隔（休み明け）・所属・好走経験は、2026-10-14 までの K の切り口を、ずれではなく成績そのものとして残した。年齢・性別は、道具「重賞攻略」の属性の切り口と同じで、古馬の G1 で4歳が強い、牝馬限定でない重賞で牝馬がどうか、のような傾向を持つ。
- レース単位の2個（1番人気・1〜3番人気の複勝率）は、前半（2011〜2018年）と後半（2019〜2026年）で測ったレースごとの値の相関が 0.16・0.27 あり（2026-09-29 の持続性の検証）、「このレースの人気は信じてよいか」というレースの性格として残した。
- 荒れ度（勝ち馬の平均人気）・二桁人気の好走は、前後半の相関が 0.16・0.13 と持続しないので、切り口にしない（分析ページには注意書き付きで載せる）。

## 使うデータの期間

**方針: DB に今入っている期間を、特徴量を外す理由にしない**（手本と同じ。[手本の 09 の「使うデータの期間」](../近走と適性から3着以内を予想/09-features.md#使うデータの期間)）。A〜J の元データの提供開始は手本の表のとおりである。この予想で足すのは次の1行だけである。

| データ | 表 | JRA-VAN の提供開始 | この設計での扱い |
|---|---|---|---|
| 傾向の数え上げの元（重賞の確定成績と、前走のレースを引く全クラスの確定成績） | `ra`・`se` | 1986年 | **2011年以降の開催から数える。** レースの同定（特別競走番号）を確かめたのが 2011年以降のため。それより前へ延ばすときは、番号の付け替えが無いかを確かめてから |

- 学習データの期間の既定（2012年1月から。ウォームアップ 2011年）は [08-training-data.md の 4](08-training-data.md#4-期間の指定) を参照。DB には 2011年からの中央の確定成績が要る。足りなければ jvdata-store で取得する。
- 予測のときの単勝オッズ（J）の与え方は、手本と同じである（[07-prediction-timing.md の「予測のときのオッズの与え方」](07-prediction-timing.md#予測のときのオッズの与え方)）。

## 使わない特徴量

そのレースの結果（着順・タイムなど）は、リークになるので候補にもしない（[11-leak-prevention.md](11-leak-prevention.md)）。JRA-VAN のマイニング予想と確定人気を使わない理由は、[手本の 09 の「使わない特徴量」](../近走と適性から3着以内を予想/09-features.md#使わない特徴量) と同じである。この予想では、次を足す。

| 特徴量 | 使わない理由 |
|---|---|
| 荒れ度（そのレースの勝ち馬の平均人気など）の切り口 | 前半と後半の期間で相関 0.16 と持続しない（上の「切り口を選んだ理由」）。「荒れやすいレース」という過去の印象は、将来の荒れを当てない |
| 二桁人気の好走の切り口 | 相関 0.13 と持続しない。同上 |
| 基準からのずれ（同じグレードの重賞全体・同じコースの全クラスとの差）と縮小推定 | 2026-10-14 までの K の作り。利用者の指定で、その重賞の数字そのものに変えた（[15-decisions.md の 10](15-decisions.md#10-k-をその重賞の過去の開催で自分と同じ条件だった馬の成績に作り直し採用か引退かを決める2026-10-15)） |
