# 01 重賞の傾向と近走から3着以内を予想する: 概要

**重賞（G1・G2・G3 の平地）だけを対象に、そのレースごとの傾向と、近走・適性・調教・血統と、市場の評価（単勝オッズ）から、出走馬ごとの「3着以内に入る確率」を出す予想である。**
レースごとの傾向とは、同じ重賞の過去の開催から数えた「自分と同じ条件（前走のレース・枠・人気やオッズの帯・脚質・年齢など）だった馬が、このレースでどれだけ走ったか（出走数・複勝率・単勝回収率・複勝回収率）」である。重賞全体やコースの平均と比べたずれではなく、そのレースの数字そのものを使う。同じ重賞は、競走名ではなく特別競走番号で見分ける（[02-glossary.md](02-glossary.md)）。
狙いは、**1番人気が本当に強いのかをレースごとの傾向で疑い、人気のわりに走る（期待値の高い）馬を重賞で見つける**ことである。
**JRA-VAN のマイニング予想は使わない。**

> **引退のまま。この専用モデルは使わない。重賞も一般の予想「近走と適性から3着以内を予想」で予想する。**
> K を「重賞全体との差」から「その重賞の過去の開催で、自分と同じ条件だった馬の成績」に作り直し（2026-10-15）、1年ずつの7つの区切りで確かめたが、木曜・前日・当日のどの時点でも、手本を重賞だけに使ったときより確率の誤差が小さくならなかった
> （K を外しても結果はほぼ同じ。重賞だけの約2万8千行では、手本が全レースの約70万行で学ぶ材料を学びきれない）。理由と決め方は [15-decisions.md の 10](15-decisions.md#10-k-をその重賞の過去の開催で自分と同じ条件だった馬の成績に作り直し採用か引退かを決める2026-10-15)（2026-10-02 の作り直しは [15 の 9](15-decisions.md#9-新しい一般の予想の材料で作り直し採用か引退かを決める2026-10-02)）。
> コードと `train`・`predict`・`evaluate` は確かめ直し用に残し、表に「引退」と書く。道具「重賞攻略」は残す。当日の予想の道具の重賞の表は、一般の予想の当日の予測を出す。

- 作り方: 機械学習の二値分類。LightGBM と CatBoost の2つのモデルで予測確率を出し、平均する（アンサンブル）。材料は手本の材料（木曜・前日は馬の力の材料 M と対戦レーティング O、当日は今の材料に券種ごとの支持 N と M）に、重賞の傾向（K。その重賞の過去の開催で、自分と同じ条件だった馬の成績）を足したもの。前日・当日は、手本の予想と同じく、オッズから作った基準（オッズから見た3着以内率）を出発点にして、傾向と馬の情報で上げ下げだけを学ぶ。
- 予測する時点: 木曜（出走馬名表）・前日（出馬表）・当日（馬体重の発表のあと）の3つのどれでも出せる。時点ごとに、その時点で分かる特徴量だけで学習した別のモデルを使う（[07-prediction-timing.md](07-prediction-timing.md)）。
- データの元: JRA-VAN Data Lab. の中央競馬のデータ（jvdata-store が DuckDB に貯めたもの）。
- 用語の意味: [02-glossary.md](02-glossary.md) を参照。
- 状態: **引退**（上の囲み）。プログラム（`src/yosou/stakes_tendency_top3/`）と分析ツール `tools/重賞攻略/` は残してある。学習済みモデル（新しい K で学習し直したもの）は Git 対象外の `reports/重賞の傾向と近走から3着以内を予想/models/`（確かめ直し用）。

手本とした予想（[手本の 01](../近走と適性から3着以内を予想/01-overview.md)）は、中央の平地の全レースの全頭について同じ確率を出す。この予想は、対象を重賞だけに絞り、そのぶん「そのレースならでは」の傾向（まとまり K）を特徴量に足したものである。重賞は毎年ほぼ同じ条件（競馬場・コース・距離・時期）で行われるので、レースごとの傾向を過去の開催から数えられる。ふつうの条件戦では、同じレースの過去の開催という考え方が成り立たないため、手本にはこのまとまりが無い。

## 1頭の例

架空の1頭を当日に予測する場合で、モデルに何を渡して何が返ってくるかを示す。傾向（まとまり K）の値の意味は [09-features.md の K](09-features.md#k-重賞の傾向51個) を参照。

> - **レース**: 2025年11月、東京・芝1800m・良の G3、16頭立て。このレース（特別競走番号は毎年同じ）の過去の開催は、DB に 14回ぶんある
> - **このレースの傾向（レース単位）**: 過去 14開催で、1番人気の複勝率 0.57、1〜3番人気の複勝率 0.52
> - **馬**: 4枠7番、4歳の牡馬、斤量 57kg、栗東所属 → このレースの過去の開催で、中枠（4〜5枠）だった馬の複勝率 0.21、4歳だった馬の複勝率 0.26、牡馬の複勝率 0.19、栗東の馬の複勝率 0.22
> - **前走**: 架空G2 で 4着、勝ち馬と 0.3秒差、42日ぶり → 過去の開催で前走が同じ架空G2 だった馬は 31頭で複勝率 0.35・複勝回収率 1.12、前走 4〜9着だった馬の複勝率 0.17、前走 2〜3番人気だった馬の複勝率 0.28、休み明けでない馬の複勝率 0.20
> - **近5走**: 平均 3.8着、推定脚質は差し → 過去の開催で後ろ（差し・追込）から行った馬の複勝率 0.18
> - **このレースの経験**: 去年の同じレースで 3着 → 過去の開催で好走経験のあった馬は 9頭で複勝率 0.44
> - **調教・血統**: 手本と同じ作りの特徴量（直近は坂路で 4ハロン 53.1秒、父B の産駒の近1年の3着以内の割合 0.29 など）
> - **市場の評価**: 単勝 9.5倍で、このレースの 4番人気 → 過去の開催で単勝 6〜10倍だった馬の複勝率 0.27・単勝回収率 0.95、4〜5番人気だった馬の複勝率 0.25
>
> → モデルの予測確率: **3着以内に入る確率 0.31**

## 使うデータ

手本の材料に、重賞の傾向（K）の51個を足して使う（木曜 238個・前日 261個・当日 336個。[07-prediction-timing.md](07-prediction-timing.md#時点ごとに使う特徴量)）。一覧は [09-features.md](09-features.md) を参照。

- **K 以外（A〜J・L・M・N・O）は、手本と同じである。** 何が分かるかの見取り図は [手本の 01 の「使うデータ」](../近走と適性から3着以内を予想/01-overview.md#使うデータ) を参照。
- **K（重賞の傾向。51個）が、この予想だけのまとまりである。**

| まとまり | 何が分かるか | 特徴量の例 |
|---|---|---|
| K. 重賞の傾向 | このレースの過去の開催で、自分と同じ条件（前走のレース・前走の着順・前走の人気・枠・単勝オッズ・人気・脚質・間隔・所属・好走経験・年齢・性別の12の切り口）だった馬が、どれだけ走ったか（出走数・複勝率・単勝回収率・複勝回収率）。レース単位では、過去の開催の数と、1番人気・1〜3番人気の複勝率 | 過去開催の前走のレースが同じ馬の複勝率、過去開催の単勝オッズが同じ帯の馬の単勝回収率 |

使わないデータとその理由は、[09-features.md の「使わない特徴量」](09-features.md#使わない特徴量) と [11-leak-prevention.md](11-leak-prevention.md) を参照。

## 関連する道具（分析ツール「重賞攻略」）

- 分析ツール `tools/重賞攻略/` が、重賞ごとの「攻略ポイント」のページ（人気の信頼度・脚質・枠・ローテ・属性の、基準からのずれと回収率）を、Git の対象外の `reports/重賞攻略/` に書く。基準（同じグレードの重賞全体・同じコースの全クラス）と比べるのは分析ページだけで、予想モデルの K は基準と比べない（[09-features.md の K](09-features.md#k-重賞の傾向51個)）。
- レースの同定（特別競走番号の対応表）と、過去の開催の出走馬を読む SQL は `tools/共通/stakes.py` にあり、予想モデル（[04-classes.md](04-classes.md) の `StakesTendencyRepository`）が使う。分析ツールも同じ対応表で重賞を見分ける。
- 分析ページには、特徴量にしない切り口（荒れ度・二桁人気の好走）も、持続しないという注意書き付きで載せる（[09-features.md の「使わない特徴量」](09-features.md#使わない特徴量)）。
- 同じページは、検索画面（`tools/検索画面/`）の「重賞攻略」タブでも見られる。CLI と画面は同じ部品（`tools/重賞攻略/guide.py`）を使う。
- 当日の予想（`tools/当日の予想/`）は、重賞の日に、そのレースの表の下に重賞の表を並べる。中身は一般の予想（近走と適性）の当日の予測（3着以内に入る確率と複勝の期待値）で、並べて見せるだけで、買い（複勝・期待値 1.2 以上）の判断には使わない。
