# 09 特徴量

**この文書で決めること:** 1着の確率の特徴量をどう扱うか。配当の見積もりの式に、どの値を渡すか。使わないものは何か。

| 決めること | 結論 |
|---|---|
| 1. 1着の確率（今のモデルのもの） | **この予想は1着の確率の特徴量を持たない。** 今のモデル（今毎週の予想に使っているモデル）の特徴量のまま使い、この予想のために足したり外したりしない |
| 2. 配当の見積もりに使う値 | 市場の組の確率の逆数の対数と、キャリーオーバーの比の対数の2つ。発売票数は、その日より前の回から見積もる |

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 1着の確率（今のモデルのもの）

今のモデルの1着の確率は、時点ごとに次の特徴量で学ばれている。一覧と数は手本にある（この文書には写さない）。

| 今のモデルの時点 | 特徴量 | 手本のどこに書いてあるか |
|---|---|---|
| 前日 | 馬の力の材料（M）・対戦レーティング（O）・市場の評価（J） | [手本の 07 の「時点ごとに使う特徴量」](../近走と適性から3着以内を予想/07-prediction-timing.md#時点ごとに使う特徴量) |
| 当日 | 今の材料（A〜J・L）・券種ごとのオッズから見た支持（N）・馬の力の材料（M の一部）・勝ち切る材料（Q） | 同上 |

- まとまりごとの特徴量の意味・例・型・どこから取るかは [手本の 09](../近走と適性から3着以内を予想/09-features.md) を参照。
- 今のモデルに特徴量を足す・外すときは、今のモデルの設計書（手本の 15）で決める。そのとき、この予想が使う1着の確率も一緒に変わる。その直しで WIN5 の成績がどう変わるかは、道具「印の成績」の WIN5 の表で見られる（[16-evaluation.md の 7.](16-evaluation.md#7-道具と全券種の回収率)）。

## 2. 配当の見積もりに使う値

配当の見積もりの式（[10-target.md の 2.](10-target.md#2-配当の見積もりで当てるもの)）に渡す値。組1つにつき、次の2つを作る（`PayoutFeatures`）。

| 値 | 意味 | 作り方 | 例 |
|---|---|---|---|
| 市場の組の確率の逆数の対数 | 市場がその組をどれだけ買っていなさそうか。大きいほど、当たったときの配当が大きい | 組の5頭の「オッズから見た勝率」（単勝オッズの逆数をレース内で合計 1 にそろえた値。共通の `MarketWinProbability`）をかけ算し、その逆数の対数をとる。5頭の単勝オッズのかけ算の対数と、ほぼ同じ向きに動く | 5頭のオッズから見た勝率が 0.13・0.30・0.07・0.25・0.16 なら、組の確率は約 0.00011、逆数は約 9,200、対数は約 9.1 |
| キャリーオーバーの比の対数 | キャリーオーバーが、払戻の元をどれだけ増やすか | log(1 + キャリーオーバー金額初期 ÷（発売票数の見積もり × 100円 × 払戻率）) | キャリーオーバーが無ければ 0 |

**発売票数の見積もり（`PoolSizeEstimate`）。** その日の発売票数は締め切りまで分からないので、その日より前の WIN5 のうち、同じ曜日の種類（土曜か、それ以外）の直近 10回の発売票数の中央値を使う。過去の回の式を作るときも、その回より前の回から同じように見積もった値を使う（その回の確定の発売票数は使わない。[11-leak-prevention.md の 8](11-leak-prevention.md#決まり)）。発売票数の見積もりは、キャリーオーバーの比と、払戻の上限・自分の1票の扱い（[06-flowchart.md の図2](06-flowchart.md#図2-組1つの配当の見積もり)）にだけ使う。

**市場の組の確率を材料にする理由。** WIN5 は、当たった票で払戻を分け合う。当たり票の数は、その組を買った人の数で決まり、買う人は単勝の人気をなぞって組を選びやすい。そのため、5頭の単勝の人気が低い組ほど当たり票が少なく、配当が大きい。払戻に回るお金をそのまま分け合うなら、配当は「払戻に回るお金 ÷（発売票数 × 市場の組の確率）」になり、対数をとると、市場の組の確率の逆数の対数に傾き 1 でそろう。実際には、WIN5 を買う人の選び方は単勝の人気とずれるので、傾きと切片は過去の当たり組から決める。

## 使わないもの

| 使わないもの | 理由 |
|---|---|
| 今のモデルに無い、WIN5 のための1着の確率の特徴量（WIN5 の対象レースかどうか など） | この予想は1着の確率を学ばない。1着になる力は対象かどうかで変わらない、という確認1の考えとも合う |
| 同じ日の、先に終わった対象レースの結果 | 予測する時点では、1レース目もまだ走っていない（[11-leak-prevention.md の 6](11-leak-prevention.md#決まり)） |
| WIN5 の票数（組ごとの売れ方） | JV-Data には、組ごとや馬ごとの WIN5 の票数が無い。発売票数の合計しか分からない |
| その日の確定の発売票数 | 締め切りまで分からない。見積もりで代える |
| 有効票数（対象レースが決まるごとの、当たる見込みの残りの票数） | レースが始まってからしか分からない |
| 発売票数そのもの・土曜か（配当の見積もりの式の材料として） | 払戻に回るお金をそのまま分け合うなら、発売票数は配当から消える（上の「市場の組の確率を材料にする理由」）。土曜と日曜の違いは、発売票数の見積もりの中で分けて扱う。式の外れが土曜で大きく偏っていたら、そのときに足す |
| 当たり組の5頭の人気の形（上位人気がいくつ・中穴がいくつ） | 市場の組の確率に、人気の形の情報はほぼ含まれている。分けて足すと、少ない回数で式を細かくしすぎる |
