# 01 近走と適性からWIN5の買い目を決める: 概要

**今毎週の予想に使っているモデル（設計書「近走と適性から3着以内を予想」。以下「今のモデル」）が出す各馬の「1着になる確率」を借りて、WIN5 の対象5レースの確率をかけ合わせた組ごとの当たる確率と、見積もった配当から、WIN5 の買い目と、その日に買うかどうかを出す予想である。この予想では、機械学習のモデルを新しく学ばない。**
今のモデルは、近走の内容と適性（そのコース・距離・馬場に向いているか）と市場の評価（単勝オッズ）から1着の確率を出している（[手本の 01](../近走と適性から3着以内を予想/01-overview.md)）。
WIN5 とは、JRA が日ごとに決めた5つのレースの1着の馬を、全部当てる馬券である（ルールの言葉と「今のモデル」の意味は [02-glossary.md](02-glossary.md#この予想で増える用語) を参照）。

- 作り方: 1着の確率は、今のモデルの1着の確率（LightGBM と CatBoost の平均）をそのまま使い、レースの中で合計が 1 になるようにそろえる。組の当たる確率は、5レースのそろえた確率のかけ算。配当は、元DB の WIN5 の表（`wf`）の過去の払戻から作った式で見積もる。この予想が学ぶのは、配当の見積もりの式（1次式）だけである。
- 1着の確率の元: 今のモデルは、中央の平地の全レースで学んでいる（WIN5 の対象レースに絞っていない）。今のモデルの学び方は手本の設計書にあり、この予想では変えない（[15-decisions.md の 1](15-decisions.md#1-1着の確率をこの予想で学ぶか)）。
- 予測する時点: WIN5 のある開催日ごとに、1レース目の発売の締め切り前に1回出す。対象レースごとに、今のモデルの当日のモデル（馬体重が出ているレース）か前日のモデル（まだのレース）の1着の確率を使う（[07-prediction-timing.md](07-prediction-timing.md)）。
- 買うかどうか: 予想は WIN5 のある日に毎回出す。買うのは、その日の判断用の買い目（1着の確率の順・50点）の期待値が線（1.25）以上の日だけ。買う日の予算は、利用者の決めた範囲（3,000〜10,000円）の中で2段階にし、本命の確率の積（5レースの本命のそろえた1着の確率のかけ算）が 0.0025 以上なら多く買う日（100点・1万円）、未満なら少なく買う日（30点・3,000円）の買い目を出す（[15-decisions.md の 13](15-decisions.md#13-1回の予算段階の予算)）。判断用の買い目の予算と線は、過去の WIN5 で比べて決めた（[16-evaluation.md の 4.](16-evaluation.md#4-買い目の組み方と買う日の線)）。キャリーオーバーの日は、配当の元が増える分を期待値に入れる。
- データの元: JRA-VAN Data Lab. の中央競馬のデータ（jvdata-store が DuckDB に貯めたもの）。
- 用語の意味: [02-glossary.md](02-glossary.md) を参照。
- 状態: **設計が決まり、予想のパッケージ `src/yosou/form_aptitude_win5_tickets`（`fit-payout`・`predict`）と、過去の WIN5 での確かめ（道具「印の成績」の `--win5`）と、毎回届ける仕組み（道具「発走前の通知」と開催日のまとめ）と、ポリシー用の財布で買う計画ができた。** 探索期間で選んだ買い方は確認期間で採用の基準に届かなかったので、予想は毎回出し、線以上の日はポリシー用の財布で買う（[16-evaluation.md の「確かめた結果」](16-evaluation.md#確かめた結果)）。1回の予算は、利用者の決めた範囲（3,000〜10,000円）の中で、多く買う日と少なく買う日に分ける段階の予算にした（[15-decisions.md の 13](15-decisions.md#13-1回の予算段階の予算)）。決めたことは [15-decisions.md](15-decisions.md) に集めた。作ったものと、残り（その日の WIN5 の取り込みが jvdata-store の main に入ること）は [05-sequence.md の「今は無く、これから作るところ」](05-sequence.md#今は無くこれから作るところ) を参照。

**手本との関係。** 手本の予想（今のモデル）は、全頭の「3着以内に入る確率」と「1着になる確率」を出し、印と単勝・複勝などの期待値に使う。この予想は、そのうち「1着になる確率」だけを借りて、WIN5 の5レースの組に広げる。手本に足すのは、確率をレースの中でそろえること、WIN5 の日の時点でレースごとに今のモデルのどの時点を使うかを選ぶこと、配当の見積もりと買い目の組み方の3つである。今のモデルを直せば、この予想が使う1着の確率も一緒に変わる。

## 1日の例

架空の WIN5 の日について、何を渡して何が返ってくるかを示す。1レース目の例の馬は、手本の [「1頭の例」](../近走と適性から3着以内を予想/01-overview.md#1頭の例) と同じ架空の馬とする。

> - **WIN5 の日**: 2025年5月の日曜。対象は架空の5レース（1レース目 東京11R・芝1600m・16頭立て など）。キャリーオーバーは無し
> - **1レース目の例の馬**: 手本の「1頭の例」の馬（単勝 6.8倍・2番人気、オッズから見た勝率 0.13、今のモデルの1着の確率 0.14）
> - **段階の予算**: 判断用 50点・少なく買う日 30点（3,000円）・多く買う日 100点（1万円）。買う日の線 1.25、多く買う日の線 0.0025
>
> → 1レース目のその馬の1着の確率（レースの中でそろえたもの）: **0.15**（上乗せ = 0.15 ÷ 0.13 = 1.15）
>
> → 判断用の買い目（50点）の期待値 **1.30**（線 1.25 以上なので買う日）。本命の確率の積 **0.0030**（0.25% 以上なので多く買う日）
>
> → 買う買い目（多く買う日の予算 100点）: 1レース目 2頭 × 2レース目 5頭 × 3レース目 2頭 × 4レース目 1頭 × 5レース目 5頭 = **100点**
>
> → 買い目のどれかが当たる確率 **0.06**、見積もった期待値 **1.18**。判断は「買う（多く）」、代金 1万円

この 1.18 は「この 100点を何度も買えば、平均で 1万円が 1万1,800円になる見込み」という意味である。本命の確率の積が 0.25% に届かない日は、少なく買う日の予算（30点）の買い目を出して「買う（少なく）」になる。判断用の買い目の期待値が線に届かない日も、少なく買う日の予算の買い目と当たる確率は同じ形で出す（そのときは「見送り」）。
