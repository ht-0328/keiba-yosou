# 07 いつ予測するか

**この文書で決めること:** WIN5 の予測をいつ行うか。そのときに、対象レースごとに今のモデル（今毎週の予想に使っているモデル）のどの時点の1着の確率を使うか。過去のレースで確かめるときに、その時点をどうまねるか。

| 決めること | 結論 |
|---|---|
| いつ予測するか | WIN5 のある開催日ごとに（日曜・土曜・祝日の月曜など）、**1レース目の発売の締め切り前（発走の 10分ほど前）に1回**出す |
| 対象レースごとの確率 | 馬体重と馬場状態が出ていれば今のモデルの当日の1着の確率、出ていなければ前日の1着の確率を使う。障害のレースはオッズから見た勝率をそのまま使う |
| 前日（前日発売）の予想 | 出さない。当日の1レース目の締め切り前だけ（[15-decisions.md の 4](15-decisions.md#4-前日前日発売の予想を出すか)） |
| 過去のレースでのまね方 | 1着の確率は、その年を学習に使っていない区切りごとの予測を使う。オッズは確定オッズで代える。馬体重は、1レース目の発走から 60分以上あとに発走するレースは「出ていない」とみなす |

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 時点ごとに分かること

1レース目の締め切り前（予測する時点）に、元DB に入っていることと、まだ分からないこと。

| 分かること | まだ分からないこと |
|---|---|
| その日の WIN5 の対象5レースとキャリーオーバー金額初期（速報の WIN5。[05-sequence.md の「今は無く、これから作るところ」](05-sequence.md#今は無くこれから作るところ)） | 5レースの結果（1レース目もまだ走っていない） |
| 5レースの出馬表・当日の馬場状態・締め切り前の単勝オッズと券種オッズ（いちばん新しい断面） | 5レースの確定オッズ。2レース目より後は、そのレースの締め切りまで十数分〜1時間ほどあるので、オッズはまだ動く |
| 発走の早いレースの馬体重 | 発走の遅いレースの馬体重 |
| それより前の WIN5 の発売票数・払戻 | その日の WIN5 の発売票数（締め切りまで売れ続ける） |

WIN5 の発売は1レース目の発走の前に締め切られるので、2レース目より後のレースの結果やオッズの動きを見て買い直すことはできない。そのため、予測は1レース目の締め切り前の1回だけにする。発走の 10分ほど前は、利用者が決めた「予想を出してよい時点」の線の内側である（発走の 1〜2分前の予想や、自動で買う仕組みは作らない）。

## 対象レースごとの確率の選び方

今のモデルは、木曜・前日・当日の時点ごとに別の1着のモデルを持つ（材料は [手本の 07 の「時点ごとに使う特徴量」](../近走と適性から3着以内を予想/07-prediction-timing.md#時点ごとに使う特徴量)）。この予想は、そのうち前日と当日を使う。

| 使う確率 | 使うとき |
|---|---|
| 今のモデルの当日の1着の確率 | 馬体重と馬場状態が発表されているレース。券種オッズが無ければ、今のモデルの中で券種オッズなしのモデルに切り替わる |
| 今のモデルの前日の1着の確率 | 締め切り前の単勝オッズと馬番はあるが、馬体重がまだ出ていないレース |
| オッズだけ | 障害のレース（今のモデルは障害を予想しない） |

判断の手順は [06-flowchart.md の図1](06-flowchart.md#図1-対象レースで使う確率の選び方) を参照。選び方は、道具「今週の予想」がレースごとに時点を選ぶやり方と同じ部品を使う。

- **木曜の1着の確率は使わない。** WIN5 の予測は開催日の当日に出し、どの対象レースにも締め切り前の単勝オッズがあるためである。木曜のモデルしか選べないレース（オッズが無い）があれば、予測を止める。
- 前日の1着の確率を出すときに渡すオッズは、前日発売のオッズではなく、予測する時点のいちばん新しい締め切り前のオッズである（今のモデルのオッズの決め方。[手本の 07 の「予測のときのオッズの与え方」](../近走と適性から3着以内を予想/07-prediction-timing.md#予測のときのオッズの与え方)）。

## 過去のレースで確かめるときの時点のまね方

過去の WIN5 で確かめるときは、次のようにまねる。

| 材料 | 実際に予想するとき（1レース目の締め切り前） | 過去のレースで確かめるとき |
|---|---|---|
| 1着の確率 | 今の学習済みのモデルの予測 | **区切りごとの予測**（半年ごとに、その半年より前のデータだけで今のモデルと同じ作りのモデルを学び直し、その半年を予測したもの）。今の学習済みのモデルは、確かめたい年も学習に使っているので、過去の予測には使わない（[11-leak-prevention.md の 10](11-leak-prevention.md#決まり)） |
| 単勝オッズ・券種オッズ | 締め切り前のいちばん新しい断面 | 確定オッズで代える（区切りごとの予測も、確定オッズで作られている）。この差の扱いは [11-leak-prevention.md の 7](11-leak-prevention.md#決まり) |
| 馬体重 | 発表されているレースだけ | 1レース目の発走時刻から **60分以上あと** に発走するレースは「まだ出ていない」とみなし、前日の区切りごとの予測を使う。それより前に発走するレースは当日の区切りごとの予測 |
| 馬場状態 | 当日の発表 | 確定の値（手本と同じ） |
| 発売票数 | 分からない（見積もる） | その日より前の回から見積もる（その日の確定の発売票数は使わない。[11-leak-prevention.md の 8](11-leak-prevention.md#決まり)） |

区切りごとの予測が、どの年からそろっているかと、どこにあるかは [16-evaluation.md の 1.](16-evaluation.md#1-期間の分け方) を参照。

**60分の理由。** 馬体重は、レースごとに発走の少し前に発表される。元DB の速報の馬体重には発表の時刻の列（`発表月日時分`）があるが、取り込んだ値はどれも空で、何分前に発表されるかを DB で確かめられなかった。60分は仮の値として決めた。発表の時刻が DB で読めるようになったら、その値で決め直す（[15-decisions.md の 10](15-decisions.md#10-過去のレースで馬体重が出ていたとみなす線)）。
