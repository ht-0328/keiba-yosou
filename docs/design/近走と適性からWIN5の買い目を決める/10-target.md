# 10 目的変数

**この文書で決めること:** この予想が使う1着の確率は、何を当てた確率で、どう使うか。配当の見積もりの式に何を当てさせ、その値をどう配当の見込みに戻すか。

| 決めること | 結論 |
|---|---|
| 1. 1着の確率（今のモデルのものを使う） | 今のモデル（今毎週の予想に使っているモデル）の目的変数「1着」（**その馬が1着なら 1、2着以下なら 0**）を当てた確率を借りる。この予想では学ばない。2つのモデルの平均を、レースの中で合計 1 にそろえて使う |
| 2. 配当の見積もりで当てるもの | 過去の WIN5 の当たり組の、100円あたりの払戻の対数。式の値を戻すときは、外れの散らばりの分を掛けて「平均の配当」にする |

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 1着の確率（今のモデルのものを使う）

**今のモデルの目的変数「1着」の作り方は、手本にある**（[手本の 10 の「作り方」](../近走と適性から3着以内を予想/10-target.md#作り方)）。確定着順が 1 なら 1、それ以外（2着以下・競走中止・失格）は 0 で、1 と 0 の数の偏りは直さず、オッズから見た勝率のロジットを出発点にして学んでいる。利用者が確認1で決めた目的変数（1着なら 1、2着以下なら 0）と同じなので、そのまま借りる（[15-decisions.md の 1](15-decisions.md#1-1着の確率をこの予想で学ぶか)）。

この予想が足すのは、**レースの中で合計 1 にそろえる** ことだけである。今のモデルは1頭ずつ確率を出す（二値分類）ので、同じレースの全頭を足しても 1 にならない。WIN5 の組の確率は5レースの確率のかけ算なので、レースごとのずれが5回重なる。そのため、今のモデルが2つのモデルの確率を平均したあとに、レースの中で割り算でそろえる（`RaceWinShare`。やり方は [03-library-basics.md の 2.](03-library-basics.md#2-レースの中で合計を-1-にそろえるpandas)）。そろえる前とそろえた後の確率の当たり具合は、過去の WIN5 での確かめで両方とも測る（[16-evaluation.md の 2.](16-evaluation.md#2-評価指標)）。

**1着の確率を使う理由。** WIN5 は、5つのレースの1着の馬を全部当てる馬券なので、要るのは各レースの「1着になる確率」そのものである。3着以内の確率からは、勝ち切る馬を見分けられない（手本の [10 の「理由」](../近走と適性から3着以内を予想/10-target.md#理由)）。

## 2. 配当の見積もりで当てるもの

### 当てるもの

過去の WIN5 の当たり組1つ（[08-training-data.md の 5.](08-training-data.md#2-配当の見積もりに使うデータ)）について、**100円あたりの払戻の対数**を当てる。材料は、市場の組の確率の逆数の対数（x1）と、キャリーオーバーの比の対数（x2）の2つ（[09-features.md の 2.](09-features.md#2-配当の見積もりに使う値)）。

```text
log(払戻) = 切片 + 傾き1 × x1 + 傾き2 × x2 + 外れ
```

- 傾きと切片は、過去の当たり組で、外れの2乗の合計がいちばん小さくなるように決める（scikit-learn の `LinearRegression`。[03-library-basics.md の 4.](03-library-basics.md#4-配当の見積もりの式を作るscikit-learn-の-linearregression)）。
- 払戻をそのままではなく対数で当てるのは、払戻が回ごとに何桁もちらばり、そのままでは大きな払戻の回だけで式が決まってしまうためである。対数にすると、市場の組の確率の逆数との関係がほぼ直線になる（[09-features.md の 2.](09-features.md#2-配当の見積もりに使う値) の「市場の組の確率を材料にする理由」）。

### 配当の見込みに戻す

組1つの「見積もりの配当」は、次の順に出す。

1. **式の値を戻す。** exp(切片 + 傾き1 × x1 + 傾き2 × x2) に、式を作るのに使った当たり組の exp(外れ) の平均を掛ける。対数の平均を戻しただけでは、配当の平均より小さく出るためである（[03-library-basics.md の 4.](03-library-basics.md#4-配当の見積もりの式を作るscikit-learn-の-linearregression)）。
2. **自分の1票と上限を当てる。** 払戻に回るお金（発売票数の見積もり × 100円 × 払戻率 + キャリーオーバー）を、ほかの人の当たり票の見込みと自分の1票で分け合い、払戻の上限で頭打ちにする（`PayoutCeiling`。[06-flowchart.md の図2](06-flowchart.md#図2-組1つの配当の見積もり)）。

`fit-payout` で決めた傾き・切片・戻すときの補正・使った期間は、`reports/近走と適性からWIN5の買い目を決める/payout_estimator.json` に保存する（`PayoutEstimatorRepository`）。

### この式の当たり具合

式がどれだけ合っているかは、式を作るのに使っていない回の当たり組で、見積もりの配当と実際の払戻を比べて測る（[16-evaluation.md の 8.](16-evaluation.md#8-配当の見積もりの確かめ)）。式が合っていないと、日の期待値がずれて、買う日の判断が狂う。
