# 12 LightGBM で学習・予測するための設計

**この文書で決めること:** この予想で、LightGBM について決めることがあるか。

**結論: この予想では LightGBM で学ばないので、決めることは無い。** この予想が使う1着の確率は、今のモデル（今毎週の予想に使っているモデル）の LightGBM と CatBoost の平均である（[15-decisions.md の 1](15-decisions.md#1-1着の確率をこの予想で学ぶか)）。今のモデルの LightGBM の設計（学習データの渡し方・ハイパーパラメータの初期値・カテゴリ特徴量の値の変え方・学習と予測のやりとり・保存）は、[手本の 12](../近走と適性から3着以内を予想/12-lightgbm.md) を参照。

- 番号と題名は、ほかの設計書とそろえるために残してある。
- この予想は、今のモデルの学習済みの LightGBM のモデル（`reports/近走と適性から3着以内を予想/models/` の1着のモデル）を、今のモデルの予測の流れを通して読むだけで、書き換えない（[04-classes.md の 1.](04-classes.md#1-今のモデルの1着の確率の受け取り方)）。
- 今のモデルの LightGBM を直すと、この予想の1着の確率も変わる。直したときに WIN5 の成績がどう変わるかは、区切りごとの予測を作り直して、道具「印の成績」の WIN5 の表で見る（[16-evaluation.md の 7.](16-evaluation.md#7-道具と全券種の回収率)）。
