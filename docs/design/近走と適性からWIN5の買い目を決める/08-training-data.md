# 08 学習データ

**この文書で決めること:** この予想が学ぶもの（配当の見積もりの式）のデータの1行を何にし、どの回を入れるか。1着の確率の学習データをどう扱うか。

| 決めること | 結論 |
|---|---|
| 1. 1着の確率の学習データ | **この予想では作らない。** 1着の確率は今のモデル（今毎週の予想に使っているモデル）のもので、その学習データ（中央の平地の全レース。WIN5 の対象レースに絞らない）は手本の 08 にある |
| 2. 配当の見積もりに使うデータ | 1行 = 過去の WIN5 の1回の当たり組（同着で当たり組が2つあれば2行）。元DB の `wf` の成績の版（データ区分 7）で、払戻のある回を使う。中止の回と的中無の回は入れない |

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 1着の確率の学習データ

今のモデルの学習データの形・列の種類・入れる行・期間は、[手本の 08](../近走と適性から3着以内を予想/08-training-data.md) を参照。今のモデルは、WIN5 の対象レースに絞らず、中央の平地の全レースで1着の確率を学んでいる。利用者の考え（WIN5 だからといって、1着を当てるレースの性質が変わるわけではない）と同じ形なので、この予想のために変えない。

この予想が1着の確率について持つのは、次の2つだけである。

| こと | どこに書いたか |
|---|---|
| 実際に予想するときに、今のモデルのどの時点の確率を使うか | [07-prediction-timing.md の「対象レースごとの確率の選び方」](07-prediction-timing.md#対象レースごとの確率の選び方) |
| 過去の WIN5 で確かめるときに、どの予測を使うか（区切りごとの予測） | [07-prediction-timing.md の「過去のレースで確かめるときの時点のまね方」](07-prediction-timing.md#過去のレースで確かめるときの時点のまね方)、[16-evaluation.md の 1.](16-evaluation.md#1-期間の分け方) |

## 2. 配当の見積もりに使うデータ

元DB の表 `wf`（重勝式。JRA-VAN の提供は 2011年4月から）と、その子表から作る。仕様は jvdata-store の [WF.md](../../../../jvdata-store/docs/reference/WF.md) を参照。読むのは `Win5HistoryRepository`（[04-classes.md](04-classes.md#repository--この予想だけの読み書き)）。

### 1行の形

架空の2回を例にすると、次の形になる。

| 開催日 | 当たり組 | 払戻（100円あたり） | 発売票数 | キャリーオーバー金額初期 | 当たり組の5頭の確定単勝オッズ | 返還 |
|---|---|---|---|---|---|---|
| 架空の日A | 03-05-01-04-06 | （架空の値） | （架空の値） | 0 | 6.8・2.4・12.0・3.1・5.5 | 無 |
| 架空の日B | 11-02-07-01-09 | （架空の値） | （架空の値） | （架空の値） | 21.5・4.0・1.8・9.9・33.0 | 有 |

### 元DB のどこから取るか

| 列 | 元DB | 読み方 |
|---|---|---|
| 開催日 | `wf` の開催年・開催月日 | キー |
| 対象レース | 子表 `wf__重勝式対象レース情報` の競馬場コード・開催回・開催日目・レース番号（`_連番` 1〜5 が発売の順） | レースの鍵につないでレースID にする |
| 当たり組・払戻・的中票数 | 子表 `wf__重勝式払戻情報` の組番・重勝式払戻金・的中票数 | 同着のときは行が2つ以上ある |
| 発売票数 | `wf` の重勝式発売票数 | 発売金額 = 票数 × 100円 |
| キャリーオーバー | `wf` のキャリーオーバー金額初期・残高 | 初期は、その日の初めの額（予測の時点で分かる） |
| 返還・的中無・不成立 | `wf` の返還フラグ・的中無フラグ・不成立フラグ | 下の決まり |
| 当たり組の5頭の確定単勝オッズ | `se`（馬毎レース情報）のいちばん新しい行の単勝オッズ（対象レースの勝ち馬の行と、そのレースの全頭の逆数の合計。事実表は作らない） | 市場の組の確率の元（[09-features.md の 2.](09-features.md#2-配当の見積もりに使う値)） |

### どの回を入れるか

| 決まり | 内容 | 理由 |
|---|---|---|
| 版 | データ区分 7（成績の月曜の版）だけを使う | 払戻が確定した版である。データ区分 9（中止）の回は払戻が無い |
| 的中無の回 | 式を作るのに入れない | 払戻の値が無い（当たり票が0）。「市場の組の確率がとても小さい組は、当たる人がいない」ことは、自分の1票の扱いで入れる（[06-flowchart.md の図2](06-flowchart.md#図2-組1つの配当の見積もり)） |
| 返還のある回 | 入れる | 返還は取消・除外の馬を含む組の代金が戻るだけで、当たり組の払戻はそのまま使える |
| 同着の回 | 当たり組ごとに1行 | 当たり組ごとに払戻が決まっているため |
| 障害のレースが対象に入った回 | 入れる | 配当の見積もりは単勝オッズだけを使うので、障害でも材料がそろう |
| 期間 | 2011年4月から、`fit-payout` の `--before` の日より前まで。過去の WIN5 での確かめでは、区切りごとに、その区切りのテスト期間の始まりより前まで | 確かめる期間の払戻を式に入れると、答えを知って見積もることになる（[11-leak-prevention.md の 8](11-leak-prevention.md#決まり)） |

### 回数の数え上げ

元DB の WIN5 は、2011年4月24日〜2026年11月1日の成績の版で 903回ある（このほかに中止の回が 14）。期間ごとには次のとおり。キャリーオーバーのあった回は、ごく少ない。

| 期間 | 回数 | そのうちキャリーオーバーのあった回 |
|---|---|---|
| 2011年4月〜2018年 | 421 | 11 |
| 2019年〜2024年 | 340 | 2 |
| 2025年〜 | 142 | 4 |

- 対象レースは 903回で 4,515 あり、そのうち障害は 4つ（どれも12月）だった。
- 対象レースは1年に 300ほどで、全レースよりずっと少ない。
- 土曜の WIN5 は、2024年から毎年増えている（2026年は、土曜の回が日曜の回の半分を超える）。祝日の月曜や、開催がずれた日の回もある。
