# 11 リークを防ぐ決まり

**この文書で決めること:** 過去の WIN5 での確かめでは当たるのに、実際に買うときには当たらない予想（リーク）にならないよう、1着の確率・配当の見積もり・確かめで守る決まり。

**結論: 1着の確率と配当の見積もりは、予測する時点（1レース目の締め切り前。[07-prediction-timing.md](07-prediction-timing.md)）で分かることだけから作る。1〜5 は今のモデル（今毎週の予想に使っているモデル）の特徴量の決まりで、手本と同じ。この予想では、同じ日の対象レースの結果（6）、締め切り時点のオッズと確定オッズの差（7）、配当の見積もり（8）、馬体重（9）、過去の年の1着の確率（10）の決まりを足す。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 決まり

1〜5 は今のモデルの決まりで、[手本の 11 の「決まり」](../近走と適性から3着以内を予想/11-leak-prevention.md#決まり) を参照する（そのレースの結果を使わない、過去走と調教は開催日より前のものだけから計算する、マスタの累計の成績を使わない、学習データと予測用データを同じプログラムで作る、確定オッズは特徴量に使ってよいが予測では締め切り前のオッズになる）。この予想は今のモデルの予測の流れをそのまま呼ぶので（[04-classes.md の 1.](04-classes.md#1-今のモデルの1着の確率の受け取り方)）、1〜5 はそのまま守られる。

**6. 同じ日の対象レースの結果は、後ろのレースの予測に使わない。**

- 予測は1レース目の締め切り前に1回だけ出すので、5つのレースの結果はどれも分かっていない。過去の WIN5 で確かめるときも、2レース目より後の予測に、先に終わった対象レースの結果（勝ち馬・着順・馬場の傾き）を使わない。今のモデルの決まり 2（同じ日の先に終わったレースも使わない）が、そのままこれを守る。
- 有効票数（対象レースが決まるごとの残りの票数）も、レースが始まってからしか分からないので使わない（[09-features.md の「使わないもの」](09-features.md#使わないもの)）。

**7. 過去の WIN5 での確かめは確定オッズで行い、実際に予想する時点のオッズとの差を結果に書き添える。**

- 元DB の終わったレースのオッズは確定オッズだけなので、過去の WIN5 での確かめでは、5レースの単勝オッズ・券種オッズを確定オッズで代える（[07-prediction-timing.md の「過去のレースで確かめるときの時点のまね方」](07-prediction-timing.md#過去のレースで確かめるときの時点のまね方)）。区切りごとの予測（下の 10）も、確定オッズで作られている。
- 実際に予想するときに使うのは、1レース目の締め切り前の断面である。1レース目は締め切りの直前なので確定オッズとほぼ同じだが、2レース目より後は、そのレースの締め切りまで十数分〜1時間ほどあり、オッズはまだ動く。**レースごとに締め切りの直前に予想する今のモデルの使い方（週末の予想・発走前の通知）より、確定オッズとの差が大きくなる。**
- この差は、今のモデルの1着の確率（基準と特徴量にオッズを使う）、上乗せ、市場の組の確率（配当の見積もり）の全部に入る。確定オッズで確かめた回収率は、実際に買うときより良く出ることがあるので、確かめの結果には必ず書き添える。あわせて、実際に予想した結果（使ったオッズの断面を含む）を自動で記録し、たまったらその成績も同じ表で見る（[15-decisions.md の 7](15-decisions.md#7-締め切り時点のオッズと確定オッズの差の扱い)。記録は `Win5ForecastRecordRepository`）。

**8. 配当の見積もりの式と発売票数の見積もりは、その日より前の WIN5 だけから作る。**

- 式（傾き・切片・戻すときの補正）は、`fit-payout` では `--before` の日より前の回だけ、過去の WIN5 での確かめでは区切りごとにテスト期間の始まりより前の回だけで作る（[08-training-data.md の 2.](08-training-data.md#2-配当の見積もりに使うデータ)）。確かめる期間の払戻を式に入れると、答えを知って配当を見積もることになる。
- 発売票数は、その日の確定の値（締め切り後に決まる）を使わず、その日より前の回から見積もる。式を作るときも、各回について、その回より前の回から見積もった値を使う（[09-features.md の 2.](09-features.md#2-配当の見積もりに使う値)）。式を作るときと予測するときで、同じ作り方にするためである。
- キャリーオーバーは、その日の初めの額（キャリーオーバー金額初期）だけを使う。その日の残高（次の回へ持ち越す額）は、結果が出てから決まる。

**9. 過去の WIN5 で確かめるときの馬体重は、予測する時点で出ていたかをまねる。**

- 実際に予想するときは、1レース目の締め切りの時点で馬体重が出ていないレースは、今のモデルの前日の1着の確率（馬体重を使わない）を使う。過去の WIN5 で全部のレースを当日の確率（馬体重を使う）にすると、実際より材料の多い予測で確かめることになる。
- そのため、1レース目の発走から決まった時間より後に発走するレースは、馬体重が出ていないとみなして前日の確率を使う（線の値は [07-prediction-timing.md の「過去のレースで確かめるときの時点のまね方」](07-prediction-timing.md#過去のレースで確かめるときの時点のまね方)）。

**10. 過去の WIN5 で確かめるときの1着の確率は、その年を学習に使っていないモデルの予測にする。**

- 今の学習済みのモデルは、確かめたい年の多くを学習と検証に使っている（学習データの期間は [手本の 08 の「4. 期間の指定」](../近走と適性から3着以内を予想/08-training-data.md#4-期間の指定)。前日のモデルは 2012年から、当日のモデルは 2021年8月から学ぶ）。それで過去の WIN5 の対象レースを予測すると、答え（そのレースの勝ち馬）を学んだモデルの確率になり、当たり具合も回収率も実際より大きく良く出る。
- そのため、過去の WIN5 で確かめるときは、**区切りごとの予測**（半年ごとに、その半年より前のデータだけで今のモデルと同じ作りのモデルを学び直し、その半年のレースを予測したもの）を使う。手本の確かめ（研究「既存モデルの改善」）と道具「印の成績」が、過去の年の印の成績を出すときと同じやり方である。どの区切りの予測がどこにあるかは [16-evaluation.md の 1.](16-evaluation.md#1-期間の分け方) を参照。
- 区切りごとの予測は、作ったときの今のモデルの作りで学んでいる。今のモデルの作り（特徴量など）が変わったら、同じ仕組みで作り直してから確かめる。
