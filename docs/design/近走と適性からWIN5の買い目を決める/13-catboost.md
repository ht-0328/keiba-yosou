# 13 CatBoost で学習・予測するための設計

**この文書で決めること:** この予想で、CatBoost について決めることがあるか。

**結論: この予想では CatBoost で学ばないので、決めることは無い。** この予想が使う1着の確率は、今のモデル（今毎週の予想に使っているモデル）の LightGBM と CatBoost の平均である（[15-decisions.md の 1](15-decisions.md#1-1着の確率をこの予想で学ぶか)）。今のモデルの CatBoost の設計（学習データの渡し方・ハイパーパラメータの初期値・カテゴリ特徴量の値の変え方・学習と予測のやりとり・保存）は、[手本の 13](../近走と適性から3着以内を予想/13-catboost.md) を参照。

- 番号と題名は、ほかの設計書とそろえるために残してある。
- この予想は、今のモデルの学習済みの CatBoost のモデルを、今のモデルの予測の流れを通して読むだけで、書き換えない（[04-classes.md の 1.](04-classes.md#1-今のモデルの1着の確率の受け取り方)）。
- LightGBM と CatBoost の両方を使うこと（利用者の指示）は、今のモデルの中で守られている。
