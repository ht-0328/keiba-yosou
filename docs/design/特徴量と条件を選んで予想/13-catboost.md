# 13 CatBoost で学習・予測するための設計

**この文書で決めること:** 07〜10 で決めた学習データ（特徴量と目的変数）を、CatBoost で学習・予測するために、CatBoost だけに必要なことを決める。**節の番号と題名は、手本の 13 とそろえてある。**

| 決めること | 結論 |
|---|---|
| 1. 学習データの渡し方 | 手本と同じ。選んだ特徴量だけを渡す。`odds_baseline: true` なら、オッズの基準を `Pool` の `baseline` に渡す |
| 2. ハイパーパラメータの初期値 | 手本と同じ値から始める。設定ファイルの `catboost` で変えられる |
| 3. カテゴリ特徴量の値の変え方 | 手本と同じ |
| 4.〜6. 学習・予測・保存の手順 | 設定1つにつき、選んだ1つの時点のモデルを1つ学習する。保存先は LightGBM と同じフォルダ |

- 用語の意味は [02-glossary.md](02-glossary.md) を参照。
- 学習データ・特徴量・目的変数は LightGBM と共通で、[08-training-data.md](08-training-data.md)・[09-features.md](09-features.md)・[10-target.md](10-target.md) を参照。
- LightGBM の設計は [12-lightgbm.md](12-lightgbm.md) を参照。
- CatBoost の使い方の基本は [手本の 03 の「5. CatBoost の使い方」](../近走と適性から3着以内を予想/03-library-basics.md#5-catboost-の使い方) を参照。

## 1. 学習データの渡し方

**列ごとの渡し方は手本と同じである**（数値はそのまま、カテゴリは文字列のまま `cat_features` に指定、カテゴリの欠損値は文字列「不明」、ID 列と評価用の列は渡さない）。[手本の 13 の「1. 学習データの渡し方」](../近走と適性から3着以内を予想/13-catboost.md#1-学習データの渡し方) を参照。渡すのは、特徴量テキストに書いた列だけで、依存項目と条件の列は渡さない。`cat_features` には、選んだ特徴量のうちカテゴリのものだけを並べる。

**オッズの基準（`odds_baseline: true`）のとき。** LightGBM と同じ基準のロジットを、`Pool` の `baseline` に渡す。基準の中身と、使う理由は [12-lightgbm.md の「1. 学習データの渡し方」](12-lightgbm.md#1-学習データの渡し方) を参照（2つのモデルで同じ基準を使う）。

## 2. ハイパーパラメータの初期値

**手本と同じである。** 引数と意味の表は [手本の 13 の「2. ハイパーパラメータの初期値」](../近走と適性から3着以内を予想/13-catboost.md#2-ハイパーパラメータの初期値) を参照（`loss_function` は `Logloss`、`learning_rate` 0.05、`iterations` 2000、`early_stopping_rounds` 100、`depth` 6、`l2_leaf_reg` 3、`random_seed` 42）。設定ファイルの `catboost` で変えられる（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)）。

- `loss_function` は変えられない（二値分類に決まっているため）。
- 1 と 0 の数の偏りを直す設定（`auto_class_weights`）は使わない（[10-target.md](10-target.md#1-と-0-の数の偏り)）。

## 3. カテゴリ特徴量の値の変え方（フローチャート）
