# 01 特徴量と条件を選んで予想する: 概要

**利用者が選んだ特徴量と条件（競馬場・距離・人気など）から、対象の馬1頭ずつについて「選んだ目的（3着以内・4着以下・1着）になる確率」を出す予想である。**
ほかの予想は、特徴量も対象の馬も目的変数も設計書で1つに決めている。この予想は、それらを **設定ファイル（YAML）と特徴量テキスト** で利用者が選ぶ。「短距離のレースで、馬体重が 440kg 以下の、6〜10番人気の馬が3着以内に入る確率」のような予想を、プログラムを書き換えずに作れる。

- 作り方: 機械学習の二値分類。LightGBM と CatBoost の2つのモデルで予測確率を出し、平均する（アンサンブル）。
- 選べるもの: 特徴量（90個の中から何個でも）、目的（馬券内・馬券外・勝利）、予測する時点（木曜・前日・当日のどれか1つ）、人気範囲、対象を絞る条件、オッズを出発点にするか、学習期間、ハイパーパラメータ（[07](07-prediction-timing.md)〜[10](10-target.md)、[14](14-hyperparameter-settings.md)）。
- 回収率: 学習と評価の結果に、単勝・複勝の回収率を出す（[16-evaluation.md](16-evaluation.md)）。
- データの元: JRA-VAN Data Lab. の中央競馬のデータ（jvdata-store が DuckDB に貯めたもの）。
- 用語の意味: [02-glossary.md](02-glossary.md) を参照。
- 使い方（コマンドと設定ファイルの書き方）: [docs/custom_binary.md](../../custom_binary.md) を参照。この設計書は、なぜその作りにしたかを書く。
- 状態: プログラムは `src/yosou/custom_binary/` に作った（2026-09-26 に main に入った）。この設計書は、作ったあとに、今のコードに合わせて書いた。

## 1頭の例

架空の設定で、架空の1頭を当日に予測する場合で、何を選んで何が返ってくるかを示す。馬は手本の [「1頭の例」](../近走と適性から3着以内を予想/01-overview.md#1頭の例) と同じ架空の馬とする。

> - **設定**: 目的 = 馬券内、時点 = 当日、人気範囲 = 6〜10番人気、条件 = 芝で距離 1600m 以下、オッズを出発点にする
> - **特徴量テキスト**: 競馬場、距離、馬齢、斤量、前走の着順、近5走の平均着順、推定脚質、騎手、3連複から見た3着以内率、3連複から見た3着以内率と単勝の差（10個）
> - **レース**: 2025年5月、東京・芝1600m・良、オープン、16頭立て
> - **馬**: 8番人気（範囲に入る）。単勝オッズから見た3着以内率 0.09、3連複から見た3着以内率 0.13
>
> → モデルの予測確率: **3着以内に入る確率 0.12**

この 0.12 は、単勝オッズから見た 0.09 を出発点に、ほかの特徴量（3連複のほうが高く見ていることなど）で上げた値である。複勝の想定払戻倍率が 10倍なら、期待値は 1.2 になる（[16-evaluation.md](16-evaluation.md#2-評価指標)）。

## 使うデータ

**特徴量は、登録された 90個の中から選ぶ。** 90個は、手本の A〜I（71個）、人気の履歴 J（4個）、単勝オッズから見た評価 K（3個）、券種オッズの特徴量（12個）である。一覧は [09-features.md](09-features.md) を参照。

| まとまり | 何が分かるか | 特徴量の例 |
|---|---|---|
| A〜I（手本と同じ） | レースの条件、馬のこと、騎手と調教師、前走、近走、この条件での経験、同じレースの馬との比較、血統、調教 | 距離、馬体重、騎手、前走の着順 |
| J. 人気と人気の履歴 | 今回どれだけ人気か。これまで人気より走ってきたか | 人気順位、近5走の平均人気 |
| K. 単勝オッズから見た評価 | 単勝の市場がどれだけ支持しているか | 単勝オッズ、オッズから見た3着以内率 |
| 券種オッズ | 3連単・3連複など売上の大きい券種が、単勝と違う見方をしているか | 3連複から見た3着以内率、その単勝との差 |

特徴量は、クラスを1つ書いて登録すれば増やせる（[09-features.md](09-features.md#特徴量を足す仕組み)）。

## 図の使い分け

**図は2種類（シーケンス図とフローチャート）だけを使う。使い分けの方針は、手本と同じである。** 方針と、記号がコードの何に当たるかは [手本の 01 の「図の使い分け」](../近走と適性から3着以内を予想/01-overview.md#図の使い分け) を参照。図は Mermaid で書いてある。VS Code で見るには、拡張機能 `bierner.markdown-mermaid` が要る。

この設計書では、次の4枚を描く。

| 図 | 何を描いたか | 置き場所 |
|---|---|---|
| シーケンス図 図1 | 学習のやりとり（設定を読む → 券種オッズを付ける → 全頭で特徴量を作る → 絞る → 学習・保存） | [05-sequence.md](05-sequence.md#図1-学習) |
| シーケンス図 図2 | 予測のやりとり（人気とオッズを決める → 特徴量を作る → 絞る → 確率） | [05-sequence.md](05-sequence.md#図2-予測) |
| フローチャート 図1 | 学習データに入れる行の選び方（人気範囲と条件の判断を含む） | [06-flowchart.md](06-flowchart.md#図1-学習データに入れる行の選び方) |
| フローチャート 図2 | 特徴量を計算する順番の決め方（依存と時点の判断） | [06-flowchart.md](06-flowchart.md#図2-特徴量を計算する順番の決め方) |

モデルごとの図（カテゴリ特徴量の値の変え方、学習・予測のやりとり）は、手本と同じなので描かない（[12-lightgbm.md](12-lightgbm.md)・[13-catboost.md](13-catboost.md)）。
