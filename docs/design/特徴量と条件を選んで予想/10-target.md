# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。

**結論: 設定ファイルの `target` で、馬券内（1〜3着）・馬券外（4着以下と中止・失格）・勝利（1着）の3つから1つを選ぶ。同着は確定着順に従う。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 作り方

学習データの1行は、1レースの対象の馬1頭である（[08-training-data.md](08-training-data.md#1-学習データの形)）。その1頭の結果から、次のように目的変数を決める。

| その馬の結果 | 馬券内 | 馬券外 | 勝利 |
|---|---|---|---|
| 確定着順が 1着 | 1 | 0 | 1 |
| 確定着順が 2着・3着 | 1 | 0 | 0 |
| 確定着順が 4着以下 | 0 | 1 | 0 |
| 競走中止・失格 | 0 | 1 | 0 |
| 出走取消・発走除外・競走除外 | ― | ― | ― |

- 取消・除外は、走っていないのでサンプルにしない（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)）。
- 着順は**確定着順**を使う。降着があれば降着後の着順、同着はどちらも同じ着順である（3着同着なら2頭とも馬券内）。
- **7頭以下のレースでも、3着以内かどうかで決める。** 複勝は7頭以下だと2着までしか付かないが、目的変数は頭数で変えない（手本と同じ決まり）。回収率は実際の払戻で数えるので、複勝の付き方の違いは回収率に入る（[16-evaluation.md](16-evaluation.md)）。

`predict_proba()` の2列目が、選んだ目的変数が 1 になる確率である。**馬券外のモデルでは、確率が高いほど「馬券外になりやすい」**（来やすいではない）。

## 理由

- **3つにした理由。** 買う馬券（複勝・単勝）と、消す判断（危険な人気馬）に、それぞれ対応させた。馬券内は複勝、勝利は単勝、馬券外は人気馬を消すときに使う。
- **中止・失格を馬券外にする理由。** 出走して馬券にならなかった点は、4着以下と同じだからである（危険な人気馬の予想と同じ）。
- **1つの設定で1つだけにした理由。** 目的ごとにモデルを分けるほうが、設定と結果の対応が分かりやすい。3つとも見たいときは、`target` だけを変えた設定を作る（[15-decisions.md](15-decisions.md#5-目的変数を3つから選ぶか)）。

## 1 と 0 の数の偏り

偏りの大きさは、目的と人気範囲で大きく変わる（例: 勝利 × 10番人気以下は、1 がごく少ない）。**偏りは直さずにそのまま学習する。** 予測確率を確率として使う（期待値を計算する）ので、確率の大きさがずれる設定は使わない（手本と同じ。[手本の 10](../近走と適性から3着以内を予想/10-target.md)）。

学習データか検証データで、目的変数が片方の値しか無いときは、学習を始める前に止める（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)）。
