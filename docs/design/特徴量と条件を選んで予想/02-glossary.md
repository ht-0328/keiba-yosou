# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想とほかの予想の設計書に出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語（二値分類・特徴量・目的変数・リーク・アンサンブルなど）と、競馬とこの設計の用語（ID 列・評価用の列・ウォームアップ期間・レース内順位など）は、手本と同じものをそのまま使う。人気に関する用語（人気馬・確定単勝人気・締め切り前の人気・馬券外）は、危険な人気馬の予想と同じものを使う。この予想で増えるのは、利用者が選ぶもの（設定ファイル・特徴量テキスト・条件）と、オッズと回収率に関する用語である。

- 機械学習の用語は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。
- 競馬とこの設計の用語は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。
- 人気に関する用語は [人気馬の 02 の「この予想で増える用語」](../人気馬が4着以下になるかを予想/02-glossary.md#この予想で増える用語) を参照。

## この予想で増える用語

| 用語 | 意味 | この設計では |
|---|---|---|
| 設定ファイル（YAML） | 1つのモデルの作り方を書いたテキストファイル。YAML は「名前: 値」を並べる書式 | 目的・時点・人気範囲・条件・期間・ハイパーパラメータを書く（[14-hyperparameter-settings.md](14-hyperparameter-settings.md#設定ファイルの形)） |
| 特徴量テキスト | モデルに渡す特徴量の名前を、1行に1つ書いたテキストファイル | 10行書けば、モデルの入力は 10列になる（[09-features.md](09-features.md#特徴量の選び方)） |
| 登録（特徴量の登録） | 選べる特徴量の一覧に、特徴量を載せること | `feature/registrations.py` の一覧に1行足す（[09-features.md](09-features.md#特徴量を足す仕組み)） |
| 依存項目 | ある特徴量を計算するのに先に要る、ほかの特徴量 | 例: 「3連複から見た3着以内率と単勝の差」は「3連複から見た3着以内率」に依存する。依存項目はモデルに渡さない |
| 利用可能な時点 | その特徴量の値が、いつから分かるか（木曜・前日・当日） | 設定の時点より後に分かる特徴量は選べない（[11-leak-prevention.md](11-leak-prevention.md#決まり)） |
| 人気範囲 | 対象にする馬の人気の範囲（両端を含む） | 例: 6〜10番人気。学習・評価・予想のすべてに当てる（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |
| 条件（conditions） | 特徴量の値で、対象の馬を絞る決まり | 例: 距離が 1400m 以下、競馬場が東京。すべてに当てはまる馬だけを残す（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)） |
| オッズの基準（odds_baseline） | 単勝オッズから見た確率を、モデルの出発点にすること | モデルは、そこからの上げ下げだけを学ぶ（[12-lightgbm.md](12-lightgbm.md#1-学習データの渡し方)） |
| 券種オッズから見た確率 | 3連単・3連複などの全買い目のオッズの逆数をレース内で合計1にそろえ、その馬が入った買い目だけ足した値 | 特徴量の一部（[09-features.md](09-features.md#券種オッズ12個)） |
| 追加の元データ | 共通の部品が読まないデータで、特徴量が計算に使うもの | 今は「券種オッズ」の1つ。その特徴量を選んだときだけ元DB から読む（[04-classes.md](04-classes.md#3-この予想だけのクラスの一覧)） |
| 回収率 | 払戻の合計 ÷ 買った金額。1点100円で数える | 学習と評価の結果に出す（[16-evaluation.md](16-evaluation.md)） |
| 想定払戻倍率 | 複勝で実際に受け取る払戻の見積もり。発表の最低オッズに、オッズ帯ごとの倍率を掛けた値 | 複勝の期待値に使う。倍率は学習期間の払戻から求める（[16-evaluation.md](16-evaluation.md#2-評価指標)） |
| 期待値 | 確率 × 払戻倍率。1 を超えれば、長い目で見て儲かる | 期待値の線ごとに回収率を出す（[16-evaluation.md](16-evaluation.md#2-評価指標)） |
| 回収率の下限 | 開催日を丸ごと取り直して回収率を1000回計算した、90% の幅の下側 | これが 100% を超えて初めて、偶然ではなく 100% を超えたと言う（[16-evaluation.md](16-evaluation.md#2-評価指標)） |
