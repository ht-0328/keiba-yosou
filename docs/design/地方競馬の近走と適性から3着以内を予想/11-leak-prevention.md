# 11 リークを防ぐ決まり

**この文書で決めること:** 学習では当たるのに本番では当たらないモデル（リーク）にならないよう、特徴量を作るときに守る決まり。

**結論: 特徴量は、予測する時点（出馬表・前日・当日。[07-prediction-timing.md](07-prediction-timing.md)）で分かることだけから作る。決まりは中央の予想の [11 リークを防ぐ決まり](../近走と適性から3着以内を予想/11-leak-prevention.md) の 1〜5 と同じで、地方のデータで気を付ける点を 6〜8 に足す。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 決まり

1〜5 は中央の予想の [11 の「決まり」](../近走と適性から3着以内を予想/11-leak-prevention.md#決まり) と同じ（そのレースの結果を使わない・開催日より前のものだけから計算する・マスタの累計を使わない・学習と予測で同じクラスでデータを作る・確定オッズは特徴量に使ってよいが予測では締め切り前のオッズになる）。

6. **出走別着度数地方（`nd`）は、その出走の時点の値なので、使ってよい。** 出走ごとに1行あり、データ作成年月日はレースの 2〜5日前（出馬表と同じころ）である。競走馬マスタ地方（`nu`）の着回数・賞金の累計は今日時点の値なので、使わない（決まり 3 と同じ）。
7. **クラスは、競走条件名称の文字列から読む。** 名称は出馬表の時点で決まっている。確定成績のレースでも同じ文字列なので、学習と予測でずれない。
8. **対戦レーティングと、騎手・調教師・血統の市場に対する成績は、開催日の前日までのレースだけから更新・集計する。** 同じ日の先に終わったレースも使わない（決まり 2 と同じ）。地方は同じ競馬場で週に何日も開催があるので、開催日の区切りを間違えると前日までの成績に当日の結果が混ざりやすい。
