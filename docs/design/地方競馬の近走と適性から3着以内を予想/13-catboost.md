# 13 CatBoost で学習・予測するための設計

**この文書で決めること:** 07〜09 で決めた学習データ（特徴量と目的変数）を、CatBoost で学習・予測するために、CatBoost だけに必要なことを決める。

| 決めること | 結論 |
|---|---|
| 1. 学習データの渡し方 | 中央の予想と同じ。カテゴリ特徴量は文字列のまま `cat_features` に指定し、欠損値だけ文字列「不明」にする |
| 2. ハイパーパラメータの初期値 | 中央の予想と同じ値から始める。目的関数は二値分類（`Logloss`）、木の数は早期終了で決める |
| 3. 学習・予測・保存の手順 | 3つの時点（出馬表・前日・当日）ごとに、3着以内と1着のモデルを1つずつ、当日は券種オッズなしも学習する。保存先は `reports/地方競馬の近走と適性から3着以内を予想/models/` |

- 使うクラスは中央と共通の `CatBoostModel`・`CatBoostEncoder`（`src/yosou/shared/ml_model/`）である。学習データの渡し方・ハイパーパラメータの初期値・カテゴリ特徴量の値の変え方（フローチャート）・学習と予測のやりとり（シーケンス図）は、中央の予想の [13 の 1.〜5.](../近走と適性から3着以内を予想/13-catboost.md#1-学習データの渡し方) を参照。ここには、この予想で違う点だけを書く。
- LightGBM の設計は [12-lightgbm.md](12-lightgbm.md) を参照。

## この予想で違う点

| 項目 | 中央の予想 | この予想 |
|---|---|---|
| カテゴリ特徴量の欠損値 | 文字列「不明」。「なし」にしないのは、調教のコースの「調教なし」と混ざるため | 同じ「不明」。この予想には調教の特徴量が無いが、中央と同じ `CatBoostEncoder` を使うので変えない |
| 木の数の上限（`iterations`） | 2000 | 2000 から始める。学習データが大きいので、早期終了が上限近くで止まるときは [16-evaluation.md の 5.](16-evaluation.md#5-ハイパーパラメータの調整のやり方) の比べ方で上限を上げて比べる |
| 学習する時点とモデルの数 | 木曜・前日・当日と券種オッズなしの当日、3着以内と1着で 8組 | 出馬表・前日・当日と券種オッズなしの当日、3着以内と1着で 8組 |
| 保存先 | `reports/近走と適性から3着以内を予想/models/` | `reports/地方競馬の近走と適性から3着以内を予想/models/`（Git の対象外） |

1 と 0 の数の偏りを直す設定（`auto_class_weights`）は使わない。[10-target.md](10-target.md) の「1 と 0 の数の偏り」を参照。
