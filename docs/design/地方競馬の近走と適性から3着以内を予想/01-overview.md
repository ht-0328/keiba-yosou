# 01 地方競馬の近走と適性から3着以内を予想する: 概要

**地方競馬（NAR）のレースについて、近走の内容と適性と、市場の評価（単勝オッズ）から、レースに出る1頭ずつの「3着以内に入る確率」と「1着になる確率」を出す予想である。** 考え方は中央の予想「[近走と適性から3着以内を予想](../近走と適性から3着以内を予想/01-overview.md)」と同じで、元のデータが地方競馬DATA（nvdata-store が DuckDB に貯めたもの）に替わる。
適性とは、そのコース・距離・馬場に向いているかどうかで、同じ条件での過去の成績・持ち時計・血統から見る。
市場の評価とは、馬券を買う人たち全体がその馬をどう見ているかで、単勝オッズと券種ごとのオッズから見る（前日と当日だけ）。

- 作り方: 機械学習の二値分類。LightGBM と CatBoost の2つのモデルで予測確率を出し、平均する（アンサンブル）。
- 予測する時点: 出馬表（オッズなし）・前日（前売りのオッズ）・当日（馬体重の発表のあと）の3つのどれでも出せる。時点ごとに、その時点で分かる特徴量だけで学習した別のモデルを使う（[07-prediction-timing.md](07-prediction-timing.md)）。
- データの元: 地方競馬DATA（UmaConn / NV-Link）の地方競馬のデータ（nvdata-store が `nvdata.duckdb` に貯めたもの）。中央の予想の元DB（jvdata-store の `jvdata.duckdb`）は読まない。
- 対象: 地方 14場（門別・盛岡・水沢・浦和・船橋・大井・川崎・金沢・笠松・名古屋・園田・姫路・高知・佐賀）の平地。ばんえい（帯広）は入れない（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)）。
- 用語の意味: [02-glossary.md](02-glossary.md) を参照。
- 状態: 決めごとは決まり（[15-decisions.md](15-decisions.md)）、プログラムは `src/yosou/local_form_aptitude_top3/` に作る（クラスとフォルダは [04-classes.md](04-classes.md)）。中央の予想と共通の部品は `src/yosou/shared/` にあり、この予想のパッケージには地方だけの決めごとを置く。

## 1頭の例

架空の1頭を当日に予測する場合で、モデルに何を渡して何が返ってくるかを示す。

> - **レース**: 2025年11月、大井・ダート1600m・良、Ｂ２の条件戦、14頭立て
> - **馬**: 5枠8番、5歳の牡馬、斤量 56kg、馬体重 492kg（前走から −2）
> - **人**: 騎手A（前走から乗り替わり）、調教師B
> - **前走**: 2着、勝ち馬と 0.1秒差、上がり3F はこのレースの出走馬の中で 3番目に速い、21日ぶり
> - **近5走**: 平均 3.4着、最高は 1着、推定脚質は先行
> - **通算**: 31戦6勝（中央で 4戦、地方で 27戦）、3着以内が 15回。大井のダートは 12戦して 3着以内が 7回
> - **血統**: 父A、母の父C。父Aの産駒は近1年で 3着以内が 29%（ダートでは 30%）、母父Cの産駒は 26%
> - **市場の評価**: 単勝 4.1倍で、このレースの 2番人気。オッズから見た勝率は 0.20。3連単から見た勝率は単勝から見た勝率より少し高い
> - **市場に対する成績**: 騎手Aの市場に対する超過3着以内率は 0.008（近1年、オッズの期待より少し多く3着以内に来ている）
> - **対戦レーティング**: 1,580（このレースの出走馬の中で 2位）
>
> → モデルの予測確率: **3着以内に入る確率 0.58**、**1着になる確率 0.22**（単勝の期待値 = 0.22 × 4.1 = 0.90）

## 使うデータ

時点によって材料を使い分ける（[07-prediction-timing.md](07-prediction-timing.md#時点ごとに使う特徴量) を参照）。土台は、中央の予想の今の材料のうち調教（I）を除いた A〜H の 65個と、L の4個、O の7個である。前日からは J の4個、当日は N の6個を足し、当日の1着のモデルだけは Q の 10個も使う。当日の3着以内のモデルは 86個、1着のモデルは 96個で学ぶ。一覧は [09-features.md](09-features.md) を参照。

| まとまり | 何が分かるか | 特徴量の例 |
|---|---|---|
| A. レースの条件 | どんなレースか | 競馬場、芝ダ、距離、馬場状態、クラス（格と番号から付けた並び順）、頭数 |
| B. 馬のこと | 今日の馬の条件と状態 | 馬齢、性別、所属（中央・地方）、枠番、斤量、馬体重とその増減 |
| C. 騎手と調教師 | 誰が乗り、誰が育てたか | 騎手、乗り替わり、騎手の近1年の3着以内の割合 |
| D. 前走 | 前のレースでどうだったか | 着順、着差、上がり3F、前走からの日数、距離の変更 |
| E. 近走のまとめ | 最近の調子と通算の成績 | 近5走の平均着順・平均着差、推定脚質、通算の3着以内の数（中央と地方の両方） |
| F. この条件での経験 | 同じ競馬場・距離・馬場で走れるか | 同じ競馬場のダートでの通算の3着以内の数、持ち時計の順位 |
| G. 同じレースの馬との比較 | このメンバーの中で強いか | 近5走の平均着差のレース内順位 |
| H. 血統 | どんな血か、その血統の産駒が近1年でどれだけ走っているか | 父、父の父、母の父、父の産駒の近1年の3着以内の割合 |
| J. 市場の評価 | 馬券を買う人たち全体が、この馬をどう見ているか（前日・当日だけ） | 単勝オッズ、人気順位、オッズから見た勝率 |
| L. 騎手・調教師・血統の市場に対する成績 | 騎手・調教師・血統が、オッズの期待より3着以内に来ているか（過去のレースのオッズだけを使う） | 騎手の市場に対する超過3着以内率 |
| N. 券種ごとのオッズから見た支持（当日） | 3連単・馬連などの人が、単勝の人よりこの馬を高く見ているか | 3連複から見た3着以内率と単勝の比（log） |
| O. 対戦レーティング | 同じレースを走った馬どうしの勝ち負けから見た強さ | 対戦レーティング、そのレース内順位 |
| Q. 勝ち切る材料（当日の1着のモデルだけ） | 3着以内に堅く来る力ではなく、勝ち切る力 | 近10走の勝ち切り率、騎手の近1年の勝ち切り率 |

記号は中央の予想とそろえてある（I・K・M・P はこの予想には無い）。使わないデータとその理由は、[09-features.md](09-features.md#使わない特徴量) と [11-leak-prevention.md](11-leak-prevention.md) を参照。
