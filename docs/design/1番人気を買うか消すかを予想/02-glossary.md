# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想とほかの予想の設計書に出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語のうち、特徴量・数値特徴量・カテゴリ特徴量・欠損値・リーク・過学習・学習データ・テストデータ・予測用データ・public メソッド・オーケストレーション・リポジトリは、手本と同じ意味で使う。この予想は LightGBM と CatBoost を使わないので、二値分類・予測確率・決定木・木の数・学習率・早期終了は出てこない。増えるのは、k近傍法と点数に関する用語と、1番人気の買い方・単位・評価に関する用語である。

- 機械学習の用語は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。
- 競馬とこの設計の用語（ID 列・評価用の列・確定オッズ・締め切り前のオッズ・オッズから見た勝率・ウォームアップ期間・レース内順位・事実表・出走別着度数）は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。
- 人気に関する用語（確定単勝人気・締め切り前の人気・時系列オッズ・馬券外）は [人気馬の 02 の「この予想で増える用語」](../人気馬が4着以下になるかを予想/02-glossary.md#この予想で増える用語)、馬券内は [穴馬の 02 の「この予想で増える用語」](../穴馬が3着以内に入るかを予想/02-glossary.md#この予想で増える用語) を参照。

## この予想で増える用語（機械学習）

| 用語 | 意味 | この設計では |
|---|---|---|
| k近傍法（k-NN） | 対象のデータに、特徴量がいちばん似ている k個のデータを探し、それを手がかりにする方法。似ているかどうかは距離で測る | グループの馬の中から、対象の1番人気に似た k頭を探す。scikit-learn の `NearestNeighbors` を使う（[03-library-basics.md](03-library-basics.md#4-nearestneighbors-の使い方)） |
| 距離（ユークリッド距離） | 2つのデータの、列ごとの差を2乗して足し、平方根をとった値。小さいほど似ている | 距離に使う数字の表（[12-neighbor-distance.md](12-neighbor-distance.md#1-距離に使う列の作り方)）どうしの距離 |
| k | k近傍法で探す、似たデータの数 | 10。グループの頭数 − 1 を超えない（[15-decisions.md の 6](15-decisions.md#6-k-の値)） |
| 標準化 | 列ごとに、平均を引いて標準偏差で割り、平均 0・ばらつき 1 にそろえること。単位の違う列（斤量と馬体重など）を同じ重みで距離に入れるために行う | 数の列だけに行う。平均と標準偏差は、単位ごとに3つのグループを合わせた学習データから求める（[12-neighbor-distance.md](12-neighbor-distance.md#3-尺度をそろえる標準化)） |
| ワンホットエンコーディング（one-hot） | 種類を表す列を、種類ごとの 0/1 の列に分けること。「良・稍重・重」なら「良か」「稍重か」「重か」の3列になる | カテゴリの特徴量（馬場状態など）を距離に使う形にする（[12-neighbor-distance.md](12-neighbor-distance.md#1-距離に使う列の作り方)） |
| 百分位（パーセンタイル） | ある値が、たくさんの値の並びの中で、どこの位置にあるかを % で表したもの | 点数のそろえ方に使う（下の「単位の1番人気全員と比べた順位」） |
| ウォークフォワード | 時期を少しずつ進めながら、「その時点までのデータで学習し、次の期間で確かめる」をくり返す評価のしかた | 評価する年ごとに、その前年までで学習し直す（[16-evaluation.md](16-evaluation.md#1-1年ごとの評価ウォークフォワード)） |
| ラベル | 学習データの行に付ける、その行の答え | 1番人気の結果のグループ（勝利・馬券内・馬券外）。距離には使わず、行をグループに分けるのに使う（[10-target.md](10-target.md#グループの分け方)） |

## この予想で増える用語（競馬とこの設計）

| 用語 | 意味 | この設計では |
|---|---|---|
| 1番人気 | 単勝オッズがいちばん低い馬。同じオッズの馬が2頭いれば、2頭とも1番人気になる | 学習データの行にする馬。学習と評価では確定単勝人気が 1 の馬、予測では渡された人気かオッズでいちばん低い馬（[07-prediction-timing.md](07-prediction-timing.md#予測のときの1番人気の決め方)） |
| グループ | 過去の1番人気を、結果で分けたもの。勝利・馬券内・馬券外の3つ。馬券内には勝利の馬も入る | 分け方は [10-target.md](10-target.md#グループの分け方) |
| 勝利モデル・馬券内モデル・馬券外モデル | それぞれのグループの馬だけのデータで作った、近さを測るモデル（`GroupSimilarity`） | 単位ごとに3つずつ作る（[13-closeness-score.md](13-closeness-score.md)） |
| 近さの点数 | 対象の馬が、そのグループにどれだけ近いかを 0〜100 で表した値。近いほど高い | 下の「単位の1番人気全員と比べた順位」で出す |
| **単位の1番人気全員と比べた順位** | 対象の馬と、そのグループの似た k頭との平均距離が、同じ単位の1番人気全員（3つのグループを合わせた学習データ）の同じ距離と比べて、どの位置にあるか。全員のうち、対象の馬と同じか、より遠い馬の割合（%）が点数になる | 点数 70 なら「この単位の1番人気の 70% より、このグループに近い」。3つのグループを同じ顔ぶれと比べるので、点数どうしを比べられる（[13-closeness-score.md](13-closeness-score.md#2-点数のそろえ方)） |
| 消し | 予想の中で、その馬を買う馬券から外すこと | 馬券外の点数が、馬券内の点数より 5点を超えて高い1番人気。単勝も複勝も買わない |
| 判定の線（fade_margin・win_margin） | 点数の差がどれだけあれば「近い」とするかの値 | 消しは 5点、単勝は 0点（[15-decisions.md の 7](15-decisions.md#7-判定の線)） |
| 判定 | 1番人気1頭についての買い方。「消す」「単勝と複勝」「複勝だけ」の3つ | 判定の手順は [06-flowchart.md](06-flowchart.md#図2-1番人気の買い方を決める) |
| 単位 | モデルを分けるまとまり。芝かダートかと、距離の組み合わせ。名前は「芝2000m」の形 | 学習データで1番人気が少ない距離は、同じ芝ダのいちばん近い単位にまとめる（[08-training-data.md](08-training-data.md#単位の決め方)） |
| 方針 | 単位のまとめ方・特徴量の時点・k・判定の線・掛け金・評価の年などの、変えられる決めごと | 設定ファイル `default_settings.toml` にまとめる（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)） |
| 回収率 | 払戻の合計 ÷ 買った金額。100% で元返し | 買い分けたときと、全部を同じ買い方で買ったときを比べる（[16-evaluation.md](16-evaluation.md#3-表の見方)） |
| 掛け金の配分 | 1頭について、単勝と複勝にそれぞれいくら賭けるか | 「単勝と複勝」は単勝 100円・複勝 200円、「複勝だけ」は複勝 300円（[16-evaluation.md](16-evaluation.md#4-買い方と掛け金)） |
