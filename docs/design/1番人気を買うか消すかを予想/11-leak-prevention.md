# 11 リークを防ぐ決まり

**この文書で決めること:** 評価では当たるのに本番では当たらない仕組み（リーク）にならないよう、特徴量を作るとき、行を選ぶとき、単位と物差しを作るとき、評価するときに守る決まり。

**結論: 特徴量は、予測する時点（前日・当日。[07-prediction-timing.md](07-prediction-timing.md)）で分かることだけから作る。この予想は1番人気を選んでからグループに分けるので、「どのオッズで1番人気を決めるか」と「単位の決め方・物差し・比べる相手を、どの期間のデータから作るか」の決まりを足す。評価の成績が本番より少し良く出るところは、そのことを書いておく。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 決まり

1〜5 は手本と同じで、[手本の 11 の「決まり」](../近走と適性から3着以内を予想/11-leak-prevention.md#決まり) を参照する（そのレースの結果を使わない、過去走と調教は開催日より前のものだけから計算する、マスタの累計の成績を使わない、学習データと予測用データを同じプログラムで作る、確定オッズは使ってよいが予測では締め切り前のオッズになる）。この予想では、6〜9 を足す。

**6. 1番人気は、学習と評価では確定単勝人気、予測では渡された人気かオッズで決める。評価の成績は、本番より少し良く出る。**

- 確定単勝人気は、レースの**結果**ではなく、発売の締め切り時点の値である。走る前に決まるので、着順やタイムのようなリークにはあたらない。
- ただし、**予測する時点には確定していない。** 前日・当日に分かるのは、まだ動く途中のオッズである。そのため、グループに入っている「確定の1番人気」と、予測する「その時点の1番人気」が、別の馬になることがある。
- **評価（1年ごとの評価）では、1番人気を確定単勝人気で選び、まとまり K のオッズの特徴量も確定オッズで作る。** 本番では締め切り前のオッズになるので、評価の成績は本番より少し良く出る（[16-evaluation.md](16-evaluation.md#3-表の見方)）。
- 学習でも「締め切り前のオッズの1番人気」にそろえる方法は取れない。締め切り前のオッズ（時系列オッズ）は過去1年ぶんしか取れず、学習データの期間ぶんがそろわないためである（[09-features.md](09-features.md#使うデータの期間)）。
- このずれを小さくするために、当日の締め切りに近い時点で予測を出し直す（[07-prediction-timing.md](07-prediction-timing.md#予測のときの1番人気の決め方)）。

**7. 単位の決め方は、学習データの頭数だけから作る。**

- 1年ごとの評価では、評価の年ごとに、その年の学習データ（前年まで）で決め直す。評価する年の頭数を見て単位を決めると、評価する年の様子を先に知ったことになる。

**8. 距離に使う行列の作り方（中央値・標準化の物差し・カテゴリの値の一覧）、グループの馬、点数の物差し（単位の1番人気全員の距離の並び）は、学習データだけから作る。**

- 1年ごとの評価では、評価する年の馬を、物差しにもグループにも入れない。答えの分かっている馬を、その馬自身と比べることになり、実際より近く見えるためである。
- 学習データの馬について距離を出すときは、そのグループの馬なら自分自身を除いた k頭で測る（[13-closeness-score.md](13-closeness-score.md#1-比べる相手の距離)）。自分を含めると、自分との距離 0 が入り、どの馬も自分のグループにいちばん近く見える。

**9. 判定の線は、評価の結果を見て決めたものは、その年を完全な未知のデータとして扱わない。**

- 消しの線（`fade_margin` = 5）は、2025年の評価の結果を見て決めた（[15-decisions.md の 7](15-decisions.md#7-判定の線)）。そのため、**2025年の評価の成績は、完全な未知のデータでの成績ではない。** 2026年の成績も、同じ線を使っている。
- 線や重みなどの方針を変えて評価し直すたびに、評価の年は「方針を選ぶのに使ったデータ」に近づく。方針をいくつも試して、いちばん良かったものを選ぶときは、その成績が本番より良く出ることを前提に読む。
