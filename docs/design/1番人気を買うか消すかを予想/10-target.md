# 10 結果のグループ（目的変数にあたるもの）

**この文書で決めること:** 過去の1番人気を、結果でどのグループに分けるか。二値分類の予想では、ここで目的変数（モデルに当てさせる答えの列）を決める。この予想は k近傍法で、答えの列を当てさせるのではなく、グループの馬だけでモデルを作るので、決めるのはグループの分け方である。

**結論: 1番人気を、勝利（1着）・馬券内（1〜3着。勝った馬も含む）・馬券外（4着以下）の3つのグループに分ける。1着の馬は、勝利と馬券内の2つに入る。競走中止・失格は馬券外に入れる（主担当が決めた。[15-decisions.md の 8](15-decisions.md#8-競走中止失格の扱い)）。**（利用者の指定。2026-09-25 に、二値分類の目的変数から、この分け方に作り直した。実装は `FinishGroupLabeler`）

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## グループの分け方

学習データの1行は、1レースの1番人気1頭である（[08-training-data.md](08-training-data.md#1-学習データの形)）。その1頭の結果から、3つのグループの列（1/0）を作る。

| その1番人気の結果 | 勝利 | 馬券内 | 馬券外 |
|---|---|---|---|
| 確定着順が 1着 | 1 | 1 | 0 |
| 確定着順が 2着・3着 | 0 | 1 | 0 |
| 確定着順が 4着以下 | 0 | 0 | 1 |
| 競走中止・失格（着順が付かない） | 0 | 0 | 1 |
| 出走取消・発走除外・競走除外 | ― | ― | ― |

| モデル | 作るのに使う馬 |
|---|---|
| 勝利モデル | 「勝利」が 1 の1番人気だけ |
| 馬券内モデル | 「馬券内」が 1 の1番人気だけ（勝った馬も含む） |
| 馬券外モデル | 「馬券外」が 1 の1番人気だけ |

- 取消・除外の馬は、サンプルにしない（走っていない。[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)）。
- 着順は**確定着順**を使う。降着があれば、降着後の着順になる。
- 同着は、どちらも同じ着順として扱う（1着同着なら2頭とも勝利、3着同着なら2頭とも馬券内）。
- **7頭以下のレースでも、3着以内かどうかで決める。** 複勝は 7頭以下だと2着までしか払戻が無いが、グループは頭数で変えない。頭数でグループの意味が変わると、同じグループの中に違う意味の馬が混ざるためである。複勝の払戻の違いは、評価の回収率にだけ表れる（[16-evaluation.md](16-evaluation.md#3-表の見方)）。
- グループの列は、行をグループに分けるのに使うだけで、距離の計算には入れない。

## 理由

**グループの馬だけでモデルを作る理由。** 利用者の考え方は、「勝った1番人気」「馬券内だった1番人気」「馬券外だった1番人気」それぞれに似た馬がいて、対象の馬がどのグループの馬に似ているかを見る、というものである。二値分類は「2つのグループの境目」を学ぶが、この予想は「それぞれのグループの馬がどんな馬か」を覚えておき、近さを測る。

**馬券内に勝った馬を含める理由。** 利用者の指定である。消すかどうかは「馬券内（勝ちを含む）と馬券外のどちらに近いか」で決める。勝った馬を馬券内から外すと、馬券内のグループが「2〜3着だった馬」になり、馬券になる1番人気の姿からずれる。

**グループの頭数の違い。** 1番人気は馬券内に入ることのほうが多いので、馬券内のグループは馬券外より大きく、勝利のグループがいちばん小さい。頭数の違うグループの距離は、そのままでは比べられない（馬の多いグループほど、近い馬が見つかりやすい）。そこで、同じ単位の1番人気全員と比べた順位（点数）にそろえてから比べる（[13-closeness-score.md](13-closeness-score.md#2-点数のそろえ方)）。
