# 01 1番人気を買うか消すかを予想する: 概要

**近走の内容と適性と市場の評価（単勝オッズ）と前走の人気から、1番人気の馬が「勝利した1番人気」「馬券内だった1番人気」「馬券外だった1番人気」の3つのグループにそれぞれどれだけ近いかを点数（0〜100）で出し、点数を比べて、その1番人気を「消す」「単勝と複勝を買う」「複勝だけ買う」のどれにするかを決める予想である。**
馬券内とは3着以内に入ること、馬券外とは4着以下になることである（[10-target.md](10-target.md#グループの分け方)）。
適性とは、そのコース・距離・馬場に向いているかどうかで、同じ条件での過去の成績・持ち時計・血統から見る。

- 作り方: 芝ダート × 距離の単位ごとに、過去の1番人気を結果で3つのグループに分け、グループごとに「そのグループの馬だけのデータ」でモデルを作る。
  - **勝利モデル**: 1着だった1番人気だけで作る。
  - **馬券内モデル**: 1〜3着だった1番人気だけで作る（勝った馬も含む）。
  - **馬券外モデル**: 4着以下だった1番人気だけで作る（競走中止・失格も含む）。
- 近さの測り方: **k近傍法**（scikit-learn の `NearestNeighbors`）。そのグループの馬の中から、対象の馬にいちばん似ている k頭（10頭）を探し、その k頭との平均の距離で近さを測る。距離は、**同じ単位の1番人気全員と比べた順位**で 0〜100 の点数にする。点数 70 なら「この単位の1番人気の 70% より、このグループに近い」（[13-closeness-score.md](13-closeness-score.md#2-点数のそろえ方)）。
- 判定: ①馬券外の点数が馬券内の点数より 5点を超えて高ければ消す → 消さなかった馬は ②勝利の点数が馬券内の点数より高ければ「単勝と複勝」、そうでなければ「複勝だけ」（[06-flowchart.md](06-flowchart.md#図2-1番人気の買い方を決める)）。
- **LightGBM と CatBoost は使わない。** この2つは「1 と 0 の両方の例」を比べて学ぶ道具で、1つのグループの馬だけのデータからは学習できないためである。
- 特徴量の時点: 当日（馬体重の発表のあと）。前日は設定で選べる（[07-prediction-timing.md](07-prediction-timing.md)）。
- データの元: JRA-VAN Data Lab. の中央競馬のデータ（jvdata-store が DuckDB に貯めたもの）。
- 用語の意味: [02-glossary.md](02-glossary.md) を参照。
- 状態: **実装済み**（`src/yosou/favorite_buy_or_fade/`。[04-classes.md](04-classes.md)）。決めることは、利用者の「いったん任せる」（2026-09-25）により、主担当が決めた（[15-decisions.md](15-decisions.md)）。方針は設定ファイルにまとめてあり、変えたらすぐ学習し直せる（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)）。

**既にある「人気馬が4着以下になるかを予想」との違い。** そちら（`src/yosou/favorites_out_of_top3/`）は、1〜5番人気を人気帯で分けて、LightGBM と CatBoost で4着以下になる確率を出す。この予想は、1番人気だけを芝ダート × 距離の単位で分け、結果のグループへの近さを比べて、消すかどうかと単勝も買うかまで決める。2つは別の予想で、そちらのプログラムは変えていない。

## 使い方

```powershell
uv run python -m yosou.favorite_buy_or_fade evaluate --out reports/favorite_buy_or_fade/evaluation.md
uv run python -m yosou.favorite_buy_or_fade train
uv run python -m yosou.favorite_buy_or_fade predict --date 2026-09-27 --venue 中山 --race 11 --odds 1:12.5 2:3.8 3:2.4
```

（1行目は、評価の年ごとにその前年までで学習し直して判定し、年ごと・判定ごと・単位ごとの表を出すコマンド。2行目は、本番用のモデルを学習して `reports/favorite_buy_or_fade/models/` に保存するコマンド。3行目は、1レースの1番人気の単位・3つの点数・判定を出すコマンド。`--odds` は「馬番:オッズ」を全頭ぶん並べる）

方針を変えるときは、変えたい項目だけを書いた設定ファイルを `--config` で渡して、`evaluate` か `train` を実行し直す。1回あたり1分ほどで終わる（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)）。

## 1頭の例

架空の1頭を当日に予測する場合で、何を渡して何が返ってくるかを示す。近走・適性・調教・血統は、手本の [「1頭の例」](../近走と適性から3着以内を予想/01-overview.md#1頭の例) と同じ架空の馬とする。

> - **レース**: 2025年5月、東京・芝1600m・良、オープン、16頭立て → 単位は「芝1600m」
> - **市場の評価**: **1番人気**、単勝 2.4倍。オッズから見た勝率 0.33、オッズから見た3着以内率 0.66
> - **前走**: 3着、**1番人気**（前走も1番人気で、人気より2つ悪い着順）
> - **近5走**: 平均人気 1.8、そのうち人気より悪い着順だったのは 2回
> - **近走・適性・調教・血統**: 手本の「1頭の例」と同じ
>
> → 芝1600m の3つのモデルでの近さの点数: **馬券外 72点、馬券内 45点、勝利 30点**
> → ① 馬券外 72点が馬券内 45点より 5点を超えて高いので、**消す**（単勝も複勝も買わない）

馬券外 72点とは、「芝1600m の1番人気の 72% は、この馬より、馬券外だった1番人気から遠い」という意味である（[13-closeness-score.md](13-closeness-score.md#2-点数のそろえ方)）。

## 使うデータ

特徴量の一覧は 78個で、11 のまとまり（A〜K）に分かれる。そのうち、騎手・調教師・父・父の父・母の父の名前と人気順位の6個は、距離に使わない（当日なら 72個を使う。前日はさらに馬体重とその増減を使わない）。一覧は [09-features.md](09-features.md) を参照。

- **A〜I の9つのまとまり（71個）は、手本と同じである。** 何が分かるかの見取り図は [手本の 01 の「使うデータ」](../近走と適性から3着以内を予想/01-overview.md#使うデータ) を参照。
- この予想では、次の J と K を足す（既にある「人気馬が4着以下になるかを予想」と同じ 78個）。前走の人気（前走も1番人気だったか）は、手本のまとまり D の「前走の人気」で分かる（[09-features.md](09-features.md#前走の人気の扱い)）。

| まとまり | 何が分かるか | 特徴量の例 |
|---|---|---|
| J. 人気と人気の履歴 | これまで人気どおりに走ってきたか | 前走の人気と着順の差、近5走の平均人気 |
| K. 単勝オッズから見た評価 | 同じ1番人気でも、どれだけ抜けた支持を受けているか | 単勝オッズ、オッズから見た勝率、オッズから見た3着以内率 |

k近傍法は数字の列どうしの距離しか測れないので、騎手・調教師・血統の名前は距離に使わず、成績の数字の列で表す（[12-neighbor-distance.md](12-neighbor-distance.md#1-距離に使う列の作り方)）。
