# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。

**結論: 目的変数は2つ。「3着以内なら 1」を当てるモデルと、「1着なら 1」を当てるモデルを、同じ学習データから別々に学習する。** 3着以内のモデルの確率は ○▲△・軸・複勝の期待値に、1着のモデルの確率は単勝の期待値と ◎ に使う（[15-decisions.md の 14](15-decisions.md#14-1着のモデルを足して--を単勝の期待値で選ぶ)）。

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 作り方

| 目的変数 | 1 になるとき | 0 になるとき | 当てるモデルの確率の使い先 |
|---|---|---|---|
| **3着以内** | 確定着順が 1〜3 | 4着以下、競走中止、失格 | 複勝の期待値、○▲△、軸 |
| **1着** | 確定着順が 1 | それ以外 | 単勝の期待値（1着になる確率 × 単勝オッズ）、◎、レースの期待度 |

- 着順は**確定着順**を使う。降着があれば、降着後の着順になる。
- 同着は、どちらも同じ着順として扱う（3着同着なら 2頭とも 1）。
- 競走中止と失格は、走ったが馬券にならなかったので 0 にする。
- 出走取消・発走除外・競走除外の馬は、サンプルにしない（[08-training-data.md](08-training-data.md) の「どのサンプルを入れるか」を参照）。

## 理由

**3着以内を使う理由。**

- 1 のサンプルが1レースに3つあり、1着（1レースに1つ）より多い。1 のサンプルが多いほど、モデルは学びやすい。
- 予測確率を、複勝やワイドの判断にそのまま使える。

**1着も当てる理由。** 単勝は、勝たないと払戻が無い。3着以内に堅く来る馬と、勝ち切る馬は同じではないので、
3着以内の確率の1位を ◎ にして単勝を買っても、◎ の大半が1番人気になり、単勝回収率は 1番人気全体とほぼ同じで、控除率の分だけ負けた水準にとどまる
（道具「印の成績」の表）。単勝の期待値を出すには、1着になる確率そのものが要る。
1着のモデルは、3着以内のモデルと同じ学習データ（同じ特徴量・同じ時点・同じ行）から、目的変数の列を持ち替えて学ぶ。
出発点（基準）は、3着以内の「オッズから見た3着以内率」に当たる「オッズから見た勝率」のロジットにする（`WinBaseline`。[04-classes.md](04-classes.md#dataset--学習データ予測用データを作るrunnerselector-はこの予想ほかは-shared)）。

## 1 と 0 の数の偏り

目的変数「3着以内」は、1 が少なく 0 が多い（14頭立てなら 3 対 11）。「1着」はさらに偏る（1 対 13）。この偏りは、**どちらも直さずにそのまま学習する。**

- 偏りを直す設定（1 のサンプルを重く扱う設定）を使うと、モデルは 1 を実際より多く見積もり、予測確率が実際の確率より高く出る。
- この予想では、予測確率を確率として使う（オッズと比べる、など）。そのため、確率の大きさがずれる設定は使わない。

LightGBM と CatBoost の、偏りを直す設定の名前は、[12-lightgbm.md](12-lightgbm.md)・[13-catboost.md](13-catboost.md) の「ハイパーパラメータの初期値」を参照。
