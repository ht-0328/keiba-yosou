# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。

**結論: 目的変数は「3着以内なら 1、それ以外は 0」。「1着なら 1」の目的変数も学習データに置いておく。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 作り方

| 目的変数 | 1 になるとき | 0 になるとき |
|---|---|---|
| **3着以内**（最初に使う） | 確定着順が 1〜3 | 4着以下、競走中止、失格 |
| 1着 | 確定着順が 1 | それ以外 |

- 着順は**確定着順**を使う。降着があれば、降着後の着順になる。
- 同着は、どちらも同じ着順として扱う（3着同着なら 2頭とも 1）。
- 競走中止と失格は、走ったが馬券にならなかったので 0 にする。
- 出走取消・発走除外・競走除外の馬は、サンプルにしない（[08-training-data.md](08-training-data.md) の「どのサンプルを入れるか」を参照）。

## 理由

**3着以内を最初に使う理由。**

- 1 のサンプルが1レースに3つあり、1着（1レースに1つ）より多い。1 のサンプルが多いほど、モデルは学びやすい。
- 予測確率を、複勝やワイドの判断にそのまま使える。

**1着の目的変数も置いておく理由。** あとで単勝用のモデルを作るときに、学習データを作り直さずに済ませるためである。

## 1 と 0 の数の偏り

目的変数「3着以内」は、1 が少なく 0 が多い（14頭立てなら 3 対 11）。この偏りは、**直さずにそのまま学習する。**

- 偏りを直す設定（1 のサンプルを重く扱う設定）を使うと、モデルは 1 を実際より多く見積もり、予測確率が実際の確率より高く出る。
- この予想では、予測確率を確率として使う（オッズと比べる、など）。そのため、確率の大きさがずれる設定は使わない。

LightGBM と CatBoost の、偏りを直す設定の名前は、[12-lightgbm.md](12-lightgbm.md)・[13-catboost.md](13-catboost.md) の「ハイパーパラメータの初期値」を参照。
