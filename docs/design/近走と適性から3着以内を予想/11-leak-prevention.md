# 11 リークを防ぐ決まり

**この文書で決めること:** 学習では当たるのに本番では当たらないモデル（リーク）にならないよう、特徴量を作るときに守る決まり。

**結論: 特徴量は、予測する時点（木曜・前日・当日。[07-prediction-timing.md](07-prediction-timing.md)）で分かることだけから作る。**

リークがあると、検証では当たるのに本番では当たらないモデルになる。用語の意味は [02-glossary.md](02-glossary.md) を参照。予測する時点は [07-prediction-timing.md](07-prediction-timing.md) を参照。

## 決まり

1. **そのレースの結果は特徴量にしない。** 確定着順・走破タイム・着差・上がり3F・通過順・脚質・確定オッズ・確定人気・払戻・異常区分である。事実表の列でいうと `finish` `finish_time` `time_diff` `last3f` `last3f_rank` `corner4` `style` `winner_style` `win_odds` `popularity` `win_payout` `place_payout` `abnormal`。
2. **過去走から作る特徴量（近走・同じコースでの成績・3着以内の割合・持ち時計）と調教の特徴量は、開催日より前のものだけから計算する。** 同じ日の先に終わったレースも使わない。
3. **マスタにある累計の成績は使わない。** 競走馬マスタ・騎手マスタ・調教師マスタの「本年」「累計」の成績は、今日時点の値である。過去のサンプルに付けると、そのあとの成績が混ざる。出走別着度数（`ck`）は、出走ごとに出走馬名表の時点の値を持つので、使ってよい。
4. **学習データと予測用データは、同じプログラムで作る。** 作り方が別だと、同じ名前の特徴量でも中身がずれる。
