# 08 学習データ

**この文書で決めること:** 学習データの1行を何にするか。どのレース・どの期間の行を入れるか。

**結論: 1サンプル = 1レースの1頭。2024年1月からの中央競馬の芝・ダートの出走を使う（約 12.5 万行）。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 学習データの形

架空の1レースの一部を例にすると、学習データは次の形になる。

| レースID | 馬番 | 馬齢 | 斤量 | 前走の着順 | 近5走の平均着差 | …（特徴量はあと 50個以上） | 目的変数: 3着以内 | 目的変数: 1着 |
|---|---|---|---|---|---|---|---|---|
| 架空レースA | 1 | 3 | 55.0 | 2 | 0.4 | … | 1 | 1 |
| 架空レースA | 2 | 3 | 57.0 | 8 | 1.3 | … | 0 | 0 |
| 架空レースA | 3 | 3 | 57.0 | （欠損値） | （欠損値） | … | 1 | 0 |

- 3番の馬は DB に過去走が無いので、前走の特徴量は欠損値になる。学習データでは、欠損値を 0 で埋めず、欠損値のまま持つ。0 で埋めると「前走 0着」のような、ありえない値になる。モデルに渡すときの欠損値の扱いは、[12-lightgbm.md](12-lightgbm.md)・[13-catboost.md](13-catboost.md) の「学習データの渡し方」を参照。
- 14頭立てのレースなら、目的変数「3着以内」が 1 のサンプルは 3つ、0 のサンプルは 11 になる。

## 2. 列の種類

学習データの列は4種類ある。モデルに渡すのは**特徴量と目的変数だけ**である。

| 種類 | 列 | モデルに渡すか |
|---|---|---|
| ID 列 | レースID、馬ID、開催日 | 渡さない |
| 特徴量 | 68個。[09-features.md](09-features.md) を参照 | `fit` の `X` として渡す |
| 目的変数 | 3着以内（1/0）、1着（1/0）。[10-target.md](10-target.md) を参照 | `fit` の `y` として渡す |
| 評価用の列 | 確定着順、確定の単勝オッズ、確定の単勝人気、単勝の払戻、複勝の払戻 | 渡さない |

3つの時点（木曜・前日・当日）のモデルは、同じ学習データから、その時点で使う特徴量の列だけを渡して学習する（[07-prediction-timing.md の「時点ごとに使う特徴量」](07-prediction-timing.md#時点ごとに使う特徴量)）。

ID 列と年を特徴量にしない理由は次のとおり。

- 馬ID を入れると、モデルは「この馬はよく来る」と個々の馬を覚えるだけになり、新しい馬に役立たない。
- 開催日や年を入れても、学習データに無い将来の年には役立たない。

予測用データは、この学習データから目的変数と評価用の列を除いた形になる。

## 3. どのサンプルを入れるか

| 決まり | 内容 | 理由 |
|---|---|---|
| 対象のレース | 中央競馬の平地（芝とダート）。障害は入れない | 障害は走り方が違い、レースの数も少ない |
| 対象の馬 | 出走した馬。出走取消・発走除外・競走除外はサンプルにしない | 走っていない馬には目的変数が無い |
| 期間 | 2024年1月1日から | 下の「ウォームアップ期間」 |
| 新馬戦 | 入れる | 過去走の特徴量は欠損値になるが、血統・騎手・調教師で予測できる |

**ウォームアップ期間（2023年）。** DB にある中央の成績は 2023年1月からである。そのため、2023年に走った馬は、実際には何戦もしていても「前走なし」に見え、近走の特徴量が作れない。2023年はサンプルにせず、2024年以降のサンプルの過去走の特徴量を計算するためだけに使う。通算の成績は、2023年より前も含む出走別着度数から取るので、この影響を受けない（[09-features.md](09-features.md) の「表の見方」を参照）。

この決まりで、学習データは約 12.5 万行になる（2024年1月〜2026年9月の芝・ダートの出走。2026-09-21 時点の DB で 125,515 行）。この中を、学習データ・検証データ・テストデータに時期で分ける。分け方は次の設計書で決める。
