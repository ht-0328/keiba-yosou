# 08 学習データ

**この文書で決めること:** 学習データの1行を何にするか。どのレース・どの期間の行を入れるか。重賞の行をどれだけ重く見るか。期間をどう指定するか。

**結論: 1サンプル = 1レースの1頭。中央競馬の平地（芝とダート）の全レースの出走を使う（手本と同じ行）。重賞（G1・G2・G3）の行には重み（初期値 5）を付け、ほかの行は重み 1 にする。学習データは手本と同じく材料ごとに2つ作り、期間の既定も手本と同じにする（馬の力の材料は 2012年1月から・約70万行、今の材料は 2021年8月から・約24万行）。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 学習データの形

架空の1つの G2（[01-overview.md の「1頭の例」](01-overview.md#1頭の例) のレース）と、同じ日の架空の条件戦の一部を例にすると、学習データは次の形になる。

| レースID | 馬番 | 格 | 重賞の3着以内の数 | 前年の同じ重賞の着順 | 過去開催の前走のレースが同じ馬の複勝率 | …（特徴量はあと 300個以上） | 目的変数: 3着以内 | 目的変数: 1着 | 重み |
|---|---|---|---|---|---|---|---|---|---|
| 架空G2レースA | 4 | G2 | 2 | 4 | 0.33 | … | 1 | 0 | 5 |
| 架空G2レースA | 9 | G2 | 0 | （欠損値） | （欠損値） | … | 0 | 0 | 5 |
| 架空条件戦B | 2 | 条件 | 0 | （欠損値） | （欠損値） | … | 1 | 1 | 1 |

- 9番の馬は、前年の同じ重賞に出ておらず、前走のレースから来た馬も過去の開催にいないので、2つの列が欠損値になる。条件戦の行は、同じ重賞の経験と K（その重賞の傾向）が全部欠損値になる。欠損値は 0 で埋めず、欠損値のまま持つ（手本と同じ。[手本の 08 の「1. 学習データの形」](../近走と適性から3着以内を予想/08-training-data.md#1-学習データの形)）。
- 「重み」は特徴量ではなく、学習のときに `fit` に渡す列である（下の 2）。

## 2. 列の種類

**手本と同じ4種類（ID 列・特徴量・目的変数・評価用の列）に、「重み」を足した5種類である。** モデルに渡すのは特徴量と目的変数で、重みは `fit` の重みの引数として渡す。種類ごとの列と、ID 列・年を特徴量にしない理由は [手本の 08 の「2. 列の種類」](../近走と適性から3着以内を予想/08-training-data.md#2-列の種類) を参照。

| 種類 | 列 | モデルに渡すか |
|---|---|---|
| 特徴量 | 手本の材料に W と K を足したもの（[07-prediction-timing.md の「時点ごとに使う特徴量」](07-prediction-timing.md#時点ごとに使う特徴量)） | `fit` の `X` として渡す |
| 重み（**この予想で足す**） | 行ごとの重み（重賞の行は設定の重み、ほかは 1。下の 4） | `fit` の重みの引数として渡す（LightGBM は `sample_weight`、CatBoost は `Pool` の `weight`。[03-library-basics.md](03-library-basics.md#行に重みを付けて学ぶ)）。予測用データには無い |
| 評価用の列 | 手本の評価用の列に、グレードコードを足す | 渡さない。重賞の行だけの当たり具合（[16-evaluation.md](16-evaluation.md)）を出すときに、重賞の行を選ぶのに使う |

学習データは、手本と同じく材料ごとに2つ作る（木曜・前日の馬の力の材料と、当日の今の材料）。同じ材料の時点ではモデルに渡す列だけを変える。1着のモデルは、同じ学習データで目的変数と基準を持ち替えて学ぶ（`WinTargetData`。重みは持ち越す）。

## 3. どのサンプルを入れるか

**手本と同じ行を入れる**（中央競馬の平地の出走した馬。障害・出走取消・発走除外・競走除外は入れない。新馬戦も入れる）。決まりと理由は [手本の 08 の「3. どのサンプルを入れるか」](../近走と適性から3着以内を予想/08-training-data.md#3-どのサンプルを入れるか) を参照。行の選び方の判断の手順も手本と同じである（[手本の 06 の図1](../近走と適性から3着以内を予想/06-flowchart.md#図1-学習データに入れる行の選び方)）。

**重賞の行だけで学ばない理由。** 前の重賞の予想は、重賞の行（約2万8千行）だけで学び、手本が全レースで学ぶ数百個の材料を学びきれずに、確率の誤差で手本に勝てなかった（[引退した予想の 15 の 9](../重賞の傾向と近走から3着以内を予想/15-decisions.md#9-新しい一般の予想の材料で作り直し採用か引退かを決める2026-10-02)）。全レースの行で学べば、近走・適性・人・血統の材料は手本と同じだけの行で学べる。そのうえで重賞の行を重く見て、重賞ならではの材料（W・K）の効き方を学ばせる。

行の数（2012年1月〜2026年11月の確定成績での数え上げ。出走した馬）:

| 行 | 数 | 全体に占める割合 | 重み 5 を付けたときの重みの割合 |
|---|---|---|---|
| 平地の全部 | 約 70.1万行 | 100% | 100% |
| うち重賞（G1・G2・G3） | 約 2.85万行（1年に約 128レース・約 1,900行） | 約 4.1% | 約 17.5% |
| うちリステッド | 約 0.68万行 | 約 1.0% | 約 0.8% |
| うちオープン（リステッドを除く） | 約 1.83万行 | 約 2.6% | 約 2.2% |

今の材料（2021年8月から）では、全部で約 24.5万行、うち重賞は約 1.03万行である。

ほかの選び方（オープン・リステッド以上だけ、重賞だけ）と、選び方で変わることは [15-decisions.md の 1](15-decisions.md#1-学習の行の選び方) を参照。

**ウォームアップ期間。** 意味と既定は手本と同じ（馬の力の材料は 2011年、今の材料は 2020年1月〜2021年7月）。その重賞の傾向（K）と同じ重賞の経験は、ウォームアップ期間に依らず、DB にある確定成績のうち、そのレースより前の開催すべてから数える（引退した予想と同じ。[09-features.md の「使うデータの期間」](09-features.md#使うデータの期間)）。

## 4. 重賞の行の重み

**重賞の行には重み 5、ほかの行には重み 1 を付ける（初期値）。** 重みは設定ファイルで変えられる（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)）。判断の手順は [06-flowchart.md の図1](06-flowchart.md#図1-学習データの行の重みの決め方)。

| 重み | 重賞の行が誤差に占める割合 | どうなるか |
|---|---|---|
| 1 | 約 4% | 手本と同じ学び方。重賞の材料（W・K）を足しても、重賞の行が少なく、効き方を学ぶ前に木を足すのが止まりやすい |
| 3 | 約 11% | 重賞の行を少し重く見る |
| **5（初期値）** | **約 18%** | 重賞の行を5回ぶん数える。全レースの材料の学び方をほとんど崩さずに、重賞の行の誤差を見て木を作る |
| 10 | 約 30% | 重賞の行を強く見る。重賞の行のくせ（約 1,900行/年の偶然）を覚えやすくなる |

- **重みは、目的変数ではなくレースの種類で付ける。** 重賞の行の中の 1 と 0 の割合は変わらないので、確率の大きさはずれない（[10-target.md の「1 と 0 の数の偏り」](10-target.md#1-と-0-の数の偏り)）。
- **検証データにも同じ重みを付ける。** 木を足すのを止める判断（早期終了）が、重賞の行を重く見た当たり具合で決まるようにする（[12-lightgbm.md の 1](12-lightgbm.md#1-学習データの渡し方)）。検証データを重賞の行だけにしない理由と、重みの値の選び方は [15-decisions.md の 2](15-decisions.md#2-重賞の行の重み)・[3](15-decisions.md#3-早期終了で見る検証データ) を参照。
- 重み 5 は、手本の当たり具合を大きく崩さない範囲で、重賞の行の重みの割合が 2割近くになる値として置いた仮の値である。7つの区切りの確かめで、重み 1・10 との比べも出す（[16-evaluation.md の 4](16-evaluation.md#4-1年ずつの7つの区切りでの確かめ)）。

## 5. 期間の指定

**期間の区切り・引数・既定は、手本と同じである**（共通の `TrainingPeriod`。今の材料は `--train-from` の既定 2021-08-01、馬の力の材料は `--ability-train-from` の既定 2012-01-01、検証は 2025-07-01 から、テストは 2026-01-01 から）。区切りの意味と既定の理由は [手本の 08 の「4. 期間の指定」](../近走と適性から3着以内を予想/08-training-data.md#4-期間の指定) を参照。

- 手本と同じ既定にするのは、学習の行が手本と同じだからである（重賞だけで学んだ前の予想は、行が少ないので 2012年からに延ばしていた）。
- 当日のモデル（今の材料）の重賞の行は約 1万行で、馬の力の材料（約 2.85万行）より少ない。今の材料の始まりを前に延ばすかは [15-decisions.md の 6](15-decisions.md#6-当日のモデルの学習データの始まり) で決める。
- 7つの区切りの確かめでは、区切りごとに学習の期間を変える（[16-evaluation.md の 4](16-evaluation.md#4-1年ずつの7つの区切りでの確かめ)）。

```powershell
uv run python -m yosou.graded_race_top3_win train
uv run python -m yosou.graded_race_top3_win train --train-from 2017-01-01
```

（1行目は、既定の期間で学習するコマンド。2行目は、当日のモデルの学習データの始まりを 2017年に変えて学習するコマンド。ウォームアップは省略すると前の年の1月1日になる）
