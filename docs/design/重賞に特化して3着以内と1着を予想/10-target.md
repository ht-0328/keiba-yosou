# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。

**結論: 手本とまったく同じ。「3着以内なら 1」を当てるモデルと、「1着なら 1」を当てるモデルを、同じ学習データから別々に学習する。共通の `Top3TargetBuilder`（列は `TOP3`・`WIN`）と、1着のモデルへの持ち替え `WinTargetData` をそのまま使う。** 3着以内の確率は ○▲△・軸・複勝の期待値に、1着の確率は単勝の期待値と ◎・期待度に使う。

- 作り方（1 になるとき・0 になるとき、確定着順を使う、同着はどちらも同じ着順、競走中止と失格は 0、取消・除外はサンプルにしない）は [手本の 10 の「作り方」](../近走と適性から3着以内を予想/10-target.md#作り方) を参照。
- 3着以内と1着の2つを当てる理由は [手本の 10 の「理由」](../近走と適性から3着以内を予想/10-target.md#理由) を参照。
- 用語の意味は [02-glossary.md](02-glossary.md) を参照。

## この予想で違う点

**目的変数そのものに違いは無い。** 違うのは、学習のときに重賞の行に重みが付くこと（[08-training-data.md の 4](08-training-data.md#4-重賞の行の重み)）だけで、それは目的変数ではなく行の重みの話である。

印と買い目は重賞で使うので、両方の目的変数を持つことがこの予想では特に効く。◎ と単勝（◎ 1点）・期待度は1着の確率から、○▲△ と3連系の相手は3着以内の確率から決まる（[買うレースと買い目を決める の 07 の 5](../買うレースと買い目を決める/07-expected-value.md#5-印の付け方)）。

## 1 と 0 の数の偏り

**手本と同じく、偏りは直さずにそのまま学習する**（理由は [手本の 10 の「1 と 0 の数の偏り」](../近走と適性から3着以内を予想/10-target.md#1-と-0-の数の偏り)）。

**重賞の行に付ける重みは、偏りを直す設定とは違う。** 偏りを直す設定は「1 の行」を重くするので、1 の割合が実際より多く見え、確率が高く出る。この予想の重みは「重賞の行」を、1 の行も 0 の行も同じだけ重くする。重賞の行の中の 1 と 0 の割合は変わらないので、重賞の行の確率の大きさはずれない。変わるのは、木がどの行の誤差を重く見て分かれ目を作るか（重賞の行のくせを、より学ぶ）だけである。

確率の大きさがずれていないかは、16 の確かめで、重賞の行の確率の帯ごとに実際の3着以内率・勝率と比べて見る（[16-evaluation.md の 2](16-evaluation.md#2-評価指標)）。
