# 16 当たり具合の測り方

**この文書で決めること:** 学習に使っていないデータで、この予想の当たり具合をどう測るか。何と比べれば「重賞に特化した意味がある」と言えるか。新しい印で全部の重賞を買うとき、印からの買い目の組み方と、レースごとに買う券種の選び方をどう決め、どう確かめるか。何を満たせば採用するか。

| 決めること | 結論 |
|---|---|
| 1. 期間の分け方 | `train` の既定は手本と同じ（検証 2025年7〜12月、テスト 2026年1月〜）。当たり具合は重賞の行だけで測る |
| 2. 評価指標 | 手本と同じ指標（ログ損失・AUC・Brier・人気の中の AUC・確率1位の馬の成績）を、重賞の行だけで、時点ごと・目的変数ごとに出す。確率の帯ごとの実際の率も見る |
| 3. 比べる基準 | 1番人気、オッズだけで学んだモデル、**手本を重賞だけに使ったとき**（いちばん大事な相手） |
| 4. 1年ずつの7つの区切りでの確かめ | テスト 2020〜2026年の1年ずつ7つ。区切りごとに学び直し、重賞の行の確率の誤差を比べる。重みを 1・10 にしたもの、K・W を外したものも比べる行として出す |
| 5. 印と期待度の成績 | 4 の予測に印と期待度を付け、印ごと・期待度ごとの成績を手本の印と並べる（採否には使わない） |
| 6. 印からの買い目の確かめ | 当日の予測で、全券種の形の候補と、レースごとに 2〜4券種を選ぶ決まりを、**前半の年（2020〜2022年）だけで選び、後半の年（2023〜2026年）で一度だけ確かめる**。第一は全券種がそれぞれ 100% 超え、届かなければ「レースごとに選んだ券種」の合計が 100% 超えで採用する。全券種の回収率は必ず出す |
| 7. ハイパーパラメータの調整のやり方 | 手本と同じ（自動の探索はしない）。比べるのは重賞の行の当たり具合 |

用語の意味は [02-glossary.md](02-glossary.md) を参照。決めてほしいことは [15-decisions.md](15-decisions.md) に集めた（この文書は、おすすめで書いてある）。

## 1. 期間の分け方

**区切りの意味と `train` の既定は手本と同じである**（[手本の 16 の「1. 期間の分け方」](../近走と適性から3着以内を予想/16-evaluation.md#1-期間の分け方)。期間の引数は [08-training-data.md の 5](08-training-data.md#5-期間の指定)）。この予想で違うのは次のとおり。

| 決まり | 理由 |
|---|---|
| `train` は、検証データの全行の当たり具合（手本と同じ表）に加えて、**重賞の行だけの当たり具合**を出す（`GradedValidationTables`） | この予想の目的は重賞を当てること。全行の当たり具合は、手本と大きく変わっていないかを見るためだけに出す |
| 半年の検証データの重賞は約 60レースしかないので、`train` の表は目安にとどめ、判断は下の 4・6 の区切りで行う | 60レースの値は偶然で大きく振れる |

## 2. 評価指標

**指標の意味と良い向きは手本と同じである**（[手本の 16 の「2. 評価指標」](../近走と適性から3着以内を予想/16-evaluation.md#2-評価指標)）。この予想では、どの指標も**重賞の行だけ**で、時点ごと（木曜・前日・当日）・目的変数ごと（3着以内・1着）に、LightGBM・CatBoost・平均の3行で出す。判断は平均の行で行う。

| 足す見方 | 何を見るか | 理由 |
|---|---|---|
| 確率の帯ごとの実際の率 | 重賞の行を、予測確率の帯（3着以内は 0.1 刻み、1着は 0.05 刻み）に分け、帯ごとの実際の3着以内率・勝率と比べる | 重みを付けて学んでも、確率の大きさがずれていないかを確かめる（[10-target.md の「1 と 0 の数の偏り」](10-target.md#1-と-0-の数の偏り)）。期待値と印は確率の大きさをそのまま使う |
| 格ごと（G1・G2・G3） | 同じ指標を格ごとに | G1 だけ当たらない、のような偏りを見る。数が少ないので判断には使わない |

## 3. 比べる基準

| 基準 | 何を出すか | 何が分かるか |
|---|---|---|
| 1番人気 | 各レースの1番人気の3着以内率・勝率・回収率 | 1頭選ぶ使い方で、市場の本命より当たるか |
| オッズだけで学んだモデル | 手本と同じ（[手本の 16 の「3. 比べる基準」](../近走と適性から3着以内を予想/16-evaluation.md#3-比べる基準)）。木曜はオッズが無いので、当日のオッズだけのモデルと比べる | 馬の情報が、オッズで分かること以上を足しているか |
| **手本を重賞だけに使ったとき** | 手本の予想（全レースを同じ重みで学んだもの。今の本番と同じ材料）を、同じ区切りで学び直し、重賞の行だけで測ったもの | **重賞に特化した意味があるか。** この相手に勝てなければ、重賞も手本で予想すればよい（前の重賞の予想は、この相手に勝てずに引退した） |

## 4. 1年ずつの7つの区切りでの確かめ

**重賞はレースが少ないので、引退した予想と同じ1年ずつの7つの区切りで確かめる**（研究「既存モデルの改善」の `STAKES_WINDOWS`。`research/既存モデルの改善/analysis/windows/stakes_windows.py`）。区切りごとに、この予想と比べる相手を学び直し、テストの年の重賞の行で測る。

| 区切り | 学習 | 検証 | テスト |
|---|---|---|---|
| 2020年 | 始まり 〜 2018年12月 | 2019年 | 2020年 |
| 2021年 | 始まり 〜 2019年12月 | 2020年 | 2021年 |
| 2022年 | 始まり 〜 2020年12月 | 2021年 | 2022年 |
| 2023年 | 始まり 〜 2021年12月 | 2022年 | 2023年 |
| 2024年 | 始まり 〜 2022年12月 | 2023年 | 2024年 |
| 2025年 | 始まり 〜 2023年12月 | 2024年 | 2025年 |
| 2026年 | 始まり 〜 2024年12月 | 2025年 | 2026年1月〜（DB にある最後の日まで） |

- 学習の始まりは、研究の学習データの表と同じ（馬の力の材料は 2012年1月、今の材料は 2017年1月）。比べる相手も同じ始まり・同じ区切りで学ぶ。学習の行はどれも中央の平地の全レースで、テストで測るのは重賞の行だけである。
- 検証の年は、木を足すのを止める判断にだけ使う（重み付きのログ損失。[12-lightgbm.md の 1](12-lightgbm.md#1-学習データの渡し方)）。テストの年の結果は、どの線を決めるのにも使わない（6 の「前半の年」で選ぶものを除く）。
- 時点は木曜・前日・当日の3つ、目的変数は3着以内と1着の2つ。ハイパーパラメータは初期値のまま。重賞のテストの行は1年に約 1,900行（約 128レース）。

**並べる行（同じ区切り・同じ時点で）。**

| 行 | 中身 | 何が分かるか |
|---|---|---|
| この予想（重み 5・W・K） | 本番の形 | ― |
| 手本を重賞だけに使ったとき | 3 の比べる相手 | 重賞に特化した意味があるか |
| オッズだけ | 3 の比べる相手 | 馬の情報が効いているか |
| 重み 1（W・K は足す） | 重みを付けずに、重賞の材料だけを足したもの | 重みの効き目（材料の効き目と分ける） |
| 重み 10 | 重みを強くしたもの | 重みの強さの向き（[15-decisions.md の 2](15-decisions.md#2-重賞の行の重み)） |
| K を外す | W だけを足したもの | その重賞の傾向の効き目（前の予想ではほとんど無かった） |
| W を外す | K だけを足したもの | 重賞の格と実績の効き目 |

**確率の誤差の条件（結果を見る前に決める。[15-decisions.md の 7](15-decisions.md#7-確率の誤差で手本に勝てなかったときの扱い)）。** おすすめは次のとおり。

| 項目 | 中身 |
|---|---|
| 見る時点と目的変数 | 当日の3着以内と1着（買い目に使うのは当日の予測。木曜・前日は同じ表を出すが条件にしない） |
| 条件 | 7つの区切りを合わせた重賞の行のログ損失が、「手本を重賞だけに使ったとき」以下であること（3着以内と1着の両方）。区切りごとに小さかった数（7つのうちいくつ）も書く |
| 満たしたとき | 6 の買い目の確かめの結果で採否を決める |
| 満たさなかったとき | 6 の確かめは参考として出すが、採用しない（重賞も手本で予想する）。コードは確かめ直し用に残す |
| 比べる行の扱い | 重み 1・10、K・W を外したものは、効き目の説明に使う。結果を見てから重みや材料を替えたら、替えたことと、何回目の確かめかを結果に書く |

動かし方（これから足す。研究「既存モデルの改善」に、この予想を区切りごとに学び直して予測を残す入口を足す。数値は Git の対象外の `reports/既存モデルの改善/` に出る）。比べる相手（手本を重賞だけに使ったとき・オッズだけ）は、引退した予想の確かめ（`stakes_rebuild.py`）で作った仕組みを使う。

## 5. 印と期待度の成績

4 の当日の予測（7つの区切りのテストの年）に、買い方の設計書の決まりで印と期待度を付け、重賞の行だけで成績を数える。**この節の表は、採否には使わない。** 6 で選ぶ形が、どんな印の成績の上に立っているかを見るためである。

| 表 | 中身 |
|---|---|
| 印ごとの成績 | ◎○▲△☆注・無印・消ごとの頭数と、成績7つ（着別度数・勝率・連対率・複勝率・馬券外率・単勝回収率・複勝回収率）。手本の印（同じ重賞・同じ決め方）と並べる |
| 期待度ごとの ◎ の成績 | S・A・B・C・見送りごとのレース数と、◎ の勝率・単勝回収率。前半の年と後半の年に分けて出す |
| ◎ と1番人気 | ◎ が1番人気だった割合、◎ の人気の分かれ方 |

- 印の決め方は [買うレースと買い目を決める の 07 の 5](../買うレースと買い目を決める/07-expected-value.md#5-印の付け方) のまま（◎ は消を除いた単勝 30倍以下の馬で単勝の期待値が1位、○▲△ は3着以内の確率の順、☆・注 も同じ決め方）。消（危険な人気馬）は、手本と同じく人気馬の予想（人気馬が4着以下になるかを予想）で判定する。この予想の確率は使わない。
- 期待度の点数の式と線は [買うレースと買い目を決める の 03 の 5](../買うレースと買い目を決める/03-race-screening.md#5-レースごとの目安期待度) のまま（線を重賞で引き直すかは [15-decisions.md の 12](15-decisions.md#12-期待度の線)）。期待度の線は、手本の当日の予測の 2023〜2026年を見て決めたものなので、後半の年の期待度ごとの成績は、まだ見ていない年の確かめではないことを結果に書く。
- 道具は `tools/印の成績/mark_stats.py`（重賞だけに絞って、この予想の予測を読めるようにする。これから足す）。

## 6. 印からの買い目の確かめ

**この節が、この予想の採否を決める。** 新しい印で全部の重賞（平地の G1・G2・G3）を買うとき、券種ごとの買い目の組み方（形）と、レースごとに買う券種の選び方を、前半の年だけで選び、後半の年で一度だけ確かめる。手順と線は、後半の年の結果を見る前にここに書いておく。

### 6.1 前提

| 項目 | 決まり |
|---|---|
| 時点 | 当日の予測（[15-decisions.md の 13](15-decisions.md#13-買い目を確かめる時点)）。前日の予測でも同じ表を参考に出す |
| 予測 | 4 の7つの区切りのテストの年の予測（どの年も、その年より前だけで学んだモデルのもの） |
| オッズと払戻 | 確定オッズと確定払戻（実際に買う締め切り前のオッズより良く出る。結果に書き添える） |
| 1点の額 | 100円。回収率は 払戻の合計 ÷ 購入額の合計 |
| 外す組 | トリガミ（どれが当たっても、その券種の購入額より戻りが少ない組）とオッズの無い組（今の印の買い目の数え方と同じ） |
| 単勝 | **◎ の1点だけ**（利用者の決定）。形の候補は作らない |
| 消 | どの券種の買い目にも入れない（3連系で無印に流すときも、消は入れない） |
| 全部の重賞を買う | どの重賞も、少なくとも2券種を買う |
| 1券種の点数の上限 | 24点（[15-decisions.md の 11](15-decisions.md#11-1券種の点数の上限)）。上限を超える形は、組の期待値の高い順に上限まで残す |
| 組の期待値 | [買うレースと買い目を決める の 07 の 2「組み合わせの券種の確率」](../買うレースと買い目を決める/07-expected-value.md#組み合わせの券種の確率馬連馬単ワイド3連複3連単) の式（市場が見た組の確率に、組の各馬の「モデル ÷ 市場」の比を掛ける）を、この予想の確率で出す。重みで合わせる作り（同じ 07 の 2 の次の節）は、重みを推定する年が確かめる年と重なるので使わない |

### 6.2 年の分け方

| 年 | 重賞のレース数（数え上げ） | 使い方 |
|---|---|---|
| 前半の年: 2020〜2022年 | 約 385レース | 形と、レースごとの券種の選び方を選ぶ |
| 後半の年: 2023〜2026年 | 約 500レース（2026年は11月まで） | 選んだものを一度だけ数える |

ほかの分け方（区切りを 2015年まで延ばして前半を 2015〜2020年にする、など）と、変わることは [15-decisions.md の 8](15-decisions.md#8-前半の年と後半の年の分け方) を参照。形を選ぶときに重賞以外のレースも見るかは [15-decisions.md の 9](15-decisions.md#9-形を選ぶときに見るレース) で決める（おすすめは重賞だけ）。

### 6.3 形の候補

券種ごとに、下の表の組み合わせを全部数える。相手の範囲の「印」は ◎○▲△☆注 のうち軸を除いたもの、「無印に流す」は消を除いた全頭（印の無い馬も入れる）である。

| 券種 | 軸と並び | 相手の範囲 | ほかに変える値 |
|---|---|---|---|
| 単勝 | ◎ 1点（固定） | ― | ― |
| 複勝 | ◎ / ◎・○ / ◎・○・▲ / それに期待値 1.25 以上の ☆ を足す | ― | 複勝の期待値の線（なし・1.0・1.1） |
| 枠連 | ◎ の枠 − 相手の枠 | ○▲ / ○▲△ / ○▲△☆ | オッズの上限（なし・50・300倍） |
| 馬連 | ◎ − 相手 / ◎○▲ の3頭の組 | ○▲ / ○▲☆ / ○▲△☆ / 印 | オッズの上限（なし・30・100倍）、組の期待値の線（なし・1.0） |
| ワイド | ◎ − 相手 / ◎○ − 相手（◎ か ○ を含む組） | ○▲ / ☆注 / 印 | 最低オッズの下限（なし・2・4倍）、組の期待値の線（なし・1.0） |
| 馬単 | ◎ → 相手 / 相手 → ◎ / ◎ と相手の両方向 | ○▲☆ / ○▲△ / 印 | オッズの上限（なし・30・100倍）、組の期待値の線（なし・1.0） |
| 3連複 | ◎ 軸 − 相手 − 相手 / ◎○ の2頭軸 − 相手 / ◎○▲△ の4頭の組 / ◎ 軸 − 印 − **無印に流す** | 印 / 印と3着以内の確率の上位の無印 3頭 / **無印に流す** | オッズの上限（なし・300・1,000倍）、組の期待値の線（なし・1.0・1.2） |
| 3連単 | ◎ → 相手 → 相手 / 相手 → ◎ → 相手 / 相手 → 相手 → ◎ / ○▲ → **消以外** → ◎ / ◎ → ○▲ → **無印に流す** | 印 / 印と3着以内の確率の上位の無印 3頭 / **無印に流す** | オッズの上限（なし・1,000・3,000倍）、組の期待値の線（なし・1.0・1.2） |

- **今の印の買い目**（[買うレースと買い目を決める の 08 の 2「複勝以外の券種の検証」](../買うレースと買い目を決める/08-bankroll-and-review.md#複勝以外の券種の検証過去のデータで先に確かめる) の表の形。ワイド ◎ − ☆・注、馬連 ◎ − ○▲☆、馬単 ◎ → ○▲☆、3連複 ◎ 軸 − ○▲☆ − ○▲△☆、3連単 ◎ → ○▲☆ → ○▲△☆）は、上の候補に含まれる。選ばれなくても、比べる行として必ず出す。
- 研究の下書き（今の予想の印で全部の重賞を買った確かめ）で 2021〜2026年に 100% を超えた2つの形（3連単 ○▲ → 消以外 → ◎、ワイド ◎○ − 印）も候補に入っている。**この2つは後半の年をすでに見て見つけた形なので、選ばれたときは、後半の年がまだ見ていない年ではないことを結果に書く。**
- 3連系の「無印に流す」は、利用者の決定で選び方の1つにした。点数が増えるので、点数の上限（6.1）を超えた分は組の期待値の高い順に残す。

### 6.4 券種ごとの形の選び方（前半の年だけを見る）

- 券種ごとに、前半の年の全部の重賞を買ったとして、**当たったレースが 15 以上の候補のうち、回収率の 90% の幅の下の端（開催日を単位にしたブートストラップ）がいちばん高い形**を1つ選ぶ。当たったレースが 15 以上の候補が無い券種は、全候補の中で下の端がいちばん高い形を選ぶ（研究「重賞の買い方」1回目と同じ決まり。重賞は数が少ないので、当たりの下限を全レースの研究の 30 から 15 に下げている）。
- 下の端で比べるのは、振れの大きい形（3連単・無印に流す形）がたまたま高い回収率で選ばれるのを防ぐためである。
- 単勝は ◎ 1点で、選ばない。

### 6.5 レースごとの券種の選び方

**1つの重賞ごとに、そのレースの中身から、買う券種を 2〜4つ選ぶ決まりを作る。** 使う中身は、レース前に分かるもの（この予想の期待度・◎ の1着の確率と単勝の期待値・券種ごとの買い目の期待値・荒れ具合の予想・頭数・格）だけである。各券種の買い目は、6.4 で選んだ形で組む。単勝を選んだときは ◎ 1点。

| 決まりの候補 | 中身 | 前半の年で選ぶもの |
|---|---|---|
| **ア. 券種ごとの期待値で上位 k 券種（おすすめ）** | レースごとに、券種ごとの買い目の期待値（6.4 の形で組んだ組の期待値の平均。単勝は ◎ の単勝の期待値、複勝は買う馬の複勝の期待値の平均）を出し、高い順に k 券種を買う | k（2・3・4）と、期待値が線（なし・1.0）に届かない券種を外すか（外しても2券種は残す） |
| イ. 期待度ごとに券種の組を決める | S・A・B・C・見送りのそれぞれで、買う 2〜4券種の組を決める | 期待度ごとの券種の組（8券種から 2〜4つの組の全部から、下の端がいちばん高い組） |
| ウ. レースの型ごとに券種の組を決める | 型 = ◎ の1着の確率の帯（3つ）× 荒れ具合の予想（中荒れ以上の確率の上下）。型ごとに 2〜4券種の組を決める | 型ごとの券種の組 |

- どの決まりを使うか（ア〜ウ）は [15-decisions.md の 10](15-decisions.md#10-レースごとの券種の選び方) で決める。複数を前半の年で比べる場合は、**前半の年の合計の回収率の 90% の幅の下の端がいちばん高いもの**を1つ選び、後半の年ではその1つだけを数える。
- イ・ウは、前半の年の 385レースを5〜6つに分けるので、1つの組が数十レースで決まる（研究「重賞の買い方」2回目は、型ごとに券種を1つ選ぶ形で、まだ見ていない年の重賞で 100% に届かなかった。下の 6.8）。アは、選ぶ値が少なく（k と線）、レースの中身をそのまま使うので、前半の年に合わせすぎにくい。
- 比べる行として、全部の重賞で同じ 2〜4券種を買う形（前半の年で下の端がいちばん高い組）も出す。

### 6.6 採用の線

**後半の年で一度だけ数え、次の順に判断する。** 線は結果を見る前に決めた（ここに書いた）ものから動かさない。

| 順 | 線 | 満たしたとき |
|---|---|---|
| 0 | 4 の確率の誤差の条件を満たしている | 1・2 に進む。満たさなければ、1・2 は参考として出し、採用しない |
| 1（第一） | 全部の重賞を 8券種すべて（6.4 の形）で買い、**8券種のどれも回収率が 100% を超える** | 「全券種で買う」で採用する |
| 2 | 1 に届かなければ、全部の重賞を「レースごとに選んだ券種」（6.5）で買い、**その合計の回収率が 100% を超える** | 「レースごとに 2〜4券種を選んで買う」で採用する |
| ― | どちらにも届かない | 採用しない。「届かなかった」か「100% を超えたが 90% の幅が 100% をまたぐ」をそのまま書き、本番の重賞の買い方は今のまま（[15-decisions.md の 14](15-decisions.md#14-今の本番の3連単重賞との関係)） |

- 90% の幅の下の端・100% を超えた年の数（4年のうち）・的中率（買い目が当たった重賞 ÷ 買った重賞）も書く。下の端が 100% を超えなくても、上の線は満たしたものとする（後半の年の重賞は約 500レースで、3連系を含む合計の下の端が 100% を超えるのは難しい）。偶然と区別できるかは、利用者に結果を見せて決める。
- **比べる相手**: 今の本番の「3連単（重賞）」（組の確率 0.2% 以上・1,000倍以下を組の期待値の高い順に10点。[買うレースと買い目を決める の 08 の 2](../買うレースと買い目を決める/08-bankroll-and-review.md#採用している券種当日の予想の重賞の3連単)）の後半の年の回収率と、手本の印で同じ形・同じ選び方をしたときの回収率。今の3連単（重賞）との関係（置き換えるか並べるか）は [15-decisions.md の 14](15-decisions.md#14-今の本番の3連単重賞との関係) で決める。
- 後半の年の結果を見て、形・選び方・線を選び直したら、それは2回目の確かめになる。何回目かを結果に書き、まだ見ていない年での確かめ（これからのレース）が済むまで本番に入れない。

### 6.8 前の研究との関係

研究「重賞の買い方」（[README](../../../research/重賞の買い方/README.md)）では、今の予想の印・組の確率で、重賞の買い方を4回探した。

| 回 | 形 | まだ見ていない年の重賞での結果 |
|---|---|---|
| 1回目 | ◎ランクごとに複数の券種を全部買う | 100% に届かなかった |
| 2回目 | レースの型（◎ランク × 配当率）ごとに券種を1つ選ぶ（[docs/03](../../../research/重賞の買い方/docs/03-レースごとに券種を選ぶ.md)） | 100% に届かなかった。同じ選び方を全レースに当てると 100% を超えたが、重賞ではその差が消えた。3連単を選んだ型は1回も当たらなかった |
| 3回目 | 単勝・複勝で条件に合う重賞だけ | 複勝は 100% を超えたが、全部の重賞を買う形ではない |
| 4回目 | 単系（単勝・馬単・3連単）で全部の重賞を買う（[docs/05](../../../research/重賞の買い方/docs/05-単系で全部の重賞を買う.md)） | 3連単（組の期待値の高い順に10点）だけ 100% を超え、本番に入れた |

研究の下書きで、今の予想の印のまま全部の重賞を印で買うと、2021〜2026年で 100% を超えたのは 3連単（○▲ → 消以外 → ◎）とワイド（◎○ − 印）だけだった。**この予想は、印の元になる確率そのものを重賞に合わせて作り直し、そのうえで同じ手順（前半で選び、後半で一度だけ確かめる）を踏む。** 2回目と違い、券種を1つではなく 2〜4つ選び、全券種で届くならそれを第一にする。

## 7. ハイパーパラメータの調整のやり方

**手順は手本と同じである**（自動の探索はしない。設定ファイルを変えて `train --config` で学び、2つの検証期間で初期値と比べ、両方で良ければ初期値を直す。[手本の 16 の「5. ハイパーパラメータの調整のやり方」](../近走と適性から3着以内を予想/16-evaluation.md#5-ハイパーパラメータの調整のやり方)）。この予想で違うのは次のとおり。

- 比べるのは、`train` の「重賞の行だけの当たり具合」の平均の行（ログ損失・AUC）。全行の当たり具合が大きく悪くなっていないかも見る。
- 重賞の行の重み（`[sample_weight]`）は、この手順では変えない。重みは 4 の区切りの比べ（重み 1・5・10）で見て、[15-decisions.md の 2](15-decisions.md#2-重賞の行の重み) で決める（半年の検証期間の重賞は約 60レースで、重みの比べには足りない）。

```powershell
uv run python -m yosou.graded_race_top3_win train --config 試す設定.toml --models reports/重賞に特化して3着以内と1着を予想/models-試し
```

（試す設定で学習し、既定の検証期間で、全行と重賞の行だけの当たり具合を出すコマンド。本番のモデルとは別の置き場所に書く）
