# 11 リークを防ぐ決まり

**この文書で決めること:** 学習では当たるのに本番では当たらないモデル（リーク）にならないよう、特徴量を作るときに守る決まり。

**結論: 特徴量は、予測する時点（木曜・前日・当日。[07-prediction-timing.md](07-prediction-timing.md)）で分かることだけから作る。決まり 1〜5 は手本と同じ、6 は引退した予想と同じで、この予想では W（重賞の格と実績）と行の重みについての決まり 7・8 を足す。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 決まり

1〜5 は手本と同じで、[手本の 11 の「決まり」](../近走と適性から3着以内を予想/11-leak-prevention.md#決まり) を参照する（そのレースの結果を使わない、過去走と調教は開催日より前のものだけから計算する、マスタの累計の成績を使わない、学習データと予測用データを同じプログラムで作る、確定オッズは特徴量に使ってよいが予測では締め切り前のオッズになる）。

6 は引退した予想と同じで、[引退した予想の 11 の「決まり」](../重賞の傾向と近走から3着以内を予想/11-leak-prevention.md#決まり) の 6 を参照する（その重賞の傾向（K）は、そのレースの開催日より前の開催だけから数える。過去の開催の馬の帯は確定値で、予測する馬の帯は走る前に分かる値で分ける）。

この予想では、次の 7・8 を足す。

**7. 重賞での実績・前走の格・同じ重賞の経験（W）は、そのレースの開催日より前の確定成績だけから数える。**

- 同じ日に先に終わったレース（同じ日の別の重賞を含む）も数えに入れない。`GradedCareerRepository` の SQL が「開催日がそのレースより前」で切り、この決まりはその1か所で守る（同じ重賞の経験は、6 と同じ `StakesTendencyRepository` の表から引くので、6 で守られる）。
- 前走の格は、その馬のそのレースより前の最後の出走から引く。対象の馬の行（確定前）も、事実表のその馬の過去の出走だけから引く。
- 競走馬マスタの「本年」「累計」の成績は使わない（決まり 3 と同じ理由。今日時点の値なので、過去の行に付けると、そのあとの成績が混ざる）。

**8. 行の重みは、レース前に分かること（そのレースの格）だけで決め、特徴量にしない。**

- 重みは、そのレースのグレードコード（出走馬名表の時点で決まっている）だけで決める。結果（着順・払戻）や人気で重みを変えない。結果で重みを変えると、当たった行を重く学ぶことになり、学習の当たり具合だけが良く見える。
- 重みは学習のときに `fit` に渡すだけで、特徴量の列にも予測用データにも入れない（[08-training-data.md の 2](08-training-data.md#2-列の種類)）。
