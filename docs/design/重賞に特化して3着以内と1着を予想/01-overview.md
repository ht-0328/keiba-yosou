# 01 重賞に特化して3着以内と1着を予想する: 概要

**中央の平地の全レースで学び、重賞（G1・G2・G3）の行を重く見て、近走・適性・市場の評価に「重賞の格と実績」と「その重賞の傾向」を足して、重賞の出走馬ごとに「3着以内に入る確率」と「1着になる確率」を出す予想である。** 2つの確率から印（◎○▲△☆注、消）と期待度（S・A・B・C・見送り）を付け、全部の重賞を印で買う。
重賞の格と実績とは、そのレースの格（G1〜G3・リステッド・オープン）と重量種別、馬の前走の格、重賞での出走数と好走の数、同じ重賞の前年の経験のような、重賞ならではの材料である（まとまり W）。
その重賞の傾向とは、同じ重賞の過去の開催で、自分と同じ条件だった馬がどれだけ走ったかで、引退した予想「重賞の傾向と近走から3着以内を予想」の材料（まとまり K）をそのまま使う。
**JRA-VAN のマイニング予想は使わない。**

- 作り方: 機械学習の二値分類。LightGBM と CatBoost の2つのモデルで予測確率を出し、平均する（アンサンブル）。目的変数は手本と同じ2つ（3着以内・1着。[10-target.md](10-target.md)）で、目的変数ごとに別のモデルを学ぶ。
- 学び方: **学習の行は、中央の平地の全レース（約70万行）。重賞の行（約2万9千行）には重み（初期値 5倍）を付けて学ぶ**（[08-training-data.md](08-training-data.md)）。当たり具合と採否は、重賞の行だけで測る（[16-evaluation.md](16-evaluation.md)）。
- 予測する時点: 木曜（出走馬名表）・前日（出馬表）・当日（馬体重の発表のあと）の3つのどれでも出せる。時点ごとに、その時点で分かる特徴量だけで学習した別のモデルを使う（[07-prediction-timing.md](07-prediction-timing.md)）。
- 予測するレース: 平地の重賞だけ（重賞でないレースを渡すと止まる。[06-flowchart.md の図2](06-flowchart.md#図2-予測する馬の行の選び方)）。
- データの元: JRA-VAN Data Lab. の中央競馬のデータ（jvdata-store が DuckDB に貯めたもの）。
- 印・期待度・買い目: 印の付け方は [買うレースと買い目を決める の 07 の 5](../買うレースと買い目を決める/07-expected-value.md#5-印の付け方)、期待度の作りは [同じく 03 の 5](../買うレースと買い目を決める/03-race-screening.md#5-レースごとの目安期待度) を、この予想の確率にそのまま当てる。印からの買い目の組み方と、レースごとに買う券種の選び方は、[16-evaluation.md の 6](16-evaluation.md#6-印からの買い目の確かめ) の手順で過去の重賞から決める。
- 用語の意味: [02-glossary.md](02-glossary.md) を参照。
- 状態: **設計書を書いたところ。決めてほしいことの返事待ち**（[15-decisions.md](15-decisions.md)）。プログラムは作っていない。パッケージは `src/yosou/graded_race_top3_win/` の予定（[04-classes.md](04-classes.md)）。

## 前の重賞の予想との違い

前に作った重賞の専用モデル（[重賞の傾向と近走から3着以内を予想](../重賞の傾向と近走から3着以内を予想/01-overview.md)）は、重賞の行（約2万8千行）だけで学んだので、手本が全レース（約70万行）で学ぶ数百個の材料を学びきれず、確率の誤差で手本に勝てずに引退した（[引退した予想の 15 の 10](../重賞の傾向と近走から3着以内を予想/15-decisions.md#10-k-をその重賞の過去の開催で自分と同じ条件だった馬の成績に作り直し採用か引退かを決める2026-10-15)）。この予想は、その失敗を繰り返さない形にする。

| 項目 | 前の重賞の予想（引退） | この予想 |
|---|---|---|
| 学習の行 | 重賞の行だけ | 中央の平地の全レース。重賞の行に重みを付ける |
| 目的変数 | 3着以内だけ | 3着以内と1着（手本と同じ） |
| 足す材料 | その重賞の傾向（K）だけ | 重賞の格と実績（W）と、その重賞の傾向（K） |
| 使い道 | 確率を見せるだけ | 印と期待度を付け、全部の重賞を印で買う |
| 確かめ方 | 確率の誤差（7つの区切り） | 確率の誤差に加え、印からの全券種の買い目の回収率（前半の年で選び、後半の年で一度だけ確かめる） |

手本の予想（[手本の 01](../近走と適性から3着以内を予想/01-overview.md)）は、全レースの全頭に同じ重みで同じ確率を出す。重賞は全レースの約4%しかないので、手本は重賞の行の当たり具合をほとんど気にせずに学ぶ。この予想は、同じ行で学びながら重賞の行を重く見て、重賞ならではの材料を足す。

## 1頭の例

架空の1頭を当日に予測する場合で、モデルに何を渡して何が返ってくるかを示す。

> - **レース**: 2025年10月、京都・芝2200m・良の G2（別定）、14頭立て。この重賞（特別競走番号は毎年同じ）の過去の開催は、DB に 14回ぶんある
> - **馬**: 3枠4番、4歳の牡馬、斤量 57kg（このレースの最も重い斤量は 58kg）、栗東所属、馬体重 486kg（前走から −2）
> - **前走**: 架空G1 で 6着、勝ち馬と 0.5秒差、49日ぶり → 前走の格は G1
> - **重賞での実績**: 重賞は 5戦して 3着以内が 2回（うち1勝）。G1 の3着以内は 0回、今回の格（G2）以上のレースでの3着以内は 2回。直近の重賞（前走）の着順は 6着
> - **同じ重賞の経験**: 去年の同じ重賞で 4着（この重賞への出走は 1回、3着以内は 0回）
> - **この重賞の傾向**: 過去の開催で、前走が同じ架空G1 だった馬は 18頭で複勝率 0.33、単勝 6〜10倍だった馬の複勝率 0.24（引退した予想の K と同じ作り）
> - **近走・適性・調教・血統・人**: 手本と同じ作りの特徴量（近5走の平均着差、同じ距離帯での3着以内の数、坂路の4ハロン、父の産駒の成績、騎手の成績など）
> - **市場の評価**: 単勝 7.2倍で、このレースの 4番人気。オッズから見た勝率は 0.12
>
> → モデルの予測確率: **3着以内に入る確率 0.33**、**1着になる確率 0.15**（単勝の期待値 = 0.15 × 7.2 = 1.08）

この馬が単勝 30倍以下の馬の中で単勝の期待値が1位なら ◎ になる（印の決め方は [買うレースと買い目を決める の 07 の 5](../買うレースと買い目を決める/07-expected-value.md#5-印の付け方)）。

## 使うデータ

**手本の材料（時点ごとの組み合わせも同じ）に、まとまり W（重賞の格と実績。14個）と K（その重賞の傾向。51個）を足して使う**（木曜 276個、前日 280個、当日 350個。1着のモデルは数が少し違う。[07-prediction-timing.md](07-prediction-timing.md#時点ごとに使う特徴量)）。一覧は [09-features.md](09-features.md) を参照。

- **W と K 以外は、手本と同じである。** 何が分かるかの見取り図は [手本の 01 の「使うデータ」](../近走と適性から3着以内を予想/01-overview.md#使うデータ) を参照。
- **W と K が、この予想で足すまとまりである。** 重賞でないレースの行では、K と W の一部（同じ重賞の経験）は欠損値になる。

| まとまり | 何が分かるか | 特徴量の例 |
|---|---|---|
| W. 重賞の格と実績 | このレースの格と重量種別、斤量の重さの位置、前走の格、重賞での実績、同じ重賞の経験 | 重賞か、格、重量種別、トップハンデとの差、前走の格、重賞の3着以内の数、前年の同じ重賞の着順 |
| K. その重賞の傾向 | 同じ重賞の過去の開催で、自分と同じ条件（前走のレース・枠・単勝オッズ・脚質など12の切り口）だった馬の出走数・複勝率・単勝回収率・複勝回収率 | 過去開催の前走のレースが同じ馬の複勝率 |

使わないデータとその理由は、[09-features.md の「使わない特徴量」](09-features.md#使わない特徴量) と [11-leak-prevention.md](11-leak-prevention.md) を参照。
