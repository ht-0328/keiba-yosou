# 15 決めてほしいこと

**この文書の目的:** 設計の中で、利用者に決めてほしいことを、ここに集める。どれも、おすすめの選び方で各文書を書いてある。決まったら、題名を「決めたこと」に変え、決定の日付を書き、選ばなかった選び方は残す。

**すでに決まっている前提（確認1の答え）。** 次のことは利用者の指示で決まっているので、ここでは聞かない。

## 1. 学習の行の選び方

| 選び方 | 変わること |
|---|---|
| **中央の平地の全レース（約70万行）で学び、重賞の行に重みを付ける（おすすめ）** | 近走・適性・人・血統の数百個の材料を、手本と同じだけの行で学べる。重賞の行は重みで重く見る。前の予想の失敗（行が少なく材料を学びきれない）を避けられる。学習の時間は手本とほぼ同じ |
| オープン・リステッド以上だけ（約 5.4万行）で学ぶ | 格の高いレースの行だけになり、重賞に近い相手関係を学べる。ただし行は全レースの約 8% で、前の予想（約2.8万行）の倍ほどにしかならず、同じ「学びきれない」不利が残る見込みが高い |
| 重賞だけ（約 2.85万行）で学ぶ | 前の予想と同じ形。確率の誤差で手本に勝てずに引退した形なので、同じ結果になる見込みが高い |

関連する資料: [08-training-data.md の 3](08-training-data.md#3-どのサンプルを入れるか)、[引退した予想の 15 の 9](../重賞の傾向と近走から3着以内を予想/15-decisions.md#9-新しい一般の予想の材料で作り直し採用か引退かを決める2026-10-02)。

## 2. 重賞の行の重み

| 選び方 | 変わること |
|---|---|
| 1（重みを付けない） | 手本と同じ学び方に、重賞の材料を足しただけになる |
| 3 | 重賞の行を少し重く見る |
| **5（おすすめ。重み 1・10 は 16 の 4 で比べる行として出す）** | 全レースの材料の学び方をほとんど崩さずに、重賞の行の誤差を見て木を作る |
| 10 | 重賞の行を強く見る。重賞の行の偶然のくせを覚えやすくなる |

重みごとに、重賞の行が誤差に占める割合は [08-training-data.md の 4](08-training-data.md#4-重賞の行の重み) の表にある。

| 選び方（重みの決め方） | 変わること |
|---|---|
| **上の値を1つ決めて固定する（おすすめ）** | 確かめの年で重みを選ばないので、16 の確かめがそのまま使える |
| 7つの区切りで 1・3・5・10 を比べ、いちばん良い重みを選ぶ | 一番良い重みを選べるが、選んだ重みでの確かめは、選ぶのに使った年と同じ年になる（確かめの年で選ぶことになる）。選ぶなら前半の年（2020〜2022年）の区切りだけで選ぶ |

関連する資料: [08-training-data.md の 4](08-training-data.md#4-重賞の行の重み)、[14-hyperparameter-settings.md](14-hyperparameter-settings.md)。

## 3. 早期終了で見る検証データ

| 選び方 | 変わること |
|---|---|
| **検証データの全行に、学習と同じ重みを付けて見る（おすすめ）** | 木を足すのを止める判断が、重賞の行を重く見たログ損失で決まる。検証の行が多い（1年で約5万行）ので、止まる位置が安定する |
| 検証データの全行を、重みを付けずに見る | 止める判断は全レースの当たり具合で決まり、重賞の行の学びが足りないところで止まることがある |
| 検証データの重賞の行だけを見る | 重賞の当たり具合で止められるが、検証の重賞は1年に約 1,900行（半年なら約 950行）しかなく、止まる位置が偶然で大きく振れる |

関連する資料: [12-lightgbm.md の 1](12-lightgbm.md#1-学習データの渡し方)・[13-catboost.md の 1](13-catboost.md#1-学習データの渡し方)。

## 4. 重賞の材料の中身

| 選び方 | 変わること |
|---|---|
| **W（重賞の格と実績。14個）と K（その重賞の傾向。51個）の両方を足し、16 の 4 で外したものも比べる（おすすめ）** | 利用者が挙げた材料（重賞か・格・その重賞の過去の傾向・前走の格・重賞での実績・同じ重賞の前年の経験・斤量の条件）が全部入る。K は前の予想では効かなかったので、外したものとの比べで効き目を見て、効かなければ外す |
| W だけ | 特徴量が 51個少なくなり、学習が少し速い。K は全レースの約 4% の行にしか値が無い |
| K だけ | 前の予想の材料を、全レースで学ぶ形にしただけになる |

格の上げ下げ・斤量の前走との差は、手本の材料に同じものがあるので足さない（[09-features.md の「使わない特徴量」](09-features.md#使わない特徴量)）。

関連する資料: [09-features.md の W](09-features.md#w-重賞の格と実績14個)、[09-features.md の K](09-features.md#k-その重賞の傾向51個)。

## 7. 確率の誤差で手本に勝てなかったときの扱い

| 選び方 | 変わること |
|---|---|
| 前の予想と同じ厳しい条件（時点ごとに、手本より小さい区切りが 7つのうち 5つ以上、かつ全期間でも小さい。満たさなければ引退） | 前の予想と同じ物差しで比べられる。ただし、印の買い目で 100% を超えても、確率の誤差でわずかに負ければ使えない |
| **当日の3着以内と1着で、7つの区切りを合わせたログ損失が手本以下なら、買い目の確かめで採否を決める（おすすめ）** | 「手本より悪くない確率」を前提にして、利用者の目的（印で全部の重賞を買って 100% 超え）で採否を決める。買い目に使わない木曜・前日は条件にしない |
| 確率の誤差は条件にせず、買い目の線だけで決める | 確率が手本より悪くても、たまたま買い目が当たれば採用してしまうおそれがある |

関連する資料: [16-evaluation.md の 4](16-evaluation.md#4-1年ずつの7つの区切りでの確かめ)、[16-evaluation.md の 6.6](16-evaluation.md#66-採用の線)。

## 10. レースごとの券種の選び方

| 選び方 | 変わること |
|---|---|
| **ア. 券種ごとの期待値で上位 k 券種（k は前半の年で 2〜4 から選ぶ。期待値の線で外すかも前半で選ぶ）（おすすめ）** | レースの中身（この予想の確率とオッズ）をそのまま使い、前半の年で選ぶ値が少ない（k と線）ので、前半の年に合わせすぎにくい。期待値の高い券種は人気薄の組に寄りやすく、的中率が下がるおそれがある |
| イ. 期待度（S・A・B・C・見送り）ごとに券種の組を決める | 利用者に説明しやすい（「期待度 A なら単勝・馬単・3連単」のような表になる）。前半の年の 385レースを5つに分けるので、1つの組が数十レースで決まり、たまたまの組を選びやすい |
| ウ. レースの型（◎ の1着の確率の帯 × 荒れ具合）ごとに券種の組を決める | 荒れそうなレースで3連系を選ぶ、のような形を作れる。イと同じく1つの組のレースが少ない。研究「重賞の買い方」2回目（型ごとに券種を1つ）は届かなかった |
| ア〜ウを全部前半の年で比べ、下の端がいちばん高いものを1つ選ぶ | 選び方の選び方まで前半の年で決めるので、後半の年で一度だけ確かめる決まりは守れる。比べる候補が増えるぶん、前半の年に合わせすぎる度合いは上がる |

関連する資料: [16-evaluation.md の 6.5](16-evaluation.md#65-レースごとの券種の選び方)、[研究「重賞の買い方」の docs/03](../../../research/重賞の買い方/docs/03-レースごとに券種を選ぶ.md)。

## 11. 1券種の点数の上限

| 選び方 | 変わること |
|---|---|
| 12点（研究「重賞の買い方」1回目と同じ） | 1レース 4券種でも最大 4,800円。3連単の ○▲ → 消以外 → ◎（2 × 頭数ほどの点数）や、無印に流す形は、組の期待値の高い順に 12点に削られる |
| **24点（おすすめ）** | 1レース 4券種で最大 96点 = 9,600円（1点 100円）で、利用者の前からの決まり「1レースに使う額は最大 1万円」に収まる。無印に流す形もほぼそのまま候補にできる |
| 上限なし | 形の候補はそのまま数えられるが、3連単の流しで1レース数十点〜百点を超え、1万円の決まりを超える |

関連する資料: [16-evaluation.md の 6.1](16-evaluation.md#61-前提)。

## 12. 期待度の線

| 選び方 | 変わること |
|---|---|
| **買い方の設計書 03 の 5 の式と線のまま（おすすめ）** | 全レースの期待度と同じ物差しになり、発走前の通知などの見せ方を変えずに済む。線は手本の当日の予測で決めたもので、この予想の確率では、等級ごとの成績の並びが変わるかもしれない（16 の 5 で見る） |
| 式はそのまま、線を重賞の前半の年で引き直す | 重賞に合った線になるが、前半の年の重賞は約 385レースで、4つの等級と見送りに分けると1つが数十〜百レースになり、線が偶然で決まる |
| 重賞では期待度を出さない | 利用者の要件（期待度を出す）に反する |

期待度は、レースごとの券種の選び方（10 のイ）に使うときだけ買い目に響く。

関連する資料: [16-evaluation.md の 5](16-evaluation.md#5-印と期待度の成績)、[買うレースと買い目を決める の 03 の 5](../買うレースと買い目を決める/03-race-screening.md#5-レースごとの目安期待度)。

## 13. 買い目を確かめる時点

| 選び方 | 変わること |
|---|---|
| **当日の予測で判定し、前日の予測は参考に同じ表を出す（おすすめ）** | 本番で買うのは当日の予想（今の買い方でも、確かめて買っているのは当日だけ）。前日の結果は、前日に買い目を見ておく目安になる |
| 前日と当日の両方で判定する | 前日にも買える形を探せるが、前日のオッズは当日と違い、確定オッズでの確かめとのずれが大きい |

関連する資料: [16-evaluation.md の 6.1](16-evaluation.md#61-前提)、[07-prediction-timing.md の「時点ごとに使う特徴量」](07-prediction-timing.md#時点ごとに使う特徴量)。

## 14. 今の本番の「3連単（重賞）」との関係

今の本番は、平地の重賞で必ず、組の確率 0.2% 以上・1,000倍以下の3連単を組の期待値の高い順に10点買っている（[買うレースと買い目を決める の 08 の 2](../買うレースと買い目を決める/08-bankroll-and-review.md#採用している券種当日の予想の重賞の3連単)。印では選ばない）。

| 選び方 | 変わること |
|---|---|
| **後半の年で比べ、新しい買い方が採用の線を満たし、3連単（重賞）より合計の回収率が高ければ置き換える。届かなければ3連単（重賞）のまま（おすすめ）** | 重賞の買い方が1つにまとまり、勝負用の財布の使い方が単純になる。比べる物差しは同じ後半の年（3連単（重賞）は研究「重賞の買い方」4回目で 2021〜2026年を確かめた形なので、後半の年はその形にとっても見た年である） |
| 採用の線を満たせば、3連単（重賞）と並べて両方買う | 重賞で買う額が増える。3連単（重賞）は印で選ばないので、新しい買い方の3連単と組が重なることがある |
| 3連単（重賞）の組の確率を、この予想の確率で作り直す（印では選ばない形のまま） | 買い方の形は変えずに確率だけ替える。組の確率の重みの推定し直しが要る |

本番への入れ方（道具「今週の予想」・発走前の通知・財布と金額）は、買い方の設計書を直す話で、採用が決まってから行う（[05-sequence.md の「これから作るところ」](05-sequence.md#これから作るところ)）。

関連する資料: [16-evaluation.md の 6.6](16-evaluation.md#66-採用の線)、[買うレースと買い目を決める の 09 の 24](../買うレースと買い目を決める/09-decisions.md#24-重賞をどう買うか)。
