# 14 ハイパーパラメータを外から指定する

**この文書で決めること:** 木の数などのハイパーパラメータと、重賞の行の重みを、プログラムを書き換えずに外から指定する方法。

**結論: 設定ファイル（TOML 形式）の形も、指定のしかたの決まりも、手本と同じである。この予想では、設定ファイルに重賞の行の重みの表 `[sample_weight]` を足す。初期値のファイルの置き場所も、この予想のものにする。ハイパーパラメータの初期値は手本と同じ値である。**

- 設定ファイルの `[lightgbm]`・`[catboost]` の表の書き方は [手本の 14 の「設定ファイルの形」](../近走と適性から3着以内を予想/14-hyperparameter-settings.md#設定ファイルの形) を参照。
- `--config` での指定、書き間違いをエラーにする、目的関数は変えられない、使った設定をモデルと一緒に保存する、の決まりは [手本の 14 の「決まり」](../近走と適性から3着以内を予想/14-hyperparameter-settings.md#決まり) を参照。
- 用語の意味は [02-glossary.md](02-glossary.md) を参照。

## この予想で足す表

初期値の設定ファイルは、手本と同じ `[lightgbm]`・`[lightgbm.params]`・`[catboost]`・`[catboost.params]` の4つの表（値も手本と同じ）の最後に、次の表を足したものである。

```toml
[sample_weight]               # 学習の行の重み（設計書 08 の 4）。モデルの引数ではない
graded_race = 5.0             # 平地の重賞（G1・G2・G3）の行の重み。ほかの行は 1。1 にすると手本と同じ学び方
```

重みだけを変えて試すときは、変えたい項目だけを書いたファイルを `--config` で渡す。

```toml
[sample_weight]
graded_race = 10.0
```

| 表（`[ ]` の部分） | 書くもの |
|---|---|
| `[sample_weight]` | 学習の行の重み。`graded_race` が重賞の行の重み（1 以上の数）。ほかの行の重みは 1 で固定 |

この初期値のファイルを読み込み、重みの表に別のファイルを重ねて、重みと一緒に2つのモデルに渡して学習できることを確かめた（Python 3.14、lightgbm 4.7.0、catboost 1.2.10。乱数の架空データ）。

## この予想で違う点

| 項目 | 手本 | この予想 |
|---|---|---|
| 初期値の設定ファイルの置き場所 | `src/yosou/form_aptitude_top3/setting/default_settings.toml` | `src/yosou/graded_race_top3_win/setting/default_settings.toml` |
| 表 | 4つ | 4つに `[sample_weight]` を足した5つ |
| ハイパーパラメータの初期値 | 手本の 12・13 の表 | 手本と同じ値（[12-lightgbm.md の 2](12-lightgbm.md#2-ハイパーパラメータの初期値)・[13-catboost.md の 2](13-catboost.md#2-ハイパーパラメータの初期値)） |
| 設定ファイルを読むクラス | 共通の `HyperparameterSettings`（`src/yosou/shared/setting/`） | ハイパーパラメータは同じ `HyperparameterSettings`。重みの表は、この予想の `GradedWeightSettings` が同じ部品（`SettingsFile`・`SettingsNameCheck`・`SettingsOverlay`）で読む（[04-classes.md の 4](04-classes.md#setting--初期値と重みの設定)） |
| 同じ設定で学習するモデル | 3つの時点（と券種オッズなし）× 目的変数2つ | 同じ。重みも、全部のモデルで同じ値を使う |

## 足す決まり

| 決まり | 理由 |
|---|---|
| `[sample_weight]` に無い名前（`graded_race` 以外）を書いたら、エラーにして止める | 手本の決まりと同じ。書き間違えた重みが黙って無視されるのを防ぐ |
| 重みが 1 未満なら、エラーにして止める | 重賞の行を軽く見る使い方は、この予想の狙いに反する。重みを付けない比べは 1 で行う |
| 使った重みを、ハイパーパラメータと一緒にモデルの置き場所に保存し、`train` の「学習データの期間」の表にも出す | どの重みで学んだモデルかが、あとで分かるようにする |
| 時点ごと・目的変数ごとに重みを変える書き方は作らない | 必要が出たら、そのとき足す（手本の「3つの時点のモデルは、同じ設定で学習する」と同じ考え方） |
