# 13 CatBoost で学習・予測するための設計

**この文書で決めること:** 07〜10 で決めた学習データ（特徴量と目的変数と行の重み）を、CatBoost で学習・予測するために、CatBoost だけに必要なことを決める。**節の番号と題名は、手本の 13 とそろえてある。**

| 決めること | 結論 |
|---|---|
| 1. 学習データの渡し方 | 手本と同じ。**行の重みを、学習データと検証データの `Pool` の `weight` で渡す**（この予想で足す）。W の3個のカテゴリ特徴量は、ほかのカテゴリ特徴量と同じ渡し方 |
| 2. ハイパーパラメータの初期値 | **手本と同じ値**（学習の行が手本と同じだから）。早期終了は、重み付きのログ損失で見る |
| 3. カテゴリ特徴量の値の変え方 | 手本と同じ |
| 4.〜6. 学習・予測・保存の手順 | 手本と同じ。4つ（木曜・前日・当日・当日の券種オッズなし）× 目的変数2つで、8つのモデルを学習する。保存先は `reports/重賞に特化して3着以内と1着を予想/models/` |

- 用語の意味は [02-glossary.md](02-glossary.md) を参照。
- 学習データ・特徴量・目的変数・重みは LightGBM と共通で、[08-training-data.md](08-training-data.md)・[09-features.md](09-features.md)・[10-target.md](10-target.md) を参照。
- LightGBM の設計は [12-lightgbm.md](12-lightgbm.md) を参照。
- CatBoost の使い方の基本は [手本の 03 の「5. CatBoost の使い方」](../近走と適性から3着以内を予想/03-library-basics.md#5-catboost-の使い方)、重みの渡し方の例は [03-library-basics.md の「行に重みを付けて学ぶ」](03-library-basics.md#行に重みを付けて学ぶ) を参照。

## 1. 学習データの渡し方

**列の渡し方は手本と同じである**（数値はそのまま、カテゴリは文字列にして `cat_features` に指定し欠損値は「不明」にする、出走の少ない値はまとめない、ID 列と評価用の列は渡さない。[手本の 13 の「1. 学習データの渡し方」](../近走と適性から3着以内を予想/13-catboost.md#1-学習データの渡し方)）。この予想で足すのは次の行だけである。

| 列 | 渡し方 | 理由 |
|---|---|---|
| 行の重み（学習データ） | 学習データの `Pool(weight=重み)` | 重賞の行を重く見て木を作る（[08-training-data.md の 4](08-training-data.md#4-重賞の行の重み)） |
| 行の重み（検証データ） | 検証データの `Pool(weight=重み)` を `eval_set` に渡す | 早期終了が見る検証データの当たり具合を、重賞の行を重く見たログ損失にする（LightGBM と同じ理由。[12-lightgbm.md の 1](12-lightgbm.md#1-学習データの渡し方)） |
| W の格・重量種別・前走の格 | 文字列にして `cat_features` に並べる（欠損値は「不明」。今回の格と重量種別は欠損しない） | 手本のカテゴリ特徴量と同じ |
| W の数値の 11個・K の 51個 | そのまま。欠損値も NaN のまま | 手本の数値特徴量と同じ |

前日・当日のモデルは、手本と同じく、オッズから作った基準を出発点にする（`Pool` の `baseline`。木曜は基準なしで学ぶ）。予測には重みを渡さない。

## 2. ハイパーパラメータの初期値

**手本の初期値をそのまま使う**（`learning_rate` 0.05、`iterations` 2000、`early_stopping_rounds` 100、`depth` 6、`l2_leaf_reg` 3、`random_seed` 42）。値と理由は [手本の 13 の「2. ハイパーパラメータの初期値」](../近走と適性から3着以内を予想/13-catboost.md#2-ハイパーパラメータの初期値) を参照。値は設定ファイルで変えられる（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)）。

- **手本と同じ値にする理由:** 学習の行が手本と同じだからである（[12-lightgbm.md の 2](12-lightgbm.md#2-ハイパーパラメータの初期値) と同じ）。
- 1 と 0 の数の偏りを直す設定（`auto_class_weights`）は使わない（[10-target.md の「1 と 0 の数の偏り」](10-target.md#1-と-0-の数の偏り)）。行の重みは `Pool` の `weight` で渡し、`auto_class_weights`・`class_weights` とは混ぜない。
- 調整のやり方は [16-evaluation.md の 7](16-evaluation.md#7-ハイパーパラメータの調整のやり方) を参照。

## 3. カテゴリ特徴量の値の変え方（フローチャート）

**手本と同じである。** `CatBoostEncoder.transform()` の手順（欠損値は文字列「不明」、それ以外は文字列にする）は、[手本の 13 の「3. カテゴリ特徴量の値の変え方（フローチャート）」](../近走と適性から3着以内を予想/13-catboost.md#3-カテゴリ特徴量の値の変え方フローチャート) を参照。

## 4. 学習のやりとり（シーケンス図）

**手本と同じである。** `TrainingWorkflow` → `CatBoostModel` → `CatBoostEncoder` → `CatBoostClassifier` の呼び出しは、[手本の 13 の「4. 学習のやりとり（シーケンス図）」](../近走と適性から3着以内を予想/13-catboost.md#4-学習のやりとりシーケンス図) を参照。違うのは、`CatBoostModel` が学習データと検証データの `Pool` を作るときに、重み（`TrainingData.weight`）も付けることだけである。この流れを、時点ごと・目的変数ごとに1回ずつ行う。

## 5. 予測のやりとり（シーケンス図）

**手本と同じである。** [手本の 13 の「5. 予測のやりとり（シーケンス図）」](../近走と適性から3着以内を予想/13-catboost.md#5-予測のやりとりシーケンス図) を参照。返すのは、3着以内のモデルなら「3着以内に入る確率」、1着のモデルなら「1着になる確率」である。

## 6. 保存

- 保存のしかた（`save_model()` で書き込み、`load_model()` で読み込む）は、[手本の 13 の「6. 保存」](../近走と適性から3着以内を予想/13-catboost.md#6-保存) と同じである。重みはモデルの中に残らないので、保存するものは増えない。
- 学習に使った設定（ハイパーパラメータと重賞の行の重み）を、モデルと一緒に保存する（[14-hyperparameter-settings.md](14-hyperparameter-settings.md)）。
- 保存先: Git の対象外の `reports/重賞に特化して3着以内と1着を予想/models/`（[04-classes.md の 3](04-classes.md#3-パッケージ構成)）。
