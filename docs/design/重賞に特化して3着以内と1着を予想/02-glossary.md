# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語のうち、手本の予想（近走と適性から3着以内を予想）と、引退した予想（重賞の傾向と近走から3着以内を予想）に出てこないものの意味をまとめる。

**この文書で示すこと:** 機械学習の用語と、競馬とこの設計の用語は、手本と同じものをそのまま使う。重賞の傾向（K）の用語は、引退した予想と同じものを使う。この予想で増えるのは、行の重み・重賞の格と実績・買い目の確かめ方に関する用語である。

- 機械学習の用語（二値分類・特徴量・目的変数・リーク・早期終了・ログ損失など）は [手本の 02 の「機械学習の用語」](../近走と適性から3着以内を予想/02-glossary.md#機械学習の用語) を参照。
- 競馬とこの設計の用語（ID 列・評価用の列・確定オッズ・オッズから見た勝率・1着になる確率・単勝の期待値・ウォームアップ期間・事実表など）は [手本の 02 の「競馬とこの設計の用語」](../近走と適性から3着以内を予想/02-glossary.md#競馬とこの設計の用語) を参照。
- 重賞・特別競走番号・過去の開催・レースごとの傾向・切り口・帯は [引退した予想の 02](../重賞の傾向と近走から3着以内を予想/02-glossary.md#この予想で増える用語) を参照。

## この予想で増える機械学習の用語

| 用語 | 意味 | この設計では |
|---|---|---|
| サンプルの重み | 学習のときに、行ごとに「どれだけ重く見るか」を表す数。重み 5 の行は、同じ行が5つあるのと同じように誤差に数えられる | 重賞の行は 5、ほかの行は 1（[08-training-data.md の 4](08-training-data.md#4-重賞の行の重み)）。LightGBM は `sample_weight`、CatBoost は `Pool` の `weight` で渡す（[03-library-basics.md](03-library-basics.md#行に重みを付けて学ぶ)） |
| 重み付きのログ損失 | 行ごとのログ損失に重みを掛けて平均したもの | 早期終了で見る検証データの当たり具合（[12-lightgbm.md の 1](12-lightgbm.md#1-学習データの渡し方)） |

## 競馬とこの設計の用語（この予想で増えるもの）

| 用語 | 意味 | この設計では |
|---|---|---|
| 重賞の行 | 学習データの行のうち、平地の重賞（グレードコード A・B・C = G1・G2・G3）の出走の行。全レースの行の約4% | 重みを付ける行。当たり具合と採否は、この行だけで測る（[16-evaluation.md](16-evaluation.md)） |
| 格 | レースの格付け。G1・G2・G3・L（リステッド）・OP（オープン）・条件（3勝クラス以下）の6つ | まとまり W の「格」と「前走の格」（[09-features.md の W](09-features.md#w-重賞の格と実績14個)）。決め方は [06-flowchart.md の図3](06-flowchart.md#図3-格の名前の決め方) |
| 格の段 | 格を低い順に並べた番号。条件 1・OP 2・L 3・G3 4・G2 5・G1 6 | 「今回の格以上のレース」を数えるときに使う |
| 重量種別 | 斤量の決め方。定量・別定・馬齢・ハンデ（JV-Data の重量種別コード） | まとまり W の「重量種別」 |
| トップハンデとの差 | 自分の斤量 − 同じレースでいちばん重い斤量。0 なら自分がいちばん重い | まとまり W。ハンデ戦で、ハンデキャッパーの見立ての中での位置を表す |
| 同じ重賞の経験 | 同じ特別競走番号の重賞に、それより前に出たか・何着だったか | まとまり W の3個。過去の開催の出走馬の表（K と同じ表）から引く |
| 手本を重賞だけに使ったとき | 手本の予想（全レースで同じ重みで学んだもの）の確率を、重賞の行だけで測ったもの | 確率の誤差の比べる相手（[16-evaluation.md の 3](16-evaluation.md#3-比べる基準)） |
| 前半の年・後半の年 | 確かめる7年（2020〜2026年）を前と後ろに分けたもの。前半の年は 2020〜2022年、後半の年は 2023〜2026年 | 印からの買い目の組み方と券種の選び方は前半の年だけで選び、後半の年で一度だけ確かめる（[16-evaluation.md の 6](16-evaluation.md#6-印からの買い目の確かめ)） |
| 形（買い目の組み方） | 1つの券種で、印から買い目を作る決まり。軸・相手・オッズの上限と下限・点数の上限・組の期待値の線の組み合わせ | 例: 3連単 ○▲ → 消以外 → ◎。候補は [16-evaluation.md の 6.3](16-evaluation.md#63-形の候補) |
| 無印に流す | 3連複・3連単の相手に、印の無い馬（無印）も入れること。消の馬は入れない | 形の候補の1つ（例: ◎ → ○▲ → 消以外の全頭） |
| レースごとの券種の選び方 | 1つの重賞で、レースの中身（期待度・◎ の確率と期待値・荒れ具合・頭数など、レース前に分かるもの）から、買う券種を 2〜4つ選ぶ決まり | [16-evaluation.md の 6.5](16-evaluation.md#65-レースごとの券種の選び方) |
| 合計の回収率 | 選んだ券種の払戻の合計 ÷ 購入額の合計。1点 100円で数える | 採用の線（[16-evaluation.md の 6.6](16-evaluation.md#66-採用の線)） |
| 90% の幅 | 開催日を単位にしたブートストラップで出した、回収率の 90% 信頼区間。下の端が 100% を超えれば、偶然で 100% を超えたとは言いにくい | 形を選ぶときは下の端で比べる |
| 期待度 | レースごとに「◎ を信じてよいか」を表す目安（S・A・B・C・見送り）。作りは [買うレースと買い目を決める の 03 の 5](../買うレースと買い目を決める/03-race-screening.md#5-レースごとの目安期待度) | この予想の ◎ の1着の確率と単勝の期待値で出す。見送りの重賞も、券種を選んで買う |
