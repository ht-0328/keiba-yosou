# 02 用語の意味

**この文書の目的:** この設計書に出てくる用語の意味を1か所にまとめる。

**結論: 機械学習の用語と、荒れ具合の用語（多クラス分類・クラス・累積確率・荒れ具合・券種・払戻・オッズの形・1番人気・過去の荒れ率 など）は、中央の荒れ具合の予想の [02 用語の意味](../レースの荒れ具合を4段階で予想/02-glossary.md) と同じである。地方のデータの用語（地方競馬DATA・nvdata-store・元DB・出馬表（時点）・出走別着度数地方・競走条件名称・格・ばんえい など）は、地方の全頭の予想の [02 用語の意味](../地方競馬の近走と適性から3着以内を予想/02-glossary.md) と同じである。** ここには、この予想で増える用語と、意味が変わる用語だけを書く。

## 中央の荒れ具合の予想・地方の全頭の予想と同じ用語

- 多クラス分類・クラス・予測確率（多クラス）・いちばん高いクラス・累積確率・目的関数（多クラス）・マクロ F1・混同行列・集約・荒れ具合・券種・払戻・払戻の人気順・不成立・特払・返還・発売の無い券種・オッズの形・市場勝率・1番人気・過去の荒れ率・レース単位の特徴量は、[中央の荒れ具合の 02](../レースの荒れ具合を4段階で予想/02-glossary.md) を参照。
- 地方競馬DATA・nvdata-store・元DB・出馬表（時点）・出走別着度数地方（`nd`）・総合着回数・競走馬マスタ地方（`nu`）・格（Ａ・Ｂ・Ｃ）・競走条件名称・交流競走・所属・ばんえいは、[地方の全頭の予想の 02](../地方競馬の近走と適性から3着以内を予想/02-glossary.md) を参照。

## この予想で増える用語・変わる用語

| 用語 | 意味 | この設計では |
|---|---|---|
| 地方の線引き | 券種ごとの荒れ具合の4段階を区切る3つの払戻の額。地方の払戻は中央より高く出るので、中央の額とは別に決める | [10-target.md](10-target.md#券種ごとの線引き)。3連単は利用者の帯（1万・10万・100万円）、ほかの券種は 3連単と同じ割合になる額 |
| 万馬券・10万馬券 | 払戻が 1万円以上・10万円以上の馬券。利用者が地方の3連単で狙う帯 | 3連単の中荒れ（1万円以上）・大荒れ（10万円以上）の境 |
| 当日の馬場傾向（U） | その日に先に終わった同じ競馬場のレースで「市場の見立てより来た馬が内か外か・前か後ろか」を傾きで数えたもの。地方の全頭の予想の U（5個。馬ごと）と同じ部品 | この予想では、馬ごとの補正ではなく、レースに1つの値（使う内の傾き・使う前の傾き）の2個を使う（[09-features.md](09-features.md#u-当日の馬場傾向のレースの値2個当日)） |
| 使う傾き | 当日の傾き（先に終わったレースの傾きの平均）と過去の傾き（同じ馬場 × 開催の何日目 × 馬場状態の平均）を、レース数で混ぜたもの。内の傾きと前の傾きの2つ | U の2個の値そのもの |
| 過去の傾きの表 | 同じ馬場 × 開催の何日目 × 馬場状態ごとの、過去のレースの傾きの平均の表。この予想では、そのレースの年の1月1日より前のレースだけで作る | 学習データ（`LocalBiasHistory`）と予測（`PriorSlopeYearStore`）で同じ決めごと（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 11） |
| 速報 0B15 | 地方競馬DATA の速報のうち、出馬表の更新と当日の成績（着順・4コーナーの順位）が入るもの。発走前の通知が発走前に取り直す | 当日の馬場傾向の元（その日に先に終わったレースの結果）。取り込んでいなければ前の日のレースと過去の傾きだけで出す |
| 学習データのとっておき | 学習データを pickle のファイルに書いておき、2回目からは読むこと | `reports/地方のレースの荒れ具合を4段階で予想/cache/`（[08-training-data.md](08-training-data.md#5-学習データのとっておき)） |
| 推奨買目 | 発走前の通知（地方）に出す買い目。道具「地方の推奨買目」が検証済みの買い方で選ぶ | この予想の「3連複の中荒れ以上の確率」が、3連複を買うかどうかの条件になる（[買い方の 10](../買うレースと買い目を決める/10-local-recommended-tickets.md)） |
| 中荒れ以上の確率の線 | 「中荒れ以上の確率」がこの値以上のレースだけを買う、という線 | 3連複は 0.6（研究「地方の万馬券」の [docs/06](../../../research/地方の万馬券/docs/06-馬連と3連複.md)）。線は設計書に書き、学び直したら `train` の報告の表で選ばれるレースの割合が変わっていないかを見る（[16-evaluation.md](16-evaluation.md#4-使い方の線引き)） |
| 市場の割れ方だけの基準 | オッズの形（B）と頭数だけで、この予想と同じ手順で学んだ基準 | 研究「地方の万馬券」で比べた（[16-evaluation.md](16-evaluation.md#3-比べる基準)）。この予想の当たり具合はこれとほぼ同じ |
