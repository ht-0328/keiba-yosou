# 03 LightGBM と CatBoost（と pandas）の使い方

**この文書の目的:** 設計を読む前に、LightGBM と CatBoost（と、表を扱う pandas）で何ができるかを知っておく。

**結論: 使う道具は中央の荒れ具合の予想と同じ（LightGBM・CatBoost・pandas・scikit-learn）で、使い方（多クラス分類で4つの確率を出し、2つのモデルの確率の表を平均する）も同じである。** 道具の説明は、手本の [03 LightGBM と CatBoost（と pandas）の使い方](../近走と適性から3着以内を予想/03-library-basics.md) と、多クラス分類で違う点を書いた [中央の荒れ具合の 03](../レースの荒れ具合を4段階で予想/03-library-basics.md) を参照する。ここには、この予想で違う点だけを書く。

## 参照する節

| 節 | 何が書いてあるか |
|---|---|
| [手本の 03 の 1.〜6.](../近走と適性から3着以内を予想/03-library-basics.md#1-準備) | 入れるパッケージ、pandas の使い方、モデルを作る → `fit()` → `predict_proba()`、LightGBM と CatBoost のコード例、2つの確率の平均 |
| [中央の荒れ具合の 03 の「この予想で違う点」](../レースの荒れ具合を4段階で予想/03-library-basics.md#この予想で違う点) | 多クラス分類の目的関数（`multiclass`・`MultiClass`）、`predict_proba()` が 行数 × 4 の表を返すこと、4列の表を平均する書き方（`np.stack(…).mean(axis=0)`） |

## この予想で違う点

| 違い | 内容 |
|---|---|
| 学習データの大きさ | 1行 = 1レースで、2019年から今までの地方の全レース（約 10万行）。中央の荒れ具合（約 5万行）の2倍ほどで、1頭ごとの地方の予想（約 87万行）よりは小さい。学習の時間は1つの時点・1つのモデルで 1〜3分 |
| 特徴量の数 | 当日は 51個（中央の 49個 ＋ 当日の馬場傾向のレースの値 2個）。LightGBM・CatBoost に渡す形は同じ（数値はそのまま、カテゴリは `category` 型） |
| 実行するコード | 中央の荒れ具合の予想と同じ共通のクラス（`src/yosou/shared/ml_model/` の `LightGbmMulticlassModel`・`CatBoostMulticlassModel`・`EnsembleModel`）なので、動かして確かめたコードも中央の 03 のものがそのまま当たる |
