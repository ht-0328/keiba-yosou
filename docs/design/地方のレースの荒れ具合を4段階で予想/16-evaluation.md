# 16 当たり具合の測り方

**この文書で決めること:** 学習に使っていないデータで、この予想の当たり具合をどう測るか。学習データ・検証データ・テストデータの期間をどう分けるか。何と比べれば「当たっている」と言えるか。推奨買目の線（中荒れ以上の確率 0.6）をどう見守るか。

| 決めること | 結論 |
|---|---|
| 1. 期間の分け方 | 時期で分ける。既定は 学習 2019年1月〜2025年6月、検証 2025年7〜12月、テスト 2026年1月〜（ウォームアップ 2016〜2018年）。`train` の引数で変えられる |
| 2. 評価指標 | 中央の荒れ具合の予想と同じ共通の指標（正解率・マクロ F1・混同行列・クラスのずれの平均・多クラスのログ損失・累積確率の AUC）を、券種ごと・時点ごとに出す |
| 3. 比べる基準 | 研究「地方の万馬券」で、クラスの割合だけの基準と「市場の割れ方だけ」の基準と比べた（済み）。学び直しのたびには比べない |
| 4. 使い方の線引き | `train` の報告に、券種ごと・時点ごとに「中荒れ以上の確率」のしきい値ごとのレース数と実際に中荒れ以上だった割合を出す。推奨買目の線（3連複 0.6）で選ばれる割合が前と大きく変わっていないかを見る |
| 5. 確かめた結果 | 研究の段④（2023年前半までで学び、2024〜2026年を未見のまま予測）で当たり具合と買い目の回収率を確かめ、本番のモデルは研究のモデルと確率の尺度が同じことを見た |

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 期間の分け方

区分（ウォームアップ・学習・検証・テスト）の意味は、中央の荒れ具合の予想の [16 の「1. 期間の分け方」](../レースの荒れ具合を4段階で予想/16-evaluation.md#1-期間の分け方) と同じ。既定の日は [08-training-data.md の「4. 期間の指定」](08-training-data.md#4-期間の指定)。共通の `PeriodSplitter` が学習データを3つに分け、`train` は検証データだけで当たり具合を測り、早期終了にも検証データを使う。テストデータ（2026年〜）は、研究のモデルとの尺度の比べ（下の 5.）に使った。

時期で分ける理由（同じ開催日のレースが学習と検証に散らばると、その日の馬場の傾向を先に知ってしまう）は中央と同じで、地方は同じ競馬場で1日 11〜12 レースを続けて行い、U がその日の傾きを数えるので、なおさら時期で分ける。

## 2. 評価指標

中央の荒れ具合の予想の [16 の「2. 評価指標」](../レースの荒れ具合を4段階で予想/16-evaluation.md#2-評価指標) と同じ。共通の `ClassMetricCalculator` で計算し、`train` の出力（`ClassTrainingReportTables`。時点は 出馬表・前日・当日 と出す）に、券種ごと・時点ごとに LightGBM・CatBoost・平均の行で出る。判断は平均の行で行う。

地方で気を付ける点: 地方は固いレースの割合が約半分で、超荒れが 1% 弱しか無い。超荒れの当たり具合は偶然の幅が大きいので見ない。推奨買目が使うのは「中荒れ以上の確率」なので、累積確率の AUC（中荒れ以上）とログ損失を主に見る。

## 3. 比べる基準

| 基準 | 何を出すか | どこで比べたか | 何が分かったか |
|---|---|---|---|
| クラスの割合をそのまま確率にする | 学習データの4クラスの割合を全レースに同じ確率として出す | 研究の段④（[研究の docs/04](../../../research/地方の万馬券/docs/04-予想方法の段ごとの精度.md)） | この予想のログ損失はこれより小さい（レースごとに違う確率を出せている） |
| 市場の割れ方だけ | 特徴量をオッズの形（B の 10個）と頭数だけにして、同じ手順で学んだモデル | 同上 | この予想とログ損失・AUC がほぼ同じ。出走馬のばらつき・1番人気の危うさ・過去の荒れ率・当日の馬場傾向を足しても、オッズの形で分かる以上のことは学べていない（荒れは市場の割れ方で決まる） |

**それでも本番にする理由。** 当たり具合に上乗せが無くても、「中荒れ以上の確率」でレースを絞ると 3連複の買い目の回収率が未見の3年とも 100% を超え、線を上げるほど単調に上がった（下の 5.）。推奨買目に要るのは、荒れるレースを並べる物差しであって、市場より当たる予想ではない。中央の `train` が出す4つの基準との比べ（利用者の規則・1番人気のオッズだけ など）は、この予想では出さない（[15-decisions.md の 10](15-decisions.md#10-学習の報告に何を出すか)）。

## 4. 使い方の線引き

推奨買目の 3連複は、3連複の中荒れ以上の確率が 0.6 以上のレースだけ買う（[買い方の 10](../買うレースと買い目を決める/10-local-recommended-tickets.md)）。線は研究で決めて設計書に書くが、学び直すとモデルの確率の尺度が少し変わりうる。そのため `train` の報告に、券種ごと・時点ごとに、しきい値 0（全レース）と 0.3〜0.9（0.1 刻み）の行で、レース数・実際に中荒れ以上だった割合・中荒れ以上のうち選んだ割合を出す（`UpsetThresholdTable`。中央の `UpsetThresholdSummary` を時点ごとに回す。[04-classes.md](04-classes.md#command--コマンド)）。

学び直したら、3連複・当日の行で、しきい値 0.6 の「レース数 ÷ 全レース数」（選ばれるレースの割合）と「実際に中荒れ以上だった割合」が、前の学習（`reports/地方のレースの荒れ具合を4段階で予想/学習の結果.md`）と大きく変わっていないかを見る。変わっていれば、研究の段6（`quinella_trio.py --stage 3`）を新しい予測でやり直して線を決め直す。

## 今はしないこと

- 本番のモデルで未見の年を作って回収率を確かめ直すこと（研究の予測で済ませてある。学び直して尺度が変わったときにやり直す。[15-decisions.md の 9](15-decisions.md#9-当たり具合をどう確かめるか)）。
- ハイパーパラメータの調整（中央と同じ初期値のまま。研究で当たり具合が市場の割れ方だけの基準と同じだったので、調整で上乗せが出る見込みが小さい）。
