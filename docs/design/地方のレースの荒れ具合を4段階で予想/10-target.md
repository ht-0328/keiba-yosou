# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。荒れ具合の4段階を、何で、どこで線を引いて決めるか。

**結論: 目的変数は中央の荒れ具合の予想と同じ「券種ごとの荒れ具合」で、単勝・馬連・3連複・3連単の4つの列を持つ。それぞれ、そのレースのその券種の払戻（100円あたりの円）を、券種ごとに決めた3つの額で区切り、固い（0）・中荒れ（1）・大荒れ（2）・超荒れ（3）にする。線引きの額は地方の払戻に合わせて中央と別に決め、3連単は利用者の帯（万馬券 1万円・10万馬券 10万円・100万円）、ほかの券種は 3連単と同じ割合になる額にした（研究「地方の万馬券」の段④。[15-decisions.md の 1](15-decisions.md#1-荒れ具合の線引き)）。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 券種ごとの線引き

**この表が、線引きのただ1つの置き場所である**（プログラムでは `LocalUpsetRule` の定数 `LOCAL_THRESHOLDS`。[04-classes.md](04-classes.md#dataset--学習データ予測用データの決めごと)）。

| 券種 | 固い（0） | 中荒れ（1） | 大荒れ（2） | 超荒れ（3） | 目安 |
|---|---|---|---|---|---|
| 単勝 | 300円未満 | 300円以上 1,500円未満 | 1,500円以上 5,000円未満 | 5,000円以上 | 勝ち馬のオッズが 3倍・15倍・50倍 |
| 馬連 | 1,000円未満 | 1,000円以上 6,000円未満 | 6,000円以上 3万円未満 | 3万円以上 | |
| 3連複 | 2,000円未満 | 2,000円以上 1.5万円未満 | 1.5万円以上 10万円未満 | 10万円以上 | |
| 3連単 | 1万円未満 | 1万円以上 10万円未満 | 10万円以上 100万円未満 | 100万円以上 | 万馬券が中荒れ、10万馬券が大荒れ、100万馬券が超荒れ |

**この線引きにした理由。** 利用者が地方の3連単で狙うのは「万馬券・10万馬券」（研究「地方の万馬券」の [README](../../../research/地方の万馬券/README.md)）なので、3連単の線は利用者の帯（1万・10万・100万円）そのままにした。中央の荒れ具合の線（3連単 2万・10万・50万円）は中央の払戻の分布で決めたもので、地方は頭数が少なく1番人気の支持が偏るぶん固いレースが多い一方、荒れると払戻が中央より高く出るので、そのまま使うと割合が合わない。ほかの3券種は、2019年以降の地方の全レースで 3連単と同じ割合（固い 5割・中荒れ 4割・大荒れ 1割・超荒れ 1% 弱）になる額を、切りのよい額に丸めた。4券種で割合をそろえると、券種どうしで「中荒れ以上の確率」の意味がそろう。

- 年ごとの割合は安定している（数値は研究の `reports/地方の万馬券/荒れ具合の精度.md`。Git の対象外）。
- 中央の線引きをそのまま使う案と、分位点で区切る案は [15-decisions.md の 1](15-decisions.md#1-荒れ具合の線引き) を参照。

## 作り方

中央の荒れ具合の予想の [10 の「作り方」](../レースの荒れ具合を4段階で予想/10-target.md#作り方) と同じ。学習データの1行（1レース）の払戻（`hr` の券種ごとの表）から、券種ごとに次のように決める（判断の手順は [中央の 06 の図1](../レースの荒れ具合を4段階で予想/06-flowchart.md#図1-学習データに入れるレースの選び方と4クラスの付け方)）。

| そのレースのその券種の状態 | 目的変数 |
|---|---|
| 払戻が1つある | 上の表で決めたクラス（0〜3） |
| 同着で払戻が複数ある | 最大の払戻でクラスを決める |
| 発売が無い（頭数が少ない） | 欠損値。その券種のモデルの学習から外す（ほかの券種の列は普通に付ける）。地方は 7頭以下のレースが多く、3連単の列が欠損値の行がそれなりにある |
| 不成立・特払 | 欠損値。同上 |
| 返還あり | 普通に扱う |

- 4つの列の名前は「荒れ具合（単勝）」「荒れ具合（馬連）」「荒れ具合（3連複）」「荒れ具合（3連単）」（中央と同じ `BetType.column_name`）。
- 払戻は、レースの結果である。特徴量にはしない。過去の同条件の荒れ率（E）は、この線引きで前日までのレースを数える（[11-leak-prevention.md](11-leak-prevention.md#決まり) の 6・7）。
- 4クラスは順序があるが、モデルは順序を見ない多クラス分類で学習する（中央と同じ）。

`predict_proba()` は、1レースにつき4つの確率（固い・中荒れ・大荒れ・超荒れの順）を返し、「中荒れ以上の確率」は固い以外の3つの合計である。推奨買目の 3連複は、3連複の中荒れ以上の確率を使う（[買い方の 10](../買うレースと買い目を決める/10-local-recommended-tickets.md)）。

## 理由

**券種ごとに決める理由と、払戻で決める理由**は、中央の荒れ具合の予想の [10 の「理由」](../レースの荒れ具合を4段階で予想/10-target.md#理由) と同じ。推奨買目は券種ごとに買い方を分けているので、荒れ具合も券種ごとに要る（3連複の条件には 3連複の荒れ具合を使う）。

## クラスの数の偏り

どの券種でも、固いが約半分、超荒れは 1% 弱である。この偏りは、**直さずにそのまま学習する**（中央と同じ。偏りを直す設定を使うと、4つの確率を確率として使えなくなる）。超荒れは少ないので、超荒れの当たり具合は偶然の幅が大きい。推奨買目が使うのは「中荒れ以上の確率」（固いかどうか）なので、超荒れの当たり具合に頼らない。
