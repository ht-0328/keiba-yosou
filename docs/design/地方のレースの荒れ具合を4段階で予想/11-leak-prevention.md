# 11 リークを防ぐ決まり

**この文書で決めること:** 学習では当たるのに本番では当たらないモデル（リーク）にならないよう、特徴量を作るときに守る決まり。

**結論: 特徴量は、予測する時点（出馬表・前日・当日。[07-prediction-timing.md](07-prediction-timing.md)）で分かることだけから作る。決まりは中央の荒れ具合の予想の [11 リークを防ぐ決まり](../レースの荒れ具合を4段階で予想/11-leak-prevention.md) の 1〜10 と同じで、当日の馬場傾向のレースの値（U）と地方のデータで気を付ける点を 11〜13 に足す。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 決まり

1〜10 は中央の荒れ具合の予想の [11 の「決まり」](../レースの荒れ具合を4段階で予想/11-leak-prevention.md#決まり) と同じ（そのレースの結果を使わない・開催日より前のものだけから計算する・マスタの累計を使わない・学習と予測で同じクラスでデータを作る・確定オッズは特徴量に使ってよいが予測では締め切り前のオッズになる・払戻は目的変数と評価用の列にだけ使う・過去の荒れ率は前日までのレースだけ・前日以降は全頭の単勝オッズが要る・1番人気はその時点のオッズの最小・出走頭数はその時点の頭数）。この予想では、次を足す。

**11. 当日の馬場傾向のレースの値（U）は、そのレースより前に終わったレースだけから作り、学習と予測で同じ決めごとにする。**

- 当日の傾きは、同じ開催日の先に終わった（レース番号の小さい）同じ競馬場のレースと、前の日のレース（0.5 本として数える）だけから数える。同じ日のあとのレースは数えない。
- 過去の傾きの表は、そのレースの年の1月1日より前のレースだけで作る。学習データは年ごとに作り直し（`LocalBiasHistory`）、予測は年ごとにとっておいた表（`PriorSlopeYearStore`）を使う。どちらも同じ `PriorSlopeTableBuilder.build(傾きの表, before=その年の1月1日)` である。中央の `PriorSlopeTableStore`（元DB にある全部のレースで作る）は使わない。使うと、予測の表に「その年のあとのレース」が混ざり、学習（年の始まりまで）と予測で過去の傾きの元がずれる。
- 当日の傾きの元になる同じ日のレースの結果は、発走前の通知が発走前に取り直す速報 0B15 で元DB に入る。取り込んでいなければ、当日の傾きは前の日のレースだけになり、過去の傾きに寄る（止めない。学習のときは全部のレースの結果がそろっているので、予測のほうが少し弱くなるだけで、学習に無い情報は入らない）。
- U は馬ごとの補正ではなく、レースの値（使う内の傾き・使う前の傾き）だけを使う（[09-features.md の U](09-features.md#u-当日の馬場傾向のレースの値2個当日)）。前らしさの見込み（馬ごと）は要らない。

**12. 事実表は確定の行（データ区分 5・6・7）で作り、速報の成績（5・6）も終わったレースとして数える。**

- 同じ日の先に終わったレースは、速報の成績（データ区分 5・6）として元DB に入り、確定の成績（7）が月曜に届く。事実表はどちらも「終わったレース」として読むので、当日の傾きの元に使える。
- 学習データのレース（目的変数を付けるレース）は、払戻のあるレースだけ（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)）。

**13. 地方の過去走・出走別着度数地方は、地方の全頭の予想と同じ決まりで読む。**

- 出走別着度数地方（`nd`）はその出走の時点の値なので使ってよい。競走馬マスタ地方（`nu`）の累計は使わない（[地方の全頭の予想の 11 の 6](../地方競馬の近走と適性から3着以内を予想/11-leak-prevention.md#決まり)）。
- クラスは競走条件名称から読む（出馬表の時点で決まっている。同じく 7）。
