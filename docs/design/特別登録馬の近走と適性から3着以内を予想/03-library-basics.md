# 03 LightGBM と CatBoost（と pandas）の使い方

**この文書の目的:** 設計を読む前に、LightGBM と CatBoost（と、表を扱う pandas）で何ができるかを知っておく。

**結論: 使う道具は中央の予想と同じ（LightGBM・CatBoost・pandas・scikit-learn）で、使い方も同じである。** 道具の説明は中央の予想の [03 LightGBM と CatBoost（と pandas）の使い方](../近走と適性から3着以内を予想/03-library-basics.md) を参照する。ここには、この予想で違う点だけを書く。

## この予想で違う点

| 違い | 内容 |
|---|---|
| カテゴリ特徴量が無い | 180個の特徴量はすべて数値である（M・O・T・Y。[09-features.md](09-features.md)）。中央の木曜のモデルと同じく、文字の列（競馬場コードなど）は数にしてから渡す。LightGBM の「出走が少ない値をその他にまとめる」変換と、CatBoost の `cat_features` の指定は、対象の列が無いので何もしない（[12-lightgbm.md](12-lightgbm.md)・[13-catboost.md](13-catboost.md)） |
| 学習データの大きさ | 中央の木曜のモデルと同じ約 70 万行（2012年〜）に 180 列。1つの目的変数・1つのモデルの学習で十数分の見込み（木曜のモデルと同じ程度） |
| モデルの数 | 時点が1つ（特別登録）なので、3着以内と1着の2つの目的変数 × LightGBM と CatBoost の 4個 |
| 基準（出発点） | オッズが無いので、オッズから作った基準は使わず、基準なしで学ぶ（中央の木曜のモデルと同じ） |

実行するコードは、中央の予想と同じ共通のクラス（`src/yosou/shared/ml_model/`）なので、動かして確かめたコードも中央の 03 のものがそのまま当たる。
