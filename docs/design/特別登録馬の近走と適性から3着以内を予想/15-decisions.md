## 1. 何を当てるか

| 選び方 | 変わること |
|---|---|
| **出走した馬だけで学び、登録馬の全員に「出走すれば」の確率を出す（決定）** | 学習データは確定成績から 14年分（約 70 万行）作れる。出走しない登録馬（約 2 割）にも確率が付く。木曜に出走馬名表が出たら中央の予想に引き継ぐ |
| 出走しなかった登録馬を 0 にする | 登録の記録が 1年分しか無く、学習データが 14年分 → 1年分になる。「出るか」と「走るか」が混ざり、確率が読めなくなる |
| 「出走するか」を別の小さなモデルで出す | 1年分の登録（約 1.66 万件）で学べる。あとから足せるので、今回の設計には入れない |
| 1着を出さない | ◎ を決める材料が 3着以内の確率だけになり、中央の木曜の印の決め方とずれる |

関連する資料: [10-target.md](10-target.md)、[16-evaluation.md の 7.](16-evaluation.md#7-登録馬全員に出した予想の確かめ)

## 2. 対象のレース

| 選び方 | 変わること |
|---|---|
| **特別登録がある平地の全レース。重賞を含む。障害は外す（決定）** | 年に約 915 レース。重賞（年 約 130）の予想もこの中で出せる |
| 重賞だけ | 年 約 130 レースで、確かめが粗くなる |
| 障害も入れる | 障害は走り方が違い、中央の予想も学習データに入れていない。スピード指数も障害には無い |

関連する資料: [08-training-data.md の 3.](08-training-data.md#3-どのサンプルを入れるか)

## 3. 学習に使う行

| 選び方 | 変わること |
|---|---|
| **中央の平地の全レースの出走馬に「特別競走か」（Y）を足して学ぶ（決定）** | 約 70 万行。中央の木曜のモデルと同じ行。特別競走の違いは Y とクラスの並び順でモデルが学ぶ |
| 特別競走の出走馬だけで学ぶ | 約 17 万行（4 分の 1）。重賞だけで学んだ専用の予想は行が足りず引退した |

関連する資料: [08-training-data.md の 3.](08-training-data.md#3-どのサンプルを入れるか)、[09-features.md の Y](09-features.md#y-特別競走の印1個)

## 4. 時点

| 選び方 | 変わること |
|---|---|
| **特別登録（月曜・ハンデ発表後）の1つだけ。木曜以降は中央の予想に任せる（決定）** | モデルは 3着以内と1着の 2組。中央の予想と同じものを2つ持たない |
| 日曜の版（ハンデ発表前）の時点も出す | 同じモデルで、ハンデ戦の負担重量を欠損値にして出せる。別の時点にはしない（下の 12） |
| この予想にも木曜以降の時点を足す | 中央の予想がすでに持っている時点を2つ持つことになる |

関連する資料: [07-prediction-timing.md](07-prediction-timing.md)

## 5. 材料

| 選び方 | 変わること |
|---|---|
| **M のうち使える 168個・O の7個・T の4個・Y の1個の 180個。相手と比べる材料は登録馬の中で数える。調教・通算と直近の成績・対戦レーティングは登録日相当まで（決定）** | 中央の木曜のモデルの材料から、騎手・枠番・馬番・出走頭数・馬場状態・馬体重・ブリンカー・持ち時計の順位を使うものを外しただけで、作る部品は同じ |
| 相手と比べる材料（70個）を外す | 学習と予測のずれは無くなるが、中央で効いている材料が減る。`backtest --variant 相手と比べない` で比べ、良いほうを採る（[16-evaluation.md の 4.](16-evaluation.md#4-7つの区切りでの確かめ)） |
| 1年分の登録で「登録頭数」「同じ週の登録の数」も足す | 学習データが 1年分になるので採らない |

関連する資料: [09-features.md](09-features.md)、[11-leak-prevention.md の 6](11-leak-prevention.md#決まり)

## 7. 時点の表し方

| 選び方 | 変わること |
|---|---|
| **共通の `thursday` の枠を使い、表示名を「特別登録」にする（決定）** | 印の成績（`--timing 木曜`）など、時点を受け取る道具を直さずに使える。地方の「出馬表」と同じ形。保存フォルダは `models/thursday/` |
| 共通の `PredictionTiming` に「特別登録」の値を足す | 時点の並びの先頭に増え、全部の時点を回す中央の予想・道具が特別登録の時点も回ろうとして止まる。直す場所が多い |

関連する資料: [07-prediction-timing.md の「時点の表し方」](07-prediction-timing.md#時点の表し方)

## 8. 登録日相当の決め方

| 選び方 | 変わること |
|---|---|
| **開催日より前の直近の月曜日（土曜 5日前・日曜 6日前・月曜の開催は 7日前）。学習と予測で同じ（決定）** | 学習データの過去のレース（登録の記録が無い）にも付けられる。火曜・水曜に出た登録（約 4 分の 1）でも月曜までの材料を使う。2 週間前に出た登録は、出した時点では翌週の月曜の記録が無く、出し直せば同じになる |
| 予測では特別登録のデータ作成年月日を締めの日にする | 学習では作成日が分からず月曜で切るので、火曜・水曜の登録で学習と予測がずれる（予測のほうが 1〜2 日ぶん多くの調教を見る） |
| 中央と同じ開催日の前日まで | 学習データには最終追い切りと土曜の結果が入るのに、予測の時点には無い。学習と予測でずれる |

関連する資料: [06-flowchart.md の図3](06-flowchart.md#図3-登録日相当の決め方)、[11-leak-prevention.md の 6](11-leak-prevention.md#決まり)

## 9. 持ち時計の順位とブリンカーを外すか

| 選び方 | 変わること |
|---|---|
| **外す（決定）** | 持ち時計の順位 2個は馬場状態が要り、中央の木曜のモデルでも予測では欠損値になっている。ブリンカーは出走馬名表から分かる。外して 168個にすると、学習と予測で同じ列がそろう |
| 中央の木曜と同じく持ち時計の順位を残す | 学習では値が入り、予測では欠損値になる列が 2個残る（中央の木曜と同じ状態）。170個 |

関連する資料: [09-features.md の M](09-features.md#m-馬の力の材料168個)

## 10. 特別競走の印の形

| 選び方 | 変わること |
|---|---|
| **「特別競走か」の 1個（決定）** | 平場と特別競走の違いを 1 列で学ぶ。重賞か・グレードはクラスの並び順で分かる |
| 「重賞か」「オープン特別か」も足す | クラスの並び順と重なる |
| 足さない（全レースを区別なく学ぶ） | 特別競走の馬の走り方の違いを学べない |

関連する資料: [09-features.md の Y](09-features.md#y-特別競走の印1個)

## 11. 当たり具合の確かめ方

| 選び方 | 変わること |
|---|---|
| **中央と同じ7つの半年の区切りを、この予想の `backtest` で回す（決定）** | 特別競走は年 約 915 レースで、テスト期間 1つ（2026年1月〜）だと約 700 レースしか無い。7つの区切りなら 3年半で約 3,200 レース。学習を 7回くり返す時間（1回に十数分 × 2つの目的変数）がかかる |
| テスト期間 1つ（地方の予想と同じ） | 早いが、約 700 レースでは偶然の幅が大きい |
| 研究「既存モデルの改善」の `walk_forward.py` に、この予想を足す | 区切りと比べ方は同じになるが、研究の表の作り方（学習データの表を先に作る）にこの予想を足す作業が要る。`backtest` を持つほうが、予想のパッケージの中で閉じる |

比べる相手は、頭数から見た割合（採用の基準）、同じレースの中央の木曜のモデル（参考。この予想より材料が多い）、相手と比べない版（良いほうを採る）。関連する資料: [16-evaluation.md の 3.・4.](16-evaluation.md#3-比べる基準)

## 12. 外国馬・地方馬と、日曜の版だけのレースの扱い

| 選び方 | 変わること |
|---|---|
| **どちらも予測を出し、表に注記を付ける（決定）** | 外国馬・地方馬（交流区分 1・2）は中央の過去走が無く、近走・指数・対戦レーティングが欠損値で、血統・調教師・調教・セリから出す粗い確率になる。日曜の版だけのレースは、ハンデ戦の負担重量と T が欠損値になる。注記で分かるようにする |
| 外国馬・地方馬は表から外す | 登録馬の全員に出すという決定（1）とずれる。重賞の外国馬は出走すれば上位に来ることが多く、見えないと困る |
| 日曜の版だけのレースは予測しない | 月曜の夕方まで待てば月曜の版が出る。待てないときに何も出ないより、欠損値のまま出すほうがよい |

関連する資料: [06-flowchart.md の図2](06-flowchart.md#図2-登録馬の行の作り方)、[02-glossary.md](02-glossary.md) の「交流区分」

## 13. 印の付け方と出し方

| 選び方 | 変わること |
|---|---|
| **印は付けない。出し方は `predict` の確率の表と、各馬の強み・弱み（数字の事実とモデルの寄与から作る）・近走の文（道具「近走の文」。近5走の文と敗因の候補・評価のことば）と有力馬の候補（1着・3着以内の確率の上位）を並べる全頭評価（道具「全頭評価」）（決定）** | 登録の時点はオッズも騎手も無く、買い目を組む段階ではない。利用者が見たいのは「どの馬が有力で、各馬のどこが良くてどこが不安か」の全体像。全券種の回収率の確かめは、道具「印の成績」が仮に付けた印で出す（[16-evaluation.md の 6.](16-evaluation.md#6-印の成績)） |
| 中央の木曜と同じ、オッズを使わない決め方で印（◎○▲△）を付ける | 印の役割（勝ってほしい馬・相手）は買い目を組むためのもので、登録の時点には無い。利用者には印の意味が分かりにくい |
| 想定の人気順も出す | 確定人気を当てる別のモデルが要る。利用者は人気を重要と見ていないので作らない |
| 今週の予想に組み込むところまでこの設計に入れる | 道具「今週の予想」は出馬表（`ra`・`se`）を前提に動くので、登録馬の表を並べるには画面の作り直しが要る。この予想が使えると分かってから行う |

関連する資料: [16-evaluation.md の 6.](16-evaluation.md#6-印の成績)、[買うレースと買い目を決める の 07 の 5.](../買うレースと買い目を決める/07-expected-value.md#5-印の付け方)
