# 09 特徴量

**この文書で決めること:** 予測の手がかり（特徴量）に、何を使うか。

**結論: 中央の予想の馬の力の材料（M）202個のうち、特別登録の時点に分かる 168個と、対戦レーティング（O）の7個、能力スコア（T）の4個、特別競走の印（Y）の1個の 180個を使う。3着以内のモデルと1着のモデルは同じ 180個で学ぶ。外すのは、枠番・馬番・馬場状態・馬体重を使う 10個、騎手を使う 20個、出走頭数、ブリンカー、持ち時計の順位 2個の 34個。同じレースの相手と比べる材料（70個）は、学習では出走馬の中で、予測では登録馬の中で比べる。調教・通算と直近の成績・対戦レーティングは、登録日相当までの記録で数える。オッズ（J・N）・騎手（C・L）・展開の予想（P）・今の材料（A〜I）は使わない。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 表の見方

- 例の値は、すべて同じ架空の1頭のもの。[01-overview.md](01-overview.md#1頭の例) の「1頭の例」の馬（2025年11月、東京・芝1800m の G3、登録 20 頭、4歳の牡馬、負担重量 57kg、栗東）である。
- 「型」は、どれも数値特徴量である（カテゴリ特徴量は無い）。
- 「どこから」は、中央の予想の部品の名前。名前・作り方・いつから分かるかは中央の予想と同じで、この予想では「材料の締めの日」が登録日相当になるだけである。
- 過去走から作る特徴量は、開催日より前のレースだけから計算する。日付で区切って数えるもの（調教・通算と直近の成績・対戦レーティング）は、登録日相当までの記録だけから計算する。[11-leak-prevention.md](11-leak-prevention.md) を参照。
- 特徴量の数は、M 168・O 7・T 4・Y 1 の 180 個で、学習データと予測用データの両方に同じ列がそろう。

## M. 馬の力の材料（168個）

中央の予想の [09 の M](../近走と適性から3着以内を予想/09-features.md#m-馬の力の材料202個木曜前日のモデル) の 202個から、特別登録の時点に無いものを外した 168個。名前・作り方は中央と同じ（`ability_columns.py`）。

- **どれも数値特徴量。** 中央の木曜のモデルと同じく、文字の列は数にしてから渡す。

| 外す理由 | 数 | 特徴量 |
|---|---|---|
| 枠番・馬番・馬場状態・馬体重が要る（中央の木曜のモデルも外す） | 10 | `frame_no`・`condition_order`・`cond_places_before`・馬番の位置・枠の傾向（勝率・3着内率・出走数）・`body_weight`・`weight_change`・体重_近走の平均との差 |
| 騎手が決まっていない | 20 | 騎手_前走と同じ、騎手・騎手×競馬場・騎手×調教師（各 勝率・3着内率・出走数）、騎手_1年_勝率・騎手_1年_3着内率・騎手_格上げ、騎手_勝率と騎手_1年_勝率のレース内の比べ（各 順位・最良との差・偏差）、減量騎手 |
| 出走頭数が決まっていない（登録頭数は出走頭数より平均 4 頭多く、別のもの） | 1 | `field_size` |
| ブリンカーの使用は出走馬名表から分かる | 1 | ブリンカーあり |
| 馬場状態が要る（中央の木曜のモデルは使っているが、木曜も馬場状態は未発表で、予測では欠損値になっている） | 2 | `best_time_unit_rank`・`best_time_dist_rank` |

- 持ち時計の順位 2個を外すのは、学習では値が入り予測では欠損値になる列を、学習と予測でそろえるためである（[15-decisions.md の 9](15-decisions.md#9-持ち時計の順位とブリンカーを外すか)）。
- **相手と比べる材料（レース内の比べ 60個・先頭率の合計 2個・セリの価格の比べ 2個）は、登録馬の中で比べる。** 下の「相手と比べる材料」を参照。
- **登録馬の行には出走別着度数（`ck`）が無い**が、M は `ck` を使わない（通算の出走数などは DB の過去走から数える `runs_before` など）ので影響しない。
- 作るのは中央と同じ `HorseAbilityFeatures`（出す列を 168個に絞って渡す）。元の記録は `AbilitySourcesLoader` が読む（[05-sequence.md の図3](05-sequence.md#図3-記録を集めるリポジトリとのやりとり)）。

## O. 対戦レーティング（7個）

中央の予想の [09 の O](../近走と適性から3着以内を予想/09-features.md#o-対戦レーティング7個木曜前日のモデル) と同じ7個（レーティング・そのレース内順位・レース内偏差・レースの平均との差・前走での変化・近5走の変化・対戦数）。同じレースを走った馬どうしの着順の勝ち負けから、Elo のレーティングを開催日の順に更新して作る。違いは、対象の行に付けるのが「登録日相当の時点」のレーティングであること（土曜の結果は日曜のレースの行に入らない）と、レース内の順位・偏差・平均との差を登録馬の中で比べることである。例: 1,612・3・0.7・+18・+8・+31・9。

## T. 能力スコア（4個）

中央の予想の [09 の T](../近走と適性から3着以内を予想/09-features.md#t-能力スコア4個木曜のモデル) と同じ4個（能力スコア・偏差・2位との差・順位）。M の能力指数（`指数_条件の重み`）を今回の負担重量で直し（1kg あたり 0.5 点）、同じレースの相手と比べた位置にしたもの。予測用データの列から作るので、外の表もモデルも要らない。中央の木曜のモデルで、確率の誤差の基準を満たし ◎ の成績が上がった材料なので、同じ木曜の枠のこの予想でも使う。負担重量はハンデ戦では月曜の版から分かる（日曜の版では欠損値になり、T も欠損値）。レース内の 3個は登録馬の中で比べる。例: 81.0・1.0・−0.5・2。

作るのは `yosou.ability_score` の `AbilityScoreAttachment`（学習データ・予測用データに足す）。

## Y. 特別競走の印（1個）

この予想だけのまとまり。学習データを平場も含む全レースで作るので、行が特別競走（登録のあるレース）か平場かをモデルに教える。

| 特徴量 | 意味 | 例 | 型 | どこから |
|---|---|---|---|---|
| 特別競走か | 競走名の付いたレースなら 1、平場なら 0 | 1 | 数値 | `race_name`（事実表。空でなければ 1）。登録馬の行では `tk` の競走名本題から、必ず 1 |

- 作るのはこの予想の `SpecialRaceFeatures`（[04-classes.md](04-classes.md#feature--特徴量一覧とこの予想のまとまりはこの予想作るクラスは-shared)）。
- 重賞か・グレードの違いは、M のクラスの並び順（`class_order`）で分かるので、別の列にしない（[15-decisions.md の 10](15-decisions.md#10-特別競走の印の形)）。

## 相手と比べる材料（70個）

同じレースの馬の中で順位・偏差・最良との差に直した材料。学習では出走した馬の中で、予測では登録馬の中で比べるので、出走しない馬（約 2 割）が混ざるぶん、予測の値は学習のときと少しずれる。

| まとまり | 数 | 中身 |
|---|---|---|
| M のレース内の比べ | 60 | 20 の列（指数 4・相対着順・着差・末脚・位置・相手の強さ・調教師と馬主と生産者と母の成績・父×芝ダ・負担重量・調教のタイム 4・調教師_60日_勝率）× 順位・最良との差・偏差 |
| M の先頭率の合計 | 2 | 先頭率の合計、ほかの馬の先頭率の合計 |
| M のセリの価格の比べ | 2 | セリの価格のレース内順位、レースの最高との差 |
| O | 3 | 対戦レーティングのレース内順位・レース内偏差・レースの平均との差 |
| T | 3 | 能力スコア_偏差・2位との差・順位 |

- 名前の一覧は `FIELD_COMPARISON_NAMES`。`backtest --variant 相手と比べない` で、この 70個を外した 110個の版も学習し、7つの区切りで比べる（[16-evaluation.md の 4.](16-evaluation.md#4-7つの区切りでの確かめ)）。
- 登録馬の中で比べる版を既定にするのは、出走しない馬の多くが同じ週の別のレースを選んだ馬か、除外（収得賞金の順で漏れる下位の馬）か回避の馬で、上位の馬の順位は出走馬の中で比べたときと大きく変わらないと見るためである。確かめた結果で決める。

## 登録日相当で切る材料

日付で区切って数える材料は、開催日の前日ではなく、登録日相当（開催日より前の直近の月曜日）までの記録で数える（[11-leak-prevention.md の 6](11-leak-prevention.md#決まり)）。

| 材料 | 何が変わるか | 守る部品 |
|---|---|---|
| 調教のまとめ（12個） | 月曜までの調教だけになる。火曜〜金曜の追い切り（最終追い切り）は入らない | `WorkoutSummaryRepository`（SQL） |
| 通算の成績（27個）・直近の成績（2個） | 日曜のレースの行に、土曜の結果が入らない | `CumulativeRecordRates`・`RecentRecordRates` |
| 対戦レーティング（7個） | 日曜のレースの行に、土曜の結果が入らない | `RatingHistoryBuilder` |
| 過去走・スピード指数・セリの価格・相手の強さ・ペースの基準 | 変わらない（月曜から開催日までに同じ馬が中央で走ることは無い。セリは開催日より前に終わったもの） | 今のまま |

## カテゴリ特徴量の渡し方

この予想にカテゴリ特徴量は無い。180個はすべて数値で、[12-lightgbm.md](12-lightgbm.md)・[13-catboost.md](13-catboost.md) の「学習データの渡し方」のとおり、変換はしない。

## 使うデータの期間

**方針: DB に今入っている期間を、特徴量を外す理由にしない。** JRA-VAN が提供している期間（jvdata-store の [データ種別と提供範囲](../../../../jvdata-store/docs/03-dataspecs.md)）を見て、学習データの期間（[08-training-data.md の「4. 期間の指定」](08-training-data.md#4-期間の指定)。既定は 2012年から、ウォームアップの 2011年を含む）にそろうものは使う。

| データ | 表 | JRA-VAN の提供 | この設計での扱い |
|---|---|---|---|
| 特別登録馬 | `tk`・`tk__登録馬毎情報` | **ハンデ発表後（月曜の版）は 1年間だけ。** セットアップでは今週・来週分のみ。過去分は通常データ（`fetch --dataspec TOKU --option 1`）で取る | 予測の対象（登録馬の行）と、登録馬の確かめ（[16-evaluation.md の 7.](16-evaluation.md#7-登録馬全員に出した予想の確かめ)）に使う。学習データには使わない（学習は確定成績から）。DB には 2025年10月からの 961 レースがある |
| レース成績 | `ra`・`se` | 1986年 | 使う（M の過去走・通算の成績・O。学習データの目的変数と評価用の列） |
| 坂路調教・ウッドチップ調教 | `hc`・`wc` | 2003年・2021年7月27日 | 使う（M の調教。登録日相当まで） |
| 競走馬市場取引価格（セリ） | `hs` | 取得した分 | 使う（M のセリの価格） |
| 競走馬マスタ・産駒マスタ | `um`・`sk` | マスタ | 使う（登録馬の行の血統・馬主・生産者。M の馬主と生産者と母の成績） |
| スピード指数 | 道具「能力指数」がとっておいたファイル（`reports/能力指数/cache/`） | ― | 使う（M の指数と T） |
| 出走別着度数 | `ck` | 2004年 | 読むが使わない（登録馬の行には無い。M は使わない） |
| 確定の単勝オッズ・人気 | `se` | レース成績と同じ | 特徴量には使わない。評価用の列だけ |
| 券種ごとのオッズ・時系列オッズ・速報（馬場・馬体重・取消） | `o1`〜`o6`・`we`・`wh`・`av` | ― | 使わない（この時点には無い） |

## 使わない特徴量

そのレースの結果（着順・タイムなど）は、リークになるので候補にもしない。[11-leak-prevention.md](11-leak-prevention.md) を参照。

| 特徴量 | 使わない理由 |
|---|---|
| M のうち 34個（上の「外す 34個の内訳」） | 特別登録の時点に無い（騎手・枠番・馬番・出走頭数・馬場状態・馬体重・ブリンカー） |
| 今の材料（A〜I の 71個） | 中央の木曜のモデルも使わない（M で置き換えた）。騎手（C）・枠番・馬番・頭数・馬場状態（A・B）・持ち時計（F）など、この時点に無いものを多く含む |
| 市場の評価（J）・券種ごとの支持（N）・騎手調教師血統の市場に対する成績（L） | オッズがまだ無い。L は過去のオッズから作れるが、騎手が決まっていないので騎手の分が作れず、中央の木曜のモデルも M の成績で置き換えている |
| 展開の予想の結果（P）・展開スコア（S） | 予想「展開から着順を予想」は出走馬と騎手が決まらないと出せない |
| 勝ち切る材料（Q） | 中央の予想で当日の1着のモデルだけが使う材料。騎手の勝ち切り率を含む |
| 登録頭数 | 学習データの過去のレースには特別登録が無く、登録頭数が分からない（提供期間が 1年）。1年分の登録で学ぶ案は、行が 14 分の 1 になるので採らない |
| 出走するかどうか（同じ週の複数の登録、除外の順） | この予想は当てない（[15-decisions.md の 1](15-decisions.md#1-何を当てるか)） |
| 確定人気（`popularity`）・確定オッズ | 特徴量にしない。評価用の列として、同じ人気の馬と当たり具合を比べるのに使う |
| JRA-VAN のマイニング予想 | 中央の予想と同じ（JRA-VAN の予想をまねるだけになる） |
