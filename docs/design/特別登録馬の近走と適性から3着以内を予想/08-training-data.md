# 08 学習データ

**この文書で決めること:** 学習データの1行を何にするか。どのレース・どの期間の行を入れるか。期間をどう指定するか。

**結論: 1サンプル = 1レースの1頭。中央競馬の平地の全レース（平場も特別競走も）の出走を使い、「特別競走か」の列（Y）で区別する。学習データは1つで、既定は 2012年1月から（ウォームアップは 2011年。中央の予想の馬の力の材料と同じ約 70 万行）。期間は `train` の引数で変えられる。出走しなかった登録馬は入れない。**

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 1. 学習データの形

架空の1レースの一部を例にすると、学習データは次の形になる。

| レースID | 馬ID | 馬齢 | 負担重量 | 指数_条件の重み | 相対着順_近5走の平均 | 対戦レーティング | 特別競走か | …（特徴量はあと 170個以上） | 目的変数: 3着以内 | 目的変数: 1着 |
|---|---|---|---|---|---|---|---|---|---|---|
| 架空レースA | 馬1 | 4 | 57.0 | 82.0 | 0.28 | 1612 | 1 | … | 1 | 1 |
| 架空レースA | 馬2 | 5 | 57.0 | 78.5 | 0.41 | 1575 | 1 | … | 0 | 0 |
| 架空レースA | 馬3 | 3 | 55.0 | （欠損値） | （欠損値） | 1500 | 1 | … | 1 | 0 |

- 3番の馬は DB に過去走が無い（初出走、または中央で走っていない地方馬・外国馬）ので、過去走から作る特徴量は欠損値、対戦レーティングは初期値になる。欠損値は 0 で埋めず、そのまま持つ。モデルに渡すときの欠損値の扱いは [12-lightgbm.md](12-lightgbm.md)・[13-catboost.md](13-catboost.md) の「学習データの渡し方」を参照。
- 14頭立てのレースなら、目的変数「3着以内」が 1 のサンプルは 3つ、0 のサンプルは 11 になる。
- 馬番は ID 列に持たない（特別登録の時点には無い）。学習データの行を突き合わせる鍵はレースID と馬ID である。

## 2. 列の種類

学習データの列は4種類ある。モデルに渡すのは**特徴量と目的変数だけ**である。中央の予想の [08 の「2. 列の種類」](../近走と適性から3着以内を予想/08-training-data.md#2-列の種類) と同じ分け方で、特徴量の中身と評価用の列が違う。

| 種類 | 列 | モデルに渡すか |
|---|---|---|
| ID 列 | レースID、馬ID、開催日、馬名 | 渡さない |
| 特徴量 | 180個（M 168・O 7・T 4・Y 1。[09-features.md](09-features.md)）。3着以内のモデルと1着のモデルは同じ列 | `fit` の `X` として渡す |
| 目的変数 | 3着以内（1/0）、1着（1/0）。[10-target.md](10-target.md) を参照 | `fit` の `y` として渡す。3着以内のモデルには「3着以内」を、1着のモデルには「1着」を渡す |
| 評価用の列 | 確定着順、確定の単勝オッズ、確定の単勝人気、単勝の払戻、複勝の払戻、確定の出走頭数、登録日相当（材料の締めの日）、馬番（確定成績のもの。印の成績が買い目を組むのに使う） | 渡さない。確定オッズ・人気は当たり具合を同じ人気の馬と比べるためだけに置く（特徴量にしない。[11-leak-prevention.md の 8](11-leak-prevention.md#決まり)） |

学習データは1つで、2つの学習（3着以内・1着）はこの学習データから目的変数の列を持ち替えて作る（[05-sequence.md の図1](05-sequence.md#図1-学習)）。基準（オッズから作ったロジット）は無い。ID 列と年を特徴量にしない理由は中央と同じ（個々の馬を覚えるだけになる・将来の年に役立たない）。

## 3. どのサンプルを入れるか

| 決まり | 内容 | 理由 |
|---|---|---|
| 対象のレース | 中央競馬の平地（芝とダート）の全レース。平場も特別競走も入れ、「特別競走か」（Y）で区別する。障害は入れない | 特別競走だけ（年 約 915 レース・14年で約 17 万行）に絞ると行が 4 分の 1 になる。重賞だけで学んだ専用の予想は「行が少なくて全レースで学ぶ材料を学びきれない」で引退した（[重賞の傾向の予想の 01](../重賞の傾向と近走から3着以内を予想/01-overview.md)）。全レースで学び、Y で特別競走の違いを学ばせる |
| 対象の馬 | 出走した馬。出走取消・発走除外・競走除外はサンプルにしない | 走っていない馬には目的変数が無い |
| 出走しなかった登録馬 | 入れない（事実表に出走の行が無い） | 結果が無い。出走するかどうかは当てない（[10-target.md](10-target.md#出走しなかった登録馬の扱い)） |
| 地方馬・外国馬（交流の出走） | 中央のレースに出走した行は入れる | 中央のレースの結果である。中央の過去走が無ければ、近走の特徴量は欠損値になる |
| 期間 | 「学習データの始まり」から。既定は 2012年1月1日 | 下の「4. 期間の指定」と「ウォームアップ期間」 |
| 新馬戦 | 入れる | 過去走の特徴量は欠損値になるが、調教師・馬主・生産者・血統・セリの価格で予測できる |

**ウォームアップ期間。** 近走・通算の成績・対戦レーティングは、DB にある過去走から数える。学習データの始まりの直後に走った馬は、実際には何戦もしていても、DB に読んだ範囲が短いと「前走なし」に見えてしまう。そこで、学習データの始まりより前の期間（ウォームアップ期間。既定は 2011年1月から 2011年12月まで。DB にある最初の年）の出走も読み、サンプルにはせず、あとのサンプルの過去走・通算の成績・対戦レーティングを計算するためだけに使う。中央の予想の馬の力の材料と同じ決まりである（[中央の 08](../近走と適性から3着以内を予想/08-training-data.md#馬の力の材料を-2012年1月からにした理由)）。

既定の決まりで、学習データは約 70 万行になる（2012年1月〜DB にある最後の日の中央の平地の出走。中央の予想の馬の力の材料の学習データと同じ行）。このうち特別競走の行は約 27%（年に約 915 レース・約 1.2 万行）である。

**材料の締めの日。** 学習データの各行には、登録日相当（開催日より前の直近の月曜日）を付け、調教・通算と直近の成績・対戦レーティングはその日までの記録で数える（[11-leak-prevention.md の 6](11-leak-prevention.md#決まり)）。過去走・スピード指数・セリの価格は開催日より前のものだけから数えるが、月曜から開催日までに同じ馬が中央で走ることは無いので、締めの日を変えても同じ値になる。

## 4. 期間の指定

学習データの期間は、古い順に4つの日で区切る。4つはまとめて共通の `TrainingPeriod` が持ち、順になっていなければエラーにする。`train` と `backtest` の引数で変えられる。

| 区切り | 引数 | 既定 | 意味 |
|---|---|---|---|
| ウォームアップの始まり | `--warmup-from` | 2011-01-01 | ここからの出走を読むが、サンプルにしない。DB にある最初の年 |
| 学習データの始まり | `--train-from` | 2012-01-01 | ここからの出走がサンプルになる |
| 検証データの始まり | `--valid-from` | 2025-07-01 | この前日までが学習データ |
| テストデータの始まり | `--test-from` | 2026-01-01 | この前日までが検証データ。ここからはテストデータ（最後に1回だけ確かめる用。[16-evaluation.md](16-evaluation.md)） |

```powershell
uv run python -m yosou.special_registration_top3 train --train-from 2017-01-01
```

（2017年1月から学習するコマンド。ウォームアップは既定の 2011年1月から）

- 使った期間は、学習の結果の表「学習データの期間」に、ウォームアップの行も含めて出る。
- 学習データの始まりを 2012年にするのは、中央の予想の馬の力の材料で、2017年からより長い期間で学ぶほうが良かったためである（[中央の 08](../近走と適性から3着以内を予想/08-training-data.md#馬の力の材料を-2012年1月からにした理由)）。この予想の材料は同じ M の一部なので、同じ既定にする。
- 検証・テストの区切りは中央の予想と同じ日にそろえてある。
- 7つの区切りでの確かめ（`backtest`）は、区切りごとに検証・テストの始まりを変え、学習の始まりは 2012年1月のままにする（[16-evaluation.md の 4.](16-evaluation.md#4-7つの区切りでの確かめ)）。
- 特別登録（`tk`）は学習データの材料ではない（学習データは事実表の確定成績から作る）ので、提供期間が 1 年でも学習データの期間は 2012年からにできる。
