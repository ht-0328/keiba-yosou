# 10 目的変数

**この文書で決めること:** モデルに何を当てさせるか（目的変数）。出走しなかった登録馬をどう扱うか。

**結論: 中央の予想と同じ2つ。「3着以内なら 1」を当てるモデルと、「1着なら 1」を当てるモデルを、同じ学習データから別々に学習する。学習は出走した馬だけで行い、登録馬には「出走すれば 3着以内に入る確率」「出走すれば 1着になる確率」として出す。出走するかどうかは当てない。** 3着以内の確率は複勝の目安と全頭評価の評価順に、1着の確率は有力馬の候補に使う（オッズが無いので期待値・◎ の期待値の帯は出ない。印は付けない）。

用語の意味は [02-glossary.md](02-glossary.md) を参照。

## 作り方

中央の予想の [10 の「作り方」](../近走と適性から3着以内を予想/10-target.md#作り方) と同じ。

| 目的変数 | 1 になるとき | 0 になるとき | 当てるモデルの確率の使い先 |
|---|---|---|---|
| **3着以内** | 確定着順が 1〜3 | 4着以下、競走中止、失格 | ○▲△、軸の目安。木曜以降の中央の予想と見比べる |
| **1着** | 確定着順が 1 | それ以外 | 有力馬の候補（1着の確率の上位の馬） |

- 着順は**確定着順**を使う。同着は同じ着順。競走中止と失格は 0。出走取消・発走除外・競走除外の馬はサンプルにしない（[08-training-data.md](08-training-data.md#3-どのサンプルを入れるか)）。
- 目的変数を作るクラスは共通の `Top3TargetBuilder`、1着のモデル用の持ち替えは `WinTargetData`（基準が無いので、目的変数の列だけを持ち替える。[04-classes.md](04-classes.md#dataset--学習データ予測用データを作る組み立てはこの予想ほかは-shared)）。

## 出走しなかった登録馬の扱い

| 選び方 | 変わること |
|---|---|
| **出走した馬だけで学び、登録馬の全員に「出走すれば」の確率を出す（決定）** | 学習データは確定成績から 14年分作れる。出走しなかった登録馬は、予測では確率が付くが、木曜に出走馬名表が出たら中央の予想に引き継ぐので、そこで消える |
| 出走しなかった登録馬を 0 にする | 登録の記録が 1年分しか無く、学習データが 14年分 → 1年分になる。「出るか」と「走るか」が混ざり、確率が「3着以内に入る確率」として読めなくなる |
| 「出走するか」を別の小さなモデルで出す | 1年分の登録（約 1.66 万件）で学べる。あとから足せるので、今回の設計には入れない（[15-decisions.md の 1](15-decisions.md#1-何を当てるか)） |

- 出走しなかった登録馬は、事実表に出走の行が無い（登録だけで `se` が無い）か、取消・除外の行がある（出走したかの問いで落ちる）ので、学習データには入らない（[06-flowchart.md の図1](06-flowchart.md#図1-学習データに入れる行の選び方)）。
- 登録馬の全員に出した確率が、出走した馬でどれだけ当たっていたかは、[16-evaluation.md の 7.](16-evaluation.md#7-登録馬全員に出した予想の確かめ) で確かめる。出走しなかった馬の割合は、この予想が当てないことなので見ない。

## 理由

中央の予想の [10 の「理由」](../近走と適性から3着以内を予想/10-target.md#理由) と同じ。3着以内は 1 のサンプルが多く学びやすく、複勝の判断の目安にそのまま使える。1着は、有力馬の候補（勝ちそうな馬）を決めるのに「1着になる確率そのもの」が要るためである。オッズの無いこの時点では単勝の期待値は出せない。

## 1 と 0 の数の偏り

中央と同じく、**偏りを直す設定は使わず、そのまま学習する。** 予測確率を確率として使う（木曜以降の予想や頭数から見た割合と比べる）ので、確率の大きさがずれる設定は使わない。LightGBM と CatBoost の、偏りを直す設定の名前は、[12-lightgbm.md](12-lightgbm.md)・[13-catboost.md](13-catboost.md) を参照。
