# 03 事前に固定した決まり（探索と確認の手順）

**この文書の目的:** 買い方を探す前に、期間・採否の基準・楽観のもとを書き留めておく。結果を見てから基準を動かさないため。

## 期間

| 区分 | 期間 | 使い方 |
|---|---|---|
| 探索 | 2025-07-01〜2025-12-31 | 参加パターン × しきい値 × 買い方 の格子を全部回し、採否の基準で絞る |
| 確認 | 2026-01-01〜2026-09-30 | 探索で残った上位5つまでを、**1回だけ**評価する。この結果だけを結論にする |

探索期間は、4つの予想モデルの検証期間（早期終了の判断に使った期間）と同じである。そのぶん探索の回収率はやや楽観側になる。
確認期間はモデルの学習・検証のどちらにも使っていない。

## 採否の基準（探索期間で満たすもの）

1. 回収率が 100% 以上
2. 買ったレース数が 100 以上、または点数が 300 以上
3. 最大の1レースの払戻を除いても、回収率が 90% 以上

満たす戦略を回収率の順に並べ、月別の回収率を添える。1〜2か月だけで稼いでいる戦略は、利用者と相談して外す。

## しきい値の格子

| 軸 | 値 |
|---|---|
| 荒れ度（広めの買い方の券種の「中荒れ以上の確率」） | 探索期間での上位 20% / 35% / 50% に当たる確率。決まった確率を確認期間にもそのまま使う |
| 本命の3着以内確率（以上） | 0.45 / 0.50 / 0.55 |
| 本命の危険確率（未満） | 0.40 / 0.50 |
| 週の上位 k | 3 / 5 / 10 |

## 楽観のもと（結果に必ず書き添える）

- 予測は当日時点のモデルで、単勝オッズの特徴量は**確定オッズ**（学習と同じ）。実際に買う時点のオッズより情報が多い。
- 荒れ度・オッズの帯・低配当目のカットも確定オッズで決めている。
- 100円均等買いで、賭けても オッズが動かない（自分の投票の影響を無視する）。

## 数値の置き場

探索・確認の結果（JV-Data 由来の数値）は `reports/馬券の買い方の検証/search/` と `.../confirm/` に置く。`docs/` には場所だけ書く。
