# 06 3回目の検証の結果（2026-10-02）

**結論: 探索（2023〜2024年の4区切り）で、採否の基準を満たす戦略は1つも無かった。決まりどおり、確認（2025年）と最後の1回（2026年）は行わず、提案は出さない。**
利用者の買い方「期待値の高い穴馬の複勝を 1日3レースまで」は、新しい予想モデルでも、まだ見ていない期間で回収率 100% を超えるとは言えない。

決まり（期間・採否・戦略の軸）は、探索の前に [05-round3-protocol.md](05-round3-protocol.md) に固定し、結果を見たあとで変えていない。
数値（回収率・点数・払戻）は Git 対象外の `reports/馬券の買い方の検証/round3/` にある。この文書には場所と読み方だけを書く。**すべて確定オッズでの検証である。**

## 分かったこと

1. **線を 1.25 に固定すると、買える点がとても少ない。** 穴馬モデルの確率と、幅で直した見込みの払戻の倍率で出す複勝の期待値は、1.25 に届く馬が少なく、
   4区切り合計でも点数の基準（600点）に遠く届かなかった。合計の回収率が 100% を超えた戦略もあったが、区切りによって大きく割り、
   100% 以上の区切りが 3つに届かず、90% の幅も 100% を大きくまたいだ。点が少ないことによるたまたまの上下と読む。
2. **線を直前の1年で選ぶと、低い線（1.05〜1.10 あたり）が選ばれ、テスト期間では 100% に届かなかった。** 直前の1年で 100% を超えて 300点以上残る線が、
   最後の区切りではどの選び方でも無く、その区切りは買っていない。中穴だけの選び方は、どの区切りでも線が決まらなかった。
   穴馬の設計書 15 の 17（「買い」の線が引けなかった）と同じ向きの結果である。
3. **どの戦略も、比べる目安（全穴馬の複勝・全頭の複勝・1番人気の複勝）よりは回収率が高い。** 期待値で選ぶことには効き目があるが、控除率を越えるほどではない。
4. **1日3レースまでに絞っても良くならなかった。** 線を選ぶ戦略では全レースより回収率が下がり、1.25 固定ではほとんど同じ（もともと1日に3レースを超えて買う日が少ない）だった。研究「既存モデルの改善」の 7（勝負するレースの選び方）と同じ向きである。
5. 荒れ具合で切った表は、確認に回す戦略だけに出す作りなので、今回は出していない（候補が無いため）。

## 決まりどおりにしたこと

- 探索で候補が無かったので、確認期間（2025年）と最後の1回（2026年）の回収率は計算していない。2025年と2026年は、この買い方の系統については手つかずのまま残る。
- 基準を緩めて候補を作ることはしていない（例: 点数の基準を下げる、線の候補を変える）。

## 確認を挟む場所

計画では、段階 0（決まりの固定）のあとに利用者の確認を挟んでから探索に進む予定だったが、**利用者の指示により挟まずに進めた（2026-10-02）**。
決まりは探索の前に独立したコミットで固定してある（`docs(research): 馬券の買い方の検証の3回目で事前に固定した決まりを書く`）。

## 楽観のもと

- 確定オッズでの検証である。研究「回収率100超」では、発走の10分前のオッズで買うと回収率が大きく下がった。今回 100% に届かなかったので、締め切り前のオッズでは、さらに届きにくいと見込まれる。
- 線を選ぶのに使った「検証」の予測は、その区切りのモデルが木を足すのを止める判断に使った期間のもので、わずかに楽観側。

## 次にやるなら

- 穴馬モデルの期待値で選ぶ系統は、3回の検証でどれも 100% に届かなかった。続けるなら、確率の出どころを替える（研究「回収率100超」の全券種のプールから作る確率は、確定オッズでは 100% を超えている）ほうが見込みがある。
- 2025年・2026年は、この系統では使っていない。別の系統を試すときの確認期間に回せる。
