# 02 買い方の一覧（ticket_plans.py）

**この文書の目的:** 精算する買い方と、それがルール集（`docs/rules/馬券の買い方/`）のどのルール・型に当たるかをまとめる。列の埋め方の記法と、候補の選び方も書く。

## 記法

- 列は `[選び方 × 頭数]` を左から並べる。`+前列` は前の列の馬を含めて数えた頭数、`=1列目` は1列目と同じ馬。
- 選び方: **近走1位** = 近走と適性モデルの確率が最大の馬（本命）、**近走2・3位** = 本命を飛ばした上位、**穴馬上位** = 穴馬モデルの確率の高い順（穴馬だけ）、**中穴上位** = そのうち中穴、**1〜3番人気** = 人気順位、**3〜9番人気を穴馬確率順** = 人気の範囲の中を穴馬モデルの順。
- 危険な人気馬の除外 = 危険確率（人気馬モデルの「4着以下になる確率」）が 0.6 以上の馬を候補から外す（ワイド・3連複・3連単の型に付ける。WID-03・SRF-02・SRT-04）。

## ルール集の型のうち、まだ入れていないもの

ルール集の型（SRF-P01〜P19・SRT-P01〜P11 など）のうち、上に無いものは今回の探索では使っていない。足すときは `ticket_plans.py` に `TicketPlan` を1つ足し、`tests/test_betting_ticket_builder.py` の点数の表に期待値を書く。
