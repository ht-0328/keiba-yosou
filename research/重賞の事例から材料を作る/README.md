# 重賞の事例から材料を作る

重賞で今の予想が外れた事例を集め、外れた理由から新しい予想の材料（特徴量）を作り、学び直して確かめる研究。
重賞に特化した予想（設計書 `docs/design/重賞に特化して3着以内と1着を予想/`）で、回収率 100% 超えの予想を探す作業の一部。
買い目の手順は研究「重賞の買い方」の docs/06 で決めたものを変えずに使い、変えるのは予想の材料だけにする。

## 文書

| 文書 | 中身 |

| [docs/02-ほかの材料とオッズの動き.md](docs/02-ほかの材料とオッズの動き.md) | 10個の候補のふるい・データマイニング予想・オッズの動きと、それで直した予想の回収率 |

## 入口

どれも DB を開かない。先に事実表を `reports/重賞の事例から材料を作る/facts.parquet` に書き出しておく（元DB の写しから作る）。

| 入口 | 何をするか |
|---|---|
| `cases.py` | 2015〜2022年の重賞で、見落とし（予想6位以下で3着以内）と買いかぶり（予想1〜2位で4着以下）の一覧を書く |
| `residuals.py` | 前走の格と着順・間隔・乗り替わり・斤量・年齢・対戦成績などの候補ごとに、予想とのずれと複勝の回収率を数える |
| `day_bias.py` | その日の馬場の傾向（前残り・内外）と脚質・枠の組み合わせごとのずれを数える |
| `day_signals.py` | 騎手のその日の調子・その日の時計の速さ × 持ち時計・父のその日の成績ごとのずれを数える |

材料を足した学び直しは、研究「既存モデルの改善」の `graded_race_check.py`（`daybias-tables` で材料 D の表を作り、`run --variants daybias-top3 daybias-win` で学ぶ）。

段2・段3の入口:

| 入口 | 何をするか |
|---|---|
| `candidates.py` | 10個の材料の候補を重賞（2015〜2026年）の出走ごとに作る |
| `screen.py` | 候補で今の予想の確率を直し、1年を抜いて学んだときに当たり具合が良くなるかをまとめて確かめる |
| `odds_move.py` | オッズの動きで今の当日の予想を直した予測を書く（元DB（の写し）を開く）。買い目は `research/重賞の買い方/graded_model.py` と道具「印の成績」で数える。`--save-models` で、2025・2026年の全部で学んだ重みを本番のモデルの置き場所の `odds_move.json` に書く（直し方の部品は本番と同じ `src/yosou/shared/odds_move/`） |
