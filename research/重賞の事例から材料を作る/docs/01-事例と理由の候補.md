# 01 事例と理由の候補

重賞で今の予想が外れた事例を集めて理由の候補を挙げ、候補ごとに「予想の確率より実際に来たか（ずれ）」を数えた。
ずれが 1 から離れる候補だけを、予想の材料（特徴量）にして学び直す。

## 1. 事例の集め方

- 対象: 2015〜2022年の中央の平地の重賞（1,022 レース・15,222 頭）
- 予想の確率: 2015〜2019年は今の前日の予想、2020〜2022年は今の当日の予想（どちらもテストの年の値。研究「既存モデルの改善」の `predictions/graded_race_day/`）
- 見落とし: 予想の順位が6位以下なのに3着以内に来た馬（979 頭）
- 買いかぶり: 予想の順位が1〜2位なのに4着以下だった馬（932 頭）
- 一覧は `cases.py` が `reports/重賞の事例から材料を作る/事例.md` に書く（Git 対象外）

## 2. 事例を見て挙げた理由の候補

見落としの事例を1件ずつ見ると、次の形が目立った。

- G1 で大敗したあと、格の下がる重賞に戻ってきて好走する
- 条件戦を勝ち上がったばかりで重賞に挑み、好走する
- 長く休んだあとの重賞で好走する
- 乗り替わり・斤量の減り・年齢（古馬と走る3歳）
- 今回の出走馬との過去の対戦で先着している

そのうえで、今の予想に入っていない情報として、その日の先のレースから分かることも候補にした。

- その日の馬場の傾向（前が残るか・内が来るか）と馬の脚質・枠の合い具合
- 騎手のその日の調子
- その日の時計の速さと持ち時計
- 同じ父の産駒のその日の成績

## 3. ずれ

ずれ = 実際の3着以内率 ÷ 予想の確率の平均。1 より大きいと予想が低く見ていて、小さいと高く見ている。

| 候補 | 区分ごとのずれの幅 | 目立った区分 |
|---|---|---|
| 格の上下と前走の着順 | 0.88〜1.10 | 格上げ・前走2〜9着 1.09〜1.10 |
| 前走の人気と着順 | 0.98〜1.04 | ― |
| 前走からの間隔 | 0.98〜1.04 | ― |
| 騎手の乗り替わり | 1.00〜1.03 | ― |
| 斤量の増減 | 0.96〜1.05 | 2kg 以上減 1.05（複勝の回収率 90%） |
| 年齢 | 0.95〜1.09 | 古馬と走る3歳 1.09 |
| 今回の出走馬との対戦の数・先着の割合 | 0.99〜1.04 | ― |
| 前走の上がり3Fの順位 | 1.01〜1.05 | ― |
| その日の前残り × 脚質 | 0.92〜1.07 | 前が残る日に先行馬が来るわけではなかった |
| その日の内外 × 枠 | 0.95〜1.09 | 内が来る日の内 1.09・外が来る日の外 1.07 |
| 騎手のその日の調子 | 0.99〜1.03 | ― |
| その日の時計の速さ × 持ち時計 | 0.92〜1.06 | ― |
| 父のその日の成績 | 1.00〜1.04 | ― |

- どの候補も、ずれは 0.9〜1.1 に収まった。事例で目立った形は、今の予想（オッズの材料を含む）が既に織り込んでいる。
- 複勝の回収率は、どの区分も 90% 以下（全体はおよそ 72%）。
- 1 から最も離れたのは、その日の内外と枠の合い具合（1.07〜1.09）。これを含む「その日の馬場の傾向」の5つを材料 D にして、学び直して確かめる（4）。

## 4. 材料 D を足して学び直した結果

今の当日の予想（3着以内と1着）に D の5つを足し、重賞の予想と同じ1年ずつの7つの区切り（テスト 2020〜2026年）で学び直した。

| 予想 | 重賞の行のログ損失（全体） | 今の予想より小さかった年 |
|---|---|---|
| 3着以内 | 0.40913（今の予想 0.40910） | 3/7 |
| 1着 | 0.20170（今の予想 0.20158） | 3/7 |

- 確率の当たり具合は良くならなかった。D は採らない（買い目の回収率は数えていない）。
- ずれで 1.07〜1.09 あった内外と枠の差も、ほかの材料（枠番・馬番・競馬場・コース）と合わせて学ぶと残らなかった。
