# 01 仮定と進め方

## 1. 何が問題だったか

今週の予想の「消」（危険な人気馬）は、予想「人気馬が4着以下になるかを予想」の危険度で決めている。

> 危険度 = 予想の4着以下の確率 − オッズから見た4着以下の確率（1 − オッズから計算した3着以内率）

利用者から「人気馬をほとんど順番に並べただけにしか見えない。ちゃんと危険な人気馬を見極めてほしい」と言われた（2026-11-01）。
道具「印の成績」で確かめると、消を付けた人気馬は、同じ人気の馬全体とほとんど同じくらい3着以内に来ていた。
危険度のいちばん高い馬（人気帯ごとの上位 5%）に絞っても、同じだった。消は付いているが、危ない馬を選べていない。

## 2. 負けた人気馬の事例から分かったこと

2016年から、1〜5番人気で4着以下になった馬を、レース後に分かる情報（回顧の不利の記録・着差）で負け方に分けた。

| 負け方 | 決め方 |
|---|---|
| 競走中止 | 異常区分が競走中止 |
| 出遅れ | 回顧の馬の回顧ノートで、出遅れの程度が中以上 |
| 展開が向かなかった | 同じく、展開の程度が中以上 |
| バイアスと逆 | 同じく、バイアスの程度が中以上 |
| 大敗 | 不利の記録がなく、勝ち馬から 1.0秒以上離された |
| 完敗 | 不利の記録がなく、0.4〜0.9秒離された |
| 惜敗 | 0.3秒以内 |

負けた1番人気のうち、半分を超えるのは「不利の記録がないのに 0.4秒以上離された」力負け（完敗・大敗）だった。
出遅れや展開のような、レース前には読みにくい負け方は少ない。つまり、危ない人気馬の多くは、レース前の材料で見分けられる余地がある。

一方で、レース前に分かる1つの条件（昇級・休み明け・距離の変更・前走の激走・馬体重の増減・過去によく負けている など）で人気馬を分けても、
同じ人気の馬全体との差は数ポイントだった。多くはオッズがすでに織り込んでいる（過去によく負けている馬は、オッズがもう割り引いている）。
1つの条件で切るのではなく、モデルで材料を組み合わせて見分ける必要がある。

## 3. 仮定: 比べる相手がずれているので、危ない馬を選べない

オッズから計算した3着以内率（Harville の式）は、人気の度合いによって実際の結果とずれる。1番人気の3着以内率を高めに出す。
これを比べる相手にすると、危険度に「オッズの計算のずれ」が混ざり、オッズの低い1番人気ほど危険に見える。
そうした1番人気は実際にはよく来るので、消が当たらない。モデルの出発点（学習の基準）も同じ計算なので、モデルは学ぶ力の一部を、このずれを直すことに使っている。

そこで、次の2段で学ぶ。

1. **オッズだけのモデル**: オッズの列（人気順位・単勝オッズ・オッズから見た勝率と3着以内率・頭数）だけで、4着以下になる確率を学ぶ。
   オッズから計算した確率を出発点に、実際の結果に合わせ直したもの。人気帯ごとに学ぶ。
2. **人気馬の予想**: 今の本番と同じ列で、オッズだけのモデルの確率を出発点にして学ぶ。危険度は「予想 − オッズだけのモデルの確率」にする。

こうすると、危険度は「オッズが同じ馬より、どれだけ負けやすいか」だけを表す。

手早く確かめたところ（研究の中の試し。数値は `reports/危険な人気馬を見極める/`）、比べる相手をオッズだけのモデルに替えるだけで危険度の上位の見分けが良くなり、
出発点も替えるとさらに良くなった。過去の癖（出遅れの回数・人気で負けた回数など）の列を足しても、ほとんど変わらなかったので足さない。

## 4. 進め方

1. **7つの区切りで学ぶ**（`danger.py run`）: 研究「既存モデルの改善」と同じ7つの区切り・同じ学習データの表・今の本番と同じ列で、2段の学び方を回す。
2. **危険度の上位の成績**（`danger.py top`）: 人気帯ごとに、危険度の上位 5%・10%・20% の人気馬の3着以内率と単勝・複勝の回収率を、同じ人気の馬全体と並べる。今の本番の危険度とも並べる。
3. **印と全券種の買い目**（道具「印の成績」）: 今週の予想と同じ決め方で消と印を付け、全券種の買い目の的中率と回収率を、今の本番・消を使わない場合と比べる。
4. **採用なら本番に入れる**: 予想「人気馬が4着以下になるかを予想」の学習と予測に2段の学び方を入れ、本番のモデルを学習し直す。

## 5. 採否の基準（結果を見る前に決めた）

利用者の希望は「人気馬を消して、馬券を当てて回収率を上げる」こと（2026-11-01）。そこで、次の両方を満たせば採用する。

- 道具「印の成績」の、印のルールの買い目の合計（元の買い目だけ・◎軸・軸馬の3つ）の回収率が、今の本番より高い。
- 印のルールの買い目の券種ごとの的中率が、今の本番より下がらない。

期間は、今の本番と同じ7つの区切りのテスト期間（2023年1月〜2026年9月）。全頭の予想と1着の予想は、道具「印の成績」の既定（今の本番と同じ前日の予測）のまま、
人気馬の予想だけを替えて比べる。

## 6. 後半で足した問い: 全頭の予想と、6番人気以下の複勝

消だけでは全レースの合計の回収率が上がらなかったので、利用者の「もともと全レースを買って回収率 100% 超えを目指すのが目的」を受けて、次の2つを足した。

1. **全頭の予想（3着以内と1着）も、オッズだけのモデルを出発点にして学ぶ**（`danger.py form`）。採否の基準は 5 と同じ（道具「印の成績」の合計の回収率が今の本番より高く、的中率が下がらない）。
2. **6番人気以下は「来そうな馬」を見つける**（利用者の考え方。`danger.py longshots`・`place`・`unseen`）。6番人気以下の馬のうち「予想の3着以内の確率 − 市場の見立て」が線以上の馬の複勝を買う。
   採否の基準（利用者の「6番人気以下で複勝回収率を 100% 超えるモデルを作って」を受けて決めた）:
   - 7つの区切りで、区切りごとに検証期間だけで線を選び、その線のテスト期間の複勝の回収率が 100% を超える。年ごとにも、多くの年で 100% を超える。
   - まだ見ていない期間（2021年前半〜2022年前半。全頭の予想をその区切りで学び直す）でも、同じ選び方で 100% を超える。
   - 両方を満たせば、今週の予想の買い目に入れ、当日の予想で買う。
