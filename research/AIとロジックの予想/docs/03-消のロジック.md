# 消のロジック（よく勝つ消を取り消す）

## 1. 何を確かめたか

利用者の依頼は「消が勝つのを減らすロジックも探して」だった。
消（危険な人気馬。1レース1頭まで）のうち、勝ちやすい消を見分けて取り消すロジックを探した。

消を使った買い目の採否は、消を使った買い目の回収率と的中率で決める（利用者の決定）。そこで、次の2つを分けて確かめた。

1. **消そのもの:** 残る消の勝率が下がるか。
2. **買い目:** 取り消した馬に印を付け直すと、買い目の回収率と的中率が上がるか。

**合格の基準（結果を見る前に決めた）:** 探す3つの期間（参考1・参考2・作る）のすべてで良くなった決まりだけを、確かめる期間で一度だけ数える。
買い目を変えるのは、確かめる期間でも、AI＋ロジック予想の印の買い目の回収率と的中率の両方が上がったときだけにする。

期間は [01](01-負けたレースとロジック.md) と同じ4つ。消の予想があるのは 2022年9月3日からなので、[02](02-ロジックの追加.md) の追加の確かめの期間（2021年1月〜2022年9月）は使えない。

## 2. 探し方

1. 印の表（1行 = 1頭）の消の馬について、予想と市場の見立ての比、予想の順位、単勝・複勝の期待値、レースと馬の材料の値ごとに、勝率と単勝の回収率を出す。探す3つの期間だけを見る。
2. 3つの期間とも勝率が高い値から「その消は取り消す」決まりの候補を作り、残る消と取り消す消の成績を比べる。
3. 選んだ決まりを、確かめる期間で数える（`analysis/danger_cancel.py`）。
4. 取り消したあとの消で道具「印の成績」を動かし、印を付け直した全券種の買い目を、今の消のときと比べる（`analysis/danger_tickets.py`）。

## 3. 消そのものの結果

候補（探す3つの期間。残る消の勝率と単勝の回収率）。

| 候補（残す消） | 参考1 | 参考2 | 作る |
|---|---|---|---|
| 今の消（比べる元） | 20.0%・71.8% | 23.3%・75.0% | 22.7%・80.4% |
| 3着以内の予想が市場の見立てより低い | 20.9%・68.6% | 23.4%・72.9% | 23.0%・77.3% |
| **1着の予想が市場の見立てより低い** | **17.5%・61.2%** | **19.5%・61.5%** | **17.1%・61.0%** |
| 3着以内と1着の予想が、両方とも市場の見立てより低い | 18.4%・60.9% | 19.7%・61.4% | 17.0%・57.8% |
| 単勝の期待値が 1.0 未満 | 20.1%・71.2% | 23.1%・73.9% | 22.3%・78.1% |
| 複勝の期待値が 1.0 未満 | 19.3%・70.2% | 22.4%・73.5% | 21.8%・77.7% |

3着以内の予想と市場の比では勝率が下がらなかった。1着の予想と市場の比だけが、3つの期間とも大きく効いた。
両方を見る形は、1着の予想だけを見る形とほとんど変わらないので、決まりの少ない「1着の予想が市場の見立て以上なら取り消す」を選んだ。

選んだ決まりの、4つの期間の成績（`analysis/danger_cancel.py`）。

| 期間 | 今の消 | 残る消 | 取り消す消 |
|---|---|---|---|
| 参考1 | 3,465頭・勝率 20.0%・単勝の回収率 71.8% | 1,912頭・17.5%・61.2% | 1,553頭・23.1%・84.9% |
| 参考2 | 2,559頭・23.3%・75.0% | 1,383頭・19.5%・61.5% | 1,176頭・27.6%・90.8% |
| 作る | 1,125頭・22.7%・80.4% | 549頭・17.1%・61.0% | 576頭・28.0%・98.9% |
| 確かめる | 787頭・16.4%・64.4% | **409頭・11.0%・41.3%** | 378頭・22.2%・89.5% |

確かめる期間でも、残る消の勝率は 16.4% → 11.0%、3着以内率は 45.0% → 40.3% に下がった。消の数は約半分になる。

## 4. 買い目の結果

取り消した馬に印（◎〜△）を付け直したときの、全レースの印の買い目（表だけ。本番と同じ配り方。馬単の裏は入れていないので、02 の数字とは少し違う）。

| 期間 | AI＋ロジック（今の消） | AI＋ロジック（消を取り消して付け直す） |
|---|---|---|
| 参考1 | 1,070レース・回収率 97.1%・的中率 19.5%・1日 −778円 | 1,174レース・98.4%・19.6%・−462円 |
| 参考2 | 489レース・120.6%・24.1%・5,057円 | 571レース・122.8%・24.5%・6,512円 |
| 作る | 342レース・138.4%・29.5%・12,100円 | 412レース・142.3%・30.6%・15,952円 |
| 確かめる | 404レース・123.5%・24.3%・8,521円 | **444レース・119.9%・23.2%・7,929円** |

探す3つの期間では3つとも上がったが、**確かめる期間では回収率・的中率・1日の儲けが3つとも下がった。**
消を取り消したレースだけを見ると、確かめる期間は 39レース・133.2% → 79レース・108.4% だった（取り消した馬が印をもらい、買うレースが増える）。

買い方ごと（1点 100円。道具「印の成績」の 37 の買い方）。

| 期間 | 回収率が上がった買い方 | 的中率が上がった買い方 |
|---|---|---|
| 参考1 | 27 | 32 |
| 参考2 | 26 | 27 |
| 作る | 20 | 30 |
| 確かめる | 20 | 27 |

- 印の買い目（単勝・馬連・馬単・3連単）は、的中率が4つの期間とも上がった。回収率は期間によって上下した。
- 実際に買う組の期待値の買い目は下がった。枠連・ワイド・3連単は、4つの期間とも回収率が下がった（3連単は確かめる期間で 104.3% → 99.5%）。

## 5. 判断

- **採る:** 消のロジック「1着の予想が市場の見立て以上の馬は、消を取り消す」を、AI＋ロジック予想に足す。**印と買い目は変えない。** AI＋ロジック予想の1行の終わりに「消の ○番は取り消し」と書き足す。
  残る消の勝率が4つの期間とも下がり、買い目は今のままなので回収率は変わらない。
- **採らない:** 取り消した馬に印を付け直して買い目を変える形。確かめる期間で、印の買い目の回収率・的中率・1日の儲けが下がり、組の期待値の買い目も下がった。

## 6. なぜ効くと見るか

消は「人気馬が4着以下になるか」の予想で決める。1着の予想は別のモデルである。
3着以内には来にくいと見た馬でも、1着の予想が市場の見立て以上なら、勝つ力はあると2つめのモデルが言っていることになる。この食い違いのある消が、よく勝っていた。

## 7. 気をつけること

- 残る消でも勝つことはある（確かめる期間で 11.0%）。
- 確かめる期間の残る消は 409頭。本番と同じ予想で数えられるのは 2025年9月からの約1年だけである。
- 消の数が約半分になるので、消の付かないレースが増える。
- 買い目は変えていないので、AI だけの予想の消で外している買い目（3連複の形など）は今のまま。

## 8. 再現

```
uv run python research/AIとロジックの予想/analysis/danger_cancel.py --flags
uv run python tools/印の成績/mark_stats.py --form graded_race_day/odds_move-top3 --win graded_race_day/odds_move-win --timing 当日 --danger-flags reports/AIとロジックの予想/消/flags_now.pkl --out-dir reports/AIとロジックの予想/消/now
uv run python tools/印の成績/mark_stats.py --form graded_race_day/odds_move-top3 --win graded_race_day/odds_move-win --timing 当日 --danger-flags reports/AIとロジックの予想/消/flags_cancel.pkl --out-dir reports/AIとロジックの予想/消/cancel
uv run python research/AIとロジックの予想/analysis/danger_tickets.py
```

1行目は消の成績を出し、道具「印の成績」に渡す消の表を書く。2・3行目は今の消と取り消したあとの消で印を付けて全券種の買い目を出す（1回 10〜15分。同時には動かさない）。4行目は2つを比べる。
