## 1. なぜこの形か

- 研究「WIN5で人気薄の勝ち馬を狙う」では、馬を1頭ずつ材料で見る作りで、大穴の中の並べ方はオッズの順を超えられなかった（上位3頭 74% → 76%）。この研究でも、展開の見込みだけで並べると人気の順より悪かった（60% 対 75%）。人気（オッズ）を出発点にして、上げ下げだけを学ぶ形は変えない。
- この研究で新しく分かったのは、**大穴の来やすさが展開の型で変わる**こと（ハイ予想の先行・差しは +0.6、スロー予想の追込は −1.2、勝ち方もハイでは差し 43%・スローではいつもより前 31%）と、**大穴2頭以上は展開の型で寄る**こと（ハイの後ろ・後ろ 33%、スローの前・前 34%）。1頭ずつの強さを1つの確率にまとめると、この「展開ごとの違い」と「展開を通じて一緒に来る」形が消える。展開の型ごとに確率を持ち、展開の確率で混ぜれば、両方を残せる。
- ハンデ戦は大穴が2倍来るが、軽い斤量は市場が値段に入れている。効くのは昇級 × 斤量の差とトップハンデで、これは材料として足す。

## 2. おすすめの案: 展開の型で混ぜる大穴の着順の予想

### 2.1 目的変数と確率の作り方

| 項目 | 案 | 理由 |
|---|---|---|
| 目的変数 | その馬が1着か（1着のモデル）、3着以内か（3着以内のモデル）の2つ | 「どれが勝つか」と「大穴が2頭以上入るか」の両方に答えるため |
| 展開の型の持ち方 | 学ぶときは、実際の結果のペース（ハイ・平均・スロー）を材料に入れる。予想するときは、3つのペースそれぞれで確率を出し、予想「展開から着順を予想」③ のペースの確率で重みを付けて足す: P(来る) = Σ P(ペース) × P(来る ｜ ペース) | 展開ごとに来やすい大穴が違うことを、モデルに直接学ばせる。予想のペースが外れても、外れたほうの展開の確率も混ざる |
| 超荒れの前提の確率 | 大穴の1着の確率を、そのレースの大穴の中で合計 1 にそろえる（「大穴のどれかが勝つとしたら、どれか」）。3着以内も同じく、大穴の3着以内の頭数の見込みで割る | 全部の大穴の行で学んだ確率から、条件つきの確率が作れる。荒れたレースだけで学ぶより学ぶ行が多い |
| 出発点 | オッズから見た率（単勝オッズから見た1着の率、人気から見た3着以内率）のロジット（LightGBM の `init_score`、CatBoost の `baseline`）。人気の順位そのものは材料に入れない | 人気の順をなぞる予想にしない。市場が見落とす分だけを学ばせる |
| 道具 | LightGBM と CatBoost の両方で学び、平均する（今のモデルと同じ） | |

### 2.4 2頭目の予想の作り方

1. 展開の型 s（ハイ・平均・スロー）ごとに、各大穴の3着以内の確率 p_i｜s を出す（2.1 の3着以内のモデル）。
2. 展開の型ごとに、大穴が2頭以上3着以内に入る確率と、大穴2頭 i・j がそろって3着以内に入る確率を出す。展開の型の中では各馬は独立とみなし、3着以内の頭数が3頭になるようにそろえる（そろえ方は今のモデルの組の確率と同じ考え方）。
3. 予想のペースの確率で混ぜる: P(i と j がそろって来る) = Σ P(s) × P(i, j ｜ s)。混ぜると、同じ展開の型で来やすい大穴どうし（ハイなら差し・先行の大穴どうし）の組の確率が、独立に掛けたときより大きくなる。
4. 探索の期間で、「大穴2頭以上の確率」を帯ごとに実際の割合と比べ、ずれがあれば1つの係数で直す（直し方は探索の期間だけで決める）。

出すもの: 大穴ごとの1着・3着以内の確率（展開の型ごとの値も）、超荒れの前提の確率（大穴の中でそろえたもの）、レースの大穴2頭以上の確率、大穴2頭の組の確率の上位。

## 4. 今のモデルにも足す材料の候補（市場が見落としているもの）

今のモデル（近走と適性から3着以内を予想）の材料には「斤量」「斤量とレースの平均との差」が入っている。「ハンデ戦か」「斤量の前走との差」は木曜の能力スコアにだけあり、「斤量 ÷ 馬体重」は入っていない。この研究で、人気から見た差がプラス（市場が低く見ている）だったものを、今のモデルに足す候補として書く。

| 候補 | 人気から見た差 | 前半・後半の年 | 今のモデルに無いもの |
|---|---|---|---|
| ハンデ戦のトップハンデ（トップとの差 × ハンデ戦か） | ハンデ戦のトップハンデ全体 +1.07 ±0.67、1番人気 +3.38 ±1.80、4〜5番人気 +2.25 ±1.60。トップハンデではない1番人気は −1.61 ±1.25 | 1番人気: +2.18・+4.81 | トップとの差、ハンデ戦か |
| ハンデ戦の昇級 × 前走との斤量の差 | 昇級して前走より軽くなった馬 +1.09 ±0.53（1着 +0.92 ±0.35） | +1.41・+0.73 | 前走との斤量の差、ハンデ戦か |
| 斤量 ÷ 馬体重（レースの平均との差） | 1着で、いちばん軽い5分の1が定量 +0.66 ±0.13・馬齢 +0.31 ±0.11・別定 +0.76 ±0.44、いちばん重い5分の1が −0.40〜−0.69（3着以内では差が無い） | （年で分けた表は作っていない。足すときに確かめる） | 斤量 ÷ 馬体重 |

- どれも、木の多いモデルなら今の材料（斤量・馬体重・クラス）の組み合わせから一部を学べている見込みがある。足して良くなるかは、研究「既存モデルの改善」の材料の確かめ（`material_check.py`。7つの区切りのうち5つ以上で良くなるか）で、今のモデルと同じ基準で確かめる。
- 市場が高く見すぎている側（人気から見た差がマイナス）には、定量・馬齢の減量騎手の馬（−0.49・−0.54）、定量・馬齢の平均より軽い馬（−0.9〜−1.2）がある。今のモデルに減量騎手の材料があるかを確かめ、無ければ同じ確かめにかける。
- 前走より軽くなっただけ（ハンデ戦の同級で軽くなった −0.34）、軽ハンデ（平均との差・トップとの差）だけは、人気から見た差が無いので候補にしない。

## 6. 段3 の形を全頭に広げる

利用者の確認（「これって大穴だけでなく、中穴も同じじゃない？逆に危険な人気馬を見つけるのにも」）で、大穴専用のモデルにはせず、全頭を同じ見方（展開・その日の馬場の傾向・適性・ハンデで、オッズのわりに得をする馬と損をする馬）で予想する形にした。[02 の 8](02-理論.md#8-全頭に広げた理論人気馬中穴大穴を同じ見方で) のとおり、展開と馬場の向きは人気帯をまたいでつながっている。上の 2. との違いは次のとおり。

| 項目 | 全頭に広げた形 |
|---|---|
| 学ぶ行 | 12頭以上のレースの全頭（重みは付けない） |
| 目的変数・出発点 | 3着以内（出発点はオッズから見た3着以内率のロジット）と1着（オッズから見た勝率のロジット）。今のモデルと同じ |
| 展開の型 | 学ぶときは実際の結果のペースを材料にし、予想するときはスロー・平均・ハイの3つで予測して、予想のペースの確率で混ぜる |
| 材料 | 今のモデルの材料（近走・適性・調教・血統・騎手と調教師・展開の予想・展開スコア）＋ 展開の型・予想のペースの確率・位置の確率・近5走の位置の平均 ＋ ハンデ（ハンデ戦か・トップとの差・前走との斤量の差・昇級か・昇級 × 前走との斤量の差・同じ斤量と重い斤量での好走の数）＋ 当日だけ その日の先のレースの内外・前後の傾きと、それに馬番の位置・近5走の位置を掛けたもの、斤量 ÷ 馬体重 |
| 道具・時点・区切り | LightGBM と CatBoost の平均。前日と当日。今のモデルと同じ15の半年の区切り（2019年前半〜2026年）で学び直す |
| 出すもの | ①中穴・大穴: 荒れる前提の確率（その人気帯の中で合計 1 にそろえた1着の確率）と、中穴・大穴2頭の組の確率（展開の型ごとに出して混ぜる）。②人気馬: 4着以下になる確率（市場の見立てとの差）。③馬ごとの理由の文（展開・馬場・ハンデのどれで得か損か）。④2026-11-08 の全レースの予想 |
| 比べる作り | 同じ材料で展開の型を外したもの（3着以内）。展開の型で混ぜる効き目を見る |

### 6.1 確かめ方と採用の目安（作る前に決めた）

探索 2019〜2024年で選び、確認 2025年からは1回だけ確かめる。今の買い目（本線）は置き換えず、新しいものは足す形にする。

| 対象 | 見るもの | 採用の目安 |
|---|---|---|
| 大穴・中穴の並べ方 | その人気帯の馬が勝ったレースで、勝ち馬をその人気帯の上位3頭に置けた割合と、荒れる前提の確率の対数損失。人気の順・今のモデル・荒れる前提のモデル・WIN5 研究の人気薄モデルと比べる（穴馬が3着以内のモデルは区切りごとの予測が残っていないので比べられない） | 確認の期間で、大穴の上位3頭の割合が人気の順より 2ポイント以上高く、荒れる前提の対数損失が市場より小さい |
| 確率の当たり具合 | 人気帯ごとの3着以内・1着の対数損失（市場・今のモデルと比べる） | 確認の期間で、中穴・大穴の対数損失が今のモデル以下 |
| 中穴・大穴2頭の組 | 2頭以上の確率の帯ごとの実際の割合、いちばん確率の高い組がそろって来た割合（展開の型ごとに分けない場合・市場と比べる） | 確認の期間で、組の的中が市場の組より多い |
| 抑えの買い目 | 本線（今の印の 3連複・3連単）に、中穴・大穴2頭の組の 3連複を少ない点数で足す。線（2頭以上の確率の上位 10・20・30%）× 組み方（◎−組 の1点、組−1〜3番人気 の3点）を探索の期間で精算し、当たったレースが 20 以上の候補のうち回収率のいちばん高いものを選ぶ | 確認の期間で、抑えの回収率が 100% 以上で、本線＋抑えの回収率が本線だけより下がらない |
| 危険な人気馬 | 人気馬の4着以下の確率の当たり具合と、市場より負けやすいと見た馬の実際。今の消（予想「人気馬が4着以下になるかを予想」）を新しい予想の 4着以下の確率に替えて、道具「印の成績」で印と全券種の買い目を作り直す | 決まりどおり、消を使った買い目（3連複・3連単など、消を外して組む買い目）の回収率と的中率が、両方の期間で今の消以上。全券種の回収率も並べる |
