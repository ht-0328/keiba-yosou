# 地方の直前の材料で買う

**何をする研究か。** 地方競馬で、発走前の通知が買い目を決める時刻（締め切りの約10分前）に分かることだけを使って、回収率 100% を超える買い方を探す。

**なぜ始めたか。** 地方の推奨買目は、過去の確かめでは回収率 100% を超えていたのに、実際の通知では大きく負けた（2026-11-16）。
調べると、確かめは確定オッズで買い目を選んでいたが、実際の通知は締め切りの約10分前のオッズで選んでいて、地方ではこの2つが大きく違った。
利用者から「見つかるまで試し続けて」「全レースでなくレースを選んでもよい」「3連単は買いたい」と言われた（2026-11-17〜18）。

数値（地方競馬DATA 由来のオッズ・成績・回収率）は Git 対象外の `reports/` に出し、この README には書かない。
過去の成績は `uv run python tools/地方の直前の買い目/check.py`（`reports/地方の直前の買い目/check.md`）、
実際の通知の成績は `uv run python tools/地方の直前の買い目/results.py`（`reports/地方の直前の買い目/results.md`）で見る。

## この文書で使う言葉の意味

| 言葉 | 意味 | この研究では（架空の例） |
|---|---|---|
| 断面 | ある時刻に発表された、全頭のオッズのひとそろい。時系列オッズ（地方競馬DATA の 0B41。単勝・複勝・枠連）は、発売の間およそ1分ごとの断面を持つ | 15:30 発表の断面 |
| 締め切りの k 分前の断面 | 締め切り（確定の断面の発表か、最後の発売中の断面）の k 分前までで、いちばん新しい断面 | 締め切りが 15:41 なら、10分前の断面は 15:31 までで最新のもの |
| 直前の材料 | 買い目を決める時刻に分かること: その時刻の断面の単勝・複勝オッズ、それより前の断面からの動き、その時刻のオッズを材料にした全頭の予想、オッズを使わない全頭の予想（出馬表の時点） | |
| 先生 | 確定オッズを材料にした全頭の予想（当日の時点）が、単勝の期待値 1.0 以上で買う馬。過去のレースでは確定オッズが分かっているので、答えとして付けられる | 1着の確率 0.2 × 確定オッズ 6.0倍 = 1.2 → 先生は買う |
| 買う馬らしさ | 「先生が買う馬か」を、直前の材料から当てるモデルの確率（0〜1）。確定オッズそのものは当てていない | 0.45 |
| 戻りの見込み | その馬の単勝を 1 買ったときに戻る額（勝てば確定オッズ、負ければ 0）を、直前の材料からじかに当てるモデルの値。1 が元 | 1.05 |
| 時間の順を守る | 確かめるレースより前のレースだけで学ぶこと。この研究では 3か月ごとに学び直す | 2025年4〜6月のレースは、2025年3月までのレースで学んだモデルで当てる |

## 決めた買い方

2つのモデルがそろって「買い」と言う馬だけを買う。線と形は道具「地方の直前の買い目」の `late_rule.py` にある。

| 項目 | 決まり |
|---|---|
| 買う馬 | 買う馬らしさと戻りの見込みが、どちらも線以上の馬 |
| 単勝 | その馬の単勝 |
| 3連単 | その馬を1着に固定し、2着・3着は、その馬を除いた人気上位（買い目を決めた時刻の単勝オッズの低い順）の馬 |
| 買わないレース | 線を満たす馬がいないレース（大半のレース） |

本番の決まり（通知での見せ方・時点・出せないとき）は、買い方の設計書の
[13](../../docs/design/買うレースと買い目を決める/13-local-late-tickets.md) に書く。

## 分かったこと

1. **確定オッズで選べば勝てる買い方も、約10分前のオッズで選ぶと勝てない。** 地方は、最後の数分で入る票が多く、約10分前のオッズと確定オッズが大きく違う。
   全頭の予想の力よりも、最後の数分の票が持つ情報のほうが大きい。
2. **期待値（確率 × そのときのオッズ）の線で選ぶ形は、どう作っても届かない。** そのときのオッズが高い馬は、あとで売れてオッズが下がる馬であることが多い。
   確定オッズを予想して掛ける形、勝った馬だけで確定オッズを学ぶ形、オッズが動きにくいレース・票数の多い競馬場に絞る形、レースを選ぶモデルも届かなかった。
3. **「先生が買う馬」を当てる形にすると、初めて 100% 前後になった。** 勝ち負けより答えのぶれが小さいので学びやすい。
4. **それに「戻りの見込み」を重ねると、100% を超えた。** 作り方の違う2つの見込みがそろう馬だけに絞る。線を上げるほど回収率が上がる。
5. **3連単は、その馬を1着に固定して相手を人気馬にする。** 単勝より回収率は高いが、少ない高配当に頼るので振れが大きい。

## 確かめ方と、割り引いて見るところ

- 時間の順を守った確かめ（`check.py`）と、種を変えた作り直し、断面を 8・10・12 分前に変えた作り直し、最初の半年（後ろの期間で学んで当てた）で確かめた。
- 線は全部の期間を見て選んだ。だから `check.py` の数字は、本当の値より高く出ているはずである。
- 払戻の上位の数本を除くと回収率が大きく下がる（`check.md` の最後の列）。高配当が出ない四半期は負ける。
- 過去の確かめは、取り直した時系列オッズの断面で「買い目を決める時刻」を再現している。実際の通知の時刻のオッズで通用するかは、
  通知が書く買い目を `results.py` で数えて確かめる。通知の文には、確かめている間「確かめ中」と出す。

## フォルダの中身

| 場所 | 何があるか |
|---|---|
| `analysis/odds_history_fetch.py` | 過去のレースの時系列オッズ（0B41）を、隣の nvdata-store の NV-Link の部品で取って分割ファイルに貯める（元DB には書かない。開催中は動かさない） |
| `analysis/odds_table.py` | 分割ファイルから、馬ごとの「締め切りの k 分前の単勝・複勝オッズ」の表を作り、着順・確定オッズ・オッズを使わない予想と結ぶ |
| `analysis/stale_odds_swap.py` | 元DB のコピーで、出走の行の単勝オッズと人気を締め切りの k 分前の値に差し替える。このコピーに向けて全頭の予想の backtest を回すと、「k 分前のオッズを材料にした当日の予想」が過去のレースぶん出る |
| `analysis/training_table.py` | 上の2つの出力と先生の予想から、道具の学習用の表（`reports/地方の直前の買い目/学習用の表.pkl`）を作る |

買い方を決めたあとの部品（特徴量・2つのモデル・決まり・過去の成績の確かめ・実際の通知の成績）は、道具 `tools/地方の直前の買い目/` にある。

## 学び直すとき

1. 新しい期間の時系列オッズを取る（`odds_history_fetch.py`。レースの時間を避ける）。
2. `odds_table.py` で表を作り直す。
3. 元DB のコピーを作って `stale_odds_swap.py` でオッズを差し替え、全頭の予想の backtest（当日の時点）をそのコピーに向けて回す。
4. `training_table.py` で学習用の表を作り、`tools/地方の直前の買い目/check.py` で成績を確かめてから、`fit.py` で本番用のモデルを書く。

全頭の予想のモデルは、学習用の表を作ったときと同じもの（`reports/地方競馬の近走と適性から3着以内を予想/models-2024検証`）を、通知のときも使う。
別のモデルに替えるなら、3 からやり直す。
