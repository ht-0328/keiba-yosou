# 05 単系で全部の重賞を買う（4回目）

**この文書は、4回目の目的・確率の作り方・形の候補・選び方・採用の線・結果を書く。** 数値は Git の対象外の `reports/重賞の買い方/4回目/` にあり、ここには書かない。

## 1. 目的

利用者の決定（2026-11-14）:「重賞は他の予想と分けるでもいいので、どうにかして回収率 100% を超す予想を見つけて。できれば単系馬券で勝ちたい」「単系は単勝、馬単、3連単です」「重賞は全勝負です」。
3回目（[04](04-単勝と複勝で探す.md)）は単系を単勝・複勝と取り違え、条件に合う重賞だけを買う形だったので、やり直した。
4回目は、**単勝・馬単・3連単のそれぞれで、全部の重賞（平地の G1・G2・G3）を必ず買う形を探す。**

## 2. 組の確率の作り方（3通り）

材料は研究「複勝以外の回収率100超」の全部の組の表（馬単・3連単。組ごとのオッズ・払戻・その券種の市場・3連単から見た市場・モデルの Harville・馬ごとの比）と、
印を付けた表（単勝。市場の勝率・1着の確率・3着以内の確率）のうち、平地の重賞の分。組の確率は、もとの対数に重みを掛けてレースの中で合計 1 にする（条件付きロジット）。

1. **重賞で合わせ直し**: 重みを重賞だけで学ぶ。選ぶ期間の各年は、その年を抜いた選ぶ期間で学び、確かめる期間は選ぶ期間の全部で学ぶ（`analysis/race_logit.py`）。
2. **本番の重み**: 今の本番の組の期待値の重み（`combo_blend.json`）。馬単・3連単だけ。この重みは直前1年で推定し直すもので、確かめる期間のデータで学んだ重みが入っているおそれがある。
3. **直前1年の重み**: 半年ごとに、その前の1年だけで学んだ重み（`rolling_weights-2015から.json`）。後出しが無い数え方。2015年の分は重みが無いので、選ぶ期間は 2016〜2020年になる。

## 3. 形の候補と選び方（重賞の 2015〜2020年だけを見る）

- 形: オッズの上限と組の確率の下限に合う組を、組の期待値（組の確率 × オッズ）の高い順に並べ、上から N点のうち期待値が線以上の組を買う。**線に届かなくても1点は買う**（全部の重賞を買うため）。
  - 点数 1・2・3・5・10・20、線 なし・1.0・1.2・1.5、オッズの上限（単勝 なし・10・20・100倍、馬単 なし・20・50・100・300倍、3連単 なし・100・300・1,000・3,000倍）、
    組の確率の下限（単勝 なし・5%・10%、馬単 なし・1%・3%、3連単 なし・0.2%・0.5%・1%）。
- 選ぶ決まり: 券種 × 確率の作り方ごとに、重賞の 9割以上を買い、当たりが 30 以上の形のうち、回収率の 90% の幅の下の端（開催日を単位にしたブートストラップ）がいちばん高いもの。
- 入口は `tankei.py`（`extract` → `fit` → `search` → `check`）。

## 4. 採用の線

**選んだ形を、確かめる期間（重賞の 2021〜2026年）で一度だけ数え、全部の重賞を買って回収率が 100% を超えれば採用する。**

**断り書き**: 確率の作り方は順に試した。はじめに「重賞で合わせ直し」の3券種を確かめる期間で数え、どれも 100% に届かなかった。そのあとで「本番の重み」を試し、
3連単の形が確かめる期間で 100% を超えた。本番の重みに確かめる期間のデータが入っているおそれがあるので、「直前1年の重み」で同じ形を数え直した。
どの段でも形は選ぶ期間だけで選んだが、確率の作り方を足したのは、確かめる期間の結果を見たあとである。

## 5. 本番に入れるときの形

当日の予想で、平地の重賞なら必ず、選んだ3連単の形の組を買う（参加の種類「勝負（重賞）」、勝負用の財布、1点 = 勝負レースの予算 ÷ 点数）。
組の確率は、本番の組の期待値と同じ重み（`combo_blend.json`）と、締め切り前のオッズで出す。

## 6. 結果（確かめたあとに書いた）

- **単勝は、どの確率でも 100% に届かなかった。** 重賞の単勝は市場の値段がほぼ正しい。
- **馬単は、確率の作り方でばらついた。** 重賞で合わせ直した確率と本番の重みでは届かず、直前1年の重みではわずかに超えたが、6年のうち3年は 100% を下回り、直近の年の高い回収率に頼っている。
- **3連単は、本番の重みの形（組の確率 0.2% 以上の組を、組の期待値の高い順に10点）が、確かめる期間で 100% を大きく超え、6年のうち5年で 100% を超えた。** 下の端も 100% に近い。
  直前1年の重みで選んだ形（20点）も 100% をわずかに超えた。下書きで、本番の重みの形（10点）を直前1年の重みで数えても、100% をわずかに超えた。
  重賞で合わせ直した確率では、100% にわずかに届かなかった。
- **本番には3連単（本番の重みの形）を入れた**（設計書「買うレースと買い目を決める」08 の 2「採用している券種（当日の予想の重賞の3連単）」）。オッズの上限は、下書きで選ばれた 1,000倍にした。
  入口で選ばれた「上限なし」とは、組の確率の下限があるので選ばれる組がほとんど変わらず、確かめる期間の回収率は同じだった。
- **気をつけること:** 当たるのは 25レースに1回ほどで、年ごとの振れが大きい（100% を大きく下回る年もある）。後出しの無い直前1年の重みでは、超え幅は小さい。
  利用者は、これを承知で「勝負する」と決めた（2026-11-14）。
