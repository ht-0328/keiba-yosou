# 06 重賞に特化した予想の印で全部の重賞を買う（5回目）

**この文書は、5回目の目的・材料・形の候補・選び方・採用の線を、後半の年を数える前に書く。** 結果は数えたあとに 7 に書く。数値は Git の対象外の `reports/重賞の買い方/5回目/` にあり、ここには書かない。

## 1. 目的

利用者の決定（2026-11-14）:「重賞に特化して、新しく予想モデルを作る」「印で全部の重賞を買う」「全券種で回収率 100% 超えを狙えるなら狙う。無理なら券種を 2〜4つ選んで、合計で 100%（2〜4券種はレースごとに選ぶ）」
「3連系は印以外の馬に流すのも選択肢の一つ」「単勝は ◎ の1点」。

1〜4回目は、今の予想（全レースを同じ重みで学んだもの）の印や確率で買い方を探した。5回目は、**印の元になる確率そのものを重賞に合わせて作り直した予想**
（設計書「[重賞に特化して3着以内と1着を予想](../../../docs/design/重賞に特化して3着以内と1着を予想/01-overview.md)」）の印で、同じ手順（前半の年で選び、後半の年で一度だけ数える）を踏む。
手順と線は設計書の [16 の 6](../../../docs/design/重賞に特化して3着以内と1着を予想/16-evaluation.md#6-印からの買い目の確かめ) に書いたもので、ここには、その手順を動かすときに決めたこと（設計書に無かったこと）だけを書く。

## 2. 材料

| 材料 | 中身 |
|---|---|
| 予測 | 研究「既存モデルの改善」の入口⑮（`graded_race_check.py`）で、1年ずつの7つの区切りで学んだ当日の3着以内と1着の予測（`predictions/graded_race_day/`）。どの年も、その年より前だけで学んだもの |
| 比べる予測 | 同じ区切り・同じ材料で、重みを付けず W・K を足さずに学んだもの（手本を重賞だけに使ったとき） |
| 印 | 道具「印の成績」の `BacktestMarker`（今週の予想と同じ決め方） |
| 組のオッズと払戻 | 元DB の確定オッズと確定払戻（道具「印の成績」の `TicketPayouts`） |

## 3. 設計書に無かったことで、動かすときに決めたこと

| こと | 決めたこと | 理由 |
|---|---|---|
| 消（危険な人気馬） | 使わない（印に消が付かない）。「○▲ → 消以外 → ◎」は「○▲ → 全頭 → ◎」になる | 人気馬の予想の7つの区切りは半年ずつ（2023年から）で、前半の年（2020〜2022年）の予測が無い。研究「既存モデルの改善」の重賞の作り直しの確かめと同じ扱い |
| 期間の終わり | 2026年9月22日まで | 学習データの表（今の本番の当日の表）が、その日までのため。9月下旬からの重賞は入らない |
| 「印」の ☆ | 複勝の期待値が 1.25 以上の ☆ だけを入れる | 今の印の買い目と同じ（表示だけの ☆ は買い目に入れない） |
| 3連複の「◎○▲△ の4頭の組」 | △ は1頭目（3着以内の確率がいちばん高い △）だけ | △ は3頭いるので、4頭にするため |
| 枠連の期待値 | 2つの枠の馬の組ごとの「3着以内の比」の積の平均 × 払戻率 77.5%（目安） | 枠連には組の比の式が無い。レースごとに券種を選ぶ順位付け（16 の 6.5 のア）にだけ使う |
| 1点の上限（24点）を超えた形 | 組の期待値の高い順に 24点まで残してから、トリガミを外す | 16 の 6.1 |

## 4. 動かし方

```powershell
uv run python research/既存モデルの改善/graded_race_check.py tables
uv run python research/既存モデルの改善/graded_race_check.py run
uv run python research/既存モデルの改善/graded_race_check.py summary
uv run python research/重賞の買い方/graded_model.py mark --top3 graded_race_day/graded-top3 --win graded_race_day/graded-win --name 重賞特化
uv run python research/重賞の買い方/graded_model.py count --name 重賞特化
uv run python research/重賞の買い方/graded_model.py search --name 重賞特化
uv run python research/重賞の買い方/graded_model.py check --name 重賞特化
```

（1行目は W を元DB から読んで学習データの表に W と K を付ける表を作る、2行目は作り方ごとに7つの区切りで学ぶ、3行目は重賞の行だけの確率の誤差を比べる。
4〜7行目は、印を付ける → 形の候補を全部の重賞で数える → 前半の年で選ぶ → 後半の年で一度だけ数える。比べる予測は `--name` を替えて同じ手順で数える）

## 5. 採用の線

設計書 16 の 6.6 のまま（結果を見る前に決めた）。0. 確率の誤差の条件（当日の3着以内と1着の両方で、7つの区切りを合わせた重賞の行のログ損失が手本以下）。
1. 8券種のどれも後半の年で 100% 超え。2. 届かなければ、レースごとに選んだ券種の合計で 100% 超え。

## 6. 後半の年の結果を見たあとに試したこと

後半の年（2023〜2026年）は、7 の1回目の確かめで見た。ここから先で選んだものは、後半の年ではまだ見ていない年の確かめにならない。

| 回 | 試したこと | 結果 |
|---|---|---|
| 2回目 | 形の候補に「組の期待値の高い順に N 点」（4回目の形。全部の組の表から数える）を足し、同じ手順で前半の年で選び、後半の年で数えた（`--family 全部`） | どちらの確率でも届かない（7 の表） |
| 3回目 | 全部の形を、前半と後半の両方で 100% を超えるかで並べた（後半の年を見て探した） | ほとんどの形は当たりが 1〜8回で、たまたまの当たりに頼る。当たりの数があって両方で超えたのは、手本の確率の「3連単 ◎ → ○▲ → 無印に流す（上限なし）」と「3連複 ◎軸 − 相手 − 相手（相手 無印に流す）・1,000倍まで・期待値 1.2 以上」 |

### 4回目の確かめ（まだ見ていない年。結果を見る前に書いた）

3回目で見つけた形は後半の年を見て選んだので、**当日の表より前の年（2015〜2019年）で一度だけ確かめる。** 当日の表は 2017年からなので、2012年からある前日の表（今の本番の前日と同じ列）で、
1年ずつの区切り（テスト 2015〜2019年。学習は 2012年から）を学び直し、前日の確率で印を付ける。オッズと払戻は確定のもの。比べのため、同じ前日の作りで 2020〜2026年も数える。

| 買い方 | 中身 |
|---|---|
| 案A（2券種） | どの重賞も、3連単 ◎ → ○▲ → 無印に流す（上限なし・期待値の線なし。24点まで）と、単勝 ◎ の1点 |
| 案B（3券種） | 案A に、3連複 ◎軸 − 相手 − 相手（相手 無印に流す）・1,000倍まで・期待値 1.2 以上を足す |

採用の線: 2015〜2019年の全部の重賞で、案A か案B の合計の回収率が 100% を超える（両方を数え、両方とも書く。下の端と、100% を超えた年の数も書く）。
2つの案を数えるので、片方だけが超えたときは、そのことを書いて利用者に判断を仰ぐ。

### 予想の作り方を替えた確かめ（2026-11-14 夜。利用者の指示「買い方の工夫ではなく、新しい予想方法を考えて確かめる」）

買い目の手順（形の候補・前半の年で選ぶ決まり・後半の年で数える）は 1回目と同じものに固定し、予想の作り方だけを替えた。
上の「4回目の確かめ」（買い方の案A・案B）は、この指示で取りやめた（数えていない）。

| 案 | 予想の作り方 | 重賞の行のログ損失（当日の手本と比べて） | 後半の年の、レースごとに選んだ券種の合計 |
|---|---|---|---|
| 1案目 | 全レースで学び、重賞の行に重み 5倍、W・K を足す（設計書どおり） | 負け（3着以内 2/7・1着 0/7）。重み 1 でも負け | 届かない |
| 2案目 | 二段の予想（前日の作りの予測を出発点に、重賞の行だけで市場とのずれを直す。3着以内はずらしのロジスティック回帰、1着は条件付きロジット） | ほぼ同じ（2段目がほとんど効かず、罰は毎年いちばん強いもの） | 届かない |
| 3案目 | 順位で学ぶ予想（レースを組にして着順の並びを lambdarank で学ぶ。出発点はオッズから見た勝率） | 負け（どちらも 1/7） | 数えていない（条件を満たさない） |
| 4案目 | 当日の手本と前日の作りの予測のロジットの平均（1着はレースで合計 1 にそろえる） | **勝ち（3着以内・1着とも 6/7、全体でも小さい）** | **100% をわずかに超えた**（下の端は 100% を大きく下回り、4年のうち 100% を超えたのは 2年） |
| 5案目 | 新しい材料 D（その日の馬場の傾向。同じ日・同じ競馬場・芝ダの2つ前までのレースの前残り・内外と、馬の脚質・枠との合い具合）を足す。材料は事例から選んだ（研究「重賞の事例から材料を作る」） | 負け（どちらも 3/7、全体でもわずかに大きい） | 数えていない（条件を満たさない） |
| 6案目 | 今の当日の予想を、オッズの動き（前日の最後の単勝オッズ → 確定の単勝オッズ）で直す（途中のオッズのある 2025年9月から。研究「重賞の事例から材料を作る」の docs/02） | 勝ち（2025年・2026年とも、3着以内・1着の両方） | 後半の年の全体 94.0% → 101.1%（2025年 152.7% → 170.2%・2026年 28.3% → 41.3%）。直した期間（2025年9月から）だけでは 66.8% → 91.2% で、100% に届かない |

- 4案目の平均の作り方は、平均の3通り（確率の平均・ロジットの平均・順位の予想も入れた3つの平均）を 2020〜2026年の重賞のログ損失で比べて選んだ。選び方に後出しがある。
- 後半の年は、1回目からの確かめで何度も見ている。買い目の手順は変えていないが、予想の作り方を4つ試した中で超えたものなので、まだ見ていない年での確かめにはならない。
- 4案目の後半の年の結果は、年や格による振れが大きい（年ごとに 35〜151%、G3 は 100% を大きく下回る）。偶然と区別できるかは、利用者に結果を見せて決める（設計書 16 の 6.6）。
- 2〜4案目は材料（特徴量）を変えず、学び方と予想の混ぜ方だけを変えたもので、新しい予想方法とは言えない（利用者の指摘）。4案目の結果は予想が良くなった結果ではないので採らない。
- 5案目からは材料を変える。事例から挙げた理由の候補は、どれも今の予想とのずれが 0.9〜1.1 に収まった（研究「重賞の事例から材料を作る」の docs/01）。

## 7. 結果

### 1回目（設計書どおりの確かめ）

- **確率の誤差の条件（0）を満たさなかった。** この予想（重み 5・W・K）のテストの年の重賞の行のログ損失は、3着以内も1着も手本より大きかった（手本より小さかった区切りは 3着以内 2/7、1着 0/7）。
- 参考として数えた印からの買い目も、後半の年でどの券種も 100% に届かず、レースごとに選んだ券種の合計も 100% に届かなかった。前半の年でも、この予想の印は手本の印より弱かった（◎ の単勝の回収率が大きく下がった）。
- 比べる行（手本の印で同じ手順）は、後半の年で複勝・馬連・ワイドが 100% をわずかに超えたが、レースごとに選んだ券種の合計は 100% に届かなかった。
- **採用しない。** 重みを付けて重賞の材料を足すと、重賞の行に合わせすぎて、確率がかえって悪くなった。重み 1（W・K だけ足す）の比べは `reports/既存モデルの改善/compare/` を参照。
