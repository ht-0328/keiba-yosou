## 1. 選んだ型（2015〜2020年）

◎ランクごと・券種ごとに、当たったレースが 15 以上の候補から下の端がいちばん高い型を選んだ。◎ランク S は重賞の中でも少なく、
枠連・馬単・3連複・3連単は当たりが 15 に届かず、全候補から選んだ（`選んだ型.md` の「当たり不足」）。

案2（勝てる券種）で買う券種は次のとおり（選ぶ期間の回収率が 100% 以上だった券種）。どの ◎ランクにも 100% 以上の券種があったので、
「1つも無いセルは下の端がいちばん高い券種を1つ」の決まりは使わなかった。

| ◎ランク | 買う券種と型 |
|---|---|
| S | 枠連（◎○ − 相手 2頭・期待値 1.2 以上）・ワイド（◎○ − 相手 2頭・絞らない） |
| A | 単勝（◎○▲ のうち期待値 1.0 以上）・枠連（◎○▲ − 相手 2頭・絞らない）・馬単（◎○▲ → 相手 6頭・絞らない）・ワイド（◎○ − 確率 25% 以上の馬・期待値 1.2 以上）・3連単（◎○▲ → 確率 25% 以上の馬 → 確率 25% 以上の馬・絞らない） |
| B | 馬連（◎○▲ − 相手 6頭・期待値 1.2 以上）・ワイド（◎○▲ − 相手 6頭・期待値 1.2 以上） |
| C | 複勝（◎○▲ のうち期待値 1.0 以上）・枠連（◎○▲ − 相手 6頭・絞らない）・馬連（◎ − 相手 2頭・絞らない）・馬単（◎○▲ → 確率 50% 以上の馬・絞らない）・ワイド（◎ − 相手 2頭・期待値 1.0 以上）・3連複（◎○▲ − 相手 2頭 − 相手 2頭・絞らない）・3連単（◎○▲ → 相手 2頭 → 相手 2頭・絞らない） |

どれも 12点まで（期待値の高い順）。3連複・3連単は「流し」。期待値の線のある型は、線に届く組が無いレースでも型の中で期待値がいちばん高い組を1点買う。

## 2. 確かめ（2021〜2026年。一度だけ）

- **合計の回収率は 案2 のほうが 案1 より少し高く、決まり（docs/01 の 6）で 案2 を本番に入れた。**
- **どちらの案も 100% には届かなかった。** 90% の幅の下の端も 100% の下で、100% を超えた年は6年のうち少ししかない。直近の2年（2025・2026年）は特に低い。
- **比べる相手（今の複勝2点）のほうが回収率は高かった。** 重賞でも複勝は市場の値段のずれが小さく、損が少ない。本気で勝負する（買う額を増やす）と、そのぶん損も大きくなる。
- 券種ごと（案1 の型）では、複勝と馬連だけが確かめる期間でも 100% 前後を保ち、3連単・単勝・馬単は大きく下がった。選ぶ期間の 100% 超えは、多くが当たりの少なさから来るたまたまだったと読める。
- ◎ランクごと（案2）は S と B が 100% を超え、A と C が届かなかった。S と B は1レースの点数が少ない。

## 3. 採否

- docs/01 の 6 の決まりでは案2 を入れることになったが、結果を見せたところ、利用者から「複数の券種で買う形じゃなくて、普通に単勝で勝負して買ってください」と言われた。**どちらの案も本番には入れない。**
- 本番の重賞は、ノルマ参加（重賞）をやめて、当日の予想の ◎ の単勝を勝負レースの予算で買う形にした（設計書「買うレースと買い目を決める」の 08 の 2・09 の 22）。過去の重賞での ◎ の単勝の回収率も 100% には届いていない（研究「全レース全券種の買い方」の表から数えた。数値は `reports/重賞の買い方/◎の単勝.md`）。

## 4. 次に確かめるとよいこと

- 複数の券種で買う形をもう一度考えるときは、ここで選んだ型から始め、何回目の確かめかを結果に書く。
