# 重賞の買い方

**何をする研究か。** どの重賞（平地の G1・G2・G3）でも、勝負用の財布から複数の券種で本気で買う前提で、◎ランク（S・A・B・C）ごとに券種ごとの買い目の形（軸・相手・期待値の線）と、
どの券種を買うかを過去の重賞から決める。

**結果。** 1回目（◎ランクごとに複数の券種を買う）も、2回目（レースの型ごとに券種を1つ選ぶ）も、重賞のまだ見ていない年で回収率 100% に届かず、本番には入れていない（[docs/02-結果.md](docs/02-結果.md) の 3、[docs/03](docs/03-レースごとに券種を選ぶ.md) の 7）。3回目（重賞だけで単勝・複勝の買い方を選ぶ）は、複勝が条件に合う重賞だけで 100% を超えたが、単系でも全部の重賞を買う形でもないので入れていない（[docs/04](docs/04-単勝と複勝で探す.md) の 6）。4回目（単系＝単勝・馬単・3連単で全部の重賞を買う）は、3連単がまだ見ていない年の重賞でも 100% を超え、本番に入れた（[docs/05](docs/05-単系で全部の重賞を買う.md) の 6）。

**なぜ始めたか。** 利用者の決定「重賞予想でノルマで複勝だけみたいな買い方じゃなくて、どんなレースでも本気で勝負して」（2026-11-14）。
今は、複勝の買い方に合う馬がいない重賞は「ノルマ参加（重賞）」になり、ポリシー用の財布から複勝を2点だけ買っていた。

## 言葉

| 言葉 | 意味 | 例 |
|---|---|---|
| ◎ランク | ◎ の1着の確率 ＋ 単勝の期待値 − 1 の点数を S 0.35 以上・A 0.15 以上・B 0 以上・C 0 未満にしたもの（設計書「買うレースと買い目を決める」03 の 5） | ◎ランク A |
| セル | この研究では ◎ランクの1つ（配当率では分けない。docs/01 の 3） | ◎ランク B |
| 型 | 券種ごとの買い目の作り方（軸・相手・2列目の置き方・期待値の線・12点まで）。研究「全レース全券種の買い方」の docs/01 の 4 と同じ候補 | ◎ − 相手 4頭・流し・期待値 1.0 以上・12点まで |
| 案1 全券種 | どの重賞でも 8券種を全部、◎ランクごとに選んだ型で買う | − |
| 案2 勝てる券種 | ◎ランクごとに、選ぶ期間の回収率が 100% 以上だった券種だけを買う（無ければ下の端がいちばん高い券種を1つ） | − |
