# レースの種類ごとの買い方

**何をする研究か。** 組の期待値で選ぶ買い方（馬単・ワイド・3連複・3連単・馬連）の的中率・回収率・勝負したレースの数を、
レースの種類（芝ダ・クラス・頭数・ハンデ戦かどうか など）ごとに予想の仕方を変えて上げられるかを確かめる。

**なぜ始めたか。** 利用者の依頼「的中率と回収率と勝負数を上げてほしい」「全部同じ方法で予想してるならレースの種類ごとに予想方法を変えるとかしてほしい。
そのためのモデルを分けたりしていい」「やれることは全部やって」（2026-10-18）。
今の買い方は、どのレースにも同じ組の確率の重みと同じ決まり（線・オッズの上限・点数）を使っている。種類ごとに数えると、
1〜2勝クラス・ダートのワイド・重賞やハンデ戦の馬単など、どの期間でも回収率が低い種類と、10頭以下の 3連単など高い種類があった。

## 言葉

| 言葉 | 意味 | 例 |
|---|---|---|
| 種類 | レースを分ける切り口の値 | 芝・1〜2勝クラス・14頭以上 |
| 組の確率・組の期待値 | 設計書「買うレースと買い目を決める」07 の 2 の作り方（4つのもとに重みを掛けて合わせる条件付きロジット）。期待値 = 確率 × 確定オッズ | − |
| 区切り | 今の本番の予測の半年ごとの区切り（`2020年前半` など） | − |
| ウォークフォワード | 各年について、その年より前のデータだけで重み・決まりを選び、その年で数えることを、年ごとに繰り返す確かめ方 | 2021年は 2016〜2020年だけで選ぶ |
| 今の本番 | 研究「複勝以外の回収率100超」の docs/04・05 で決めた、今の買い方（`tools/今週の予想/ticket_rules.py` の `COMBO_VALUE_RULES`） | − |

## 置き場所

| 場所 | 中身 |
|---|---|
| `analysis/` | 部品（1ファイル1クラス） |
| `walk_forward.py` | 入口。組の表の用意・重みの推定・決まりの選び方・成績の表 |
| `horse_model.py` | 入口。上のクラス・ハンデ戦の馬の予想モデルを分ける案の確かめ |

| `tests/` | 部品のテスト（架空の値だけ） |
| `reports/レースの種類ごとの買い方/`（Git 対象外） | 実測の数値。JV-Data 由来の値はここにだけ置く |

組の表は、研究「複勝以外の回収率100超」の手順6 が作った `reports/複勝以外の回収率100超/組の期待値/combos/`（2015〜2026年の当日の予想の、券種ごとの全部の組）を使う。
この表から本番の部品と同じ式で組の確率を作ると、道具「印の成績」の買い目の組の確率と一致する（ワイド・3連複は直前1年の重み、馬単は固定の重みで差 0）。
