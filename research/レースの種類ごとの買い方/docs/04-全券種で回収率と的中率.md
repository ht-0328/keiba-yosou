# 04 全券種で回収率 100% 超えと的中率の向上（手順6）

**この文書は、8券種（単勝・複勝・枠連・馬連・ワイド・馬単・3連複・3連単）のそれぞれで、回収率が 100% を超え、的中率も今より上がる買い方を探す手順と、採用の基準を書く。**
選び方と基準は 2019〜2026年の結果を見る前に決めて、この文書をコミットした。数値は Git の対象外の `reports/レースの種類ごとの買い方/` にあり、ここには書かない。

## 1. なぜやるか

利用者の依頼「全券種の回収率が100%を超えて、的中率も上がる方法を見つかるまでやって。全券種だから、後単勝、複勝、枠連もだよ」「満たせるまで、いろんな方法試してください。やり方は任せます」
「券種ごとにレース変えるのもありなんじゃないの」（2026-10-19）。

[03](03-券種ごとに向くレース.md) では、券種ごとに仮説の絞り方を1つずつ当てた。ここでは、券種ごとに、決まり（対象・線・上限・点数）と買うレースの絞り方（レースの中身の帯）の全部の組み合わせから、
**的中率を上げることを条件にして**選ぶ。券種ごとに選ぶので、券種ごとに買うレースが変わる。

## 2. 券種ごとの候補

| 券種 | 買い目の作り方 | 決まりの候補 |
|---|---|---|
| 単勝 | 馬ごとの単勝の期待値（1着の確率 × 単勝オッズ） | 対象（全レース・期待度「高」・◎ だけ・期待度「高」の ◎）× 線（1.0〜1.5）× 単勝オッズの上限（5・10・30・50倍）× 1レースの点数（1・3・5・全部） |
| 複勝 | 馬ごとの複勝の期待値（今の本番の `place_value`。複勝オッズは最低オッズ） | 同じ形。複勝オッズの上限は 2・3・5・10倍 |
| 枠連 | 組の期待値（3.） | 02 と同じ形。上限は馬連と同じ |
| 馬連・ワイド・馬単・3連複・3連単 | 組の期待値（案「今」。直前1年の重み） | 02 と同じ 320 個 |

買うレースの絞り方は 03 の B と同じ（絞らない／レースの中身6つの帯 k 以下・帯 k 以上／危険な人気馬が いない・いる。帯は 2016〜2018年の5分位）。
数え方は道具「印の成績」と同じ（当日の予想・確定オッズ・1点 100円・トリガミとオッズの無い組を外す）。

## 3. 枠連の組の確率

枠連の組（枠の組。同じ枠どうしを含む）の確率を、馬連の組の4つのもとを枠の組ごとに足し合わせて作る。
その券種自身の市場（枠連のオッズの逆数をレースで合計 1）、馬連のオッズから見た市場・3連単から見た市場・モデルの Harville（どれも、その枠の組に入る馬の組の和）の対数に重みを掛けて合わせる（条件付きロジット）。
重みは、ほかの券種と同じく区切りごとに直前の2つの区切りで推定する。◎ を含む組は、◎ の馬の枠を含む組。

## 4. 選び方（2016〜2018年だけを見る）

券種ごとに、2016〜2018年の成績で、次の全部を満たす組み合わせ（決まり × 絞り方）のうち、**回収率の 90% の幅の下の端がいちばん高い**ものを1つ選ぶ。

- 当たったレースが 50 以上。
- 回収率が 110% 以上、回収率の 90% の幅の下の端（開催日を単位にしたブートストラップ）が 100% 以上。
- 的中率（レースで数える）が、比べる相手の 2016〜2018年の的中率の 1.1倍以上。

比べる相手は今の本番（単勝は期待度「高」の ◎、複勝は期待値 1.25 以上を3点まで、馬単・ワイド・3連複・3連単は 03 の絞り方を足した今の決まり、馬連は比べる行の今の決まり）。
枠連は今の本番が無いので、馬連の今の決まりと同じ形（全レース・期待値 1.1 以上・100倍以下）を比べる相手にする。

## 5. 採用の基準（2019〜2026年）

選んだ組み合わせを 2019〜2026年で一度だけ数え、次の全部を満たした券種だけ本番に入れる。

1. 回収率が 100% を超え、90% の幅の下の端も 100% を超える。
2. 的中率（レースで数える）が、比べる相手の 2019〜2026年の的中率より高い。
3. 回収率が 100% を超えた年が、8年のうち 5年以上。

満たさない券種は、本番を変えない。

## 6. 満たさない券種のやり直し

満たさない券種は、別のやり方（新しい材料・新しい組の確率の作り方 など）を立て、その作り方と基準をこの文書に書き足してコミットしてから、同じ形で確かめる。
2019〜2026年は確かめるたびに見ることになるので、**何回目の確かめかを結果に書き、回数が多いほど、たまたま基準を満たした見込みが高いと読む。** この手順6 の1回目より前に、2019〜2026年は 03（1回）で見ている。
