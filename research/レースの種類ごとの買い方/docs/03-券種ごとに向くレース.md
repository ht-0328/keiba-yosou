# 03 券種ごとに向くレース（手順5）

**この文書は、券種ごとに、向いたレースの中身（人気の偏り・危険な人気馬・頭数 など）で買うレースを絞る案の、仮説・確かめ方・採用の基準を書く。**
仮説は 2016〜2018年だけを見て立て、確かめ方と基準は 2019〜2026年の結果を見る前に決めて、この文書をコミットした。数値は Git の対象外の `reports/レースの種類ごとの買い方/` にあり、ここには書かない。

## 1. なぜやるか

利用者の依頼「券種ごとに適したレースがあるんじゃない？とにかく全券種100%超えるように頑張って。後的中率は？」（2026-10-19）。
手順2〜3（[02](02-結果.md)）で分けたのは芝ダ・クラス・頭数のような「レースの条件」で、どの券種も同じ分け方だった。
ここでは、券種ごとに向き不向きがありそうな「レースの中身」（1番人気がどれだけ抜けているか、危険な人気馬がいるか など）で、券種ごとに別の絞り方を確かめる。

## 2. 仮説（2016〜2018年だけで立てた）

2016〜2018年の、今の決まりの買い目と、広い決まり（全レース・期待値 1.0 以上）の買い目を、レースの中身の5分位の帯ごとに数えた（`reports/レースの種類ごとの買い方/中身の帯ごとの事例-2016から2018.md`）。
帯の多くは上がり下がりがばらばらでたまたまの範囲だったが、**今の決まりと広い決まりの両方で同じ向きだったもの**を、券種ごとの絞り方の仮説にした。

| 券種 | 仮説の絞り方 | 見えたこと |
|---|---|---|
| 馬単 | 15頭以下のレースだけ | 16頭以上で回収率が低い |
| ワイド | 1番人気の単勝オッズが 2.9倍以上のレースだけ | 1番人気が抜けたレースで低く、1番人気が弱いレースで高い |
| 3連複 | 危険な人気馬がいないレースだけ | 危険な人気馬がいるレースで大きく低い |
| 3連単 | ◎ の単勝の期待値が 0.99 以下のレースだけ | ◎ の期待値の高いレースで低い |
| 馬連 | 1番人気の単勝オッズが 1.9倍以下のレースだけ | 1番人気が抜けたレースで高い |

的中率は、どの券種も、モデルと市場の勝率の食い違いが大きいレースほど高かった（回収率の向きはばらばら）。

## 3. レースの中身

`analysis/race_traits.py` の6つ。どれも当日の発走前に分かる値（確かめは確定オッズで数える）。

| 列 | 中身 |
|---|---|
| favorite_odds | 1番人気の単勝オッズ |
| top3_share | 市場の勝率の上位3頭の和（人気の集まり方） |
| field_size | 頭数 |
| model_gap | モデルと市場の勝率の食い違い（差の絶対値の和の半分） |
| top_value | ◎ の単勝の期待値 |
| has_danger | 危険な人気馬がいるか |

帯の区切りは、2016〜2018年のレースの5分位で決めて固定する（has_danger は いる・いない の2つ）。

## 4. 確かめ方

組の確率の重みは今の本番と同じ（案「今」。直前1年の重み）。数え方は道具「印の成績」と同じ（当日の予想・確定オッズ・1点 100円・トリガミとオッズの無い組を外す）。数える年は **2019〜2026年**。

### A. 仮説の絞り方を、今の決まりに足す

今の本番の決まり（`CURRENT_RULES`）に、2. の仮説の絞り方を足して、2019〜2026年で、足さないときと比べる。
絞り方は 2019〜2026年を見ずに決めたので、絞ったことの効き目は正直に測れる。ただし今の決まり自身は 2020〜2026年を見て選んだので、回収率の水準は甘く出る。

### B. 決まりと絞り方を、年ごとに選び直す

各年について、その年より前（2016年〜前の年）だけで、決まりの候補（02 と同じ 320 個）× 絞り方の候補を選び、その年で数える。

- 絞り方の候補: 絞らない／中身の6つそれぞれについて「帯 k 以下」「帯 k 以上」（k = 2〜5。5分位の帯の続いた範囲）／危険な人気馬が いない・いる。
- 選ぶ基準: 今の本番の決まりを選んだのと同じ、**回収率の 90% の幅の下の端**がいちばん高い組み合わせ（選ぶ期間の当たったレースが 150 以上）。
  手順2〜3 の利益の下の端で選ぶと、オッズの上限の高い決まりに寄って翌年に続かなかったので、こちらにする（手順2〜3 の比べる目安の行で、この基準の方が多くの券種で成績が良かった。この選び方は手順2〜3 の結果を見て決めた）。

## 5. 採用の基準

券種ごとに、次のどちらかを満たせば、その絞り方（A）か選び方（B）を本番に入れる。両方満たせば B を採る（後から選んだ甘さが無いため）。

- **B の採用**: 2019〜2026年で、回収率が 100% を超え、開催日を単位にしたブートストラップの 90% の幅の下の端も 100% を超え、回収率が 100% を超えた年が 8年のうち 5年以上。
  本番の決まりは、同じ選び方で 2016〜2026年の全部から選んだもの。
- **A の採用**: 2019〜2026年で、絞ったときの回収率が絞らないときより高く、絞ったときの 90% の幅の下の端が 100% を超え、絞ったときの回収率が絞らないとき以上の年が 8年のうち 5年以上。

どちらも満たさない券種は、今の本番のまま変えない。的中率（レースで数える）は、採否には使わず、表に並べて報告する。

## 6. 気をつけること

- 2019〜2026年は、手順2〜3 で（今の決まりの成績として）見ている。仮説は 2016〜2018年だけで立てたが、選び方（4. の B の基準）は手順2〜3 の結果を見て決めた。
- 絞り方の候補が多いので、B ではたまたま良かった絞り方を選ぶおそれがある。年ごとに選び直すので、その分は 2019〜2026年の成績に出る。

## 7. 結果

**A（仮説の絞り方を今の決まりに足す）は、馬単・ワイド・3連単で採用の基準を満たした。3連複・馬連は満たさなかった。B（決まりと絞り方を年ごとに選び直す）は、どの券種も満たさなかった（2026-10-19）。**
数値は `reports/レースの種類ごとの買い方/券種ごとに向くレース.md`（選んだものは `券種ごとに向くレース-選んだもの.md`）。

| 券種 | A（仮説の絞り方） | B（年ごとに選び直す） | 本番 |
|---|---|---|---|
| 馬単 | 満たす。ただし絞らないときとの回収率の差はごく小さく、勝負するレースは4割ほど減る | 満たさない（幅の下の端が 100% を割る） | 15頭以下のレースだけ買う |
| ワイド | 満たす。回収率がはっきり上がり、勝負するレースは半分ほどになる | 満たさない | 1番人気が 2.9倍以上のレースだけ買う |
| 3連複 | 満たさない（絞ったほうが良い年が半分にとどまる） | 満たさない | 変えない |
| 3連単 | 満たす。回収率がはっきり上がり、勝負するレースは4割ほど減る | 満たさない | ◎ の単勝の期待値が 0.99 以下のレースだけ買う |
| 馬連 | 満たさない（絞ると回収率が下がる） | 満たさない | 変えない（買わないまま） |

- **的中率は、絞ってもほぼ変わらないか、少し下がる。** 絞り方は回収率の高いレースを選ぶもので、当たりやすいレースを選ぶものではない。ワイド・馬単はほぼ同じ、3連単は少し下がった（◎ の期待値の低いレースは、人気の割に ◎ が弱く、荒れやすい）。
- **B は、選ぶ期間でたまたま良かった帯を選び、翌年に続かなかった。** 年ごとに選ばれる絞り方と決まりが入れ替わった。2016〜2018年の事例から立てた仮説（A）のほうが、2019〜2026年でも続いた。
- **A の回収率の水準は甘く出ている。** 今の決まり自身が 2020〜2026年を見て選ばれているので、絞ったことで上がった分は正直に測れているが、絞ったあとの回収率そのものは、実際に期待できる値より高い。
