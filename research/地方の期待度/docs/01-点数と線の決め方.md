# 01 点数と線の決め方

**この文書で決めること:** 地方の期待度（レースに添える1つだけの目安）の点数の式と、S・A・B・C の線。数値（勝率・回収率）は `reports/地方の期待度/期待度の候補-<時点>.md`（Git 対象外）にあり、ここには載せない。

**結論: 点数は ◎ の1着の確率 ＋ 3 ×（◎ の単勝の期待値 − 1）、線は S 0.45 以上・A 0.15 以上・B −0.10 以上・C それ未満。当日の時点だけ出す（前日の時点は目安にならない）。** 本番の決まりは設計書「買うレースと買い目を決める」の [11](../../../docs/design/買うレースと買い目を決める/11-local-expectation.md)。

## 1. 仮定（何が成り立てば目安として使えるか）

- 期待度が高いレースほど、◎ の単勝・複勝をべた買いしたときの勝率・複勝率・単勝回収率・複勝回収率が高い（4つの率が C → B → A → S の順に上がる）。
- その向きが、線を決めた年（2024年）だけでなく、ほかの年（2025・2026年）でも変わらない。
- 推奨買目（研究「地方の万馬券」段5 の買い目）の成績も、期待度の順に並ぶ（買い目は変えないが、目安として整合する）。

## 2. 進め方（結果を見る前に決めたこと）

| 段 | 内容 |
|---|---|
| 材料 | 地方の予想モデルの backtest の未見の予測 `predictions-2024検証`（2023年前半までで学んだモデルの 2024-01〜2026-11 の予測。当日と前日）。印の成績と同じ決め方で印を付け（`BacktestMarker`・`MarkRule`）、◎ の行（1着の確率・単勝の期待値・3着以内の確率・複勝の期待値・結果・払戻・頭数）を残す（`TopPicks`） |
| 候補 | 10 の式（`CANDIDATES`）: A 中央の式（1着の確率 ＋ 期待値 − 1）、B 1着の確率だけ、C 期待値だけ、D・I・J 期待値の重みを 2・3・0.5 にしたもの、E 確率の重みを 2 にしたもの、F 3着以内の確率 ＋ 複勝の期待値 − 1、G 両方の期待値を足したもの、H 確率と期待値の積。参考に A を中央の線（0.35・0.15・0）で当てたもの |
| 線 | 候補ごとに、2024年の点数の分位（上から 20%・30%・30%・20%）で S・A・B の下の線を決める（`GradeLines`。小数2桁）。本番の線は 0.05 刻みに丸める |
| 判定 | 2025・2026年の各年で、4つの率が等級の順に真に上がった回数（最大 8）。多いものを採る。同じなら S と C の単勝回収率の差が大きいもの |
| 補足 | 等級ごとの推奨買目の回収率と的中レース率（`RecommendedTickets`）、頭数（7頭以下・8〜10・11以上）ごとの等級の成績、期待値の重みを 2.5・4・5 にしたときの向き |

## 3. 分かったこと（当日の時点）

- **中央の式（A）と確率だけ（B）**: 勝率・複勝率は順に上がるが、単勝回収率が順に上がらない（S が A・B より低い）。地方は 1番人気が買われすぎで、確率の高い ◎ の単勝は回収率が低い。中央の線のままでも同じ。
- **期待値だけ（C）**: 回収率は順に上がるが、勝率が逆（S の勝率がいちばん低い）。
- **期待値の重みを上げる（D 2・I 3）**: 7 回（最大 8）順に上がる。上がらなかった 1 回は 2026年の単勝回収率で、B が A をわずかに上回ったもの（S はどの年も最も高い）。重み 3 のほうが S と C の単勝回収率の差が大きい。
- **重み 2.5・4・5**: 2.5 は 3 とほぼ同じ向きで差が小さい。4 以上は S の勝率が A を下回る（期待値に寄りすぎ）。3 は、勝率の順を保てる中で回収率の差がいちばん大きい。
- **3着以内の確率や複勝の期待値で作る（F・G）、積（H）**: 単勝回収率が順に上がらない。
- **推奨買目**: どの候補でも、的中レース率は期待度の順に上がる（期待度は推奨買目の当たりやすさの目安にもなる）。回収率は S がおおむね高いが、年によって順に並ばない。
- **頭数**: 重み 3 の等級は、7頭以下・8〜10頭・11頭以上のどれでも S の ◎ の単勝回収率が 100% を超え、C は割る。11頭以上で差がいちばん大きい。
- **線の丸め**: 2024年の分位の線（0.43・0.16・−0.09）を 0.05 刻み（0.45・0.15・−0.10）に丸めても、等級の割合（S 約 2割・A 約 3割・B 約 3割・C 約 2割）と向きは変わらない。

## 4. 前日の時点

前日の時点の未見の予測で同じ候補を当てた（`reports/地方の期待度/期待度の候補-前日.md`）。

- どの候補でも、**単勝回収率が等級の順に上がった年は無い**（勝率・複勝率・複勝回収率は多くの候補で上がる）。前日の ◎ は全体の単勝回収率が 100% を割り、点数の分布が当日より大きく下に寄る（期待値 1.00 以上の ◎ が少ない）。
- 重み 3 に当日の線（0.45・0.15・−0.10）を当てると、S がごくわずか・A と B が3割ほど・C が 7割近くに偏る。前日だけの線（2024年の分位）にしても単勝回収率は順にならない。
- そのため、期待度は**当日の時点だけ**出し、前日の時点の通知は「期待度 なし（当日の時点で出す）」と書く。推奨買目が当日の時点だけなのと同じ扱い。

## 5. 採ったこと

| 項目 | 内容 |
|---|---|
| 式 | ◎ の1着の確率 ＋ 3 ×（◎ の単勝の期待値 − 1）（候補 I） |
| 線 | S 0.45 以上・A 0.15 以上・B −0.10 以上・C それ未満（2024年の分位を 0.05 刻みに丸めたもの。固定） |
| 時点 | 当日だけ。前日は出さない（4） |
| 採らなかった | 中央の式と線のまま（回収率が順に上がらない）、期待値だけ（勝率が逆）、重み 4 以上（S の勝率が A を下回る）、3着以内の確率・複勝の期待値・積の式、前日の時点の期待度 |
| 見直すとき | 地方の予想モデルを学び直したら、`expectation.py --rebuild` で ◎ の行を作り直し、向きが変わっていないかを見る。本番の確かめは道具「印の成績」の表13（`--scene 地方`） |
