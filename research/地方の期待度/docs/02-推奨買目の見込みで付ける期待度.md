# 02 推奨買目の見込みで付ける期待度

**この文書で決めること:** 地方の期待度を、◎ の点数（[01](01-点数と線の決め方.md)）から、そのレースの推奨買目の見込みに変えるか。変えるなら、どの見込みを点数にし、どこで線を引くか。
数値（回収率・的中率・1日の儲け）は `reports/地方の期待度/推奨買目の見込みの期待度[-前の年].md`（Git 対象外）にあり、ここには載せない。

**結論: 点数は推奨買目の期待の儲け（1点ごとの（期待値 − 1）の合計）、線は S 3.2 以上・A 1.4 以上・B 0.5 以上・C それ未満。** 的中率と1日の儲けが等級の順に上がり、
回収率も S が最も高い。A と B の回収率はほぼ同じで、年によって入れ替わる。C は 100% 前後で、年ごとの振れが大きい。本番の決まりは設計書「買うレースと買い目を決める」の
[11](../../../docs/design/買うレースと買い目を決める/11-local-expectation.md)。

**この結論は、確定オッズで作り直した推奨買目でのもの。** 通知の時刻のオッズで作った推奨買目では成り立たなかったので、通知の期待度には使っていない（[03](03-通知の時刻での確かめ.md)）。

## 1. なぜ始めたか

利用者から「期待度と推奨買目は関係あるのか」と聞かれ、期待度（◎ の点数）は推奨買目を決めるのに使っていないと答えたところ、
「期待度は、そもそも推奨買目の期待度にしたほうがいいのでは」と言われた。地方の推奨買目はほぼ全レースで出るので、どのレースの推奨買目に期待できるかの目安が要る。

## 2. 仮定（何が成り立てば目安として使えるか）

- 期待度が高いレースほど、そのレースの推奨買目の実際の回収率・的中率・1日の儲けが高い（C → B → A → S の順に上がる）。
- その向きが、線を決めた年（2024年）だけでなく、ほかの年（2025・2026年）でも変わらない。

## 3. 進め方（結果を見る前に決めたこと）

| 段 | 内容 |
|---|---|
| 推奨買目を作り直す | 2024年1月からの 5頭以上の確定レースで、本番と同じ決まり（道具「地方の推奨買目」の `RECOMMENDED_PLANS`。券種ごとの期待値の線・オッズの帯・頭数の線・馬連の形「人中」・3連複の荒れ具合の線と上位 3点）で推奨買目を作る（`RecommendedBetsBuilder`・`BulkPlanChooser`） |
| 組の確率 | 本番と同じ 1着・2着・3着の条件つきロジット（研究「地方の万馬券」段5）。係数は本番と同じく 11頭以上のレースで当てはめる。各年を残りの年で当てはめる（入れ替え）と、その年より前の年だけで当てはめる（前の年）の2通り。本番の予想モデルの予測（テスト期間の 2026年）に本番の係数をそのまま当てた形（本番）でも確かめる |
| オッズ・払戻・形・荒れ具合 | オッズと払戻は確定の値（本番は発走 10分前のオッズ。確定 ≒ 10分前 の前提）。組の形は確定の単勝人気。3連複の荒れ具合は研究「地方の万馬券」段④の予測（2024年以降は学びに使っていない） |
| 点数の候補 | 見込みの回収率（そのレースの推奨買目の期待値の平均。1点 100円で買ったときの見込み）と、期待の儲け（（期待値 − 1）の合計）。比べる相手は今の ◎ の点数 |
| 線 | 候補ごとに、2024年の点数の分位（上から 20%・30%・30%・20%）で S・A・B の下の線を決める（`GradeLines`。01 と同じ） |
| 判定 | 2025・2026年の各年で、回収率・的中率・1日の儲けが等級の順に上がるか（`grade.py` の表の最後） |

## 4. 分かったこと

- **推奨買目はほぼ全レースで出る。** 1レースの点数は平均 13点ほど。どの年も、作り直した推奨買目全体の回収率は 100% を超える。
- **見込みの回収率（期待値の平均）は目安にならない。** 見込みの最も高い帯（S）の実際の回収率が、A・B より低い年がある。見込みの高い組ほど期待値が高めに出やすく、
  見込みの高さが実際の得に結びつかない。的中率の順も年によって崩れる。
- **期待の儲け（（期待値 − 1）の合計）は目安になる。** 的中率と1日の儲けは 2025・2026年とも C → B → A → S の順に上がる。回収率は S がどの年も最も高く、C は（入れ替えでは）どの年も最も低い。
  10の帯に細かく分けると、下の 2割は 100% 前後かそれを割り、真ん中の 6割（A と B）は回収率がほぼ平らで年ごとに上下し、上の 2割がよい。
  そのため A と B の回収率は年によって入れ替わる（1日の儲けと的中率は A のほうが高い）。
- **◎ の点数で分けると、推奨買目の成績は等級の順に並ばない。** 回収率はどの等級も近く、S が最も高い年は無い。◎ の点数は ◎ の単勝・複勝の目安で、推奨買目の目安ではない。
- **C のレースの推奨買目は 100% 前後。** 入れ替えでは 3年とも 100% を割るが、前の年だけで当てはめた 2025年は 100% を超えた。1レース 4点ほどで的中率が低く、年ごとの振れが大きい。1日の儲けはどの場合もほぼ 0。
- **前の年だけで当てはめても、同じ向き。** 前の年だけで当てはめた組の確率で作り直した推奨買目（2025・2026年）でも、本番の線の等級で的中率と1日の儲けが両年とも順に上がり、S の回収率が最も高い（`推奨買目の見込みの期待度-前の年.md`）。
- **本番の予想モデルと本番の係数でも、同じ向き。** 2026年の本番の予想モデルの予測に本番の係数を当てて作り直した推奨買目でも、等級の割合（S が 2割強・C が 2割弱）、1レースの点数、的中率と1日の儲けの順、S の回収率が最も高く C が 100% を割ることは同じ（`推奨買目の見込みの期待度-本番.md`）。

## 5. 採ったこと

| 項目 | 内容 |
|---|---|
| 点数 | そのレースの推奨買目の1点ごとの（期待値 − 1）の合計（期待の儲け）。全頭の予想から足す ◎ の単勝・複勝は数えない |
| 線 | S 3.2 以上・A 1.4 以上・B 0.5 以上・C それ未満（2024年の分位 3.20・1.37・0.51 を 0.1 刻みに丸めたもの。丸めても向きと割合は変わらない） |
| 時点 | 当日だけ（推奨買目が当日の時点だけなので） |
| 推奨買目が無いとき | 「期待度 なし（推奨買目が無い: 理由）」 |
| ◎ の点数 | 道具「印の成績」の表13 の地方の分け方として、名前を「◎の点数」にして残す（◎ の行だけの backtest では推奨買目を作らない） |
| 採らなかった | 見込みの回収率（S が最もよくない年がある）、◎ の点数のまま（推奨買目の目安にならない） |
| 買い目との関係 | 期待度で買い目は変えない。C のレースの推奨買目を買わない形は買い目の決まりの話で、この文書では決めない |
