# 01 進め方: 計画の項目を、どう直してどう確かめたか

計画（`plans/既存モデルの修正計画.md`）の項目ごとに、予想のコードの何を直したか（`src/yosou/`）と、この研究で何を比べたかを書く。
数値は `reports/既存モデルの改善/` にあり、ここには書かない。

## 1. 予想ごとの直し

| 予想 | 計画の「どう変えるか」 | 直したコード | 比べた作り方 |
|---|---|---|---|
| 全出走馬の3着以内 | オッズから作った3着以内の基準確率を出発点にし、近走や適性で上げ下げする。複勝を買う判断は「複勝的中確率と払戻倍率」で | 基準（`Top3Baseline`）を LightGBM の `init_score`・CatBoost の `baseline` として渡す。特徴量に「オッズから見た3着以内率」を足す。予測の出力に「オッズから見た3着以内率・複勝的中の確率・複勝の期待値」を足す | 現行 / オッズだけ / 変更版 |
| 穴馬の3着以内 | 中穴と大穴を分けて学習。オッズがある時点ではオッズに基づく確率を補正。「来る確率」と「複勝を買う期待値」を別々に出し、買う候補は期待値で選ぶ | 基準（`Top3Baseline`）と、特徴量「単勝オッズ・オッズから見た勝率・3着以内率」（まとまり K）を足す。中穴と大穴で別のモデル（`SEGMENTS`）。予測に期待値を足す。`--odds` を受け取る | 現行 / オッズだけ / 基準＋補正（分けない）/ 変更版（分ける） |
| 人気馬の4着以下 | 1番人気・2〜3番人気・4〜5番人気に分けて学習。オッズから見た4着以下の基準に対する危険の増え方を予想。「4着以下の確率」と「通常より危険な度合い」を出し、後者で危険を判定。線は検証期間で | 基準（`OutOfTop3Baseline`）とまとまり K を足す。人気帯で別のモデル（`SEGMENTS`）。予測に「オッズから見た4着以下の確率・危険度・危険」を足す。線は学習のときに検証データで決めて保存する（`DangerThresholdStep`）。`--odds` を受け取る | 現行 / オッズだけ / 基準＋補正（分けない）/ 変更版（分ける） |
| レースの荒れ具合 | 現行方式を比較対象に残し、馬ごとの着順確率から荒れ具合を計算する方法を試す。勝率・着順の組合せ・券種別オッズを用意し、同じ「払戻額による4段階」を予想できる形にしてから比べる | 予想のコードは現行のまま。計算の方法はこの研究（`analysis/upset/`）で作って比べた | 現行（区切りごとに学習し直す）/ 計算（オッズだけの勝率）/ 計算（3つの予想を組み合わせた勝率） |

人気馬・中穴・大穴の範囲は、現行の頭数別の定義のまま（13頭以下は 1〜3番人気・4〜6・7〜、14頭以上は 1〜5・6〜9・10〜）。

## 2. 材料と学び方の直し

| 計画の項目 | したこと |
|---|---|
| オッズの使い方 | 基準と補正を分けた。「1 ÷ 単勝オッズ」をそろえた勝率を、そのまま3着以内の確率にせず、Harville の式で3着以内率にしてから基準にした（`src/yosou/shared/feature/odds/`） |
| 中穴・大穴、人気帯の扱い | 区分ごとに学習と評価を分けた。分けない「基準＋補正」も残して比べた |
| 馬を選ぶ基準 | 全頭・穴馬は、確率の順位（予測の表の並び）と、買う候補（期待値）を分けた。人気馬は購入期待値ではなく危険度で評価した |
| 3着以内と複勝的中 | 目的変数「3着以内」は残し、払戻の表と照合した「複勝的中」の列を足した（7頭以下は2着まで、同着は払戻どおり、4頭以下は複勝を売らない） |
| 騎手・調教師・血統 | 「オッズから期待された3着以内率をどれだけ上回ったか」（件数が少ないと 0 に寄せる）を作り、足したときの効果を比べた（実験） |
| タイム・近走の実績 | 能力指数（条件の標準タイムと比べた速さ）、近走の市場に対する成績（相手の強さを含めた評価）、当日の馬場傾向を、1つずつ足して比べた（実験） |
| 競馬場・距離などの違い | 分けない変更版を基準に、芝ダ・競馬場（主場とローカル）・距離帯・芝ダ×距離帯・頭数帯で分けた作り方を比べた（実験） |
| 券種ごとのオッズ | 3連単・馬単・3連複・馬連・ワイド・複勝の確定オッズから馬ごとの支持を取り出し、単勝から見た値との比を足して比べた（実験。当日だけ） |
| 予想する時点 | 締め切り前の全券種オッズは DB に無いので、確定オッズで検証した（実運用より楽観側）。オッズを保存する作業は計画の「別途」 |

## 3. 確かめ方

- 過去で学習して次の半年を予想する検証を、2023年前半〜2026年の7つの区切りで行った。学習は 2017年1月から検証の始まりの前日まで、
  検証はテストの直前の半年、テストは評価する半年（2026年は 9月まで）。時点は当日。
- ハイパーパラメータは予想の初期値のまま（LightGBM と CatBoost の両方を学習し、確率を平均する）。
- 確率の線・買う線・危険の線は、区切りごとに検証期間だけで決めた。テスト期間の結果は使っていない。
- 評価の指標: 確率の誤差はログ損失、同じ人気の馬どうしの見分けやすさは人気別 AUC。買い方の結果には、点数・的中率・回収率と、
  開催日を単位にしたブートストラップの 90% の幅を添えた。

採用の基準は計画の 3 のとおり。

| 予想 | 採用の基準 |
|---|---|
| 全頭 | オッズだけより確率の誤差が小さい区切りが7つのうち5つ以上あり、全期間を通じた誤差とばらつきも確かめられること |
| 穴馬 | 大穴でも、現行の大穴予想・大穴を全部買う方法・人気最上位の大穴を選ぶ方法より良いか。回収率の推定幅も示す |
| 人気馬 | 危険と判定した馬が、同じ人気の馬全体より実際に4着以下になりやすく、1番人気にも有効で、件数と複数の区切りで裏付けられること |
| 荒れ具合 | 計算の方法が、同じ券種・同じ払戻の区分で現行に劣らないこと（正解率・ログ損失） |
| 材料の追加・学習の分割 | 変更版より、未学習の期間（テスト期間）で良くなったものだけ残す |

## 4. 組み合わせた買い方の確かめ方

1. 3つの予想（全頭・穴馬・人気馬の変更版）の「上げ下げ」（予想の確率のロジット − 基準のロジット。3着以内の向き）と、
   log(オッズから見た勝率) を材料にして、レースの中の勝率を条件付きロジットで出す。材料の重みは検証期間の1着の馬で決める。
2. 勝率から、Stern の補正つき Harville の式で、7つの券種（単勝・複勝・馬連・ワイド・馬単・3連複・3連単）の買い目が当たる確率を出す。
   補正の強さ（2着・3着での人気馬の寄り方）は、検証期間の実際の1〜3着の並びで決める。
3. 買い目ごとに期待値（当たる確率 × 見込みの倍率。複勝・ワイドは最低オッズ × 帯ごとの倍率、ほかは確定オッズ）を出す。
4. 券種ごとに、買い方（期待値の線・オッズの上限・1レースの点数の上限）を、検証期間の回収率で選ぶ（点数 100以上・レース 30以上）。
   検証期間の回収率が 100% に届かない券種は、その区切りのテスト期間では買わない。
5. テスト期間で、選んだ買い方のとおりに 1点 100円で買い、確定の払戻で精算する。

出す表（`reports/既存モデルの改善/backtest/結果.md`）: 全体、券種ごと、単勝・複勝の人気ごと、年ごと、年 × 券種、運用の目安
（1年・1開催日・1レースあたりの数と金額、いちばん深い落ち込み、いちばん長い連敗）、1レースの点数の分布、買い目のオッズの帯、
区切りごとに選んだ買い方、勝率の出し方、参考（検証で 100% に届かなかった券種も買ったとき）、比べる目安（1番人気を全部買ったとき）。
