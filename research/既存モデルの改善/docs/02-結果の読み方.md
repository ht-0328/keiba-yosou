# 02 結果の読み方: どの表を見て、何が分かったか

`reports/既存モデルの改善/` に出る表の読み方と、そこから分かったことを書く。数値は `reports/` にあり、ここには書かない
（JV-Data 由来の数値を Git に載せないため）。ここでは、区切りの数え上げと言葉だけで書く。

## この文書で使う言葉の意味

この文書に出てくる言葉のうち、分かりにくいものの意味をまとめた（README の表にあるものは、そちらを見る）。

| 言葉 | 意味 | この研究では（例） |
|---|---|---|
| ログ損失 | 確率の誤差。当たった馬に低い確率、外れた馬に高い確率を付けるほど大きくなる。小さいほど良い | 3着以内に入った馬に 0.1 を付けると、0.6 を付けたときより大きく罰せられる |
| 人気別 AUC | 同じ単勝人気の馬どうしで、目的変数が 1 の馬に高い確率を付けられた割合。0.5 なら人気で説明できない部分を何も当てていない | 同じ3番人気の中で、3着以内に入る馬を見分けられているか |
| 回収率の 90% の幅 | 開催日を単位にしたブートストラップ（開催日を選び直して何度も計算する）で出した、回収率がばらつく範囲 | 幅が 100% をまたぐなら、「100% を超える」とも「超えない」とも言えない |
| 上げ下げ | 予想の確率のロジットから、基準（オッズから作った確率）のロジットを引いた値。予想が市場より高く見ているか低く見ているか | 正なら「市場の見立てより来る」と予想している |

## 2. 予想ごとに分かったこと

| 予想 | 採用の基準（`01-進め方.md` の 3） | 結果 | 判断 |
|---|---|---|---|
| 全頭 | オッズだけより確率の誤差が小さい区切りが 7つのうち 5つ以上 | 7つすべてで小さかった。複勝を期待値で買う回収率は、現行より高くなったが、100% にはわずかに届かなかった（90% の幅は 100% をまたぐ） | 採用 |
| 穴馬 | 大穴でも、現行・大穴を全部買う・人気最上位の大穴を選ぶより良いか | 中穴・大穴とも、7つすべてで現行とオッズだけより誤差が小さかった。大穴を期待値で買う方法は、比べた3つの方法のどれより回収率が高かったが、100% には届かなかった | 採用（中穴と大穴で分ける） |
| 人気馬 | 危険と判定した馬が、同じ人気の全体より負けやすく、1番人気にも効くこと | オッズだけより誤差が小さい区切りは、1番人気で 5つ、2〜3番人気と 4〜5番人気で 7つすべて。危険の判定は、現行では1番人気をほとんど判定できなかったが、変更版では 7つすべての区切りで、危険とした1番人気が全体より負けやすかった | 採用（人気帯で分ける） |
| 荒れ具合 | 計算の方法が、同じ券種で現行に劣らないこと | 3つの予想を組み合わせた勝率から計算する方法は、4券種 × 7区切りの 28 すべてで現行よりログ損失が小さく、正解率も4券種とも現行以上だった | 方法としては現行より良い。ただし予想する時点で全券種のオッズが要り、まだ取れないので、本番の予想は現行のまま（設計書の 15 の 14） |

分ける（中穴・大穴、人気帯）・分けないの差は、穴馬と人気馬のどちらでもごく小さかった。計画どおり分けたものを採用した。

## 3. 組み合わせた買い方で分かったこと

表は `backtest/結果.md`。買い方の作り方は `01-進め方.md` の 4（印 → ルール → 期待値のカット）。
2026-09-25 より前の「全部の組み合わせから期待値で選ぶ」買い方の結果は `backtest-全組み合わせから選ぶ版/` にある。

- **勝負するレースと点数は大きく減った。** 前の買い方は8割のレースで勝負していたが、印の買い方では全レースの1割に満たず、
  1開催日に数レース、1レースに1〜2点になった。
- **全体の回収率は 100% 前後まで上がったが、90% の幅は 100% をまたぐ。** 前の買い方よりはっきり良くなったが、
  「100% を超える」とはまだ言えない。年ごとに見ると、100% を超えた年と下回った年がある。
- **買うと決まった券種は、複勝と馬連が中心だった。** ワイド・3連複・3連単は、どの区切りでも検証期間の回収率が 100% に届かず、
  テスト期間に買わなかった。参考の表（届かなかった券種も買ったとき）でも、この3つは 100% を大きく下回った。
- **確率のずれの表では、3連複・3連単の高いオッズの帯で、当たる確率を見積もりすぎていた。** オッズの低い帯では、予想と実際が
  ほぼ合っていた。高い帯の買い目を買うなら、確率の出し方（Stern の補正）を直す必要がある。
- **押さえ（◎が危ういときの相手同士）は、押さえだけが当たったレースがあったが、押さえの回収率は低かった。**
- **重賞は、買うと決まった券種の、期待値の線を超えた買い目だけ買った。** 重賞だけの成績は、表「重賞だけの券種ごとの成績」にある。

## 4. 気をつけること

- **オッズは確定オッズで検証している。** 実際に買う時点では締め切り前のオッズしか分からないので、ここの成績は実運用より楽観側にぶれる。
- **2026-09-24 に、勝率の重みの学び方の不具合を直した。** 着順の無い馬（取消・除外など）の「1着か」が欠損のまま残り、重みの最適化が
  1歩も進まずに「市場の勝率そのまま」を返していた。直す前の `backtest/` の結果は、`backtest-重みが学べていなかった版/` に退避してある。
  直したあとは、3つの予想の上げ下げに重みが付き（「勝率の出し方」の表）、的中の数が大きく増えた。荒れ具合の計算も、直したあとで回した。
- 確率の線・買い方・危険の線は、区切りごとに検証期間だけで決めた。テスト期間の結果を見て選び直してはいない。

## 5. 材料の実験で分かったこと

表は `compare/form_experiments.md`。全頭の変更版（base）に、材料を1つずつ足した作り方と、条件で学習データを分けた作り方を、
base と比べた。採用の基準は、テスト期間のログ損失が base より小さい区切りが 7つのうち 5つ以上あり、全期間を合わせても小さいこと。
「base との差」の列は、差がごく小さいので 1000倍して出している。

| 作り方 | base より良かった区切り | 判断 |
|---|---|---|
| ＋ 券種ごとのオッズから見た支持 | 7つすべて。差もほかの作り方よりはっきり大きく、人気別 AUC も上がった | 採用の基準を満たす。ただし予想する時点で全券種の締め切り前のオッズが要り、まだ取れないので、src にはまだ移さない |
| ＋ 騎手・調教師・血統の市場に対する成績 | 6つ。ただし全期間の差はごく小さい（券種ごとのオッズの数十分の一） | 採用の基準は満たす。効き目がごく小さいので、src に移すかは利用者の確認待ち |
| ＋ 当日の馬場傾向 | 2つ | 採用しない |
| ＋ 能力指数（標準タイムと比べた速さ） | 3つ | 採用しない |
| ＋ 相手関係を考えた近走（市場に対する成績） | 3つ | 採用しない |
| 芝ダで分ける | 3つ | 採用しない |
| 競馬場（主場・ローカル）で分ける | 4つ | 採用しない |
| 距離帯で分ける | 1つ | 採用しない |
| 芝ダ×距離帯で分ける | 0 | 採用しない（細かく分けるほど悪くなった） |
| 頭数帯で分ける | 2つ | 採用しない |

- 条件で分ける作り方は、どれも分けないほうが良かった。今の木のモデルは、条件を特徴量として受け取って、条件ごとに予想を変えられている。
  分けるとデータが減るぶん、かえって悪くなる。
- 馬の情報から作った材料（能力指数・相手関係・当日の馬場傾向）は、オッズから作った基準に上乗せできる情報がほとんど無かった。
  効き目がはっきりあったのは、ほかの券種のオッズ、つまり市場の別の見方だけだった。
