# 02 理論を確かめる（段2）

**この文書で決めること:** 段1 の事例から立てた理論（人気馬が崩れる条件・穴馬が来る条件・荒れやすいレースの条件）を、全レースの数でどう確かめ、何を残すか。

**結論: 地方の単勝オッズは、遠征・転入・前走の着順と位置・騎手の場内順位・斤量のような事情を、ほぼ織り込んでいる。「同じ人気の馬全体」と比べると差が出る理論も、「同じオッズの馬全体」と比べると差がほとんど消える。オッズと比べて残るのは少数（人気馬の 休み明け・持ち時計1位・単勝支持の厚さ、中穴の 中央所属、大穴の 先行馬の距離短縮（複勝回収率）、人気薄の 休み明け・転入直後（来ない））で、どれも差は数ポイントである。レースの荒れやすさは、1〜3番人気の支持率・1番人気のオッズ・頭数・競馬場で大きく分かれる。地方の予想は、馬の事情で人気馬を消したり穴馬を選んだりするのではなく、(1) 市場の見立て（オッズ・券種ごとの支持のずれ）を土台にした確率の予想、(2) 市場の見立てから決まる荒れ具合、(3) 荒れ具合に合わせた決着の型と組の期待値、で組み立てる。**

## 1. 確かめ方

| 項目 | 決めごと |
|---|---|
| 対象 | 2019年以降の地方（ばんえいを除く）の 11頭以上の確定レースの出走。2024年の前後の2つの期間に分ける |
| 理論 | `analysis/theory_catalog.py`。人気馬（1〜3番人気）が崩れる・信頼できる 20個、穴馬（中穴 4〜7・大穴 8番人気以下）が来る・来ない 23個 |
| 比べる相手 | **同じ人気の馬全体**（人気ごとの複勝率・回収率を、当てはまる馬の人気の内訳で重み付け）と、**同じオッズの馬全体**（単勝オッズの帯ごと。`analysis/odds_baseline.py`）の2つ |
| 残す線 | 同じオッズの馬全体との複勝率の差が、2つの期間とも理論の向きで 1.5pt 以上、1年あたり 100頭以上 |
| レースの条件 | 頭数・クラス・競馬場・距離・馬場・1番人気のオッズ・1〜3番人気の支持率・遠征馬と転入初戦と中央所属の数・前走で前にいた馬の数・連闘の数・2歳戦 ごとに、万馬券率と 10万馬券率を期間ごとに出す |

「同じオッズ」と比べる理由: 人気の順位が同じでもオッズは広く散らばる（地方は売上が小さく、1番人気でも 1.2倍から 4倍まである）。同じ人気と比べて差が出ても、それがオッズの違いで説明できるなら、市場はすでにその事情を知っている。予想が市場に勝つには、オッズで説明できない差が要る。

## 2. 分かったこと（数値は `reports/地方の万馬券/理論の検証.md`）

### 2-1. 人気馬（1〜3番人気）

- 同じ人気と比べると「単勝支持が薄い」「前走6着以下」「前走は後ろにいた」「斤量が軽い」「休み明け」の人気馬は崩れやすく見える。しかし同じオッズと比べると、「単勝支持が薄い」はむしろ少し上（オッズが高い分は織り込み済み）、「前走6着以下」「前走は後ろにいた」も差が消える。
- **オッズと比べても残る**のは、崩れる側で **休み明け**（90日以上）、信頼できる側で **持ち時計1位** と **単勝支持が厚い**（人気の順位のわりにオッズが低い）。**斤量が軽い** は向きは合うが線に届かない。
- 「地方で2走以下」「騎手が場の上位3」「乗り替わり」「牝馬」「高齢」「別の場から」は、オッズと比べると差が無い。

### 2-2. 穴馬（中穴 4〜7・大穴 8番人気以下）

- 同じ人気と比べて来やすく見えた「前走3着以内」「前走1〜3番人気」「前走は前にいた」「騎手が場の上位3」「持ち時計1位」「斤量が重い」は、同じオッズと比べるとすべて差が消えるか、むしろ少し下になる。地方の市場は人気薄の実績も織り込んでいる。
- **オッズと比べても残る**のは、**中央所属の中穴**（交流競走の中央馬。頭数は少ない）と、**先行馬の距離短縮**（大穴。複勝率の差は小さいが、複勝回収率が同じオッズの馬全体より 20pt ほど高い。複勝の市場が単勝ほど評価していない）。
- 来ない側では、**休み明け**（中穴・大穴とも）、**転入初戦・地方で2走以下**（人気薄で来ると思われがちだが、オッズと比べて 2〜4pt 低い）。
- 「単勝支持が厚い人気薄」は、同じ人気と比べると大きく上だが同じオッズと比べると下。ただし複勝回収率は同じオッズの馬全体より高い（大穴で 10pt 以上）。単勝と複勝で支持のずれがある馬で、券種ごとの支持（今の全頭の予想の N）で拾える。

### 2-3. 荒れやすいレース

- **1〜3番人気の支持率**（単勝オッズから見た支持率の合計）が 55% 未満のレースは 10万馬券率が全体の約 2倍、70% 以上なら 0.75倍。**1番人気のオッズ** 3.0倍以上でも約 1.5倍。市場が割れているレースが荒れる。
- **頭数** 13頭以上で 1.4〜1.8倍。**競馬場** は 大井・川崎・高知 が荒れやすく、門別・佐賀・金沢・姫路・園田 は固い。**2歳戦** は固い。
- 遠征馬・転入初戦・連闘・前走で前にいた馬の数は、荒れやすさと関係が薄い。

## 3. 段3 への引き渡し（地方の予想の組み立て）

| 予想 | 段2 からの決めごと |
|---|---|
| ① 全頭の確率 | 市場の見立て（単勝オッズ・券種ごとの支持）を土台にし、オッズと比べて残った事情（休み明け・持ち時計1位・斤量差・中央所属・前走の位置×距離変更・転入からの出走数）と、地方の走りの材料（コーナーの順位から作る脚質。地方競馬DATA に脚質の判定が無い）を足す。人気馬・穴馬を別の表で学ぶより、全頭の確率と市場の差で「危険な人気馬」（1〜3番人気で確率 − 市場 が低い）「来そうな穴馬」（中穴・大穴で確率 − 市場 が高い）を決めるほうが、事情の表より強い |
| ② 危険な人気馬 | ①の確率と市場の差（1〜3番人気の帯）。消は1レース1頭 |
| ③ 穴馬 | ①の確率と市場の差（中穴・大穴の帯）。中穴 4〜7・大穴 8〜 の区切りは、段1 の人気ごとの3着以内率の段差と合うのでそのまま |
| ④ 荒れ具合 | 市場の割れ方（1〜3番人気の支持率・1番人気のオッズ・支持の散らばり）・頭数・競馬場・クラス・2歳戦と、①の確率の散らばりから、4段階（固い 1万円未満・中荒れ 1〜10万・大荒れ 10〜100万・超荒れ 100万〜）の確率を出す |
| 買い方 | 荒れ具合 → 型（段1 の表 2・3）→ 消を外した人気馬と穴馬 → 組の確率 × 3連単オッズ の期待値で点数 |

②③を独立のモデルにするかは、段3 でまず「①の確率と市場の差」で消と穴を決めた買い目の回収率を出してから決める（事情の理論は市場に織り込み済みなので、独立のモデルが①に勝つ見込みは薄い）。
