# 03 3連単の買い方を確かめる（段3・段4）

**この文書で決めること:** 全頭の予想の確率と市場の見立てから 3連単の買い目をどう組み、何で比べ、何を採るか。

**結論: 買い目は「全頭の予想の 1着の確率から Harville の式で出した組の確率 × 確定の 3連単オッズ = 組の期待値」で選ぶ。帯の役（人気馬は予想と市場の差がいちばん低い1頭を消して2頭、中穴は差の高い順に3頭、大穴も3頭）で組を絞り、荒れ具合で型を絞らない。荒れ具合（市場の割れ方）で型を絞る買い方と、消をしない買い方は、どちらも回収率が下がった。採否は、テスト期間と未見期間の両方で回収率 100% 超、90% の幅の下の端、最高の1点を除いた回収率、万馬券・10万馬券の的中数、最長の連敗で見る。**

## 1. 買い目の組み方（`analysis/trifecta/`）

| 段 | 何をするか | 部品 |
|---|---|---|
| 確率 | 全頭の予想（地方競馬の近走と適性から3着以内を予想）の当日の予測の表（`backtest` が書いた pkl）から、馬ごとの 3着以内の確率と 1着の確率を読む | `PredictionRepository` |
| 市場 | 単勝オッズから支持率（1/オッズ をレース内で合計 1 に）、Harville で市場の 3着以内率、予想との差（確率 − 市場）、1〜3番人気の支持率の合計、荒れ具合（70% 以上 固い・55〜70% 中荒れ・55% 未満 大荒れ） | `RaceMarket` |
| 組の確率 | 1着の確率（または 3着以内の確率、両方の相乗平均）を勝つ力にして、全部の 1着→2着→3着 の組の確率を出す | `HarvilleCombos` |
| 3着以内に合わせた勝つ力 | Harville の 3着以内率が、全頭の予想の 3着以内の確率（1着の確率より市場に対する上乗せが大きい）に一致する勝つ力をレースごとに繰り返しで解き、それで組の確率を出す。1着だけ 1着の確率を使う形もある | `Top3FittedStrength`・`HarvilleCombos`（`first_strength`） |
| 縮め | 組の確率を、券種のオッズから見た市場の組の確率に寄せる（`p ^ 縮め × m ^ (1 − 縮め)` をレース内で合計 1 に）。選んだ組だけ見ると確率が高く出すぎる（選び取りの偏り）のを抑える | `TicketPlan._shrunk`・`Strategy.shrink` |
| 役 | 人気馬（1〜3番人気）は差の低い1頭を消して残り、中穴（4〜7番人気）・大穴（8番人気以下）は差の高い順に頭数ぶん | `TicketPlan._roles` |
| 型 | 荒れ具合ごとに買う型（人中大 など）を決めるか、型を問わない | `Strategy.patterns` |
| 期待値 | 組の確率 × 確定の 3連単オッズ が線以上の組を、期待値の高い順に 1レースの上限まで | `TicketPlan.build` |
| レース単位の線 | 残した買い目の確率の合計（そのレースでどれかが当たる見込み）や期待値の平均が線に届かないレースは丸ごと買わない。「当たりそうなレースだけ買う」で勝った日の割合と落ち込みを良くする狙い | `TicketPlan._races_worth_buying` |
| 成績 | 確定払戻を当てて、期間ごとに 投資・払戻・回収率・90% の幅（開催日のブートストラップ）・最高の1点を除く回収率・的中・**的中の実際÷見込み**（当たった点数 ÷ 買い目の確率の合計。1 より小さいほど選んだ組の確率が高く出すぎている）・万馬券と10万馬券の的中・**勝った日の割合・1日の損益の中央値・最大の落ち込み**・最長の連敗（日）。同じ列を年ごとにも出す（年をまたいで勝ち続けるか） | `TrifectaSimulator` |
| 3連複 | 同じ流れで、組は3頭の組み合わせ（6通りの並びの確率の和）、型は 人→中→大 の順に並べた帯。「安定して勝てる」を見るために 3連単と並べて比べる | `Strategy.ticket`・`HarvilleCombos.trios` |

比べる買い方の一覧は `strategy_catalog.py`。基準の買い方 L（全レース・型を問わず・人2中3大3・期待値 1.0 以上・30点まで・11頭以上）から、1つずつ変えて比べる。`trifecta.py --only L T S3` のように、名前の先頭の記号で比べる買い方を絞れる。

## 2. 分かったこと（数値は `reports/地方の万馬券/3連単の買い方.md`）

- **荒れ具合（市場の割れ方）で型を絞ると負ける。** 市場が「固い」と見るレース（地方の 8割）を外すと、万馬券・10万馬券の取りこぼしが大きい。市場が割れたレースだけを買う買い方は、的中も回収率も低い。
- **型を問わず、組の期待値で選ぶ買い方（L）は、テスト期間と未見期間のどちらも回収率 100% を超えた。** ただし払戻の多くを 10万馬券以上の数本が占め、最高の1点を除くと 100% を割る。90% の幅も広い。
- 消（人気馬のうち差のいちばん低い1頭を外す）は、L では回収率を上げた（点数が 4割減り、払戻はあまり減らない）。型を絞る買い方では逆だった。
- 期待値の線を上げる・点数の上限を下げる・10万馬券の組だけにする、は回収率の数字が上がるが、的中が減って幅が広がる（大当たり頼み）。
- 頭数を 10頭以下まで広げると回収率が下がる。11頭以上が主戦場、という段1 の見立てと合う。

### 2024〜2026年（2023年前半までで学んだモデル。`3連単の買い方-2024検証.md`）

- **年ごとに見ると、どの買い方も安定して 100% を超えない。** L は 2024年 8割・2025年 16割・2026年 9割で、2025年の数本の大当たり（10万馬券）が全体を持ち上げている。3連複の T・T2 は 8割前後で、2026年だけで見えていた T2 の 13割は偶然だった。
- 落ち込みが小さく年ごとの差も小さいのは、100〜1000倍の組だけ・当たる見込み 5% 以上のレースだけ（L21）で、3年とも 95〜98%。安定はしているが勝てていない。
- 内訳（型・荒れ具合・頭数・組のオッズ・期待値・競馬場）は、テスト期間と未見期間で良い所が入れ替わり、絞り込める範囲は見つからない。
- **原因は、選んだ組の確率が高く出すぎること。** 買った組だけで見ると、当たった点数は確率の合計の 0.6〜0.7 倍（期待値の帯が高いほど低く、期待値 2.0 以上の組はほぼ当たらない）。期待値 1.0 で選ぶと実際は 0.7 前後になり、回収率が 7〜8割に落ち着く。確率が高く出た組を選ぶほど、確率の誤差が大きい方へ偏る（選び取りの偏り）。
- 対策が「縮め」（S）と「3着以内に合わせた勝つ力」（F）。縮めの割合は 2024年で的中の実際÷見込みが 1 に近づく値を選び、2025年・2026年で確かめる。

### 組の確率を的中の実績で直すと（`組の確率の直し.md`。`calibration.py`）

- 全部の組（11頭以上、2024年）で「的中 ~ log(予想の組の確率) + log(市場の組の確率)」を当てはめると、**3連単は市場の確率の係数が 0.9 近く、予想の確率の係数は 0.2 に満たない。** 市場の 3連単オッズが、予想から Harville で出した組の確率より当たり具合をよく表している。3連複（1着の確率）も同じ傾向。3着以内に合わせた勝つ力で出した 3連複の組の確率は、予想の係数が 0.6〜0.7 で市場より当てになるが、それでも市場の係数は 0.4 残る。
- **直した期待値が 1.0 以上の組は、3連単ではほぼ無い（全部の組の 0.00 いくつ％）。** 3連複（3着以内に合わせた勝つ力）では 1% 弱残り、それを買うと年ごとに 9割前後。縮めや帯の役で選ぶ買い方より安定するが、100% には届かない。
- 馬ごとの 3着以内の確率は、選んだ馬だけで見ても当たり具合が合っている（複勝の 的中の実際÷見込み が 1.0〜1.05）。高く出すぎているのは組の確率で、Harville の式の作る組の確率が、地方の 3連単・3連複の市場の値付けに勝てていない。
- ここから言えるのは、**今の全頭の予想の情報量では、地方の 3連単・3連複で安定して 100% を超える買い方は作れない**ということ。買い方の工夫（型・消・期待値の線・オッズの帯・縮め・レース単位の線・勝つ力の当てはめ）はどれも、年をまたいで 100% を超えなかった。
- 地方の材料（コーナー順位から作る脚質・調教師の地区・遠征・場内の騎手成績）を全頭の予想に足しても、当たり具合は変わらなかった（当日のログ損失 0.442 → 0.442）。モデルの新しさ（2023年前半まで／2025年前半まで）も 2026年の当たり具合を変えない（0.4422 と 0.4419）。

## 3. 確かめ終えたことと、次の候補

確かめ終えたこと: 期間を 2024〜2026年に広げて年ごとに見る（`3連単の買い方-2024検証.md`）、内訳で絞る（入れ替わるだけで範囲は無い）、確率を強くする（地方の材料を足しても変わらない。`3連単の買い方-2024検証-地方材料.md`）、縮め・3着以内に合わせた勝つ力・レース単位の線（`3連単の買い方-2024検証-縮め.md`）、組の確率の直し（`組の確率の直し.md`）。どれも年をまたいで 100% を超えない。

このあとは、利用者の指示（荒れそうなレースを選ぶ → 危険な人気馬と穴馬を見つける → 3連単の買い目。当日の馬場傾向を入れる）で予想方法の段ごとの精度を上げる（[04-予想方法の段ごとの精度.md](04-予想方法の段ごとの精度.md)）。買い方の工夫はここまでで打ち切る。

組の確率の作り方そのものを変えた続き（Harville の式をやめ、1着・2着・3着を分けた条件つきロジットで市場に合わせる）は [05-1着2着3着を分けて市場に合わせる.md](05-1着2着3着を分けて市場に合わせる.md)。そこで、ここで原因とした「選んだ組の確率が高く出すぎる」が解消し、3連単を含む全券種の買い方ができた。

## 4. 採否の基準（計画の 3. と同じ。「安定して勝てる」の意味）

利用者の希望は「安定して勝てる買い方」（2026-11-03）。回収率の平均だけでなく、次をそろえて見る。

- テスト期間（2024〜2025年）と未見期間（2026年）の両方で回収率 100% 超、テスト期間では 90% の幅の下の端も 100% 超。
- 最高の1点を除いた回収率も 100% に近い（大当たり1本に頼らない）。
- 勝った日の割合・1日の損益の中央値・最大の落ち込みが、財布で耐えられる範囲（1点 100円で、最大の落ち込みが数十万円以内）。
- 万馬券・10万馬券の的中数、最長の連敗、1日の金額。
