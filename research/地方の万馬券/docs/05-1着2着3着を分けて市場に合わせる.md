# 05 1着・2着・3着を分けて市場に合わせる（段5）

**この文書で決めること:** 利用者の指示「全券種で回収率 100% を超える方法を見つける。特に 3連単」に対して、組の確率の作り方を Harville の式（docs/03）から変え、全券種の買い方をどう組み、どう確かめ、何を採るか。

**結論: 1着・2着・3着を分けた条件つきロジットで、全頭の予想の確率と各券種の票の見立てから組の確率を出すと、期待値の帯ごとの的中が見込みと合う（docs/03 の「選んだ組の確率が高く出すぎる」が消える）。その期待値でオッズの帯を絞って買うと、単勝・複勝・枠連・ワイド・馬単・3連単は、各年を残りの年で当てはめた未見の評価で 2024・2025・2026 年とも回収率 100% を超え、全券種をまとめても毎年超える（月ごとの損益も大半の月で正）。馬連・3連複は単体では 100% に届かない。数値は `reports/地方の万馬券/全券種の買い方.md`。**

## 1. 何が問題だったか（docs/03 の振り返り）

- Harville の式は「1着の確率をそのまま 2着・3着の強さにも使う」ので、2着・3着の確率が市場の 3連単の票より粗い。組の確率を「的中 ~ log(予想) + log(市場)」で直すと、市場の係数が 0.9 近くで予想の係数が 0.2 に満たず、買える組がほぼ残らなかった。
- 一方で、馬ごとの確率（単勝・複勝）は当たり具合が合っていて、◎ の単勝と 6番人気以下の複勝は年をまたいで 100% を超えていた。つまり、**馬の強さの情報はあるのに、組にする段階で失われていた**。

## 2. 作り方

### 2-1. 1着・2着・3着を分けた条件つきロジット（`PositionModel`）

| 着 | 何の中で選ぶか | 特徴量（対数） |
|---|---|---|
| 1着 | レースの全頭（softmax） | 1着の確率（LightGBM・CatBoost を分ける）、単勝の支持率、3連単の票で1着の割合、馬単の票で1着の割合、3連複の票で含まれる割合、複勝オッズの逆数 |
| 2着 | 1着 a を除いた馬 | 1着の確率、3着以内の確率（LightGBM・CatBoost）、単勝の支持率、a との対の票（3連単の条件つき・馬単 a→b・3連複で a,b を含む）、複勝オッズの逆数 |
| 3着 | 1着 a・2着 b を除いた馬 | 1着の確率、3着以内の確率（同上）、単勝の支持率、a,b との組の票（3連単の条件つき・3連複 {a,b,c}）、複勝オッズの逆数 |

- 学ぶときは実際の 1着・2着（同着のレースは外す）で条件を付け、予測は全部の (a, b) について softmax を出す。組の確率は P(a) × P(b | a) × P(c | a, b)。レース内の softmax なので、票の割合はレース内で共通の定数（合計で割ること）を省ける（`PoolTablesBuilder`）。
- 係数は外部ライブラリを使わずニュートン法で求める（`ConditionalLogit`）。
- LightGBM と CatBoost を分けるのは、2つのモデルの食い違いが「どれだけ当てになるか」を表すため（印の成績の「2モデル一致」と同じ考え）。
- 馬単・3連複・複勝の票を足すかは `--trifecta-only` で切り替えられる。足した方がワイド・枠連・馬単・3連単（10〜200倍）で良く、3連単の 100倍以下はわずかに下がる。

### 2-2. 券種ごとの確率と期待値（`TicketProbabilities`・`TicketPlan`）

- 3連単の全部の組の確率を足し合わせて、馬単（a→b の組の和）・単勝（a が1着の和）・馬連（両方向の和）・3連複（6通りの和）・複勝（含む組の和）・ワイド（2頭を含む組の和）・枠連（馬連を枠に写す）の確率にする。
- 期待値は 直した確率 × その券種の確定オッズ（複勝・ワイドはオッズの幅の真ん中）。オッズの帯と期待値の線で買う（点数の上限は付けない。上限を付けて期待値の高い順に残すと、高く出すぎた組に偏って下がる）。

### 2-3. 確かめ方（結果を見る前に決めた）

- 対象は 2024-01-01 以降の 11頭以上のレース（地方の主戦場。頭数を問わないと 3連単の 2026年が 100% を割る）。全頭の予想は 2023年前半までで学んだ当日の予測。
- **入れ替え**（既定）: 各年を、残りの 2年で当てはめた係数で評価する（3年とも未見）。**前の年**: 2024年で当てはめて 2025年、2024〜2025年で 2026年。どちらでも向きが同じことを見る。
- 採用の基準は docs/03 の 4. と同じ（年ごとに 100% 超、最高の1点を除いても 100% に近い、開催日のブートストラップの 90% の幅）。加えて、全券種をまとめた成績で月ごとの損益を見る（安定して勝てるか）。
- 的中の実際÷見込み（当たった点数 ÷ 確率の合計）が期待値の帯ごとに 1 に近いこと（組の確率が当たり具合と合っていること）。

## 3. 分かったこと（数値は `reports/地方の万馬券/全券種の買い方.md`・`-前の年`・`-3連単の票だけ`）

- **組の確率が当たり具合と合う。** 期待値 0.5〜1.0 の帯で的中の実際÷見込みが 1.0 前後、1.0〜1.1 の帯でも 0.9〜1.0。Harville の式では 0.6〜0.8 だった。1着の係数は全頭の予想の確率が 1 を超え（予想が言うより鋭い）、単勝の支持率と 3連単の票は負（予想を見たうえでは市場は買われすぎている方向）。
- **市場の偏り。** どの券種も、組のオッズが低い帯ほどべた買いの回収率が高く（控除率の見当に近い）、高い帯ほど低い（10万馬券の帯は半分以下）。穴の組は市場が買いすぎているので、期待値で選んでも高い帯ほど届きにくい。オッズの帯で絞るのはこのため。
- **券種ごと（入れ替え）。** 単勝（30倍以下）・複勝（20倍以下）・枠連（全部）・ワイド（50倍以下）・馬単（50倍以下・期待値 1.05 以上）・3連単（10〜200倍・期待値 1.05 以上。100倍以下・期待値 1.0 以上も 3連単の票だけなら 3年とも超える）は 3年とも 100% を超える。馬連（20倍以下）・3連複（20〜300倍）は 1年か 2年が 100% を割る。
- **前の年だけで当てはめても向きは同じ**（`全券種の買い方-前の年.md`）。2024年だけで当てはめた 2025年は、採った 6券種がどれも 100% を超えるが 3連単はぎりぎりで、全券種の合計の 90% の幅の下がちょうど 100%。2年で当てはめた 2026年は入れ替えと同じ。当てはめる年は多いほど安定する（本番は全部の年で当てはめる）。
- **3連単の票だけ**（`全券種の買い方-3連単の票だけ.md`）だと、3連単（10〜200倍）と馬単が 1年ずつ 100% を割り、全券種の合計も下がる。馬単・3連複・複勝の票を足す意味はここにある。
- **全券種をまとめると**、年ごとの回収率は 3年とも 100% を超え、90% の幅の下も 100% を超える。月ごとの損益は大半の月で正。1日の投資は数万円（点数が多いのは複勝・ワイド・枠連）。
- **3連単の万馬券。** 10〜200倍の帯には 1万〜2万円の払戻が含まれ、万馬券の的中が年に 100本前後ある。10万馬券（1,000倍以上）は市場の買いすぎが大きく、この方法でも 100% にならない。
- 馬連・3連複が届かないのは、組の確率を「その券種の市場で直し直す」（条件つきロジット）をしても変わらない（係数は予想 1.0・市場 0 で、直す余地が無い）。情報は市場と同じで、上乗せが無い。

## 4. 採ったことと、採らなかったこと

| 項目 | 内容 |
|---|---|
| 採った | 1着・2着・3着を分けた条件つきロジット（馬単・3連複・複勝の票も足す）。買い方は `ticket_plan.py` の `DEFAULT_PLANS`（単勝 30倍以下・複勝 20倍以下・枠連 全部・ワイド 50倍以下・馬単 50倍以下 1.05・馬連 20倍以下・3連複 20〜300倍・3連単 10〜200倍 1.05。どれも期待値 1.0 以上） |
| 採らなかった | 点数の上限（期待値の高い順に残す）、「組の確率をその券種の市場で直し直す」（係数が 1・0 で変わらない）、頭数を問わない対象、予想と市場の食い違いの二乗の特徴量（向きは同じで安定しない） |
| 残っている | 馬連・3連複の単体の 100% 超（今の全頭の予想の情報では届かない。全券種の合計には入れて見る）。本番（今週の予想の地方）への取り込みは別の作業 |

## 5. 本番に入れるときの注意

- 係数は 2024〜2026年の全部で当てはめ直して使う（評価は入れ替えだが、本番は全部の年）。全頭の予想のモデルを学び直したら（鋭さが変わるので）係数も当てはめ直す。
- 確定オッズ前提（発走 10分前のオッズ ≒ 確定オッズ）。枠連・馬単の票は小さいので、1点 100円の前提を超えて買うとオッズが動く。
- 票の見立て（3連単・馬単・3連複・複勝の全部の組のオッズ）が要るので、当日の速報のオッズをそろえてから出す。
