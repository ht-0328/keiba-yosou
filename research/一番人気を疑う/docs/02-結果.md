# 02 結果

**この文書は、分かったことと、これからを書く。** 数値は Git の対象外の `reports/一番人気を疑う/結果.md`（作り方ごとの表・条件ごとの表・◎の確率の帯）と
`reports/一番人気を疑う/締め切り前での確かめ.md` にある。表の見方は [prompts/結果の見方.md](../prompts/結果の見方.md)。

## 結論

**オッズを使わない予想（馬の力の材料だけ）では、◎が1番人気より多く3着以内に来るところまでは届かなかった（2026-09-29）。**
材料とモデルの作りを直して、今の予想の木曜版より◎の3着以内率を大きく上げられたが、7つの区切りのどれでも1番人気を下回った。

**1番人気を「うまく疑えた」のは、単勝以外の券種（3連単・馬連など）のオッズを材料にしたときだけだった。**
単勝の1番人気でも、ほかの券種ではそれほど買われていない馬がいる。そういう馬を疑うと、疑ったレースで◎のほうがよく来た。
ただし、これは人気（市場）を材料にした疑い方で、馬の力だけで疑ったものではない。

## 1. 今の予想の◎（出発点）

| 版 | 分かったこと |
|---|---|
| 単勝オッズを使う版（前日・当日） | ◎はほとんどのレースで1番人気と同じ馬だった。3着以内率も1番人気とほぼ同じ。オッズを強く信じていて、ほとんど疑っていない |
| オッズを使わない版（木曜） | 半数近くのレースで1番人気を疑っていたが、疑ったレースでは、疑われた1番人気のほうがはっきりよく来た。全体でも1番人気を大きく下回った |

## 2. どこで疑いを外していたか

- **条件で分けても、ほとんどどこでも一様に外していた。** 特定の条件だけで負けているのではなく、全体に情報が足りない。
- **いちばん負けていたのは新馬戦。** 過去走が無く、材料がほとんど無い。市場は、調教の評判・血統・厩舎の話など、手元に無い情報を持っている。
- **今の予想は、強く疑ったときも弱く疑ったときも、当たり方が変わらなかった。** 疑いの強さが当たりにつながっていない。
  §3 で直した予想（木曜の197個の材料）では、いちばん強く疑った4分の1のレースだけ、◎と1番人気がほぼ互角になった。
- 外したレースをいくつか取り出して並べると、予想が「前走で人気だった」「近走の着順が良い」「騎手の成績が良い」馬を◎にし、
  人（市場）が「若くて上り調子」「クラスが下がった」「調教の時計が速い」馬を1番人気にしていた例があった（数レースを見ただけで、数えてはいない）。

## 3. 何を直して、どれだけ近づいたか

| 直したこと | 効き目 |
|---|---|
| 今の予想の材料に、レース内で比べた値を足す | 少し良くなった |
| 今の予想の材料に、能力指数・市場に対する成績・当日の馬場傾向を足す | 少し良くなった |
| **研究「馬の力と展開でオッズに勝つ」の197個の材料に替え、2012年から学習する** | **大きく良くなった。** 木曜の時点で使える材料だけでも、今の予想の木曜版と1番人気との差の半分以上を埋めた |
| 学習の始まりを 2012年から 2017年に遅らせる | 少し悪くなった（長い期間で学ぶほうが良い） |
| 木を小さくする・前走の人気を足す・マイニング予想を足す・セリの価格を足す | ほとんど変わらない |
| CatBoost で学習する | LightGBM より少し良く、試した中でいちばん1番人気に近づいた。2つの平均は、その間 |
| 1レースの中の順位を学ぶ（lambdarank） | 良くならない |

197個の材料のまとまりを1つずつ外すと、どれを外しても少し悪くなった。下がり幅が大きい順に、
調教、騎手・調教師の成績、スピード指数・展開と位置・馬主と生産者と母の成績（この3つは同じくらい）、相手の強さ、レース内の比較、血統。
**1つの材料が効いているのではなく、たくさんの材料が少しずつ効いている。** 今の予想に移すなら、まとめて移す必要がある。

それでも、どの作り方も、7つの区切りのうち6つ以上で1番人気を下回った。

## 4. オッズを見なくても「◎が堅いレース」は見分けられる

オッズを使わない予想でも、◎の確率が高い帯ほど◎はよく3着以内に来て、いちばん高い帯（0.8 以上。レースの数は少ない）では、
同じレースの1番人気と同じくらい来た。木曜の時点の材料だけでも同じだった。予想が1番人気に負けているのは、◎の確率が低い（予想が迷っている）レースである。
「◎が堅いレースだけに印を付ける」使い方なら、オッズを見ずにそのレースを選べる。

## 5. オッズを使う作り方との比べ

| 作り方 | 分かったこと |
|---|---|
| 単勝オッズを材料にする（今の予想の当日版） | ◎は1番人気とほぼ同じ |
| **＋ 券種ごとのオッズから見た支持** | **◎が1番人気を上回った（7つの区切りすべて）。** 疑ったレースで、◎のほうがはっきりよく来た |
| ＋ 券種の支持を、締め切り前のオッズで（単勝・複勝・馬連だけ。過去1年） | 上回る幅は小さくなったが、その時点の1番人気よりは多く来た |

3連単・馬単・3連複・ワイドは、締め切り前の値が過去に無く、確かめられていない。

## 6. これから

どちらに進むかは、利用者が決める（2026-09-29 に報告）。**2026-10-01 に、利用者が「両方移す」と決め、1 と 2 を予想「近走と適性から3着以内を予想」に移した**（下の「移した」）。

1. **馬の力だけで予想する（木曜版）を、197個の材料で作り直す。** ◎は今よりはっきり良くなるが、1番人気には届かない。
   材料の多く（スピード指数・展開・相手の強さ・馬主と生産者と母の成績・調教の集計）は、今の予想のパッケージに無いので、移す作業が大きい。
2. **当日版に、券種ごとのオッズから見た支持を足す。** ◎が1番人気を上回る。人気を材料にする疑い方になる。
   予想する時点の全券種の締め切り前のオッズは、jvdata-store の速報オッズ（`0B30`）で取れる。
3. 手元に無い情報（パドック・外厩・厩舎の話など）を取れるか調べる。新馬戦の差が大きいのは、この情報が無いためと考えている。

### 移した（2026-10-01）

- **1 は、木曜と前日のモデルに移した。** 197個の材料とセリの価格を、まだ走っていないレースにも付けられる形で
  `src/yosou/shared/feature/ability/` に移した（予想の設計書 `docs/design/近走と適性から3着以内を予想/` の 09 の M）。
  木曜は M だけ、前日は M に単勝オッズの材料（J）を足し、オッズから作った基準を出発点にして学ぶ。
- **2 は、当日のモデルに移した。** 券種ごとのオッズから見た支持の6個を足した（同じ設計書の 09 の N）。券種のオッズが無いレースは、
  支持を使わないモデルで予測する（同じ設計書の 06 の図3）。
- **確かめた結果。** 予想のパッケージで作った学習データで、研究「既存モデルの改善」と同じ7つの区切りで、時点ごとに今の予想と比べた
  （入口 `port_check.py`。数値は `reports/一番人気を疑う/移したあとの確かめ/結果.md`）。

| 時点 | 今の予想と比べた確率の誤差（ログ損失） | ◎と1番人気 |
|---|---|---|
| 木曜 | 7つすべての区切りで小さく、差も大きい | ◎の3着以内率は今の木曜版より上がった。1番人気にはまだ届かない（研究の §3 と同じ傾向） |
| 前日 | 7つすべての区切りで小さい | ◎が7つすべての区切りで1番人気を上回った（今の前日版より上回る区切りが増えた） |
| 当日 | 7つすべての区切りで小さい | ◎が7つすべての区切りで1番人気を上回った。疑ったレースで◎のほうがよく来た（研究の §5 と同じ） |

3つの時点とも、研究「既存モデルの改善」と同じ採用の基準（7つのうち 5つ以上で小さく、全期間でも小さい）を満たしたので、全部採用した。
前日に 197個の材料を使うことは、この研究では試していなかった。移すときに比べて、前日でも今の材料より良かったので使った。
- **残課題。** 当日に 197個の材料を使う作り方は比べていない。券種の支持は確定オッズで確かめたもので、締め切り前のオッズ（3連単・馬単・
  3連複・ワイド）での確かめは、これからのレースで貯めてから行う（§5）。3（手元に無い情報）は**調べない**（2026-10-02 利用者の判断）。パドックは発走の直前にしか分からず、直前のデータで予想する仕組みは作らないと決めている。外厩は JV-Data に無く、別のサイトから自動で取る仕組みが要るため。
