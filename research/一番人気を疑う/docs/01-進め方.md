# 01 進め方

**この文書は、何を・どの順で・どう確かめたかを書く。** 言葉の意味は [README](../README.md) の表にある。

## 1. 物差し

- **比べるのは、◎の3着以内率と、同じレースの1番人気の3着以内率。** 7つの区切りのテスト期間（2023年1月〜2026年9月）を合わせて比べ、区切りごとにも勝ち負けを数える。
- **「疑ったレース」だけでも比べる。** ◎が1番人気と同じ馬のレースでは、どちらも同じ結果になる。差がつくのは疑ったレースだけなので、そこで◎と疑われた1番人気のどちらがよく来たかを見る。
- 1番人気は、確定の単勝オッズで決める（締め切り後の値）。オッズを使う作り方を締め切り前のオッズで確かめるときは、「その時点の1番人気」とも比べる（§4）。

## 2. 手順

| 順 | やったこと | 目的 |
|---|---|---|
| 1 | 今の予想の材料で学習し直し、◎と1番人気を比べた | 出発点を測る |
| 2 | 疑ったレースを、クラス・芝ダ・1番人気の単勝オッズ・キャリア・◎の人気・確信の強さで分けた | どこで疑いが外れているかを探す |
| 3 | 外したレースを取り出し、◎と1番人気の材料を並べて見た | 人がなぜその馬を1番人気にし、予想がなぜ別の馬を選んだかを見る |
| 4 | 材料とモデルの作りを変えて比べた（`analysis/experiments.py` の一覧） | 疑いを当てられるようにする |
| 5 | 効いた材料のまとまりを1つずつ外した | どの材料が効いているかを知る（今の予想に移す順を決める） |
| 6 | オッズを使う作り方（単勝オッズ・券種のオッズ）とも比べた | オッズを使うと疑いを当てられるかを知る |
| 7 | 券種のオッズの材料を、締め切り前のオッズで確かめた（`pre_deadline_check.py`） | 確定オッズでの結果が、実際に予想する時点でも残るかを知る |

## 3. 試した作り方

`analysis/experiments.py` の一覧のとおり。大きく3つに分かれる。

- **今の予想の材料**（研究「既存モデルの改善」の表。学習は 2017年から）: 木曜版・当日版からオッズを外したもの・木を小さくしたもの・レース内の比較を足したもの・能力指数などを足したもの。
- **オッズを使わない197個の材料**（研究「馬の力と展開でオッズに勝つ」の表。学習は 2012年から）: そのまま・木を小さく・セリの価格・マイニング予想・前走の人気を足す・CatBoost・2つの平均。
- **木曜の時点の197個の材料**: 学習の始まりを変えたもの・材料のまとまりを1つずつ外したもの。

このほかに、調査の途中で、1レースの中の順位を学ぶ学び方（lambdarank）も試したが、二値分類より良くならなかったので一覧には残していない。

## 4. オッズを使う作り方との比べ方

オッズを使う作り方の予測は、研究「既存モデルの改善」が保存したもの（`reports/既存モデルの改善/predictions/`）をそのまま使う。
券種のオッズの材料が締め切り前でも効くかは、過去の締め切り前の断面がある単勝・複勝・馬連だけで確かめる（`pre_deadline_check.py`）。
3連単・馬単・3連複・ワイドは、締め切り前の値が過去に無いので、これからのレースで貯めないと確かめられない。

## 5. 期間の使い方

作り方の比べ合いは、研究「既存モデルの改善」と同じ7つの区切りのテスト期間で行った。どの作り方も、テスト期間の結果で
ハイパーパラメータや線を決めてはいない（木の本数は検証期間で決めている）。ただし、7つの区切りは、これまでの研究でも何度も見ている。
今の予想に移す作り方を決めたあとは、これからのレースで確かめる。
