# 02 結果

**この文書は、手順ごとの結果と採否を書く。** 数値は Git の対象外の `reports/全レース全券種の買い方/` にあり、ここには書かない（満たした・満たさない と読み方だけ）。
手順・型の候補・選び方・採用の基準は [01-進め方.md](01-進め方.md)。

## 0. ランクの決め方が3回変わったこと

セルの1つ目の軸（レースのランク）は、利用者とのやりとりで次のように変わった。前の定義での結果は `reports/全レース全券種の買い方/3着以内で測ったとき/`・`1着の確率で測ったとき/` に残してあるが、採否には使わない。

| 順 | ランクの定義 | 変えた理由 |
|---|---|---|
| 1 | ◎ の3着以内の確率の等級（S 75% 以上…） | 利用者「的中率 45% は B」。等級は ◎ の単勝が当たるかで測ってほしい |
| 2 | ◎ の1着の確率の等級（同じ線） | 的中率はランクの順に上がるが、回収率は上がらない（当たりやすい馬ほど単勝が安い）。利用者「ランクが高いほど的中率と回収率が高くなるように。S・A・B・C は的中率でなくてよい」 |
| 3（最終） | **◎ランク** = ◎ の1着の確率 ＋ 単勝の期待値 − 1 の点数（S 0.35 以上・A 0.15 以上・B 0 以上・C 0 未満） | 確率と期待値を足すと、2019〜2026年で単勝・複勝とも的中率と回収率がランクの順に上がる |

◎ランクの線は、2015〜2018年の当日の予想で ◎ の単勝・複勝のべた買いを数え、的中率と回収率がランクの順に上がる区切りのよい値から選んだ（候補 B 0／A 0.1・0.15／S 0.25〜0.35）。
2019〜2026年で確かめると、◎ の単勝のべた買いは C → S の順に回収率が上がり、B・A・S は 100% 前後から 100% 超え、C は 100% を割る。複勝は S だけ 100% を超える。
的中率（勝率・複勝率）もランクの順に上がる。これが設計書「買うレースと買い目を決める」03 の 5 の ◎ランクの根拠。
前日のモデル（道具「印の成績」の既定。2023〜2026年のテスト期間）で同じ表13 を出すと、勝率・複勝率はランクの順に上がるが、単勝・複勝の回収率は S・A・B の差が小さく C だけ低い。
回収率の差がはっきり出るのは当日のモデル（確定の券種オッズを材料に持つ）で、前日のモデルでは ◎ランクは「当たりやすさ」の目安として読む（`reports/印の成績/◎ランク/`）。

## 1. 材料（手順2）

- 配当率: 荒れ具合の予想（当日）を半年の区切りごとに学び直し（学習の始まりは 2012年、検証は直前の半年）、2015年前半〜2026年の区切りを予測した（`配当率/`）。
  2015年の区切りは学習が3年ぶんしか無い。
- 等級: 2015〜2026年の当日の予想の全レースに、◎ランクと配当率の等級が付いた（`等級.parquet`。配当率の無いレースは無かった）。
  ◎ランクは B・A が多く、S は 1割弱。配当率は中央値が 6割ほどで、等級は A・B が多く、C は少ない。◎ランク S × 配当率 S のセルも数百レースある。
- 比べる相手: 今の印の買い目（08 の 2 の形）を全レースで買ったものを、道具「印の成績」の買い目の CSV（研究「レースの種類ごとの買い方」が 2015年からの予測で回したもの）から
  開催日ごとにまとめた（`比べる相手.parquet`）。その CSV の複勝は、当時の決まり（期待値 1.25 以上）のもの。

## 2. 事例の読み方（手順3）

`事例.md`（セルごとの決着の型）から読めること。

- ◎ランクは ◎ の着順に効く。S では ◎ が1着になるレースが4割ほど、C では ◎ が4着以下のレースが8割ある。
- 配当率の等級は、3着以内に来る馬の「位置」（◎ と消を除いた確率の順）に効く。配当率 C（固そう）のセルでは、3着以内の馬の位置の平均が 2 前後で、
  ◎○▲ だけで決まるレースが多い。配当率 S（荒れそう）のセルでは、位置 4 以下（○▲△ より下）の馬が3着以内に入る割合が 4〜6割あり、無印の馬が1頭は入るレースが半分を超える。
- どのセルでも、消（危険な人気馬）が3着以内に来るレースが 2〜3割ある。型は消を軸にも相手にも入れないので、この分は取りこぼす（今の買い方と同じ）。
- 読み方の結論: ◎ランクで軸の頭数を、配当率の等級で相手の広さを変えるのは筋が通っている。配当率 S のセルは相手を広く、C のセルは ◎○▲ に絞るのが決着の型に合う。
  この表は候補を絞るためには使わず、選び方（docs/01 の 5）は全候補から行う。

## 3. 候補の数え上げと選んだ型（手順4）

候補を 2015〜2026年の全レースで数え上げ（`候補/<券種>.npz`）、2015〜2018年だけでセルごとに選んだ（`選んだ型-<n>回目.md`・`.json`、候補ごとの成績は `候補/<券種>-成績.csv`）。

- 最初の数え上げは、相手の候補に「全頭」を入れ、点数の上限も無かった。相手「全頭」で線の無い型が選ばれたセルでは、1レースの点数が数十〜百点を超えた。
  利用者の決定で、**全頭に流す候補は外し（予想が馬を選ぶ）、1レースに使う額は最大 1万円（1券種 12点まで）にした。** この数え上げの結果は使っていない。
- 確率の線で相手を決める型で、相手が券種の馬の数に足りないレース（◎ランク C のレースなど）に買い目が無くなる誤りがあり、相手が足りないレースでは確率の順に券種の馬の数まで相手にするよう直した（docs/01 の 4）。
- 選んだ型の向き: 配当率 S・A（荒れそう）のセルでは相手が広い型（6頭・確率 25% 以上の馬）が、配当率 B・C（固そう）のセルでは ◎ か ◎○ の軸に相手 2頭の型が選ばれやすい。
  期待値の線（1.0・1.2）が付いた型が半分ほどのセルで選ばれ、そのときは 1レース 1〜2点になる。
- 小さいセル（配当率 C のセルの多く。レースが数百以下）は当たりが 30 に届かず、全候補から選んだ（「当たり不足」）。これらのセルの型は偶然の影響が大きい。

## 4. 2019〜2026年での確かめ（手順5）

### 1回目（上限 12点の型だけ。全レースを同じ形で買う）

**枠連だけが採用の基準を満たし、ほかの 7券種と合計は満たさなかった**（`確かめ-1回目.md`。◎ランクごとは `ランクごと-1回目.md`）。

- 3連単は回収率が 100% を超え、100% 超えの年も 8年中 6年あったが、90% の幅の下の端が 100% に届かなかった。単勝・ワイドは 95% 前後、馬単・複勝も 95% 前後、馬連は 9割強、3連複は 9割弱。
- ◎ランクごとに見ると、**単勝は S・A・B が 100% 以上で C だけ 100% を割る（的中率も S → C の順に下がる）。** 枠連はどのランクでも 100% を超える。
  3連単は S・A・B で 100% を超え、C が引き下げている。複勝は S だけ 100% 超え。馬連・ワイド・3連複はどのランクでも届かない。
- 比べる相手（今の印の買い目を全レースで買ったもの）と比べると、3連単・馬単・ワイドは同じか少し良く、馬連・3連複はほぼ同じ。複勝は比べる相手（期待値で選ぶ）のほうが高い。

### 2回目（過去に損だったセルは 1点に落とす）

docs/01 の 7 の決まり（選ぶ期間で下の端が 100% に届かないセルは、同じ型の上限 1点）で選び直して確かめた（`確かめ-2回目.md`・`ランクごと-2回目.md`）。

- **枠連が満たした。** ほかは、単勝・馬単が回収率 100% を超えたが下の端が届かず、ワイド・3連複が 100% 弱、複勝・馬連が 95% 前後、3連単は 1点に落とすと 9割に下がった。合計は 100% 弱。
- ◎ランク C のセルの負けが、どの券種でも合計を引き下げる。全レースを買う前提では、損なセルを「少なく買う」ことはできても「買わない」ことはできない。

### 3回目（◎ が 2倍以下のレースは単勝・複勝を買わず、馬単・3連単は ◎ 頭固定）

docs/01 の 8 の決まりで、◎ が 2倍以下のレースを別のセル（`<ランク>/2倍以下`）にし、選び直して確かめた（`確かめ-3回目.md`・`ランクごと-3回目.md`）。

- **枠連が満たした。** 単勝は 2倍以下を外して回収率が 100% を少し超え、◎ランク S で 115% ほどに上がったが、90% の幅の下の端は届かない。馬単も 100% を超えたが下の端が届かない。
  複勝・馬連・ワイド・3連複は 95〜99%、3連単は 9割。合計は 100% 弱。
- 2倍以下のセルの馬単・3連単は、選ぶ期間（2015〜2018年。レースが数百）で下の端が 100% に届かず、2回目の決まりで 1点に落ちた。確かめる期間では ◎ランク S の 3連単・馬単が 100% を大きく超えており、
  利用者の案（2倍以下は単勝でなく馬単・3連単で ◎ 頭固定）の向きは合っているが、レースが少なく、基準では「偶然と区別できない」。
- ◎ランク C のレース（◎ の期待値が 1 を切る）の負けが合計を引き下げるのは 1・2回目と同じ。

## 5. 採否

- **◎ランク（点数）: 採用。** 今週の予想の目安を、◎ランク（S・A・B・C）・的中率（◎ の1着の確率。% だけ）・配当率の等級にした（設計書 03 の 5・09 の 17）。
  ランクが高いほど ◎ の単勝・複勝のべた買いの的中率と回収率が上がり、単勝は S・A・B で 100% 以上。道具「印の成績」の表13 で、モデルを直すたびに確かめる。
- **枠連: 採用の候補。** 全レースを買う前提で、1〜3回目とも基準を満たした（回収率と下の端が 100% 超え、100% 超えの年が 8年中 5〜6年）。どの ◎ランクでも 100% を超える。
  セルごとの型は `選んだ型-1回目.md`。本番に入れるかは利用者の判断（今の枠連の買い方は、◎の期待値 1.00 以上のレースに絞って買う形）。
- **ほかの 7券種: 全レースを買う形では採用しない。** 3連単・単勝・馬単は ◎ランク S・A・B では 100% を超えるが、C を含めて全レースを買うと基準に届かない（3回目の「2倍以下は単複を買わない」でも同じ）。
  これらの券種で 100% を超えているのは、レースと組を絞る今の買い方（設計書 08 の 2）で、全レースを買う形とは両立しない。◎ランク C のレースを買わない形にするなら、それはレースを絞る買い方になる。
