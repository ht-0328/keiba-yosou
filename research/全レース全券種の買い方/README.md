# 全レース全券種の買い方

**何をする研究か。** 全レースを買い（レースを選んで見送らない）、1レースごとに 8券種（単勝・複勝・枠連・馬連・ワイド・馬単・3連複・3連単）を
買う前提で、レースの ◎ランク（◎ の1着の確率 ＋ 単勝の期待値 − 1 の点数の S・A・B・C）と配当率（配当が中荒れ以上になる確率）の等級ごとに買い目の形（軸・相手の広さ・点数）を変え、
券種ごとに回収率 100% 超えになる買い方を探す。

**なぜ始めたか。** 利用者の依頼「全レースを買って、全券種を購入して、回収率を 100% 超えにしてほしい。的中率が S なら ◎ を軸にして固定し、
低いなら 1列目 ◎○▲・2列目 ◎○▲・3列目を的中率の高い馬に全部流す、というイメージ」（2026-10-25）。
今の買い方は、券種ごとにレースと組を絞って 100% を超えている（研究「レースの種類ごとの買い方」）。全レースを買うと、どの券種も合計は 100% に届いていない
（設計書「近走と適性から3着以内を予想」の 16 の 6）ので、等級ごとに形を変えて届くかを確かめる。

## 言葉

| 言葉 | 意味 | 例 |
|---|---|---|
| ◎ランク | ◎ の1着の確率 ＋ 単勝の期待値 − 1 の点数を S 0.35 以上・A 0.15 以上・B 0 以上・C 0 未満にしたもの（設計書「買うレースと買い目を決める」03 の 5。利用者の決定「ランクが高いほど的中率と回収率が高くなるように」） | ◎ランク A |
| 配当率の等級 | 荒れ具合の予想（当日）の4券種の「中荒れ以上の確率」の平均を同じ線で等級にしたもの。過去のレースには、区切りごとに学び直した予測を当てる（手順2） | 配当率 A |
| セル | 券種 × ◎ランク × 配当率の等級 の1つ | 3連単 × ◎ランク B × 配当率 S |
| 軸（K） | 買い目の1列目に置く馬。◎ だけ、◎○、◎○▲ のどれか（消は入れない） | ◎○ |
| 相手（N） | 軸以外で買い目に入れる馬。◎・消を除いた3着以内の確率の高い順に軸の次から N 頭か、3着以内の確率が線以上の馬全部 | 相手 4頭・確率 25% 以上の馬 |
| 型 | 券種ごとの買い目の作り方（軸・相手・2列目の置き方・期待値の線）。[docs/01](docs/01-進め方.md) の 4 | ◎ 1頭軸 − 相手 4頭 の流し |
| 区切り | 半年ごとの区切り（道具「印の成績」と同じ名前。2015年前半 〜 2026年） | 2019年後半 |
| 組の表 | 研究「複勝以外の回収率100超」が作った、2015〜2026年の当日の予想の券種ごとの全部の組（確定オッズ・払戻・印・組の確率つき） | `reports/複勝以外の回収率100超/組の期待値/combos/` |
