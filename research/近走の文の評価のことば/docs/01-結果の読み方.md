# 結果の読み方と決めたこと

数値は `reports/近走の文の評価のことば/評価のことばの確かめ.md`（Git の対象外）にある。この文書には数値を書かない。

## 確かめ方

- 元DB の出走した走（2011年〜）の全部に、候補のことばと苦手の傾向を「その走より前の走」だけから付け、その走の3着以内率を数えた。
- 比べる相手は、同じ人気の馬がふつう出す3着以内率（人気から見た差。`tools/共通/popularity_expectation.py`）。人気薄に偏るなどの混ざり方の違いを除くため。
- 採用の線は、差がことばの向き（良いことばなら +、悪いことばなら −。苦手の傾向は「次も苦手」なので −）に標準誤差の 2倍以上あること。全期間と 2021年以降の両方で見る。

## 分かったこと

| 候補 | 結果 | 扱い |
|---|---|---|
| 上向き（近3走で着差が続けて縮んでいる） | 差が + で、全期間・2021年以降とも線を超えた。着順で見た版も同じ向きだが、着差の版の方が差が大きい | **採用**（着差の版） |
| 大敗続き（近2走とも着差 1.0秒以上） | 差が − で、両方の期間で線を超えた | **採用** |
| 負けて強し（前走 4着以下・着差 0.3秒以内で、不利があったか上がり3ハロン 3位以内） | 差はほぼ 0（不利あり・上がり上位のどちらで切っても同じ）。「前走 4着以下で着差が小さい」だけでも同じ | 見送り。着差と不利は走ごとの敗因の候補に事実として書くので、ことばにはしない |
| 人気薄で好走の実績（近5走に 10番人気以下で3着以内がある） | 差は + だが線に届かない | 見送り |
| 苦手の傾向（重い馬場・芝ダ・距離で、過去の成績がほかの条件よりはっきり悪い馬が、今回もその条件） | どの線（両側 2走・3走、差 0.34・0.50）でも差は 0 かわずかに +。距離は + の側で、市場の方が強く割り引いている | **出さない**。「苦手」と書くと次も走らないという予想になるが、そうなっていない |

## 決めたこと

- 予想の出力（今週の予想・全頭評価・次のレースの予想）に付ける評価のことばは、上向きと大敗続きの2つ。線は `tools/近走の文/evaluation_words.py` の定数。
- 負けた走の敗因の候補にある成績の対比（「重・不良では 0-0-0-2、良・稍重では 2-1-0-0」）は、その走までの事実の説明として残す。次走を当てる線ではないので、馬ごとの「苦手の傾向」の行は作らない。
- 線を変えたいときは、この研究の `verify_words.py` を流し直して同じ基準で見る。
