# 裏まで買うかの予想

## 1. 何を確かめたか

全レースの印の買い目は ◎ を1着に置いた組（表）だけで、◎ が2着・3着に負けると外れる。利用者からの依頼は「裏まで買ったほうがいいのかを判断する予想をしろ」
「そもそも裏を買わないといけないなら ◎ の意味ない」だった。毎回裏を買うのではなく、裏まで買ったほうがよいレースを1レースごとに見分けられるかを確かめる。
見分けられるなら、本番の予想に組み込む。

| 言葉 | 意味 |
|---|---|
| 表 | 今の印の買い目。単勝 ◎・馬連 ◎−○▲☆・馬単 ◎→○▲☆・3連単 ◎→○▲☆→○▲△☆ |
| 裏 | 1着が ○▲☆（☆ は複勝の期待値 1.25 以上だけ。表の相手と同じ）のどれかで、◎ が2着か3着 |
| 馬単の裏 | ○▲☆→◎ |
| 3連単の裏 | ○▲☆→◎→○▲△☆ と ○▲☆→○▲△☆→◎ |

予想は、オッズの動きで直した当日の予想（研究「既存モデルの改善」の `graded_race_day/odds_move-top3`・`odds_move-win`）。
買い方は本番と同じにした。どの組が当たっても同じ額が戻るように配り、当たったときに購入額の 1.1倍に届かなければ期待値の低い組から外し、
1レース 5,000円を 100円単位に分け、見込みの回収率が 100% 以上のレースだけ買う。検証は確定オッズ。

## 2. 期間

| 期間 | 使い方 |
|---|---|
| 2025年9月5日まで | 裏の当たる確率のモデルを学ぶ |
| 2025年9月6日〜2026年3月7日（前半） | 形と線を選ぶ |
| 2026年3月8日〜2026年11月14日（後半） | 確かめる（一度だけ数える） |
| 2024年9月7日〜2025年9月5日（3つ目の期間） | 2024年9月6日までで学び直したモデルで、前半で決めた線のまま確かめる |

## 3. 試した形

| 形 | 前半 | 後半 | 判断 |
|---|---|---|---|
| 毎回裏を足す | 的中率は上がったが、回収率は上がらなかった | 同じ | 入れない（◎ の意味が無くなる） |
| 決まった条件で足す（◎ の人気・◎ の1着の確率と3着以内の確率の比など） | 上がった | 今のままを下回った | 入れない |
| 裏の組の期待値で、足すと見込みの回収率が上がるなら足す | 大きく上がった | 今のままを大きく下回った | 入れない（前半に合わせすぎ） |
| 裏の当たる確率をモデルで出し、線以上なら足す | 上がった | 上がった | 馬単の裏を入れる |

## 4. 裏の当たる確率のモデル

1行 = 1レースで、裏が当たったか（1 か 0）を学ぶ。LightGBM と CatBoost の確率の平均。木の数は固定（LightGBM 400本・CatBoost 600回）。

材料は本番の予想の結果にあるものだけにした（3連単の売れ方・オッズの動き・2着以内の市場の見立ては、本番の予想の表に無いので使わない）。

| 材料 | 中身 |
|---|---|
| 裏の Harville | 今の予想の1着の確率と、市場の1着の見立て（単勝オッズから）のそれぞれから、Harville の考え方で出した裏の当たる確率 |
| ◎ | 1着・3着以内の確率、市場の1着・3着以内の見立て、人気、単勝オッズ、複勝と単勝の期待値、1着の確率 ÷ 3着以内の確率 |
| 相手 | 1着の確率の最大と合計、市場の1着の見立ての最大と合計、3着以内の確率の最大、相手の数、相手の1着の確率の最大 ÷ ◎ の1着の確率 |
| レース | 頭数 |

当たり具合（2025年9月6日からの 3,516 レース。裏が当たったのは 15.2%）:

| 確率の出し方 | ログ損失 | AUC | 予想の平均 |
|---|---|---|---|
| 今の予想の1着の確率から Harville | 0.4083 | 0.662 | 0.174 |
| 市場の1着の見立てから Harville | 0.4089 | 0.657 | 0.152 |
| モデル | 0.4071 | 0.657 | 0.153 |

今の予想の Harville は、裏を多めに見る（予想の平均 0.174 に対して実際は 0.152）。モデルは平均が実際に合い、確率の高い帯でも予想と実際が近かった。
確率 0.30 以上のレースは 7.5% で、そのレースの裏が当たったのは 37.6%。

## 5. 結果

裏の当たる確率が線以上のレースだけ裏を足し、表だけ（今のまま）と比べた。1日の儲けは、1レース 5,000円で買ったときの開催日1日あたり。

| 形 | 前半の回収率 | 後半の回収率 | 3つ目の期間の回収率 |
|---|---|---|---|
| 今のまま（表だけ） | 125.7% | 116.3% | 111.5% |
| 確率 0.25 以上 → 馬単の裏 | 126.6% | 118.0% | 112.8% |
| **確率 0.30 以上 → 馬単の裏** | **127.2%** | **118.2%** | **113.2%** |
| 確率 0.35 以上 → 馬単の裏 | 125.7% | 117.3% | 112.4% |
| 確率 0.30 以上 → 3連単の裏 | 131.4% | 116.4% | 111.8% |
| 確率 0.30 以上 → 裏全部 | 125.6% | 115.9% | 111.9% |

- 馬単の裏は、どの線でも3つの期間すべてで今のままを上回った。0.30 は前半でいちばん良く、後半と3つ目の期間でもいちばん良かった。
- 確率 0.30 以上で馬単の裏を足すと、1日の儲けは3つの期間とも 5〜15% 増え、的中率は 0.3〜0.4 ポイント上がった。買うレースの割合はほとんど変わらない。
- 3連単の裏は前半で大きく上がったが、後半と3つ目の期間ではほぼ今のままだった。

## 6. 本番に入れたもの

当日の予想で、裏の当たる確率が 0.30 以上のレースだけ、全レースの印の買い目に馬単の裏（「馬単（裏）」）を足す。表は今までどおり全レースで出す。
足した組も、ほかの組と同じ決め方で割合と金額を配る。文と通知には、裏の確率と、裏まで買うかの1行を添える。

本番の部品で作った材料は、研究で作った材料と全 22,457 レースで一致した。本番のモデルは全部のレースで学んだもの（`fit.py --save-models`）。

## 7. 気をつけること

- 裏を足すのは全レースの数パーセントで、上がる幅は回収率で 1〜2 ポイントと小さい。
- 検証は確定オッズで、本番の割合は締め切り前のオッズで決める。
- 予想の頭数は、本番では予想の表の行の数（取消の馬が残っていればその分多い）、研究では出走頭数。
