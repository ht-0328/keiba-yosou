# 裏目を買うかの予想

全レースの印の買い目（単勝 ◎・馬連 ◎−○▲☆・馬単 ◎→○▲☆・3連単 ◎→○▲☆→○▲△☆）は ◎ を1着に置いた組（表）だけで、◎ が2着・3着に負けると外れる。
この研究では、1レースごとに「裏まで買ったほうがよいか」を予想で見分けられるかを確かめ、見分けられた形を本番の予想に組み込む。
裏は「1着が ○▲☆（☆ は複勝の期待値 1.25 以上だけ）のどれかで、◎ が2着か3着」。

結論: 裏の当たる確率をモデルで出し、0.30 以上のレースだけ馬単の裏（○▲☆→◎）を足すと、線を決めた期間・確かめた期間・学びに使わなかった1年のどれでも、
今のまま（表だけ）より回収率と1日の儲けが上がった。本番に入れた（設計書「買うレースと買い目を決める」08 の 2・09 の 26）。3連単の裏は入れなかった。

## 入口

数値は Git の対象外の `reports/裏目を買うかの予想/`。DB を開くのは `marked_table.py` と `candidates.py` だけで、元DB は読むだけ（`--db` で写しを渡せる）。

| 入口 | 何をするか |
|---|---|
| `analysis/marked_table.py` | 当日の予想（オッズの動きで直したもの）の全レースに、道具「印の成績」と同じ部品で印を付けた表を書く（`marked.pkl`） |
| `fit.py --until 2025-09-06` | その日より前で裏の当たる確率のモデルを学び、その日からのレースで当たり具合（ログ損失・AUC・線以上のレースで裏が当たった割合）を出す |
| `fit.py --save-models` | 全部のレースで学び、本番のモデルの置き場所（`reports/近走と適性から3着以内を予想/models/馬単の裏/`）に書く |
| `analysis/candidates.py --start <日> --end <日>` | その期間の ◎ の入った馬単・3連単の組に、組の期待値・確定オッズ・払戻を付けて書く（`candidates_<start>_<end>.pkl`） |
| `analysis/compare.py --learn-until <日> --start <日> --end <日>` | 今のまま（表だけ）と、裏の確率が線以上のレースだけ裏を足した形を、本番と同じ配り方で比べる（`--split` で前と後に分ける） |

`compare.py` の表の買い目は、道具「印の成績」の買い目の CSV（`uv run python tools/印の成績/mark_stats.py --form graded_race_day/odds_move-top3 --win graded_race_day/odds_move-win --timing 当日 --out-dir reports/印の成績/全レースとオッズの動き/odds_move_value` の `買い目/`）を読む。

本番の部品は `tools/今週の予想/` の `reverse_exacta_features.py`（材料）・`harville_reverse.py`（Harville の裏の確率）・`reverse_exacta_model.py`（モデル）・`reverse_exacta_judge.py`（線と判定）。
研究と本番で同じ部品を使う。
