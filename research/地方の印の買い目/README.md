# 地方の印の買い目

**何をする研究か。** 地方の発走前の通知に、中央と同じく「印の買い目」（印で組む買い目と、そのレースで買うか見送るか・1点の金額）を出すために、
地方のデータで、どの買い方を・どの条件で買えば回収率 100% を超えるかを確かめる。

**なぜ始めたか。** 利用者から「中央競馬は推奨買目と印で買えるようになっているが、地方競馬も同じようにしてほしい」と言われた（2026-11-15）。
地方の印どおりの買い目を全部買うと、2024〜2026年のどの年も 100% に届かない（道具「印の成績」の `--scene 地方`）。
中央の形（印の点に組の期待値を付け、1レースの見込みの回収率で買うか決める）をそのまま持ち込まず、地方の組の確率（研究「地方の万馬券」段5 の
1着・2着・3着の条件つきロジット。本番の推奨買目と同じもの）で期待値を付け直して、地方の年ごとの成績で選ぶ。

数値（地方競馬DATA 由来の成績・配当・回収率）は Git 対象外の `reports/地方の印の買い目/` に出し、この README と docs には書かない。

## この文書で使う言葉の意味

| 言葉 | 意味 | 例（架空） |
|---|---|---|
| 印の買い目 | 印（◎○▲△☆注）で組む買い目。単勝 ◎・ワイド ◎−☆注・馬連と馬単 ◎−○▲☆・馬単の裏 ○▲☆→◎・3連複 ◎−○▲☆−○▲△☆・3連単 ◎→○▲☆→○▲△☆ | ◎ 3・○ 1・▲ 5 なら 馬単 3→1・3→5 |
| 組の確率 | 研究「地方の万馬券」段5 の条件つきロジットで出した、その組が当たる確率。各年の値は、その年を除いた年で当てはめた係数で出す（入れ替え）。その年より前の年だけで当てはめた係数でも確かめる（前の年） | |
| 期待値 | 組の確率 × 確定オッズ | 確率 5% × 30倍 = 1.5 |
| 点ごと | 期待値が線以上の点だけを 1点 100円で買う | |
| レースごと | 中央の印の買い目と同じく、レースの点を どれが当たっても払った額の 1.1倍以上戻るように 1レース 5,000円で配り、見込みの回収率（割合で重みを付けた期待値の和）が線以上のレースだけ買う | |
| 採用の基準 | 2024・2025・2026年の各年で回収率が 100% を超え、各年の最高の1点を除いても 100% 以上 | |

## フォルダの中身

| 場所 | 何があるか |
|---|---|
| `mark_tickets.py` | 入口。`--build` で印の組の表を作り、引数なしで買い方の候補の年ごとの成績を書く |
| `analysis/mark_combos.py` | 道具「印の成績」の買い目の表（1行 = 1点）から、印の買い方の組・確定オッズ・払戻を読む |
| `analysis/reverse_combos.py` | 馬単の印の組から裏の組を作る |
| `analysis/mark_table_builder.py` | 印の組に、各年を残りの年で当てはめた組の確率と期待値を付ける |
| `analysis/mark_table_store.py` | 印の組の表の置き場所 |
| `analysis/mark_plan.py` | 買い方の候補（買い方の名前・点ごとかレースごとか・線・頭数） |
| `analysis/plan_catalog.py` | 比べる買い方の一覧 |
| `analysis/plan_summary.py` | 成績（投資・払戻・回収率・最高の1点を除く回収率・的中・見込みの回収率） |
| `analysis/mark_study.py` | 流れと報告 |
| `reverse.py` | 入口。`--build-marked` で印の全頭の表を作り、引数なしで裏を足すかの比べを書く（docs/02） |
| `analysis/marked_table.py` | 道具「印の成績」の部品で、地方の全頭の予想に印を付けた全頭の表を作る（`MarkedTable`） |
| `analysis/reverse_probabilities.py` | 中央と同じ材料とモデルで、学びに使わなかった年のレースの裏の当たる確率と当たり具合を出す（`ReverseProbabilities`） |
| `analysis/reverse_study.py` | 今のままと、裏の確率が線以上のレースだけ馬単の裏を足した形の年ごとの成績（`ReverseStudy`） |
| `docs/` | 結果の読み方と結論（[01](docs/01-印の買い目の買い方.md) 印の買い目の買い方、[02](docs/02-裏を買うかの予想.md) 裏を買うかの予想） |
| `tests/` | 架空の値で部品を確かめるテスト（実DB は要らない） |
| `reports/地方の印の買い目/`（Git 対象外） | `印の組.pkl`・`印の買い目の成績.md`（入れ替え）と `印の組-前の年.pkl`・`印の買い目の成績-前の年.md`（前の年だけで当てはめた係数）、`marked.pkl`・`裏を買うかの成績[-前の年].md` |

## 動かし方

リポジトリ直下（`keiba-yosou/`）から実行する。元DB は nvdata-store の `nvdata.duckdb`（読むだけ）。先に道具「印の成績」を地方の
2024検証の予測で動かし、買い目の表（`reports/印の成績/地方/2024検証/買い目/`）を作っておく。

```bash
uv run python research/地方の印の買い目/mark_tickets.py --build   # 印の組の表を作る（30〜40分）
uv run python research/地方の印の買い目/mark_tickets.py           # 買い方の候補の年ごとの成績を書く（20分ほど）
uv run python research/地方の印の買い目/mark_tickets.py --build --protocol 前の年   # 前の年だけで当てはめた表（2025・2026年）
uv run python research/地方の印の買い目/mark_tickets.py --protocol 前の年           # その表で成績を書く
uv run python research/地方の印の買い目/reverse.py --build-marked   # 印の全頭の表を作る（元DB を読む。数分。--db で写しを渡せる）
uv run python research/地方の印の買い目/reverse.py                  # 裏を足すかの比べ（入れ替え。印の組の表が要る。数分）
uv run python research/地方の印の買い目/reverse.py --protocol 前の年  # 前の年だけで学んだ確率で
```
