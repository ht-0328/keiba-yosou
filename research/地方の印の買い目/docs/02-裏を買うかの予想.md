# 02 裏を買うかの予想（地方）

**この文書で決めること:** 中央と同じく、裏の当たる確率のモデルで確率が線以上のレースだけ、地方の印の買い目に馬単の裏（○▲☆→◎）を足すか。
数値（回収率・的中率・1日の儲け・AUC）は `reports/地方の印の買い目/裏を買うかの成績[-前の年].md`（Git 対象外）にあり、ここには載せない。

**結論: 足さない。** 地方でも裏が当たるかはある程度見分けられるが、確率の線を 0.20〜0.40 のどこに置いても、3年とも今のまま（単勝・馬単・3連単）より1日の儲けが増える線は無い。
2026年はどの線でも減る。本番の決まりは設計書「買うレースと買い目を決める」の [12](../../../docs/design/買うレースと買い目を決める/12-local-mark-tickets.md)。

## 1. なぜ確かめたか

利用者から「裏を買うかの予想も中央と同じようにやっているか」と聞かれた。中央は、裏の当たる確率が 0.30 以上のレースだけ馬単の裏を足している
（研究「裏目を買うかの予想」）。地方の印の買い目（[01](01-印の買い目の買い方.md)）は、裏をいつも足す形が基準を満たさなかったので入れていなかったが、
確率で選んで足す形は確かめていなかった。

## 2. 進め方（結果を見る前に決めたこと）

| 段 | 内容 |
|---|---|
| 裏の定義 | 1着が ○▲☆（☆ は複勝の期待値 1.25 以上だけ）のどれかで、◎ が2着か3着。中央と同じ |
| 印の全頭の表 | 道具「印の成績」の部品で、地方の全頭の予想（2023年前半までで学んだ当日の予測。`predictions-2024検証`）に印を付けた全頭の表（`MarkedTable`）。印の組の表と同じ引数（`--timing 当日 --scene 地方 --no-danger --no-upset`） |
| 材料と答え | 中央の研究「裏目を買うかの予想」と同じ部品（`race_rows`・`ReverseExactaFeatures`）で、1行 = 1レースの材料と、裏が当たったか |
| モデル | 中央の本番と同じ `ReverseExactaModel`（LightGBM と CatBoost の平均）を、各年を残りの年で（入れ替え）、またはその年より前の年だけで（前の年）学び、学びに使わなかった年のレースの確率を出す（`ReverseProbabilities`） |
| 比べ方 | 今のまま（単勝・馬単・3連単。レースごと・見込み 1.0 以上）と、確率が線（0.20・0.25・0.30・0.35・0.40）以上のレースだけ馬単の裏を足した形を、年ごとの回収率・最高の1点を除いた回収率・的中率・1日の儲けで比べる（`ReverseStudy`） |
| 採用の基準 | どの年も、回収率と1日の儲けが今のままを上回り、最高の1点を除いた回収率も 100% 以上 |

## 3. 分かったこと

- **裏の当たり具合は見分けられる。** 学びに使わなかった年の AUC は中央とほぼ同じで、予想の平均と実際に裏が当たった割合もほぼ一致する（確率の大きさも合っている）。
- **足しても儲けは増えない。** 線を低くするほど、どの年も1日の儲けが減る。線を高くすると増える年もあるが、2026年はどの線でも減り、3年とも上回る線は無い。
  前の年だけで学んだ確率でも、2026年はどの線でも減る。
- **理由。** 裏の組は配当が低く、足すと1レースの見込みの回収率が下がって、見込み 1.0 以上で買うレースが少し減る。的中率は上がるが、その分の儲けが増えない。
