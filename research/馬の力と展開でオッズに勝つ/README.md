# 馬の力と展開でオッズに勝つ

**何をする研究か。** オッズと人気を一切使わずに、馬の力（スピード指数・近走・相手の強さ）と展開（位置取り・ペース）、人（騎手・調教師・馬主・生産者）、血統、調教から1着の確率を出し、**市場（単勝オッズ）より当てる**ことを目指す。そのうえで、その確率で期待値の高い馬券を買って、回収率 100% を超える方法を探す。

**なぜ始めたか。** 研究「回収率100超」と「複勝以外の回収率100超」は、オッズから作った確率が中心だった。利用者の求めは「オッズに頼らず、馬の力や展開から予想して、オッズより当てたい」で、そのために既存のオッズを使わない予想が「何が足りなくて市場に負けているか」を突き止めて直すことを求められた（2026-09-27）。

## この文書で使う言葉の意味

| 用語 | 意味 | この研究では（架空の例） |
|---|---|---|
| ログ損失（1着） | レースごとに、勝った馬に付けた確率の −log を平均した値。小さいほど当たっている | 勝ち馬に 0.25 を付ければ 1.386 |
| 市場の勝率 | 単勝オッズの逆数を、レースで合計 1 にそろえた値。比べる相手にだけ使い、材料には入れない | 単勝 4.0倍なら、およそ 0.2 |
| 差（モデル − 市場） | モデルと市場のログ損失の差。正ならモデルが市場に負けている | 2.06 − 1.96 = 0.10 |
| ウォークフォワード | その年の2年前までで学習し、前の年で木の本数を決め、その年を予測する、を年ごとにくり返す | 2021年は 2012〜2019年で学習 |
| 作り方を選ぶ年・確かめる年 | 材料やモデルの作りは 2019〜2021年の成績だけで選ぶ。2022〜2026年は最後の確かめに取っておく | |
| 組み合わせ（Benter の方法） | モデルの勝率と市場の勝率を、重みを付けて1つにする方法。**オッズを使う**ので、オッズを使わないモデルとは分けて扱う | 勝率 ∝ exp(0.1 × log モデル + 0.9 × log 市場) |

## フォルダの中身

| 場所 | 何があるか |
|---|---|
| `extract.py` | 入口①。元DB の事実表を中間データにする |
| `experiment.py` | 入口②。材料とモデルの作りを変えて、年ごとに市場とログ損失を比べる |
| `extract_extra.py` | 入口③。調教（坂路・ウッド）・馬主・生産者・母の中間データを作る |
| `backtest.py` | 入口④。モデルの確率で全券種を期待値で買い、線を前半で決めて後半で確かめる |
| `combine.py` | 入口⑤。モデルと市場の勝率を組み合わせる（オッズを使う。別扱い） |
| `analysis/` | 材料を作る部品と、モデル・ログ損失の部品 |
| `docs/` | 進め方と、分かったこと |
| `prompts/` | 実験の見方 |
| `tests/` | 架空の値で部品を確かめるテスト |
| `reports/馬の力と展開でオッズに勝つ/`（Git 対象外） | 実測の数値と中間データ |

## 動かし方

リポジトリ直下から。スピード指数の中間データ（`reports/能力指数/cache/figures.parquet`）と、研究「回収率100超」の中間データ（`extract.py`・`extract_tickets.py`）が先に要る。

```bash
uv run python research/馬の力と展開でオッズに勝つ/extract.py
uv run python research/馬の力と展開でオッズに勝つ/extract_extra.py
uv run python research/馬の力と展開でオッズに勝つ/experiment.py --name 基本 --rebuild
uv run python research/馬の力と展開でオッズに勝つ/experiment.py --name 全年 --also-placed --leaves 7 --min-child 2000 --learning-rate 0.02 --years 2018 2019 2020 2021 2022 2023 2024 2025 2026
uv run python research/馬の力と展開でオッズに勝つ/backtest.py --predictions 全年
uv run python -m pytest -q research/馬の力と展開でオッズに勝つ
```
