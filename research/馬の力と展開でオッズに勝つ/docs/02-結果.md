# 02 結果

**この文書は、何が足りなかったか、何を直してどれだけ縮んだか、最後の確かめの結果を書く。** 数値は Git の対象外の `reports/馬の力と展開でオッズに勝つ/`（`実験/`・`検証の結果_*.md`）にある。

## 結論

**オッズを使わない予想は、材料とモデルの作りを直して市場との差を縮めたが、市場より当てるところまでは届かなかった（2026-09-27）。** その予想で全券種を期待値で買っても、確かめの年で回収率 100% を超える券種は無かった。オッズと組み合わせた場合も、100% には届かなかった。

## 1. 何が足りなかったか（手順1・2）

| 見つけたこと | 中身 |
|---|---|
| 既存の予想は、オッズを間接に使って市場に近づいていた | 「展開から着順を予想」は、当日の時点で既存の予想（オッズを出発点にするもの）を材料に入れていた。それを入れる前の、オッズを使わない形では、1着のログ損失が市場より大きく劣っていた |
| 市場との差は、どの条件でもほぼ同じ | クラス・芝ダ・頭数のどれで分けても、差はおおむね同じだった。特定の条件だけで負けているのではなく、全体に情報が足りない |
| いちばん差が大きいのは新馬戦 | 過去走が無く、材料がほとんど無い。市場は、調教・血統・評判など別の情報を持っている |
| 確率の当てはまりは良い | 帯ごとの予想の平均と実際の割合はほぼ一致していた。自信の強さを変える（べき乗）と、かえって悪くなった。足りないのは、馬どうしを見分ける情報である |

## 2. 何を直して、どれだけ縮んだか（手順3）

| 直したこと | 効き目 |
|---|---|
| 調教（坂路・ウッド）、馬主・生産者・母（兄弟）の成績を足す | 縮んだ。新馬戦の差がはっきり縮んだ |
| 騎手・調教師の直近の成績、騎手の格上げを足す | ほとんど変わらない |
| 展開の不利・末脚と着順のずれ・指数の伸び・枠の傾向などを足す | ほとんど変わらない |
| 順位の学習（lambdarank） | 良くならない |
| JRA-VAN のマイニング予想を足す | ほとんど変わらない |
| CatBoost と平均する | わずかに縮んだ（学習の時間は大きく延びる） |
| **木を小さくし、葉ごとの最小のサンプルを増やす** | **縮んだ。材料を足したときより大きく効いた。** 大きい木は学習データのくせまで覚えていた |

これらを合わせて、市場との差は、はじめのおよそ 4分の3 まで縮んだが、0 にはならなかった。材料を足すほど効き目が小さくなっており、手元の JV-Data から作れる材料では、ここが限界に近いと考えている。

## 3. 馬券で確かめた結果（手順4・5）

| 作り方 | 結果 |
|---|---|
| オッズを使わないモデル × 全券種（期待値で買う） | どの券種も、確かめの年で 100% を超えなかった。単勝・複勝は 100% から大きく離れていた。馬連・馬単・3連単は後半の点の回収率が 90% 前後まで来たが、幅が大きく、前半では届いていない |
| モデルと市場の組み合わせ（オッズを使う。別扱い） | 組み合わせは、市場よりわずかに当たるようになった（モデルの重みは小さい）。複勝がいちばん近かったが、100% には届かなかった |

## 4. 分かったことと、これから

- **オッズを使わない予想は、市場より当てるところまでは届かなかった。** 市場は、手元の JV-Data に無い情報（パドック・外厩・関係者の評価など）も織り込んでいると考えられる。競馬の予想で知られる Benter の報告でも、オッズを使わないモデル単独では市場に劣り、利益はモデルと市場の組み合わせから出ていた。
- **組み合わせの効き目を大きくするには、モデルが市場と違う情報を持つ必要がある。** 今のモデルの情報は、多くが市場に織り込み済みで、組み合わせの重みが小さい。
- 次にできること:
  1. 手元に無い情報（外厩・パドックなど）を取れるか調べる。
  2. 組み合わせ（オッズを使う）を前提に、モデルが市場と違う情報を持つ材料を探す。
  3. 券種ごとの市場の歪み（研究「回収率100超」の複勝）と組み合わせる。
     **確かめた（2026-10-02）。** 予想「近走と適性から3着以内を予想」の当日のモデル（券種ごとのオッズから見た支持と馬柱の材料を持つ）の
     3着以内の確率で、研究「回収率100超」と同じ複勝の買い方（期待値の線・線の選び方・1点100円・開催日単位の下限）をしても、
     回収率は 100% を超えたが、元の確率（全券種のオッズから取り出したもの）より良くはならなかった。元との平均も互角止まりだった。
     複勝の買い方の確率は元のまま。詳しくは研究「回収率100超」の [docs/04-買い方.md](../../回収率100超/docs/04-買い方.md) の 8。
