# 01 進め方

**この文書は、何をどの順で確かめたかを書く。** 言葉の意味は [../README.md](../README.md) の表を参照。

## 1. 決まり

- **オッズと人気は材料に入れない。** 前走の人気（`prev_popularity`）も入れない。単勝オッズは、比べる相手（市場の勝率）と、馬券の値段・精算にだけ使う。
- **材料は、そのレースより前に分かることだけにする。** 過去走は前日までの走、成績の数え上げは前日までの結果だけ。
- **作り方は 2019〜2021年の成績だけで選ぶ。** 2022〜2026年は最後の確かめに取っておき、作り方を選ぶのに使わない。

## 2. 手順

| 手順 | すること | 入口 |
|---|---|---|
| 1 | 既存の「展開から着順を予想」が、オッズを使わないとき、どれだけ市場に負けているかを見る | `reports/race_development/backtest/` |
| 2 | 材料をそろえた、オッズを使わない勝率のモデルを作り、条件ごとに市場との差を測って、何が足りないかを探す | `experiment.py` |
| 3 | 足りないと考えた材料・モデルの作りを1つずつ足して、差が縮むかを確かめる | `experiment.py` |
| 4 | いちばん良い作りで 2018〜2026年を予測し、全券種を期待値で買って確かめる | `backtest.py` |
| 5 | 別扱いとして、モデルと市場の勝率を組み合わせた場合も確かめる | `combine.py`・`backtest.py` |

## 3. 使った材料（手順3で足した順）

| まとまり | 中身 | 部品 |
|---|---|---|
| 馬の力 | スピード指数（前走・近5走の最高・新しさと条件の近さの重みの平均・伸び）、近5走の相対着順・着差・末脚 | `ability_features.py`・`past_run_features.py` |
| 相手の強さ | 過去のレースの出走馬の力の上位5頭の平均 | `dataset_builder.py`・`past_run_features.py` |
| 展開 | 近5走の序盤の位置・4角の位置・先頭率、レースの先頭率の合計、過去のレースのペース、展開の不利、末脚と着順のずれ | `past_run_features.py`・`dataset_builder.py` |
| 人と血統 | 騎手・調教師・父・母父・父×芝ダ・父×距離・騎手×競馬場・騎手×調教師・調教師×距離・馬主・生産者・母（兄弟）の通算の成績、騎手と調教師の直近の成績、騎手の格上げ | `track_record_rates.py`・`recent_record_rates.py` |
| 調教 | 坂路（14日・30日の本数・4F と 1F の最速・直前）、ウッド（30日の本数・5F・4F・1F の最速。2021年7月から） | `extract_extra.py` |
| 今回の条件 | 距離・頭数・クラス・馬齢・性別・斤量・馬体重と増減・近走の平均との差・枠・ハンデ戦・ブリンカー・減量騎手・所属・枠の傾向 | `dataset_builder.py` |
| レース内の位置 | 主な材料の、レース内の順位・最良との差・偏差 | `race_relative.py` |
