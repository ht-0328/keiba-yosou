# 02 結果

数値（JV-Data 由来の成績・回収率）は Git の対象外の `reports/G1の危険な人気馬のサイン/` にある（`事例.md`・`結果.md`・`印の成績のまとめ.md`）。ここには、そこから読み取れることを言葉で書く。

## まとめ

**10のサインは、どの範囲で学んでも、G1 の危険な人気馬を今より見抜けるようにはしなかった。今の本番（全レースで学ぶ・サインなし）のままにする。**

| 範囲 | サインなし | サインあり | 一言で |
|---|---|---|---|
| G1だけ | オッズだけに負ける | オッズだけに負ける | 学習に使える人気馬が少なすぎて、木がほとんど育たない。危険の線も決められず、消が1頭も付かない |
| 重賞（G1〜G3） | オッズだけと同じくらい | オッズだけと同じくらい | 数は増えるが、G1 の確率は良くならない。消はわずかしか付かない |
| 全レース | **オッズだけに合格**（今の本番） | 今の本番に負ける | サインを足すと、G1 の確率の誤差がかえって大きくなり、G1 の買い目の回収率も下がった |

## 1. 事例の表（サインごとの成績）

G1 の人気馬で、サインに当てはまる馬が、同じ人気の馬よりどれだけ負けたかを数えた（`事例.md`）。

- **はっきり効くサインは無かった。** 同じ人気の馬との差は、どのサインも数ポイント程度で、当てはまる頭数も少ない。
- 前半（2012〜2019年）と後半（2020年から）で同じ向きに負けが多かったのは、「馬場・枠の不利」「惜しい競馬を繰り返す」「急に走らなくなった」「人気薄の激走のあと」の4つ。ただし頭数が少なく、偶然と見分けられる大きさではない。
- 「G1の格がない」「重度のリピーター」は前半と後半で向きが逆になった。「距離適性の外」「普通は来ない条件」「断然人気の陰の2・3番人気」は、同じ人気の馬よりむしろ負けが少ないか、差が無かった。
- サインの数が多いほど負ける、という形にもならなかった（3つ以上の馬は、同じ人気の馬より負けが少なかった）。
- 1番人気だけで見ると、「G1の格がない」「そもそも強くない」の1番人気は負けが多かったが、頭数がごく少ない。

## 2. 確率の誤差（G1 の人気馬・2020〜2026年の7つの区切り）

`結果.md` の表1〜3。

- 採否の基準（7つの区切りのうち5つ以上でログ損失が小さく、全期間でも小さい）を「オッズだけ」に対して満たしたのは、**全レースで学ぶ・サインなし（今の本番）だけ**だった。
- **サインを足すと、どの範囲でも今の本番に勝てなかった。** 全レースで学ぶときにサインを足すと、全期間のログ損失が少し大きくなり、今の本番より小さい区切りは7つのうち3つだった。人気帯ごとでは、1番人気の確率がいちばん悪くなった。
- **G1だけで学ぶと、オッズだけにも負けた。** 学習に使える G1 の人気馬は全レースの百分の一にも満たず、LightGBM・CatBoost の木がほとんど育たず（数本〜数十本）、オッズの見立てに少し手を加えただけの確率になった。サインを足しても変わらない。
- 重賞で学ぶと、G1 だけよりは良く、オッズだけと同じくらいだが、全レースで学ぶ今の本番には届かなかった。

## 3. 印と全券種の買い目（道具「印の成績」・G1 のテスト期間のレース）

`印の成績のまとめ.md`。作り方で変わるのは消（危険な人気馬）だけで、消の馬は ◎〜注 に入らないので、印と買い目が変わる。

- **G1だけで学んだ2つは、消が1頭も付かなかった。** 危険の線は、区切りごとに検証期間（前の1年）で「危険とした馬が 30頭以上で、偶然と見分けられる差がある」ものを選ぶ決まりで、G1 の1年分（約24レース）ではこれを満たせない。印と買い目は「消を使わない」と同じになった。
- 重賞で学んだ2つも、消が付いたのは7年のうち1〜2年だけで、買い目は「消を使わない」とほとんど同じ。
- 全レースで学ぶ2つを比べると、サインを足したほうが、消にした馬の複勝率と回収率は少し低い（危険な馬を少しよく選んでいる）が、印のルールの元の買い目の合計の回収率は、今の本番より大きく下がった（ワイド・馬連・馬単・3連単で下がった）。消が変わると、◎〜注 に繰り上がる馬が変わり、買い目の当たり外れが入れ替わるためである。
- G1 は1年に約24レースしか無いので、どの作り方の回収率も 90% の幅が広く、券種ごとの差の多くは偶然の範囲である。確率の誤差の結果（サインを足すと悪くなる）と同じ向きなので、サインを足さない判断は変わらない。
- 印の成績は `--no-win`（◎ は3着以内の確率の1位）で数えた。1着の予想の予測は区切りが半年ずつで 2023年からしか無く、G1 のテスト期間（2020年から）を覆わないため。期待度と、期待値で選ぶ複勝の買い目は付かない。

## 4. なぜ効かなかったか

- **市場がサインを知っている。** サインの多くは、近走の着順・G1 の成績・距離・人気の履歴など、新聞や戦績で誰でも見られることで、G1 ではとくに多くの人が見て単勝オッズに入れている。オッズを出発点にして補正だけを学ぶ今の作りでは、オッズに入っていない分しか残らない。
- **今の材料と重なる。** 前走の人気と着順・近5走の着順・距離の変更・通算の成績・騎手と血統の市場に対する成績などは今の材料にあり、サインはその言い換えになっているところが多い。
- **G1 は数が少ない。** 1年に約24レースでは、10のサインの効き目を学ぶにも確かめるにも足りない。サインごとの差が本当にあっても、偶然と見分けられない。

## 5. 決めたこと

- 人気馬の予想（今週の予想の消）は、今の本番（全レースで学ぶ・サインなし）のままにする。G1 だけ・重賞だけで学ぶ専用のモデルは作らない。
- サインの表を作る部品（`analysis/`）は研究に残す。サインの数え方を変えて試すときは、`danger_signs.py` の線を変えて `g1_signs.py signs` からやり直す。
