# 02 公開ルールを2段にする

この文書の目的: 01 の公開ルール（回収率 110% 台）を、「全レースに参加しても 100% 超え、勝負レースだけなら 150% 超え」に近づけるために、何を試し、何を採ったかを示す。

結論: **今の1着の確率を締め切り前に分かる材料で直し（印は変えない）、直した ◎ の単勝を全レースで、直した ◎ の期待値が 1.25 以上のレースは単勝と馬単 ◎→相手3頭を勝負として買う。** 勝負は、選ぶのに使った期間・確かめる期間・10分前のオッズの1年のどれも回収率 140% 以上、全レースは全体で 100% 超え。数値は `reports/的中実績の公開ルール/walk_forward.md`。

## 1. 条件

| 条件 | 中身 |
|---|---|
| 全レース | 毎週・毎開催日に参加できる買い方で、回収率 100% 超え（利用者「100％越えっていうのは全レースとかに参加する場合って意味」） |
| 勝負 | 勝負レースだけを選んだら回収率 150% 超え（利用者「勝負レースだけを選んだら150%超えて」）。200% が目指せるなら 200% |
| 買う時点 | 01 と同じく発走10分前のオッズで決め、10分前のオッズで選んでも崩れないこと |

## 2. 確かめ方

- **年ごとの学び直し:** 確率を直すモデルは、その年より前の年（2020年から）の確定オッズの表だけで学び、その年の確率を直す。1年だけで学んだモデル（2021年）は期待値を出しすぎた（期待値 1.2 以上のレースがほかの年の3倍出た）ので、2年以上で学べる 2022年から数える。本番は 2020年からの全部で学ぶ。
- **期間:** 選ぶのに使った期間は 2022〜2023年、確かめる期間は 2024年から。10分前のオッズの1年（2025年9月から）も見る。
- **10分前の時点の表:** 単勝・複勝（最低・最高）・馬連のオッズを10分前の断面に置き換え、1着の確率は出発点（オッズから見た勝率）だけを10分前のものに差し替えた近似（01 と同じ）。3着以内の確率と事実表の列はそのまま。
- **払戻:** どの時点で選んでも、払戻は確定の払戻で数える。

## 3. 試したことと結果

| 試したこと | 結果 | 判断 |
|---|---|---|
| 今の確率のまま、全レースで ◎ をベタ買い | 回収率 100% 前後 | 土台にならない |
| 確率を直す: 券種どうしのずれ（単勝・複勝・馬連から見た率と予想の確率の比）と人気・順位・頭数 | 全レースのベタ買いが少し上がった | 採る（材料の柱） |
| 上に、レースの中身と馬の事情（事実表の数の列）を足す | さらに上がった。外すと勝負が年によって 100% を割った | 採る |
| 上に、馬単・ワイド・3連複のオッズから見た率を足す | 上がらなかった（10分前の断面も1年分無い） | 採らない |
| 上に、ほかの作りの予測7種の食い違いを足す | 上がらなかった | 採らない |
| 締め切り前1時間の単勝の動き | 遅く買われた馬は、確定の払戻で見ると回収率が低い（買われたあとのオッズで払われる）。期待値の高い馬の中では、前半と後半の半年で向きが逆 | 採らない |
| 勝負の形: 期待値の線だけ（単勝） | 線を上げると年に数十レースになり、年によって大きくぶれる | 単独では採らない |
| 勝負の形: 1開催日に期待値の上位 n レース | どの n でも年によってぶれる | 採らない |
| 勝負の形: ◎ を1着に固定した馬単・3連単・3連複（相手は直した確率の順。オッズを使わずに組む） | 馬単 ◎→相手3頭が、単勝と組み合わせて安定した | 採る |
| 確率を直すモデルの縛り（木の大きさ・1枚の葉の行数・重みの罰・学習の速さ・種を変えた平均）を5通り | 縛りが弱いと期待値の高い帯で確率を出しすぎて、確かめる期間の勝負が崩れた。葉 4枚・1枚の葉に 3,000行以上・重みの罰 100 が、どの期間でもそろった | 採る（確かめる期間も含めて見て選んだ） |
| 勝負の線（期待値 1.15〜1.35） | 1.2〜1.3 はどの期間も 125% 以上。1.25 が、選ぶのに使った期間・確かめる期間・10分前の1年の釣り合いがいちばん良い | 1.25 を採る |

本番では、発走前に分かるか怪しい事実表の列（馬場状態・馬体重の増減）と、文字の列（乗り替わり・減量）を外した。外した形で年ごとに学び直しても、成績はほぼ同じだった。

## 4. 採った決まり

| 段 | 決まり |
|---|---|
| 全レース | 当日の予想の全レースで、直した ◎（単勝 30倍以下で評価できる馬のうち、直した1着の確率 × 単勝オッズが1位）の単勝を 100円 |
| 勝負 | 直した ◎ の期待値が 1.25 以上のレースで、単勝 ◎ と、馬単 ◎→相手（◎ を除いた直した1着の確率の上位3頭）を各 100円（4点 400円） |

- 勝負は 1開催日に 1〜2レースほど（10分前のオッズの1年では 2レース強）。勝負の当たりは約8レースに1回で、馬単が当たると払戻が大きい。
- 確定オッズの年ごとでは、勝負はどの年も 130% を超えた。全レースは、全体では 100% を超えたが、1年だけ 100% を割った。

## 5. 気をつけること

- **選び方の偏り:** 確率を直すモデルの縛りの強さは、確かめる期間も含めた結果を見て5通りから選んだ。勝負の線も、周りの線と比べて選んだ。本番の成績は、表より少し下がることもありうる。
- **10分前の1年は振れが大きい:** 勝負は運が悪いほうに振れると 100% を少し割る。買うレースが少ないので、数本の当たりで年の成績が大きく変わる。
- **10分前の確率は近似:** 過去の表は確定オッズで出した予測の出発点を差し替えた近似で、本番は10分前のオッズでそのまま予測する。発走前の通知とその日の結果で、本番の成績を数え続ける。
- **学び直し:** 学習に使う予測（研究「既存モデルの改善」の `graded_race_day/odds_move`）を作り直したら、`tools/公開ルール/fit.py` でモデルを作り直す。
