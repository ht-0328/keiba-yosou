# 01 公開ルールの決め方

この文書の目的: 的中実績の公開ルール（買う決まりを先に決めて、当てはまるレースを全部数える）を、どう探して、なぜ ◎ の単勝にしたかを示す。

結論: **◎ の単勝の期待値 1.00 以上・◎ の単勝 6倍以下のレースだけ、◎ の単勝を買う。** 3つの期間（探す・確かめる・発走10分前のオッズで選んだ約1年）とも条件を満たした。数値は `reports/的中実績の公開ルール/check.md`。

## 1. 条件

| 条件 | 中身 |
|---|---|
| 回収率 | 探す期間と確かめる期間のどちらでも 110% 位以上（利用者「110%位以上じゃないと」） |
| 的中率 | レースあたり 20〜30% くらい（利用者「20~30%くらいほしい」）。当たりが年に数本では実績にならない |
| 買う時点 | 発走10分前のオッズで決める（本番の通知の時点）。10分前のオッズで選んでも崩れないこと |
| 決まりの形 | 先に決めて、当てはまるレースは全部買う。当たったレースだけを選んで見せない |

## 2. 確かめ方

- **予測:** 今の本番の当日の予想と同じ作りの、学習に使っていない期間の予測（研究「既存モデルの改善」の `graded_race_day/odds_move`）。2020〜2026年9月。
- **期間:** 決まりを選ぶのは探す期間（2020〜2022年）だけ。確かめる期間（2023〜2026年）は選んだあとに見る。年ごとの成績と、開催日を引き直したときの下の端（運が悪いほうに振れたとき）も見る。
- **10分前のオッズ:** JV-Data の時系列オッズ（途中の断面）があるのは、単勝・複勝・枠連・馬連の約1年（2025年9月から）だけ。ワイド・馬単・3連複・3連単の途中の断面は、発走前の通知が取り込み始めた 2026年10月からしか無い。
- **10分前の時点の確率:** 1着のモデルは「オッズから見た勝率のロジット」を出発点にして、そこからの上げ下げを学んでいる。過去の予測は確定オッズの出発点で出ているので、出発点だけを10分前のオッズのものに差し替えて近似した（`analysis/snapshot_probability.py`）。材料の単勝オッズそのものの違いは直らないので、近似である。
- **払戻:** どの時点で選んでも、払戻は確定の払戻で数える（締め切りのオッズで払われるため）。

## 3. 試した決まりと結果

| 決まり | 結果 | 判断 |
|---|---|---|
| 印の形（◎−○▲☆ など）の馬連・馬単・3連複に、◎ の期待値とオッズの下限を付ける | 確定オッズでは両期間とも 100% を超えるものがあったが、当たりが年に数本〜十数本。的中率 20% 以上に絞ると、どれも 100% をわずかに超える程度で、試した数の多さから偶然の範囲を出ない | 採らない |
| 全部の組（馬連・馬単・3連複）の確率（1着の確率から Harville の式）に、期待値の線・オッズの上限と、「買う組の確率の合計が線以上のレースだけ」を付ける | 馬連は確定オッズで両期間とも 110% を超え、的中率も 4割台だった。馬単・3連複は 110% に届かなかった | 10分前のオッズで確かめ直した（次の行） |
| 上の馬連の決まりを、10分前のオッズで選び直す | 100% を割った。10分前に期待値が高く見える組ほど、締め切りまでにオッズが下がっていて（遅い時間の票が入る）、確定の払戻では割安でなかった。同じ組を選ぶレースも少ない | 採らない |
| ◎ の単勝（期待値の線） | 10分前のオッズで選んでも、確定オッズで選んだときと同じくらいの回収率を保った。ただし的中率は 20% に届かない | 土台にする |
| ◎ の単勝（期待値の線 ＋ ◎ の単勝オッズの上限）。線・上限・頭数・人気・◎ が3着以内の確率でも1番手か、を探す期間で総当たり | 期待値 1.00 以上・単勝 6倍以下が、探す期間で回収率・的中率・買うレースの数の釣り合いがいちばん良く、確かめる期間と10分前の1年でも 110% を超えた。ほかの絞りを足しても良くならなかった | **採る** |
| ◎ の単勝と複勝を組み合わせる | 的中率は上がるが、複勝の分だけ回収率が下がる。110% を保てるのは、期待値の線を上げて買うレースが年に数十まで減るときだけ | 採らない |

## 4. 採った決まり

**当日の予想で、◎ の単勝の期待値が 1.00 以上、かつ ◎ の単勝オッズが 6倍以下のレースだけ、◎ の単勝を 100円買う。** 線ちょうどは買う。

- 買うのは全レースの1割前後で、1開催日に 2〜4レース。
- 確定オッズの7年は、どの年も回収率 100% を超えた。
- 期待値の線（0.95〜1.10）と単勝の上限（5〜8倍）を動かしても、探す期間・確かめる期間とも、ほぼ 100% を超える範囲にある（`check.md` の3つ目の表）。
- 8分前の断面にしても、選ぶ断面は10分前と同じだった（時系列オッズの断面は、発走の約11分前の次が締め切りの近くまで無い）。

## 5. 気をつけること

- **10分前のオッズで確かめられたのは約1年。** 回収率は 110% を超えたが、運が悪いほうに振れると 100% を少し割る。月ごとでは 100% を割る月もある。
- **10分前の時点の確率は近似。** 本番の予想は10分前のオッズを材料にそのまま予測するので、近似とは少し違う。発走前の通知とその日の結果で、本番の成績を数え続ける。
- **払戻は小さい。** 単勝 6倍以下の1点なので、当たったときの払戻は 100円あたり 600円前後まで（締め切りまでにオッズが上がれば少し超える）。20レース近い外れ続きもあった。
- **探す期間で選んだ線は、周りより少し良い点を選んでいる。** 周りの線の成績から見ると、これからの回収率は 110% より少し下がることもありうる。
