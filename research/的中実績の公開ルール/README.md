# 的中実績の公開ルール

ほかの予想家が公開している「的中実績の公開ルール」（買う決まりを先に決めて、当てはまるレースの当たり外れを全部見せる）と同じ形で、
うちの予想の決まりを作る。利用者の条件は、最初は回収率 110% 位以上・レースあたりの的中率 20〜30% くらい（01）、
そのあと「全レースに参加しても 100% 超え、勝負レースだけなら 150% 超え」（02）。
本番では発走10分前のオッズで買うので、10分前のオッズで選んでも崩れないことも条件にした。

結論: **今の1着の確率を締め切り前に分かる材料で直し（印は変えない）、直した ◎ の単勝を全レースで買い、直した ◎ の期待値が 1.25 以上のレースは勝負として単勝と馬単 ◎→相手3頭も買う（2段）。**
確率を直すモデルを年ごとに学び直して数えると、勝負は選ぶのに使った期間（2022〜2023年）・確かめる期間（2024年〜）・発走10分前のオッズで選んだ約1年のどれも回収率 140% 以上、
全レースは全体で 100% 超え（02）。最初に作った ◎ の単勝の決まり（期待値 1.00 以上・単勝 6倍以下。回収率 110% 台）は、これに置き換えた（01）。
馬連・馬単・3連複の組の決まりは、10分前のオッズで選ぶと崩れた（01）。
本番は設計書「買うレースと買い目を決める」08 の 2 の「的中実績の公開ルール」と 09 の 38・39。

## 入口

数値は Git の対象外の `reports/的中実績の公開ルール/`。元DB は読むだけ（確定の単勝オッズ・単勝の払戻・時系列オッズの断面）。
予測は研究「既存モデルの改善」の `reports/既存モデルの改善/predictions/graded_race_day/odds_move-win.pkl`（今の本番の当日の予想と同じ作りの、学習に使っていない期間の1着の予測。研究「重賞の事例から材料を作る」の `odds_move.py` が書く）。

| 入口 | 何をするか |
|---|---|
| `analysis/walk_forward.py` | 今の公開ルール（02）の成績を、確率を直すモデルを年ごとに学び直して、期間ごと・年ごと・勝負の線を動かしたときの3つの表で出す（`--minutes 8` で締め切り前の断面を8分前に。勝負の線とモデルの設定は本番と同じ）。数分 |
| `analysis/check.py` | 最初の公開ルール（01）の成績を、期間ごと・年ごと・線を動かしたときの3つの表で出す |

部品は `analysis/horse_table.py`（1頭1行の表）・`snapshot_probability.py`（確定オッズで出した確率を、締め切り前のオッズの時点に近づける）・`top_picks.py`（◎ と買うレース）・
`rule_report.py`（01 の成績の表）・`day_bootstrap.py`（開催日を引き直した、運が悪いほうの回収率）・`repository/pre_deadline_board_repository.py`（締め切り前の断面の板。単勝・複勝・馬連）・
`snapshot_table.py`（学習の表を断面の時点に置き換える）・`walk_forward_model.py`（年ごとの学び直し）・`public_bets.py`（公開ルールの ◎・相手と払戻。決め方は本番の `PublicRulePicker.decide`）・`tier_report.py`（02 の成績の表）。
確率を直すモデルは本番の `yosou.shared.win_correction`、学習の表は道具「公開ルール」の `training_table.py`・`repository/training_input_reader.py` を使う。
