# 的中実績の公開ルール

ほかの予想家が公開している「的中実績の公開ルール」（買う決まりを先に決めて、当てはまるレースの当たり外れを全部見せる）と同じ形で、
うちの予想の決まりを作る。利用者の条件は、回収率 110% 位以上と、レースあたりの的中率 20〜30% くらい。
本番では発走10分前のオッズで買うので、10分前のオッズで選んでも崩れないことも条件にした。

結論: **◎ の単勝。◎ の単勝の期待値（1着になる確率 × 単勝オッズ）が 1.00 以上で、◎ の単勝オッズが 6倍以下のレースだけ買う。**
探す期間（2020〜2022年）・確かめる期間（2023〜2026年）・発走10分前の単勝オッズで選んだ約1年の3つとも、回収率 110% 超え・的中率 20% 台後半。
確定オッズの7年は、どの年も 100% を超えた。馬連・馬単・3連複の決まりは、10分前のオッズで選ぶと崩れるか、確定オッズでも 110% に届かず、採らなかった。
本番は設計書「買うレースと買い目を決める」08 の 2 の「的中実績の公開ルール」と 09 の 38。

## 入口

数値は Git の対象外の `reports/的中実績の公開ルール/`。元DB は読むだけ（確定の単勝オッズ・単勝の払戻・時系列オッズの断面）。
予測は研究「既存モデルの改善」の `reports/既存モデルの改善/predictions/graded_race_day/odds_move-win.pkl`（今の本番の当日の予想と同じ作りの、学習に使っていない期間の1着の予測。研究「重賞の事例から材料を作る」の `odds_move.py` が書く）。

| 入口 | 何をするか |
|---|---|
| `analysis/check.py` | 公開ルールの成績を、期間ごと・年ごと・線を動かしたときの3つの表で出す（`--minutes 8` で締め切り前の断面を8分前に。線は本番の `tools/今週の予想/public_rule.py` と同じ） |

部品は `analysis/horse_table.py`（1頭1行の表）・`snapshot_probability.py`（確定オッズで出した確率を、締め切り前のオッズの時点に近づける）・`top_picks.py`（◎ と買うレース）・
`rule_report.py`（成績の表）・`day_bootstrap.py`（開催日を引き直した、運が悪いほうの回収率）・`repository/pre_deadline_win_odds_repository.py`（締め切り前の単勝オッズ）。
