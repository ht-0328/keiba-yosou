# 01 事例を集める（段1）

**この文書で決めること:** 何を「事例」として集め、1件ずつ何を見るか。表の読み方。事例から読み取ったこと。

**結論: 高知のファイナルレース（9頭以上）を全部集め、3連単の配当の帯と決着の型を数える。そのうえで、配当の高かったレースを1レースずつ、出走馬ごとに人気・オッズ・着順・近走を並べて読む。読み取ったのは「近走の着順が良い馬ほど買われすぎている」「着順は悪くても前に行ける人気薄が来る」「ファイナルの常連より、初めて出る人気馬のほうが信頼できる」「騎手で差がつく」の4つで、これを段2 の理論にする。**

## 1. なぜファイナルレースの荒れたレースから始めるか

- 目的が「荒れる前提で、どの馬が来るかを当てる」なので、起きてほしい事象（高配当の決着）そのものから見る。
- ファイナルレースは、高知のほかのレースと比べて1番人気が勝ちにくく、3連単の万馬券・10万馬券がはっきり多い。事例として十分な数がある。
- ただし、荒れることは単勝オッズに入っている。どの人気の馬を全部買っても回収率は 100% を割る。だから「荒れやすいレースを探す」のではなく、「人気のわりに来る馬・来ない馬」を探す。
- 頭数が少ないレースは荒れ方が違うので、9頭以上に絞る（`--min-heads` で変えられる）。

## 2. 事例の決めごと

| 項目 | 決めごと |
|---|---|
| ファイナルレース | 高知で、その日の最大のレース番号のレースのうち、競走名に「ファイナルレース」を含むもの（`analysis/final_race.py`） |
| 数える範囲 | DB にある全期間の、9頭以上で 3連単の払戻があるファイナルレース |
| 1レースずつ並べる範囲 | 新しい期間（`--list-from` で始まりの日を決める）から、3連単の配当の高い順に 20 レース（`--limit`） |
| 人気の帯 | 人気馬 1〜3番人気・中穴 4〜7番人気・大穴 8番人気以下 |
| 配当の帯 | 固い・中荒れ（万馬券）・大荒れ（10万馬券）・超荒れ。線は研究「地方の万馬券」と同じ |
| 載せないもの | 馬名・騎手名 |

## 3. 1レースで見るもの

| 見るもの | どこから | 何が分かるか |
|---|---|---|
| 決着の型 | 1〜3着の単勝人気を帯（人・中・大）にして並べる | 高配当が「人気馬1頭・中穴1頭・大穴1頭」で決まるのか、「大穴2頭」なのか。買い目の形の元になる |
| 来た人気薄と来なかった人気薄 | 同じレースの中穴・大穴の、近走の文とファイナルの出走歴 | 来た馬だけにある特徴。穴馬の材料の候補 |
| 崩れた人気馬と残った人気馬 | 同じレースの 1〜3番人気の、近走の文とファイナルの出走歴 | 危険な人気馬の材料の候補 |
| 近走の文 | そのレースより前の高知の出走を、古い順に5走。「クラス 距離: 人気・着順（着差・4コーナーの順位）」。ファイナルレースだった走は頭に F | 着順だけでなく、着差・位置・相手（クラス）・ファイナルでの走りを1走ずつ読める |
| ファイナルの出走/3着以内 | そのレースより前のファイナルレースの出走数と3着以内の数 | 常連か、初めてか |

近走は高知の出走だけから作る。ほかの競馬場から来たばかりの馬は「高知での出走なし」と出る。

| 表 | 何が書いてあるか | どう読むか |

## 5. 事例から読み取ったこと

数値は `reports/高知ファイナルの高配当/事例.md` にある。ここには向きだけを書く。

- **荒れ方。** 万馬券にならないほうが珍しく、10万馬券もよく出る。一方で、超荒れ（100万円以上）はほとんど出ない。狙う高配当は 10万円台から数十万円までの帯になる。
- **決着の型。** 多いのは「人気馬2頭と中穴1頭」「人気馬・中穴・大穴が1頭ずつ」「人気馬1頭と中穴2頭」。人気馬が1頭も来ない決着は少ない。大穴が1頭入る決着は珍しくなく、10万馬券のほとんどは大穴が絡む。
- **来た人気薄。** 近走の着順は悪い馬が多い。着順だけでは買えないが、近走で4コーナーを前のほうで回っていた馬、ファイナルレースで着差の小さい負け方をしていた馬が混ざる。
- **来なかった中穴。** 近走に3着以内が何度もあって「見た目が良い」馬が、中穴に推されて来ない例が目立つ。前走のファイナルレースで3着以内だった馬も同じ。
- **人気馬。** ファイナルレースに何度も出て人気になっている馬より、ファイナルレースが初めての人気馬のほうが残っている。
- **騎手。** 高知での成績が下位の騎手が乗る人気薄は、ほとんど来ていない。その日すでに勝っている騎手の人気馬は残っている例が多い。
- **差が見えなかったもの。** 枠・馬場状態・距離の延長と短縮・年齢・性別・斤量では、来た馬と来なかった馬の違いが見えなかった。
