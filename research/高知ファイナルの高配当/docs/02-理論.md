# 02 理論を確かめる（段2）

**この文書で決めること:** 段1 の事例から立てた理論を、全部のファイナルレースの数でどう確かめ、何を予想の材料に残すか。

**結論: 次の5つを材料に残す。どれも、同じ人気の馬と比べた3着以内の倍率が、3つの期間とも同じ向きに出た。**

- **① 前走がファイナルレースで3着以内だった馬は買われすぎ。** 人気の帯を問わず、同じ人気の馬より来ない。
- **② 近走の着順が良く見える中穴は買われすぎ。** 近5走に3着以内が2回以上ある中穴は来ない。近5走に3着以内が無い中穴は来る。
- **③ 前に行ける大穴は来る。** 近3走の4コーナーの位置が、そのレースで1〜2番目に前の大穴。
- **④ 騎手の成績が下位の大穴は来ない。その日2勝以上している騎手の人気馬は来る。**
- **⑤ ファイナルレースが初めての人気馬は来る。**

**枠・馬場状態・距離の延長と短縮・年齢・性別・斤量・持ち時計・ファイナルレースの出走回数は、同じ人気の馬と差が無かった。材料の中心にはしない。**

## 1. 確かめ方

| 項目 | 決めごと |
|---|---|
| 対象 | DB にある全期間の、9頭以上のファイナルレースの出走馬（`analysis/final_runners.py`） |
| 比べる相手 | **同じ人気の馬**。ファイナルレースの全出走馬から人気ごとの3着以内率と勝率を数え、条件に当てはまる馬が「同じ人気の馬と同じ率で来たら何頭来るか」を出す（`analysis/same_popularity_rates.py`） |
| 倍率 | 実際に来た頭数 ÷ 上の見込みの頭数。3着以内と1着の2つ。1 より大きければ人気のわりに来る、小さければ買われすぎ |
| 回収率 | 当てはまる馬の単勝・複勝を全部買ったときの回収率。全部の馬を買ったときの回収率（基準）と比べる |
| 人気の帯 | 全部・人気馬（1〜3番人気）・中穴（4〜7番人気）・大穴（8番人気以下）の4つの行に分ける |
| 期間 | 3つに分けて、3着以内の倍率が同じ向きに出るかを見る（`analysis/period_split.py`。区切りは `--split`） |
| 出さない行 | 頭数が少ない行と、頭数が少ない期間の倍率は出さない（偶然の幅が大きいため。線は `analysis/theory_check_table.py`） |
| 残す線 | 3着以内の倍率が、3つの期間とも理論の向き（1 より上か下か）に出ること |

材料は、レースの前に分かるものだけで作る。

| 材料 | 作り方 | 先の情報を混ぜない工夫 |
|---|---|---|
| 近走（位置・着差・着順・人気・上がり） | その馬の、今回より前の高知の出走（`analysis/past_runs.py`） | 今回の出走を1つずらしてから数える |
| ファイナルレースの出走歴 | 今回より前のファイナルレースの出走数・3着以内の数・勝利数、前走がファイナルレースだったか（`analysis/final_history.py`） | 同上 |
| 前に行けるか | 近3走の4コーナーの相対位置の平均を、そのレースの出走馬の中で前から順位にする（`analysis/final_runners.py`） | 近走だけから作る。今回の通過順は使わない |
| 騎手の成績 | その日より前の 365日の、高知での3着以内率（`analysis/jockey_form.py`） | その日の騎乗は数えない |
| その日の傾向・その日の騎手の勝利数 | その日の最終レースより前のレース（`analysis/day_trend.py`） | ファイナルレースは最終レースなので、その日のほかのレースは全部終わっている |

着順が付かなかった出走（競走中止など）は「3着以内でない」と数える。

## 2. 分かったこと（数値は `reports/高知ファイナルの高配当/理論の検証.md`）

### 2-1. ① 前走がファイナルレースで3着以内だった馬

- 人気馬・中穴・大穴のどの帯でも、3着以内の倍率が 1 をはっきり下回る。3つの期間とも下回る。
- 単勝・複勝の回収率も、基準より大きく低い。
- 前走がファイナルレースでも、4着以下だった馬には差が無い。買われすぎるのは「ファイナルレースで好走した」馬である。

### 2-2. ② 近走の着順が良く見える中穴

- 近5走に3着以内が2回以上ある中穴は、倍率が 1 を下回り、回収率も基準より低い。3つの期間とも下回る。大穴も全体では同じ向きだが、期間でそろわない。人気馬では差が無い。
- 前走の着差が小さい中穴、近5走にごく小さい着差の走がある中穴も、同じ向きに出る。「近走が良く見える」ことが、中穴ではオッズに入りすぎている。
- 逆に、近5走に3着以内が無い中穴は、倍率が 1 を上回る。3つの期間とも上回る。特に1着の倍率が高い。

### 2-3. ③ 前に行ける大穴

- 近3走の4コーナーの位置がレースの中で1〜2番目に前の大穴は、3着以内の倍率・1着の倍率とも 1 をはっきり上回る。3つの期間とも上回る。
- 単勝・複勝の回収率が 100% を超える。理論①〜⑤のうち、単勝・複勝とも 100% を超えるのはこの条件だけである。
- 最初のコーナーの位置で見ても、同じ向きに出る。
- 同じ条件の中穴は、倍率が 1 を少し下回る。前に行けることは、中穴ではすでに買われている。

### 2-4. ④ 騎手

- 直近 365日の高知での3着以内率が低い騎手の大穴は、倍率が 1 をはっきり下回り、回収率も低い。3つの期間とも下回る（いちばん新しい期間は差が小さい）。
- その日すでに2勝以上している騎手の人気馬は、倍率が 1 を上回る。3つの期間とも上回る。
- 3着以内率が高い騎手は、全体では倍率が 1 を少し上回るが、期間で向きがそろわない帯がある。

### 2-5. ⑤ ファイナルレースが初めての馬

- ファイナルレースに出たことが無い人気馬は、3着以内の倍率・1着の倍率とも 1 を上回る。3つの期間とも上回る。
- 中穴・大穴では差が無い。

### 2-6. 差が無かった材料

| 材料 | 見た条件 | 結果 |
|---|---|---|
| 枠 | 内の枠・外の枠、枠と位置の組み合わせ | 全体の倍率はほぼ 1。期間で向きがそろわない |
| 馬場状態 | 重・不良、馬場状態と位置の組み合わせ | 同上 |
| 距離 | 前走からの延長・短縮、いちばん長い距離の日 | 同上 |
| 年齢・性別 | 若い馬・高齢の馬・牝馬 | 同上 |
| 斤量 | 前走より軽い・軽い斤量 | 同上 |
| 持ち時計 | そのコースの持ち時計がレースで1位 | 同上 |
| ファイナルレースの出走回数 | 出走が多い・3着以内率が高い・勝ったことがある | 同上（「初めて」の人気馬だけが⑤として残る） |

上がりの順位・人気の変化・クラスの上がり下がり・同じ距離の実績・出走の間隔・乗り替わり・その日の位置と枠の傾向・馬体重の増減も同じ表で確かめた。どれも、3つの期間で向きがそろう帯が無いか、頭数が少ない。

## 3. 読むときの注意

- 比べる相手は「同じ人気の馬」で、同じオッズの馬ではない。人気の順位が同じでもオッズは違うので、予想を作る段ではオッズ（市場の見立て）を材料に入れたうえで、ここの材料が上乗せになるかを確かめる。
- ファイナルレースは1日に1つしか無い。帯と期間で分けた行は頭数が少なく、倍率は動きやすい。3つの期間で向きがそろうことを線にしたのはそのためである。
- 条件の線（位置・騎手の率など）は事例を見て置いたもので、成績が良くなるように動かしてはいない。予想を作る段では、線で切らずに元の値のまま材料にする。
- 理論①〜⑤のうち、回収率が 100% を超えたのは③の大穴だけである。ほかの理論は「買えば勝てる条件」ではなく、「予想の確率を人気から上下に動かす材料」である。

| 材料 | 元の値 | 効く帯 |
|---|---|---|
| ① 前走がファイナルレースだったか・その着順と着差 | `prev_run_final`・前走の着順・前走の着差 | 全部 |
| ② 近5走の3着以内の数・近走の着差 | `places_recent5`・`time_diff_recent3`・`time_diff_best5` | 中穴（大穴も同じ向き） |
| ③ 近3走の4コーナー・最初のコーナーの相対位置と、レースの中での順位 | `corner4_rel_recent3`・`corner4_rank_in_race`・`corner1_rank_in_race` | 大穴 |
| ④ 騎手の直近 365日の3着以内率・その日の勝利数 | `jockey_place_rate_365`・`jockey_day_wins` | 大穴（率）・人気馬（その日の勝利数） |

帯で効き方が違うので、予想では人気（オッズ）との組み合わせで学べる形にする。
