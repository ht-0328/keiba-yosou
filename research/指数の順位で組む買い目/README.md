# 指数の順位で組む買い目

**何をする研究か。** 予想サイトが載せている「指数の順位で組む買い目の形」（単勝 1位、馬単 1位→2〜8位、3連単 1位→2〜8位→2〜8位の残り、上位5頭BOX など）を、
今のモデル（予想「近走と適性から3着以内を予想」）のレースの中の順位に当てて、過去のレースで全券種の的中率と回収率を出す。
「指数 n位」は、レースの中で走った馬を 3着以内の確率の高い順（主）か 1着の確率の高い順（比べる）に並べたときの n番目と読む。

**なぜ始めたか。** サイトの表に載っている的中は、集計金額（単勝 500円以上、3連単 10,000円以上 など）を満たしたものだけで、
買った全部のレースで回収率 100% を超える形かどうかは分からない。今のモデルの順位で同じ形を全レースに当て、どの形が 100% を超えるか、
的中のうちどれだけが集計金額を満たすか（サイトが載せている当たりがどれだけ選ばれたものか）を確かめる。

## 言葉

| 言葉 | 意味 | 例 |
|---|---|---|
| 順位 | レースの中で走った馬を確率の高い順に並べた番号（1 が最上位）。出走取消・除外の馬は入れない。同じ確率は馬番の小さい順 | 3着以内の確率の順の 1位 |
| 形 | 券種と、1頭目・2頭目・3頭目に置く順位の範囲の組み合わせ。頭数が足りずに存在しない順位（9位以下が無い など）の組は買わない | 馬単 1位→2〜8位（7点） |
| 上位5頭BOX | 順位 1〜5位の5頭の全部の組（馬連 10点・馬単 20点・3連複 10点・3連単 60点） | − |
| 集計金額 | サイトが集計に載せている的中の、1レースの払戻の下限（形の全部の点を 1点 100円で買ったときの払戻の合計で見る） | 3連単 10,000円以上・50,000円以上 |
| 探索・確認 | 形を比べる期間（2019〜2024年）と、一度だけ確かめる期間（2025年〜）。当日の予測は 2015年からあるので 2015〜2018年は参考 | − |
| 比べる相手 | 今の印の買い目（設計書「買うレースと買い目を決める」08 の 2 の形）を全レースで買ったもの。道具「印の成績」の買い目の CSV からまとめる | 3連単（◎→○▲☆→○▲△☆） |

## 置き場所

| 場所 | 中身 |
|---|---|
| `rank_tickets.py` | 入口。`run`（予測で形を組んで精算）・`baseline`（比べる相手をまとめる）・`report`（成績の表を書く） |
| `analysis/` | 部品（1ファイル1クラス。一覧は `analysis/__init__.py`） |
| `tests/` | 部品のテスト（架空の値だけ。元DB は使わない） |
| `reports/指数の順位で組む買い目/`（Git 対象外） | 実測の数値。精算の表（`精算/<時点>-<順位の決め方>.parquet`）・比べる相手（`比べる相手/<時点>.parquet`）・`成績.md`（払戻の実額つき）・`docs向けの表.md`（割合・件数だけ） |

## 使い方

```
uv run python research/指数の順位で組む買い目/rank_tickets.py run --timing 当日       # 当日の予測（2015年〜）。元DB を読む。10分ほど
uv run python research/指数の順位で組む買い目/rank_tickets.py run --timing 前日       # 前日の予測（2019年〜）
uv run python research/指数の順位で組む買い目/rank_tickets.py baseline --timing 当日  # 比べる相手（道具「印の成績」の買い目の CSV から。数分）
uv run python research/指数の順位で組む買い目/rank_tickets.py baseline --timing 前日
uv run python research/指数の順位で組む買い目/rank_tickets.py report                 # 成績.md と docs向けの表.md を書く
uv run python -m pytest research/指数の順位で組む買い目/tests                          # 部品のテスト
```

材料は研究「複勝以外の回収率100超」の半年ごとに学び直した区切りの予測（`reports/複勝以外の回収率100超/predictions-2015から`・`predictions-2019から`）の
テスト期間の行。払戻は道具「印の成績」の精算と同じ部品（`PayoutRepository`）で確定の払戻を読む。1点 100円。
研究フォルダをリポジトリの外に置いて動かすときは、環境変数 `KEIBA_YOSOU_ROOT` にリポジトリ直下を入れる。
