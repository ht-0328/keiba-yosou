# 02 結果

**この文書は、事例から分かったことと、検証の結果を書く。** 数値は Git の対象外の `reports/複勝以外の回収率100超/`（`事例.md`・`検証の結果.md`）にあり、ここには書かない。

## 結論

**券種ごとに前半の年で選んだ作り方では、どの券種も採用の基準を満たさなかった（2026-09-27）。** いちばん近かったのはワイドで、「3連単か3連複から作った組の確率に、モデルの上げ下げを掛ける」作り方が、後半の年で回収率 100% 前後になった。ただし前半の年では 100% に遠く届かず、前半で選ぶ決まりでは選ばれていない。

## 1. 事例から分かったこと（手順1。前半の年だけ）

| 分かったこと | 中身 |
|---|---|
| 3連単から作った確率は、全体としてよく合っている | どの券種でも、比の帯ごとの「見込みの当たり」（3連単から見た確率の合計）が、実際の当たりの数とほぼ一致した。3連単の市場は正確である |
| 比が大きい（割安に見える）帯ほど、回収率は下がる | 比が大きい組は、ほとんどが人気薄の組だった。その帯では、3連単自身が人気薄の組を買われすぎていて、見込みより当たらなかった |
| 比が大きい組の形 | 1〜3番人気の馬と、8〜12番人気の馬の組が多かった。一覧の組は、ほとんど外れていた |
| 控除率の差が大きい | 券種どうしの値段がそろっている帯では、買う券種の控除率（22.5〜27.5%）の分だけ負ける。100% を超えるには、控除率を埋めるほどの食い違いが要るが、それは人気薄の組にしか出ていない |

ここから、仮説「3連単の人気薄の組の買われすぎを先に直してから、ほかの券種の確率を作れば、本物の割安だけが残る」を立て、作り方に足した（「3連単を直す」）。

## 2. 検証の結果（手順3）

| 券種 | 前半で選んだ作り方で | 分かったこと |
|---|---|---|
| 単勝 | 不採用 | その券種自身・3連単からのどちらでも、上げ下げを強く掛けた作り方が 100% に近づいたが、届かない |
| ワイド | 不採用 | 前半で選ばれたのは「ワイド自身・上げ下げ 0.5」で、後半は大きく下がった。一方、3連単・3連複から作って上げ下げを掛ける作り方は、後半で 100% 前後。どの作り方も、前半と後半で成績が大きく違う |
| 馬連 | 不採用 | どの作り方でも届かない |
| 馬単 | 不採用 | 前半で 100% を超えた作り方が、後半で大きく下がった（前半のたまたま） |
| 3連複 | 不採用 | 前半でわずかに 100% を超えた作り方が、後半で下がった |
| 3連単 | 不採用 | 自身のオッズからしか作れず、上げ下げを掛けても届かない |

### 作り方ごとに分かったこと

- **市場の確率だけ（上げ下げ 0）では、ほとんど買い目が出ない。** 較正のあと、期待値が 1 を超える買い目が少なく、多くの作り方で前半の当たりが 30回に届かなかった。券種どうしの値段は、控除率の差を埋めるほどには食い違っていない。
- **モデルの上げ下げを掛けると、回収率が上がる。** どの券種でも、強さ 0 → 0.5 → 1 の順に、おおむね回収率が上がった。市場に無い情報は、市場の組の値段ではなく、モデルの側にある。
- **仮説「3連単を直す」は、はっきりとは支持されなかった。** ワイドでわずかに良くなった程度で、単勝・馬連・3連複・馬単では良くならなかった。
- **作り方を多く試すと、前半のたまたまを選んでしまう。** 馬単とワイドで、前半にいちばん良かった作り方が、後半でいちばん悪い部類になった。後半で確かめる決まりが、それを見分けた。

## 3. 残っている見込みと、次にできること

- **ワイド × 3連単・3連複から × 上げ下げ** が、いちばん 100% に近い。ただし前半では届かず、前半と後半で成績が違う理由はまだ分からない。考えられる理由は次の2つ（確かめていない）。
  - 2019年の較正は 2018年の1年ぶんしか実績が無く、前半の年ほど較正が粗い。
  - 年によって、ワイドと3連単の値段のずれ方が変わっている。
- 後半の年はすでに見てしまったので、期間の分け方を変えて確かめ直しても、手つかずのデータでの確かめにはならない。これからのレースを締め切り前のオッズで確かめる仕組み（フォワードテスト）は作らないと決めた（2026-10-01）ので、**ワイドをフォワードテストで確かめる案はここで閉じる。** 確かめ直すなら、これからのレースの確定成績がたまってから、確定オッズで行う。
- 複勝の買い方（研究「回収率100超」）は、ここでの作り方とは別に、100% を超えたままである。
