# 04 組の期待値で選ぶ買い方（手順5）

**この文書は、ワイド・馬連・馬単・3連複・3連単を、組ごとの期待値で選んで買う買い方と、それを確かめる手順・採用の基準を書く。**
買い方（確率の作り方・線・オッズの上限・対象のレース）と基準は、2019〜2022年の結果を見る前に決めた。数値は Git の対象外の `reports/複勝以外の回収率100超/組の期待値/` にあり、ここには書かない。

## 1. なぜやるか

印のルールの買い目は、◎ を単勝の期待値で選ぶので、単勝と馬単（◎→○▲☆）は当日の期待度「高」のレースで回収率が 100% を超えた（[03](03-印の買い目の確かめ.md)）。
一方、相手の ○▲△☆ は「3着以内に来やすい順」に選んでいて、その組の値段が割安かどうかを見ていない。そのため、ワイド・馬連・3連複・3連単は基準に届かなかった。

道具「印の成績」の3連複・3連単の「組の期待値」（市場が見た組の確率 × 3頭の「モデル ÷ 市場」の比）も、2023〜2026年で期待値の帯ごとに数えると、期待値が上がっても回収率がほとんど上がらなかった。
比を掛けるだけでは、人気薄の組の確率を大きく見積もりすぎるからである（前の研究と同じ見立て）。

そこで、**組の確率を、市場の値段とモデルの確率を重みを付けて合わせて作り、重みを実際の当たりに合わせて推定する**。そのうえで、組ごとの期待値（確率 × 確定オッズ）が線以上の組だけを買う。

## 2. 組の確率の作り方

券種ごとに、そのレースの全部の組について、次の4つの「確率のもと」を作る（どれもレースの中で合計をそろえる）。

| もと | 中身 |
|---|---|
| その券種自身の市場 | その券種のオッズの逆数（ワイドは最低オッズ）を、レースで合計 1（ワイドは 3）にそろえた値 |
| 3連単から見た市場 | 3連単のオッズの逆数を合計 1 にそろえ、その券種の組に足し合わせた値（研究「複勝以外の回収率100超」の `pool_derivation.py` と同じ足し方） |
| モデルの Harville | 今の本番の1着のモデルの確率（レースで合計 1 にそろえる）から、Harville の式で作った3連単の組の確率を、その券種の組に足し合わせた値 |
| モデルの比 | 組の各馬の「モデル ÷ 市場」の比の積（着順を区別する券種の1着は1着の比、ほかは3着以内の比。今の「組の期待値」の比と同じ） |

組の確率は、4つの対数に重みを掛けて足し、レースの中で合計 1（ワイドは 3）にそろえる（条件付きロジット）。

```text
組の確率 ∝ exp( a × log その券種自身の市場 + b × log 3連単から見た市場 + c × log モデルの Harville + d × log モデルの比 )
組の期待値 = 組の確率 × 確定オッズ（ワイドは最低オッズ）
```

重み a〜d は、券種ごとに、2023〜2026年の当日の予想（今の本番の7つの区切りのテスト期間）で、当たった組の確率の対数の合計が最大になるように推定した（3連単は組が多いので、レースの 3分の1 で推定した）。
重みは4つだけなので、推定した期間に合わせすぎるおそれは小さい。どの券種でも、市場だけのときより当たり具合（対数損失）が良くなった。

## 3. 線・オッズの上限・対象のレース

券種ごとに、線（1.0・1.1・1.2・1.3）× オッズの上限 × 対象のレース（全レース・期待度「高」）の組み合わせを、**2023〜2026年だけで**数え、
開催日を単位にしたブートストラップの 90% の幅の下の端がいちばん高いもの（当たりが 150回以上）を選んだ。選んだ結果は次のとおり。

| 券種 | 対象のレース | 線（組の期待値） | オッズの上限 |
|---|---|---|---|
| ワイド | 当日の期待度「高」 | 1.1 以上 | 100倍以下（最低オッズ） |
| 馬連 | 全レース | 1.1 以上 | 100倍以下 |
| 馬単 | 全レース | 1.1 以上 | 30倍以下 |
| 3連複 | 全レース | 1.2 以上 | 300倍以下 |
| 3連単 | 全レース | 1.1 以上 | 3,000倍以下 |

1レースで条件に合う組は全部買う（1点 100円で数える）。オッズの上限を置くのは、オッズの高い組ほど確率を大きく見積もりすぎて回収率が下がるからである。

## 4. 確かめ方と採用の基準

1. 今の本番の5つのモデルを、2019年前半〜2020年後半の4つの区切りで学び直す（`early_years.py run --from-year 2019` と `combine --from-year 2019`）。2021〜2022年は手順4 で数えたので、一度も数えていないのはこの2年だけである。
2. 2019〜2026年の予測（15の区切り）に、道具「印の成績」と同じ決め方で印と期待度を付け、券種ごとに 2. の重みと 3. の決まりで買い目を作って数える
   （道具「印の成績」の表7・表8 の「（組の期待値）」の行と、`combo_value.py check` の期間ごとの表）。
3. 次の2つをどちらも満たす券種を採用する（複勝・単勝・馬単と同じ強さ）。
   - **まだ見ていない 2019〜2020年で、回収率が 100% を超える。**
   - **2019〜2026年の全体で、回収率が 100% を超え、開催日を単位にしたブートストラップの 90% の幅の下の端も 100% を超える。**

2021〜2022年の成績も別に出すが、採否には使わない（印のルールの買い目で見た期間なので）。

## 5. 気をつけること

- 2019〜2020年の区切りは学習が 1年半〜3年と短く、モデルが 2021年以降より弱い。その分は割り引かずに判定する。
- 確定オッズでの検証である。実際に買うときは締め切り前のオッズで、組の期待値もそのオッズで出す。
- 重みも線も 2023〜2026年で決めたので、2023〜2026年の成績はよく見える。採否は 2019〜2020年と全体の下の端で決める。

## 6. 結果

**馬連と馬単が、4. の基準を両方満たしたので採用した（馬連は、そのあと手順6 で採用をやめた）。** ワイド・3連複・3連単は満たさなかった。数値は `reports/複勝以外の回収率100超/組の期待値/`（`確かめの結果.md`・`確かめ-1回目.txt`・`確かめ-2回目.txt`）と `印の成績-2019から/` の表7・表8。

| 券種 | まだ見ていない 2019〜2020年 | 2019〜2026年の全体の 90% の幅の下の端 | 採否 |
|---|---|---|---|
| 馬連（全レース・1.1・100倍以下） | 100% 超え | 100% 超え | **採用** |
| 馬単（全レース・1.1・30倍以下） | 100% 超え | 100% 超え | **採用** |
| ワイド（期待度「高」・1.1・100倍以下） | 100% に届かない | − | 不採用 |
| 3連複（全レース・1.2・300倍以下） | 100% 超え | 100% に届かない | 不採用 |
| 3連単（全レース・1.1・3,000倍以下） | 100% 超え | 100% に届かない | 不採用 |

### 2回目（ワイド・3連複・3連単だけ。1回だけ）

1回目の結果を見たあとで、届かなかった3つの券種だけ、対象の組に「◎ を含む組」（3連単は ◎ が1着の組）を足して、同じく 2023〜2026年だけで選び直した。
◎ の単勝が、まだ見ていない年でも 100% を超えた（手順4）ので、モデルの強みが出やすい組に絞れば届くかを見るためである。
2019〜2020年を一度見てしまったので、2回目の基準は厳しくし、**2019〜2020年と 2021〜2022年の両方で 100% 超え、かつ全体の幅の下の端が 100% 超え**とした。

- 3連複と3連単は、選び直しても1回目と同じ決まりが選ばれたので、新しい候補は無かった（不採用のまま）。
- ワイドは「◎ を含む組・線 1.0・100倍以下」が選ばれたが、2019〜2020年も 2021〜2022年も 100% に届かず、不採用。

### 分かったこと

- **比を掛けるだけの組の期待値は、人気薄の組を大きく見積もりすぎる。** 2023〜2026年で、期待値の帯を上げても回収率がほとんど上がらず、オッズの高い組ほど負けた。
- **市場とモデルを重みで合わせると、どの券種でも当たり具合（対数損失）が良くなった。** 重みは、どの券種でもモデルの比に大きく掛かった。3連単から見た市場の重みは、ワイド・馬単では正、馬連・3連複・3連単では小さな負だった。
- **それでも人気薄の組の見積もりすぎは残る。** オッズの上限を置いたのはそのためで、多くの券種で、上限を高くすると 2023〜2026年の幅の下の端が下がった（`線と上限の選び方.md`）。
- **2023〜2026年は、2019〜2022年より成績が良い。** 重みと線をこの期間で決めたことと、2019〜2022年の区切りは学習が短くモデルが弱いことの両方が考えられる（確かめていない）。基準はまだ見ていない年と全体の下の端で決めたので、採用した2つはそれでも満たしていた（そのあと手順6 で、馬連は 2016〜2018年で届かなかった）。
- **馬単は、◎ の馬単（印のルール）と別の組も多く買う。** 組の期待値の馬単は ◎ を含まない組も選ぶ（印を使わない）。同じ組を両方で買うこともある。

**その後、手順6（[05](05-直前1年の重みと2015年から.md)）で新しく作った「まだ見ていない年」2016〜2018年でも確かめたところ、馬単は基準を満たしたが、馬連は 100% に届かなかった。そのため、馬連は実際に買うのをやめた（比べるための行にした）。**

馬単を実際に買う決まり（買うレース・1点の額・財布）は、設計書「買うレースと買い目を決める」の [08 の 2](../../../docs/design/買うレースと買い目を決める/08-bankroll-and-review.md#採用している券種当日の予想の組の期待値の買い目) に書いた。
