# 02 結果の読み方

手順2〜4（全体で数える・発生条件を確かめる・まとめる）で、何を比べ、どう決めたかを書く。
数値は Git の対象外の `reports/展開の理論の検証/まとめ.md` と `reports/展開の理論の検証/集計/` にある。この文書には数値を書かない。

## この文書で使う言葉の意味

この文書に出てくる言葉のうち、[01-進め方.md](01-進め方.md#この文書で使う言葉の意味) に無いものの意味をまとめた。

| 言葉 | 意味 | この研究では（架空の例） |
|---|---|---|
| 前−後ろの差 | 前（逃げ・先行など、分け方の前2つ）の複勝率 − 後ろ（差し・追込など、後ろ2つ）の複勝率（ポイント） | 前 40%・後ろ 15% なら 25 |
| 展開の効き目 | スローでの前−後ろの差 − ハイでの前−後ろの差。大きいほど、ペースで有利・不利が入れ替わる | スローで 30、ハイで 18 なら 12 |
| オッズから見た勝率 | 単勝オッズの逆数を、レースで合計 1 にそろえた値。市場が見ていた馬の力 | オッズ 4.0 の馬は、おおよそ 0.2 |
| 勝率とオッズの差 | 勝率 − オッズから見た勝率。馬の力（市場の評価）では説明できない分 | 勝率 15%・オッズから見た勝率 10% なら +5 |
| 先頭率の合計 | 出走馬全員の、近5走で最初のコーナーを先頭で回った割合を足した値。レースに逃げたい馬がどれだけいるか | 先頭率 0.6・0.4 の2頭と、0 の 14頭なら 1.0 |
| AUC | 数の大きさでハイとスローを見分けられる度合い。0.5 は当てずっぽう、1 は完全に見分けられる | |

## 比べたこと

| 比べたこと | 候補 | 何で比べたか |
|---|---|---|
| ペースの測り方 | ① 前半の速さ（手順1の測り方）② 前半の速さ（基準に馬場状態を入れる）③ 前後半の差（前3ハロン − 後3ハロン。基準に馬場状態を入れる） | 展開の効き目の大きさ。前半と後半のどちらで測るかは、使い道で分けた（下の「決めたこと」） |
| 脚質の分け方 | ① 結果の脚質 ② 最初のコーナーの位置（結果）③ 推定脚質（レース前）④ 先頭率と位置（レース前） | 展開の効き目と、4つを別々に見たときの成績 |

| 条件ごとの違い | 芝ダ・距離・競馬場・頭数・クラス・年 | 効き目がどの条件でも同じ向きか、年でぶれないか |

## 分かったこと（理論の答え合わせ）

| 理論 | 答え | 分かったこと |
|---|---|---|
| 逃げたい馬が1頭か0頭ならスロー、複数ならハイ | **向きは正しい。ただし外れも多い** | 逃げたい馬が多いほどハイが増え、スローが減る。ただし、逃げたい馬が多いレースでもハイになるのは半分ほどで、逃げたい馬がいなくてもハイになるレースもある |
| スローなら逃げ・先行が有利 | **正しい。特に逃げ** | スローで最も得をするのは逃げた馬。先行はペースによる違いが小さい |
| ハイなら差し・追込が有利 | **言い過ぎ** | ハイでも、前の複勝率は後ろより高い（どの競馬場・距離・年でも）。ハイで起きるのは「逃げた馬の得が消える」「差し・追込が、オッズから見た勝率並みに戻る」こと |
| ミドルなら有利・不利が少ない | **違う** | ミドルでも前が大きく有利。競馬では、ペースに関係なく前にいる馬が有利で、ペースはその大きさを変えるだけ |

- 人気で分けても、オッズとの差で見ても、効き目は残る。むしろ1〜3番人気で大きい。「強い馬がたまたま前にいた」だけでは説明できない。
- 効き目の大きさは、芝とダート、距離、競馬場、年でほぼ変わらない。前の有利そのものは、直線の短い競馬場で大きく、東京で小さい。
- 結果の脚質で見た数字は、「その日に前に行けた馬はもともと調子が良かった」ことも含むので、大きく出る。レース前に分かる脚質（先頭率と位置）で見ると、効き目は小さくなるが、向きは同じ。

## 決めたこと

利用者から「いろんなパターンを検証しておすすめを出して。決めてほしいことは任せる」と任されたので、比べた結果で次のように決めた。

| 決めること | 決めたこと | 理由 |
|---|---|---|
| ペースの測り方（能力指数の補正に使う） | ③ 前後半の差（馬場状態あり） | どの脚質の分け方でも、展開の効き目が最も大きい。中盤で緩んだレースを、ハイと見誤らない |
| ペースの測り方（レース前にペースを読むときに使う） | ② 前半の速さ（馬場状態あり） | 逃げたい馬の数で最もよく当たる（前半のペースは、逃げたい馬が作るため）。後半を混ぜると、逃げたい馬の数では当たりにくくなる |
| 馬場状態を基準に入れるか | 入れる。馬場状態ごとの基準が作れないときは、馬場状態を分けない基準で補う | 全体の効き目の違いは小さいが、当たり方がわずかに良くなり、悪くなるところは無い |
| 脚質の分け方 | 逃げ・先行・差し・追込（または先頭・前・中・後ろ）の4つを別々に見る | 逃げと先行でペースの影響がまるで違う。まとめると、逃げた馬の得を先行に薄めてしまう |
| 逃げたい馬の数え方 | ⑥ 先頭率の合計 | 当たり方が最も良い（「近3走で逃げた馬の数」とほぼ同じで、今の推定脚質の数え方よりはっきり良い）。既存の展開予想の特徴量（ほかの馬の先頭率の合計）とも同じ考え方 |
| 馬の力の影響の分け方 | 勝率とオッズの差で見る。人気で分けた表も残す | 人気で分けると頭数が減る。オッズとの差なら、全部の馬で一度に力を差し引ける |

## 能力指数への使い方（次の作業）

- 過去の走のタイムを、その走のペース（前後半の差）と、その馬がいた位置（逃げ・先行・差し・追込）で補正する。例: スローで逃げた走は得をしているので、タイムの評価を下げる。ハイで逃げた走は損をしているので、上げる。
- 補正の大きさ（何秒ぶんか）の決め方は、能力指数の計画で決める。この研究の表は、補正の向きと、どの脚質で大きいかの手がかりにする。
