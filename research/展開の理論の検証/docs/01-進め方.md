# 01 進め方

## 何を確かめるか

よく言われる展開の理論が、過去のレースで本当に成り立つかを確かめる。

| 理論 | 中身 |
|---|---|
| 発生条件 | 逃げたい馬が1頭しかいない、または誰も逃げたくないときはスローになりやすい。逃げたい馬が複数いて先頭争いが激しくなるとハイになりやすい |
| 有利な脚質 | スローなら逃げ・先行が有利（体力を温存でき、最後までバテにくい）。ハイなら差し・追込が有利（前の馬が前半で体力を使って止まる）。ミドルなら有利・不利が少なく、馬の力がそのまま出やすい |

この結果は、あとで作る「馬の能力指数」で、過去の走のタイムからペースで得をした分・損をした分を差し引くのに使う。

## この文書で使う言葉の意味

この文書に出てくる言葉のうち、分かりにくいものの意味をまとめた。

| 言葉 | 意味 | この研究では（架空の例） |
|---|---|---|
| 前半タイム | JV-Data の前3ハロン。スタートから 600m のタイム（距離が 200m で割り切れないレースは 500m か 550m）。先頭の馬のタイム | 34.6秒 |
| 前半タイムの基準 | 開催日の前日までの3年の、同じ競馬場・コース・距離・クラスのレースの前半タイムの平均と標準偏差。30 レースに満たなければクラスをまとめ、それでも満たなければ「基準なし」。展開予想（`docs/design/展開から着順を予想/10-target.md` の 4.・5.）と同じ作り方で、同じクラス（`RaceBaselineLookup`）を使う | 平均 35.1秒、標準偏差 0.6秒 |
| 前半の速さ（z） | （基準 − 前半タイム）÷ 基準の標準偏差。速いほどプラス | （35.1 − 34.6）÷ 0.6 = 0.83 |
| ペース | z が 0.5 より大きければハイ、−0.5 より小さければスロー、そのあいだはミドル。展開予想の設計書の「平均」を、理論の言い方に合わせて「ミドル」と呼ぶ | z = 0.83 はハイ |
| 脚質 | 逃げ・先行・差し・追込。JV-Data がレース後に付けた判定（`se` の「今回レース脚質判定」） | 勝ち馬の脚質 = 差し |
| 前（に行く脚質）・後ろ（から行く脚質） | 前 = 逃げと先行、後ろ = 差しと追込 | |
| 推定脚質 | 今回より前の直近3走の脚質の真ん中。レース前に分かる脚質（事実表の `style_before`） | 前3走が 逃げ・先行・先行 なら 先行 |
| 逃げそうな馬 | そのレースで推定脚質が逃げの馬の数（事実表の `lead_candidates`） | 2頭 |
| 事例の型 | 理論どおり・理論に反するレースの分け方。`analysis/cases/case_patterns.py` に6つある | 「ハイで前が勝った」（理論に反する） |

## 手順

| 手順 | 何をするか | 成果物 | 確認 |
|---|---|---|---|
| 1. 事例を見る | 6つの型ごとに、2023年からのレースを 20 ずつ無作為に選び、ラップ・通過順・1〜3着を1レースずつ読んで、なぜそうなったかを書く | `reports/展開の理論の検証/cases/`（一覧と型ごとの分析） | **確認①**: 見えたことを報告し、手順2で数える切り口を決める |
| 2. 全体で数える | 2014年からの全レースで、ペース × 脚質ごとの成績（勝率・複勝率・回収率）を出す。芝ダ・距離・競馬場で分け、年ごとのぶれも見る。脚質は、結果の脚質と推定脚質の両方で数える | `reports/展開の理論の検証/` の集計 | ― |
| 3. 発生条件を確かめる | レース前に逃げそうな馬が何頭いたかと、実際のペースの関係を数える | 同上 | ― |
| 4. まとめる | 理論のどこが正しく、どこが言い過ぎか。コースによって違うか | `docs/02-結果の読み方.md` と、数値は `reports/` | **確認②** |

- 数える期間を 2014年からにするのは、DB が 2011年からで、前半タイムの基準に前の3年が要るためである。
- 結果の脚質だけで数えると、「前に行けた馬は、もともとその日の調子が良かった」という別の理由が混ざる。レース前に分かる推定脚質でも数えて、理論が予想に使えるかを見る。
- 手順1のあとで、手順2で数える切り口を、事例で見えたことに合わせて足した（ペースの測り方3通り・脚質の分け方4通り・逃げたい馬の数え方7通り・人気とオッズとの差）。比べた結果と決めたことは [02-結果の読み方.md](02-結果の読み方.md)。
