# 01 狙い方と進め方

**この文書は計画である。** 帯（払戻 100万円以上）を当てる狙い方と、それを何の順で確かめるかを書く。
言葉の意味は [../README.md](../README.md) の表を参照。利用者の承認を得るまで、プログラムは作らない。
（2026-10-12 に利用者から「動かすところまでやって」と任され、この計画で進めた。結果と、計画から変えたことは [04-検証の結果.md](04-検証の結果.md)。）

## 1. 狙い方の考え

**「このレースは荒れる」と最初から決めて、そのレースだけは今の予想とは別の方法で予想し、1レース 1万円で帯を狙う。**

| 段 | 何を決めるか | 書いてある節 |
|---|---|---|
| 第1段 レース選び | どのレースを「荒れる」と決めて買うか | 4 |
| 第2段 荒れる前提の予想 | 選んだレースで、荒れるとしたらどの馬が1〜3着に来るか | 5 |
| 第3段 買い目 | 第2段の予想から、1万円でどの組をいくらずつ買うか | 6 |

**作る順は第1段からである。** 荒れるレースを選べなければ、そのあとの予想も買い目も意味が無いためである。第1段の確かめが済んでから第2段を作る。

## 2. 前提（これまでに分かっていること）

- **帯は倍率ではなく、受け取る金額で決まる。** 帯の倍率は「100万円 ÷ 1点の掛け金」である。1点 100円なら 1万倍、1点 500円なら 2,000倍の組が当たれば帯になる。
- **高配当の組は、市場で買われすぎている。** 研究「回収率100超」「複勝以外の回収率100超」「既存モデルの改善」では、今の予想で3連単・3連複を期待値で買っても 100% に届かなかった。今の予想と同じ見方で穴を拾っても届かない。これが「別の方法」にする理由である。
- **荒れ具合の予想（`src/yosou/upset_level/`）がすでにある。** 一番上の段は3連単なら 50万円以上で、帯より下に線がある。帯を狙うレース選びとして十分かは、まだ確かめていない。今回は、これを比べる目安にする。
- **今の穴馬の予想（`src/yosou/longshots_in_top3/`）は、すべてのレースで学んでいる。** 荒れたレースだけで学んだ予想は、まだ無い。
- **元DB には、3連単・3連複の払戻の明細がある。** 払戻 100万円を線にした資料や道具は、まだ無い。
- 確定オッズで数える。発走10分前のオッズと確定オッズは、ほぼ同じとみなす。

## 3. 決めたこと

利用者から方法を任されたので、次のように決めた（2026-10-12）。

| 決めたこと | 中身 | 理由 |
|---|---|---|
| 1レースの予算 | **1万円**（利用者の指定） | − |
| 主な券種 | **3連単**。3連複は第3段で比べる行として並べる | 3連複で帯が出ることはまれで、1万円では帯の倍率に届く組がほとんど無い |
| 買うレースの数の上限 | **1日1レースまで**（その日でいちばん荒れる見込みの高いレース） | 1万円のレースを1日に何本も買うと、外れが続いたときの減り方が大きすぎる。選ぶレースの数は手順4・7で数えて報告する |
| 予想する時点 | 木曜・前日・当日の全部で作る。**買うかどうかは当日の予想で決める** | 人気の割れ方・馬場・3連単のオッズは前日・当日からしか分からない |
| 荒れの物差し | 3連単の払戻で「帯（100万円以上）」「大荒れ（10万〜100万円）」「それ以外」に分ける。3連複も同じに分けて並べる | 帯だけでは数が少なく、学ぶにも確かめるにも足りないため、10万円以上も使う |
| WIN5 | 対象にしない | 1レース 1万円の形に合わない。5レース分の荒れる前提が要って広がりすぎる |
| お金の出どころ | **帯狙いの財布**を新しく分ける。勝負用・ポリシー用・単勝と馬単用の財布とは別に数える | 帯狙いは外れが長く続くので、ほかの財布の成績と混ぜない |
| 採用の線 | 8 に書く | − |

## 4. 第1段 レース選び

### 4.1 確かめる理論の候補

手順1の事例で確かめる仮の候補である。どれを残すかは、事例を見てから決める。

| 候補 | 中身 | 分かる時点 |
|---|---|---|
| 頭数 | 出走頭数が多いほど組の数が増え、荒れやすい | 木曜 |
| レースの種類 | ハンデ戦・牝馬限定・2勝クラスと3勝クラス・新馬と未勝利・夏のローカル開催 | 木曜 |
| 力の拮抗 | 能力指数や近走の上位が団子で、抜けた馬がいない | 木曜 |
| 読めない馬が多い | 初出走・休み明け・昇級・距離やコースの初挑戦の馬が多い | 木曜 |
| 展開が読めない | 逃げ馬・先行馬が多すぎる、または一頭もいない | 木曜 |
| コース | 小回り・内回り・直線の短いコース、外枠の不利が大きいコースなど | 木曜 |
| 馬場 | 重・不良、雨、開催が進んで荒れた馬場 | 前日・当日 |
| 人気の割れ方 | 1番人気の単勝オッズが高い。上位人気のオッズの差が小さい | 前日・当日 |
| 1番人気の危うさ | 人気馬の予想（`favorites_out_of_top3`）で、1番人気が4着以下になる確率が高い | 前日・当日 |

### 4.2 作り方

- 事例から残した候補を材料にして、レースごとに「帯・大荒れになる点数」を出す。
- 材料が3つ以下に絞れるなら条件のルールにし、それより多いならモデルにする。モデルにするときは、作る前に設計書を `docs/design/` に、今の設計書一式と同じ構成（01〜16）で書く。
- その日の点数がいちばん高いレースを1つ選び、点数が線を超えたときだけ買う。線は 2018〜2020年だけで決める。

### 4.3 物差し

レース選びは馬券を買わないので、回収率ではなく「選んだレースに帯がどれだけ集まったか」で見る。

| 物差し | 意味 |
|---|---|
| 帯の集まり方（倍率） | 選んだレースの帯の割合 ÷ 全レースの帯の割合。2 なら、全レースより2倍帯が出やすい |
| 帯の拾い方 | 全レースの帯のうち、選んだレースに入っていた割合 |
| 選ぶレースの数 | 1年あたり何レースを選ぶか |

## 5. 第2段 荒れる前提の予想

### 5.1 何を予想するか

**荒れたレースだけで学んで、「このレースが荒れるとしたら、どの馬が1着・2着以内・3着以内に来るか」を予想する。**

- 学ぶレース: 3連単の払戻が 10万円以上だったレース（帯と大荒れ）だけ。荒れなかったレースは学びに使わない。
- 答え: 馬ごとの1着・3着以内（3連単の着順を組むため、1着と3着以内の両方を出す）。
- 材料: レースの前に分かる情報だけ。候補は次のとおりで、手順5の事例で残すものを決める。

  | 候補 | 中身 |
  |---|---|
  | 展開で残る | 人気薄の逃げ馬・先行馬が、楽なペースでそのまま残る |
  | 展開で届く | ハイペースで前が崩れ、人気薄の差し馬・追い込み馬が届く |
  | 馬場の偏り | その日の内外・前後の有利不利（トラックバイアス）に合った枠と脚質 |
  | 条件替わり | 距離・コース・芝ダート・休み明け・叩き2戦目など、前走から条件が変わって一変する |
  | 巻き返し | 前走の大敗に理由（不利・道悪・合わない条件）があり、人気を落としている |
  | 斤量と騎手 | ハンデ戦の軽い斤量、減量騎手、騎手の乗り替わり |
  | 人気 | 荒れたレースでも、人気馬が1頭は来ることが多いので、人気も材料に入れる |
  | 今の材料 | 近走・適性・能力指数・展開スコア・血統・騎手・調教師（今の予想と同じもの） |

- 作り方: 今の予想と同じ表の作り方で、LightGBM と CatBoost の両方を学ぶ。作る前に設計書を `docs/design/荒れる前提で3着以内を予想/`（仮の名前）に、今の設計書一式と同じ構成（01〜16）で書く。

### 5.2 予想の出し方

- 第2段の確率の順に、印 ◎○▲△☆注 を付ける（△は3頭）。
- 印の付いた上位の馬が人気薄になっているかを必ず確かめる。上位が人気馬ばかりなら、出し方や使い方を変えて済ませず、学ばせ方を直す。

### 5.3 物差し

- 荒れたレース（2021〜2022年の、3連単 10万円以上のレース）の中で、第2段の上位の馬が実際に1〜3着に来た割合。比べる目安は、同じレースでの今の印。
- 今の印より良くなければ、第3段に進まない。

## 6. 第3段 買い目（1レース 1万円）

第2段の確率から、3連単の組ごとに「荒れる前提の当たる確率」を出す（1着の確率と3着以内の確率から組み立てる）。次の3つの買い方を、結果を見る前に決めておき、2018〜2020年でいちばん良かったものを1つ選ぶ。

| 買い方 | 組の選び方 | 1点の金額 | 点数の目安 |
|---|---|---|---|
| 甲 全部帯 | 当たれば必ず帯になる組だけ買う。組ごとに「帯に要る金額 = 100万円 ÷ その組のオッズ」（100円単位で切り上げ）を出し、当たる確率 × 払戻 ÷ 金額の高い順に、1万円になるまで積む | 組ごとに 100〜1,000円 | 10〜60点 |
| 乙 本線厚め | 1着: 上位3頭 → 2着: 上位5頭 → 3着: 上位8頭のフォーメーション（72点）。組の当たる確率の上位10点を厚くする | 上位10点 300円、残り62点 100円（計 9,200円） | 72点 |
| 丙 3連複 | 3連複で、当たる確率の高い順に、帯に要る金額で1万円になるまで積む | 組ごとに 100〜1,000円 | 10〜30点 |

- 甲は、外れが多い代わりに当たれば全部帯になる。乙は、帯より下の当たりも拾って財布を長持ちさせる。丙は比べる行である。
- 合成オッズを確かめ、当たっても1万円を下回る組（トリガミ）は、乙でも買わない。
- 比べる目安として、同じレースで今の印から作った3連単（1万円分）も並べる。

## 8. 採用の基準（結果を見る前に決めておく）

開催日を単位にしたブートストラップの 90% の幅を使う。どれも 2021〜2022年の結果で判定する。

| 段 | 条件 |
|---|---|
| 第1段 レース選びを使う | 帯の集まり方が 2倍以上で、90% の幅の下の端も 1倍を超える。かつ、荒れ具合の予想で同じ数のレースを選んだときより、帯の集まり方が高い |
| 第2段 荒れる前提の予想を使う | 荒れたレースで、上位の馬が1〜3着に来た割合が、今の印より高い |
| 第3段 勝負用の財布で買う | 回収率が 100% を超え、90% の幅の下の端も 100% を超える |
| 第3段 帯狙いの財布で買う | 2年で帯を1回以上当てていて、いちばん大きい当たりを除いた回収率が 80% 以上（3連単の払戻率 72.5% を上回る線） |
| 採らない | 上のどれにも届かない。比べる行として結果に残す |

数回の大当たりで回収率が大きく上下するので、いちばん大きい当たりを除いた回収率を判定に使う（研究「馬券の買い方の検証」の教訓）。

## 9. 結果の報告で出す数値

1文目には、全部で何レースあって何レースを買い、1レースで何点・何円買ったかを書く。続けて次の数値を出す。

- 全レースのうち何レースを買ったか（年あたり、1日あたり）。どんな種類のレースを選んだか
- 選んだレースのうち、帯・大荒れ・それ以外がそれぞれ何レースか。帯の集まり方と帯の拾い方
- 買い方（甲・乙・丙と今の印）ごとの成績を1つの表にまとめる。列は次のとおり
  - 買ったレース数、点数、的中数、的中率、回収率
  - 帯の回数
  - いちばん大きい当たりを除いた回収率
- 1年の投資額と払戻。最初の帯までに平均で何レースかかったか
- いちばん深い落ち込み（ドローダウン）と、最大の連敗。帯狙いの財布の年の予算は、この2つから決める
- 第2段の上位の馬の人気の分け方（人気薄を選べているか）
