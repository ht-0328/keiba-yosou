# 05 線を下げた買い方の確かめ（計画）

**この文書は計画である。結果を見る前に、候補・期間・採用の基準をここに決めて、コミットしてから数える。** 結果は、この文書の「結果」の節に、あとから書き足す。

## 1. なぜやるか

[04](04-検証の結果.md) では、帯（当たれば 100万円以上）を狙う甲・乙・丙のどれも、採用の基準に届かなかった。そのあと、利用者の「10万以上にするとどのくらい当たるの」に答えるため、甲の「当たれば必ず線以上になる金額で買う」の線を 10万円・30万円に下げて、2021〜2026年で数えた。いくつかの組み合わせで回収率が 100% を超えた。

しかし、その線は 2021〜2026年の結果を見てから試したもので、たまたま良かったものを選んでいるおそれがある。利用者の指示（「見ないで最初からテストして」）で、**買い方の成績をまだ一度も数えていない期間**で、決めた候補だけを確かめる。

## 2. 確かめる期間

**2015〜2020年**（半年ずつ12の区切り。2015年前半〜2020年後半）。

- この期間の、選んだレースの買い目の成績は、まだ一度も数えていない。
- 理論（docs/02・03）を作るのには、2012〜2020年のレースと 2017〜2020年の馬の事例を使った。ただし、そこで見たのはレースや馬の傾向で、買い目の成績や線ではない。線を選ぶのに使った 2021〜2026年とは重ならない。
- 予測は、区切りごとに、その区切りより前のレースだけで学んだモデルで出す（学習は 2012年1月から。いちばん早い 2015年前半の区切りでも 2年半ある）。

## 3. 候補（4つ。これ以外は数えない）

| 候補 | 線 | 予想 |
|---|---|---|
| A | 10万円 | 荒れる前提の予想（荒れたレースだけで学んだ当日の 3着以内と1着） |
| B | 30万円 | 荒れる前提の予想 |
| C | 10万円 | 今の予想（今の本番の当日の 3着以内と1着と同じ列で、全部のレースで学んだもの） |
| D | 30万円 | 今の予想 |

どの候補も、次は同じにする。

- レース選び: 開催日ごとに、荒れ具合の予想（今の本番と同じ作り。同じ区切りで学び直す）の当日の3連単の超荒れの確率がいちばん高いレースを1つ。
- 買い方: 甲と同じ形（`ObiStakePlan`）。3着以内の確率の上位8頭で作った3連単の組のうち、「線 ÷ オッズ」（100円単位で切り上げ）が 1,000円以下の組を、当たる確率 ÷ 金額の高い順に、1レース 1万円に収まるまで、その金額で買う。当たれば必ず線以上の払戻になる。
- オッズは確定オッズで数える。

## 4. 採用の基準（結果を見る前に決める）

最初の計画（[01 の 8](01-狙い方の案と進め方.md#8-採用の基準結果を見る前に決めておく)）の第3段の基準と同じにする。「帯」を「線以上の当たり」に読み替える。開催日を単位にしたブートストラップの 90% の幅を使う。

| 段 | 条件 |
|---|---|
| 勝負用の財布で買う | 2015〜2020年の回収率が 100% を超え、90% の幅の下の端も 100% を超える |
| 遊びの財布（帯狙いの財布）で買う | 6年で線以上の当たりが6回以上（1年に1回以上）あり、いちばん大きい当たりを除いた回収率が 80% 以上 |
| 採らない | 上のどちらにも届かない |

- 4つの候補を比べて、いちばん良いものを選び直すことはしない。基準を満たした候補だけを、満たした段で使う。
- 半年ごとの区切りのうち、回収率が 100% を超えた区切りの数も並べる（判定には使わない）。
