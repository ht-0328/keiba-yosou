# 02 レース選びの理論

**この文書で決めること:** 帯（3連単の払戻が 100万円以上）になるレースには、どんな型があるか。それをどの形（条件のルールかモデルか）でレース選びにするか。

**結論:**

| 決めること | 結論 |
|---|---|
| 帯になるレースの型 | 1番人気が4着以下に負け、6番人気以下の馬が勝つ。そうなりやすいのは、多頭数で、人気が割れていて、展開や馬場が読みにくいレース |
| レース選びの形 | 2つを作って比べる。①モデル: レース単位の表の全部の材料で「帯になる確率」を学ぶ（木曜・前日・当日）。②条件のルール「多頭数で人気が割れている」 |
| 1日に選ぶレース | その日でいちばん点数の高いレースを1つ。点数の線は引かない（理由は 3） |

数値は `reports/百万馬券を当てる/事例-レース選び.md`（Git 対象外）にある。この文書には、言葉でまとめたことだけを書く。

## 1. 見たもの

研究「既存モデルの改善」の `build_tables.py` で、荒れ具合の予想と同じ作り方のレース単位の表を 2012年から作り（`reports/百万馬券を当てる/tables/`）、`cases.py races` で 2012〜2020年のレースを見た。2021年以降は確かめに使うので見ていない。

- 帯のレースは、どの年もおよそ70〜110レースあった（開催日の数と同じくらいで、1日に1レースより少ない）。
- 1つずつ並べた事例は、理論を作る年の最後の2年（2019〜2020年）の181レース。

## 2. 帯になるレースの型

### 2.1 決着の形

- **帯のレースでは、ほぼ全部で1番人気が4着以下に負けていた。** 1番人気が勝って帯になったレースは、ごく一部しかない。
- **勝ち馬の多くは6番人気以下で、10番人気以下も多い。**

つまり、帯は「人気馬が飛んで、人気薄が勝つ」レースで出る。人気馬を軸にした買い目では、帯はほとんど取れない。

### 2.2 帯が集まりやすいレース

| 候補 | 分かったこと |
|---|---|
| 頭数 | いちばんはっきり効く。多頭数（16頭以上）ほど帯が集まり、12頭以下ではほとんど出ない |
| 人気の割れ方 | 上位3頭の市場勝率の合計が小さい（人気が割れている）ほど帯が集まる。1番人気のオッズが高いレースも同じ向き |
| レースの種類 | ハンデ戦と G3 で帯が集まる。4月と1月にやや多く、7月と10月にやや少ない。函館・札幌では少ない |
| 馬場 | 重・不良で帯が集まる |
| 展開が読めない | 逃げそうな馬が3頭以上いると帯が集まる |
| 読めない馬が多い | 乗り替わりの馬が多いと帯が集まる（多頭数と重なる）。前走の無い馬の割合や昇級馬の数は、はっきりしない |
| 力の拮抗 | 近5走の平均着差の1位と2位の差が小さい（抜けた馬がいない）と、やや帯が集まる |
| 1番人気の危うさ | 1番人気の前走の着順などは、はっきりしない |
| コースの単位 | 短距離（1200m 前後）のダートや、ローカルの小回りのコースの道悪で集まる傾向がある。ただし、コースの単位ごとの帯は数レースずつしかなく、たまたまの差と見分けられない |

## 3. レース選びの形

- **モデル**: 1つずつの候補の差は大きくないが、多くの候補が少しずつ効く。そこで、レース単位の表の全部の材料（49個。荒れ具合の予想と同じ）で、目的変数「帯」（1 か 0）を LightGBM と CatBoost で学び、2つの確率の平均を点数にする（`analysis/race_obi_window_trainer.py`）。時点ごとに使える材料が違うので、木曜・前日・当日の3つのモデルを作る。
- **条件のルール**: 事例でいちばんはっきりしていた2つだけで作る。多頭数（16頭以上）のレースを先にし、その中で上位3頭の市場勝率の合計がいちばん小さいレースを選ぶ（`analysis/crowded_split_rule.py`）。人気の割れ方はオッズから分かるので、前日・当日に使える。
- **1日1レース・線なし**: 帯は1日に1レースも出ないので、線を決めるための確かめの年の帯の数が少なく、線を選ぶとたまたまに合わせてしまう。そこで、線は引かず、毎日いちばん点数の高いレースを1つ選ぶ。買うレースの数は1年におよそ100レース（開催日の数）に決まる。

比べる目安は、今の荒れ具合の予想（`yosou.upset_level`）の「3連単の超荒れ（50万円以上）の確率」で、同じく1日1レース選んだもの。同じ表・同じ区切りで学び直した（`walk.py baseline`）。

確かめの結果は [04-検証の結果.md](04-検証の結果.md) に書く。
