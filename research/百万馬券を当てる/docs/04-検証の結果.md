# 04 検証の結果

**この文書で示すこと:** 計画（[01](01-狙い方の案と進め方.md)）の手順4・7・8 の結果と、結果を見る前に決めた採用の基準（01 の 8）による判定。

**結論:**

| 段 | 判定 | 使うもの |
|---|---|---|
| 第1段 レース選び | 新しく作った「帯になる確率」のモデルは**採らない**（確かめの期間で比べる目安と同じだった）。比べる目安（今の荒れ具合の予想の3連単の超荒れの確率）が基準を満たしたので、それを使う | 荒れ具合の予想の学習済みモデル |
| 第2段 荒れる前提の予想 | **使う**。荒れたレースで、上位の馬が1〜3着に来た割合が今の予想より高かった。1着の上位にも人気薄を選べている | 荒れたレースだけで学んだ 3着以内と1着のモデル |
| 第3段 買い目 | 甲・乙・丙の**どれも採らない**。勝負用の基準にも、帯狙いの財布の基準にも届かなかった | 実際のお金では買わない。道具「帯狙い」は買い目を参考として出す |

数値は `reports/百万馬券を当てる/`（Git 対象外）の `レース選びの結果.md`・`来る馬の予想の結果.md`・`買い目の結果.md` と、`印の成績/`（全券種の回収率）にある。この文書には、判定と言葉でまとめたことだけを書く。

## 1. 第1段 レース選び（手順4）

開催日ごとに点数がいちばん高いレースを1つ選び、まだ見ていない 2021〜2022年の 214レース（開催日の数）で確かめた。

- 新しく作った当日の「帯になる確率」のモデル（研究の `walk.py race`）も、比べる目安も、選んだレースのうち帯は同じ15レースだった。どちらも帯の集まり方は2倍を超え、90% の幅の下の端も1倍を超えた。
- 採用の条件は「比べる目安より高い」こと（01 の 8）なので、新しいモデルは採らない。基準（2倍以上・幅の下の端が1倍超え）を満たした比べる目安を、そのままレース選びに使う。今の本番の荒れ具合の予想の学習済みモデル（3つの時点）を使えるので、新しく学習するものが減る。
- 前日のモデルは確かめの期間で目安を上回ったが、参考の 2023〜2026年では大きく下がった。たまたまと見分けられないので採らない。
- 条件のルール「多頭数で人気が割れている」は、確かめの期間で目安を下回った（参考の期間では上回った）。

## 2. 第2段 荒れる前提の予想（手順7の前半）

研究の `walk.py horses` で、今の本番の当日の 3着以内と1着のモデルと同じ表・同じ列・同じ基準のまま、学ぶ行を荒れたレース（3連単の払戻が 10万円以上）だけにして、11の区切りで学んだ。今の予想（研究「複勝以外の回収率100超」の、同じ区切りで学び直した今の本番）と比べた。

| 比べたこと（2021〜2022年） | 荒れたレース | 帯のレース | 選んだレース（荒れなかったレースも含む） |
|---|---|---|---|
| 上位5頭のうち3着以内に来た頭数 | わずかに多い | 多い | 少ない |
| 1〜3着が全部、上位8頭に入っていた | 多い | どちらもほとんど無い | わずかに少ない |
| 勝ち馬が、1着の上位3頭に入っていた | わずかに多い | はっきり多い | 少ない |

- 採用の条件（荒れたレースで今の予想より高い）は満たした。帯のレースでは差がはっきりしている。
- **人気薄を選べている。** 1着の上位3頭に人気薄（6番人気以下）が入る割合は、今の予想ではほぼ無いのに対し、荒れる前提の予想では1割を超えた。荒れたレースだけで学ばせると、人気馬を下げ、人気薄を上げることを学ぶ（docs/03 の理論どおり）。
- ただし、選んだレースの全体（荒れなかったレースも含む）では、今の予想のほうが当たっていた。選んだレースの多くは荒れないので、「荒れる前提」で外したぶんが効いている。

## 3. 第3段 買い目（手順7）

選んだレース（比べる目安で1日1レース）で、甲・乙・丙を1レース 1万円で買ったとき。確定オッズで数えた。

| 買い方 | 荒れる前提の予想（確かめの 2021〜2022年） | 判定 |
|---|---|---|
| 甲 全部帯（3連単） | 帯は1回だけ。回収率は 100% に遠く届かず、その1回を除くと払戻は無かった | 採らない |
| 乙 本線厚め（3連単） | 回収率は 100% に届かなかった。いちばん大きい当たりを除いた回収率は 80% を超えたが、帯は1回も無かった | 採らない（帯が無い） |
| 丙 全部帯（3連複） | 帯に要る金額で買える組がほとんど無く、買えたレースでも当たらなかった | 採らない |

- **1レース 1万円・1日1レースだと、1年でおよそ 100万円を使う。** 甲は当たればすべて帯だが、2年で1回しか当たらず、外れが100レース以上続いた。乙は当たりが多く財布の減り方は小さいが、払戻が帯に届く当たりが無かった。
- 比べる行の「今の予想で甲」は、確かめの2年で帯が数回あり、回収率も 100% を超えた。しかし参考の 2023〜2026年では 100% を下回り、いちばん大きい当たりを除くと大きく下がった。帯の当たりは数回しかなく、たまたまと見分けられない。結果を見てから採る買い方を替えると、たまたま良かったものを選んでしまうので、今回は採らない。
- 荒れる前提の予想の乙は、参考の期間では回収率が 100% を超えた。確かめの期間では超えていないので、これも採らない。

**まとめ。** 帯の当たりは、1日1レース・2年で数回しか起きない。数回の当たりの有無で回収率が大きく動くので、2年の確かめでは、どの買い方が良いかを見分けられなかった。

## 4. 印の成績（手順8）

荒れる前提の予想の印（今週の予想と同じ決め方）で、道具「印の成績」の全券種の買い目の回収率を、2021〜2026年の11の区切りの全レースで数えた。結果は `reports/百万馬券を当てる/印の成績/` にある。

- 全レースに当てはめると、どの券種の買い目も回収率が 100% に届かず、今の予想の印より下がる。荒れないレースでも人気薄を上位にするためで、理論（docs/03）どおりである。
- そのため、荒れる前提の予想は、今週の予想の印には使わない。第1段で選んだレース（荒れやすいレース）にだけ使う。

## 5. 計画から変えたこと

| 計画（01） | 変えたこと | 理由 |
|---|---|---|
| 手順1・5 の事例は 2016〜2020年 | レースの事例は 2012〜2020年、馬の事例は 2017〜2020年 | レース単位の表は荒れ具合の予想の学習と同じく 2012年から作れた。馬ごとの表（研究「既存モデルの改善」）は 2017年からしか無い |
| 甲・乙・丙は 2018〜2020年でいちばん良かったものを1つ選ぶ | 3つとも、まだ見ていない 2021〜2022年で採用の基準に照らした | 荒れる前提の予想の予測は、学習に 3年半は要るので、2021年前半の区切りより前を作れない（研究「複勝以外の回収率100超」の `early_windows.py` と同じ理由）。どれも基準に届かなかったので、選び方の違いは判定を変えなかった |
| 設計書のフォルダ名は「荒れる前提で3着以内を予想」（仮） | 「荒れる前提で着順を予想」 | 3着以内だけでなく1着も当てるため |
| 第1段にモデルを作る場合は設計書を書く | 新しいモデルは採らなかったので、設計書には書かない（研究の `walk.py race` に残す） | 本番で使わないものを設計書に載せない |

## 6. 動かすもの

採用の判定にかかわらず、利用者の依頼どおり、次の形で動かせるようにした（設計書 `docs/design/荒れる前提で着順を予想/`）。

- 予想 `yosou.upset_premise`: 荒れたレースだけで学ぶ 3着以内と1着（木曜・前日・当日）。`uv run python -m yosou.upset_premise train` で学習する。
- 道具「帯狙い」（`tools/帯狙い/obi.py`）: 開催日ごとにレースを選び、荒れる前提の予想で、1レース 1万円の買い目を出す。買い目は参考で、財布にも買い目の記録にも書かない（第3段を採らなかったため）。
