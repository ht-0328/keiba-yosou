# 03 来る馬の理論

**この文書で決めること:** 荒れたレース（3連単の払戻が 10万円以上）では、どんな人気薄が1〜3着に来るか。それをどの形で予想にするか。

**結論:**

| 決めること | 結論 |
|---|---|
| 荒れたレースで来る人気薄の型 | いつもの「近走が良い・力が上・人気がある」という差が、荒れたレースでは大きく縮まる。いつもは来ない9〜13番人気、前走で大敗した馬、力の順位が下のほうの馬、追込の馬が、いつもよりずっと来る |
| 予想の形 | 今の本番の予想（近走と適性から3着以内を予想）と同じ材料・同じ列のまま、**学ぶ行を荒れたレースだけにした** 3着以内と1着のモデル。予測は選んだレースの全頭に出す |

数値は `reports/百万馬券を当てる/事例-来る馬.md`（Git 対象外）にある。この文書には、言葉でまとめたことだけを書く。

## 1. 見たもの

`cases.py horses` で、2017〜2020年の人気薄（確定の単勝6番人気以下）を、荒れたレースとそれ以外のレースに分け、切り口の値ごとに3着以内の割合を比べた。馬ごとの材料は、今の本番の当日の3着以内のモデルの表（研究「既存モデルの改善」の `dscore_race_day`）の列を使った。

## 2. 荒れたレースで来る人気薄の型

| 切り口 | それ以外のレース | 荒れたレース |
|---|---|---|
| 人気（9〜13番人気） | ほとんど来ない | 人気薄の平均に近いくらい来る。差がいちばん大きく縮まる |
| 近走（前走の着順・着差、近5走の平均着順） | 前走で負けた馬はほとんど来ない | 前走で大敗した馬もかなり来る |
| 力の順位（能力指数・相対着順のレース内順位） | 下のほうの馬はほとんど来ない | 下のほうの馬もかなり来る |
| 脚質 | 逃げ・先行が来やすい | 差が縮まり、追込の馬もいつもより来る |
| 騎手・調教師の成績の順位 | 下のほうはほとんど来ない | 下のほうも来る |
| 条件替わり（芝ダ替わり） | 芝ダ替わりの馬は来にくい | 来にくさが縮まる |
| 枠・馬番 | 差が無い | 差が無い |
| 14番人気以下・単勝 160倍以上 | 来ない | 荒れたレースでも来にくい |

つまり、荒れたレースは「力どおりにならないレース」で、ふだんの予想の材料（近走・力・人気）が効きにくくなる。そのかわりに、ふだんなら消す馬がまとめて来る。ただし、どの材料でも、下の下（14番人気以下など）までは来ない。

## 3. 予想の形

- 学び方: 今の本番の当日のモデルと同じ表・同じ列・同じ基準（オッズから見た確率を出発点にして、そこからの上げ下げを学ぶ）にし、**学習と早期終了に使う行を、荒れたレースの行だけにする**（`analysis/wild_only_window_trainer.py`）。荒れたレースでは、オッズから見た確率が人気馬を高く見すぎているので、モデルは人気馬を下げ、来る人気薄を上げることを学ぶ。
- 目的変数: 3着以内と1着の2つ（3連単の着順を組むため）。
- 予測: 選んだレースの全頭に出す。レースを選ぶ時点では、荒れるかどうかは分からないためである。荒れなかったレースでは外れる前提で、その外れも含めて回収率を数える。
- 確かめ: 荒れたレースで、上位の馬が実際に1〜3着に来たかを、今の予想と比べる。あわせて、上位に人気薄を選べているかを数える（人気上位しか選べないなら、学ばせ方を直す）。

確かめの結果は [04-検証の結果.md](04-検証の結果.md) に書く。
