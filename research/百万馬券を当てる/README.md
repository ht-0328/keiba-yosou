# 百万馬券を当てる

**何をする研究か。** 払戻が 100万円以上になる馬券（いわゆる「帯」）を当てる買い方を探す。そのあと、狙いを「3連単が 1,000倍以上（払戻 10万円以上）で決まるレースを選んで当てる」に広げ、レース選びの精度と、選んだレースでの的中率を上げる（[docs/06](docs/06-1000倍以上のレースを狙う.md)）。

**なぜ始めたか。** 利用者が帯を当てたいと希望した（2026-10-12）。
これまでの買い方は、回収率 100% を超えることだけを目当てにしてきた。そのため、実際に買っているのは複勝と、一部のレースの単勝・馬単だけである。3連単・3連複・WIN5 は参考として出すだけで、帯を当てる仕組みはまだ無かった。

**狙い方。** 「このレースは荒れる」と最初から決めて、そのレースだけは今の予想とは別の方法で予想し、1レース 1万円で3連単を買う。

| 段 | 何を決めるか | 文書 |
|---|---|---|
| 第1段 レース選び | 開催日ごとに、荒れやすいレースを選ぶ（最初は1つ。今は線以上のレースを全部） | [docs/02](docs/02-レース選びの理論.md)・[docs/06 の 2](docs/06-1000倍以上のレースを狙う.md#2-レース選びの精度) |
| 第2段 荒れる前提の予想 | 荒れたレースだけで学んだモデルで、選んだレースの1着・3着以内の確率を出す | [docs/03](docs/03-来る馬の理論.md) |
| 第3段 買い目 | 1万円で3連単（と比べる3連複）を組む。今は一律（1,000倍以上の組を組の確率の高い順に一律の金額で） | [docs/01 の 6](docs/01-狙い方の案と進め方.md#6-第3段-買い目1レース-1万円)・[docs/06 の 3](docs/06-1000倍以上のレースを狙う.md#3-選んだレースでの的中率) |

**結果（[docs/04](docs/04-検証の結果.md)・[docs/06](docs/06-1000倍以上のレースを狙う.md)）。** まだ見ていない 2021〜2022年で確かめた。レース選びは、新しく作った「帯になる確率」のモデルも「1,000倍以上になる確率」の専用モデルも今の荒れ具合の予想と同じだったので、荒れ具合の予想（3連単の大荒れ＋超荒れの確率）を使い、線以上のレースを全部買う。荒れる前提の予想は、荒れたレースで今の予想より上位の馬が来て、人気薄も選べたので使う。買い目は、一律（1着は荒れる前提の予想、2着・3着は今の予想と荒れる前提の予想の3着以内の確率の平均の重み）が、1,000倍以上で決まったレースをいちばん当てたので既定にした。順位の付け方を 2021〜2026年の結果を見て選んだので、まだ見ていない期間での確かめが無く、実際のお金では買わず、参考として出す。
本番で動かすものは、予想「荒れる前提で着順を予想」（`src/yosou/upset_premise/`、設計書 `docs/design/荒れる前提で着順を予想/`）と道具「帯狙い」（`tools/帯狙い/`）。

## この文書で使う言葉の意味

| 用語 | 意味 | 架空の例 |
|---|---|---|
| 帯 | 1つの的中で受け取る払戻が 100万円以上になること。倍率ではなく受け取る金額で数える。レースについて言うときは、3連単の払戻（100円あたり）が 100万円以上のレース | 3連単 2,500倍を 400円買って当てると 100万円 |
| 大荒れ | 3連単の払戻（100円あたり）が 10万円以上 100万円未満のレース | − |
| 荒れたレース | 帯と大荒れのレース（3連単の払戻が 10万円以上） | − |
| 帯の倍率 | 100万円 ÷ 1点の掛け金。この倍率以上の組が当たると帯になる | 1点 100円なら 1万倍、1点 1,000円なら 1,000倍 |
| 帯の集まり方 | 選んだレースの帯の割合 ÷ 全レースの帯の割合。2 なら、全レースより2倍帯が出やすいレースを選べている | − |
| 人気薄 | 確定の単勝6番人気以下 | − |
| 帯狙いの財布 | 帯を狙う買い目にだけ使うお金。勝負用・ポリシー用・単勝と馬単用の財布とは分けて数える | − |

## フォルダの中身

| 場所 | 何があるか |
|---|---|
| `docs/` | 狙い方と進め方（01）、事例から分かったこと（02・03）、検証の結果（04）、1,000倍以上のレースを狙う（06） |
| `cases.py` | 入口①。帯のレースの事例（手順1）と、荒れたレースで来た人気薄の事例（手順5）を出す |
| `walk.py` | 入口②。区切りごとに学んで、レース選び（帯になる確率・1,000倍以上になる確率）と荒れる前提の予想の予測を作る。比べる目安（今の荒れ具合の予想）も学び直す |
| `backtest.py` | 入口③。レース選び（手順4）、来る馬の予想（手順7の前半）、買い目（手順7）、レース選びの精度と一律の買い目（docs/06）を確かめる |
| `analysis/` | 部品（一覧は `analysis/__init__.py`） |
| `tests/` | 架空の値で部品を確かめるテスト |
| `reports/百万馬券を当てる/`（Git 対象外） | 実測の数値。レース単位の表（`tables/`）、予測（`predictions/`）、事例と結果の Markdown、買い目（`買い目/`）。JV-Data 由来の値はここにだけ置く |

## 動かし方

リポジトリ直下（`keiba-yosou/`）から実行する。先に研究「既存モデルの改善」の `build_tables.py` で馬ごとの表（`dscore_race_day` など）を作っておく。

```bash
uv run python research/既存モデルの改善/build_tables.py --only upset_level --tables reports/百万馬券を当てる/tables  # レース単位の表を 2012年から作る（1分ほど）
uv run python research/百万馬券を当てる/cases.py races      # 手順1: 帯のレースの事例
uv run python research/百万馬券を当てる/cases.py horses     # 手順5: 荒れたレースで来た人気薄の事例
uv run python research/百万馬券を当てる/walk.py race        # 第1段のモデル（帯になる確率）を 11の区切りで学ぶ（3時点。数分）
uv run python research/百万馬券を当てる/walk.py big         # 第1段の専用モデル（1,000倍以上になる確率）を同じ区切りで学ぶ（3時点。30分ほど）
uv run python research/百万馬券を当てる/walk.py baseline    # 比べる目安の荒れ具合の予想を同じ区切りで学び直す（1時間ほど）
uv run python research/百万馬券を当てる/walk.py horses      # 第2段のモデルを 11の区切りで学ぶ
uv run python research/百万馬券を当てる/backtest.py races   # 手順4: レース選びの結果
uv run python research/百万馬券を当てる/backtest.py horses  # 手順7の前半: 来る馬の予想の結果
uv run python research/百万馬券を当てる/backtest.py bets    # 手順7: 買い目の結果（初回は元DB からオッズを読む）
uv run python research/百万馬券を当てる/backtest.py select  # docs/06 の 2: 同じレース数を選んだときのレース選びの精度
uv run python research/百万馬券を当てる/backtest.py flat    # docs/06 の 3: 線以上のレースを全部買う一律の買い目の結果（初回は元DB からオッズを読む）
uv run python -m pytest -q research/百万馬券を当てる         # 部品のテスト（架空の値だけ）
```

（1行目は、荒れ具合の予想と同じ作り方のレース単位の表を、この研究の置き場に作るコマンド。2〜3行目は事例を Markdown に出すコマンド。4〜7行目は、まだ見ていない 2021〜2022年の4つと参考の 2023〜2026年の7つの区切りで学び、予測を残すコマンド。8〜12行目は確かめの表を出すコマンド。最後は部品のテスト）
