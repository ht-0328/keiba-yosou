# 04 段2 の結果

**この文書で決めること:** [03-次の段の案.md](03-次の段の案.md) のおすすめで作った「人気薄の1着の予想」（荒れる前提の予想）が、人気薄の中から勝ち馬を選べるようになったか。それを WIN5 の「抑え」として今の買い目（本線）に足すと、高配当を当てられるようになるか。採用するか。

**結論:**

| 決めること | 結論 |
|---|---|
| 選んだ学び方 | 比べた5つの作り方のうち「6番人気以下で学ぶ」（学ぶ行を 6番人気以下に広げ、オッズから見た勝率を出発点にし、レースごとに重みをそろえた二値分類。材料は今のモデルの1着の材料＋型の材料）。ただし、どの作り方も人気の順・今のモデルとの差はわずか |

| WIN5 での使い方 | 本線（今の買い目: 1着の確率の順・50点・日の期待値 1.25 以上の日に買う）はそのまま。本線を買う日に、荒れそうなレースを本線に無い人気薄に差し替えた「抑え」（10〜30点）を足す形にした |

| 2026-11-08 | 選んだ人気薄の1着の予想は、1レース目の勝ち馬（締め切り前 11番人気）を人気薄（2頭）の中の2位、4レース目の勝ち馬（16番人気）を人気薄の中の7位に置いた。本線にも抑えにも、どちらの勝ち馬も入らなかった（[下の 5.](#5-2026-11-08)） |
| 判定 | **採用しない**（利用者の決まり ① の「100万円以上の的中が本線だけより多い」を、2025年〜で満たさない）。段3 には進まない |

数値は `reports/WIN5で人気薄の勝ち馬を狙う/段2の結果.md`（Git 対象外）にある。払戻の額もそこにある。この文書には回数と割合だけを書く。

## 1. 作ったもの: 人気薄の1着の予想

docs/03 の 1.2 のおすすめどおりに作り、比べる作り方も同じ区切りで学んだ。

| 項目 | 作ったもの |
|---|---|
| 目的変数 | その馬が1着なら 1 |
| 学ぶ行 | 平地のレースの 10番人気以下（確定の単勝人気）の馬だけ。2012年からの今のモデルの学習の表（研究「複勝以外の回収率100超」の `tables-2012`）の行を使う |
| 人気の与え方 | オッズから見た勝率のロジットを出発点にし（LightGBM の `init_score`、CatBoost の `baseline`）、モデルはそこからの上げ下げだけを学ぶ。人気の順位そのものは材料から外した |
| 重み | レースごとに人気薄の行の重みの合計をそろえる |
| 材料 | 今のモデルの1着の材料（当日 294・前日 209。人気順位を除く）に、段1 の型の材料 24 を足した（逃げ・先行と差し・追込での好走の回数（全部と近5走）、前走の脚質、推定脚質、楽に前へ行けるか、同じ格以上での好走歴・勝ち歴、前走との距離の差、馬場の替わり、クラスが下がった幅、ハンデ戦の斤量の差、騎手の勝率の前走との差、人気薄の市場合計、1番人気のオッズ、型 A〜G の真偽） |
| 時点 | 当日と前日 |
| 道具 | LightGBM と CatBoost の平均（ハイパーパラメータは今のモデルの初期値） |
| 確かめの予測 | 今のモデルの区切りごとの予測と同じ 15 の区切り（2019年前半〜2026年）。どの区切りも、その半年より前で学び、直前の半年で木を足すのを止め、その半年を予測した |

比べた作り方（どれも同じ区切り・同じ材料）:

| 作り方 | 違い |
|---|---|
| 10番人気以下で学ぶ（おすすめ） | 上のとおり |
| 10番人気以下で学ぶ（重みなし） | 重みをそろえない |
| 10番人気以下で学ぶ（出発点は今のモデル） | 出発点を、今のモデルのそろえた1着の確率（区切りごとの予測）に替える。今のモデルの予測がある 2015年からの行で学ぶ |
| 6番人気以下で学ぶ | 学ぶ行を 6番人気以下に広げる（確かめは 10番人気以下で） |
| 人気薄が勝ったレースだけで並べ替えを学ぶ | 10番人気以下が勝ったレースの人気薄の行だけで「どれが勝ったか」を並べ替えとして学ぶ（LightGBM の `lambdarank`、CatBoost の `YetiRank`。出発点はオッズから見た勝率）。点数は「そのレースの人気薄の市場合計 × 学習の期間の実際 ÷ 市場」をレースの人気薄の中で分けて確率にする |

作り方は、2019〜2024年の平地の全レースで「人気薄が勝ったレースの勝ち馬を、人気薄の中の上位3頭に置けた割合」がいちばん大きいものを選ぶ（同じなら対数損失の小さいほう）。

## 2. 人気薄の中の並べ方と確率の当たり具合

人気薄（10番人気以下）が勝ったレースで、人気薄の中を並べたとき、勝ち馬を上位3頭に置けた割合（段1 の表と同じ形。全部の作り方の予測がそろったレースだけ）。

| 並べ方 | 平地 2019〜2024年（845レース） | 平地 2025年〜（238レース） | WIN5 2019〜2024年（98レース） | WIN5 2025年〜（41レース） |
|---|---|---|---|---|
| 人気の順 | 74.3% | 73.5% | 72.4% | 73.2% |
| 今のモデル | 75.1% | 73.9% | 71.4% | 68.3% |
| 10番人気以下で学ぶ（おすすめ） | 73.7% | 74.4% | 70.4% | 70.7% |
| 10番人気以下で学ぶ（重みなし） | 74.6% | 73.1% | 72.4% | 75.6% |
| 10番人気以下で学ぶ（出発点は今のモデル） | 74.8% | 73.9% | 73.5% | 70.7% |
| **6番人気以下で学ぶ（選んだ）** | **76.1%** | 73.9% | 75.5% | 75.6% |
| 人気薄が勝ったレースだけで並べ替えを学ぶ | 75.0% | 73.9% | 70.4% | 75.6% |
| でたらめに選んだとき（目安） | 46.9% | 45.5% | 45.2% | 45.6% |

- 1レースの人気薄は平均 6.4〜6.6頭。人気の順に3頭選ぶだけで、人気薄の勝ち馬の 7割余りを拾える。どの学び方も、そこから 1〜2ポイントしか上積みできなかった（WIN5 のレースは数が少なく、1レースで 1〜2.5ポイント動く）。
- 対数損失（人気薄の1着の確率の当たり具合。小さいほど良い）は、平地 2019〜2024年で 人気の順 0.04637・今のモデル 0.04608・選んだ作り方 0.04614。どの作り方も今のモデルとの差は 0.5% 未満。確率の合計 ÷ 実際の勝ちは、人気の順 1.07（市場は人気薄の勝ちを多めに見る）、今のモデル 1.02、選んだ作り方 1.00。
- 段1 で市場が見落としていた型（G・E）を材料に足しても、順位を動かすほどの差にはならなかった。人気薄の中の違いのほとんどは、市場（オッズ）がすでに値段に入れている。

## 3. WIN5 での使い方: 本線と抑え

利用者の決めたとおり、今の買い目（今のモデルの1着の確率・1着の確率の順・50点・日の期待値 1.25 以上の日に買う）は **本線** としてそのまま出し続ける。人気薄の1着の予想は、本線とは別の **抑え**（荒れる前提の買い目）にだけ使う。

- **抑えの組み方:** 本線を買う日に、荒れそうなレース（段1 の R1 人気薄に票が残る か R3 ハンデ戦。人気薄の市場合計の大きい順）を最大 1〜2 つ選び、そのレースを **本線で選んでいない人気薄（10番人気以下）の上位 k 頭** に差し替え、ほかのレースは確率の上位から、点数が抑えの予算以下で見積もりの払戻の合計がいちばん大きい頭数にする（見積もりは今の組み方と同じ）。荒れそうなレースで本線に無い馬だけを使うので、抑えのどの組も本線と重ならない（＝少なくとも1レースは人気薄が勝つ組だけ）。
- **候補:** 荒れそうなレースの数 1・2 × 人気薄 2・3・4頭 × 抑えの点数 10・20・30点 × 抑えの日の期待値の線（無し・1.00）= 36。人気薄を「人気薄の1着の予想の順」で選ぶもの（ほかのレースの確率も、人気薄を置き換えた確率）と、比べる決まりとして「人気の順」で選ぶもの（今のモデルの確率）の両方。
- **選び方:** 2019〜2024年で、本線＋抑えの回収率がいちばん高い候補（同じなら 100万円以上の的中が多いもの）。決まりも同じ選び方。
- **採用の決まり（利用者の決まり。結果を見る前に決めた）:** 2019〜2024年と 2025年〜の両方で、①本線＋抑えの 100万円以上の的中が本線だけより多く、②本線＋抑えの回収率が本線だけの 8割以上（回収率を大きく下げない）なら採用。
- **2025年〜を使うのは3回目**（WIN5 の買い方の確かめの 240点と、50点に決め直したあとに続いて）。この期間の結果だけでは決めず、2026年11月以降の毎週の答え合わせも見る。

## 5. 2026-11-08

2026-11-08 の5レースを、学習の表の最後の日（2026年10月12日）までの全部の行で学び直した人気薄の1着の予想（6番人気以下で学ぶ・当日の時点）と、今のモデルの予測の流れ（WIN5 の予想と同じ組み立て）で予想し直した。人気は元DB にある締め切り前の単勝オッズの順。払戻はまだ分からない日なので、勝ち馬が入ったかだけを見る。表は `段2の結果.md` の「詳しく見る日 2026-11-08」。

- 本線（50点）は 6×2×1×1×4 頭で、1・3・4レース目の勝ち馬が入らなかった（3レース目は2番人気の勝ち馬を外し、1頭に絞っていた）。

## 6. 判定と、足りなかったこと

**判定: 採用しない。** 利用者の決まりのうち ②（回収率を大きく下げない）は両方の期間で満たしたが、①（100万円以上の的中が本線だけより多い）は 2019〜2024年だけで、2025年〜では満たさなかった（抑えが1回も当たらない）。決まりどおり、段3（設計書・パッケージ・通知への組み込み）には進まない。

足りなかったこと:

1. **人気薄の中から勝ち馬を選ぶ力が、学び方を変えても伸びない。** 学ぶ行を人気薄だけにし、出発点をオッズ（または今のモデル）にして上げ下げだけを学ばせ、段1 の型の材料も足したが、上位3頭に勝ち馬を置ける割合は人気の順より 1〜2ポイント高いだけだった。人気薄の中の違いは、ほとんどが市場にすでに織り込まれている。段1 で市場が見落としていた型（G 前で運べば走る馬が前走は後ろで負けた・E ハンデで軽い）も、効く馬の数が少なく、順位を動かすほどではない。
2. **16番人気のような大穴は、人気薄の中でも下のほうに置かれる。** 2026-11-08 の4レース目の勝ち馬は、選んだ予想でも人気薄の中の7位だった。荒れそうなレースに人気薄を3〜4頭入れても届かない。7頭以上を入れると、10〜30点の抑えでは他の4レースを1頭ずつにするしかなく、当たりにつながらない。
3. **抑えが当たるには、他の4レースも当てる必要がある。** 人気薄の勝ち馬を買い目に含めた割合は 1割前後から 3割近くまで上がったが、抑えの点数が少ないので他のレースを絞らざるを得ず、6年あまりで当たりは2回だった。100万円以上の当たりは1回だけで、確かめの結果はこの1回に左右される。
4. **確かめられる日が少ない。** 本線を買う日は 2025年〜で 83日しかなく、抑えの当たりのような「数年に1回」の出来事は、この長さでは良し悪しを決めきれない。2025年〜はすでに3回目の利用でもある。

この研究で作った人気薄の1着の予想（区切りごとの予測）と抑えの組み方は、`reports/WIN5で人気薄の勝ち馬を狙う/` と `research/WIN5で人気薄の勝ち馬を狙う/analysis/` に残してある。
