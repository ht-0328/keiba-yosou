# 01 事例

**この文書で決めること:** 人気薄（10番人気以下）が勝ったレースを、WIN5 の対象レースと平地の全レースから集め、どんなレースで・どんな馬が勝ったかを1つずつ見た結果。2026-11-08 の2レースを詳しく見た結果。

**結論:**

| 決めること | 結論 |
|---|---|
| 事例の数 | 2019年1月〜2026年11月8日。WIN5 の対象レース 2,412 のうち 144（6.0%）、平地の全レース 26,195 のうち 1,100（4.2%）で人気薄が勝った。WIN5 の 483日のうち 129日（26.7%）は、5レースのどれかを人気薄が勝った |
| どんなレースか | 人気薄が勝つのは、頭数が多く、1番人気が抜けておらず、市場が人気薄にも票を残しているレースに大きく偏る。ハンデ戦も多い。WIN5 の対象レースは、ふだんのレースより人気薄が勝ちやすい（多頭数・3勝クラス〜重賞・ハンデ戦が多いため） |
| どんな馬か | 勝った人気薄の多くは、レースの前に見えていた手がかり（上のクラスでの好走歴、前の走の負けに理由がある、前で運べる展開、ハンデで軽い、騎手の上積み など）を1つ以上持っていた。WIN5 の対象レースで、手がかりを1つも持たなかったのは 144頭のうち 9頭だけ |
| 今のモデルの見方 | 今のモデルは、勝った人気薄に、どれもオッズから見た勝率とほぼ同じ確率しか付けていなかった。レースの中の順位は、予測のある 140頭のうち 137頭が9位以下で、5位以内は1頭もいなかった（2026年9月下旬〜10月の4頭は、区切りごとの予測も予想の記録も無い） |
| 2026-11-08 の2頭 | どちらも、レースの前に手がかりがあった。共通するのは「前で運ぶと走る馬が、近走では後ろからの競馬になって負けていた」こと。16番人気の馬は、同じ格のハンデ重賞で2着に来たことがある馬で、レースの側からも「いちばん荒れそうなレース」と読めた（[下の 5.](#5-2026-11-08-の2レース)） |

数値は `reports/WIN5で人気薄の勝ち馬を狙う/事例.md`（Git 対象外）にある。全部の事例の一覧は同じ場所の `WIN5の事例.csv`・`平地の事例.csv`。この文書には回数と割合だけを書く。

## 1. 集め方

- 期間: 2019年1月5日〜2026年11月8日の中央の平地のレース（障害は除く）。
- 人気: 確定の単勝人気。オッズは確定オッズで、締め切り前のオッズとほぼ同じとみなす（2026-11-08 の1レース目のように、確定と締め切り前で人気の順が少し入れ替わる馬はいる）。
- WIN5 の対象レース: 元DB の WIN5 の表（`wf` と子表の対象レース）。成績の版（月曜）に加え、その日の速報の版の回（2026-11-08）も入れた。中止の回は除いた。
- 今のモデルの1着の確率: 研究「複勝以外の回収率100超」の区切りごとの当日の予測（その半年より前だけで学び直した、今のモデルと同じ作りのもの。2026年9月22日まで）。それより後の WIN5 の日は、WIN5 の予想の記録（`reports/近走と適性からWIN5の買い目を決める/記録/`）の値。
- 材料: 事実表の列（前の走・距離やコースの替わり・コース実績・持ち時計・脚質・逃げ候補の数・斤量・騎手・ブリンカー など）に、過去走からたどった列（前の走のクラス・馬場・騎手、これまでに3着以内に入った最高のクラス、逃げ・先行で好走した回数と差し・追込で好走した回数）、騎手と調教師の前の年の勝率、父の産駒の芝ダ・馬場（良か道悪か）ごとの前の年までの勝率を足した。どれもレースの前に分かる値である。
- 結果側の値（ペース・4コーナーの位置・上がり・着差・1番人気の着順）は、何が起きたかを理解するためだけに見た。予想の材料にはしない。
- 調教の内容は、この段では見ていない（今のモデルの材料には入っている）。

## 2. 事例の数

| 範囲 | レース数 | 人気薄が勝った | 割合 |
|---|---|---|---|
| 平地の全レース | 26,195 | 1,100 | 4.2% |
| WIN5 の対象レース | 2,412 | 144 | 6.0% |

- WIN5 の 483日のうち、人気薄が勝ったレースが 0 の日は 354日（73.3%）、1レースの日は 115日（23.8%）、2レースの日は 13日（2.7%）、3レースの日は1日（0.2%）。**4日に1日は、人気薄を1頭も買い目に入れなければ WIN5 は当たらない。**
- 勝ち馬の人気で見ると、WIN5 の対象レースは平地の全体より1番人気の勝ちが少なく（全体の 33.2% に対して 28.8%）、10番人気以下の勝ちが多い（4.2% に対して 6.0%）。16番人気以下の勝ちも、WIN5 で7回あった。
- 市場の見立てとの比べ: 人気薄全体では、実際に勝った数は市場が見た数より少し少ない（人気薄はふだん、オッズほどには勝たない）。

表は `事例.md` の「平地の全レースの分布」「WIN5 の対象レースの分布」。コースの単位（競馬場・芝ダ・距離・馬場状態）ごとの表も同じ場所にある。

| 切り口 | 見えたこと |
|---|---|
| 頭数 | いちばん大きく分かれる。10頭以下ではほとんど起きず（平地 0.2%）、15頭以上で多い（15〜16頭 6.0%・17〜18頭 7.7%）。WIN5 の対象レースの人気薄の勝ち 144 のうち 114 が15頭以上だった |
| 1番人気の単勝オッズ | 1番人気が抜けていないほど多い。2倍以下 2.3% → 4倍を超えると 9.1%、5倍を超えると 18.5%（平地） |
| 人気薄の市場合計 | 市場自身が分けている。0.03 未満 0.8% → 0.12 以上 15.6%（平地）。市場の見立てとの比は、荒れそうと見られたレースほど1に近く、固いと見られたレースでは市場の見立てより少ない |
| 重量種別 | ハンデ戦が多い（平地 8.6%、WIN5 9.7%）。市場の見立てより1割ほど多く勝っている |
| クラス | 3勝クラス・G2・G3 が多い（平地 6.5〜7.9%）。新馬・未勝利・G1・リステッドは少ない |
| 芝ダ・距離・馬場状態 | 芝がダートより少し多い。距離・馬場状態では大きな差は無い。道悪だから荒れる、とは言えない |
| 競馬場 | 福島・小倉（平地 6%台）が多く、阪神・中京・京都が少ない |
| 年 | 年ごとの差は小さい（平地 3.4〜4.9%） |

## 4. どんな馬が勝ったか（1つずつ見て分けた）

WIN5 の対象レースの 144頭は全部、1頭ずつ前の走・過去走・条件の替わり・展開の材料・結果側を並べて見た（`WIN5の事例.csv`）。平地の全体（1,100頭）は、型ごとに数え、代表的な事例を型ごとに3つずつ見た。

見ていて目立ったことを、数えられる形にしたのが、[02-理論.md](02-理論.md) の「馬の側の型」（A〜G）である。WIN5 の 144頭の当てはまり方は次のとおり。1頭が複数の型に当てはまってよい。

| 型 | WIN5 の勝った人気薄（144頭）のうち |
|---|---|
| A 力の見直し（同じかそれより上のクラスで3着以内の実績があるのに、前の走は6着以下） | 53頭 |
| B 前走は条件が合わなかった（前の走は6着以下で、芝ダ・距離・馬場・クラスが今回と違った） | 36頭 |
| C 先行できる展開（逃げ・先行の馬で、逃げ候補が1頭以下のレース） | 38頭 |
| D 近走が良いのに人気が無い（前の走が3着以内など） | 36頭 |
| E ハンデで軽い（ハンデ戦で、斤量が平均より 1kg 以上軽い） | 25頭 |
| F 騎手の上積み（前の走より勝率の高い騎手に替わった） | 19頭 |
| G 前で運べば走る馬が前走は後ろで負けた | 45頭 |
| どれにも当てはまらない | 9頭 |

- 型を2つ以上持っていたのは 86頭（59.7%）。
- どの型にも当てはまらない9頭は、ほとんどが差し・追込の馬で、前半が速くなったレース（前が崩れた展開）で差し切っていた。レースの前に「前が速くなる」と読めたかを、逃げ候補の多さで確かめたが、逃げ候補の多いレースの差し・追込の人気薄が勝ちやすいということは無かった。この9頭は、展開の紛れと見る。
- 結果側で見ると、人気薄が勝ったレースは、ふだんのレースより前半が速く（ハイペースの割合が 33% → 44%）、1番人気が4着以下に沈み（35% → 62%）、2着との差が小さい（ハナ・アタマ差 21% → 30%）。人気薄の勝ちの多くは「力でねじ伏せた」のではなく、「流れが向き、人気馬が崩れ、際どく残った（差し切った）」勝ちである。

## 5. 2026-11-08 の2レース

表は `事例.md` の「詳しく見る日」（5レース全部の勝ち馬の材料と、人気薄2頭の過去走）。

### 1レース目（東京 ダート1600m・3勝クラス・11頭立て）

- 人気: 締め切り前（WIN5 の予想をしたとき）は 11番人気、確定では 9番人気。確定の人気では10番人気以下に入らないので、上の数には入っていない。
- レースの側: 頭数が少なく、1番人気が抜けていて、人気薄の市場合計も小さい。**レースの側からは「荒れそう」とは見えなかった。**
- 馬の側（レースの前に見えていたこと）:
  - 過去走のほとんどを逃げ・先行で運び、前で運んだ走で好走を重ねていた（3着以内の7回のうち6回が逃げ・先行）。2勝クラスを先行して勝って昇級した。
  - 前の走（昇級の初戦。ハンデ戦・稍重）は、いつもと違って後ろからの競馬になり大敗した。**前の走の負けは「いつもの形で走れなかった負け」と読める**（型 G）。
  - このレースは、推定脚質が逃げの馬が1頭もいなかった（型 C。楽に前へ行ける）。
  - 騎手が、前の走より前の年の勝率の高い騎手に替わった（型 F）。
- 結果側: 前半がいつもより遅い流れで、4コーナー3番手から押し切った（2着とハナ差）。1番人気は6着。
- 今のモデル: 1着の確率はオッズから見た勝率とほぼ同じ（上乗せ 1.1 ほど）で、レースの中の順位は9位。

### 4レース目（東京 芝2500m・G2・ハンデ・18頭立て・16番人気）

- レースの側: 18頭立てのハンデ重賞で、1番人気は5倍を超え、人気薄の市場合計も大きい。**レースの側の型（R1〜R4）に全部当てはまる、いちばん荒れそうなレースだった。**
- 馬の側（レースの前に見えていたこと）:
  - 1年前までは1〜2番人気に推される馬で、3勝クラスまで勝ち上がっていた。今年の初めには、同じ格（G2）のハンデ戦で、11番人気で2着に来ていた（型 A。同じ格での好走歴）。
  - その好走のときは逃げていた。過去走を見ると、逃げ・先行で運んだ走で好走し、後ろからの走で負けている。
  - 近3走（G2 の長距離・G1 の道悪・G2 の稍重）は、どれも後ろからの競馬で負けた。**近走の大敗は、条件（長すぎる距離・道悪・別定や定量の重い斤量）と位置取りで説明がつく。** ただし、若いころに差しで好走した回数もあり、逃げ・先行での好走（5回）と差し・追込での好走（5回）が同じ数なので、型 G の決まり（前での好走のほうが多い）にはぎりぎり入らない。この1年に絞れば、前での好走のほうがはっきり多い（次の段で、数える期間を近い走に絞るかを確かめる）。
  - 斤量はレースの平均より少し軽かった（1kg には届かず、型 E には入らない）。
- 結果側: 前半がいつもより速い流れを、4コーナー4番手で運び、上がりは11位ながら粘り込んだ（2着と僅差）。1番人気は10着。
- 今のモデル: 1着の確率はオッズから見た勝率よりやや低く（上乗せ 0.9 ほど）、レースの中の順位は16位。
- WIN5 の予想の記録（100点の買い目）では、このレースを1頭だけ（今のモデルの確率がいちばん高い馬）に決めていた。**いちばん荒れそうなレースを1頭に絞っていた**ことになる。

### 2頭から分かったこと

- どちらも、レースの前に手がかりはあった。手がかりは「近走の着順」ではなく、「過去走の中身（どの形で走ったときに好走したか）」と「同じ格での好走歴」にあった。近走の着順だけを見ると、どちらも買えない馬に見える。
- 今のモデルは、どちらにも市場とほぼ同じ確率を付けていた。今のモデルは市場の評価（単勝オッズ）を材料に持ち、近走の着順や人気から外れる情報を、人気薄についてはほとんど足せていない。
- 4レース目は、レースの側からも「荒れそう」と読めた。1レース目は、レースの側からは読めなかった。
