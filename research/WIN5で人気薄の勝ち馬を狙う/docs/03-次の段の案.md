# 03 次の段の案

**この文書で決めること:** [02-理論.md](02-理論.md) の理論をもとに、①人気薄を選べる予想の学び方、②WIN5 の買い目への入れ方、③確かめ方 を案として書く。**この段では作らない。** 利用者の確認のあとで作る。

**結論（案）:**

| 決めること | 案 |
|---|---|
| 学び方の芯 | 人気薄の行だけで学ぶ「人気薄の1着の予想」を新しく作る。**オッズから見た勝率を出発点にし、モデルはそこからの上げ下げだけを学ぶ**（人気を材料として渡して人気の順をなぞらせるのではなく、市場が見落とす分だけを学ばせる）。材料は今のモデルの材料に、型の材料（前で運んだときの好走・同じ格での好走歴・ハンデの斤量差・騎手の替わり・逃げ候補の数・前走の条件の違い）を足す |
| レースの側 | まずはモデルを作らず、決まり（R1 人気薄に票が残る か R3 ハンデ戦）で「荒れそうなレース」を選ぶ。モデル（人気薄が勝つかの予想）は、決まりに勝てたときだけ使う |
| WIN5 への入れ方 | 荒れそうなレースのうち人気薄の市場合計の大きい1〜2レースに、人気薄の予想の上位2〜3頭を入れ、残りのレースを今の確率で絞る。50点に収める |
| 確かめ方 | 2019〜2024年で学んで選び、2025年〜で確かめる。2025年〜は WIN5 の買い方の確かめで既に2回使っているので、それだけで採用を決めず、年ごとの安定と、2026年11月以降に毎週たまる WIN5 での確かめを足す |

## 1. 人気薄を選べる予想の学び方

### 1.1 なぜ今のモデルのままではだめか

今のモデルは全頭を一緒に学び、目的変数は「1着かどうか」で、市場の評価（単勝オッズ）を材料に持つ。人気薄の1着は全体の約 1% しかないので、学びは人気馬の当たり外れでほぼ決まり、人気薄の中の違いを学ぶ力が残らない（[02 の 4.](02-理論.md#4-今のモデルは人気薄をどう見ていたか)）。今のモデルの出力を並べ替えたり、期待値で絞ったりしても、人気薄の中の違いを学んでいないことは変わらない。だから、学び方そのもの（学ぶ行・人気の与え方・重み）を変える。

### 1.2 案（おすすめ）: 人気薄の行だけで、市場からの上げ下げを学ぶ

| 項目 | 案 | 理由 |
|---|---|---|
| 目的変数 | その人気薄が1着なら 1、それ以外は 0 | WIN5 で要るのは1着の確率 |
| 学ぶ行 | 平地のレースの、10番人気以下の馬だけ（2012年〜。約 25万行・1着 約 2,100） | 人気馬の行を入れると、学びが人気馬の当たり外れで決まってしまう。人気薄の中の違いだけを学ばせる |
| 人気の与え方 | オッズから見た勝率（の対数オッズ）を出発点にする（LightGBM の `init_score`、CatBoost の `baseline`）。人気の順位そのものは材料に入れない | 出発点に市場を置けば、モデルは「市場がどこを見落としているか」だけを学ぶ。人気の順をなぞっても良くならないので、人気順の再現器にならない。穴馬の予想（設計書「穴馬が3着以内に入るかを予想」）で人気順位だけを渡したときに再現器になった反省から |
| 重み | レースごとに人気薄の行の重みの合計をそろえる（人気薄の多い多頭数のレースに学びが偏らないように）。人気薄が勝ったレースの重みを大きくする案は、比べる候補にとどめる | 重みを付けすぎると、確率が全体に高く出て、WIN5 の組の確率が狂う |
| 材料 | 今のモデルの材料（近走・適性・調教・血統・騎手と調教師・市場の評価）に、型の材料を足す: 逃げ・先行と差し・追込それぞれでの好走の回数（近い走に絞った版も）、前の走の位置取りと着順、同じかそれより上のクラスでの3着以内の有無、前の走と今回の条件の違い（芝ダ・距離・馬場・クラス）、ハンデ戦での斤量の平均との差、騎手の前の年の勝率の前の走との差、逃げ候補の数と自分の推定脚質、レースの人気薄の市場合計 | 型 G・E は市場が見落としていた（[02 の 3.](02-理論.md#3-馬の側の型勝ちそうな人気薄)）。騎手・調教師・血統は外さない |
| 時点 | 前日（前日売りの最終オッズ）と当日（馬体重のあと）の2つ。WIN5 の予想と同じく、1レース目の発走から 60分以上あとのレースは前日を使う | WIN5 の予想は締め切り前に1回出す（設計書「近走と適性からWIN5の買い目を決める」07）。木曜はオッズが無く、出発点が作れないので作らない |
| 道具 | LightGBM と CatBoost の両方で学び、平均する（今のモデルと同じ） | |
| 出力の使い方 | 人気薄の1着の確率を、今のモデルの人気馬の確率と合わせて、レースの中で合計 1 にそろえる（人気薄の合計は、人気薄の予想の合計に置き換え、人気馬の確率はその残りで比を保って縮める） | WIN5 の組の確率は、レースの中で合計 1 の確率が要る |

比べる案（次の段で一緒に学んで、上の案に勝てば替える）:

- **条件つきの並べ替え**: 人気薄が勝ったレースだけ（2012年〜で約 2,100レース）を使い、「人気薄のうちどれが勝ったか」をレースの中の並べ替えとして学ぶ（LightGBM の `lambdarank`、CatBoost の `YetiRank`。出発点は同じくオッズから見た勝率）。「人気薄が勝つとしたらどれか」をそのまま学べるが、行が少ない。
- **6〜9番人気も同じ作りで扱う**: 線を 6番人気以下にすると、学ぶ1着が増える（約 4倍）。WIN5 で 6〜9番人気の勝ちも、今の買い目に入りにくい。人気の帯を材料に入れ、帯ごとの成績も見る。

### 1.3 レースの側: 決まりで選び、モデルは決まりに勝ったときだけ

- 決まり: 「R1 人気薄の市場合計が 0.10 以上」か「R3 ハンデ戦」。WIN5 の対象レースの 38% で、人気薄の勝ちの 67% が集まる（[02 の 2.](02-理論.md#2-レースの側の型荒れそうなレース)）。
- モデル案: 1行 = 1レース、目的変数 = 人気薄が勝ったか、出発点 = 人気薄の市場合計、材料 = 頭数・クラス・重量種別・1番人気のオッズ・上位3頭の市場合計・レースの中の型 G・E・C の頭数。過去の研究で、荒れるレース選びの精度は市場のオッズ板を使っても上限が近かったので、決まりより大きく良くなることは期待しない。決まりに勝てなければ使わない。

## 2. WIN5 の買い目への入れ方

### 2.1 まず試すこと: 新しい確率を今の組み方に渡す

今の組み方（1着の確率の順で、予算の中で点数を割り振る `FormationSearch`）は変えず、対象レースの確率を「1.2 の出力の使い方」でそろえた確率に替える。荒れそうなレースで人気薄に確率が回れば、組み方が自然にそのレースを広げるかを見る。作り直しがいちばん少ない。

### 2.2 次に試すこと: 荒れそうなレースに人気薄の枠を取る組み方

今の組み方は、確率の順に詰めるので、確率の小さい人気薄はほとんど入らない（買い目の馬の半分が1〜2番人気）。人気薄の確率が少し上がっても入らないときは、次の決まりを足した組み方を比べる。

- その日の5レースのうち、荒れそうなレース（R1 か R3）を、人気薄の市場合計の大きい順に最大2つ選ぶ。
- 選んだレースには、人気薄の予想の上位から2〜3頭を必ず入れる（人気馬は今の確率の上位1〜2頭）。
- 残りのレースは、今の組み方で残りの点数に収める。

50点（5,000円）の組み方の例:

| その日の荒れそうなレース | 例 |
|---|---|
| 1つ | 荒れそうなレース 5頭（人気馬2・人気薄3）× 残り4レースで 10点（1×1×2×5 など）= 50点 |
| 2つ | 荒れそうなレース 3頭（人気馬1・人気薄2）× 3頭（同じ）× 残り3レースで 5点（1×1×5 など）= 45点 |
| 無い | 今の組み方のまま |

- 拾える割合の目安（人気の順で選んだとき）: R1 か R3 のレースに人気薄を人気の順に3頭入れると、WIN5 の人気薄の勝ち 144 のうち 67（46.5%）が、そのレースの買い目に入る。4頭なら 75（52.1%）。新しい予想の順で選んで、これを上回れるかを見る。
- 引き換え: 荒れそうなレースを広げる分、ほかのレースの点数が減り、人気薄の勝ちの無い日（4日に3日）の的中率は下がる。どちらが得かは、確かめで決める。

## 3. 確かめ方

### 3.1 測るもの

| 指標 | 何を見るか |
|---|---|
| 人気薄の勝ち馬を買い目に含めた割合 | WIN5 の対象レースで人気薄が勝ったとき、その馬がそのレースの買い目に入っていた割合（いまは今の買い目でいくつか、を先に数える） |
| 人気薄の中の並べ方 | 人気薄が勝ったレースで、勝ち馬を人気薄の中の上位1〜4頭に置けた割合。人気の順と比べる（[02 の 3.](02-理論.md#型を数えるだけでは人気の順に勝てなかった) の表と同じ作り） |
| 確率の当たり具合 | 人気薄の行の対数損失を、オッズから見た勝率と比べる。確率の帯ごとの実際の勝率 |
| WIN5 の成績 | 50点の買い方の的中率（日数）・回収率と 90% の幅・年ごと（道具「印の成績」の `--win5` と同じ精算） |

### 3.2 期間

- **学びと選び: 2019〜2024年。** 区切りごとに、その半年より前だけで学び直す（今のモデルの区切りごとの予測と同じ作り）。買い方の候補（2.1 と 2.2、人気薄の頭数 2・3 など）は、この期間の成績で決まりどおりに1つ選ぶ。
- **確かめ: 2025年〜。** ただし 2025年〜は、WIN5 の買い方の確かめで既に2回使っている（240点の買い方の確かめと、50点に決め直したあとの確かめ）。今回は3回目なので、2025年〜の結果だけで採用を決めない。
  - 2019〜2024年の年ごとに、同じ向きの結果が出ているか（1年の大当たりで決まっていないか）を見る。
  - 2025年〜で同じ向きか（回収率の 90% の幅も）を見る。
  - 2026年11月以降に毎週たまる WIN5（まだ誰も見ていない期間）で、予想を出し続けて答え合わせをする。採用の決め手はここに置く。
- 2026-11-08 は事例として見たので、確かめの日には数えない。

### 3.3 比べる相手

- 今の買い方（50点・1着の確率の順・線 1.25）。
- 学びを使わない決まり: 荒れそうなレース（R1 か R3）に、人気薄を人気の順に3頭足すだけ。**新しい予想は、これに勝てなければ意味が無い。**
