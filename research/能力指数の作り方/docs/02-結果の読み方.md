# 02 結果の読み方

比べたこと・分かったこと・決めたことを書く。数値は Git の対象外の `reports/能力指数の作り方/`（`まとめ.md` と `比べ/`）にある。
この文書には数値を書かない。言葉の意味は [01-進め方.md](01-進め方.md#この文書で使う言葉の意味)。

## スピード指数の補正

| 補正 | 分かったこと | 決めたこと |
|---|---|---|
| 馬場差 | いちばん効く。同じ馬の続けた走のぶれが、はっきり減る | 入れる |
| 斤量 | 続けた走の相関では、大きくするほど良く見える（見かけ。[01 の「決め方の注意」](01-進め方.md#決め方の注意)）。同じ馬で斤量だけが変わった走で測ると、1kg あたりの効きは、よく言われる「1kg = 1馬身」よりずっと小さい | 1kg あたり 0.05% |
| ペース | 少し効く。ペース補正の大きさ（タイムで測った得・損）は、スローではどの脚質も遅くなり、後ろの脚質ほど大きく損をする。研究「展開の理論の検証」の結果（スローでは前が有利）と向きが合う | 入れる |
| 大敗の切り上げ | よく効く。レースでいちばん高い指数から 30点で切り上げるのがいちばん良く、それより狭くても広くても下がる | 30点 |

## 能力指数のまとめ方

1回目は、近走の「最高」「上位2走の平均」「平均」「新しい走ほど重く」と、適性を「ふだんとの差の平均」で足すやり方を比べた。

| 比べたこと | 分かったこと | 決めたこと |
|---|---|---|
| まとめ方 | 新しい走ほど重く見る平均がいちばん良い。最高はいちばん悪い（1回の好走に引っ張られる） | 新しい走ほど重く（1つ古い走は 0.7倍） |
| 近走の数・期間 | 5走より少ないと悪くなり、8走より多くしても変わらない。期間は 1〜3年でほとんど変わらない | 近8走・2年以内 |
| 適性を「ふだんとの差の平均」で足す（1回目） | 足さないほうがわずかに良い。1回ごとのぶれを、適性と見誤って足してしまう | 使わない |
| 適性を「今回の条件に近い走ほど重く見る」（2回目） | わずかに良くなる。距離・芝ダが変わるレースで、はっきり良くなる。重みの細かい値（距離の近さ・競馬場・馬場の組）はほとんど効かず、芝ダの重みだけが効く | この入れ方にする。距離は 800m 離れると 0.37倍、違う競馬場 0.9倍、違う馬場の組 0.8倍、違う芝ダ 0.4倍 |

## 確かめ

選ぶのに使っていない期間（2024年から）で当てても、能力指数の相関は少し下がるだけで、年ごとのぶれも小さい。

## 分かっていること・残っていること

- **適性の効きは小さい。** 距離・コース・馬場の適性を入れても、全体の当たり方はわずかしか変わらない。馬の能力の大部分は「基礎の速さ」で決まり、適性は、条件が大きく変わるレース（芝ダ替わり・大きな距離変更）で効く。
- **一度も走っていない条件の適性は分からない。** 初めてのダート・初めての長距離などは、その条件の過去の走が無いので、適性は 0 に近くなる。血統（父の産駒のその条件の成績）で補うことはできるが、この研究ではまだしていない。
- **能力指数は実際の指数より少し低めに出る**（ずれがプラス）。若い馬が成長する分と、調子の悪い馬が出走を控える分と考えられる。順位を比べるのには影響しない。
- 過去走の無い馬（新馬など）と、障害レースには指数を出さない。地方・海外の走は使わない。
