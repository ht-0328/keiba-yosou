# 02 結果の読み方

比べたこと・分かったこと・決めたことを書く。数値は Git の対象外の `reports/能力指数の作り方/`（`まとめ.md` と `比べ/`）にある。
この文書には数値を書かない。言葉の意味は [01-進め方.md](01-進め方.md#この文書で使う言葉の意味)。

## スピード指数の補正

| 補正 | 分かったこと | 決めたこと |
|---|---|---|
| 馬場差 | いちばん効く。同じ馬の続けた走のぶれが、はっきり減る | 入れる |
| 斤量 | 続けた走の相関では、大きくするほど良く見える（見かけ。[01 の「決め方の注意」](01-進め方.md#決め方の注意)）。同じ馬で斤量だけが変わった走で測ると、1kg あたりの効きは、よく言われる「1kg = 1馬身」よりずっと小さい | 1kg あたり 0.05% |
| ペース | 少し効く。ペース補正の大きさ（タイムで測った得・損）は、スローではどの脚質も遅くなり、後ろの脚質ほど大きく損をする。研究「展開の理論の検証」の結果（スローでは前が有利）と向きが合う | 入れる |
| 大敗の切り上げ | よく効く。レースでいちばん高い指数から 30点で切り上げるのがいちばん良く、それより狭くても広くても下がる | 30点 |

## 能力指数のまとめ方

1回目は、近走の「最高」「上位2走の平均」「平均」「新しい走ほど重く」と、適性を「ふだんとの差の平均」で足すやり方を比べた。

| 比べたこと | 分かったこと | 決めたこと |
|---|---|---|
| まとめ方 | 新しい走ほど重く見る平均がいちばん良い。最高はいちばん悪い（1回の好走に引っ張られる） | 新しい走ほど重く（1つ古い走は 0.7倍） |
| 近走の数・期間 | 5走より少ないと悪くなり、8走より多くしても変わらない。期間は 1〜3年でほとんど変わらない | 近8走・2年以内 |
| 適性を「ふだんとの差の平均」で足す（1回目） | 足さないほうがわずかに良い。1回ごとのぶれを、適性と見誤って足してしまう | 使わない |
| 適性を「今回の条件に近い走ほど重く見る」（2回目） | わずかに良くなる。距離・芝ダが変わるレースで、はっきり良くなる。重みの細かい値（距離の近さ・競馬場・馬場の組）はほとんど効かず、芝ダの重みだけが効く | この入れ方にする。距離は 800m 離れると 0.37倍、違う競馬場 0.9倍、違う馬場の組 0.8倍、違う芝ダ 0.4倍 |

## 確かめ

選ぶのに使っていない期間（2024年から）で当てても、能力指数の相関は少し下がるだけで、年ごとのぶれも小さい。
ただし、相関は 2019年の夏から一段下がっている。理由は下の「年ごとの当たり具合」。

## 血統で補う（初めての条件の適性）

近走に同じ条件の走が無い馬（初めての条件。[01 の言葉の意味](01-進め方.md#この文書で使う言葉の意味)）は、その条件の適性が 0 に近くなる。
そこで、父と母の父の産駒が「初めてのその条件」を走ったとき、能力指数よりどれだけ速かったか・遅かったかを平均し、その分を足す候補を比べた
（`tools/共通/ability/pedigree_aptitude.py`）。使う産駒の走は、そのレースの開催日より前のものだけ。数値は `比べ/04-血統で補う.md`。

| 初めての条件 | 分かったこと | 決めたこと |
|---|---|---|
| 芝ダ（芝しか走っていない馬の初めてのダートなど） | 補うと、その走の相関が上がり、ばらつきが減る。選ぶ期間でも、確かめる期間でも同じ向き。父だけより、父と母の父の両方を使うほうが少し良い | 補う（父と母の父。寄せる強さ 20） |
| 距離帯（初めての長距離など） | ほとんど変わらない。寄せる強さを大きくして、足す値をほぼ 0 にしたときだけ、わずかに良い。寄せる強さを小さくする（産駒の走が少ない親の値もそのまま使う）と悪くなる | 補わない |
| 競馬場 | 距離帯と同じ（ほとんど変わらない） | 補わない |
| 馬場の組（初めての道悪など） | 良くならない（変わらないか、少し悪くなる） | 補わない |

- 初めての芝ダの走は全体の1割に満たないので、全部の走の相関は、ほとんど変わらない（下がりはしない）。
- 距離・競馬場・道悪で効かないのは、近い条件の走（1600m と 2000m など）の重みで、その馬自身の適性がある程度もう入っているためと考えられる。
  芝とダートは、違う芝ダの走の重みを小さくしているだけで、その馬のもう一方の芝ダでの力を示す走が無い。

## 年ごとの当たり具合（2020年ごろから少し下がる理由）

`比べ/03-確かめ.md` の年ごとの相関は、2019年までより 2020年からのほうが少し低い。原因の候補を分けて調べた（`比べ/05-年ごとの当たり具合.md`）。

**結論: 下がったのは、能力指数の外れ方が大きくなったからではなく、当てる相手の「馬どうしの差」が小さくなったから。** きっかけは 2019年6月の降級制度の廃止で、
指数の作り方の問題ではないので、直さない。年で比べるときは、2019年6月の前と後を分けて見る。

| 原因の候補 | 確かめたこと | 結論 |
|---|---|---|
| 降級制度の廃止（2019年6月） | 2019年を 1〜5月と 6〜12月に分けると、6月から下がる。外れ方（ばらつき）はほとんど変わらず、指数の広がりが小さくなった。縮んだのはクラスの間の差で、2勝・3勝クラスの古馬の指数の平均が下がり、未勝利の3歳が上がった。クラスの中の広がりは変わらない | 主な原因。降級が無くなり、上のクラスに力の足りない馬が残るようになったためと考えられる。レースの組み方が変わったためで、直せない |
| 無観客の開催（2020年2月29日〜10月9日） | 無観客の期間と、そのあと（観客が戻ってから 2021年末まで）で、相関も外れ方も変わらない | 原因ではない |
| 基準タイム・馬場差の作り方 | レースの水準の差（クラスの強さ）を、降級制度の廃止の前と後で別々に求め直しても、相関・外れ方・続けた走の相関のどれも変わらない | 原因ではない。作り方はそのまま |
| 出走数の変化 | 1頭あたりの使える近走が少し減り、1レースの頭数も少し減った。外れ方はわずかに増えたが、近走を 8走とも使えた走だけで比べても同じだけ増える | 近走の数の減りでは説明できない。外れ方のわずかな増え方の理由は、分かっていない |

## 分かっていること・残っていること

- **適性の効きは小さい。** 距離・コース・馬場の適性を入れても、全体の当たり方はわずかしか変わらない。馬の能力の大部分は「基礎の速さ」で決まり、適性は、条件が大きく変わるレース（芝ダ替わり・大きな距離変更）で効く。
- **一度も走っていない条件の適性は、芝ダだけ血統で補う。** 初めての芝ダは、父と母の父の産駒の、初めてのその芝ダの走から補う（上の「血統で補う」）。
  初めての距離帯・競馬場・道悪は、血統で補っても良くならなかったので補わず、適性は 0 に近いまま。
- **能力指数は実際の指数より少し低めに出る**（ずれがプラス）。若い馬が成長する分と、調子の悪い馬が出走を控える分と考えられる。順位を比べるのには影響しない。
- 過去走の無い馬（新馬など）と、障害レースには指数を出さない。地方・海外の走は使わない。
