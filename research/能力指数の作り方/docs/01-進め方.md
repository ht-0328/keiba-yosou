# 01 進め方

## 何を作るか

レースを1つ指定すると、出走馬を「能力指数」の高い順に並べる。能力指数は、過去の走破タイムを条件の違いで補正して、
「どれだけ速く走れる馬か」を数字にしたもの。利用者の依頼は「あくまで馬の基礎能力の数値化であって、勝ち負けは関係ない」なので、
着順・人気・オッズは使わない。距離・コース・馬場の適性も能力に含める（利用者の指摘による）。

## この文書で使う言葉の意味

この文書に出てくる言葉のうち、分かりにくいものの意味をまとめた。

| 言葉 | 意味 | この研究では（架空の例） |
|---|---|---|
| スピード指数 | 1回の走の速さを、条件の違いを補正して点数にしたもの。80 が基準の水準（1勝クラス・古馬）のふつうの走で、10点 = 1%速い | 基準より実質 0.23% 速ければ 82.3点 |
| 基準タイム（コースの基準） | 競馬場・トラック・距離ごとの、基準の水準のふつうの馬場でのタイム。タイムは対数で扱い、「何%速いか」で比べる | 東京芝1600m = 96.0秒 |
| レースの水準 | クラスと年齢の組（例: 未勝利・2歳）。基準タイムと馬場差を求めるときに、強いレースの多い日を「速い馬場」と見誤らないために使う。**指数からは引かない**（引くと、クラスの違い = 能力の差まで消えるため） | G1・古馬は 1勝クラス・古馬より約2%速い |
| 馬場差（トラックバリアント） | その日・その競馬場・その芝ダの馬場が、ふつうより何%速かったか。その日の全レースの中央値タイムから求める | その日の東京の芝は 0.5% 速かった |
| 斤量補正 | 背負った重さの違いの補正。55kg より重いほど指数を上げる | 1kg あたり 0.05% |
| ペース補正 | 展開で得をした分・損をした分を引く。ペースは研究「展開の理論の検証」で決めた「前後半の差（馬場状態あり）」、位置は JV-Data の脚質判定 | スローで追い込んだ走は損をしているので、その分を足す |
| 大敗の切り上げ | レースでいちばん高い指数より 30点以上低い指数を、その線まで上げる。大きく負けた走は、力を出し切っていないことが多いため | |
| 能力指数 | 近8走（2年以内）のスピード指数を、新しい走ほど・今回の条件に近い走ほど重く見た平均 | |
| 基礎の速さ | 新しさだけで重みを付けた平均（条件を問わない、その馬のいまの力） | |
| 適性（距離・コース・馬場） | その条件の近さを重みに足した平均 − 基礎の速さ。馬場は芝ダと馬場の組（良・稍重 か 重・不良）の両方 | 1600m では、ふだんより +2点 |
| 続けた走の相関 | 同じ馬の、1つ前の走（180日以内）と今回の走のスピード指数の相関。補正がタイムのぶれを取り除くほど上がる | |
| 能力指数の相関 | 能力指数（その走より前の走だけから作る）と、その走のスピード指数の相関。能力指数がその馬の速さをどれだけ言い当てるか | |
| 初めての条件 | 能力指数に使った近走（近8走・2年以内）に、今回と同じ条件の走が無いこと。条件は、距離帯（1400m 以下・1401〜1800m・1801〜2200m・2201m 以上）・競馬場・芝ダ・馬場の組の4つ | 芝しか走っていない馬の、初めてのダート |
| 血統で補う | 初めての条件の馬の能力指数に、父と母の父の産駒が「初めてのその条件」で能力指数よりどれだけ速かったかの平均（全部の馬の平均を引き、産駒の走が少ない親は 0 に寄せたもの）を足す。そのレースより前の産駒の走だけを使う | 父の産駒が初ダートで平均 3点速ければ、初ダートの馬に 3点近くを足す |
| 寄せる強さ | 血統で補うときに、産駒の走が少ない親の値を 0 に寄せる強さ。産駒の走の数に、この数を足して割る | 20 なら、産駒の走が 20回の親の値は半分になる |
| 指数の広がり | その期間の走のスピード指数の標準偏差。馬どうしの差の大きさ。外れ方（ばらつき）が同じでも、広がりが小さいと相関は下がる | |
| 降級制度 | 4歳の夏に、収得賞金を半分にしてクラスを下げる仕組み。JRA は 2019年6月にやめた | 3歳のうちに2勝クラスへ上がった馬が、4歳の夏に1勝クラスへ戻る |

## 手順

| 手順 | 何をするか | 何で決めるか |
|---|---|---|
| 1. スピード指数の補正を決める | 基準タイムだけの指数に、馬場差 → 斤量 → ペース → 大敗の切り上げ を1つずつ足す | 続けた走の相関。ただし斤量は、同じ馬で斤量だけが変わった走どうしの指数の差で測る（下の「決め方の注意」） |
| 2. 能力指数のまとめ方を決める | 近走の数・期間・古い走の重み・適性の入れ方（条件の近さの重み）を1つずつ変える | 能力指数の相関 |
| 3. 確かめる | 選んだ設定を、選ぶのに使っていない期間で当てる | 能力指数の相関が大きく落ちないか。年ごとにぶれないか |
| 4. 道具にする | `tools/能力指数/ability.py` と検索画面の「能力指数」タブ | 合成DB のテスト。CLI と画面が同じ表を出すか |
| 5. 初めての条件を血統で補う | 父・母の父・寄せる強さ・補う条件の候補を比べる | 初めての条件の走の相関とばらつき。選ぶ期間と確かめる期間の両方で良くなるものだけを入れる |
| 6. 年ごとの当たり具合を分ける | 年ごとの相関を、外れ方と指数の広がり（クラスの間とクラスの中）に分け、原因の候補の期間どうしを比べる | 原因が指数の作り方にあるなら直す。無いなら、理由を 02 に書く |

- 基準タイム・水準の差・ペースの基準・ペース補正の大きさは、2023年までのレースで求める。候補を選ぶのは 2016〜2023年の走、確かめるのは 2024年からの走。
- 道具は、DB にある全部の確定成績で基準を求める（予想するレースより前の走だけを使うのは同じ）。

## 決め方の注意

- **斤量は、続けた走の相関で決めない。** 斤量は馬ごとにほぼ決まっていて（古馬は重く、2歳は軽く、強い馬はハンデで重い）、
  補正を大きくするほど「馬ごとに決まった値」を足すことになり、相関がいくらでも上がってしまう。そこで、同じ馬で斤量だけが
  変わった続けた走（同じ芝ダ・距離の差 200m 以内・90日以内）の、指数の差と斤量の差の傾きで測った。この測り方は、好調な馬ほど
  重い斤量を背負わされる分だけ小さく出るので、少し上に丸めた。
- **能力指数のまとめ方の比べでは、当てる指数は同じ**（スピード指数の設定を固定している）なので、相関をそのまま比べられる。
  スピード指数の補正の比べでは、当てる指数そのものが変わるので、主な物差しは続けた走の相関にした。
